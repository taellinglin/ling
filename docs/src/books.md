# The Ling Book (PDF)

The Ling Book is a series of four books written against Ling 2030.1.53. Each one is a
free PDF download. The books are in English.

| Volume | Level | Pages | Download |
|---|---|---|---|
| **Learn Ling** | Beginner | 321 | [ling-beginner.pdf](https://ling-lang.org/books/ling-beginner.pdf) (13 MB) |
| **Build with Ling** | Intermediate | 716 | [ling-intermediate.pdf](https://ling-lang.org/books/ling-intermediate.pdf) (27 MB) |
| **Mastering Ling** | Advanced | 452 | [ling-advanced.pdf](https://ling-lang.org/books/ling-advanced.pdf) (16 MB) |
| **The Ling Reference** | Complete reference | 650 | [ling-reference.pdf](https://ling-lang.org/books/ling-reference.pdf) (26 MB) |

## What each book covers

### Learn Ling (Beginner)

Values and bindings, decisions and loops, functions, lists and text, your first 3D room,
drawing and games, sound and music. It ends with a finished project.

### Build with Ling (Intermediate)

Forms, errors and results, modules and project structure, data and files, UI apps,
animation and input, games and physics, music tools, testing and debugging, and
packaging and shipping.

### Mastering Ling (Advanced)

How Ling runs, concurrency and isolates, network services, web apps with the Rust crates,
cryptography, peer-to-peer protocols, AI and tensors, using the crates from Rust,
extending Ling, Ling OS and embedded targets, and designing large apps.

### The Ling Reference

Every keyword and builtin with its parameters, return value, aliases and examples. The
last chapter lists known limits and gotchas.

## Which one to read

- **New to programming, or new to Ling:** start with *Learn Ling*.
- **Building real programs:** read *Build with Ling*.
- **Going deep:** read *Mastering Ling*.
- **Looking something up:** keep *The Ling Reference* open.

These docs are the short online companion. The books go further and stay on one Ling
version. For quick lookups, the [Builtins Reference](reference/index.md) and the
[Known Limits](language/limits.md) page are often faster.
