# Literals & operators

Literals and operators are spelled the same in every language.

## Literals

| Literal | Meaning |
|---------|---------|
| `true` / `false` | Boolean values |
| `ok` / `bad` | Result success / error |
| `none` | Absent value |
| `123`, `1.5`, `-7` | Numbers |
| `"hello"` | Text |
| `[1, 2, 3]` | List |
| `0..10` | Range (used by `for`) |

## Operators

| Operator | Meaning |
|----------|---------|
| `+` `-` `*` `/` `%` | Arithmetic |
| `==` `!=` `<` `<=` `>` `>=` | Comparison |
| `&&` `\|\|` `!` | Logical and / or / not |
| `=` | Bind / assign |
| `->` | Function return type |
| `.` | Field / method access |
| `\|>` | Pipe |
