# Glossary
A language-switchable reference for every Ling **keyword**, **type**, **literal** and **builtin**. Pick a language from the selector in the top bar — the tables and the sidebar switch to show only that language's spelling.
- **40** keywords · **6** types · **363** builtins across **12** crates.

## Builtins by crate
- [ling (core runtime)](crate-core.md) — I/O, math, noise, time, colour helpers and collections — always available.
- [ling-graphics](crate-graphics.md) — Window, 2-D/3-D drawing, camera, lighting, cel shading, vector textures, surfaces, shadows and SVG export.
- [ling-ui](crate-ui.md) — HUD, meters, controls, game UI widgets and vector fonts.
- [ling-audio](crate-audio.md) — Tone synthesis, WAV playback, microphone capture, spatial SFX, samples and FX.
- [ling-music](crate-music.md) — Music decode/analysis, GM synth, rhythm grading, karaoke and MIDI.
- [ling-physics](crate-physics.md) — Vector maths, forces, soft bodies, rigid + angular bodies and a liquid sim.
- [ling-animation](crate-animation.md) — The Anima procedural-animation drivers: tweens, gaits, springs, gears and IK.
- [ling-ai](crate-ai.md) — Neural nets, behaviour trees and the dialog LLM.
- [ling-crypto](crate-crypto.md) — Hashing, AEAD, signatures and the geometric / post-quantum suite.
- [ling-input](crate-input.md) — Gamepad / joystick polling, sticks, triggers and rumble.
- [ling-net](crate-net.md) — HTTP and WebSocket clients.
- [ling-dialog](crate-dialog.md) — On-screen dialog boxes with typewriter text.
