# Types

Ling is dynamically typed. These type names can appear in annotations such as `x: number` or `-> text`, but annotations are parsed and ignored. See [Types and Values](../language/types.md).

| English | 中文 | 日本語 | 한국어 | ไทย | Description |
|---|---|---|---|---|---|
| `number` | `数` | `数値` | `숫자` | `จำนวน` | Number. Every number is a 64-bit float. |
| `text` | `文` | `文字列` | `문자열` | `ข้อความ` | Text (string). |
| `bool` | `布` | `論理` | `논리` | `ตรรกะ` | Boolean: `true` or `false`. |
| `list` | `列` | `リスト` | `목록` | `รายการ` | List; mixed types, indexed from 0. |
| `map` | `图` | `マップ` | `맵` | `แผนที่` | No such type exists; the name is documentation only. |
| `tuple` | `元` | `タプル` | `튜플` | `สิ่งอันดับ` | No such type exists; the name is documentation only. |
