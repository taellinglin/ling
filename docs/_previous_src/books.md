# The Ling Book

The Ling Book is a four-volume series written against Ling 2030.1.53. Every
volume is a free PDF download.

| Volume | Level | Pages | Download |
|---|---|---|---|
| **Learn Ling** | Beginner | 321 | [ling-beginner.pdf](https://ling-lang.org/books/ling-beginner.pdf) (13 MB) |
| **Build with Ling** | Intermediate | 716 | [ling-intermediate.pdf](https://ling-lang.org/books/ling-intermediate.pdf) (27 MB) |
| **Mastering Ling** | Advanced | 452 | [ling-advanced.pdf](https://ling-lang.org/books/ling-advanced.pdf) (16 MB) |
| **The Ling Reference** | Complete reference | 650 | [ling-reference.pdf](https://ling-lang.org/books/ling-reference.pdf) (26 MB) |

## Which one to read

- **New to programming, or new to Ling:** start with *Learn Ling*: values
  and bindings, decisions and loops, functions, lists and text, your first 3D
  room, drawing and games, sound and music, and a first finished project.
- **Building real programs:** *Build with Ling* covers forms, errors and
  results, modules and project structure, data and files, UI apps, animation
  and input, games and physics, music tools, testing and debugging, and
  packaging and shipping.
- **Going deep:** *Mastering Ling* covers how Ling runs, concurrency and
  isolates, network services, web apps with the Rust crates, cryptography,
  peer-to-peer protocols, AI and tensors, using the crates from Rust,
  extending Ling, Ling OS and embedded targets, and architecting large apps.
- **Looking something up:** *The Ling Reference* documents every keyword and
  builtin with parameters, return values, aliases and examples, and ends
  with a chapter on known limits and gotchas.

These docs are the short, online companion. The books go further and stay
on one Ling version.
