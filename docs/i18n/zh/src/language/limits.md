# 已知限制

Ling 还很年轻，变化很快。本页收集了最容易让人意外的行为，让你能在几分钟而不是几小时内认出它们。
这里的每一条都在当前的 `ling` 程序（2030.1.53）的两个引擎上核实过：默认的 JIT（`ling run`）
和解释器（`ling run --interp`）。

> **提示：** 程序行为异常时，请用 `ling run --interp` 运行一次。解释器会报告未知函数和运行时
> 错误，而 JIT 会悄悄把它们变成 `()`。

## JIT 与解释器对照

| 情况 | JIT（默认） | 解释器 |
|---|---|---|
| 未知的函数名 | 悄悄返回 `()` | `unknown function` 错误 |
| 运行时错误（文件不存在、索引错误等） | 返回 `()` 或空值，继续运行 | 停止，并给出错误和回溯 |
| `1 / 0` | `()` | `inf` |
| 单独写 `pi` 这个名字 | `()`（请写 `pi()`） | 该值 |
| 条件中的 `""` 或 `[]` | 真 | 假 |
| 索引超出列表末尾 | 空值 | `index N out of bounds` 错误 |
| 文本中的单个字符 `s[i]` | 空值 | 该字符（两边都可用 `substr(s, i, 1)`） |
| `历 c 于 "文本"` | 空值 | 逐个字符 |
| 文本排序 `"a" < "b"` | `false` | 错误 |
| `执 { }` 中的 `令` | 之后仍可见 | 被丢弃 |
| 存在变量里的闭包 `f(3)` | `()` | `unknown function 'f'` 错误 |
| 把函数或闭包传给内置函数（`试`、`list_map` 等） | 变成 `()` | 可用 |
| `待 表达式` | `()` | 该值 |
| 打印范围值 `0..5` | `[0, 5]` | `[0, 1, 2, 3, 4]` |
| 构造函数的字段数量不对 | `()` | 错误 |
| 使用缺少的函数参数 | `()` | `undefined` 错误 |
| 直接写在入口点里的 `归` | 悄悄结束程序 | `unexpected top-level return` 错误 |

避开这些角落的程序，在两个引擎上的行为是一样的。

## 没有赋值

`x = x + 1` 是解析错误。请改为重新绑定：`令 x = x + 1`。见
[绑定与重新绑定](syntax.md#绑定与重新绑定)。

## 循环与作用域

| 结构 | 内部的 `令` 会更新外层变量吗？ |
|---|---|
| `循` 的主体 | 会 |
| `若` 的主体 | 会 |
| `历` 的主体 | **不会**：每一轮都得到作用域的一份新副本 |
| `执 { }` 代码块 | JIT 上会，解释器上不会；两种行为都不要依赖 |

要累加总数或构建列表，请使用带计数器的 `循` 循环。

没有 `break` 或 `continue`。`止` 和 `继续` 是不起作用的保留词：在 JIT 上循环照常进行，在解释器
上它们是 `undefined` 错误。请把循环放进函数里然后 `归`，或者使用带标志的 `循`。

## 范围边界必须简单

`0..n` 和 `0..(n + 1)` 可以用。`0..n + 1` 是解析错误，而 `0..长度(xs)` 会悄悄出错（在 JIT 上
循环为空，在解释器上报错）。除了单纯的名字或数字，其他边界都要加括号：`0..(长度(xs))`。

## && 和 || 总是对两边求值

两个引擎都不做短路求值。在 `x != 0 && 10 / x > 1` 中，即使 `x` 是 `0`，除法也照样执行。
右边不能执行时，请使用嵌套的 `若`。

## 数字与文本

- 数字字面量是十进制数字，最多一个小数部分。没有 `1e3`、`0xff`、`1_000`、`.5` 或 `3.`。更糟
  的是，`1e3` 和 `0xff` 并不是解析错误：它们会被读成 `1` 或 `0`，后面跟一个未知的名字。
- 文本只能用双引号，没有插值。请用 `+` 和 `str()` 拼接文本。
- `print` 和 `println`（中文都是 `打印`）都会换行，并且都把参数**不加分隔符**地连在一起：
  `打印("和", 1 + 2)` 打印 `和3`。
- `!x` 的意思是 `x == 假`，所以 `!0` 和 `!""` 都是 `false`。`!` 只用于布尔值。

## 比较结构化值

列表、记录、枚举值和结果之间的 `==` 永远是 `false`，即使内容完全相同。请自己比较元素或字段。
见[类型与值](types.md#比较值)。

## 类型系统能做什么、不能做什么

Ling 是动态类型语言。`x: number` 和 `-> T` 这样的类型标注会被解析然后忽略。没有映射（字典）、
集合、元组，也没有 JSON 解析器。请使用记录或平行列表，或者用 `db_*` 内置函数把数据存进 SQLite。

## 不起作用的关键字

这些词是保留的，但没有任何作用：

`止`（`stop`）、`继续`（`again`）、`变`（`change`）、`出`（`post`）、`予`（`give`）、
`适合`（`fit`）、`能`（`can`）、`确`（`sure`）、`或`（`maybe`）、`纯`（`pure`）、
`启`（`spawn`）、`无`（`none`）

所有权词 `独`、`借`、`共`、`移`、`复` 会被解析然后忽略，不做任何借用或移动检查。`异 函` 同步
运行。`符`（`type`）声明会被丢弃，并吞掉后面的内容。见[关键字](keywords.md)。

## 闭包与函数值

直接调用的闭包表达式 `(|x| x + 1)(5)` 在哪里都可行。除此之外：

- 存在变量里的闭包在解释器上不能按名字调用，在 JIT 上也不可靠。
- JIT 不能把函数或闭包传给内置函数。`list_map`、`list_filter` 等内置函数返回 `()`，`试()`
  总是返回 `坏("try: first argument must be a function")`。它们在解释器上可用。
- 调用 `http_serve` 的程序会自动在解释器上运行，所以闭包和 `试` 在请求处理函数里可以用。

请优先使用具名的顶层 `函` 和普通循环。

## 模块

- `载 "文件"` 把文件加载到同一个共享命名空间。如果两个文件定义了同名函数，最后加载的那个会悄悄
  生效，即使调用者在先加载的文件里也是如此。这也适用于入口点，所以库永远不要绑定 `start` 这样
  的入口名。
- 在 `核` 里调用同一个模块的其他函数时，请写完整名字（`几何::面积`）。只写名字会失败。
- 在 `核` 里绑定的值无法使用。请把常量写成函数。

请在库函数前加上库名作前缀，例如 `geom_area`。见[模块与项目](modules.md)。

## 工具

- `lingfu new` 创建 `src/start.ling`，但除非清单另有说明，`lingfu build` 会去找 `main.ling`。
  请在 `Ling.toml` 的 `[spirit]` 部分加上 `entry = "src/start.ling"`。
- `lingfu check`、`lingfu fmt` 和 `lingfu translate` 调用了不存在的 `ling` 子命令。它们只会打印
  `ling` 的用法说明，什么也不做；`check` 和 `fmt` 仍然报告成功。检查程序请用
  `ling run --interp`，翻译程序请用 `lingfu normalize <语言>`（它会改写当前文件夹中的每个
  `.ling` 文件，所以请在副本上使用）。
- `lingfu normalize` 会写错几个关键字。在中文、韩文和泰文中，它把 `form` 写成词法分析器不接受的
  词（请使用[关键字](keywords.md#拼写)中的写法）；它把 `choose` 保留为英文；在日文和泰文中，它
  把 `ok`/`bad` 写成不能用作 `配` 模式的内置函数名。一些所有权词（`copy`、`lend`、`share`）在
  日文和泰文中也会出错。请运行结果，并手动修正这些词。
- `lingfu build` 用 Cargo 编译生成的 Rust 代码，所以需要 Rust 工具链。

## 测试

`lingfu test` 在 JIT 上运行测试，而 JIT 遇到运行时错误不会停止，所以失败的测试也可能打印
`All tests passed!`。请让测试打印清楚的 `PASS` 或 `FAIL` 行并检查它，或者用
`ling run --interp` 运行测试。放在 `tests/` 里的辅助文件会被当作测试，并以 `no entry point`
失败，所以请把辅助文件放在别处。

## 解析陷阱

- 以 `-` 或 `[` 开头的行会接续上一行。
- `形 P { x: number, y: number }` 是解析错误。带标注的字段列表请以逗号结尾：
  `形 P { x: number, y: number, }`。
- 空闭包需要一个空格，写作 `| | 表达式`，因为 `||` 是"或"。
- `函 main() { ... }` 不是入口点。请用 `令 main = 执 { ... }`。
- `assert`、`panic`、`exit`、`append_file` 和 `delta_time` 都不是内置函数。要计算帧时间，请把
  相邻两次 `time_now()` 的值相减。
