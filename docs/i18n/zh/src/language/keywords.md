# 关键字

Ling 的每个关键字都有英文写法，以及中文、日文、韩文和泰文写法。词法分析器会把每种写法转换成
同一个记号，所以你可以用一种语言写完整个程序，也可以混用多种语言。本页列出所有关键字、它们的
写法，以及它们目前真正的作用。

有些关键字是为将来的功能保留的，现在还不起作用。下面都做了标注，这样当 `止`（`stop`）没能
跳出循环时，你就不会感到意外。

## 拼写

一个单元格里有多种写法时，每一种都能用，第一种是常用写法。这些写法取自词法分析器
（`src/lexer/mod.rs`），也就是运行时真正接受的写法。它和 `lexicons/*.ling` 有几处不一致，
以词法分析器为准：例如日文的 `choose` 是 `選択`，韩文的 `form` 是 `구조`，泰文的 `form` 是
`โครงสร้าง`。

## 各关键字的作用

| 关键字 | 状态 | 作用 |
|---|---|---|
| `令` (`bind`) | 有效 | 创建或替换绑定。也用来定义全局值和入口点。 |
| `执` (`do`) | 有效 | 代码块，值为最后一条语句的值。 |
| `函` (`fn`) | 有效 | 声明函数。 |
| `若` / `否` (`if` / `else`) | 有效 | 条件表达式。 |
| `循` (`while`) | 有效 | 条件成立时循环。主体与外层共享作用域。 |
| `历` / `于` (`for` / `in`) | 有效 | 遍历范围或列表。每一轮都有新的作用域。 |
| `配` (`match`) | 有效 | 模式匹配。 |
| `归` (`return`) | 有效 | 带着一个值离开当前函数。 |
| `形` (`form`) | 有效 | 声明记录类型。 |
| `选` (`choose`) | 有效 | 声明枚举类型，变体可携带值。 |
| `核` (`mod`) | 有效 | 把函数归入命名空间（`名字::f()`）。 |
| `载` / `为` (`use` / `as`) | 有效 | 加载另一个文件，可以起别名。 |
| `好` / `坏` (`ok` / `bad`) | 有效 | 构造结果，也可作为模式匹配结果。 |
| `真` / `假` (`true` / `false`) | 有效 | 布尔值。 |
| `试` (`try`) | 内置函数 | 不是语法，而是内置函数 `试(f, 参数...)`。只在解释器上可用。 |
| `符` (`type`) | 忽略 | `符 名字 为 T` 被解析后丢弃。它会吞掉后面的内容，请避免使用。 |
| `条件` (`where`) | 忽略 | `函 f(x) 条件 ... { }`：直到 `{` 为止的内容都被跳过。 |
| `异` (`async`) | 忽略 | `异 函` 和普通函数一样同步运行。 |
| `待` (`wait`) | 不可靠 | 在解释器上得到值，在 JIT 上得到 `()`。不要使用。 |
| `独` `借` `共` `移` `复` (`own` `lend` `share` `move` `copy`) | 忽略 | 前缀词，原样返回操作数。不做任何所有权检查。 |
| `asm` | 忽略 | `asm("...")` 是为裸机构建准备的。普通运行时没有实际作用。 |
| `止` (`stop`) | 保留 | **不会**跳出循环。 |
| `继续` (`again`) | 保留 | **不会**进入下一轮循环。 |
| `变` (`change`) | 保留 | 没有作用。请用 `令` 重新绑定。 |
| `出` `予` `适合` `能` `确` `或` `纯` (`post` `give` `fit` `can` `sure` `maybe` `pure`) | 保留 | 没有作用。对解析器来说是普通名字。 |
| `启` (`spawn`) | 保留 | 没有作用，也没有 `spawn` 内置函数。 |
| `无` (`none`) | 保留 | 不是一个值。解释器会报 `undefined: 'none'`。表示"什么都没有"请用 `()`。 |

**保留**词对解析器来说是普通名字，所以 `令 止 = 2` 是合法的。在解释器上，循环中单独写的 `止`
或 `继续` 会引发 `undefined` 错误；在 JIT 上会被悄悄忽略，循环照常进行。

## 有效关键字

### 令（bind）

`令 名字 = 表达式` 是创建或"修改"变量的唯一方式。再次绑定同一个名字就会替换它。见
[绑定与重新绑定](syntax.md#绑定与重新绑定)。

```ling
令 始 = 执 {
  令 价格 = 40
  令 价格 = 价格 + 2
  打印(价格)
}
```
```output
42
```

### 执（do）

`执 { ... }` 按顺序执行语句，值为最后一条语句的值。入口点就是绑定到 `始` 等名字的 `执`
代码块。见[代码块](syntax.md#代码块)。

### 函与归（fn、return）

`函 名字(参数) { 主体 }` 声明函数。最后一个表达式就是结果，`归` 用于提前返回。

```ling
函 描述(n) {
  若 n > 100 { 归 "大" }
  "小"
}
令 始 = 执 {
  打印(描述(500))
  打印(描述(5))
}
```
```output
大
小
```

直接写在入口点里的 `归`，在 JIT 上会悄悄结束程序，在解释器上则是错误
（`unexpected top-level return`）。

### 若、否、循、历、于（if、else、while、for、in）

控制流关键字见[控制流](syntax.md#控制流)。没有 `break` 或 `continue`：`止` 和 `继续` 只是
保留词。要提前离开循环，请从函数中 `归`：

```ling
函 查找(列表, 目标) {
  历 x 于 列表 {
    若 x == 目标 { 归 真 }
  }
  假
}
令 始 = 执 {
  打印(查找([1, 2, 3], 2))
  打印(查找([1, 2, 3], 9))
}
```
```output
true
false
```

### 配（match）

`配 值 { 模式 => 表达式, ... }` 执行第一个匹配的分支。模式包括 `_`、字面量、名字、
`好(p)` / `坏(p)` 和枚举变体。见 [match](syntax.md#match)。

### 形与选（form、choose）

`形` 声明记录类型，`选` 声明枚举。见[记录与枚举](syntax.md#记录与枚举)。

```ling
选 信号灯 { 红, 黄, 绿 }
函 动作(灯) {
  配 灯 {
    红() => "停",
    黄() => "慢",
    绿() => "行"
  }
}
令 始 = 执 {
  打印(动作(绿()))
  打印(红().tag)
}
```
```output
行
红
```

### 核、载、为（mod、use、as）

`核 名字 { ... }` 把函数分组，用 `名字::f()` 调用。`载 "文件.ling"` 加载另一个文件，
`载 "文件.ling" 为 m` 让它的函数以 `m::f()` 的形式可用。见[模块与项目](modules.md)。

### 好与坏（ok、bad）

`好(值)` 和 `坏(原因)` 构造结果。在 `配` 中它们是模式。`坏` 结果打印为 `Err(...)`。见
[错误与结果](errors.md)。

```ling
函 一半(n) {
  若 n % 2 == 0 { 好(n / 2) } 否 { 坏("奇数") }
}
令 始 = 执 {
  打印(一半(10))
  打印(配 一半(7) { 好(v) => v, 坏(e) => "错误：" + e })
}
```
```output
Ok(5)
错误：奇数
```

### 真与假（true、false）

布尔字面量。`若` 和 `循` 的条件应该使用它们。

## 解析后被忽略的关键字

所有权词 `独`、`借`、`共`、`移`、`复` 可以写在表达式（或参数名）前面，然后被忽略。没有借用
检查器，`移` 之后继续使用原值也没问题：

```ling
令 始 = 执 {
  令 a = 独 [1, 2, 3]
  令 b = 移 a
  打印(a)
  打印(b)
}
```
```output
[1, 2, 3]
[1, 2, 3]
```

`异 函` 声明的是普通函数，调用时立即运行。函数参数后面的 `条件` 子句会被跳过：

```ling
异 函 工作(n) { n * 2 }
函 下一个(x) 条件 x { x + 1 }
令 始 = 执 {
  打印(工作(4))
  打印(下一个(2))
}
```
```output
8
3
```

真正的并行工作请使用 `thread_*` 内置函数。

## 看起来像关键字但不是的词

- `start`、`main`、`启`、`เริ่ม` 和 `시작` 是名字，不是关键字。运行时靠它们找到入口点。见
  [入口点](syntax.md#入口点)。
- `result`、`loop`、`break`、`continue`、`struct`、`enum`、`let`、`const` 等词出现在某些词库
  文件里，但它们不是关键字。Ling 没有 `loop` 也没有 `let`：请用 `循` 和 `令`。
- `number`、`text`、`bool`、`list`、`map`、`tuple` 只是文档用词。Ling 是动态类型语言。见
  [类型与值](types.md)。
