# 用五种语言编写

你可以用英语、中文、日语、韩语或泰语编写 Ling。每个关键字在这五种语言里都有对应的写法，
大多数常用内置函数也是如此。解释器同时接受所有写法：不需要切换任何设置，你甚至可以在
同一个文件、同一行里混用多种语言。

## 同一个程序，写五遍

下面是同一个小程序的五个版本。关键字、内置函数、名称、注释和文本都使用该语言，
每个版本都能直接运行。

**English**

```ling
# Count the fruit in a basket
fn describe(n) {
    if n == 1 {
        return "1 fruit"
    } else {
        return to_str(n) + " fruits"
    }
}

bind start = do {
    bind basket = ["apple", "pear", "plum"]
    for fruit in basket {
        print("- ", fruit)
    }
    print(describe(len(basket)))
    print("square root of 16: ", sqrt(16))
}
```

```output
- apple
- pear
- plum
3 fruits
square root of 16: 4
```

**中文**

```ling
# 数一数篮子里的水果
函 描述(数量) {
    若 数量 == 1 {
        归 "1 个水果"
    } 否则 {
        归 to_str(数量) + " 个水果"
    }
}

令 始 = 执 {
    令 篮子 = ["苹果", "梨", "李子"]
    历 水果 于 篮子 {
        打印("- ", 水果)
    }
    打印(描述(长度(篮子)))
    打印("16 的平方根：", 平方根(16))
}
```

```output
- 苹果
- 梨
- 李子
3 个水果
16 的平方根：4
```

**日本語**

```ling
# かごの果物を数える
関数 説明(個数) {
    もし 個数 == 1 {
        戻る "果物 1 個"
    } 他 {
        戻る "果物 " + to_str(個数) + " 個"
    }
}

束縛 開始 = 実行 {
    束縛 かご = ["りんご", "なし", "すもも"]
    繰 果物 の中 かご {
        印刷("- ", 果物)
    }
    印刷(説明(長さ(かご)))
    印刷("16 の平方根：", 平方根(16))
}
```

```output
- りんご
- なし
- すもも
果物 3 個
16 の平方根：4
```

**한국어**

```ling
# 바구니 속 과일 세기
함수 설명(개수) {
    만약 개수 == 1 {
        반환 "과일 1개"
    } 아니면 {
        반환 "과일 " + to_str(개수) + "개"
    }
}

바인드 시작 = 실행 {
    바인드 바구니 = ["사과", "배", "자두"]
    위해 과일 안에 바구니 {
        출력("- ", 과일)
    }
    출력(설명(길이(바구니)))
    출력("16의 제곱근: ", 제곱근(16))
}
```

```output
- 사과
- 배
- 자두
과일 3개
16의 제곱근: 4
```

**ไทย**

```ling
# นับผลไม้ในตะกร้า
ฟังก์ชัน บรรยาย(จำนวน) {
    ถ้า จำนวน == 1 {
        คืน "ผลไม้ 1 ผล"
    } มิฉะนั้น {
        คืน "ผลไม้ " + to_str(จำนวน) + " ผล"
    }
}

ผูก เริ่ม = ทำ {
    ผูก ตะกร้า = ["แอปเปิล", "สาลี่", "พลัม"]
    สำหรับ ผลไม้ ใน ตะกร้า {
        พิมพ์("- ", ผลไม้)
    }
    พิมพ์(บรรยาย(ความยาว(ตะกร้า)))
    พิมพ์("รากที่สองของ 16: ", รากที่สอง(16))
}
```

```output
- แอปเปิล
- สาลี่
- พลัม
ผลไม้ 3 ผล
รากที่สองของ 16: 4
```

有几点值得注意：

- 你自己起的名字（`describe`、`篮子`、`かご`、`바구니`、`ตะกร้า`）可以使用这些文字中的任何一种。
- 程序从值为 `do` 块的那个绑定开始执行，所以你可以把它命名为 `start`、`始`、`開始`、
  `시작` 或 `เริ่ม`。
- `to_str` 在每个版本里都保持英文，因为它在这些语言里没有别名。英文名称永远可用。
- 当文件使用其他语言时，`ling run` 会向标准错误输出一条简短提示，例如
  `[detected language: Thai (ภาษาไทย)]`。程序本身的输出不受影响。

## 关键字

最常用的关键字：

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `bind` | `令` | `束縛` | `바인드` | `ผูก` |
| `do` | `执` | `実行` | `실행` | `ทำ` |
| `fn` | `函` | `関数` | `함수` | `ฟังก์ชัน` |
| `return` | `归` | `戻る` | `반환` | `คืน` |
| `if` | `若` | `もし` | `만약` | `ถ้า` |
| `else` | `否则` | `他` | `아니면` | `มิฉะนั้น` |
| `while` | `循` | `間` | `동안` | `ขณะที่` |
| `for` | `历` | `繰` | `위해` | `สำหรับ` |
| `in` | `于` | `の中` | `안에` | `ใน` |
| `match` | `配` | `一致` | `매치` | `จับคู่` |
| `form` | `形` | `形` | `구조` | `โครงสร้าง` |
| `ok` | `好` | `良い` | `좋아` | `ตกลง` |
| `bad` | `坏` | `悪い` | `나쁨` | `ผิดพลาด` |
| `true` | `真` | `真` | `참` | `จริง` |
| `false` | `假` | `偽` | `거짓` | `เท็จ` |

有些关键字不止一种写法（中文的 `如` 也表示 `if`，韩语的 `반복` 也表示 `while`）。
完整列表见[关键字](../glossary/keywords.md)。

## 内置函数

内置函数也一样：`print`、`打印`、`印刷`、`출력` 和 `พิมพ์` 是同一个函数。

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `print` | `打印` | `印刷` | `출력` | `พิมพ์` |
| `len` | `长度` | `長さ` | `길이` | `ความยาว` |
| `sqrt` | `平方根` | `平方根` | `제곱근` | `รากที่สอง` |
| `abs` | `绝对值` | `絶対値` | `절댓값` | `ค่าสัมบูรณ์` |
| `max` | `最大` | `最大` | `최댓값` | `สูงสุด` |
| `rand` | `随机` | `乱数` | `난수` | `สุ่ม` |
| `list_push` | `列表添加` | `リスト追加` | `목록추가` | `เพิ่มรายการ` |
| `open_window` | `开窗` | `ウィンドウ開く` | `창열기` | `เปิดหน้าต่าง` |
| `window_is_open` | `窗开` | `開いている` | `창열림` | `หน้าต่างเปิดอยู่` |
| `fill` | `填` | `塗り潰し` | `채우기` | `เติม` |
| `present` | `显` | `表示` | `표시` | `แสดงผล` |
| `set_color` | `设色` | `色設定` | `색설정` | `สีดินสอ` |
| `key_down` | `按键` | `キー押す` | `키누름` | `กดค้าง` |
| `audio_blip` | `提示音` | `ビープ音` | `효과음` | `เสียงบี๊บ` |
| `time_now` | `当前时间` | `経過時間` | `현재시간` | `เวลาปัจจุบัน` |

哪些内置函数有别名：

- **五种语言都有：** 打印、数学、列表、窗口与帧循环、2D 和 3D 绘图、大部分键盘输入、
  音频与音乐播放、时间，以及 `ui_*` 控件。
- **只有英文：** 大部分文本辅助函数（`to_str`、`to_number`、`str_upper`、`str_split` 等）、
  `write_file` 之类的文件函数、音乐工作站（`daw_*`），以及大部分 Web 服务器、数据库和
  请求辅助函数（`http_*`、`db_*`、`query_param`、`json_escape`）。其中一些有泰语别名
  （`http_route` 也可以写成 `เว็บเส้นทาง`，`db_open` 也可以写成 `ฐานข้อมูลเปิด`），
  但没有中文、日语或韩语别名。

[按 Crate 分类的内置函数](../glossary/builtins.md)页面列出了每个内置函数及其别名。

> **提示：** 在默认引擎上，拼错或未知的名称不会报错，调用只会返回 `()`。例如 `长`
> 不是内置函数（`len` 的中文是 `长度`）。如果某个调用看起来什么都没做，请运行
> `ling run --interp yourfile.ling`，它会以 `unknown function` 报错停止。

## 在一个文件里混用多种语言

你完全可以把几种语言放在一起使用：

```ling
# English, Chinese, Japanese, Korean and Thai in one file
函 double(x) {
    归 x * 2
}

bind start = do {
    束縛 n = 21
    만약 n > 10 {
        พิมพ์("double: ", double(n))
    }
    print(长度([1, 2, 3]))
}
```

```output
double: 42
3
```

当你参考另一种语言写的示例，或者团队共享代码时，这很方便。对于需要长期维护的项目，
每个项目只用一种语言会更易读。

## 用 lingfu normalize 转换项目

`lingfu normalize` 会把整个项目改写成一种语言。在项目文件夹里运行：

```sh
lingfu normalize --dry-run zh    # 只显示会改动什么
lingfu normalize zh              # 改写为中文
lingfu normalize en              # 再改回英文
```

语言可以是 `en`、`zh`、`ja`、`ko` 或 `th`（也可以写名称，例如 `thai`）。

- 它会翻译当前文件夹（包括子文件夹）中每个 `.ling` 文件里的关键字和内置函数名称。
- 它还会**重命名**它知道如何翻译的文件和文件夹。加上 `--content-only` 只修改文件内容，
  加上 `--files-only` 只重命名。
- 它不会翻译你自己起的名称、注释或文本，这些需要手动处理。
- 目标语言中没有别名的内置函数保留英文名称。

> **警告：** `normalize` 会直接修改文件。请先提交你的工作或做一份备份，并且只在项目自己的
> 文件夹里运行它。

转换之后，请运行一次程序进行检查，尤其要注意 `form`、`ok` 和 `bad`：如果新的写法无法解析
或者不起作用，就换成上面关键字表中的写法。
内置函数也可能受影响：如果转换后的某个调用突然返回 `()`，请运行 `ling run --interp`，
它会指出未知的函数名，然后把那个调用改回英文名称。
