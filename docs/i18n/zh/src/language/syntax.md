# 语法

本页介绍 Ling 程序的写法：程序布局、字面量、运算符、绑定、函数和控制流。每个例子都用当前的
`ling` 程序实际运行过。Ling 有两个执行引擎：默认的 JIT（`ling run`）和解释器
（`ling run --interp`）。两者行为不同的地方，本页都会指出；[已知限制](limits.md)把所有差异
汇总在一处。

本页的代码用中文关键字书写。每个关键字的英文和其他语言写法见[关键字](keywords.md)。

## 程序结构

Ling 文件由一系列顶层**条目**组成：

| 条目 | 形式 | 参见 |
|---|---|---|
| 绑定 | `令 名字 = 表达式` | [绑定与重新绑定](#绑定与重新绑定) |
| 函数 | `函 名字(a, b) { ... }` | [函数](#函数) |
| 记录类型 | `形 名字 { 字段, 字段 }` | [记录与枚举](#记录与枚举) |
| 枚举类型 | `选 名字 { 变体, 变体(a) }` | [记录与枚举](#记录与枚举) |
| 模块 | `核 名字 { 函 ... }` | [模块与项目](modules.md) |
| 导入 | `载 "文件.ling"` | [模块与项目](modules.md) |

`打印(...)` 这样的语句不能写在顶层，只能写在函数里或入口点里。

### 入口点

程序从一个值为 `执` 代码块的顶层绑定开始运行：

```ling
令 始 = 执 {
  打印("你好，Ling！")
}
```
```output
你好，Ling！
```

运行时按以下顺序查找这些名字的绑定：`start`、`main`、`启`、`เริ่ม`、`시작`，以及其他几种
语言中的同义词。如果都没有，就运行第一个值为 `执` 代码块的顶层绑定，上面例子里的 `始` 就是
这样被找到的。如果文件里没有这样的绑定，它就是一个库，`ling run` 会报 `no entry point`
并停止。

```ling
令 main = 执 {
  打印("main 也可以")
}
```
```output
main 也可以
```

> `函 main() { ... }` **不是**入口点。请写 `令 main = 执 { ... }`。

## 注释与语句

注释从 `#` 或 `//` 开始，到行尾结束。没有块注释。语句之间用换行分隔。语句末尾可以加 `;`，
这样就能把两条语句写在同一行。

```ling
# 井号注释
// 斜杠注释
令 始 = 执 {
  打印("甲") // 行尾注释
  打印("乙"); 打印("丙")
}
```
```output
甲
乙
丙
```

## 标识符

名字以字母或 `_` 开头，后面可以跟字母、数字和 `_`。任何 Unicode 字母都算，所以中文、日文、
韩文和泰文名字都可以用。名字区分大小写。

```ling
令 始 = 执 {
  令 名前 = "Ling"
  令 ชื่อ = 3
  打印(名前)
  打印(ชื่อ + 1)
}
```
```output
Ling
4
```

目前还不起作用的关键字（例如 `变`（`change`）、`止`（`stop`）、`或`（`maybe`），见
[关键字](keywords.md)）对解析器来说只是普通名字，所以 `令 止 = 2` 可以运行。但不要把
`历`（`for`）、`若`（`if`）这样的有效关键字当作名字使用。给中文变量起名时也要注意，
`可`、`或`、`为`、`于` 这些单字都是关键字。

## 字面量

| 字面量 | 形式 | 说明 |
|---|---|---|
| 数字 | `42`、`3.14` | 十进制数字，最多一个小数部分。所有数字都是 64 位浮点数。 |
| 文本 | `"你好"` | 只能用双引号。可以跨行。转义：`\n` `\t` `\r` `\"` `\\` `\0`。 |
| 布尔值 | `真`、`假` | |
| 单元值 | `()` | 表示"什么都没有"。 |
| 列表 | `[1, "二", 3.5]` | 元素可以是任意类型，从 0 开始编号。 |
| 范围 | `0..5` | 左闭右开：0、1、2、3、4。用于 `历`。 |
| 闭包 | `\|x\| x + 1` | 见[闭包](#闭包)。 |

没有 `1e3`、`0xff`、`1_000`、`.5` 或 `3.` 这些写法。没有字符字面量（`'a'` 是解析错误），
没有映射字面量，也没有元组。文本没有插值：`"{x}"` 就是这三个字符本身。请用 `+` 和 `str()`
拼接文本。未知的转义（如 `\q`）会原样保留，包括反斜杠。

```ling
令 始 = 执 {
  打印("第一行\n第二行")
  打印("引号：\"q\" 反斜杠：\\")
  打印(1.5 + 1)
  打印([1, "二", 3.5, 真])
  打印(())
}
```
```output
第一行
第二行
引号："q" 反斜杠：\
2.5
[1, 二, 3.5, true]
()
```

## 运算符与优先级

从结合最紧到最松：

| 级别 | 运算符 | 说明 |
|---|---|---|
| 1 | `.` `()` `[]` `::` `..` | 字段或方法、调用、索引、模块路径、范围 |
| 2 | `-x` `!x` | 前缀负号和取反 |
| 3 | `*` `/` `%` | `%` 也适用于小数：`7.5 % 2` 是 `1.5` |
| 4 | `+` `-` | `+` 拼接文本；只要一边是文本，另一边的数字就会转成文本 |
| 5 | `==` `!=` `<` `>` `<=` `>=` | |
| 6 | `&&` | |
| 7 | `\|\|` | |

所有二元运算符都是左结合：`10 - 3 - 2` 等于 `5`。

```ling
令 始 = 执 {
  打印(2 + 3 * 4)
  打印((2 + 3) * 4)
  打印(10 - 3 - 2)
  打印(-3 + 5)
  打印(2 * -4)
  打印(1 < 2 && 2 < 3)
  打印("n=" + 5)
  打印(7 / 2)
}
```
```output
14
20
5
2
-8
true
n=5
3.5
```

需要注意：

- `&&` 和 `||` 在两个引擎上都**总是对两边求值**。`x != 0 && 10 / x > 1` 并不能保护除法。
  请改用嵌套的 `若`。
- 比较运算向左结合：`1 == 1 == 1` 的意思是 `(1 == 1) == 1`，结果是 `false`。
- 前缀负号不能叠用：`- - x` 是解析错误。`0 - x` 总是可行。
- 列表、记录和枚举值之间的 `==` 永远是 `false`。见[类型与值](types.md#比较值)。

## 绑定与重新绑定

`令 名字 = 表达式` 给一个值起名字。Ling 没有赋值语句：`x = 5` 是解析错误。要"修改"一个值，
就再绑定一次同一个名字。从那里开始，新绑定会取代旧绑定。

```ling
令 始 = 执 {
  令 x = 1
  令 x = x + 10
  令 x = x * 2
  打印(x)
}
```
```output
22
```

代码块结束后，块内的重新绑定是否仍然可见，取决于是哪种代码块：

| 位置 | 代码块结束后的重新绑定 |
|---|---|
| `若` / `否` 的主体 | 保留 |
| `循` 的主体 | 保留，所以 `循` 循环可以累加 |
| `历` 的主体 | **丢失**：每一轮都从一份新的副本开始 |
| `配` 的分支 | 丢失 |
| 函数体 | 只在本次调用内有效 |
| `执 { }` 代码块 | 解释器上丢失，JIT 上保留；两种行为都不要依赖 |

```ling
令 始 = 执 {
  令 总数 = 0
  历 i 于 1..5 { 令 总数 = 总数 + i }
  打印(总数)
  令 和 = 0
  令 i = 1
  循 i < 5 {
    令 和 = 和 + i
    令 i = i + 1
  }
  打印(和)
}
```
```output
0
10
```

顶层的 `令` 是全局常量。函数可以读取它，但函数永远看不到调用者的局部绑定：

```ling
令 倍率 = 3
函 放大(n) { n * 倍率 }
令 始 = 执 {
  令 倍率 = 100
  打印(放大(2))
}
```
```output
6
```

## 代码块

`执 { ... }` 按顺序执行其中的语句，它的值就是最后一条语句的值。入口点就是一个 `执` 代码块，
凡是能写表达式的地方都可以使用它：

```ling
令 始 = 执 {
  令 总计 = 执 {
    令 a = 20
    令 b = 22
    a + b
  }
  打印(总计)
}
```
```output
42
```

## 函数

`函 名字(参数) { 主体 }` 在顶层（或 `核` 内）声明一个函数。函数的结果是主体中最后一个表达式。
`归 值` 提前返回，单独的 `归` 返回 `()`。函数可以递归，声明顺序不限，但不能嵌套在其他函数里。

```ling
函 斐波那契(n) {
  若 n < 2 { 归 n }
  斐波那契(n - 1) + 斐波那契(n - 2)
}
函 问候(名字) { "你好，" + 名字 + "！" }
令 始 = 执 {
  打印(斐波那契(15))
  打印(问候("Ling"))
}
```
```output
610
你好，Ling！
```

- `函 f(a: number) -> text` 这样的类型标注会被接受，然后被忽略。
- 如果传入的参数太少，缺少的参数是未定义的。使用它时，解释器会报错，JIT 则得到 `()`。
- 调用不存在的函数，解释器会报错，但 JIT 会悄悄返回 `()`。程序"什么也不做"时，请用
  `ling run --interp` 运行一次。

## 闭包

闭包写作 `|参数| 表达式`，例如 `|x| x * 2`。没有参数的闭包需要加一个空格：`| | 42`，因为
`||` 是"或"运算符。

直接调用闭包表达式在哪里都可行：

```ling
令 始 = 执 {
  打印((|x| x + 1)(5))
}
```
```output
6
```

闭包是目前语言中最不可靠的部分。存放在变量里的闭包在解释器上不能按名字调用，而 JIT 不能把
闭包（或函数名）传给 `list_map`、`尝试`（`try`）这样的内置函数。请优先使用具名的 `函`。
见[已知限制](limits.md#闭包与函数值)。

## 控制流

### if / else

`若`（`if`）是一个表达式。花括号必不可少，条件不需要括号。没有 `否`（`else`）时，条件为假的
`若` 得到 `()`。

```ling
令 始 = 执 {
  令 n = 7
  令 标签 = 若 n < 0 { "负数" } 否 若 n == 0 { "零" } 否 { "正数" }
  打印(标签)
}
```
```output
正数
```

条件里请使用真正的布尔值。两个引擎对 `""` 和 `[]` 的看法不同，见[类型与值](types.md#真值判断)。

### while

`循 条件 { 主体 }`（`while`）在条件成立时反复执行。主体与外层共享作用域，所以计数和求和要用它。

```ling
令 始 = 执 {
  令 n = 27
  令 步数 = 0
  循 n != 1 {
    令 n = 若 n % 2 == 0 { n / 2 } 否 { 3 * n + 1 }
    令 步数 = 步数 + 1
  }
  打印(步数)
}
```
```output
111
```

### for

`历 名字 于 序列 { 主体 }`（`for ... in`）对范围或列表中的每一项执行一次主体。范围 `lo..hi`
在 `hi` 之前停止。

```ling
令 始 = 执 {
  历 i 于 1..4 { 打印(i * i) }
  历 名字 于 ["ada", "lin"] { 打印(str_upper(名字)) }
}
```
```output
1
4
9
ADA
LIN
```

没有 `break` 或 `continue`。要提前结束，可以把循环放进函数里然后 `归`，或者使用带标志的 `循`。

### match

`配 值 { 模式 => 表达式, ... }`（`match`）从上到下逐个尝试分支，执行第一个匹配的分支。模式有：

| 模式 | 匹配 |
|---|---|
| `_` | 任何值 |
| `0`、`"是"`、`真` | 该字面量 |
| `名字` | 任何值，并把它绑定到 `名字` |
| `好(p)`、`坏(p)` | 结果（见[错误与结果](errors.md)） |
| `变体(p, ...)`、`变体()` | 枚举值 |

```ling
函 分类(n) {
  配 n {
    0 => "零",
    1 => "一",
    其他 => "很多（" + str(其他) + "）"
  }
}
令 始 = 执 {
  打印(分类(0))
  打印(分类(9))
}
```
```output
零
很多（9）
```

如果没有分支匹配，`配` 得到 `()`。没有守卫条件，也没有针对列表或记录的模式。

## 记录与枚举

`形`（`form`）声明记录类型。按字段顺序调用类型名即可创建记录，用 `.` 读取字段：

```ling
形 点 { x, y }
令 始 = 执 {
  令 p = 点(3, 4)
  打印(p)
  打印(p.x + p.y)
}
```
```output
点 { x: 3, y: 4 }
7
```

`选`（`choose`）声明枚举，它的变体可以携带值。调用变体来构造值，用 `配` 拆开它。不带值的变体
也要写括号：`圆点()`。变体的名字可以通过 `.tag` 取得。

```ling
选 形状 { 圆(r), 矩形(w, h), 圆点 }
函 面积(s) {
  配 s {
    圆(r) => 3 * r * r,
    矩形(w, h) => w * h,
    圆点() => 0
  }
}
令 始 = 执 {
  打印(面积(圆(2)))
  打印(面积(矩形(3, 4)))
  打印(面积(圆点()))
  打印(矩形(1, 2).tag)
}
```
```output
12
12
0
矩形
```

记录不能修改，需要时请新建一个。不支持 `点 { x: 1, y: 2 }` 这样的字面量写法。用错误的字段
数量调用构造函数，解释器会报错，JIT 则得到 `()`。

## 解析陷阱

- **以 `-` 或 `[` 开头的行会接续上一行。** `令 x = 5` 的下一行如果是 `-1`，`x` 就变成 `4`；
  以 `[1, 2]` 开头的行会被当作索引。
- **范围边界。** `0..n + 1` 是解析错误，`0..长度(xs)` 会悄悄出错。除了单纯的名字或数字，
  其他边界都要加括号：`0..(n + 1)`、`0..(长度(xs))`。
- **`形` 中的字段标注。** `形 P { x: number, y: number }` 是解析错误，因为紧挨 `}` 的标注会
  吞掉右花括号。请在字段列表末尾加逗号：`形 P { x: number, y: number, }`。
- **没有赋值。** `x = x + 1` 是解析错误。请写 `令 x = x + 1`。
- **空闭包。** 请写 `| | 表达式`，不要写 `|| 表达式`。
