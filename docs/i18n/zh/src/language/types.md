# 类型与值

Ling 是动态类型语言。你从不需要声明类型：每个值都带着自己的类型，运算符和内置函数在运行时检查
它。本页列出值的种类、它们的打印形式、它们在条件和比较中的行为，以及如何在类型之间转换。

## 值的种类

| 类型 | 例子 | 来源 | 打印为 |
|---|---|---|---|
| 数字 | `3`、`2.5`、`-7` | 数字字面量、算术运算 | `3`、`2.5` |
| 文本 | `"abc"` | 文本字面量、`+`、文本内置函数 | `abc` |
| 布尔值 | `真`、`假` | 字面量、比较 | `true` |
| 单元值 | `()` | `()`、没有结果的函数、查找失败 | `()` |
| 列表 | `[1, "a", 真]` | 列表字面量、`新建列表`、列表内置函数 | `[1, a, true]` |
| 记录 | `点(3, 4)` | 调用 `形` 声明的名字 | `点 { x: 3, y: 4 }` |
| 枚举值 | `圆(2)`、`圆点()` | 调用 `选` 声明的变体 | `圆(2)` |
| 结果 | `好(5)`、`坏("e")` | `好` 和 `坏` | `Ok(5)`、`Err(e)` |
| 函数 | `\|x\| x + 1` | 闭包 | |

没有映射（字典）、集合、元组、字符类型，也没有 `null`。键值数据可以用列表、记录或平行列表
表示，也可以用 `db_*` 内置函数存进 SQLite。`x: number`、`-> text` 这样的类型标注会被解析器
接受，然后被忽略。

```ling
形 点 { x, y }
令 始 = 执 {
  打印(42)
  打印("文本")
  打印(真)
  打印(())
  打印([1, "a", 真])
  打印(点(3, 4))
  打印(好(5))
  打印(坏("不行"))
}
```
```output
42
文本
true
()
[1, a, true]
点 { x: 3, y: 4 }
Ok(5)
Err(不行)
```

### 数字

所有数字都是 64 位浮点数。整数打印时不带小数点，2^53 以内的整数是精确的，除法总是给出精确的商。

```ling
令 始 = 执 {
  打印(7 / 2)
  打印(10 / 5)
  打印(7 % 3)
  打印(0.1 + 0.2)
  打印(1000000 * 1000000)
}
```
```output
3.5
2
1
0.30000000000000004
1000000000000
```

除以零不是错误。在解释器上 `1 / 0` 是 `inf`；在 JIT 上是 `()`。两者的 `0 / 0` 都是 `NaN`。

### 文本

文本是 Unicode 字符序列。`长度` 计算的是字符数而不是字节数，`+` 拼接文本。只要 `+` 的一边
是文本，另一边就会转成文本。

```ling
令 始 = 执 {
  打印(长度("héllo"))
  打印("甲" + "乙")
  打印("n=" + 5)
  打印(5 + "！")
}
```
```output
5
甲乙
n=5
5！
```

用 `s[i]` 读取单个字符只在解释器上可行。要在两个引擎上都取得一个字符，请用 `substr(s, i, 1)`。

### 列表

列表可以存放任意类型的值，从 0 开始编号。列表内置函数返回新列表，所以一定要绑定结果：
`令 xs = 列表添加(xs, v)`。读取超出末尾的位置，在 JIT 上得到空值，在解释器上会以
`index N out of bounds` 停止。列表内置函数见[文本与列表](../reference/text-lists.md)。

### 单元值

`()` 表示"什么都没有"。最后一个表达式没有值的函数返回 `()`；条件为假且没有 `否` 的 `若`，
以及没有分支匹配的 `配`，也得到 `()`。

### 记录、枚举值与结果

记录来自 `形`，枚举值来自 `选`，结果来自 `好` 和 `坏`。用 `.名字` 读取记录字段，用 `.tag`
读取枚举值的变体名，用 `配` 打开结果。见[记录与枚举](syntax.md#记录与枚举)和
[错误与结果](errors.md)。

## 真值判断

`若` 和 `循` 应该使用真正的布尔值。其他值也能用，但两个引擎的看法并不完全一致：

| 条件中的值 | JIT（默认） | 解释器 |
|---|---|---|
| `真` / `假` | 真 / 假 | 真 / 假 |
| `0` | 假 | 假 |
| `()` | 假 | 假 |
| 其他数字、非空文本、非空列表 | 真 | 真 |
| `""`（空文本） | **真** | 假 |
| `[]`（空列表） | **真** | 假 |

判断是否为空请明确地写 `长度(xs) == 0` 或 `s == ""`。另外，`!x` 的意思是 `x == 假`，所以
`!0` 和 `!""` 都是 `false`。`!` 只用于布尔值。

## 比较值

`==` 和 `!=` 按值比较数字、文本、布尔值和 `()`。不同类型的值永远不相等：`1 == "1"` 是 `false`。

**列表、记录、枚举值和结果永远不相等**，即使内容完全相同。请自己逐个比较元素或字段。

```ling
形 P { x }
令 始 = 执 {
  打印("abc" == "abc")
  打印(1 == "1")
  打印([1, 2] == [1, 2])
  打印(P(1) == P(1))
  打印(P(1).x == P(1).x)
}
```
```output
true
false
false
false
true
```

`<`、`>`、`<=`、`>=` 用于数字。对文本排序（`"a" < "b"`）在 JIT 上得到 `false`，在解释器上
是错误。

## 类型转换

| 内置函数 | 转换 | 说明 |
|---|---|---|
| `str(v)` | 任意值转文本 | 与 `打印` 显示的文本相同。也叫 `to_str`。 |
| `to_number(s)` | 文本转数字 | 忽略两端空格。文本不是数字时返回 `0`。 |
| `hex_to_number(s)` | 十六进制文本转数字 | 不带 `0x` 前缀：`hex_to_number("ff")` 是 `255`。 |
| `取整(x)` | 数字转整数 | 截掉小数部分（向零取整）。英文为 `int`，也叫 `trunc`。 |
| `向下取整(x)` / `向上取整(x)` | 数字转整数 | 向下 / 向上取整。英文为 `floor` / `ceil`。 |
| `四舍五入(x)` | 数字转整数 | 0.5 远离零舍入。英文为 `round`。 |

```ling
令 始 = 执 {
  打印(str(3) + "！")
  打印(to_number(" 4 ") + 1)
  打印(to_number("abc"))
  打印(取整(-3.7))
  打印(向下取整(-2.5))
  打印(四舍五入(2.5))
  打印(hex_to_number("ff"))
}
```
```output
3！
5
0
-3
-3
3
255
```

没有能告诉你值的类型的内置函数，也没有把值转成布尔值的内置函数。因为 `to_number` 对无效输入
返回 `0`，如果 `0` 也是合法答案，请先检查文本。[错误与结果](errors.md#验证输入)演示了做法。
