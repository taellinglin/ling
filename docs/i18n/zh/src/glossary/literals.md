# 字面量与运算符

字面量和运算符在所有语言中写法都相同，只有 `true` 和 `false` 有各自语言的写法。

## 字面量

| 字面量 | 含义 |
|---|---|
| `42`、`3.14` | 数字。所有数字都是 64 位浮点数。没有十六进制或指数写法。 |
| `"hello"` | 文本。只能用双引号。转义：`\n` `\t` `\r` `\"` `\\` `\0`。不支持插值。 |
| `true`、`false` | 布尔值 |
| `()` | 单元值，表示“无” |
| `[1, "two", 3.0]` | 列表；可混合类型，从 0 开始编号 |
| `0..5` | 范围，左闭右开：0、1、2、3、4。与 `for` 一起使用。 |
| `\|x\| x + 1` | 函数值（闭包） |
| `ok(v)`、`bad(e)` | 结果值 |

没有字符、映射或元组字面量。

## 各语言的布尔值

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `true` | `真` | `真` | `참` | `จริง` |
| `false` | `假` | `偽` | `거짓` | `เท็จ` |

## 运算符

按结合从紧到松排列：

| 运算符 | 含义 |
|---|---|
| `.` `()` `[]` `::` `..` | 字段或方法、调用、索引、路径、范围 |
| `-x` `!x` | 取负、逻辑非 |
| `*` `/` `%` | 乘、除、取余 |
| `+` `-` | 加、减。`+` 也能拼接文本。 |
| `==` `!=` `<` `>` `<=` `>=` | 比较 |
| `&&` | 逻辑与 |
| `\|\|` | 逻辑或 |

其他符号：`bind name = value` 中的 `=`，`match` 中模式与结果之间的 `=>`，以及返回类型前的 `->`
（会被解析但被忽略）。在解释器中，`&&` 和 `||` 总会计算两边。详见[已知限制](../language/limits.md)。
