# 类型

Ling 是动态类型语言。这些类型名可以出现在 `x: number` 或 `-> text` 这样的标注中，但标注只会被解析，然后被忽略。详见[类型与值](../language/types.md)。

| English | 中文 | 日本語 | 한국어 | ไทย | 说明 |
|---|---|---|---|---|---|
| `number` | `数` | `数値` | `숫자` | `จำนวน` | 数字。所有数字都是 64 位浮点数。 |
| `text` | `文` | `文字列` | `문자열` | `ข้อความ` | 文本（字符串）。 |
| `bool` | `布` | `論理` | `논리` | `ตรรกะ` | 布尔值：`true` 或 `false`。 |
| `list` | `列` | `リスト` | `목록` | `รายการ` | 列表；可混合类型，从 0 开始编号。 |
| `map` | `图` | `マップ` | `맵` | `แผนที่` | 不存在这种类型，这个名字仅用于文档。 |
| `tuple` | `元` | `タプル` | `튜플` | `สิ่งอันดับ` | 不存在这种类型，这个名字仅用于文档。 |
