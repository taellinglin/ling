# 3D 形状与网格

这些内置函数把物体放进 3D 场景：约二十多种参数化实体、原始三角形和线段、铺在平面上的 `vtex_*` 矢量图案、
`tex_*` 像素纹理，以及从文件加载的网格（Ling 自有格式和 glTF）。这里的一切都需要一个已打开的窗口和
[窗口与摄像机](window.md) 中的摄像机。光源、着色风格和后期处理在 [后期特效与光照](postfx.md)。

3D 调用不会立即绘制。它们进入一个**深度队列**，在 `present()`（或 `flush_3d()`）时排序并绘制，
所以在一帧之内你可以按任意顺序调用它们。

## 基本实体

每个实体都接受相同的参数：

```text
name(cx, cy, cz,  sx, sy, sz,  rx, ry, rz,  mode,  e0, e1, e2)
```

| 参数 | 含义 |
|---|---|
| `cx, cy, cz` | 世界坐标中的中心 |
| `sx, sy, sz` | 各轴缩放（默认 1）。形状半径约为一个单位，所以缩放大致等于半尺寸：`cube(0, 0, 8, 1, 1, 1)` 是边长 2 的立方体 |
| `rx, ry, rz` | 以弧度为单位的旋转（默认 0），按 X、Y、Z 的顺序应用 |
| `mode` | `0` 实心（默认），`1` 线框，`2` 两者 |
| `e0, e1, e2` | 形状特有的额外参数（见下表）；0 或省略表示默认值 |

只有位置是必需的；末尾的参数可以省略。画笔颜色（`set_color`）是填充色和线框色。
实体由场景光源照亮，并以卡通风格着色。

记住 +y 朝下。`cone` 的顶点在 +y，所以不旋转时它指向屏幕下方；绕 x 旋转 π 可以翻过来。
`gear` 和 `torus` 位于 x-z 平面；绕 x 旋转约 1.57 让它们面向摄像机。

```ling-gui
令 start = 执 {
    开窗(900, 600, "形状")
    深度测试(1)
    令 帧号 = 0
    循 窗开() {
        填(8, 10, 24)
        设镜(1, 0, 1, 0)
        清灯()
        加灯(-2, -6, -2, 1.0, 0.95, 0.85, 0.6, 0)
        令 角 = 帧号 * 0.03
        设色(230, 120, 90)
        立方体(-2.8, 0, 7.5, 0.8, 0.8, 0.8, 角, 角 * 0.7, 0, 0)
        设色(120, 200, 255)
        球体(0, 0, 7.5, 0.9, 0.9, 0.9, 0, 0, 0, 0)
        设色(190, 190, 200)
        齿轮(2.8, 0, 7.5, 0.9, 0.3, 0.9, 1.57, 角 * 2, 0, 0, 14, 0.3)
        显()
        令 帧号 = 帧号 + 1
    }
}
```

### 各实体说明

- **`cylinder`** 沿局部 y 轴从 -1 延伸到 1，所以高度为 `2 * sy`。较小的 `sy`（如 0.05）可以做成圆盘或圆板。
- **`torus`**：`tube` 是管半径占外半径的比例（0.02 到 0.9）。
- **`frustum`**：顶部比例是顶部半径与底部半径之比。接近 0 是圆锥，1 是圆柱；比例小、`sy` 高就成了方尖碑。
- **`gear`**：厚度由 `sy` 决定；齿数范围 3 到 96，齿深 0.02 到 0.6。
- **`stairs`**：每级台阶在 +y 和 +z 方向各前进一级。由于 +y 朝下，楼梯看起来是越远越低；绕 `rz` 旋转 π 可以翻转。
- **`gyro`** 在交替的轴上嵌套万向环；**`capsule_chain`** 沿 x 轴排列珠子。
- 骰子类实体（`tetrahedron` 到 `icosahedron`）用 `mode` 2 和明亮的颜色看起来像宝石。

```ling-gui
令 start = 执 {
    设色(255, 140, 180)
    二十面体(0, 0, 8, 1, 1, 1, 0.4, 0.7, 0, 2)
    圆锥(3, 0, 8, 0.8, 1, 0.8, 3.14159, 0, 0, 0)       # 顶点朝上
}
```

## 三角形、线段与深度测试

| 内置函数 | 中文 | 日本語 | 한국어 | ไทย | 用途 |
|---|---|---|---|---|---|
| `draw_triangle_3d(ax, ay, az, bx, by, bz, cx, cy, cz)` | — | — | — | — | 一个受光三角形 |
| `draw_quad_3d(...)`, `draw_polygon_3d(...)` | — | — | — | — | 受光的凸多边形 |
| `draw_line_3d(ax, ay, az, bx, by, bz)` | — | — | — | — | 按深度排序的线段 |
| `set_depth_test(on)` | `深度测试` | `深度テスト` | `깊이테스트` | `ทดสอบความลึก` | 逐像素深度缓冲区 |
| `clear_depth()` | — | — | — | — | 在帧中途清空深度缓冲区 |

### `draw_triangle_3d`、`draw_quad_3d` 和 `draw_polygon_3d`

用画笔颜色绘制世界空间几何体，带光照、雾效，并在近平面裁剪。
`draw_triangle_3d` 接受三个点；顶点顺序决定哪一面朝向光源。
`draw_quad_3d` 接受四组 `x, y, z`（12 个数）；`draw_pent_3d` 和 `draw_hex_3d` 分别接受 5 组和 6 组。
它们与 `draw_polygon_3d` 共用同一实现，后者也接受单个扁平列表 `[x0, y0, z0, x1, y1, z1, ...]`。最多使用 8 个顶点。

```ling-gui
令 start = 执 {
    设色(120, 200, 255)
    draw_quad_3d(-2, 1, 8, 2, 1, 8, 2, 1, 12, -2, 1, 12)     # 一块地砖
    draw_polygon_3d([0, -1, 8, 1, 0, 8, 0, 1, 8, -1, 0, 8])  # 一个菱形
}
```

### `draw_line_3d(ax, ay, az, bx, by, bz)`

两个世界点之间的线段，与其他内容一起按深度排序，并在近平面裁剪。用 `set_antialias(1)` 得到平滑的线。

### `set_depth_test(on)` 和 `clear_depth()`

深度测试默认关闭：排队的几何体按从远到近的顺序绘制。只要实体可能相交，或使用环境光遮蔽、轮廓线和景深时，
就把它打开（`1`）。`fill()` 每帧已经会清空深度缓冲区；`clear_depth()` 用于在帧中途开始新的深度绘制。

## 矢量图案：`vtex_*`

每个 `vtex_*` 调用在 **3D 空间中的一个平面**上绘制动态线条图案。前九个参数对所有图案都相同，最后两个总是 `fr` 和 `hue`：

```text
vtex_name(cx, cy, cz,  ux, uy, uz,  vx, vy, vz,  ...图案参数...,  fr, hue)
```

`cx, cy, cz` 是中心。`u` 是图案中“右”的方向，`v` 是“上”的方向。`fr` 是你提供的帧计数器，驱动颜色和运动；
`hue` 偏移颜色，使相邻图案有所区别。颜色会自行循环成彩虹，不使用画笔颜色。

| 平面 | `u` | `v` |
|---|---|---|
| 地板或天花板 | `1, 0, 0` | `0, 0, 1` |
| 面向摄像机的竖直墙面 | `1, 0, 0` | `0, -1, 0` |
| 竖直的侧墙 | `0, 0, 1` | `0, -1, 0` |

竖直图案使用 `v = (0, -1, 0)`，因为 +y 朝下。这些图案只是简单的线段，所以开销很小；
它们会稍微向摄像机方向偏移绘制，从而贴在同一位置的表面之上。

|---|---|---|---|---|---|
| `vtex_grid` | `纹格` | `格子模様` | `격자무늬` | `ลายตาราง` | 列 10，行 10，单元宽 1，单元高 1 |

| `vtex_star` | `纹星` | `星模様` | `별무늬` | `ลายดาว` | 角数 6，外径 2，内径 1，每帧旋转 0.01 |
| `vtex_spiral` | `纹螺` | `螺旋模様` | `나선무늬` | `ลายเกลียว` | 圈数 3，最大半径 3，步数 120 |
| `vtex_flower` | `纹花` | `花模様` | `꽃무늬` | `ลายดอกไม้` | 半径 1，边数 24（生命之花） |
| `vtex_halftone` | `纹半调` | `ハーフトーン` | `하프톤무늬` | `ลายจุด` | 列 16，行 12，单元宽 0.5，单元高 0.5，密度 0.4 |

| `vtex_letter_rain` | — | — | — | — | 列 16，可见 14，列宽 0.65，行高 0.6，速度 0.025 |
| `vtex_lotus` | `纹莲` | `蓮模様` | `연꽃무늬` | `ลายดอกบัว` | 内半径 1，外半径 2，花瓣 12 |

        纹塔(3, 1.9, 8, 1, 0, 0, 0, -1, 0, 5, 1.6, 0.5, 0.72, 0.2, 帧号, 2)

`orb_shell(cx, cy, cz, radius, rot_y, rot_x, density, r, g, b)` 是这些图案的近亲：缠绕在球体上的交错螺旋构成的半透明外壳
（`density` 1 到 48，默认 10；色调默认为浅灰）。别名：zh `球壳`，ja `オーブ殻`，ko `오브껍질`，th `เปลือกทรงกลม`。

## 像素纹理：`tex_*`

`tex_*` 内置函数逐像素地、**立即**用程序化图案填充一个屏幕矩形。和其他 2D 调用一样，它们会被排队的 3D 几何体覆盖。
所有函数都以像素矩形 `x, y, w, h` 开头（默认 0, 0, 256, 256）。

每次调用都要计算每个像素，所以大纹理很慢。尽量把它们做小，或者只画一次并留在屏幕上。

接受 `palette` 的地方可以是 `"rainbow"`、`"fire"`、`"ocean"`、`"psychedelic"`、`"neon"` 或 `"forest"`；
未知名称回退为 rainbow。

| 内置函数 | 用途 |
|---|---|
| `tex_checkerboard(x, y, w, h, tiles, r1, g1, b1, r2, g2, b2)` | 双色棋盘格（8 格，白与黑） |
| `tex_gradient(x, y, w, h, angle_deg, r1, g1, b1, r2, g2, b2)` | 沿某角度的线性渐变（0 为从左到右） |
| `tex_noise(x, y, w, h, scale, octaves, seed, palette)` | 分形噪声（scale 4，octaves 1 到 8） |
| `tex_spiral(x, y, w, h, freq, bands, time, palette)` | 随 `time` 旋转的螺旋条带 |
| `tex_ripple(x, y, w, h, freq, cx, cy, time, palette)` | 从 `cx, cy`（矩形内 0 到 1）扩散的波纹 |
| `tex_mandelbrot(x, y, w, h, zoom, cx, cy, max_iter, palette)` | 曼德博集合 |
| `tex_julia(x, y, w, h, c_re, c_im, max_iter, palette)` | 朱利亚集合（c = -0.7 + 0.27i） |
| `tex_voronoi(x, y, w, h, cells, seed, palette)` | 沃罗诺伊单元（16 个） |
| `tex_halftone(x, y, w, h, dot_size, time, palette)` | 半调网点 |
| `tex_freq_map(x, y, w, h, time, speed, palette)` | 来自最近一次 `fft_bands` 调用的频谱（参见 [音频](audio.md)） |

`tex_mandelbrot` 在两个方向上都显示复平面的 `1 / zoom` 个单位，所以 `zoom` 为 1 时只能看到主心形区；
要看到整个集合，请用约 0.4。

```ling-gui
令 start = 执 {
    开窗(660, 340, "tex")
    填(0, 0, 0)
    tex_checkerboard(10, 10, 200, 150, 8, 240, 240, 240, 30, 30, 60)
    tex_noise(230, 10, 200, 150, 5, 4, 7, "fire")
    tex_mandelbrot(450, 10, 200, 150, 0.4, -0.5, 0, 64, "psychedelic")
    显()
    wait_window()
}
```

## 网格

Ling 可以绘制你用列表构建的网格、它自有的二进制网格格式，以及 glTF 模型。它们都通过摄像机投影，并与 3D 场景的其他部分一起排队。

### `draw_mesh(positions, indices, ox, oy, oz, scale, mode)`

绘制存储在两个列表中的三角形网格：`positions` 是扁平的 `[x0, y0, z0, x1, y1, z1, ...]`，
`indices` 每个三角形列出三个顶点编号。每个顶点先乘以 `scale`（默认 1），再平移 `ox, oy, oz`。
`mode` 为 `0` 时用画笔颜色受光绘制；为 `1` 时每个三角形一种彩虹色。无效的索引会被忽略。

```ling-gui
令 start = 执 {
    令 顶点 = [0, -1, 8, 1, 1, 8, -1, 1, 8, 0, 0, 10]
    令 索引 = [0, 1, 2, 0, 2, 3, 0, 3, 1]
    设色(200, 160, 255)
    draw_mesh(顶点, 索引, 0, 0, 0, 1, 0)
}
```

### `mesh_load(path)` 和 `mesh_draw(id, x, y, z, scale, yaw)`

`mesh_load` 读取 `.lmesh` 文件（一种每个三角形一种纯色的紧凑格式），返回句柄或 `-1`。
`mesh_draw` 以自身颜色**不受光**地绘制它，参数为位置、统一缩放和偏航角。
更多可选参数（`sway`、`arm`、`lean`、`leg`、`tuck`，默认 0）用于让角色网格变形：`sway` 使上身倾斜，`arm` 让手臂摆动。
`mesh_free(id)` 释放几何数据。`mesh_load` 的别名：zh `载入网格`，ja `メッシュ読込`，ko `메시로드`，th `โหลดเมช`。

### glTF 模型：`gltf_*`

`gltf_load(path)` 读取 `.glb` 或 `.gltf` 文件（包括骨架、蒙皮和动画），返回句柄或 `-1`。
glTF 是 Y 轴朝上的；绘制函数会替你把它翻转到 Ling 的 Y 轴朝下的世界中。

| 内置函数 | 用途 |
|---|---|
| `gltf_load(path)` | 加载模型；句柄或 `-1` |
| `gltf_draw(h, x, y, z, scale, yaw)` | 以静止姿态受光绘制 |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | 带纹理绘制，姿态取自动画片段在 `time` 秒时的状态 |
| `gltf_anim_count(h)`, `gltf_anim_name(h, i)`, `gltf_anim_dur(h, i)` | 动画片段：数量、名称、时长（秒） |
| `gltf_bounds(h, clip, time)` | 按绘制结果计算的 `[minx, miny, minz, maxx, maxy, maxz]`，在 glTF 空间中 |
| `gltf_tris(h)` | 三角形数量 |
| `gltf_mesh_count(h)`, `gltf_mesh_name(h, i)` | 模型中的网格 |
| `gltf_mesh_show(h, i, on)` | 在之后的绘制中显示或隐藏某个网格（装备、服装） |
| `gltf_mesh_tint(h, i, color)` | 用打包颜色乘以某个网格 |
| `gltf_joint_count(h)`, `gltf_joint_name(h, j)` | 骨架的骨骼 |

在 `gltf_bounds` 中 y 朝上，所以在地面高度 `gy`、以缩放 `s` 绘制的模型，其顶部位于 `gy - maxy * s`。

```ling-gui
令 start = 执 {
    开窗(800, 600, "模型")
    深度测试(1)
    令 狐狸 = gltf_load("models/fox.glb")
    令 片段 = 0
    循 窗开() {
        填(20, 24, 40)
        清灯()
        加灯(-3, -6, 2, 1.0, 1.0, 1.0, 1.0, 0)
        若 狐狸 >= 0 {
            令 时长 = gltf_anim_dur(狐狸, 片段)
            gltf_anim_draw_tex(狐狸, 0, 2, 8, 0.02, 当前时间(), 片段, 当前时间() % 最大(时长, 0.01))
        }
        显()
    }
}
```

## 带纹理网格：`tm_*`

`tm_*` 系列为 3D 游戏绘制带纹理的几何体。纹理和网格各自有句柄。

| 内置函数 | 用途 |
|---|---|
| `tm_tex_load(path, size)` | 把 PNG、SVG 或 SVGZ 加载为 `size` 像素的正方形纹理（默认 256）；id 或 `-1` |
| `tm_load(path)` | 加载 `.ltm` 网格（带名字的带纹理三角形组）；id 或 `-1` |
| `tm_groups(m)`, `tm_group(m, name)`, `tm_group_name(m, g)`, `tm_group_tris(m, g)` | 查看网格的分组 |
| `tm_bounds(m, g)` | 某一组的 `[minx, miny, minz, maxx, maxy, maxz]`，`g = -1` 时为全部 |
| `tm_edges(m, g, max)` | 以扁平线段列表返回轮廓边，用于小地图和线框 |
| `tm_draw(m, g, tex, x, y, z, scale, rot, tint, alpha, ...)` | 把一组加入队列，作为带纹理三角形绘制 |
| `tm_sprite(tex, cx, cy, w, h, rot, tint, alpha, blend)` | 直接绘制到屏幕上的旋转纹理矩形 |
| `tm_billboard(tex, x, y, z, size, rot, tint, alpha, blend)` | 3D 中始终面向摄像机的纹理方块 |
| `tm_quad(tex, x, y, z, ux, uy, uz, vx, vy, vz, tint, alpha, blend)` | 任意朝向的纹理四边形（贴花） |
| `tm_wire(kind, x, y, z, size, rx, ry, rz, color, detail, thick)` | 线框形状 |
| `tm_solid(kind, x, y, z, size, rx, ry, rz, color, alpha, blend)` | 多面、平面着色的水晶实体 |

通用约定：`tint` 和 `color` 是打包的 `0xRRGGBB` 数字（默认白色），`alpha` 从 0 到 1，`blend` 为 `0` 普通或 `1` 叠加。
纹理 id 为 `-1` 表示内置的柔和光点；对 `tm_quad` 来说，`-2` 是柔和的圆形阴影。

- **`tm_draw`** 之后的参数依次是 `uoff, voff, uscale, vscale`（纹理滚动和缩放）、`shade`（0 到 1，使背光的面变暗）、
  `blend` 和 `cull`（`0` 不剔除，`1` 或 `2` 剔除一种绕向）。`rot` 是偏航角或按行排列的 3×3 列表。它返回加入队列的三角形数。
- **`tm_sprite`** 绘制到 2D 帧缓冲区，所以要做 HUD 或标题卡时，请在 `flush_3d()` 之后调用。
- **`tm_wire`** 的种类：`0` 立方体、`1` 四面体、`2` 八面体、`3` 二十面体、`4` 圆环、`5` 球、`6` 环、`7` 星柱、`8` 网格。
  `size` 是半径；`thick` 为 1 时笔画加倍。
- **`tm_solid`** 的种类：`0` 立方体、`1` 四面体、`2` 八面体、`3` 二十面体、`9` 碎片（拉长的八面体）。

```ling-gui
令 start = 执 {
    开窗(800, 600, "水晶")
    令 t = 0.0
    循 窗开() {
        填(6, 8, 20)
        混合模式(1)
        tm_wire(3, -2, 0, 8, 1, t, t * 0.7, 0, 65535, 12, 1)
        混合模式(0)
        tm_solid(9, 2, 0, 8, 0.8, 0, t, 0, 16744576, 0.8, 1)
        显()
        令 t = t + 0.02
    }
}
```
