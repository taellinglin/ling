# 窗口与摄像机

每个图形 Ling 程序都要打开一个窗口、运行帧循环，并对准唯一的 3D 摄像机。
本页介绍这三件事：窗口及其帧循环、帧率控制与计时，以及把 3D 点投影到屏幕上的摄像机。
绘图内容在后面几页：[2D 绘图与图像](drawing.md) 和 [3D 形状与网格](shapes.md)。

## 帧循环

图形程序的结构总是一样的：打开窗口，然后重复以下步骤直到窗口关闭——清屏、绘制、`present()`。

```ling-gui
令 start = 执 {
    开窗(800, 600, "帧循环")
    令 帧号 = 0
    循 窗开() {
        填(10, 12, 30)                  # 1. 用背景色清屏
        设色(255, 200, 80)               # 2. 绘制
        画实心圆(400 + 200 * 正弦(帧号 * 0.05), 300, 40)
        显()                             # 3. 显示这一帧
        令 帧号 = 帧号 + 1
    }
}
```

有三点值得记住：

1. 当用户关闭窗口**或按下 Escape** 时，`window_is_open()` 变为假。你不必自己处理 Escape。
2. `present()` 是唯一把像素送上屏幕的调用。它还会绘制排队的 3D 几何体、运行后期处理并读取鼠标。
   没有 `present()` 的帧是看不见的。
3. 没有帧间隔（delta time）内置函数。用当前的 `time_now()` 减去上一次的值，或用 `frame_count()` 数帧。

调用不存在的内置函数（例如 Ling 并没有的 `draw_rect`）会被静默忽略。如果某个绘图调用似乎什么都没做，
先检查拼写。

### 坐标

| 空间 | 原点 | +x | +y | +z |
|---|---|---|---|---|
| 屏幕（2D） | 左上角像素 | 向右 | **向下** | 不使用 |
| 世界（3D） | 摄像机枢轴 | 向右 | **向下** | 远离摄像机 |

因为 +y 朝下，“上方”是负的 y：天花板在 `y = -3`，地板在 `y = 3`。

默认投影以窗口为中心，焦距等于窗口高度（像素），并在透视除法之前加上深度偏移 `zdist = 5`：

```text
screen_x = width/2  + height * x / (z + zdist)
screen_y = height/2 + height * y / (z + zdist)
```

## 窗口与帧

### `open_window(w, h, title, resizable)`

打开程序的窗口并分配帧缓冲区。

- **参数：** `w`、`h` 像素尺寸（默认 800×600）；`title`（默认 `"Ling"`）；
  `resizable` 可选，`1` 表示窗口可调整大小（默认 0）。
- **返回值：** 无。
- **注意：** 数字在前，标题是第三个参数。打开窗口也会把摄像机投影重置为默认值。
  窗口可调整大小时，请在每帧读取 `get_width()` 和 `get_height()`。
  如果无法创建窗口，程序会以 `cannot open window` 停止。

```ling-gui
令 start = 执 {
    开窗(1024, 640, "我的游戏", 1)
}
```

### `open_fullscreen(title, w, h)` 和 `open_fullscreen_scaled(title, scale)`

`open_fullscreen` 打开一个覆盖主显示器的无边框窗口。`w` 和 `h` 可选（默认为显示器分辨率）。
注意这里**标题在前**。

`open_fullscreen_scaled` 以显示器分辨率的几分之一渲染，再放大显示，用清晰度换速度。
`scale` 为 `1`、`2` 或 `4`（其他值按 1 处理）；`get_width()` 和 `get_height()` 返回缩小后的尺寸。

```ling-gui
令 start = 执 {
    open_fullscreen_scaled("复古", 2)
}
```

### `window_is_open()`

窗口打开时为 `true`；用户关闭窗口、按下 Escape 或代码调用 `quit()` 之后为 `false`。
在打开任何窗口之前它返回 `false`，所以以它为条件的循环不会运行。

### `present()`

结束这一帧：绘制所有排队的 3D 图元、应用后期处理、把帧缓冲区复制到窗口并读取鼠标。

3D 形状（`cube`、`vtex_*`、`draw_line_3d` 等）会按深度排序，并且只在这里光栅化，所以你可以按任意顺序调用它们。
直接的 2D 调用（`draw_line`、`triangle`、`draw_disc`、`tex_*`、`image_draw`）会立即写入帧缓冲区，
因此排队的 3D 几何体最终会**盖在它们上面**。要在 3D 场景上绘制 HUD，请先调用 `flush_3d()`。
`ui_*` 控件跨帧检测点击，所以需要每帧调用一次 `present()`。

### `flush_3d()` 和 `flush_post()`

`flush_3d()` 立即把排队的 3D 几何体绘制到帧缓冲区，但不呈现。之后绘制的内容会在它上面。
`flush_post()` 做同样的事，然后立即运行后期处理链，这样之后绘制的 HUD 不会被泛光模糊。
参见 [后期特效与光照](postfx.md)。

```ling-gui
令 start = 执 {
    立方体(0, 0, 8, 1, 1, 1, 0, 0, 0, 0)
    flush_3d()                          # 立方体现在已在帧缓冲区中
    进度条(20, 20, 200, 14, 0.5, 1)     # 画在它上面
    显()
}
```

### `quit()`

从代码中关闭窗口，与按下 Escape 完全相同。`exit_game` 和 `close_window` 是英文同义词。

```ling-gui
令 start = 执 {
    若 按钮(20, 20, 100, 32) == 1 { quit() }
}
```

### `get_width()` 和 `get_height()`

当前帧缓冲区的像素尺寸。固定窗口时它们等于 `open_window` 的参数；可调整大小的窗口在用户改变大小时会变化。
没有窗口时返回 0。

```ling-gui
令 start = 执 {
    令 中心x = 宽() / 2
    令 中心y = 高() / 2
}
```

### `set_fps(n)` 和 `set_vsync(on)`

`set_fps(n)` 限制帧率（默认 60，最小 1）。请在 `open_window` 之后调用。
`set_vsync(on)` 则按显示器刷新率控制循环节奏。它只是帧节奏控制，不是无撕裂的垂直同步。
显式的 `set_fps` 或环境变量 `LING_FPS_CAP` 优先。

```ling-gui
令 start = 执 {
    开窗(800, 600, "限帧")
    设帧率(30)
}
```

### `monitor_width()`、`monitor_height()`、`monitor_refresh()`、`monitor_info()`

主显示器的像素宽度、高度和以赫兹为单位的刷新率。`monitor_info()` 以列表 `[宽, 高, 赫兹]` 返回全部三个值。
你可以在打开窗口之前调用它们，例如用来决定窗口大小。

```ling-gui
令 start = 执 {
    令 信息 = 屏幕信息()
    开窗(信息[0] / 2, 信息[1] / 2, "半个屏幕")
}
```

### `wait_window()`

阻塞并让最后一帧留在屏幕上，直到窗口关闭或按下 Escape。适合只画一张静态图的程序。

```ling-gui
令 start = 执 {
    开窗(400, 300, "静止")
    填(20, 40, 80)
    显()
    wait_window()
}
```

### `screenshot(tag)`

把当前帧缓冲区保存为 PNG 并返回路径 `screenshots/ss_<unix 时间>_<tag>_<宽>x<高>.png`。
`tag` 默认为 `"game"`；字母和数字以外的字符会变成下划线。文件夹建在程序运行的位置。
在 `present()` 之后调用，才能截到完整的一帧。

```ling-gui
令 start = 执 {
    显()
    println(screenshot("title"))
}
```

### `record_frame()` 和 `record_count()`

`record_frame()` 把当前帧缓冲区依次写入 `recordings/frame_00000.ppm`、`frame_00001.ppm` 等文件，
以便之后合成视频，并返回所写帧的编号。`record_count()` 返回已写入的帧数。

### `frame_count()` 和 `time_now()`

`frame_count()` 是程序启动以来已呈现的帧数。`time_now()` 是程序启动以来的秒数（带小数）。
要得到帧间隔，记住上一次的值：

```ling-gui
令 start = 执 {
    令 上次 = 当前时间()
    循 窗开() {
        令 此刻 = 当前时间()
        令 间隔 = 此刻 - 上次
        令 上次 = 此刻
        填(0, 0, 0)
        显()
    }
}
```

## 摄像机

所有 3D 内置函数都通过一台全局摄像机投影世界中的点，它由三样东西决定：

* **枢轴** `(x, y, z)`，用 `set_camera_pos` 设置，会从每个点中减去；
* **朝向**，用 `set_camera` 以偏航角和俯仰角的余弦与正弦设置；
* **深度偏移** `zdist`，用 `set_zdist` 设置，在透视除法之前加上。

正的偏航让摄像机向右转，于是正前方的物体在屏幕上向左滑动。正的俯仰让摄像机向下倾，于是前方的物体向上滑动。
对于偏航角 `a`，世界中的“前方”是 x-z 平面上的 `(sin a, cos a)`。请在每帧绘制 3D 几何体之前设置摄像机。

| 内置函数 | 中文 | 日本語 | 한국어 | ไทย | 用途 |
|---|---|---|---|---|---|
| `set_camera(cy, sy, cp, sp)` | `设镜` | `カメラ設定` | `카메라설정` | `ตั้งกล้อง` | 由偏航和俯仰的余弦/正弦设定朝向 |
| `set_camera_pos(x, y, z)` | `镜坐标` | `カメラ座標` | `카메라좌표` | `ตั้งตำแหน่งกล้อง` | 移动枢轴 |
| `move_camera(dx, dy, dz)` | — | — | — | — | 按偏移量移动枢轴 |
| `set_zdist(d)` | `镜距` | `Z距離設定` | `Z거리설정` | `ตั้งระยะห่าง` | 深度偏移 |
| `set_projection(cx, cy, focal, zdist)` | `投影` | `投影設定` | `투영설정` | `ตั้งโปรเจกชัน` | 一次设置全部镜头参数 |
| `tm_fov(degrees, width)` | — | — | — | — | 由视野角设定焦距 |
| `set_camera_roll(angle)` | — | — | — | — | 绕视线轴滚转 |
| `set_camera_hyper(R, saddle, px, mid_y, pz)` | — | — | — | — | 双曲空间视图 |
| `project_3d(x, y, z)` | `投影3D` | `3D投影` | `3D투영` | `ฉาย3มิติ` | 世界点到屏幕 |
| `mouse_ray()` | — | — | — | — | 屏幕（鼠标）到世界的射线 |

### `set_camera(cy, sy, cp, sp)`

用预先算好的值设置朝向：`cy`、`sy` 是偏航角的余弦和正弦，`cp`、`sp` 是俯仰角的余弦和正弦
（默认 `1, 0, 1, 0`，即正对 +z 方向）。传入这四个数，而不是角度本身。

```ling-gui
令 start = 执 {
    令 偏航 = 0.3
    令 俯仰 = 0.1
    设镜(余弦(偏航), 正弦(偏航), 余弦(俯仰), 正弦(俯仰))
}
```

### `set_camera_pos(x, y, z)` 和 `move_camera(dx, dy, dz)`

`set_camera_pos` 把摄像机枢轴移到某个世界位置（默认 0, 0, 0）；`move_camera` 在其上加一个偏移。
记住 y 朝下：要升高摄像机，就减小 y。音频运行时，听者位置会跟随摄像机。

```ling-gui
令 start = 执 {
    镜坐标(0, -2, -6)      # 向上两个单位，向后六个单位
}
```

### `set_zdist(d)`、`set_projection(cx, cy, focal, zdist)` 和 `tm_fov(degrees, width)`

`set_zdist(d)` 设置深度偏移（默认 5，打开窗口时重置）。值越大，场景越远、透视越平；
比 `-zdist` 更近的几何体会被裁掉。

`set_projection` 覆盖所有镜头参数：`cx`、`cy` 是光学中心的像素位置，`focal` 是像素焦距（越大越放大），
以及 `zdist`。只有分屏之类的特殊设置才需要它。

`tm_fov(degrees, width)` 设置焦距，使视野横向跨越给定角度；`width` 是视口宽度（像素，默认为窗口宽度）。
`tm_fov(0)` 恢复默认焦距。

```ling-gui
令 start = 执 {
    投影(宽() / 2, 高() / 2, 高() * 1.5, 5)   # 放大
}
```

### `set_camera_roll(angle)` 和 `set_camera_hyper(R, saddle, px, mid_y, pz)`

`set_camera_roll` 让视图绕前向轴滚转，单位为弧度（别名 `camera_roll`）。
`set_camera_hyper` 开启围绕枢轴 `(px, mid_y, pz)` 的双曲视图：地面距离按 `R * tanh(d / R)` 压缩，
空间像强度为 `saddle` 的马鞍一样弯曲。`R = 0` 关闭该效果。

### `project_3d(x, y, z)`

用当前摄像机投影一个世界点，返回 `[screen_x, screen_y, depth]`。在摄像机后方的点返回
`[-99999, -99999, depth]`。用它把 2D 标签钉在 3D 物体上。
没有窗口时，投影假定帧为 1920×1080，所以下面的程序可以在终端中运行：

```ling
令 start = 执 {
    设镜(1, 0, 1, 0)
    println("正前方：" + str(投影3D(0, 0, 5)))
    println("右侧：  " + str(投影3D(1, 0, 5)))
    镜坐标(2, 0, 0)
    println("移动后：" + str(投影3D(0, 0, 5)))
    镜坐标(0, 0, 0)
    println("身后：  " + str(投影3D(0, 0, -20)))
}
```

```output
正前方：[960, 540, 5]
右侧：  [1068, 540, 5]
移动后：[744, 540, 5]
身后：  [-99999, -99999, -20]
```

在深度 10（5 加上 `zdist`）处向右一个单位，在焦距 1080 下移动 108 像素。

日语和韩语别名 `3D投影` 与 `3D투영` 以数字开头，会被读成数字 3，无法调用。在日语和韩语代码中请使用 `project_3d`。

### `mouse_ray()`

从摄像机枢轴穿过鼠标下像素的世界空间射线，形式为列表 `[ox, oy, oz, dx, dy, dz]`：起点和方向。
它是 `project_3d` 的逆运算。沿着它步进，就能找到光标下的地面，实现点击移动。

```ling-gui
令 start = 执 {
    令 射线 = mouse_ray()
    令 t = (2 - 射线[1]) / 射线[4]          # 射线与 y = 2 地面相交处
    令 地面x = 射线[0] + 射线[3] * t
    令 地面z = 射线[2] + 射线[5] * t
}
```

## 自由飞行摄像机

鼠标视角、WASD 行走和一个旋转的立方体。沿 `(sin 偏航, cos 偏航)` 移动，让行走方向与视线保持一致。
鼠标和键盘内置函数见 [输入与麦克风](input.md)；光照见 [后期特效与光照](postfx.md)。

```ling-gui
令 start = 执 {
    开窗(900, 600, "飞行")
    捕鼠()
    深度测试(1)
    令 偏航 = 0.0
    令 俯仰 = 0.0
    令 位x = 0.0
    令 位z = -4.0
    令 t = 0.0
    循 窗开() {
        令 偏航 = 偏航 + mouse_dx() * 0.003
        令 俯仰 = 截取(俯仰 + mouse_dy() * 0.003, -1.5, 1.5)
        令 前x = 正弦(偏航) * 0.08
        令 前z = 余弦(偏航) * 0.08
        若 按键("w") { 令 位x = 位x + 前x  令 位z = 位z + 前z }
        若 按键("s") { 令 位x = 位x - 前x  令 位z = 位z - 前z }
        若 按键("d") { 令 位x = 位x + 前z  令 位z = 位z - 前x }
        若 按键("a") { 令 位x = 位x - 前z  令 位z = 位z + 前x }
        设镜(余弦(偏航), 正弦(偏航), 余弦(俯仰), 正弦(俯仰))
        镜坐标(位x, 0, 位z)
        填(8, 10, 24)
        清灯()
        加灯(-3, -6, 0, 1.0, 0.95, 0.85, 1.0, 0)
        纹格(0, 2, 8, 1, 0, 0, 0, 0, 1, 20, 20, 1, 1, t, 0)
        设色(240, 150, 110)
        立方体(0, 0, 8, 1, 1, 1, t * 0.5, t, 0, 0)
        显()
        令 t = t + 0.02
    }
}
```
