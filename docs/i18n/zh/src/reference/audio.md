# 音频

音频引擎能播放游戏需要的一切：放在 3D 空间中的持续音调、短促的提示音和音效、采样文件、循环的背景音乐，以及一条主效果链。另有一个独立的 FFT 分析器，把采样数据变成频段，用于随音频变化的视觉效果。

整首歌曲、乐器音色、MIDI 和 DAW 请见[音乐](music.md)。麦克风请见[输入与麦克风](input.md)。

先了解几点：

- 程序启动时运行时会打开音频设备。没有输出设备时，`audio_*` 内置函数会静默地什么都不做。
- 时间以秒为单位。签名中从列出默认值的参数开始，后面的参数都是可选的。
- 音频只在原生版本中可用：在浏览器版本中 FFT 内置函数什么都不做，部分调用接受的参数更少（见下文）。
- 这些示例会发出声音，所以都是 `ling-gui` 程序。最后的 FFT 示例在任何地方都能运行。

## 引擎如何混音

一条输出流承载四类声音：

- **音调**：编号槽位中长期存在的振荡器，放在空间中（`audio_tone`）。
- **单次音**：提示音（`audio_blip`、`ui_sound`）、空间音效（`audio_sfx`）和变形音（`morph_note`）。
- **采样**：解码后的文件，在 3D 空间中或不定位地播放（`audio_sample_*`）。
- **背景音乐**：一个循环的 WAV（`audio_bgm`）。

听者就是摄像机。声像根据声音相对摄像机的位置做等功率左右分配，音量随距离衰减。`set_camera_pos` 移动听者；`audio_listener` 转动听者。最终混音会软削波，所以响亮的混音只会柔和地失真，而不会硬削波。

音调槽位按需增加。提示音有 32 个声部，音效 64 个，变形音 32 个，采样 64 个；某个池满了时，最早的声部会被丢弃。

## 音量与背景音乐

### `audio_volume(level)`

此引擎混合的所有声音的主增益（默认 0.7；1.0 为原始音量）。它不影响音乐引擎，后者有自己的 `music_volume`。

### `audio_bgm(path, volume)` 和 `audio_bgm_volume(level)`

`audio_bgm` 加载一个 **WAV** 文件并循环播放作为背景音乐（默认音量 0.5）。再次调用会替换当前曲目。文件无法读取时，错误会输出到标准错误，程序在静音中继续运行。路径原样使用。MP3、OGG、FLAC 或 AAC 请用 `audio_sample_load` 或 `music_load`。

`audio_bgm_volume` 在不重新加载的情况下改变音量。

```ling-gui
令 始 = 执 {
    音量(0.6)
    背景乐("theme.wav", 0.4)
    背景乐音量(0.15)
}
```

## 音调

### `audio_tone(slot, x, y, z, w, freq, amp, lfo_rate, lfo_depth, wave, duty)`

创建或重新调整一个持续的振荡器。重复使用同一个槽位会原地更新该音调，频率和振幅会滑向新值，所以你可以每帧调用它。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `slot` | 0 | 音调槽位编号。 |
| `x, y, z` | 0 | 声源的世界坐标。 |
| `w` | 1 | 第四维的值。它驱动一个缓慢的子振荡器对音调做交叉调制；0 表示关闭。 |
| `freq` | 220 | 频率（Hz）。 |
| `amp` | 0.15 | 振幅。传 0 让该槽位静音（没有删除操作）。 |
| `lfo_rate` | 0.5 | 颤音速度（Hz）。 |
| `lfo_depth` | 0.02 | 颤音深度，以 `freq` 的比例表示。 |
| `wave` | `"sine"` | `"sine"`、`"square"`、`"saw"`、`"triangle"` 或 `"noise"`（以 `freq` 为音高的阶梯噪声）。 |
| `duty` | 0.5 | 方波占空比，例如芯片音乐常用的 0.125、0.25、0.5、0.75。 |

### `audio_glide(amp_ms, freq_ms)`

设置音调振幅和频率滑向新值所需的时间，以毫秒计（0 或以下保持默认）。每帧更新一次音调的芯片音乐播放器，设为约 10 毫秒会更平滑。

### `audio_listener(cos_yaw, sin_yaw, cos_pitch, sin_pitch)`

转动听者。传入与 `set_camera` 相同的四个数（默认 1, 0, 1, 0）。摄像机转动时每帧调用。

```ling-gui
令 始 = 执 {
    开窗(640, 360, "音调")
    音调(0, 0, 0, 6, 0, 261.63, 0.10, 0.5, 0.01)
    音调(1, 0, 0, 6, 0, 440.0, 0.06, 0, 0, "square", 0.25)
    令 偏航 = 0.0
    循 窗开() {
        令 偏航 = 偏航 + 0.01
        设镜(余弦(偏航), 正弦(偏航), 1, 0)
        音频监听(余弦(偏航), 正弦(偏航), 1, 0)
        填(10, 12, 28)
        显()
    }
}
```

## 单次音

### `audio_blip(freq, duration, wave, amp)`

短促、不定位的提示音，起音和衰减都很快。默认值：`freq` 660 Hz，`duration` 0.08 秒（最小 0.01），`wave` `"sine"`，`amp` 0.25。波形名称：`"sine"`、`"square"`（`"sq"`）、`"saw"`（`"sawtooth"`）、`"tri"`（`"triangle"`）、`"noise"`。未知名称按正弦播放。

### `ui_sound(name)`

内置界面音之一：`"click"`（默认）、`"hover"`、`"confirm"`、`"error"`、`"toggle"`、`"tick"`。其他名称都播放 `"click"`。

### `audio_sfx(x, y, z, w, freq, amp, duration, wave)`

在世界坐标处合成的单次音效，像音调一样做声像和衰减。默认值：位置 0，`w` 1，`freq` 440，`amp` 0.3，`duration` 0.15，`wave` `"sine"`。

### `morph_note(x, y, z, w, freq, amp, duration, material, morph)`

把物理模型和数字模型融合在一起的“阴阳”音符。`material` 为 0 弓弦、1 拨弦、2 吹管、3 敲击金属。`morph` 从 0（明亮、原声）到 1（暗沉、数字化：FM、比特压缩、过载）。默认值：`freq` 220，`amp` 0.3，`duration` 0.6。

### `audio_stop_sfx()`

一次性停止所有单次音效、变形音和采样声部，避免尾音在切换场景时漏出来。音调、背景音乐和音乐引擎继续播放。

```ling-gui
令 始 = 执 {
    界面音("confirm")
    提示音(880, 0.06, "square", 0.2)
    音效(1.5, 0, 4, 1, 330, 0.3, 0.2, "triangle")
    morph_note(0, 0, 5, 1, 220, 0.3, 1.2, 1, 0.4)
}
```

## 采样

### `audio_sample_load(path)`

把 WAV、FLAC、OGG、MP3 或 AAC 文件解码到内存中，并混合成单声道。如果按原样找不到该路径，会相对于脚本所在文件夹再试一次。返回采样 id（从 0 开始），失败或没有音频设备时返回 `-1`。

### `audio_sample_play(id, x, y, z, w, volume, loop, pitch)`

在世界坐标处播放已加载的采样，相对于听者做声像和衰减。`volume` 默认 1，`loop` 大于 0.5 时循环，`pitch` 是播放速率倍数（2 升高一个八度，0.5 降低一个八度）。`w` 对采样没有可听的效果。返回声部 id，失败时返回 0。在浏览器版本中签名是 `(id, x, y, z, w, volume, loop)`，没有 pitch。

### `audio_sample_play_flat(id, volume, loop, pitch)`

不做声像、不随距离衰减地播放采样。用于旁白、配音和界面提示。返回声部 id，或 0。

### `audio_sample_stop(voice)` 和 `audio_sample_duration(id)`

`audio_sample_stop` 停止播放调用返回的声部。`audio_sample_duration` 返回采样的长度（秒；未知 id 返回 0），便于让过场动画配合实际加载的片段长度。

```ling-gui
令 始 = 执 {
    令 脚步 = 载入采样("step.ogg")
    令 嗡鸣 = 载入采样("hum.wav")
    播放采样(脚步, 1.0, 0.0, 3.0, 1.0, 0.8, 0, 1.2)
    令 声部 = audio_sample_play_flat(嗡鸣, 0.5, 1, 1.0)
    打印(audio_sample_duration(嗡鸣))
    停止采样(声部)
}
```

## 主效果

主效果链依次是延迟、混响、低通滤波器。三者起初都是关闭或完全打开的状态。

| 内置函数 | 参数 |
|---|---|
| `audio_fx_delay(time, feedback, mix)` | 回声时间（秒，默认 0.3），反馈 0 到 0.95（默认 0.3），湿声比例 0 到 1（默认 0.3；0 表示关闭）。 |
| `audio_fx_reverb(mix)` | 混响湿声比例，0 到 1（默认 0.3）。 |
| `audio_fx_lowpass(cutoff)` | 0 到 1。1 表示完全打开；值越低混音越闷，像在水下。滤波器会平滑过渡到新值。 |

```ling-gui
令 始 = 执 {
    回声(0.35, 0.4, 0.25)
    混响(0.4)
    低通滤波(0.15)
}
```

## FFT 分析

FFT 分析器处理你提供给它的采样。用 `fft_push` 推入一块单声道采样（-1 到 1 之间的数字，44.1 kHz），然后读取结果：

| 内置函数 | 返回值 |
|---|---|
| `fft_bands(n)` | `n` 个对数间隔的幅度频段组成的列表（默认 32），低音在前。 |
| `fft_beat()` | 最近一块是节拍时为 `true`。 |
| `fft_beat_ratio()` | 节拍强度：1 表示正好在检测阈值，大于 1 表示强拍。 |
| `fft_rms()` | 信号的均方根电平。 |
| `fft_dominant_freq()` | 最强的频率（Hz）。 |

这个程序生成一个 1000 Hz 的正弦波并分析它。结果接近 1000，受分析器的频率分辨率限制：

```ling
令 始 = 执 {
    令 采样 = []
    令 i = 0
    循 i < 4096 {
        令 采样 = 采样.添加(正弦(i * 6.2831853 * 1000 / 44100))
        令 i = i + 1
    }
    频谱输入(采样)
    打印(四舍五入(主频()))
    打印(四舍五入(均方根() * 1000) / 1000)
    令 频带 = 频段(8)
    令 最响 = 0
    令 k = 1
    循 k < 长度(频带) {
        若 频带[k] > 频带[最响] {
            令 最响 = k
        }
        令 k = k + 1
    }
    打印("最响的频段：" + str(最响))
}
```

```output
991
0.707
最响的频段：4
```

要对正在播放的歌曲做反应，请使用[音乐](music.md)页面中的 `music_fft(track, bands)`；麦克风请使用[输入与麦克风](input.md)中的 `mic_fft`。
