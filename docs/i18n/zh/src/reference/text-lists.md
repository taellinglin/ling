# 文本与列表

文本（字符串）和列表是 Ling 中最常用的两种集合。本页介绍用来测量、查找、截取和转换文本的内置函数，
以及用来构造和读取列表的内置函数。如果想要更平缓的入门，请看[列表与文本](../tutorials/lists-text.md)教程。

有两条规则贯穿全页：

- **内置函数从不修改输入。** 它们返回一个新值，所以要重新绑定结果：
  `令 xs = 列表添加(xs, 5)`。
- **错误输入很少报错。** 越界的索引或无法解析的数字会得到一个备用值（`""`、`0`、`-1`），
  而不是错误。每个条目都会说明是哪一个。

## 文本

### 拼接与转换

`+` 用来拼接文本，两边任意一侧的数字都会被转换成文本。`to_str` 显式地把任意值转为文本。
`to_number` 会忽略两端空白，遇到无法读取的内容返回 **`0`**，因此无法区分 `"0"` 和错误输入。
它不认十六进制；那要用 `hex_to_number`。

```ling
令 start = 执 {
  印("得分：" + 10)
  印(to_str(3) + "！")
  印(转数字(" 42 ") + 1, " ", 转数字("abc"))
  印(十六进制转数字("ff"))
}
```
```output
得分：10
3！
43 0
255
```

### `len(value)`

计算文本的字符数或列表的项数；其他值得到 `0`。方法形式 `"文本".len()` 计算的是**字节数**，
所以对非 ASCII 文本结果不同。

```ling
令 start = 执 {
  印(长度("Ling"), " ", 长度([1, 2, 3]))
  印(长度("中文"), " ", "中文".len())
}
```
```output
4 3
2 6
```

### 查找

`starts_with`、`ends_with` 和 `str_contains` 返回 `true` 或 `false`。`str_find` 返回第一个匹配处
从 0 开始的字符索引，找不到时返回 `-1`。方法 `text.contains(part)` 也可以用。

```ling
令 start = 执 {
  令 词 = "你好世界"
  印(starts_with(词, "你好"), " ", ends_with(词, "世界"))
  印(字符串包含(词, "好世"), " ", 词.contains("再见"))
  印(str_find(词, "世"), " ", str_find(词, "再"))
}
```
```output
true true
true false
2 -1
```

### 截取与修改

`substr(text, start, length)` 从 0 开始按字符计数；省略 `length` 就截到末尾。
越界的值会被收拢到有效范围，永远不会报错。`str_replace` 替换所有出现的位置。

```ling
令 start = 执 {
  印(substr("hello", 1, 3), " ", substr("hello", 2))
  印(str_replace("a-b-c", "-", "+"))
  印(trim("   留白   ") + "|")
  印(str_upper("Ling"), " ", str_lower("LING"))
  印(str_repeat("哈", 3), " ", str_strip_prefix("v1.2", "v"))
}
```
```output
ell llo
a+b+c
留白|
LING ling
哈哈哈 1.2
```

### `split(text, sep)`

返回字符串列表。不给分隔符（或给 `""`）时按换行拆分。它从不去除空白，所以连续两个分隔符之间会得到空字符串。

```ling
令 start = 执 {
  印(split("一 二 三", " "))
  印(split("a,b,,c", ","))
  印(长度(split("第一行\n第二行")))
}
```
```output
[一, 二, 三]
[a, b, , c]
2
```

### 字符与哈希

`ord` 给出第一个字符的码点（空文本为 `-1`），`chr` 把码点转回单个字符的文本。`hash_str` 和 `hash_int`
对同一段文本每次运行都给出相同的值，适合根据名字挑选一个固定的颜色或变体。

```ling
令 start = 执 {
  印(字码("A"), " ", 字符(97))
  印(hash_str("苹果") == hash_str("苹果"))
  印(hash_int("apple", 10))
}
```
```output
65 a
true
5
```

## 列表

### 构造与读取

列表可以直接写成 `[1, 2, 3]`，也可以从 `list_new()` 开始，用 `list_push` 添加项。
用 `xs[i]`（从 0 开始）或 `list_get(xs, i)` 读取一项。区别在于越界时的行为：
`list_get` 返回 `""`，而 `xs[i]` 在解释器上会报错。`list_set` 返回替换了一项的副本，越界的索引会被忽略。

```ling
令 start = 执 {
  令 表 = 新建列表()
  令 表 = 列表添加(表, "甲")
  令 表 = 列表添加(表, "乙")
  令 表 = 设元素(表, 0, "丙")
  印(表, " ", 长度(表))
  印(表[1], " ", 取元素(表, 0))
  印(取元素(表, 9) == "")
}
```
```output
[丙, 乙] 2
乙 丙
true
```

方法 `xs.push(value)` 与 `list_push` 作用相同。一定要重新绑定结果：解释器不会改动原列表，
默认后端可能会就地修改它，你的程序不应依赖其中任何一种行为。

### 组合

```ling
令 start = 执 {
  印(连接(["甲", "乙", "丙"], "、"))
  印(连接([1, 2, 3], "-"))
  印(list_cat([1, 2], [3]), " ", list_iota(4))
  印(列表最大值([3, 9, 2], 0), " ", 列表最小值([], 0 - 1))
}
```
```output
甲、乙、丙
1-2-3
[1, 2, 3] [0, 1, 2, 3]
9 -1
```

### 用循环代替 map 和 filter

`list_map`、`list_filter` 和 `list_find` 接受一个函数，而传给内置函数的函数只在解释器
（`ling run --interp`）上有效；默认后端传进去的是 `()`。`list_filter` 只有在函数返回的恰好是 `true` 时才保留该项。

```ling-module
函 加倍(表) { 映射列表(表, |x| x * 2) }
```

另外也没有 `sort`、`slice` 或 `reverse` 内置函数。用 `while` 循环就能完成这些工作，而且在所有后端上都能运行。
累加时请用 `while` 而不是 `for`：`for` 循环体内的 `bind` 不会影响外层作用域。

```ling
令 start = 执 {
  令 数 = [3, 1, 2, 4]
  令 总和 = 0
  令 倒序 = 新建列表()
  令 i = 长度(数) - 1
  循 i >= 0 {
    令 总和 = 总和 + 数[i]
    令 倒序 = 列表添加(倒序, 数[i])
    令 i = i - 1
  }
  印(总和, " ", 倒序)
}
```
```output
10 [4, 2, 1, 3]
```
