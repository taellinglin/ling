# 2D 绘图与图像

这些内置函数以屏幕像素为单位直接绘制到窗口的帧缓冲区：线条、三角形、圆、多边形、渐变和柔和阴影，
以及从文件加载或逐像素构建的图像。它们都需要一个已打开的窗口，并应放在 `fill()` 和 `present()` 之间
（参见 [窗口与摄像机](window.md)）。

## 2D 绘图如何工作

- **坐标**以像素为单位。原点在左上角，+x 向右，**+y 向下**。窗口外的坐标不会被绘制。
- **画笔颜色。** 形状用当前画笔颜色绘制，由 `set_color` 设置。它在你改变之前一直有效。3D 形状也把它当作基础色。
- **颜色值**是 0 到 255 的数字。它们**不会被截断**：运行时按 `(r << 16) | (g << 8) | b` 打包，
  所以超过 255 的值会溢出到相邻通道。负值变为 0。
- **立即写入。** 2D 调用会马上写入像素。排队的 3D 几何体稍后在 `present()` 时才绘制，因此会盖住你的 2D 绘图。
  要在 3D 场景上绘制 2D 内容，请先调用 `flush_3d()`。
- **打包颜色。** 有些内置函数接受一个 `0xRRGGBB` 数字。Ling 没有十六进制字面量，所以写成
  `r * 65536 + g * 256 + b`（例如 `51 * 65536 + 102 * 256 + 255`）。

```ling-gui
令 start = 执 {
    开窗(640, 360, "2D")
    循 窗开() {
        填(12, 14, 30)
        设色(230, 90, 90)
        画三角(60, 300, 160, 140, 260, 300)
        设色(90, 200, 255)
        draw_circle(380, 150, 60)
        设色(120, 255, 160)
        画实心圆(520, 150, 40)
        设色(255, 220, 90)
        draw_arc(380, 280, 50, 0, 3.14159)
        渐变矩形(20, 320, 600, 24, 255, 80, 0, 0, 80, 255, 0)
        显()
    }
}
```

## 画笔与混合

### `fill(r, g, b)`

把整个帧缓冲区清为一种颜色，并重置深度缓冲区。每帧首先调用它。
每个通道默认为 0，所以 `fill()` 清为黑色。它不改变画笔颜色。`clear` 是英文同义词。

### `set_color(r, g, b)`、`set_color_hsl(h, s, l)` 和 `mix_color(...)`

`set_color` 设置画笔颜色（每个通道默认 255）。

`set_color_hsl` 用以度为单位的色相（0 到 360）、饱和度和亮度（0 到 100；默认 70 和 50）设置颜色。
逐步改变色相是画彩虹的简单方法。

`mix_color(r0, g0, b0, r1, g1, b1, t)` 把画笔设为两种颜色的混合，`t` 从 0 到 1（默认 0.5）。
它在 OkLab 颜色空间中混合，所以中间色调干净而不浑浊。

```ling-gui
令 start = 执 {
    开窗(700, 300, "彩虹")
    填(0, 0, 0)
    令 序号 = 0
    循 序号 < 12 {
        色相(序号 * 30, 80, 55)
        画实心圆(60 + 序号 * 50, 150, 20)
        令 序号 = 序号 + 1
    }
    显()
    wait_window()
}
```

### `set_alpha(a)`

画笔不透明度，从 0（不可见）到 1（不透明），默认 1。它作用于渐变填充和排队的 3D 形状。

### `set_blend(mode)`

新像素与已有像素如何组合：`0` 普通（默认），`1` 叠加。叠加混合时重叠的形状会更亮，这是所有发光效果的基础。
排队的 3D 绘制还接受 `2` 正片叠底、`3` 滤色、`4` 减去和 `5` 叠加（overlay）。用完后请设回 0。

```ling-gui
令 start = 执 {
    混合模式(1)
    设色(60, 40, 20)
    画实心圆(500, 280, 40)
    画实心圆(530, 280, 40)       # 重叠部分更亮
    混合模式(0)
}
```

### `set_antialias(on)` 和 `get_antialias()`

平滑线条笔画：直线、圆弧、圆的轮廓和 3D 边。默认关闭，得到清晰的像素线；不带参数的 `set_antialias()` 会开启它。
`get_antialias()` 读回当前设置。文字平滑是单独的设置（参见 [字体与界面](fonts-ui.md)）。

## 形状

### `draw_pixel(x, y)` 和 `draw_line(x0, y0, x1, y1)`

`draw_pixel` 设置一个像素。`draw_line` 在两点之间画一条一像素宽的线；它遵循 `set_antialias` 和叠加混合。

### `triangle(x0, y0, x1, y1, x2, y2)`

实心三角形。用两个三角形拼出矩形，或使用 `draw_poly`。`draw_triangle` 是英文同义词。

```ling-gui
令 start = 执 {
    设色(230, 90, 90)
    画三角(100, 100, 300, 100, 300, 200)
    画三角(100, 100, 300, 200, 100, 200)      # 合起来是一个矩形
}
```

### `draw_circle(cx, cy, r)` 和 `draw_disc(cx, cy, r)`

圆的轮廓和实心圆，圆心和半径以像素为单位（半径默认 10）。`draw_disc` 遵循混合模式，所以配合 `set_blend(1)` 可以画出光晕。

### `draw_arc(cx, cy, r, a0, a1, segments)`

从角度 `a0` 到 `a1`（弧度，默认 0 到 2π，即整圆）描绘圆的一部分；`segments` 可选。
因为 +y 朝下，角度在屏幕上**顺时针**增长：0 指向右，`pi() / 2` 指向正下方。

### `draw_poly(points)`

自动闭合的实心多边形。`points` 是扁平列表 `[x0, y0, x1, y1, ...]`。配合 `project_3d` 可以填充投影后的 3D 点之间的形状。

```ling-gui
令 start = 执 {
    设色(200, 140, 255)
    填充多边形([100, 100, 200, 120, 180, 200, 90, 180])
}
```

### `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` 和 `grad_triangle(...)`

`grad_rect` 用从第一种颜色到第二种颜色的渐变填充矩形。`dir` 为 `0` 表示从左到右，其他值表示从上到下（默认 1）。

`grad_triangle(x0, y0, r0, g0, b0, x1, y1, r1, g1, b1, x2, y2, r2, g2, b2)` 给每个角一种颜色，并在它们之间平滑过渡：
一种廉价的“受光”表面。

两者都遵循 `set_alpha`。渐变默认按感知方式混合；`set_gradient_space(0)` 切换为普通 sRGB。

### `shadow_blob`、`cast_shadow` 和 `shadow_params`

`shadow_blob(cx, cy, rx, ry, alpha)` 用画笔颜色画一个柔和的椭圆（半径默认 16 和 8，`alpha` 默认 0.5）。
深色画笔得到普通阴影；其他颜色得到带色调的阴影。

`cast_shadow(cx, cy, height)` 画一个接触阴影，其大小和柔和度随物体离地高度变化：低处物体的阴影小、深、清晰，
高处物体的阴影大而淡。`shadow_params(base, grow, alpha, fade, soft)` 用来调整它；省略的参数保持原值。

```ling-gui
令 start = 执 {
    设色(0, 0, 20)
    投射阴影(320, 330, 24)
}
```

### `depth_triangle(x0, y0, x1, y1, x2, y2, z)` 和 `depth_line(x0, y0, x1, y1, z)`

把一个 2D 三角形或线段加入队列，与 3D 几何体一起按深度排序，并在 `present()` 时绘制。`z` 越大越远。
用它们绘制需要在 3D 物体前后穿行的 2D 精灵。

### `set_frame_blur(amount)`

残影拖尾：每一帧都与上一帧的淡化副本混合。`amount` 从 0 到 0.95；约 0.9 时，在每秒 60 帧下拖尾大约持续一秒。
`0` 关闭该效果。

## 图像

图像保存在运行时内部的一张表中。每次加载或创建都会返回一个**句柄**，即一个小数字，传给其他 `image_*` 内置函数使用。
`-1` 表示失败。

| 内置函数 | 用途 |
|---|---|
| `image_load(path)` | 加载 PNG、JPEG 等位图；返回句柄或 `-1` |
| `image_draw(id, x, y, w, h)` | 按 `w`×`h` 像素缩放绘制 |
| `image_new(w, h)` | 新建透明图像 |
| `image_set_pixel(id, x, y, r, g, b, a)` | 绘制一个像素 |
| `image_pixel_r(id, x, y)`, `_g`, `_b`, `_a` | 读取一个通道（0 到 255） |
| `image_width(id)`, `image_height(id)` | 像素尺寸 |
| `image_save(id, path)` | 写出 PNG；`1` 或 `-1` |
| `image_replace(id, path)` | 把新文件加载到已有句柄中 |
| `image_tint(id, color)` | 按 alpha 塑形的单色副本 |
| `image_resized(id, w, h)` | 缩放后的副本 |
| `image_svg(svg_text, w, h)` | 把 SVG 源文本渲染为图像 |
| `image_free(id)` | 释放像素 |

### `image_load(path)`

加载位图并返回句柄；无法读取文件时返回 `-1`（并在错误流中输出一条消息）。路径先按原样尝试，再相对于脚本所在文件夹尝试。
再次加载同一路径会返回缓存的句柄，所以在帧循环中调用也是安全的。

### `image_draw(id, x, y, w, h, cx, cy, cw, ch, opacity)`

以 `x, y` 为左上角绘制图像，按最近邻缩放到 `w`×`h` 像素，并以 alpha 混合到画面上。
**`w` 和 `h` 是必需的**：为 0 时什么也不画，所以要原尺寸就传入 `image_width(id)` 和 `image_height(id)`。
可选参数：裁剪矩形 `cx, cy, cw, ch`（其外不绘制），以及其后的 `opacity`（0 到 1）。
图像按原样显示，不受后期处理对 3D 施加的卡通着色影响。

```ling-gui
令 start = 执 {
    开窗(640, 400, "精灵")
    令 英雄 = image_load("hero.png")
    令 横坐标 = 0
    循 窗开() {
        填(20, 24, 40)
        若 英雄 >= 0 {
            image_draw(英雄, 横坐标, 160, image_width(英雄) * 2, image_height(英雄) * 2)
        }
        显()
        令 横坐标 = (横坐标 + 2) % 640
    }
}
```

### `image_new`、`image_set_pixel` 和像素读取函数

`image_new(w, h)` 创建一张全透明的空白图像。`image_set_pixel(id, x, y, r, g, b, a)` 绘制一个像素（`a` 默认 255）。
`image_pixel_r`、`image_pixel_g`、`image_pixel_b` 和 `image_pixel_a` 读取像素的一个通道。
越界位置和无效句柄在写入时被忽略，读取时为 0。这些函数不需要窗口：

```ling
令 start = 执 {
    令 图 = image_new(8, 4)
    image_set_pixel(图, 2, 1, 255, 128, 0)
    println("尺寸：" + str(image_width(图)) + " x " + str(image_height(图)))
    println("像素：" + str(image_pixel_r(图, 2, 1)) + ", " + str(image_pixel_g(图, 2, 1)))
    println("空白：" + str(image_pixel_a(图, 0, 0)))
    令 蓝图 = image_tint(图, 51 * 65536 + 102 * 256 + 255)
    println("着色：" + str(image_pixel_b(蓝图, 2, 1)))
}
```

```output
尺寸：8 x 4
像素：255, 128
空白：0
着色：255
```

`image_pixel_u16(id, x, y)` 一次调用返回 `r * 256 + g`，用于 16 位高度图。

### `image_save(id, path)` 和 `image_replace(id, path)`

`image_save` 把图像（加载的或新建的）写入文件，保留 alpha，并创建缺失的文件夹。路径相对于程序运行的位置。
成功返回 `1`，失败返回 `-1`。`image_replace` 把新文件解码到已有句柄中，这样经常重新加载的图片不会让图像表不断增长；
它返回 `1` 或 `-1`。

要保存窗口本身，请使用 `screenshot`（参见 [窗口与摄像机](window.md)）。

### `image_tint`、`image_resized`、`image_svg` 和 `image_free`

`image_tint(id, color)` 返回一张由一种打包颜色构成、按原图 alpha 塑形的新图像：可以用任意颜色重绘图标。
`image_resized(id, w, h)` 返回缩放后的副本。`image_svg(svg_text, w, h)` 把 SVG **源文本**（不是路径）渲染为新图像；
需要时先用 `read_file` 读取文件。三者都返回新句柄或 `-1`。

`image_free(id)` 释放图像的像素。句柄仍然有效，但不再绘制任何内容。

## 文字

文字请使用矢量字体或内置笔画字体，两者都在 [字体与界面](fonts-ui.md) 中介绍。
在屏幕上放一个标签最快的方法不需要字体文件：

```ling-gui
令 start = 执 {
    设色(120, 255, 160)
    界面文字(30, 30, 16, "SCORE 0420")
}
```

`ui_text` 把字母画成大写，并且只认识基本的 ASCII 字符，其他字符显示为小方框（所以上例的文本保持英文）。
其他文字请用 `font_load` 加载字体，再用 `font_text_fill` 绘制。
