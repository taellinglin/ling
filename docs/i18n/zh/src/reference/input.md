# 输入与麦克风

Ling 通过**轮询**读取输入：每一帧在循环里问一次"玩家现在在做什么"。没有回调。
本页介绍键盘和鼠标、文字输入、游戏手柄（通过 `gilrs` 库和 `ling-input` crate）
以及麦克风（`ling-mic` crate）。

即使设备不存在，调用任何输入内置函数也是安全的：按键和按钮读作未按下，摇杆读作
`0`，麦克风读作静音。所以游戏可以直接退回到键盘操作，不需要特殊处理。想知道硬件
是否存在，就检查 `mic_open` 或 `pad_poll` 的返回值。

键盘、鼠标和文字输入需要打开的窗口才能收到事件。没有窗口时，它们只会读作空闲：

```ling
令 始 = 执 {
  打印(按键("space"))
  打印(键按("enter"))
  打印(mouse_down())
  打印(滚轮())
  打印(麦克风音量())
  打印(实时频谱(4))
}
```

```output
false
false
false
0
0
[0, 0, 0, 0]
```

## 键盘

### `key_down(name)` 和 `key_pressed(name)`

`key_down` 在按键按住期间一直为真，适合用于移动。`key_pressed` 只在按键按下的那
一帧为真，按住不会重复触发，适合用于开关、菜单和每按一次触发一次的动作。

两者都接受小写的按键名。未知的名字直接为 `false`。其他窗口获得焦点时，两者都读作
`false`。按游戏手柄上的 Start 键也算作 `key_pressed("enter")`，所以等待回车的菜单
也能用手柄操作。

| 分组 | 名字 |
|---|---|
| 字母、数字 | `"a"` 到 `"z"`，`"0"` 到 `"9"` |
| 方向与导航 | `"left"`、`"right"`、`"up"`、`"down"`、`"home"`、`"end"`、`"pageup"`、`"pagedown"`、`"insert"`、`"delete"` |
| 编辑 | `"space"`、`"enter"`、`"escape"`、`"tab"`、`"backspace"`、`"capslock"` |
| 修饰键 | `"lshift"`、`"rshift"`、`"lctrl"`、`"rctrl"`、`"lalt"`、`"ralt"` |
| 功能键 | `"f1"` 到 `"f12"` |
| 小键盘 | `"numpad0"` 到 `"numpad9"`（或 `"kp0"` 到 `"kp9"`）、`"numpad+"`、`"numpad-"`、`"numpad*"`、`"numpad/"` |
| 标点 | `"minus"`、`"equals"`、`"comma"`、`"period"`、`"slash"`、`"semicolon"`、`"quote"`、`"lbracket"`、`"rbracket"`、`"backslash"`、`"grave"`（符号本身也可以） |

```ling-gui
令 始 = 执 {
  开窗(800, 600)
  令 x = 400
  令 暂停 = 0
  循 窗开() {
    若 键按("p") { 令 暂停 = 1 - 暂停 }
    若 暂停 == 0 {
      若 按键("left") { 令 x = x - 4 }
      若 按键("right") { 令 x = x + 4 }
    }
    填(0, 0, 0)
    设色(255, 255, 255)
    画实心圆(x, 300, 20)
    显()
  }
}
```

### 文字输入

输入名字或聊天时，可以让 Ling 替你收集字符。`text_poll()` 把上次调用以来输入的按键
加入文本缓冲区（退格键删除，按住会重复），并返回整个缓冲区。输入框激活期间每帧调用
一次。`text_get()` 不轮询、只读取缓冲区，`text_set(s)` 替换它，`text_clear()` 清空它。

```ling
令 始 = 执 {
  text_set("阿达")
  打印(text_get())
  text_clear()
  打印("[" + text_get() + "]")
}
```

```output
阿达
[]
```

## 鼠标

- `mouse_x()`、`mouse_y()`：光标在窗口内的位置，单位是像素。窗口出现之前都是 `0`。
- `mouse_down()`、`mouse_down_right()`、`mouse_down_middle()`：对应按键按住期间为真。
  它们检查的是状态；要检测一次点击，就和上一帧的值比较。
- `mouse_scroll()`、`mouse_scroll_x()`：上一帧的滚轮移动量，空闲时为 `0`。
- `mouse_dx()`、`mouse_dy()`：自上一帧以来鼠标移动了多远。`dx` 为正表示向右，`dy`
  为正表示向下。只有鼠标被捕获时才不为零。
- `capture_mouse()` 隐藏光标并切换到相对移动，这样无论鼠标移多远，`mouse_dx` 和
  `mouse_dy` 都会持续报告。这是第一人称视角的基础。`release_mouse()` 撤销它。
  Esc 仍然会关闭窗口。
- `cursor_hide()`、`cursor_show()` 只隐藏或显示指针，位置照常跟踪，适合自己绘制光标
  的游戏。

```ling-gui
令 始 = 执 {
  开窗(800, 600)
  令 上次 = 假
  循 窗开() {
    令 本次 = mouse_down()
    若 本次 && !上次 {
      打印("点击位置 " + str(mouse_x()) + ", " + str(mouse_y()))
    }
    令 上次 = 本次
    填(0, 0, 0)
    显()
  }
}
```

## 游戏手柄

手柄有两个系列。推荐使用 **`pad_*`** 系列：最多四名玩家，按钮带边沿检测，有模拟扳机，
桌面和浏览器上代码相同（浏览器里使用 W3C Gamepad API）。较旧的 **`gamepad_*`** 系列
按名字读取最近使用的手柄，并且是能让手柄震动的那个系列。

### `pad_*` 系列

每帧在读取任何值之前调用一次 `pad_poll()`。它会取出手柄事件、推进边沿检测，并返回
已连接的手柄数量。玩家槽位是 `0` 到 `3`。第一次调用会打开手柄后端；如果失败，它返回
`0`，之后所有读取都保持中性值。

- `pad_button(player, name)`：按住按钮期间为真。
- `pad_pressed(player, name)`：只在按下的那一帧为真。浏览器构建中只能知道当前状态，
  所以它在那里的行为和 `pad_button` 一样。
- `pad_lx`、`pad_ly`、`pad_rx`、`pad_ry`：摇杆轴，`-1` 到 `1`。把摇杆**向上**推得到
  **负**的 `y`，与屏幕方向一致。不做死区处理，所以很小的值请自己忽略。
- `pad_lt`、`pad_rt`：模拟扳机，`0`（松开）到 `1`（按到底）。
- `pad_connected(player)`、`pad_count()`：哪些槽位有手柄。
- `pad_rumble(player, low, high)`：目前在桌面和浏览器上都不起作用。要震动请用
  `gamepad_rumble`。

按钮名不区分大小写，有几个名字指同一个按钮。在桌面上，面部按钮按位置区分：
无论哪个品牌，最下面的都是 `a`。

| 按钮 | 名字 |
|---|---|
| 下方面部按钮 | `a`、`south`、`cross` |
| 右方面部按钮 | `b`、`east`、`circle` |
| 左方面部按钮 | `x`、`west`、`square` |
| 上方面部按钮 | `y`、`north`、`triangle` |
| 肩键 | `lb`、`l1`、`left_shoulder`；`rb`、`r1`、`right_shoulder` |
| 扳机（数字） | `lt`、`l2`、`left_trigger`；`rt`、`r2`、`right_trigger` |
| 开始 / 选择 | `start`、`menu`、`options`；`select`、`back`、`share`、`view` |
| 主页键 | `guide`、`home` |
| 摇杆按下 | `l3`、`left_stick`；`r3`、`right_stick` |
| 方向键 | `up`/`dpad_up`、`down`/`dpad_down`、`left`/`dpad_left`、`right`/`dpad_right` |

```ling-gui
令 始 = 执 {
  开窗(800, 600)
  令 x = 400.0
  令 y = 300.0
  循 窗开() {
    手柄轮询()
    若 手柄连接(0) {
      令 x = x + 手柄左X(0) * 5.0
      令 y = y + 手柄左Y(0) * 5.0
      若 手柄按下(0, "a") { 打印("跳") }
    }
    填(0, 0, 0)
    设色(255, 255, 255)
    画实心圆(x, y, 20)
    显()
  }
}
```

### `gamepad_*` 系列

每帧调用一次 `gamepad_poll()`；最近活动的手柄会成为当前手柄。浏览器构建中
`gamepad_poll` 和 `gamepad_rumble` 什么也不做，那里请用 `pad_*`。

- `gamepad_button(name)`：按住时为 `1`，否则为 `0`。名字：`a`、`b`、`x`、`y`、`l1`、
  `r1`、`l2`、`r2`、`l3`、`r3`、`start`、`select`、`dup`、`ddown`、`dleft`、`dright`。
- `gamepad_axis(name)`：`lx`、`ly`、`rx`、`ry`（摇杆，`-1` 到 `1`）以及 `l2`、`r2`
  （扳机）。这里把摇杆向上推得到**正**的 `y`，与 `pad_ly` 相反。
- `gamepad_rumble(low, high, ms)`：让重马达（`low`）和轻马达（`high`）以 `0` 到 `1`
  的强度震动 `ms` 毫秒（默认 200）。手柄不支持力反馈时什么也不会发生。
- `gamepad_list()`：系统能看到的每个手柄一行：名字、是否已连接、能否震动、按钮映射
  来自哪里。手柄表现异常时用它来诊断。
- `gamepad_any()`：有任意标准按钮按下时为 `1`。

```ling-gui
令 始 = 执 {
  打印(gamepad_list())
  gamepad_poll()
  若 gamepad_button("a") == 1 {
    gamepad_rumble(0.4, 0.8, 250)
  }
}
```

## 麦克风

`mic_open()`（`开麦克风`）以 44.1 kHz 单声道开始从默认输入设备采集，成功返回 `1`；
没有设备或访问被拒绝时返回 `0`。只需调用一次，之后读取电平几乎没有开销。

- `mic_rms()`：最新缓冲区的响度（均方根），`0` 到 `1`。
- `mic_peak()`：最新缓冲区中绝对值最大的采样，`0` 到 `1`。
- `mic_fft(bands)`：从 20 Hz 起按对数间隔划分的 `bands`（默认 8）个频带的平滑幅度
  列表，低音在前。麦克风关闭时全为零。

```ling-gui
令 始 = 执 {
  开窗(640, 240)
  若 开麦克风() == 0 { 打印("没有麦克风") }
  循 窗开() {
    令 频带 = 实时频谱(16)
    填(0, 0, 0)
    设色(80, 200, 255)
    令 i = 0
    循 i < 长度(频带) {
      令 高 = 频带[i] * 200.0
      令 x = i * 40
      画三角(x, 230, x + 30, 230, x + 30, 230 - 高)
      画三角(x, 230, x + 30, 230 - 高, x, 230 - 高)
      令 i = i + 1
    }
    显()
  }
}
```

想给跟唱打分，就把麦克风和音乐内置函数结合起来：`music_mic_pitch()`（`麦克风音高`）
每帧给出唱出的频率。见[音乐](../reference/music.md)。

### 录制种子

`mic_capture()` 把最新的采样追加到录音缓冲区（保留最近的 96000 个采样），并返回
缓冲区长度。录音期间每帧调用。`mic_seed()` 以 64 个十六进制字符返回缓冲音频的
SHA3-256 哈希，可直接作为随机数生成器的种子。`mic_clear()` 清空缓冲区。麦克风关闭时
缓冲区保持为空，种子就是空输入的哈希：

```ling
令 始 = 执 {
  打印(mic_capture())
  打印(mic_seed())
  打印(mic_clear())
}
```

```output
0
d75a5e3ee36c258bec7dced963d55ef24bda7d06d0cef7708f2ecca8371a95f7
0
```
