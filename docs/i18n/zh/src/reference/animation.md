# 动画

Anima 是 Ling 的动画系统。任何会动的东西，无论是 2D 图形、3D 网格、粒子还是一个普通数字，都由小小的**驱动器**来带动：驱动器就是你每帧用当前时间调用一次的函数。每个驱动器返回一个数字，你把这个数字用作尺寸、位置、角度或图案参数。

驱动器分为两种气质：

- **有机**驱动器（灵）产生柔和、栩栩如生的运动：呼吸、摇摆、行走、带弹性的跟随动作，以及两骨骼反向运动学。
- **机械**驱动器（机）产生精确、刚性的运动：啮合齿轮、凸轮、曲柄滑块和齿轮齿条。

一个角色里可以混用两者，比如胸口会呼吸、下颌却是机械结构的生物。对于带骨骼的导入 3D 角色，本页末尾的 `gltf_*` 内置函数可以播放骨骼动画片段。

## 驱动器如何工作

驱动器是**纯函数**。它们不保存任何隐藏状态，所以相同的参数总是得到相同的结果。

- 基于时间的驱动器（`breathe`、`wobble`、`gait_*`）由你传入当前时间，通常是 `time_now()`，或者一个每帧加 `1/60` 的变量。后台不会有任何东西在“播放”。
- 弹簧驱动器（`spring_to`）返回新的状态，你在下一帧再把它传回去。状态归你的程序所有。

角度以弧度为单位。长度使用你绘图所用的任意单位。驱动器以单精度计算，所以示例用一个小辅助函数 `取三位` 来对结果取整。

## 插值

### `tween(a, b, t)` 和 `tween_ease(a, b, t, curve)`

`tween` 返回 `a + (b - a) * t`。进度 `t` 会被**限制**在 0..1 之间，所以你可以让它一直增长超过 1，值会停在 `b`。

`tween_ease` 做同样的事，但要经过一条缓动曲线。`curve` 是下面 Anima 表中的名称（默认 `"linear"`）。弹性曲线和回弹曲线可能会越过 `b`。

### `ease(curve, t)`

UI 工具包缓动曲线在进度 `t`（限制在 0..1）处的原始值：开始为 0，结束为 1。曲线名称放在**第一个**参数。当你需要曲线本身的值时使用它，例如混合两种颜色。它没有本地化名称。

```ling
函 取三位(x: 数) -> 数 {
    四舍五入(x * 1000) / 1000
}

令 始 = 执 {
    打印(补间(0, 10, 0.25))
    打印(补间(0, 10, 2.0))
    打印(取三位(缓动补间(0, 100, 0.5, "cubic_in")))
    打印(取三位(缓动补间(0, 100, 0.5, "bounce_out")))
    打印(ease("quad_in", 0.5))
    打印(取三位(ease("smooth", 0.25)))
}
```

```output
2.5
10
12.5
76.563
0.25
0.125
```

### 缓动曲线名称

这两个内置函数使用**不同的名称集合**。两者都不区分大小写。

**`tween_ease`**（Anima 曲线）。下划线可写可不写。未知名称按 `linear` 处理。

| 类别 | 名称 |
|---|---|
| 基本 | `linear`、`step` |
| 二次 | `quad_in`、`quad_out`、`quad_in_out` |
| 三次 | `cubic_in`、`cubic_out`、`cubic_in_out`（也可写 `smooth`） |
| 正弦 | `sine_in`、`sine_out`、`sine_in_out` |
| 指数 | `expo_in`、`expo_out`、`expo_in_out` |
| 弹性 | `elastic_in`、`elastic_out`（也可写 `elastic`） |
| 回弹 | `back_in`、`back_out`、`back_in_out`（也可写 `overshoot`） |
| 弹跳 | `bounce_in`、`bounce_out`（也可写 `bounce`） |

**`ease`**（UI 曲线）。短横线和下划线可以互换。未知名称按 `quad_inout` 处理。

| 名称 | 形状 |
|---|---|
| `linear` | 直线 |
| `quad_in`、`ease_in` | 慢启动 |
| `quad_out`、`ease_out` | 慢收尾 |
| `quad_inout`、`ease`、`smooth` | 慢启动、慢收尾（默认） |
| `cubic_in`、`cubic_out`、`cubic_inout` | 更强的版本 |
| `quart_out` | 快速启动，长而慢的收尾 |
| `sine`、`sine_inout` | 柔和的正弦进出 |
| `expo`、`expo_out` | 指数衰减 |
| `back`、`back_out` | 先越过，再回落 |
| `elastic`、`elastic_out` | 弹簧般的越过 |
| `bounce`、`bounce_out` | 结尾处弹跳 |

## 有机驱动器

### `breathe(t, rate, depth)`

以 1 为中心的呼吸倍数：`1 + depth * sin(2π * rate * t)`。`rate` 是每秒呼吸次数（默认 1），`depth` 是幅度（默认 0.1）。用它乘以尺寸或图案半径。

### `wobble(t, freq, amp, phase)`

用于次级运动的正弦摇摆：`amp * sin(2π * (freq * t + phase))`。默认值：`freq` 1，`amp` 1，`phase` 0。相位以周期为单位，所以 `0.25` 是四分之一周期的偏移。给每个肢体不同的相位，整个身体就不会整齐划一地摇摆。

### `gait_phase(t, speed)`、`gait_swing(t, speed, stride)` 和 `gait_lift(t, speed, height)`

步行周期。`speed` 是每秒的周期数（默认 1）。

- `gait_phase` 返回周期进行到哪里，从 0 到 1（不含 1）。
- `gait_swing` 返回腿的前后摆动，在 `-stride` 到 `stride` 之间。另一条腿使用 `t + 0.5 / speed`。
- `gait_lift` 返回脚抬起的高度：摆动的半个周期为正，着地时为 0。屏幕 y 轴向下，所以要减去它：`脚y = 地面y - gait_lift(...)`。

```ling
函 取三位(x: 数) -> 数 {
    四舍五入(x * 1000) / 1000
}

令 始 = 执 {
    令 t = 0.125
    打印(取三位(呼吸(t, 1, 0.2)))
    打印(取三位(摆动(t, 1, 10, 0)))
    打印(取三位(步相(t, 2)))
    打印(取三位(步摆(t, 1, 30)))
    打印(取三位(抬脚(t, 1, 10)))
}
```

```output
1.141
7.071
0.25
21.213
7.071
```

### `spring_to(pos, vel, target, stiffness, damping, dt)`

阻尼弹簧把 `pos` 拉向 `target` 的一步。用于跟随动作、摄像机平滑和尾巴。默认值：`stiffness` 120，`damping` 14，`dt` 1/60。它返回一个两元素列表 `[新位置, 新速度]`。保存这两个数，下一帧再传回去。

使用默认值时，数值会稍微越过目标，然后在大约一秒内稳定下来：

```ling
令 始 = 执 {
    令 位置 = 0.0
    令 速度 = 0.0
    令 帧 = 0
    循 帧 < 60 {
        令 s = 弹向(位置, 速度, 1.0, 120, 14, 1 / 60)
        令 位置 = s[0]
        令 速度 = s[1]
        令 帧 = 帧 + 1
        若 帧 % 15 == 0 {
            打印("第" + str(帧) + "帧：" + str(四舍五入(位置 * 1000) / 1000))
        }
    }
}
```

```output
第15帧：0.982
第30帧：1.021
第45帧：0.997
第60帧：1
```

### `ik2(l1, l2, tx, ty)`

平面两骨骼反向运动学：求出让两段手臂或腿的末端到达目标的肩角和肘角。`l1` 和 `l2` 是骨骼长度（默认 1），`(tx, ty)` 是相对于肩部的目标。

它返回以弧度表示的 `[肩, 肘]`。`肩` 是第一根骨骼的角度，`肘` 是第二根骨骼**相对于第一根**的弯曲角。够不着的目标会被限制，肢体会朝它伸直。关节位置这样计算：

- 肘 = 肩的位置 + `l1 * (cos(肩), sin(肩))`
- 手 = 肘 + `l2 * (cos(肩 + 肘), sin(肩 + 肘))`

```ling
函 取三位(x: 数) -> 数 {
    四舍五入(x * 1000) / 1000
}

令 始 = 执 {
    令 角 = 反解(1, 1, 1, 1)
    打印([取三位(角[0]), 取三位(角[1])])
}
```

```output
[1.571, -1.571]
```

## 机械驱动器

| 内置函数 | 返回值 |
|---|---|
| `gear_couple(angle, teeth_in, teeth_out)` | 从动齿轮的角度：`-angle * teeth_in / teeth_out`（`teeth_out` 为 0 时返回 0）。啮合的齿轮朝相反方向转动。 |
| `gear_train(angle, teeth)` | 一个列表，包含齿轮链中每个齿轮的角度。`teeth` 是齿数列表；结果的第一个元素就是 `angle` 本身。 |
| `cam_lift(angle, lift)` | 凸轮从动件的高度：`lift * (1 - cos(angle)) / 2`，角度 0 时为 0，π 时为 `lift`。 |
| `piston(angle, crank, rod)` | 活塞销沿气缸到曲柄中心的位置。默认值：`crank` 1，`rod` 2（连杆应长于曲柄）。 |
| `rack(angle, radius)` | 齿条行程：`angle * radius`。 |

12 齿的齿轮带动 36 齿的齿轮时，后者以三分之一的速度反向转动：

```ling
函 取三位(x: 数) -> 数 {
    四舍五入(x * 1000) / 1000
}

令 始 = 执 {
    打印(取三位(齿轮联动(3, 12, 36)))
    令 齿轮 = 齿轮组(1, [12, 36, 12])
    打印([取三位(齿轮[0]), 取三位(齿轮[1]), 取三位(齿轮[2])])
    打印(取三位(凸轮升程(3.14159265, 2)))
    打印(取三位(活塞(0, 1, 3)))
    打印(齿条(2, 0.5))
}
```

```output
-1
[1, -0.333, 1]
2
4
1
```

## 一个运动的场景

这个窗口组合了一个会呼吸的圆盘、一只行走的脚，以及一个追逐移动目标的弹簧。弹簧的位置和速度逐帧传递下去。

```ling-gui
令 始 = 执 {
    开窗(640, 360, "动画")
    令 t = 0.0
    令 弹位 = 0.0
    令 弹速 = 0.0
    循 窗开() {
        填(10, 12, 28)
        # 有机：会呼吸的圆盘
        设色(120, 220, 255)
        画实心圆(120, 120, 40 * 呼吸(t, 0.4, 0.12))
        # 有机：行走的脚
        令 摆 = 步摆(t, 1.0, 30)
        令 抬 = 抬脚(t, 1.0, 20)
        设色(255, 210, 90)
        画线(120, 200, 120 + 摆, 260 - 抬)
        画实心圆(120 + 摆, 260 - 抬, 10)
        # 有机：追逐目标的弹簧
        令 目标 = 400 + 80 * 正弦(t * 1.3)
        令 s = 弹向(弹位, 弹速, 目标, 120, 10, 0.016)
        令 弹位 = s[0]
        令 弹速 = s[1]
        设色(120, 255, 160)
        画实心圆(弹位, 180, 12)
        显()
        令 t = t + 0.016
    }
}
```

## 骨骼动画（glTF）

以 `.glb` 或 `.gltf` 导出的绑好骨骼的角色带有骨骼、蒙皮权重和动画片段。这些内置函数加载这样的模型并以蒙皮方式绘制。除了两个带纹理的绘制函数，它们都没有本地化名称：`gltf_anim_draw_tex` 也可写作 `骨骼动画纹理绘制`（zh）、`スキンアニメ描画`（ja）、`글꼴애니텍스처`（ko）、`วาดแอนิเมชันมีพื้นผิว`（th），`gltf_pose_draw_tex` 也可写作 `骨骼姿势纹理绘制`、`スキンポーズ描画`、`글꼴포즈텍스처`、`วาดสกินมีพื้นผิว`。

| 内置函数 | 用途 |
|---|---|
| `gltf_load(path)` | 加载模型。返回句柄，失败时返回 `-1`。 |
| `gltf_anim_count(h)` | 动画片段数量。 |
| `gltf_anim_name(h, i)` | 片段 `i` 的名称。 |
| `gltf_anim_dur(h, i)` | 片段 `i` 的长度（秒）。 |
| `gltf_joint_count(h)` | 蒙皮关节（骨骼）数量。 |
| `gltf_joint_name(h, j)` | 关节 `j` 的名称。 |
| `gltf_autorig(h)` | 给没有骨骼的模型生成一套程序化的 20 骨骼人形骨架。返回骨骼数。 |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | 以片段 `clip` 在 `time` 秒处的姿势，带纹理、带蒙皮地绘制模型。 |
| `gltf_pose_draw(h, x, y, z, scale, yaw, pose)` | 用你自己给出的姿势蒙皮绘制模型（纯色）。 |
| `gltf_pose_draw_tex(h, x, y, z, scale, yaw, pose)` | 同上，带纹理。 |
| `gltf_bounds(h, clip, time)` | 用该片段和时间绘制时模型的 `[minX, minY, minZ, maxX, maxY, maxZ]`。 |

注意：

- 片段时间会循环，所以你可以传入一直增长的时间，片段会反复播放。
- `pose` 是一个扁平的欧拉角列表（弧度），每根骨骼三个值（X、Y、Z）。
- glTF 模型是 Y 轴向上的。绘制函数会把它翻转到渲染器 y 轴向下的空间，所以 `(x, y, z)` 是模型原点（通常是脚底）所在的位置。
- `gltf_anim_draw_tex` 在 `time` 之后还有更多可选参数：环境光、背面剔除（`1` 表示剔除）、一个用其片段驱动本模型的源模型（用于按关节名匹配的装备）、一个额外的逐骨骼旋转列表，以及一个 `0xRRGGBB` 色调。
- `gltf_draw(h, x, y, z, scale, yaw)` 不带蒙皮地绘制模型。`gltf_mesh_count`、`gltf_mesh_name`、`gltf_mesh_show(h, i, on)` 和 `gltf_mesh_tint(h, i, 0xRRGGBB)` 可以显示、隐藏或着色单个网格，例如用来换装备。

```ling-gui
令 始 = 执 {
    开窗(960, 540, "行走")
    深度测试(1)
    令 英雄 = gltf_load("hero.glb")
    令 i = 0
    循 i < gltf_anim_count(英雄) {
        打印(gltf_anim_name(英雄, i) + "：" + str(gltf_anim_dur(英雄, i)) + " 秒")
        令 i = i + 1
    }
    循 窗开() {
        填(20, 24, 40)
        gltf_anim_draw_tex(英雄, 0, 2, 6, 1, 0.5, 0, 当前时间())
        flush_3d()
        显()
    }
}
```

## 哪些不是内置函数

`ling-animation` crate 里还有关键帧轨道和时间线、带蒙皮矩阵的关节骨架、程序化的双足和四足步态、四连杆求解器以及面部骨架。这些是给嵌入者用的 Rust API，不是 Ling 内置函数。旧文档里出现的 `rig_load`、`anim_play` 之类的名称并不存在，`delta_time()` 也没有实现。请用 `time_now()` 获取时间。

另见：[后期特效与光照](postfx.md)、[窗口与摄像机](window.md)。
