# 概览

内置函数是 Ling 自带的函数：打印、数学、文本、文件、窗口、声音、Web 服务器等等。本部分按主题列出它们，
包括各语言中的名字、参数与返回值，以及可以直接运行的简短示例。

## 内置函数如何工作

**随时可用。** 内置函数不需要导入。在程序的任何地方直接按名字调用即可：

```ling
令 start = 执 {
  印(根(16) + 最大(2, 5))
}
```
```output
9
```

**按位置传参。** 参数没有名字，顺序很重要。末尾缺少的参数通常会取文档中写明的默认值，而不会报错，
所以 `clamp(1.5)` 会限制在 0..1 范围内。

**失败也是一个值。** 大多数内置函数通过返回可以检查的值来报告问题：`false`、`0`、`-1`、空列表，
或者 `bad(...)` 结果。每个条目都会说明是哪一种。失败方式比较复杂的内置函数会返回 `ok(value)` 或 `bad(reason)`；
见[错误与结果](../language/errors.md)。

**五种语言的名字。** 许多内置函数除了英文名，还有中文、日文、韩文和泰文名字。它们调用的是同一个函数，
而且英文名始终可用，在任何文件中、与任何其他语言混用都没问题：

```ling
令 start = 执 {
  print(sqrt(16))
  印(根(16))
  印刷(平方根(16))
  출력(제곱근(16))
  พิมพ์(รากที่สอง(16))
}
```
```output
4
4
4
4
4
```

`lingfu normalize --to <lang>` 会把程序的关键字和内置函数改写成同一种语言。见[用五种语言编写](../language/multilingual.md)。
运行时还认识其他一些语言（法语、德语、俄语、阿拉伯语、波斯语、希伯来语、乌尔都语）中的名字；这些页面只列出文档覆盖的五种语言。

## 安装配置

`cargo install ling-lang` 安装的是 `full` 配置，包含所有内置函数。如果你安装的是较小的[安装配置](../getting-started/install.md)，
有些内置函数族会被排除在构建之外。调用这样的函数会让程序停止，并给出一条指明需要添加哪个配置的错误：

```text
'http_get' needs the `web` profile, which this build of ling leaves out (reinstall with: cargo install ling-lang --features web, or the default full install)
```

| 配置 | 内置函数族（示例） |
|---|---|
| `core` | “输出”“文本”“文件”页面上的内容（进程除外）、窗口、2D 绘图、字体、图像、网格 |
| `web` | `http_*`、`db_*`、`zip_*`、`tar_gz_*`、`video_*`、`run_process`、`proc_*`、哈希与加密 |
| `privacy` | `p2p_*`、`lingtp_*`、`ssh_*`、`lw_*` |
| `game` | `rb_*`、`soft_*`、`liquid_*`、`gltf_*`、`gpu_*`、`body_*`、`pad_*`、`dialog_*`、`ui_*` |
| `ai` | `nn_*`、`bt_*`、`stt_*`、学习型对话模型 |
| `audio` | `audio_*`、`music_*`、`mic_*`、`fft_*` |

`llm_*`（本地语言模型）和 `vision_*` 这类重量级扩展需要在任何配置之上另行开启。

## 如何阅读这些页面

每个参考页面的结构都相同：

1. 一段介绍，说明适用于整页的规则。
2. **一览表。** 第一列是签名，例如 `clamp(x, low, high)`。各语言列给出本地化的名字；`—` 表示还没有本地化名字，
   请使用英文名。阅读翻译版页面时，只会显示你所用语言的那一列。
3. **每个内置函数或每组一个小节**：参数、返回值、注意事项和示例。

标为 `ling` 的示例都用 `ling run` 运行过，下面显示的输出是真实的。需要窗口、声音、网络或服务器的示例只检查语法，
因此没有输出块。没有 `start` 块的代码片段是更大程序的一部分。

Ling 有两个后端：默认的编译后端和解释器（`ling run --interp`）。两者行为不同的地方（例如作为参数传入的函数只在解释器上有效），
条目中都会注明。[已知限制](../language/limits.md)汇总了这些差异。
