# 对话

Ling 有两种对话工具。**对话框**负责展示角色说的话：一个冒险游戏风格的文本框，
文字逐字打出、可以分页，并用颜色高亮人名、地名和物品。**对话模型**负责决定角色
说什么：一个极小的语言模型，用角色自己的台词在一秒内训练完成，每个 NPC 都能带一个。
它的训练数据使用一种纯文本格式，即 **Ling 对话标准**（`.lingdialog`）。

除了 `dialog_draw` 之外，两者都不需要窗口，所以你可以在无窗口模式下测试整段对话。

## 对话框

对话框的状态保存在运行时里，与绘制分开：`dialog_show` 打开它，`dialog_step` 推进时间，
`dialog_advance` 响应玩家，`dialog_draw` 把它画出来。`dialog_active()` 为真时，
请暂停你的游戏世界。

### 标记

| 标记 | 含义 |
|---|---|
| `{n}...{/}` | 人名（颜色角色 1）。 |
| `{p}...{/}` | 地名（角色 2）。 |
| `{i}...{/}` | 物品（角色 3）。 |
| 换行符 | 在框内换行。 |
| `\|\|` | 分页。 |

标签恰好是三个字符：`{`、一个字母和 `}`；`{/}` 回到普通文本（角色 0）。其他内容
按原样显示。

一页打完后，1.4 秒后会自动翻到下一页；最后一页之后对话框关闭。

### `dialog_show(text, cps)`

用 `text` 打开对话框，以每秒 `cps` 个字符的速度打字（默认 32，至少 1）。
会替换已经打开的对话框。

### `dialog_step(dt)`

把打字效果和自动翻页计时器推进 `dt` 秒（默认 `0.016`）。对话框激活期间每帧调用。

### `dialog_advance()`

玩家按下确认键时调用。如果当前页还在打字，就立即显示整页；否则翻到下一页，
或在最后一页之后关闭。请用一次按键（`key_pressed`）驱动它，而不是按住的键，
这样按一下不会连跳好几页。

### `dialog_active()`、`dialog_typing()` 和 `dialog_close()`

对话框打开期间 `dialog_active()` 为 `true`。当前页还在逐字出现时 `dialog_typing()`
为 `true`。`dialog_close()` 立即关闭对话框。

```ling
令 始 = 执 {
  对话显示("你好，{n}小灵{/}。||第二页。", 100)
  打印("打开：" + str(对话激活()))
  打印("打字中：" + str(对话打字()))
  对话步进(0.5)
  打印("0.5 秒后打字中：" + str(对话打字()))
  对话推进()
  打印("第 2 页打字中：" + str(对话打字()))
  对话推进()
  对话推进()
  打印("最后是否打开：" + str(对话激活()))
}
```

```output
打开：true
打字中：true
0.5 秒后打字中：false
第 2 页打字中：true
最后是否打开：false
```

每秒 100 个字符时，第一页在 0.5 秒后就已打完。第一次 `对话推进` 翻到第 2 页，
第二次显示第 2 页的全部内容，第三次关闭对话框。

### `dialog_color(role, r, g, b)`

设置一个角色的颜色：`0` 普通文本、`1` 人名、`2` 地名、`3` 物品（大于 3 的值按 3 处理）。
`r`、`g`、`b` 取 0 到 255（默认 255）。

### `dialog_draw(x, y, w, h, font)`

以 `(x, y)`（默认 40, 0）为左上角、`w` × `h`（默认 720 × 150）为大小，绘制带斜边的
对话框和目前已显示的文字。`font` 是 `font_load` 返回的句柄；省略或传 `-1` 时使用
内置的文字绘制。

```ling-gui
令 始 = 执 {
  开窗(800, 600)
  令 界面字体 = 加载字体("assets/fonts/NotoSansSC.ttf", 600.0)
  令 台词 = "嘿，{n}林克{/}！把{i}大师之剑{/}带到{p}海拉鲁平原{/}去。||小心夜晚。"
  对话颜色(1, 255, 210, 80)
  循 窗开() {
    若 键按("space") {
      若 对话激活() { 对话推进() } 否则 { 对话显示(台词, 34.0) }
    }
    填(10, 10, 20)
    若 对话激活() {
      对话步进(0.016)
      对话绘制(50.0, 420.0, 700.0, 150.0, 界面字体)
    } 否则 {
      // 这里写平时的游戏更新
    }
    显()
  }
}
```

## 对话模型

对话模型是 Ling 内置的一个微型"预测下一个词"的语言模型（`ling_ai::dialog_lm`），
只有几 KB 大小。你把一个角色的台词交给它，训练它，再让它接着一个提示往下说。
它学到的是语气和用词，而不是事实，所以适合环境闲聊、随口的喊话和点缀性的文字。
训练一个小语料远不到一秒。温度为 `0` 时输出是确定的。

```ling
令 始 = 执 {
  令 店主 = 建对话模型(3, 32, 64, 1)
  对话学习(店主, "欢迎 旅人")
  对话学习(店主, "磨 好 你的 剑")
  对话学习(店主, "欢迎 回来 旅人")
  令 损失 = 对话训练(店主, 60, 0.1)
  打印(损失 < 2.0)
  打印(对话生成(店主, "欢迎", 6, 0.0))
}
```

```output
true
回来 旅人
```

### `dialog_new(ctx, embed, hidden, seed)`

创建一个空模型并返回句柄。`ctx`（默认 3）是它回看的前文词数，`embed`（默认 32）
和 `hidden`（默认 64）是网络大小，`seed`（默认 1）让训练结果可以复现。

### `dialog_learn(m, text)` 和 `dialog_load(m, path)`

`dialog_learn` 向语料加入一行。`dialog_load` 加入整个 `.lingdialog` 文件，返回加入的
训练行数（每段对话一行）；文件无法读取时返回 `-1`。

### `dialog_train(m, epochs, lr)`

以学习率 `lr`（默认 0.1）把语料里的所有内容训练 `epochs` 遍（默认 20）。返回最终
损失：越低表示模型越贴合它的台词。

### `dialog_say(m, prompt, max, temp)`

接着 `prompt` 往下生成最多 `max` 个词（默认 24），只返回新生成的词。遇到一轮发言
的结尾会提前停止。`temp`（默认 0.8）是温度：`0` 总是选最可能的词，越高越多变。

分词器按空格和标点切分文本，并转成小写。中文书写时词与词之间没有空格，所以在语料
和提示里请用空格隔开词语；回复里的词也会以空格分隔。

### `dialog_save(m, path)` 和 `dialog_load_model(path)`

`dialog_save` 把训练好的模型写入文件（默认 `"model.llm"`），成功返回 `true`。
`dialog_load_model` 读回一个模型并返回新句柄，失败返回 `-1`。在开发游戏时训练一次，
发布时附带并加载这个小小的模型文件即可。

## Ling 对话标准

`.lingdialog` 是一种按行组织、便于手写的语料格式。编剧可以手工编辑，也可以从电子
表格生成；在代码评审中差异清晰，也能像普通文本文件一样做本地化。

```text
# Ling Dialog Standard v1
@meta title: 酒馆老板
@meta speaker: 布拉姆

= 欢迎
布拉姆: 欢迎 旅人
英雄: 路上 有 什么 消息
布拉姆: 北 山口 有 强盗
      我 的 炖菜 包 治 百病

= 传闻
布拉姆: 磨 好 你的 剑
```

| 行 | 含义 |
|---|---|
| `# ...` | 注释，直到行尾。 |
| `@meta key: value` | 数据集的元数据。可以重复。 |
| `= label` | 开始一段新对话。标签可选。 |
| `speaker: text` | 一轮发言。说话人是**第一个**冒号之前的文字。 |
| 不含 `:` 的行 | 接在上一轮发言后面（用空格连接）。 |
| 空行 | 忽略。 |

冒号请使用半角的 `:`。解析永远不会失败：格式错误的行会被跳过，所以一个多余的字符
不会毁掉一次训练。第一个 `=` 之前的发言组成一段隐含的对话。

每段对话会变成一行训练数据，各轮发言之间用保留词元 `<eos>` 连接，因此模型学会的是
**跨越**发言轮次往下接。自己写出 `<eos>` 也表示一轮发言的边界。保留词元有 `<pad>`、
`<bos>`、`<eos>` 和 `<unk>`。

```ling
令 始 = 执 {
  write_file("bram.lingdialog", "# Ling Dialog Standard v1\n@meta speaker: 布拉姆\n\n= 欢迎\n布拉姆: 欢迎 旅人\n英雄: 路上 有 什么 消息\n布拉姆: 北 山口 有 强盗\n\n= 传闻\n布拉姆: 磨 好 你的 剑\n")
  令 店主 = 建对话模型(3, 32, 64, 1)
  打印(对话载入(店主, "bram.lingdialog"))
  对话训练(店主, 80, 0.1)
  打印(对话生成(店主, "北 山口", 8, 0.0))
  打印(对话存模(店主, "bram.llm"))
  令 再次 = 对话载模("bram.llm")
  打印(对话生成(再次, "磨 好", 8, 0.0))
}
```

```output
2
有 强盗
true
你的 剑
```

### 写好语料

- **一致胜过数量。** 一份声音统一的小语料，比一大份泛泛的语料更能塑造出辨识度高的角色。
- **重复标志性台词。** 希望角色常说的话，应在不同对话里出现几次。
- **一个声音一个文件。** 每个角色单独一个文件，这样每个角色都有自己的模型和性格。
- **自然地写。** 大小写和标点由分词器处理。

## 组合使用

模型负责写台词，对话框负责展示：

```ling-gui
令 始 = 执 {
  开窗(800, 600)
  令 布拉姆 = 对话载模("npc/bram.llm")
  循 窗开() {
    若 键按("e") && !对话激活() {
      对话显示("{n}布拉姆{/}：" + 对话生成(布拉姆, "欢迎", 12, 0.7))
    }
    若 键按("space") && 对话激活() { 对话推进() }
    填(10, 10, 20)
    对话步进(0.016)
    若 对话激活() { 对话绘制(50, 420, 700, 150) }
    显()
  }
}
```
