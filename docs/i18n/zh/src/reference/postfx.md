# 后期特效与光照

本页介绍 Ling 如何照亮 3D 场景，以及如何收尾每一帧。光源和着色决定每个三角形绘制时的颜色。之后，一条屏幕空间的**后期处理链**会作用在完成的画面上：环境光遮蔽、墨线描边、色调渐变、泛光和抗锯齿。在此之上，你还可以加景深、屏幕扭曲和柔和的体积光柱。

这里的一切都绘制到打开的窗口中，所以示例都是 `ling-gui` 程序。

解释器接受表中的所有名称。`lingfu normalize` 只翻译其中一部分（光源相关函数和 `set_ambient`），所以本站的本地化示例中其余函数保留英文名。

## 光源

光源和绘图一样遵循每帧的流程：清除、添加、绘制。

### `set_ambient(level)`

不依赖任何光源、照到所有表面的光，取值 0 到 1（默认 0.15）。

### `add_light(x, y, z, r, g, b, intensity, radius)`

在世界坐标的某个位置添加一个彩色点光源。颜色可以用 0 到 1 或 0 到 255：只要有一个通道大于 1.5，三个通道都按 0 到 255 理解。`intensity` 是亮度倍数（默认 1）。`radius` 是光线衰减到零的距离；0 表示不衰减（默认）。

参数顺序是位置、**颜色**、强度、半径。光源会一直累加，直到你调用 `clear_lights()`，所以每帧都要先清除再重新添加。

### `set_fog(r, g, b, start, end)`

距离雾：几何体在摄像机深度 `start` 到 `end` 之间逐渐融入该颜色（0 到 255）。`end` 小于等于 0 时关闭雾。下面的体积光也会随雾淡出。

```ling-gui
令 始 = 执 {
    开窗(720, 420, "光源")
    深度测试(1)
    环境光(0.2)
    set_fog(8, 10, 24, 10, 40)
    循 窗开() {
        填(8, 10, 24)
        清灯()
        加灯(0, -5, 4, 1.0, 0.85, 0.6, 1.2, 20)
        设色(240, 150, 110)
        立方体(0, 0, 8, 1, 1, 1, 0.3, 当前时间(), 0, 0)
        显()
    }
}
```

## 着色

着色器为每个顶点混合以下内容：你的画笔颜色、环境光项（表面背对所有光源的地方会染上阴影色）、每个光源的贡献、朝向轮廓的边缘光，以及默认模式下一层淡淡的彩虹光泽。结果再被量化成几个亮度色阶。

默认值刻意做了风格化：冷靛蓝的阴影色、青色的边缘光和全息光泽。想让颜色与画笔一致，请使用 `set_shade_mode(1)`、`set_rim(0, 0, 0, 0)` 和一个深色中性的 `set_shadow_color`。

| 内置函数 | 参数 |
|---|---|
| `set_shade_mode(m)` | `0` 平面，每个三角形一个色阶；`1` 平滑卡通，无光泽，边缘光减弱；`2` 全息（默认）。 |
| `set_cel_bands(n)` | 色阶数，至少 2（默认 4）。 |
| `set_shadow_color(r, g, b)` | 背光区域的色调，0 到 255（默认 26, 33, 77）。 |
| `set_rim(strength, r, g, b)` | 边缘光强度（默认 0.6；0 表示关闭）和颜色 0 到 255（默认 115, 217, 255）。 |
| `set_flat_shade(on)` | 非零时跳过所有光照，直接用画笔原色绘制。用于性能测试。 |

### `set_material(key, value)` 和 `reset_material()`

`set_material` 为之后的 `draw_triangle_3d` 和多边形绘制启用一种基于物理的卡通材质。`key` 是字符串，`value` 是数字；颜色类的键接受打包的 `0xRRGGBB` 数字。可用的键：`albedo`、`roughness`、`metallic`、`emission`、`emission_strength`、`specular`、`specular_tint`、`subsurface`、`subsurface_color`、`clearcoat`、`clearcoat_roughness`、`transmission`、`ior`、`iridescence`、`sheen`、`anisotropy`、`anisotropy_angle`、`toon_bands`、`shadow_softness`、`outline_px`、`outline_color`、`highlight_color`。未知的键会被忽略。`reset_material()` 切回普通光照。基本立体（`cube`、`sphere` 等）不读取材质。

## 后期处理链

后期处理链在 `present()` 内部按以下顺序运行：

1. **环境光遮蔽**（`set_ssao`）：根据深度缓冲生成柔和的接触阴影。
2. **描边**（`toon_outlines`）：在深度突变处画墨线。
3. **色调渐变**（`tone_*`）：把亮度映射成卡通色阶。
4. **泛光**（`set_bloom`）：从亮像素向外渗出的辉光。
5. **FXAA**（`set_fxaa`）：对最终画面做边缘抗锯齿。

环境光遮蔽、描边、泛光和 FXAA 在你开启之前都是关闭的。色调渐变总是运行，从默认的三段渐变开始。遮蔽和描边要读取深度缓冲，所以要先调用 `set_depth_test(1)`。

矢量线条和文字不受色调渐变影响，所以界面文字和线框永远不会被量化成色阶。

### `set_ssao(strength, radius_px, zrange)`

在角落、缝隙和物体下方产生柔和的暗部，以半分辨率计算并平滑。`strength` 0 到 1（0 表示关闭），`radius_px` 是以像素计的采样半径（默认 6），`zrange` 是邻近像素被算作遮挡物的深度范围（默认 12）。

### `toon_outlines(thickness, color, threshold)`

在深度不连续处画墨线。`thickness` 是以像素计的半宽（0 表示关闭，1.5 是不错的动漫风默认值），`color` 是打包的 `0xRRGGBB` 数字（默认 0，即黑色），`threshold` 是算作边缘的深度跳变（默认 0.05）。

### 色调渐变

色调渐变是一组节点，每个节点把输入亮度 `t` 映射为输出亮度 `value`（都在 0 到 1 之间）。默认渐变有三段：低于 0.25 时为 0.08，低于 0.60 时为 0.50，以上为 1.00。

- `tone_stop(t, value)` 添加一个节点。节点按 `t` 保持排序。
- `tone_ramp_clear()` 移除所有节点，好让你自己搭建。`tone_ramp_reset()` 恢复默认。
- `tone_smooth(on)`：`0` 在节点之间硬切换（默认），`1` 平滑混合。
- `tone_bezier(y1, y2)` 在查找之前用三次贝塞尔曲线重映射输入亮度。约 `0.333, 0.667` 是中性的（默认值），`0, 0` 偏暗，`1, 1` 偏亮，`0.1, 0.9` 是 S 形曲线。`tone_bezier_off()` 移除它。
- `tone_soft(soft, sheen)`：`soft`（0 到 1，默认 0.32）是每个色阶间隔中跨越边界混合的比例，0 时边缘锐利如刀，约 0.3 时阴影边缘柔和。`sheen`（0 到 1，默认 0.65）让亮像素保留渐变，使高光看起来是干净的光泽，而不是粗糙的色块。

两种常见风格：

| 风格 | 调用 |
|---|---|
| 清爽的动漫卡通 | `tone_smooth(0)`、`tone_soft(0.32, 0.65)` |
| 平滑的绘画感 | `tone_smooth(1)`、`tone_bezier(0.12, 0.88)`、`tone_soft(0.32, 0.65)` |

### `set_bloom(strength, threshold)`

亮像素向外渗出柔和的辉光，以四分之一分辨率计算。`strength` 默认 0.45（0 表示关闭）；`threshold` 是亮度阈值，0 到 0.99（默认 0.74）。

### `set_fxaa(on)`

对整个画面做一次轻量的抗锯齿（参数默认 1）。它柔化多边形的锯齿和描边的毛刺，不影响平涂区域。它与 `set_antialias` 不同，后者是在绘制时平滑线框笔画。

### `flush_post()`

像 `flush_3d()` 一样刷新 3D 队列，然后立即运行后期处理链。这一帧的 `present()` 会跳过处理链，所以在 `flush_post()` 之后画的 HUD 保持清晰，不会被泛光或模糊。`post_now()` 是它的另一个英文名。

```ling-gui
令 始 = 执 {
    开窗(960, 540, "卡通")
    深度测试(1)
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    toon_outlines(1.5, 0, 0.05)
    set_ssao(0.4, 7, 14)
    tone_smooth(1)
    tone_bezier(0.12, 0.88)
    tone_soft(0.32, 0.65)
    set_bloom(0.5, 0.74)
    set_fxaa(1)
    循 窗开() {
        填(20, 24, 40)
        清灯()
        加灯(-2, -6, -2, 1.0, 0.95, 0.85, 0.8, 0)
        设色(220, 180, 120)
        球体(0, 0, 8, 1.5, 1.5, 1.5, 0, 当前时间(), 0, 0)
        flush_post()
        设色(255, 255, 255)
        界面文字(20, 20, 16, "HUD")
        显()
    }
}
```

## 屏幕效果

### `depth_blur(focus, range, radius, oil)`

利用深度缓冲对画面做景深。画面在摄像机深度 `focus`（默认 30）处清晰，深度偏离 `range`（默认 60）时达到 `radius` 像素（默认 3）的完全模糊。没有几何体的背景完全模糊。`oil`（0 到 1，默认 0）给模糊区域加上彩虹般的油膜色边和色相漩涡，适合水面或热浪。`dof` 和 `depth_of_field` 是它的其他英文名。

要在 `flush_3d()` **之后**（深度缓冲已填好）、绘制界面**之前**调用。需要 `set_depth_test(1)`。

### `screen_distort(amount, t, step)`

黏稠的全屏扭曲，边缘环绕，用于黏液、热浪和梦境效果。`amount` 是最大位移像素数（默认 8），`t` 是让扭曲动起来的时间值（默认 0），`step` 为 1 时全分辨率，2 及以上时是更省的分块扭曲（默认 1）。与 `depth_blur` 一样，在 3D 刷新之后、界面之前调用。浏览器版本中不可用。

```ling-gui
令 始 = 执 {
    开窗(960, 540, "热浪")
    深度测试(1)
    循 窗开() {
        填(10, 20, 40)
        设色(120, 200, 255)
        立方体(0, 0, 8, 1, 1, 1, 0, 当前时间(), 0, 0)
        立方体(3, 0, 20, 1, 1, 1, 0, 当前时间(), 0, 0)
        flush_3d()
        depth_blur(8, 6, 4, 0.3)
        screen_distort(4, 当前时间(), 2)
        显()
    }
}
```

## 体积光

`light_pool` 和 `light_beam` 绘制柔和的叠加渐变，看起来像光在水中或尘埃中扩散。它们的外缘渐变到黑色，所以在叠加混合下没有可见的边缘。两者都会随距离雾淡出，代价是填充率：在屏幕上越大，越昂贵。

### `light_pool(x, y, z, radius, r, g, b, intensity)`

灯光投在高度 `y` 处地面上的彩色光斑。默认值：位置 0，`radius` 20，颜色 255（每通道 0 到 255），`intensity` 1（约 0.2 到 1.5 效果较好）。

### `light_beam(x, y, z, floor_y, radius, r, g, b, intensity)`

耶稣光：从光源位置向下到 `floor_y` 处地面的双锥体，逐渐扩展到 `radius`（默认 14）。在它底部配一个 `light_pool`。

两者都用 `set_blend(1)`（叠加）绘制，之后回到 `set_blend(0)`。配合 `tone_smooth(1)` 效果最好，因为硬色阶会把平滑的渐变变成一级级的平台。

```ling-gui
令 始 = 执 {
    开窗(720, 420, "体积光")
    深度测试(1)
    环境光(0.2)
    set_shade_mode(1)
    tone_smooth(1)
    set_bloom(0.5, 0.74)
    循 窗开() {
        填(6, 8, 18)
        设镜(1, 0, 余弦(0.25), 正弦(0.25))
        镜坐标(0, -3, 0)
        清灯()
        加灯(0, -5, 8, 1.0, 0.9, 0.7, 0.8, 0)
        设色(220, 180, 120)
        圆柱(0, 1.3, 9, 0.8, 0.7, 0.8, 0, 0, 0, 0)
        混合模式(1)
        light_beam(0, -6, 9, 2, 3.0, 255, 220, 160, 0.8)
        light_pool(0, 2, 9, 5.0, 255, 220, 160, 0.9)
        混合模式(0)
        flush_3d()
        显()
    }
}
```

## 旧名称

`shadow_smooth(softness)` 是一个旧的快捷方式，会同时设置 `tone_smooth` 和 `tone_bezier`；请改用这两个函数。`toon_highlight(...)` 仍被接受但什么都不做；请用 `tone_stop` 和 `tone_soft`。
