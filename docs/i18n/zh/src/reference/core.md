# 输出、数学与逻辑

这些内置函数负责向控制台打印、构造文本、做算术运算以及暂停程序。
它们不需要窗口，所以本页的每个示例都可以在普通终端里用 `ling run` 运行。

Ling 中的所有数字都是 64 位浮点数。整数值打印时不带小数点（`3`，而不是 `3.0`）。
角度使用弧度。末尾缺少的数值参数通常会取默认值，而不是报错。

## 输出

### `print(value, ...)` 与 `println(value, ...)`

`print` 和 `println` 是同一个内置函数。每个参数先转换成文本，再**不加分隔符**地拼接起来，
最后换行。列表打印为 `[1, 2, 3]`，结果打印为 `Ok(v)` 和 `Err(e)`。

```ling
令 start = 执 {
  印("你好，Ling！")
  印(42, " ", 3.5, " ", 真)
  印([1, 2, 3])
  印("总和", 1 + 2)
  印("总和 ", 1 + 2)
}
```
```output
你好，Ling！
42 3.5 true
[1, 2, 3]
总和3
总和 3
```

空格需要自己写进字符串里，或者用 `format` 来构造这一行。

### `print_file(text)`

打印第一个参数，**不**换行。别看名字，它并不读写文件。这是在同一行上继续打印的唯一方法。

```ling
令 start = 执 {
  历 i 于 1..4 {
    print_file(i)
    print_file(" ")
  }
  印("出发！")
}
```
```output
1 2 3 出发！
```

### `print_color(color, value, ...)`

用加粗的明亮 ANSI 颜色打印一行。`color` 取 0 到 7：黑、红、绿、黄、蓝、品红、青、白。
其余参数像 `print` 一样拼接。转义码会原样写出，所以把输出重定向到文件时，它们会显示为控制字符。

```ling-gui
令 start = 执 {
  print_color(2, "成功：", "所有测试通过")
  print_color(1, "出错了！")
}
```

### `format(template, value, ...)`

返回把每个 `{}` 依次替换成下一个参数后的文本。`{:.N}` 把数字格式化为 `N` 位小数。
没有对应参数的 `{}` 变成空；多余的参数会被忽略。只支持 `{}` 和 `{:.N}`
（不支持宽度、`{0}`、`{name}`，也不能转义花括号）。

```ling
令 start = 执 {
  印(格式("{} + {} = {}", 2, 3, 2 + 3))
  印(格式("圆周率约为 {:.3}", 圆周率()))
  印(格式("{:.1}%", 45.678))
  印(格式("{} 和 {}", "只有一个"))
}
```
```output
2 + 3 = 5
圆周率约为 3.142
45.7%
只有一个 和 
```

`format::join(list)` 把每一项按文本拼接，中间不加分隔符。如果要在各项之间插入内容，
请用 `list_join`（见[文本与列表](text-lists.md)）。

## 结果

### `ok(value)` 与 `bad(reason)`

Ling 没有异常。可能失败的函数返回 `ok(value)` 或 `bad(reason)`，调用者用 `match` 拆开。
它们打印为 `Ok(...)` 和 `Err(...)`；`err` 是 `bad` 的英文别名。
完整说明见[错误与结果](../language/errors.md)。

```ling
函 一半(n) {
  若 n % 2 == 0 { 好(n / 2) } 否则 { 坏("奇数") }
}
令 start = 执 {
  印(一半(10))
  印(一半(7))
  印(配 一半(7) { 好(v) => v, 坏(e) => "失败：" + e })
}
```
```output
Ok(5)
Err(奇数)
失败：奇数
```

### `try(function, arg, ...)`

用其余参数调用 `function`。成功时返回 `ok(result)`，调用中发生运行时错误时返回 `bad(message)`。

> **仅限解释器。** 默认后端会把作为参数传入的函数和闭包变成 `()`，于是 `try` 返回
> `Err(try: first argument must be a function)`。使用 `try` 的程序请用 `ling run --interp` 运行。
> 没有参数的闭包写作 `| | expr`，中间有一个空格。

```ling-module
函 安全读取(路径) { 尝试(| | read_file(路径)) }
```

## 数学

### 取整

`floor` 向下取整，`ceil` 向上取整，`round` 四舍五入（恰好一半时远离零），`trunc` 去掉小数部分，
`fract` 只保留小数部分。`int` 是 `trunc` 的英文别名：它不会把文本转换成数字（那要用 `to_number`）。

```ling
令 start = 执 {
  印(向下取整(2.7), " ", 向下取整(0 - 2.1))
  印(向上取整(2.1), " ", 向上取整(0 - 2.9))
  印(四舍五入(2.5), " ", 四舍五入(2.4), " ", 四舍五入(0 - 2.5))
  印(取整(2.9), " ", 取整(0 - 2.9), " ", int(7.99))
  印(小数部分(2.25))
}
```
```output
2 -3
3 -2
3 2 -3
2 -2 7
0.25
```

### `min`、`max`、`clamp`、`sign`、`abs`

`min` 和 `max` 只接受两个数；对列表请用 `list_min` 和 `list_max`。`clamp` 默认范围是 0..1，
如果 `low > high` 会自动交换上下界。`sign(0)` 是 `1`，不是 `0`。

```ling
令 start = 执 {
  印(最小(3, 1), " ", 最大(3, 1))
  印(截取(15, 0, 10), " ", 截取(0 - 3, 0, 10))
  印(符号(0 - 4), " ", 符号(0), " ", 绝对值(0 - 7))
}
```
```output
1 3
10 0
-1 1 7
```

### 幂、根与对数

负数的 `sqrt` 是 `NaN`。`log` 是**自然**对数（与 `ln` 相同）；以 10 为底请用 `log10`。

```ling
令 start = 执 {
  印(根(16), " ", 幂(2, 10), " ", 幂(9, 0.5))
  印(立方根(27), " ", 斜边(3, 4), " ", 指数(1))
  印(对数(指数(2)), " ", 对数(1), " ", 对数2(8), " ", 对数10(1000))
  印(根(0 - 1))
}
```
```output
4 1024 3
3 5 2.718281828459045
2 0 3 3
NaN
```

### 三角函数与常数

角度使用弧度。调用 `pi()` 和 `tau()` 时一定要带括号：在默认后端下，单独写 `pi` 得到的是 `()`。

```ling
令 start = 执 {
  印(正弦(圆周率() / 2), " ", 余弦(圆周率()))
  印(反正切2(1, 1) * 4)
  印(双周率())
}
```
```output
1 -1
3.141592653589793
6.283185307179586
```

### 插值与噪声

`lerp(a, b, t)` 不会限制 `t` 的范围。`smoothstep(low, high, x)` 在 `low` 以下返回 0，
在 `high` 以上返回 1，中间是一条平滑曲线。噪声函数是确定性的：相同参数总是得到相同的值，
很适合用来生成地形和纹理。

```ling
令 start = 执 {
  印(线性插值(0, 10, 0.25), " ", 平滑步进(0, 1, 0.5), " ", 平滑步进(0, 1, 2))
  印(柏林噪声2D(1.5, 2.5, 0) == 柏林噪声2D(1.5, 2.5, 0))
  印(分形噪声(0.3, 0.7, 4, 1) >= 0)
}
```
```output
2.5 0.5 1
true
true
```

### `rand()`

返回 0 到 1（不含 1）之间的伪随机数。没有种子，也没有整数版本，需要自己缩放和取整。
它不适合安全用途：需要不可预测的值时请用 `random_hex`（见[文件、时间与系统](files.md)）。

```ling
令 start = 执 {
  令 骰子 = 向下取整(随机() * 6) + 1
  印(骰子 >= 1 && 骰子 <= 6)
}
```
```output
true
```

## 逻辑与比较

逻辑与比较是运算符，而不是内置函数：`==`、`!=`、`<`、`<=`、`>`、`>=`、`&&`、`||` 和 `!`。
数字、文本和布尔值按值比较。有两个陷阱：列表用 `==` 比较永远不相等（请逐项比较），
用 `<` 给文本排序也不可靠。

```ling
令 start = 执 {
  印(1 < 2 && !(3 == 4))
  印("甲" == "甲", " ", 2 != 3)
  印([1, 2] == [1, 2])
}
```
```output
true
true true
false
```

## 暂停

### `sleep(ms)`

让程序暂停指定的毫秒数（`sleep_ms` 是英文别名）。要测量时间，请看[文件、时间与系统](files.md)中的 `time_now`。

```ling
令 start = 执 {
  睡眠(50)
  印("完成")
}
```
```output
完成
```
