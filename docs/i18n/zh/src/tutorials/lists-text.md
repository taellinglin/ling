# 列表与文本

到目前为止，每个名字只保存一个值。在这一课里，你会把许多值一起放进一个**列表**，用循环逐个
走过它们，还会把文本拆开再拼回去。最后你会完成一个小小的词语计数器。

## 创建列表

把列表写在方括号里，各项之间用逗号隔开：

```ling
令 始 = 执 {
  令 水果 = ["苹果", "香蕉", "樱桃"]
  打印(水果)
  打印(长度(水果))
  打印(取元素(水果, 0))
  打印(水果[2])
}
```
```output
[苹果, 香蕉, 樱桃]
3
苹果
樱桃
```

- 打印列表时，会在方括号里显示它的各项。
- `长度(水果)` 是项的个数。
- `取元素(水果, 0)` 读取位置 0 上的项。`水果[2]` 是 `取元素(水果, 2)` 的简写。

**位置从 0 开始。** 第一项在位置 0，三项中的最后一项在位置 2。可以把位置理解为"前面要跳过几项"。
位置要保持在 0 到 `长度(xs) - 1` 之间：如果请求一个不存在的位置，默认引擎会给出一个空值，
解释器则会报错。

## 修改列表：一定要重新绑定

`列表添加`（`list_push`）在末尾加一项，`list_set` 替换某个位置上的项。两者都会给你一个**新**列表。
要保留它，就再绑定一次名字：

```ling
令 始 = 执 {
  令 水果 = ["苹果", "香蕉", "樱桃"]
  令 水果 = 列表添加(水果, "枣")
  打印(水果)
  令 水果 = list_set(水果, 1, "蓝莓")
  打印(水果)
  打印("现在有 ", 长度(水果), " 种水果")
}
```
```output
[苹果, 香蕉, 樱桃, 枣]
[苹果, 蓝莓, 樱桃, 枣]
现在有 4 种水果
```

一定要写 `令 水果 = 列表添加(水果, "枣")`，千万不要单独写 `列表添加(水果, "枣")`。这和你在
[值与绑定](values.md)里学到的重新绑定习惯是一样的。

## 在循环中构建列表

先用 `新建列表()` 得到一个空列表，再往里添加项。记住[判断与循环](control-flow.md)里的作用域规则：
`历` 循环体无法留下结果，所以要用 `循` 构建列表：

```ling
令 始 = 执 {
  令 平方数 = 新建列表()
  令 i = 1
  循 i < 8 {
    令 平方数 = 列表添加(平方数, i * i)
    令 i = i + 1
  }
  打印(平方数)
}
```
```output
[1, 4, 9, 16, 25, 36, 49]
```

## 遍历列表

如果只是**读取**列表，用 `历` 就可以。如果还需要累积结果，就用带位置的 `循`：

```ling
令 始 = 执 {
  令 成绩 = [72, 95, 88, 61, 79]
  历 s 于 成绩 {
    打印("成绩：", s)
  }
  令 总分 = 0
  令 最高 = 成绩[0]
  令 i = 0
  循 i < 长度(成绩) {
    令 s = 成绩[i]
    令 总分 = 总分 + s
    若 s > 最高 {
      令 最高 = s
    }
    令 i = i + 1
  }
  打印("总分：", 总分)
  打印("平均：", 总分 / 长度(成绩))
  打印("最高：", 最高)
  打印("list_max 的结果：", list_max(成绩, 0))
}
```
```output
成绩：72
成绩：95
成绩：88
成绩：61
成绩：79
总分：395
平均：79
最高：95
list_max 的结果：95
```

`最高` 一开始是第一项，之后每遇到更大的项就换成它。内置函数 `list_max` 和 `list_min` 做的是同样的事，
它们的第二个参数是列表为空时的答案。

## 文本工具

Ling 有一组处理文本的内置函数：

```ling
令 始 = 执 {
  令 s = "  你好，Ling 世界  "
  打印(长度(s))
  令 s = trim(s)
  打印("[" + s + "]")
  打印(str_upper(s))
  打印(str_lower(s))
  打印(substr(s, 0, 2))
  打印(str_find(s, "Ling"))
  打印(str_find(s, "Python"))
  打印(str_replace(s, "世界", "朋友"))
  打印(starts_with(s, "你好"))
  打印(str_repeat("哈", 3))
}
```
```output
14
[你好，Ling 世界]
你好，LING 世界
你好，ling 世界
你好
3
-1
你好，Ling 朋友
true
哈哈哈
```

| 内置函数 | 用途 |
|---|---|
| `长度(s)` | 字符个数 |
| `trim(s)` | 去掉两端的空格 |
| `str_upper(s)`、`str_lower(s)` | 改变大小写 |
| `substr(s, 起点, 个数)` | 从位置 `起点`（从 0 算起）开始取 `个数` 个字符 |
| `str_find(s, 片段)` | 第一次出现的位置；找不到时为 `-1` |
| `str_replace(s, 旧, 新)` | 把所有的 `旧` 换成 `新` |
| `starts_with(s, 片段)`、`ends_with(s, 片段)` | `真` 或 `假` |
| `str_repeat(s, n)` | 把文本重复 `n` 次 |

和列表的内置函数一样，这些函数从不修改原来的文本。它们返回新的文本，所以要绑定结果：`令 s = trim(s)`。

## 拆分与连接

`split` 在分隔符出现的地方把文本切成一个列表。`list_join` 把列表重新粘成一段文本（`join` 是同一个
内置函数）：

```ling
令 始 = 执 {
  令 一行 = "红,绿,蓝"
  令 各部分 = split(一行, ",")
  打印(各部分)
  打印(长度(各部分))
  打印(list_join(各部分, " | "))
  令 数字 = split("3 8 15", " ")
  打印(to_number(数字[1]) + 1)
}
```
```output
[红, 绿, 蓝]
3
红 | 绿 | 蓝
9
```

`split` 得到的各部分都是文本。要先用 `to_number` 转换，才能拿它们做算术。

## 逐个字符处理

`substr(s, i, 1)` 取出位置 `i` 上的单个字符。下面用它把文本倒过来：

```ling
函 倒序(s) {
  令 结果 = ""
  令 i = 长度(s) - 1
  循 i >= 0 {
    令 结果 = 结果 + substr(s, i, 1)
    令 i = i - 1
  }
  归 结果
}

令 始 = 执 {
  打印(倒序("你好世界"))
  打印(倒序("上海自来水来自海上") == "上海自来水来自海上")
}
```
```output
界世好你
true
```

## 词语计数器

Ling 还没有字典类型，所以我们并排放两个列表：`词语` 保存每个不同的词，`次数` 保存它出现了几次。
一个辅助函数负责找出某个词的位置：

```ling
函 位置(各项, 目标) {
  令 i = 0
  循 i < 长度(各项) {
    若 各项[i] == 目标 {
      归 i
    }
    令 i = i + 1
  }
  归 -1
}

令 始 = 执 {
  令 全部 = split("猫、狗、鸟、猫、狗、猫、鱼", "、")
  令 词语 = 新建列表()
  令 次数 = 新建列表()
  令 i = 0
  循 i < 长度(全部) {
    令 词 = 全部[i]
    令 p = 位置(词语, 词)
    若 p == -1 {
      令 词语 = 列表添加(词语, 词)
      令 次数 = 列表添加(次数, 1)
    } 否则 {
      令 次数 = list_set(次数, p, 次数[p] + 1)
    }
    令 i = i + 1
  }
  令 k = 0
  循 k < 长度(词语) {
    打印(词语[k], "：", 次数[k])
    令 k = k + 1
  }
}
```
```output
猫：3
狗：2
鸟：1
鱼：1
```

> **注意：** `==` 可以比较数字、文本和布尔值。用 `==` 比较两个列表总是得到 `假`，即使它们的项完全
> 相同。要逐项比较。

## 动手试试

1. 建一个有五个数字的列表，用 `循` 循环打印它们的总和。
2. 用逗号拆分 `"3,8,15,4"`，用 `to_number` 转换每一部分，打印最大的数。
3. 写一个 `数元音(s)`，统计英文字母 a、e、i、o、u 出现的次数。（提示：先把文本变成小写，再用
   `str_find("aeiou", 字符) != -1` 检查每个字符。）
4. 用 `str_replace` 去掉文本里的空格和逗号，写一个回文检测，并用 `"上海，自来水来自海上"` 试一试。
5. 扩展词语计数器，让它同时打印出现次数最多的词。
