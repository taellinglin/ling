# 函数

函数就是一份有名字的食谱：步骤写一次，想用多少次就用多少次。你已经用过 `打印`、`四舍五入` 和
`str` 这样的内置函数了。在这一课里，你会用 `函`（`fn`）写自己的函数，给它们参数，用 `归`
（`return`）把答案交回来，还会让函数调用它自己。

## 定义和调用函数

```ling
函 问候(名字) {
  打印("你好，" + 名字 + "！")
}

令 始 = 执 {
  问候("小明")
  问候("小红")
  问候("小美")
}
```
```output
你好，小明！
你好，小红！
你好，小美！
```

- `函` 表示"我要定义一个函数"。
- `问候` 是函数的名字。
- 括号里的 `名字` 是**参数**：每次调用函数时都会被填上的空白。
- 大括号里是**函数体**，也就是函数要执行的步骤。

定义函数并不会运行它。只有当你**调用**函数时，函数体才会运行，比如 `问候("小明")`。括号里的值
叫做**实参**，在这次调用中它就成了 `名字` 的值。

函数写在文件的顶层，放在 `令 始` 的外面。真正做事的指令写在 `始` 里面。

## 用 `归` 交回答案

很多时候，你希望函数算出点什么，再把答案交回来。这就是 `归` 的作用。函数可以有多个参数，用逗号隔开：

```ling
函 平方(n) {
  归 n * n
}

函 平均(a, b) {
  归 (a + b) / 2
}

令 始 = 执 {
  打印(平方(7))
  打印(平均(10, 25))
  打印(平方(平均(2, 4)))
}
```
```output
49
17.5
9
```

因为 `平方(7)` 有一个值，所以凡是能放值的地方都能用它：放在 `打印` 里，放在更大的表达式里，或者
作为另一个调用的实参。`平方(平均(2, 4))` 从里往外算：`平均(2, 4)` 是 3，`平方(3)` 是 9。

### 提前返回

第一个执行到的 `归` 会结束函数。可以利用这一点先处理特殊情况：

```ling
函 描述(n) {
  若 n < 0 {
    归 "负数"
  }
  若 n == 0 {
    归 "零"
  }
  归 "正数"
}

函 立方(n) { n * n * n }

令 始 = 执 {
  打印(描述(-5))
  打印(描述(0))
  打印(描述(12))
  打印(立方(3))
}
```
```output
负数
零
正数
27
```

`描述` 里不需要 `否则`，因为 `归` 已经离开了函数。`立方` 展示了一种简写：没有 `归` 时，函数会交回
最后一个表达式的值。像 `问候` 这样什么都不计算的函数，交回的是 `()`，也就是"空"值。

## 函数能看到什么

每次调用都有自己私有的名字：它的参数，以及它自己绑定的东西。这些名字不会和调用它的代码里的名字冲突：

```ling
令 税率 = 0.2

函 含税(价格) {
  令 总价 = 价格 + 价格 * 税率
  归 总价
}

令 始 = 执 {
  令 总价 = 99
  打印(含税(50))
  打印("我的总价还是 ", 总价)
}
```
```output
60
我的总价还是 99
```

函数能看到文件顶层的绑定，比如 `税率`。那里适合放常量。但它**看不到**调用者的局部名字，所以要把
它需要的东西作为实参传进去。

## 调用自己的函数

函数可以调用它自己，这叫做**递归**。递归需要两个部分：

1. **基本情况**：简单到可以直接知道答案。
2. **递归情况**：通过调用自己来解决一个更小的问题。

5 的阶乘是 `5 * 4 * 3 * 2 * 1`，也就是 `5 * 阶乘(4)`：

```ling
函 阶乘(n) {
  若 n <= 1 {
    归 1
  }
  归 n * 阶乘(n - 1)
}

函 斐波那契(n) {
  若 n < 2 {
    归 n
  }
  归 斐波那契(n - 1) + 斐波那契(n - 2)
}

令 始 = 执 {
  打印("5! = ", 阶乘(5))
  打印("10! = ", 阶乘(10))
  历 i 于 0..10 {
    打印("斐波那契(", i, ") = ", 斐波那契(i))
  }
}
```
```output
5! = 120
10! = 3628800
斐波那契(0) = 0
斐波那契(1) = 1
斐波那契(2) = 1
斐波那契(3) = 2
斐波那契(4) = 3
斐波那契(5) = 5
斐波那契(6) = 8
斐波那契(7) = 13
斐波那契(8) = 21
斐波那契(9) = 34
```

手动跟踪一下 `阶乘(3)`：它返回 `3 * 阶乘(2)`，这需要 `2 * 阶乘(1)`，而 `阶乘(1)` 是基本情况，等于 1。
然后答案一层层往回算：`2 * 1 = 2`，再 `3 * 2 = 6`。如果没有基本情况，函数会一直调用自己，直到耗尽空间。

## 综合练习：FizzBuzz

从 1 数到 15。是 3 的倍数就打印 `Fizz`，是 5 的倍数就打印 `Buzz`，同时是两者的倍数就打印
`FizzBuzz`，其他情况打印数字本身：

```ling
函 fizzbuzz(n) {
  若 n % 15 == 0 {
    归 "FizzBuzz"
  }
  若 n % 3 == 0 {
    归 "Fizz"
  }
  若 n % 5 == 0 {
    归 "Buzz"
  }
  归 str(n)
}

令 始 = 执 {
  历 n 于 1..16 {
    打印(fizzbuzz(n))
  }
}
```
```output
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

15 的判断要放在最前面，否则 15 会停在 3 的判断上，只打印 `Fizz`。函数负责把数字变成词，`始` 只负责
循环和打印。好的函数只做一件事，把需要的东西作为参数接收，并且有一个能说明它做什么的名字。

## 把函数当作值

在有些语言里，你可以把函数存进一个绑定，或者把它传给另一个函数。Ling 为此提供了简短的闭包写法
`|x| x * 2`，但在当前版本中，函数值是语言里最不可靠的部分：存在绑定里的闭包，或者作为实参传递的函数，
可能会得到 `()`，也可能报告 `unknown function`。唯一总能正常工作的形式，是在写闭包的地方立即调用它：

```ling
令 始 = 执 {
  打印((|x| x + 1)(5))
}
```
```output
6
```

目前请写一个有名字的 `函`，并按名字调用它。详情请参阅[已知限制](../language/limits.md)。

> **提示：** 如果把函数名拼错了，默认引擎会打印 `()` 而不是报错。当一个函数好像"什么都没做"时，
> 用 `ling run --interp yourfile.ling` 运行程序，它会报告 `unknown function`。

2. 写一个 `三者最大(a, b, c)`，返回三个数中最大的一个。（内置函数 `最大` 接受两个参数，可以嵌套使用。）
