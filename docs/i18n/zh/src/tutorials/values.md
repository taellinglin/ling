# 值与绑定

每个程序都在处理信息：一个分数、一个名字、一个"是"或"否"的回答。在这一课里，你会认识
Ling 中最基本的几种值，用 `令`（`bind`）给它们起名字，通过重新绑定来"修改"它们，并把它们
打印出来。每一步都有一个小程序，你可以复制到文件里，用 `ling run` 运行。

## 值

一条信息叫做一个**值**。下面是最常用的几种：

| 种类 | 存放什么 | 例子 |
|---|---|---|
| 数字 | 任何数，整数或小数 | `42`、`3.14`、`-7` |
| 文本 | 字母、词语、句子（也叫*字符串*） | `"你好"`、`"101 房间"` |
| 布尔值 | 两个答案之一：是或否 | `真`、`假` |
| 列表 | 排成一行的多个值 | `[1, 2, 3]`、`["红", "蓝"]` |

每种打印一个看看：

```ling
令 始 = 执 {
  打印(42)
  打印(3.14)
  打印("一段文本")
  打印(真)
  打印([1, 2, 3])
}
```
```output
42
3.14
一段文本
true
[1, 2, 3]
```

数字直接写。文本写在双引号之间。`真` 和 `假` 不加引号，因为它们不是文本；打印时显示为
`true` 和 `false`。列表写在方括号里，各项之间用逗号隔开。

写值的几条规则：

- 数字用普通的数字书写，最多一个小数点。要写 `0.5`，不能写 `.5`。没有 `1e3` 或 `0xff` 这种写法。
- 文本只能用双引号。在文本里，`\n` 表示换行，`\"` 表示一个引号。

## 绑定：给值起名字

用 `令` 给一个值起名字。之后，这个名字就代表那个值：

```ling
令 始 = 执 {
  令 名字 = "小美"
  令 年龄 = 12
  打印("你好，" + 名字)
  打印(名字, "今年", 年龄, "岁")
  打印("明年：", 年龄 + 1)
}
```
```output
你好，小美
小美今年12岁
明年：13
```

`令 年龄 = 12` 可以读作"把名字 `年龄` 绑定到值 12"。名字可以包含文字、数字和下划线，但不能以
数字开头。名字要能说明值的含义：`年龄` 比 `a` 好。

你写的每个程序都以同样的方式开始：`令 始 = 执 { ... }`。大括号里的指令从上到下依次执行。

## 重新绑定：Ling 怎样"修改"东西

Ling **没有赋值语句**。你不能写 `分数 = 分数 + 5`，那是语法错误。要给名字一个新值，就再绑定一次：

```ling
令 始 = 执 {
  令 分数 = 10
  打印("分数是 ", 分数)
  令 分数 = 分数 + 5
  打印("分数是 ", 分数)
  令 分数 = 分数 * 2
  打印("分数是 ", 分数)
}
```
```output
分数是 10
分数是 15
分数是 30
```

`令 分数 = 分数 + 5` 先用 `分数` 当前的值算出右边的结果，再把 `分数` 这个标签贴到结果上。
养成一个习惯：每当你想改变什么，就写 `令`。

## 打印

`打印` 会打印它的参数，然后换行。英文的 `println` 作用完全一样：在 Ling 里两者都以换行结尾。
传入多个参数时，它们会一个接一个地打印出来，**中间什么都不加**，连空格也没有：

```ling
令 始 = 执 {
  打印("和", 1 + 2)
  打印("和：", 1 + 2)
  打印("甲", "乙", "丙")
  打印("第一行\n第二行")
  打印("她说：\"你好\"")
}
```
```output
和3
和：3
甲乙丙
第一行
第二行
她说："你好"
```

如果需要空格或标点，就把它写进文本里，比如 `"和："`。

## 算术

Ling 使用常见的符号：`+`、`-`、`*`、`/`，以及求余数的 `%`。

```ling
令 始 = 执 {
  打印(7 + 3)
  打印(7 / 2)
  打印(7 % 2)
  打印(2 + 3 * 4)
  打印((2 + 3) * 4)
  打印(四舍五入(3.7))
  打印(平方根(81))
}
```
```output
10
3.5
1
14
20
4
9
```

除法给出精确结果（`3.5`），不会取整。乘法先于加法，所以 `2 + 3 * 4` 是 `14`。想表达别的顺序时
就加括号。`四舍五入` 和 `平方根` 是**内置函数**：Ling 自带的函数。

## 文本和数字之间的转换

用 `+` 可以把两段文本连起来。要把数字接到文本上，先用 `str` 把它变成文本（`to_str` 是同一个
函数）。反过来，`to_number` 把文本变成数字：

```ling
令 始 = 执 {
  令 苹果 = 3
  打印("我有 " + str(苹果) + " 个苹果")
  令 输入 = "12"
  打印(to_number(输入) + 1)
  打印(格式("{} + {} = {}", 2, 3, 2 + 3))
  打印(格式("大约 {:.2}", 3.14159))
}
```
```output
我有 3 个苹果
13
2 + 3 = 5
大约 3.14
```

`格式`（`format`）把模板里的每个 `{}` 依次换成后面的参数。`{:.2}` 让数字显示两位小数。

## 比较和布尔值

比较就是提一个"是或否"的问题，得到 `真` 或 `假`：

```ling
令 始 = 执 {
  打印(5 > 3)
  打印(5 == 5)
  打印(5 != 5)
  打印("猫" == "猫")
  令 很大 = 100 > 50
  打印("很大：", 很大)
  打印(真 && 假)
  打印(真 || 假)
  打印(!真)
}
```
```output
true
true
false
true
很大：true
false
true
false
```

比较运算符有 `==`、`!=`、`<`、`>`、`<=` 和 `>=`。单个 `=` 从来不是比较，它只出现在 `令` 里。
用 `&&`（并且：两个都要为真）、`||`（或者：至少一个为真）和 `!`（取反）组合答案。不要像数学里
那样连写比较：要写 `x > 1 && x < 10`，而不是 `1 < x < 10`。

## 注释

一行中 `#` 或 `//` 之后的内容都是注释。Ling 会忽略它，它是写给人看的说明。

```ling
# 一个简单的分账程序
令 始 = 执 {
  令 账单 = 84.50
  令 人数 = 4      // 一桌的朋友
  令 每人 = 账单 / 人数
  打印("每人付 ", 四舍五入(每人 * 100) / 100)
}
```
```output
每人付 21.13
```

`四舍五入(x * 100) / 100` 可以把数字保留两位小数，方便显示。

## 动手试试

1. 绑定你的年龄，打印"10 年后我 ... 岁"，填上正确的数字。
2. 一个长方形宽 12.5、高 8。打印它的面积和周长，各带一个标签。
3. 把 `n` 绑定为 10。只用 `令`，让它依次变成 11、22、4。每一步后都打印 `n`。
4. 用 `(f - 32) * 5 / 9` 把华氏 98.6 度换算成摄氏度，打印保留一位小数的结果。
5. 打印 `"7" + "3"`，再打印 `to_number("7") + to_number("3")`。为什么结果不同？
