# 判断与循环

程序能在不同的动作之间做选择、能重复做事，才变得有意思。在这一课里，你会用 `若` 和 `否则`
做判断，用 `循` 和 `历` 重复工作，用 `配` 在多种情况之间挑选。你还会学到一条几乎让每个
Ling 新手都吃过惊的作用域规则。

## 用 `若` 做判断

```ling
令 始 = 执 {
  令 气温 = 31
  若 气温 > 30 {
    打印("天很热，多喝水。")
  }
  打印("检查完毕。")
}
```
```output
天很热，多喝水。
检查完毕。
```

格式是 `若 条件 { ... }`。条件可以是任何能得出 `真` 或 `假` 的东西，通常是一个比较。条件为真时，
代码块就会执行；否则 Ling 会跳过它。条件两边不需要括号，但大括号必须写。

把 `气温` 改成 `20` 再运行一次：只会打印 `检查完毕。`。

## `否则` 和 `否则 若`

`否则` 给出另一条路。用 `否则 若` 可以串起更多判断。Ling 从上到下逐个检查，执行第一个条件为真的代码块：

```ling
令 始 = 执 {
  令 分数 = 83
  若 分数 >= 90 {
    打印("等级 A")
  } 否则 若 分数 >= 80 {
    打印("等级 B")
  } 否则 若 分数 >= 70 {
    打印("等级 C")
  } 否则 {
    打印("继续努力")
  }
}
```
```output
等级 B
```

83 也大于等于 70，但 `分数 >= 80` 这个分支在前面，所以它胜出。要把最大的门槛放在最前面。

用 `&&`（并且）、`||`（或者）和 `!`（取反）组合条件：

```ling
令 始 = 执 {
  令 小时 = 14
  令 下雨 = 真
  令 带伞 = 假
  若 小时 >= 9 && 小时 < 17 {
    打印("商店营业中")
  }
  若 下雨 && !带伞 {
    打印("你会被淋湿")
  }
  若 小时 < 6 || 小时 > 22 {
    打印("该睡觉了")
  } 否则 {
    打印("还可以醒着")
  }
}
```
```output
商店营业中
你会被淋湿
还可以醒着
```

## 用 `循` 重复

`循`（`while`）循环会在条件保持为真时一直重复它的代码块：

```ling
令 始 = 执 {
  令 i = 1
  循 i <= 5 {
    打印("计数：", i)
    令 i = i + 1
  }
  打印("发射！")
}
```
```output
计数：1
计数：2
计数：3
计数：4
计数：5
发射！
```

每个 `循` 循环都有三个部分：

1. 在循环前设置计数器（`令 i = 1`）。
2. 让循环继续的条件（`i <= 5`）。
3. 在循环里做事，**并推进计数器**（`令 i = i + 1`）。

如果忘了第 3 步，条件就永远为真。程序停不下来时，按 **Ctrl+C** 终止它。

### 累积结果

在 `循`（或 `若`）代码块里的 `令` 会改变块外的名字。所以 `循` 很适合计算累计总数：

```ling
令 始 = 执 {
  令 总和 = 0
  令 n = 1
  循 n <= 100 {
    令 总和 = 总和 + n
    令 n = n + 1
  }
  打印("1 + 2 + ... + 100 = ", 总和)
}
```
```output
1 + 2 + ... + 100 = 5050
```

## 用 `历` 计数

当你知道要重复多少次时，`历`（`for`）更简短。它会逐个走过一个**范围**里的数字，或者一个列表里的各项：

```ling
令 始 = 执 {
  历 i 于 0..4 {
    打印("i 是 ", i)
  }
  历 k 于 1..4 {
    打印(k, " x 7 = ", k * 7)
  }
  历 颜色 于 ["红色", "绿色", "蓝色"] {
    打印("我喜欢", 颜色)
  }
}
```
```output
i 是 0
i 是 1
i 是 2
i 是 3
1 x 7 = 7
2 x 7 = 14
3 x 7 = 21
我喜欢红色
我喜欢绿色
我喜欢蓝色
```

`0..4` 表示 0、1、2 和 3：范围在第二个数**之前**停下。所以 `历 i 于 0..4` 正好运行四次。

范围的终点必须是一个数字、一个名字，或者括号里的内容。要写 `0..(n + 1)` 和 `0..(长度(xs))`，
千万不要写 `0..长度(xs)`：那样写会悄无声息地一次也不运行。

### `历` 的作用域规则

这条规则让每个人都吃惊。`历` 循环的每一轮都会得到周围名字的一份全新副本。`历` 循环体里的 `令`
**不会改变**外面的名字：

```ling
令 始 = 执 {
  令 总和 = 0
  历 i 于 1..5 {
    令 总和 = 总和 + i
  }
  打印("历 之后：", 总和)

  令 总和 = 0
  令 i = 1
  循 i < 5 {
    令 总和 = 总和 + i
    令 i = i + 1
  }
  打印("循 之后：", 总和)
}
```
```output
历 之后：0
循 之后：10
```

经验法则：只**做**事情的循环（打印、绘图、播放音符）用 `历`。需要**留下结果**的循环
（总和、计数、不断增长的列表）用 `循`。

Ling 没有能用的 `break` 或 `continue`。想提前离开 `循` 循环，就让它的条件变为假，例如用一个
标志 `令 查找中 = 假`。

### 循环里的循环

一个循环可以放在另一个循环里。这里外层的 `历` 只负责打印，内层的 `循` 拼出每一行的文本：

```ling
令 始 = 执 {
  历 行 于 1..5 {
    令 文本 = ""
    令 列 = 0
    循 列 < 行 {
      令 文本 = 文本 + "*"
      令 列 = 列 + 1
    }
    打印(文本)
  }
}
```
```output
*
**
***
****
```

## 用 `配` 做选择

当你要把一个值和许多可能性比较时，`配`（`match`）比一长串 `否则 若` 更整洁。每个**分支**写成
`模式 => 动作`。Ling 执行第一个匹配的分支，而 `_` 能匹配任何东西：

```ling
令 始 = 执 {
  令 星期 = 3
  配 星期 {
    1 => 打印("星期一")
    2 => 打印("星期二")
    3 => 打印("星期三")
    _ => 打印("别的日子")
  }
  令 指示 = 配 "绿灯" {
    "红灯" => "停"
    "绿灯" => "行"
    _ => "等"
  }
  打印(指示)
}
```
```output
星期三
行
```

`配` 可以匹配数字和文本，还能产生一个值让你绑定。最后总要加一个 `_` 分支：如果什么都没匹配上，
`配` 会悄悄地给出 `()`，也就是"空"值。

## 动手试试

1. 绑定一个数字 `n`，打印 `正数`、`负数` 或 `零`。
2. 用 `历` 循环打印 6 的乘法表，从 `6 x 1` 到 `6 x 10`。
3. 用 `循` 循环把 2 到 50 的偶数加起来。（答案是 650。）
4. 从 1 开始不断翻倍，直到大于 1000。打印一共翻了几次。
5. 把等级的例子改成相反的顺序（先判断 `分数 >= 70`）。会出什么问题？
