# 绘图与游戏

在这一页里，你会用圆、三角形、线条和渐变绘制平面 2D 图画，让它们响应键盘和鼠标，
最后把这些组合成一个可以玩、也可以修改的小游戏。这里用到的都是 Ling 自带的内置函数，
不需要任何图片文件或游戏引擎。

这些程序会打开窗口，所以代码块下面没有输出。按 **Escape** 或关闭窗口即可停止。

## 打开窗口，运行帧循环

每个图形程序的结构都一样：先打开一次窗口，然后不断重复 **清屏、绘制、呈现**，直到窗口关闭。

```ling-gui
令 始 = 执 {
    开窗(640, 400, "帧循环")
    令 t = 0
    循 窗开() {
        填(10, 12, 30)                           # 1. 清屏
        设色(255, 200, 80)                       # 2. 绘制
        画实心圆(320 + 200 * 正弦(t * 0.05), 200, 30)
        显()                                     # 3. 显示这一帧
        令 t = t + 1
    }
}
```

- `开窗(宽, 高, 标题)`（`open_window`）打开窗口。尺寸在前，标题在后。
- 窗口关闭或按下 Escape 时，`窗开()`（`window_is_open`）变为假。
- `填(r, g, b)`（`fill`）把整个窗口涂成一种颜色。颜色是 0 到 255 的红、绿、蓝。
- `显()`（`present`）把画好的一帧放到屏幕上。没有 `显()` 的帧是看不见的。
- `t` 用来数帧。`正弦(t * 0.05)` 在 -1 和 1 之间平滑摆动，让圆来回移动。

Ling 没有计算帧间隔的内置函数。如果需要真实的秒数，请用 `当前时间()`（`time_now`，
程序启动后经过的秒数）或 `帧数()`（`frame_count`）。

## 2D 画布

窗口是一张像素网格。它和数学课上有两点不同：

- 原点 `(0, 0)` 在**左上角**。
- **y 向下增长。** `y = 300` 在屏幕上比 `y = 100` 更靠下。

你用一支**画笔**作画。`设色(r, g, b)`（`set_color`）选择画笔颜色，之后的每个图形都使用
这个颜色，直到你再次更改。

| 内置函数 | 绘制 |
|---|---|
| `fill(r, g, b)` / `填` | 用一种颜色填满整个窗口 |
| `draw_disc(cx, cy, r)` / `画实心圆` | 实心圆 |
| `draw_circle(cx, cy, r)` | 圆的轮廓 |
| `triangle(x0, y0, x1, y1, x2, y2)` / `画三角` | 实心三角形 |
| `draw_line(x0, y0, x1, y1)` / `画线` | 细线 |
| `draw_arc(cx, cy, r, a0, a1, segments)` | 一段圆弧轮廓；角度用弧度，顺时针 |
| `draw_poly([x0, y0, x1, y1, ...])` / `填充多边形` | 由扁平点列表构成的实心多边形 |
| `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` / `渐变矩形` | 两种颜色渐变的矩形；`dir` 为 1 表示从上到下，0 表示从左到右 |
| `set_color_hsl(h, s, l)` / `色相` | 用色相 0-360、饱和度 0-100、亮度 0-100 设置画笔颜色 |

没有画纯色矩形的内置函数。从一种颜色渐变到同一种颜色就是纯色矩形，所以可以自己写一个辅助函数：

```ling-module
函 矩形(x, y, 宽, 高, r, g, b) {
    渐变矩形(x, y, 宽, 高, r, g, b, r, g, b, 1)
}
```

> **提示：** 如果某个绘图调用好像什么都没做，请检查拼写。像 `draw_rect` 这样的未知名称会被
> 悄悄忽略。

### 风景画

从后往前分层绘制。后画的图形会覆盖先画的。

```ling-gui
函 矩形(x, y, 宽, 高, r, g, b) {
    渐变矩形(x, y, 宽, 高, r, g, b, r, g, b, 1)
}

函 树(x, 地面) {
    矩形(x - 6, 地面 - 50, 12, 50, 110, 70, 40)
    设色(40, 150, 70)
    画实心圆(x, 地面 - 70, 32)
    画实心圆(x - 20, 地面 - 50, 24)
    画实心圆(x + 20, 地面 - 50, 24)
}

令 始 = 执 {
    开窗(800, 500, "风景")
    令 t = 0
    循 窗开() {
        渐变矩形(0, 0, 800, 380, 30, 40, 110, 250, 150, 140, 1)     # 天空
        设色(255, 220, 120)
        画实心圆(600, 300, 60)                                       # 太阳
        设色(70, 60, 110)
        画三角(0, 380, 150, 190, 300, 380)                           # 山
        画三角(200, 380, 380, 150, 560, 380)
        矩形(0, 380, 800, 120, 50, 110, 60)                          # 地面
        树(120, 440)
        树(330, 460)
        树(690, 450)
        设色(20, 20, 30)                                             # 一只鸟
        令 扇动 = 正弦(t * 0.15) * 6
        draw_arc(150, 120 - 扇动, 18, 3.4, 6.0, 16)
        draw_arc(186, 120 - 扇动, 18, 3.4, 6.0, 16)
        显()
        令 t = t + 1
    }
}
```

`树(x, 地面)` 根据参数放置树干和树叶，所以你想种多少棵树都可以。鸟的翅膀是两段圆弧。
因为 y 向下，角度按顺时针方向增长：`0` 指向右，`3.14` 指向左。

## 读取键盘

Ling 没有事件处理函数。你在每一帧里**询问**某个键是否按下：

- 只要按住，`按键("left")`（`key_down`）就为真。
- `键按("space")`（`key_pressed`）只在按下的那一帧为真。用它处理每按一次只发生一次的事，
  比如跳跃或重新开始。

键名是小写英文字符串：`"a"` 到 `"z"`、数字、`"left"`、`"right"`、`"up"`、`"down"`、
`"space"`、`"enter"`、`"escape"`、`"lshift"` 等。未知的键名只会返回假。

```ling-gui
令 始 = 执 {
    开窗(640, 400, "移动小球")
    令 x = 320
    令 y = 200
    循 窗开() {
        令 速度 = 3
        若 按键("lshift") {
            令 速度 = 8
        }
        若 按键("left") {
            令 x = x - 速度
        }
        若 按键("right") {
            令 x = x + 速度
        }
        若 按键("up") {
            令 y = y - 速度
        }
        若 按键("down") {
            令 y = y + 速度
        }
        令 x = 截取(x, 20, 620)
        令 y = 截取(y, 20, 380)

        填(10, 10, 30)
        设色(255, 180, 60)
        画实心圆(x, y, 20)
        显()
    }
}
```

几乎每个游戏都有这三部分：

1. **状态：** `x` 和 `y` 定义在循环外面，所以能从一帧保留到下一帧。
2. **输入与更新：** `按键` 检查改变状态，`截取`（`clamp`）让小球留在窗口内。
3. **绘制：** 根据状态画出画面。

每一帧都保持这个顺序：输入、更新、绘制。

## 读取鼠标

`mouse_x()` 和 `mouse_y()` 给出指针的像素位置。按住左键时 `mouse_down()` 为真，
按住右键时 `mouse_down_right()` 为真。这几个函数没有中文别名，所以保留英文名称。

```ling-gui
令 始 = 执 {
    开窗(640, 400, "鼠标画画")
    填(245, 240, 225)
    令 色调 = 0
    循 窗开() {
        若 mouse_down() {
            色相(色调, 80, 50)
            画实心圆(mouse_x(), mouse_y(), 10)
            令 色调 = (色调 + 3) % 360
        }
        若 mouse_down_right() {
            填(245, 240, 225)
        }
        显()
    }
}
```

这个程序不会每帧都调用 `填`，所以颜料会留在画布上。点击右键会调用一次 `填` 把它擦掉。

## 一个小游戏：接星星

星星从天上落下，你左右移动篮子去接。每接住一颗得一分，下一颗会落得更快。漏掉三颗游戏结束；
按空格键重新开始。

写游戏之前，先列出它的**状态**（篮子的 x、星星的位置、下落速度、得分、生命）、**规则**
（每一帧状态如何变化）和**画面**（状态如何画出来）。

```ling-gui
函 矩形(x, y, 宽, 高, r, g, b) {
    渐变矩形(x, y, 宽, 高, r, g, b, r, g, b, 1)
}

# 五角星：一个有十个角的多边形。
函 星星(cx, cy, 大小, 旋转) {
    令 点 = []
    令 i = 0
    循 i < 10 {
        令 角 = 旋转 + i * 0.6283185
        令 半径 = 大小
        若 i % 2 == 1 {
            令 半径 = 大小 * 0.45
        }
        令 点 = 列表添加(点, cx + 余弦(角) * 半径)
        令 点 = 列表添加(点, cy + 正弦(角) * 半径)
        令 i = i + 1
    }
    填充多边形(点)
}

令 始 = 执 {
    开窗(640, 480, "接星星")
    令 篮子x = 320
    令 星x = 100 + 随机() * 440
    令 星y = 0
    令 下落 = 3
    令 得分 = 0
    令 生命 = 3
    令 t = 0

    循 窗开() {
        若 生命 > 0 {
            # 输入
            若 按键("left") || 按键("a") {
                令 篮子x = 篮子x - 7
            }
            若 按键("right") || 按键("d") {
                令 篮子x = 篮子x + 7
            }
            令 篮子x = 截取(篮子x, 50, 590)
            # 更新
            令 星y = 星y + 下落
            若 星y > 440 {
                若 绝对值(星x - 篮子x) < 55 {
                    令 得分 = 得分 + 1
                    令 下落 = 下落 + 0.25
                } 否则 {
                    令 生命 = 生命 - 1
                }
                令 星x = 50 + 随机() * 540
                令 星y = 0
            }
        } 否则 {
            若 键按("space") {
                令 生命 = 3
                令 得分 = 0
                令 下落 = 3
                令 星y = 0
            }
        }

        # 绘制
        渐变矩形(0, 0, 640, 480, 15, 15, 50, 40, 25, 80, 1)
        设色(255, 220, 80)
        星星(星x, 星y, 24, t * 0.05)
        矩形(篮子x - 50, 445, 100, 14, 90, 190, 255)
        设色(255, 255, 255)
        界面文字(16, 14, 22, "SCORE " + to_str(得分))
        界面文字(500, 14, 22, "LIVES " + to_str(生命))
        若 生命 <= 0 {
            设色(255, 110, 110)
            界面文字(170, 200, 36, "GAME OVER")
        }
        显()
        令 t = t + 1
    }
    打印("最终得分：", 得分)
}
```

它是这样工作的：

- **星星。** `星星` 用 `余弦` 和 `正弦` 算出十个角的坐标，长短半径交替，组成一个扁平列表，
  再交给 `填充多边形`（`draw_poly`）。`旋转` 角度让星星一边下落一边转动。
- **游戏状态。** `若 生命 > 0 { ... } 否则 { ... }` 在“进行中”和“游戏结束”之间切换。
  游戏结束时只检查重新开始的按键。
- **接住。** 星星落到篮子的高度时，用 `绝对值(星x - 篮子x) < 55` 判断是否接住。
  `随机()`（`rand`）返回 0 到 1 之间（不含 1）的数，所以 `50 + 随机() * 540` 是 50 到 590
  之间的随机 x。
- **难度。** `令 下落 = 下落 + 0.25` 让下一颗星星稍微快一点。
- **文字。** `界面文字(x, y, 大小, 文本)`（`ui_text`）用内置的线条字体以画笔颜色绘制文字。
  它不需要字体文件，但只能画拉丁大写字母和数字，所以屏幕上的文字保留英文。
- **结束。** 关闭窗口后循环结束，最后一行在终端里打印你的得分。

## 动手试试

1. 画一张脸：一个大的黄色圆、两个深色小圆作眼睛、一段圆弧作嘴巴
   （脸的中心在 `(200, 200)` 时，可以试试 `draw_arc(200, 210, 60, 0.4, 2.74, 24)`）。
2. 让小球弹跳：保存速度 `vx` 和 `vy`，每帧把它们加到 `x` 和 `y` 上，碰到墙时把符号反过来
   （`令 vx = 0 - vx`）。
3. 在画画程序里，让颜色跟随指针的 x 位置：`令 色调 = mouse_x() / 640 * 360`。
4. 给接星星加上最高分，并用 `界面文字` 显示在得分下方。
5. 加一颗炸弹：第二个下落的物体，画成深色的圆，接住它会失去一条生命。
