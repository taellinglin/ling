# Ling 之书（PDF）

Ling 之书是一套四卷本的书，基于 Ling 2030.1.53 编写。每一卷都可以免费下载 PDF。这些书是用英文写的。

| 分卷 | 难度 | 页数 | 下载 |
|---|---|---|---|
| **Learn Ling**（学习 Ling） | 入门 | 321 | [ling-beginner.pdf](https://ling-lang.org/books/ling-beginner.pdf)（13 MB） |
| **Build with Ling**（用 Ling 构建） | 中级 | 716 | [ling-intermediate.pdf](https://ling-lang.org/books/ling-intermediate.pdf)（27 MB） |
| **Mastering Ling**（精通 Ling） | 高级 | 452 | [ling-advanced.pdf](https://ling-lang.org/books/ling-advanced.pdf)（16 MB） |
| **The Ling Reference**（Ling 参考手册） | 完整参考 | 650 | [ling-reference.pdf](https://ling-lang.org/books/ling-reference.pdf)（26 MB） |

## 每本书讲什么

### Learn Ling（入门）

值与绑定、判断与循环、函数、列表与文本、你的第一个 3D 房间、绘图与游戏、声音与音乐。最后完成一个完整的项目。

### Build with Ling（中级）

记录（`form`）、错误与结果、模块与项目结构、数据与文件、UI 应用、动画与输入、游戏与物理、音乐工具、
测试与调试，以及打包与发布。

### Mastering Ling（高级）

Ling 如何运行、并发与隔离、网络服务、用 Rust crate 构建 Web 应用、密码学、点对点协议、AI 与张量、
从 Rust 使用这些 crate、扩展 Ling、Ling OS 与嵌入式目标，以及大型应用的设计。

### The Ling Reference

每个关键字和内置函数的参数、返回值、别名和示例。最后一章列出已知限制和容易踩的坑。

## 该读哪一本

- **刚接触编程，或刚接触 Ling：** 从 *Learn Ling* 开始。
- **要写真正的程序：** 读 *Build with Ling*。
- **想深入：** 读 *Mastering Ling*。
- **要查东西：** 把 *The Ling Reference* 放在手边。

本文档是简短的在线配套资料。书讲得更深入，并且固定在同一个 Ling 版本上。如果只是快速查询，
[内置函数参考](reference/index.md)和[已知限制](language/limits.md)页面往往更快。
