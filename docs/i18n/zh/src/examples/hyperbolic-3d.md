# 双曲 3D

源代码：[`examples/physics/hyperbolic3d.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic3d.ling)

虽然文件名如此，这个演示的当前版本其实是普通（欧几里得）3D 空间里的物理迷宫。你推着一个球穿过线框迷宫，
撞墙反弹、蓄力跳跃，同时有一个音调跟随球的运动而变化。想看真正的双曲几何，请见[双曲世界](hyperbolic-world.md)。

在仓库根目录运行：

```sh
ling run examples/physics/hyperbolic3d.ling
```

## 操作

| 按键 | 动作 |
|---|---|
| `W` / `S` | 把球向前 / 向后推 |
| `A` / `D` | 把球向左 / 向右推 |
| `Space` | 按住蓄力，松开跳跃 |
| `←` / `→` | 让摄像机环绕 |
| `↑` / `↓` | 让摄像机俯仰 |
| `Z` / `X` | 拉近 / 拉远 |

## 工作原理

- **物理。** 每一帧加上重力，把速度乘以阻尼系数（`DAMPING = 0.99`），然后移动球。球越过墙时，程序把它推回去，
  并把速度反向，再乘以 `ELASTICITY = 0.80`。
- **迷宫。** 一个 300 × 200 × 300 单位的外框和五面内墙。墙按矩形做碰撞检测，并用 `draw_line_3d` 画成线条。
- **跳跃。** 球在地面上时按住 `Space` 会积蓄力量，最多到 `MAX_CHARGE`。松开就把球发射出去。球旁边的小量表显示蓄力程度。
- **球。** 画成一个旋转的 `vtex_chakra` 轮子，颜色随高度变化。地面上的十字阴影、垂到地面的线和红色的速度箭头帮你看清它的位置。
- **跟随物理变化的声音。** 一个 `audio_tone` 声部每帧都在变化：音高随高度和速度升高，每次反弹时短暂跳高；
  音量随速度增大；立体声声像跟随球的 x 坐标。
- **光照。** 三盏灯：一盏缓慢漂移的暖光、一盏冷色补光，以及一盏跟随球的紫光。

## 可以试试

- 修改文件开头的 `GRAVITY`、`DAMPING` 和 `ELASTICITY`，感受一下区别。
- 加一面墙：复制一段墙的碰撞检测，再用对应的 `draw_line_3d` 调用把它画出来。
- 把别的数值映射到声音上，例如让蓄力程度控制音高。
