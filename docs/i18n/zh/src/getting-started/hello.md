# 你好，世界

每个 Ling 程序都从一个入口绑定开始，它的值是一个 `执` 代码块。中文里入口的名字是 `启`。
下面是能打印内容的最小程序。

## 第一个程序

把下面的代码保存为 `hello.ling`：

```ling
令 启 = 执 {
    印("你好，世界！")
}
```
```output
你好，世界！
```

运行它：

```sh
ling run hello.ling
```

- `令 启 = ...` 把名字 `启` 绑定到一个值上。Ling 通过这个名字找到程序的起点
  （英文写作 `start`）。
- `执 { ... }` 是一组按顺序执行的步骤。
- `印(...)` 向终端输出一行文字。

## 再多一点

绑定也可以写在 `启` 外面。下面的程序先问候一个名字，然后遍历一个列表：

```ling
# 向几位朋友问好
令 名字 = "灵"
令 启 = 执 {
    印("你好，" + 名字 + "！")
    历 朋友 于 ["小明", "小红", "阿强"] {
        印("嗨，" + 朋友)
    }
}
```
```output
你好，灵！
嗨，小明
嗨，小红
嗨，阿强
```

`+` 用来拼接文本，`历 ... 于` 会对列表中的每一项执行一次代码块。

运行中文程序时，`ling` 会在标准错误输出上提示它检测到的语言，例如
`[detected language: Chinese (中文)]`。这不会影响程序的运行。

## 混用多种语言

每个关键字和内置函数都有英文、中文、日文、韩文和泰文的名字，而且可以在同一个文件里随意混用。
下面这个程序同时用了五种语言：

```ling
令 名字 = "Ling"
bind start = do {
    พิมพ์("สวัสดี " + 名字)
    만약 참 {
        印刷("こんにちは")
    }
}
```
```output
สวัสดี Ling
こんにちは
```

想了解五种语言如何协同工作，请阅读[用五种语言编写](../language/multilingual.md)。
