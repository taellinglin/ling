# 你的第一个 3D 房间

是时候离开终端了。在这一页，你会打开一个窗口，学习驱动所有 Ling 画面的帧循环，
并搭建一个可以用方向键四处走动的小型 3D 房间。Ling 用内置的软件渲染器绘制一切，
所以你不需要游戏引擎，也不需要 GPU。

会打开窗口的程序无法在终端里检查，所以它们的代码块没有输出。按 **Escape** 或关闭窗口即可停止。

## 帧循环

窗口每次显示一张静止的画面（一帧）。程序画好一帧、显示出来，然后开始画下一帧。
所有图形程序都有同样的节奏：

1. **打开**窗口，只做一次。
2. 用 `填` **清空**画面，免得上一帧残留。
3. **绘制**你的形状。
4. 用 `显()` **显示**这一帧。

循环条件是 `循 窗开()`。窗口被关闭或按下 Escape 时它会变成假，所以你不需要自己写退出逻辑。

```ling-gui
令 启 = 执 {
    开窗(640, 400, "我的第一个窗口")
    令 角度 = 0
    循 窗开() {
        填(15, 18, 40)
        设色(255, 120, 60)
        立方体(0, 0, 3, 1, 1, 1, 角度, 角度 * 0.7, 0, 0)
        显()
        令 角度 = 角度 + 0.02
    }
}
```

- `开窗(640, 400, "我的第一个窗口")` 打开一个 640 x 400 的窗口。先写尺寸，最后写标题。
- `填(15, 18, 40)` 涂满整个窗口。颜色是红、绿、蓝三个 0 到 255 的数。
- `设色(...)` 选择后面形状的颜色。
- `立方体(...)` 画一个立方体。参数按三个一组：中心 `x, y, z`、尺寸、以弧度表示的旋转，
  最后是模式（`0` 实心，`1` 线框，`2` 两者都有）。
- `显()` 显示这一帧。不调用它就什么都看不到。
- 每帧重新绑定 `角度`，立方体才会转动。

## 东西在哪里

在 Ling 的 3D 世界里，**x** 指向右，**y** 指向**下**，**z** 指向屏幕里面、远离你的方向。
所以“上”是负的 y：在下面的房间里，地板在 `y = 3`，天花板在 `y = -3`。

摄像机位于原点，沿 z 方向看。三个调用可以改变它看到的画面：

| 调用 | 作用 |
|---|---|
| `镜坐标(x, y, z)` | 移动摄像机。 |
| `设镜(cos_yaw, sin_yaw, cos_pitch, sin_pitch)` | 转动摄像机。传入的是每个角度的余弦和正弦，所以要转过角度 `a`，就调用 `设镜(余弦(a), 正弦(a), 1, 0)`。 |
| `镜距(d)` | 眼睛离画面有多远。像 `0.5` 这样的小值适合第一人称视角。 |

每一帧都要在绘制之前调用摄像机函数。

## 一个可以走动的房间

下面的程序把这些都组合起来：由网格组成的地板和天花板、四面墙、四根柱子、一盏灯、
一个旋转的中心装饰，以及键盘控制。把它保存为 `room.ling`。

```ling-gui
# 一个可以四处走动的房间。
# 左右方向键转身，上下方向键行走。按 Escape 退出。

函 柱子(x, z) {
    设色(200, 190, 170)
    圆柱(x, 0, z, 0.5, 3, 0.5, 0, 0, 0, 0)
}

函 墙面(帧) {
    # 地板和天花板（y 轴朝下，所以地板在 y = 3）
    纹格(0, 3, 0,   1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  帧, 0)
    纹格(0, -3, 0,  1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  帧, 2)
    # 四面竖直的墙
    纹格(0, 0, 8,   1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  帧, 1)
    纹格(0, 0, -8,  1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  帧, 1)
    纹格(-8, 0, 0,  0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  帧, 3)
    纹格(8, 0, 0,   0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  帧, 3)
    # 远处墙上的一朵花
    纹花(0, 0, 7.9,  1, 0, 0,  0, -1, 0,  1.6, 24,  帧, 0)
}

令 启 = 执 {
    开窗(960, 600, "我的 3D 房间")
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    环境光(0.3)

    令 位置x = 0
    令 位置z = -5
    令 朝向 = 0
    令 帧 = 0

    循 窗开() {
        # 输入：转身和行走
        若 按键("left") {
            令 朝向 = 朝向 - 0.03
        }
        若 按键("right") {
            令 朝向 = 朝向 + 0.03
        }
        若 按键("up") {
            令 位置x = 位置x + 正弦(朝向) * 0.1
            令 位置z = 位置z + 余弦(朝向) * 0.1
        }
        若 按键("down") {
            令 位置x = 位置x - 正弦(朝向) * 0.1
            令 位置z = 位置z - 余弦(朝向) * 0.1
        }

        # 绘制
        填(8, 8, 20)
        设镜(余弦(朝向), 正弦(朝向), 1, 0)
        镜坐标(位置x, 0, 位置z)
        镜距(0.5)
        清灯()
        加灯(0, -2.5, 0, 1.0, 0.85, 0.6, 1.0, 14)

        墙面(帧 * 0.3)
        柱子(-6, -6)
        柱子(6, -6)
        柱子(-6, 6)
        柱子(6, 6)

        设色(240, 200, 80)
        圆环(0, 1.5, 0, 0.7, 0.7, 0.7, 1.2, 帧 * 0.03, 0)

        显()
        令 帧 = 帧 + 1
    }
}
```

运行它：

```sh
ling run room.ling
```

工作原理：

- `柱子` 和 `墙面` 是绘制房间各部分的函数。它们在循环里被调用，所以每帧都会重新绘制。
  `墙面` 通过参数拿到 `帧`，因为函数只能看到自己的参数和顶层名字。
- `开窗` 之后的四行切换到柔和、真实的颜色。没有它们的话，Ling 默认的风格会把阴影染成靛蓝色，
  并加上发光的轮廓。
- `位置x`、`位置z` 和 `朝向` 保存摄像机的位置和方向。按住左方向键时 `按键("left")` 为真。
  行走时沿 x 移动 `正弦(朝向)`，沿 z 移动 `余弦(朝向)`，也就是你面对的方向。
- `清灯()` 和 `加灯(x, y, z, r, g, b, 强度, 半径)` 每帧都要调用，否则灯光会不断叠加。
  灯在 `y = -2.5`，靠近天花板。
- `纹格` 和 `纹花` 在一个平面上画线条图案。前三个数是中心，接下来六个数是平面的“右”和“上”方向。
  竖直的墙“上”方向是 `0, -1, 0`，因为 y 指向下方。

墙只是画出来的，并不是实体：你可以直接穿墙而过。

## 动手试试

- 修改每个 `纹格` 调用的最后一个数（色调），换一种颜色。
- 加第五根柱子，或者再加一个不同颜色的 `加灯`。
- 在 `显()` 后面加上 `若 键按("p") { screenshot("room") }`。按 P 会把一张 PNG 存到
  `screenshots` 文件夹里。
