# 简介

Ling 是一门可以用你自己的语言来写的编程语言。它的关键字和内置函数有 16 种以上人类语言的名字，
包括中文、日语、韩语、泰语、英语、阿拉伯语、希伯来语和俄语，而且可以在同一个文件里混用。
本文档涵盖其中五种：English、中文、日本語、한국어 和 ไทย。可以在页面顶部的语言选择器中切换。

本指南对应 Ling 2030.1.53。

## 初见 Ling

下面是一个小程序。每个程序都从 `令 始 = 执 { ... }` 开始。

```ling
# 向几位朋友问好
令 始 = 执 {
    令 朋友们 = ["小明", "小红", "阿杰"]
    历 名字 于 朋友们 {
        打印("你好，" + 名字 + "！")
    }
    打印(长度(朋友们))
}
```

```output
你好，小明！
你好，小红！
你好，阿杰！
3
```

同样的程序也可以用英语、日语、韩语或泰语的关键字来写。切换页面语言就能看到，也可以阅读
[用五种语言编写](language/multilingual.md)。

## 你能得到什么

一个 `ling` 程序就包含：

- **JIT 编译器和解释器。** 程序通过 Cranelift 编译成本机代码，其余部分由解释器负责。
- **图形与 3D。** 窗口、2D 绘图、图像、字体，以及带摄像机、光照、卡通着色和矢量几何（`vtex_*`）的软件 3D 渲染器。
- **音频与音乐。** 音调、空间音效、WAV 播放、音乐解码、BPM 与调性分析、GM 风格合成器和 MIDI。
- **物理。** 刚体、软体和液体模拟。
- **UI。** HUD、仪表、按钮和其他组件。
- **Web 服务器。** 通过 `http_*` 和 `db_*` 内置函数提供路由、静态文件和 SQLite。
- **密码学。** 哈希、加密、签名和后量子密钥交换。
- **AI。** 神经网络、行为树，以及可选的语言模型支持。

项目管理工具 `lingfu` 可以创建、运行和测试项目，`lingfu normalize` 还能把整个项目改写成同一种语言。

## 安装

macOS 或 Linux：

```sh
curl --proto '=https' --tlsv1.2 -sSf https://ling-lang.org/install.sh | sh
```

Windows（PowerShell）：

```powershell
irm https://ling-lang.org/install.ps1 | iex
```

如果你还没有 Rust，脚本会先安装 Rust，再构建 `ling` 和 `lingfu`。其他安装方式和安装配置见
[安装](getting-started/install.md)。
