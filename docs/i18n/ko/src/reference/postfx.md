# 포스트 FX와 조명

이 페이지에서는 Ling이 3D 장면을 비추는 방법과 각 프레임을 마무리하는 방법을 다룹니다. 조명과 셰이딩은 삼각형을 그리는 순간 그 색을 정합니다. 그다음 완성된 이미지 위로 화면 공간 **포스트 체인**이 돕니다. 앰비언트 오클루전, 잉크 윤곽선, 톤 램프, 블룸, 안티앨리어싱 순서입니다. 여기에 피사계 심도, 화면 왜곡, 부드러운 볼류메트릭 광선을 더할 수 있습니다.

여기 있는 것은 모두 열린 창에 그리므로, 예제는 `ling-gui` 프로그램입니다.

## 조명

조명도 그리기와 같은 프레임 단위 순서를 따릅니다. 지우고, 추가하고, 그립니다.

### `set_ambient(level)`

조명과 상관없이 모든 표면에 닿는 빛입니다. 0부터 1까지이며 기본값은 0.15입니다.

### `add_light(x, y, z, r, g, b, intensity, radius)`

월드 위치에 색이 있는 점광원을 추가합니다. 색은 0~1 또는 0~255로 줄 수 있습니다. 어느 한 채널이라도 1.5를 넘으면 세 채널 모두 0~255로 읽습니다. `intensity`는 밝기 배율(기본값 1)입니다. `radius`는 빛이 완전히 사라지는 거리이며, 0이면 감쇠가 없습니다(기본값).

순서는 위치, **색**, 세기, 반지름입니다. 조명은 `clear_lights()`를 부를 때까지 계속 쌓이므로, 매 프레임 지우고 다시 추가하세요.

### `set_fog(r, g, b, start, end)`

거리 안개입니다. 카메라 깊이 `start`와 `end` 사이에서 지오메트리가 지정한 색(0~255)으로 흐려집니다. `end`가 0 이하면 안개가 꺼집니다. 아래의 볼류메트릭 광원도 안개에 따라 흐려집니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(720, 420, "조명")
    깊이테스트(1)
    환경광설정(0.2)
    set_fog(8, 10, 24, 10, 40)
    동안 창열림() {
        채우기(8, 10, 24)
        조명초기화()
        조명추가(0, -5, 4, 1.0, 0.85, 0.6, 1.2, 20)
        색설정(240, 150, 110)
        정육면체(0, 0, 8, 1, 1, 1, 0.3, 현재시간(), 0, 0)
        표시()
    }
}
```

## 셰이딩

셰이더는 정점마다 펜 색에 다음을 섞습니다. 환경광 항(모든 조명에서 등을 돌린 면에서는 그림자 색으로 물듦), 각 조명의 기여, 실루엣 쪽으로 갈수록 밝아지는 림 글로우, 그리고 기본 모드에서는 은은한 무지갯빛 광택입니다. 결과는 몇 단계의 밝기로 양자화됩니다.

기본값은 일부러 양식화되어 있습니다. 차가운 남색 그림자, 청록색 림, 홀로그램 광택입니다. 펜 색과 일치하는 색을 원하면 `set_shade_mode(1)`, `set_rim(0, 0, 0, 0)`, 어둡고 중립적인 `set_shadow_color`를 쓰세요.

| 내장 함수 | 매개변수 |
|---|---|
| `set_shade_mode(m)` | `0` 플랫(삼각형마다 한 단계), `1` 부드러운 셀(광택 없음, 림 약화), `2` 홀로그램(기본값). |
| `set_cel_bands(n)` | 단계 수, 최소 2(기본값 4). |
| `set_shadow_color(r, g, b)` | 빛이 닿지 않는 곳의 색조, 0~255(기본값 26, 33, 77). |
| `set_rim(strength, r, g, b)` | 림 세기(기본값 0.6, 0이면 끔)와 색 0~255(기본값 115, 217, 255). |
| `set_flat_shade(on)` | 0이 아니면 조명 계산을 모두 건너뛰고 펜 색 그대로 그립니다. 성능 테스트용입니다. |

### `set_material(key, value)`와 `reset_material()`

`set_material`은 이후의 `draw_triangle_3d`와 다각형 그리기에 물리 기반 툰 재질을 켭니다. `key`는 문자열, `value`는 숫자이며, 색 키에는 `0xRRGGBB` 형태의 숫자를 넣습니다. 키: `albedo`, `roughness`, `metallic`, `emission`, `emission_strength`, `specular`, `specular_tint`, `subsurface`, `subsurface_color`, `clearcoat`, `clearcoat_roughness`, `transmission`, `ior`, `iridescence`, `sheen`, `anisotropy`, `anisotropy_angle`, `toon_bands`, `shadow_softness`, `outline_px`, `outline_color`, `highlight_color`. 모르는 키는 무시됩니다. `reset_material()`은 일반 조명으로 되돌립니다. 기본 입체(`cube`, `sphere` 등)는 재질을 읽지 않습니다.

## 포스트 체인

포스트 체인은 `present()` 안에서 다음 순서로 돕니다.

1. **앰비언트 오클루전**(`set_ssao`): 깊이 버퍼로 만든 부드러운 접촉 그림자.
2. **윤곽선**(`toon_outlines`): 깊이가 급히 바뀌는 곳의 잉크 선.
3. **톤 램프**(`tone_*`): 밝기를 셀 단계로 바꿉니다.
4. **블룸**(`set_bloom`): 밝은 픽셀에서 번지는 빛.
5. **FXAA**(`set_fxaa`): 최종 이미지 위의 경계 안티앨리어싱.

앰비언트 오클루전, 윤곽선, 블룸, FXAA는 켜기 전까지 꺼져 있습니다. 톤 램프는 언제나 돌며, 기본 3단계 램프에서 시작합니다. 오클루전과 윤곽선은 깊이 버퍼를 읽으므로 먼저 `set_depth_test(1)`을 부르세요.

벡터 선과 텍스트는 톤 램프의 영향을 받지 않으므로, 인터페이스 텍스트와 와이어프레임이 단계로 끊기는 일은 없습니다.

### `set_ssao(strength, radius_px, zrange)`

모서리, 주름, 물체 아래를 부드럽게 어둡게 합니다. 절반 해상도로 계산해 매끄럽게 다듬습니다. `strength`는 0~1(0이면 끔), `radius_px`는 샘플링 반지름 픽셀(기본값 6), `zrange`는 이웃을 가리개로 볼 깊이 범위(기본값 12)입니다.

### `toon_outlines(thickness, color, threshold)`

깊이가 끊기는 곳에 잉크 선을 그립니다. `thickness`는 반폭 픽셀(0이면 끔, 1.5가 무난한 애니메이션 기본값), `color`는 `0xRRGGBB` 숫자(기본값 0, 검정), `threshold`는 경계로 볼 깊이 차이(기본값 0.05)입니다.

### 톤 램프

톤 램프는 정지점의 리스트입니다. 각 정지점은 입력 밝기 `t`를 출력 밝기 `value`로 대응시킵니다(둘 다 0~1). 기본 램프는 3단계입니다. 0.25 미만은 0.08, 0.60 미만은 0.50, 그 위는 1.00입니다.

- `tone_stop(t, value)`는 정지점을 추가합니다. 정지점은 `t` 순서로 정렬됩니다.
- `tone_ramp_clear()`는 정지점을 모두 지워 직접 램프를 만들 수 있게 합니다. `tone_ramp_reset()`은 기본값으로 되돌립니다.
- `tone_smooth(on)`: `0`이면 정지점 사이를 딱 잘라 끊고(기본값), `1`이면 부드럽게 섞습니다.
- `tone_bezier(y1, y2)`는 조회하기 전에 입력 밝기를 3차 베지어로 다시 매핑합니다. `0.333, 0.667` 정도가 중립(기본값)이고, `0, 0`은 그림자 쪽, `1, 1`은 하이라이트 쪽, `0.1, 0.9`는 S자 곡선입니다. `tone_bezier_off()`로 제거합니다.
- `tone_soft(soft, sheen)`: `soft`(0~1, 기본값 0.32)는 각 단계 경계에서 섞이는 폭의 비율로, 0이면 칼같이 날카롭고 0.3 정도면 그림자 경계가 부드러워집니다. `sheen`(0~1, 기본값 0.65)은 밝은 픽셀이 그라데이션을 유지하게 해서, 하이라이트가 거친 계단 대신 깨끗한 광택으로 보이게 합니다.

자주 쓰는 두 가지 느낌:

| 느낌 | 호출 |
|---|---|
| 또렷한 애니메이션 셀 | `tone_smooth(0)`, `tone_soft(0.32, 0.65)` |
| 회화풍, 부드러움 | `tone_smooth(1)`, `tone_bezier(0.12, 0.88)`, `tone_soft(0.32, 0.65)` |

### `set_bloom(strength, threshold)`

밝은 픽셀에서 부드러운 빛이 번집니다. 4분의 1 해상도로 계산합니다. `strength`의 기본값은 0.45(0이면 끔), `threshold`는 0~0.99 범위의 휘도 기준(기본값 0.74)입니다.

### `set_fxaa(on)`

이미지 전체에 가벼운 안티앨리어싱을 겁니다(인자 기본값 1). 다각형의 계단 현상과 윤곽선의 들쭉날쭉함을 누그러뜨리고, 평평한 면은 건드리지 않습니다. 와이어프레임 선을 그릴 때 매끄럽게 하는 `set_antialias`와는 다릅니다.

### `flush_post()`

`flush_3d()`처럼 3D 큐를 비운 다음, 포스트 체인을 바로 실행합니다. 그 프레임에서는 `present()`가 체인을 건너뛰므로, `flush_post()` 뒤에 그린 HUD는 블룸이나 흐림 없이 또렷하게 남습니다. 영어 이름 `post_now()`로도 부를 수 있습니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(960, 540, "툰")
    깊이테스트(1)
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    toon_outlines(1.5, 0, 0.05)
    set_ssao(0.4, 7, 14)
    tone_smooth(1)
    tone_bezier(0.12, 0.88)
    tone_soft(0.32, 0.65)
    set_bloom(0.5, 0.74)
    set_fxaa(1)
    동안 창열림() {
        채우기(20, 24, 40)
        조명초기화()
        조명추가(-2, -6, -2, 1.0, 0.95, 0.85, 0.8, 0)
        색설정(220, 180, 120)
        구(0, 0, 8, 1.5, 1.5, 1.5, 0, 현재시간(), 0, 0)
        flush_post()
        색설정(255, 255, 255)
        UI텍스트(20, 20, 16, "HUD")
        표시()
    }
}
```

## 화면 효과

### `depth_blur(focus, range, radius, oil)`

깊이 버퍼를 써서 프레임에 피사계 심도를 겁니다. 카메라 깊이 `focus`(기본값 30)에서 선명하고, 깊이가 `range`(기본값 60)만큼 멀어지면 최대 `radius` 픽셀(기본값 3)까지 흐려집니다. 지오메트리가 없는 배경은 완전히 흐려집니다. `oil`(0~1, 기본값 0)은 흐려진 부분에 기름막 같은 무지갯빛 테두리와 색 소용돌이를 더해, 물이나 아지랑이 느낌을 냅니다. 영어 이름 `dof`, `depth_of_field`로도 부를 수 있습니다.

`flush_3d()` **다음에**(깊이 버퍼가 채워진 뒤), 인터페이스를 그리기 **전에** 부르세요. `set_depth_test(1)`이 필요합니다.

### `screen_distort(amount, t, step)`

가장자리에서 이어지는 끈적한 전체 화면 왜곡으로, 점액, 아지랑이, 꿈 같은 효과에 씁니다. `amount`는 최대 변위 픽셀(기본값 8), `t`는 왜곡이 움직이게 하는 시간 값(기본값 0), `step`은 1이면 전체 해상도, 2 이상이면 더 가벼운 블록 왜곡(기본값 1)입니다. `depth_blur`처럼 3D 플러시 뒤, 인터페이스 전에 부르세요. 브라우저 빌드에서는 쓸 수 없습니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(960, 540, "아지랑이")
    깊이테스트(1)
    동안 창열림() {
        채우기(10, 20, 40)
        색설정(120, 200, 255)
        정육면체(0, 0, 8, 1, 1, 1, 0, 현재시간(), 0, 0)
        정육면체(3, 0, 20, 1, 1, 1, 0, 현재시간(), 0, 0)
        flush_3d()
        depth_blur(8, 6, 4, 0.3)
        screen_distort(4, 현재시간(), 2)
        표시()
    }
}
```

## 볼류메트릭 라이트

`light_pool`과 `light_beam`은 물속이나 먼지 낀 공기 속으로 퍼지는 빛처럼 보이는 부드러운 가산 그라데이션을 그립니다. 바깥 가장자리가 검정으로 사라지므로, 가산 블렌딩에서는 테두리가 보이지 않습니다. 둘 다 거리 안개에 따라 흐려지며, 비용은 필 레이트입니다. 화면에서 클수록 비쌉니다.

### `light_pool(x, y, z, radius, r, g, b, intensity)`

높이 `y`의 바닥에 램프가 드리우는 색 있는 빛 웅덩이입니다. 기본값은 위치 0, `radius` 20, 색 255(채널마다 0~255), `intensity` 1입니다(0.2~1.5 정도가 보기 좋습니다).

### `light_beam(x, y, z, floor_y, radius, r, g, b, intensity)`

빛줄기입니다. 광원 위치에서 높이 `floor_y`의 바닥면까지 내려가며 `radius`(기본값 14)까지 넓어지는 이중 원뿔입니다. 아래쪽에 `light_pool`을 함께 두세요.

둘 다 `set_blend(1)`(가산)로 그리고, 끝나면 `set_blend(0)`으로 되돌리세요. 딱딱한 단계는 부드러운 그라데이션을 평평한 계단으로 만들기 때문에, `tone_smooth(1)`과 함께 쓰면 가장 보기 좋습니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(720, 420, "볼류메트릭")
    깊이테스트(1)
    환경광설정(0.2)
    set_shade_mode(1)
    tone_smooth(1)
    set_bloom(0.5, 0.74)
    동안 창열림() {
        채우기(6, 8, 18)
        카메라설정(1, 0, 코사인(0.25), 사인(0.25))
        카메라좌표(0, -3, 0)
        조명초기화()
        조명추가(0, -5, 8, 1.0, 0.9, 0.7, 0.8, 0)
        색설정(220, 180, 120)
        원기둥(0, 1.3, 9, 0.8, 0.7, 0.8, 0, 0, 0, 0)
        블렌드모드(1)
        light_beam(0, -6, 9, 2, 3.0, 255, 220, 160, 0.8)
        light_pool(0, 2, 9, 5.0, 255, 220, 160, 0.9)
        블렌드모드(0)
        flush_3d()
        표시()
    }
}
```

## 예전 이름

`shadow_smooth(softness)`는 `tone_smooth`와 `tone_bezier`를 한꺼번에 설정하는 예전 단축 함수입니다. 대신 그 둘을 쓰세요. `toon_highlight(...)`는 받아들여지지만 아무것도 하지 않습니다. `tone_stop`과 `tone_soft`를 쓰세요.
