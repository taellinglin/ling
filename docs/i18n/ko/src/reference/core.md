# 출력, 수학, 논리

이 내장 함수들은 콘솔에 출력하고, 텍스트를 만들고, 계산을 하고, 프로그램을 잠시 멈춥니다.
창이 필요 없으므로 이 페이지의 모든 예제는 일반 터미널에서 `ling run`으로 실행할 수 있습니다.

Ling의 모든 숫자는 64비트 부동소수점입니다. 정수 값은 소수점 없이 출력됩니다(`3.0`이 아니라 `3`).
각도는 라디안입니다. 끝쪽 숫자 인수를 생략하면 대개 오류 대신 기본값이 쓰입니다.

## 출력

### `print(value, ...)`와 `println(value, ...)`

`print`와 `println`은 같은 내장 함수입니다. 각 인수를 텍스트로 바꾼 뒤 **구분자 없이** 이어 붙이고
줄을 바꿉니다. 리스트는 `[1, 2, 3]`, 결과는 `Ok(v)`와 `Err(e)`로 출력됩니다.

```ling
바인드 start = 실행 {
  출력("안녕하세요, Ling!")
  출력(42, " ", 3.5, " ", 참)
  출력([1, 2, 3])
  출력("합계", 1 + 2)
  출력("합계 ", 1 + 2)
}
```
```output
안녕하세요, Ling!
42 3.5 true
[1, 2, 3]
합계3
합계 3
```

공백은 문자열 안에 직접 넣거나, `format`으로 줄을 만드세요.

### `print_file(text)`

첫 번째 인수를 줄바꿈 **없이** 출력합니다. 이름과 달리 파일은 건드리지 않습니다.
같은 줄에 이어서 출력하는 유일한 방법입니다.

```ling
바인드 start = 실행 {
  위해 i 안에 1..4 {
    print_file(i)
    print_file(" ")
  }
  출력("출발!")
}
```
```output
1 2 3 출발!
```

### `print_color(color, value, ...)`

굵고 밝은 ANSI 색으로 한 줄을 출력합니다. `color`는 0부터 7까지이며 검정, 빨강, 초록, 노랑, 파랑, 자홍, 청록, 흰색입니다.
나머지 인수는 `print`처럼 이어 붙입니다. 이스케이프 코드가 그대로 쓰이므로 출력을 파일로 리디렉션하면 제어 문자로 나타납니다.

```ling-gui
바인드 start = 실행 {
  print_color(2, "성공: ", "모든 테스트 통과")
  print_color(1, "오류!")
}
```

### `format(template, value, ...)`

각 `{}`를 다음 인수로 바꾼 텍스트를 돌려줍니다. `{:.N}`은 숫자를 소수점 아래 `N`자리로 맞춥니다.
짝이 없는 `{}`는 빈 문자열이 되고, 남는 인수는 무시됩니다. `{}`와 `{:.N}`만 지원합니다
(너비 지정, `{0}`, `{name}`, 중괄호 이스케이프는 안 됩니다).

```ling
바인드 start = 실행 {
  출력(서식("{} + {} = {}", 2, 3, 2 + 3))
  출력(서식("원주율은 약 {:.3}", 파이()))
  출력(서식("{:.1}%", 45.678))
  출력(서식("{} 그리고 {}", "하나만"))
}
```
```output
2 + 3 = 5
원주율은 약 3.142
45.7%
하나만 그리고 
```

`format::join(list)`는 모든 항목을 텍스트로 구분자 없이 이어 붙입니다. 항목 사이에 무언가를 넣으려면
`list_join`을 쓰세요([텍스트와 리스트](text-lists.md) 참고).

## 결과

### `ok(value)`와 `bad(reason)`

Ling에는 예외가 없습니다. 실패할 수 있는 함수는 `ok(value)`나 `bad(reason)`을 돌려주고, 호출하는 쪽은 `match`로 풀어 봅니다.
출력은 `Ok(...)`와 `Err(...)`이며, `err`는 `bad`의 영어 별칭입니다.
자세한 내용은 [오류와 결과](../language/errors.md)를 보세요.

```ling
함수 절반(n) {
  만약 n % 2 == 0 { 좋아(n / 2) } 아니면 { 나쁨("홀수") }
}
바인드 start = 실행 {
  출력(절반(10))
  출력(절반(7))
  출력(매치 절반(7) { 좋아(v) => v, 나쁨(e) => "실패: " + e })
}
```
```output
Ok(5)
Err(홀수)
실패: 홀수
```

### `try(function, arg, ...)`

나머지 인수로 `function`을 호출합니다. 성공하면 `ok(result)`, 호출 중 런타임 오류가 나면 `bad(message)`를 돌려줍니다.

> **인터프리터 전용입니다.** 기본 백엔드는 인수로 넘긴 함수와 클로저를 `()`로 바꾸므로
> `try`가 `Err(try: first argument must be a function)`을 돌려줍니다. `try`를 쓰는 프로그램은
> `ling run --interp`로 실행하세요. 매개변수가 없는 클로저는 공백을 넣어 `| | expr`로 씁니다.

```ling-module
함수 안전하게읽기(경로) { 시도(| | read_file(경로)) }
```

## 수학

### 반올림과 버림

`floor`는 내림, `ceil`은 올림, `round`는 반올림(정확히 절반이면 0에서 먼 쪽으로), `trunc`는 소수 부분을 버리고,
`fract`는 소수 부분만 남깁니다. `int`는 `trunc`의 영어 별칭으로, 텍스트를 숫자로 바꾸지 않습니다(그때는 `to_number`를 쓰세요).

```ling
바인드 start = 실행 {
  출력(내림(2.7), " ", 내림(0 - 2.1))
  출력(올림(2.1), " ", 올림(0 - 2.9))
  출력(반올림(2.5), " ", 반올림(2.4), " ", 반올림(0 - 2.5))
  출력(정수화(2.9), " ", 정수화(0 - 2.9), " ", int(7.99))
  출력(소수부(2.25))
}
```
```output
2 -3
3 -2
3 2 -3
2 -2 7
0.25
```

### `min`, `max`, `clamp`, `sign`, `abs`

`min`과 `max`는 정확히 두 수를 받습니다. 리스트에는 `list_min`과 `list_max`를 쓰세요. `clamp`의 기본 범위는 0..1이며,
`low > high`이면 두 경계를 바꿉니다. `sign(0)`은 `0`이 아니라 `1`입니다.

```ling
바인드 start = 실행 {
  출력(최솟값(3, 1), " ", 최댓값(3, 1))
  출력(범위제한(15, 0, 10), " ", 범위제한(0 - 3, 0, 10))
  출력(부호(0 - 4), " ", 부호(0), " ", 절댓값(0 - 7))
}
```
```output
1 3
10 0
-1 1 7
```

### 거듭제곱, 제곱근, 로그

음수의 `sqrt`는 `NaN`입니다. `log`는 **자연**로그(`ln`과 같음)입니다. 밑이 10인 로그는 `log10`을 쓰세요.

```ling
바인드 start = 실행 {
  출력(제곱근(16), " ", 거듭제곱(2, 10), " ", 거듭제곱(9, 0.5))
  출력(세제곱근(27), " ", 빗변(3, 4), " ", 지수(1))
  출력(로그(지수(2)), " ", 로그(1), " ", 로그2(8), " ", 로그10(1000))
  출력(제곱근(0 - 1))
}
```
```output
4 1024 3
3 5 2.718281828459045
2 0 3 3
NaN
```

### 삼각함수와 상수

각도는 라디안입니다. `pi()`와 `tau()`는 항상 괄호를 붙여 호출하세요. 기본 백엔드에서 괄호 없는 `pi`는 `()`입니다.

```ling
바인드 start = 실행 {
  출력(사인(파이() / 2), " ", 코사인(파이()))
  출력(아크탄젠트2(1, 1) * 4)
  출력(타우())
}
```
```output
1 -1
3.141592653589793
6.283185307179586
```

### 보간과 노이즈

`lerp(a, b, t)`는 `t`를 제한하지 않습니다. `smoothstep(low, high, x)`는 `low` 아래에서 0, `high` 위에서 1,
그 사이에서는 부드러운 곡선을 돌려줍니다. 노이즈 함수는 결정적이어서 같은 인수에는 항상 같은 값을 주므로 지형과 텍스처를 만들 때 편리합니다.

```ling
바인드 start = 실행 {
  출력(선형보간(0, 10, 0.25), " ", 스무스스텝(0, 1, 0.5), " ", 스무스스텝(0, 1, 2))
  출력(값노이즈2D(1.5, 2.5, 0) == 값노이즈2D(1.5, 2.5, 0))
  출력(프랙탈노이즈(0.3, 0.7, 4, 1) >= 0)
}
```
```output
2.5 0.5 1
true
true
```

### `rand()`

0 이상 1 미만의 의사 난수를 돌려줍니다. 시드도 정수 버전도 없으므로 직접 곱하고 내림하세요.
보안 용도에는 맞지 않습니다. 예측할 수 없는 값이 필요하면 `random_hex`([파일, 시간, 시스템](files.md) 참고)를 쓰세요.

```ling
바인드 start = 실행 {
  바인드 주사위 = 내림(난수() * 6) + 1
  출력(주사위 >= 1 && 주사위 <= 6)
}
```
```output
true
```

## 논리와 비교

논리와 비교는 내장 함수가 아니라 연산자입니다: `==`, `!=`, `<`, `<=`, `>`, `>=`, `&&`, `||`, `!`.
숫자, 텍스트, 불리언은 값으로 비교합니다. 주의할 점이 두 가지 있습니다. 리스트는 `==`로 비교하면 절대 같지 않으며(항목별로 비교하세요),
`<`로 텍스트 순서를 비교하는 것은 믿을 수 없습니다.

```ling
바인드 start = 실행 {
  출력(1 < 2 && !(3 == 4))
  출력("가" == "가", " ", 2 != 3)
  출력([1, 2] == [1, 2])
}
```
```output
true
true true
false
```

## 일시 정지

지정한 밀리초 동안 프로그램을 멈춥니다(`sleep_ms`는 영어 별칭). 시간을 재려면 [파일, 시간, 시스템](files.md)의 `time_now`를 보세요.

```ling
바인드 start = 실행 {
  잠자기(50)
  출력("완료")
}
```
```output
완료
```
