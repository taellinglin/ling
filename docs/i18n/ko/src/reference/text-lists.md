# 텍스트와 리스트

텍스트(문자열)와 리스트는 Ling에서 매일 쓰는 두 가지 컬렉션입니다. 이 페이지에서는 텍스트를 재고, 찾고, 자르고, 변환하는 내장 함수와
리스트를 만들고 읽는 내장 함수를 다룹니다. 좀 더 쉬운 입문은 [리스트와 텍스트](../tutorials/lists-text.md) 튜토리얼을 보세요.

페이지 전체에 적용되는 규칙이 두 가지 있습니다.

- **내장 함수는 입력을 바꾸지 않습니다.** 새 값을 돌려주므로 결과를 다시 바인딩하세요:
  `바인드 xs = 목록추가(xs, 5)`.
- **잘못된 입력에도 오류가 나는 경우는 드뭅니다.** 범위를 벗어난 인덱스나 해석할 수 없는 숫자는 오류 대신
  대체 값(`""`, `0`, `-1`)이 됩니다. 어떤 값이 되는지는 항목마다 적혀 있습니다.

## 텍스트

### 잇기와 변환

`+`는 텍스트를 잇고, 어느 쪽에 있든 숫자를 텍스트로 바꿉니다. `to_str`은 어떤 값이든 명시적으로 텍스트로 바꿉니다.
`to_number`는 앞뒤 공백을 무시하고 읽을 수 없는 것에는 **`0`**을 돌려주므로, `"0"`과 잘못된 입력을 구별하지 못합니다.
16진수는 읽지 못하니 그때는 `hex_to_number`를 쓰세요.

```ling
바인드 start = 실행 {
  출력("점수: " + 10)
  출력(to_str(3) + "!")
  출력(to_number(" 42 ") + 1, " ", to_number("abc"))
  출력(hex_to_number("ff"))
}
```
```output
점수: 10
3!
43 0
255
```

### `len(value)`

텍스트의 글자 수나 리스트의 항목 수를 셉니다. 그 밖의 값은 `0`입니다. 메서드 형식 `"텍스트".len()`은
**바이트 수**를 세므로 ASCII가 아닌 텍스트에서는 결과가 다릅니다.

```ling
바인드 start = 실행 {
  출력(길이("Ling"), " ", 길이([1, 2, 3]))
  출력(길이("한글"), " ", "한글".len())
}
```
```output
4 3
2 6
```

### 찾기

`starts_with`, `ends_with`, `str_contains`는 `true` 또는 `false`를 돌려줍니다. `str_find`는 처음 일치한 곳의
0부터 센 글자 인덱스를 돌려주고, 없으면 `-1`을 돌려줍니다. 메서드 `text.contains(part)`도 쓸 수 있습니다.

```ling
바인드 start = 실행 {
  바인드 말 = "안녕하세요"
  출력(starts_with(말, "안녕"), " ", ends_with(말, "세요"))
  출력(문자열포함(말, "하세"), " ", 말.contains("잘가"))
  출력(str_find(말, "하"), " ", str_find(말, "잘"))
}
```
```output
true true
true false
2 -1
```

### 자르기와 바꾸기

`substr(text, start, length)`는 0부터 글자 단위로 셉니다. `length`를 생략하면 끝까지입니다.
범위를 벗어난 값은 범위 안으로 맞춰지며 오류가 나지 않습니다. `str_replace`는 나오는 곳을 모두 바꿉니다.

```ling
바인드 start = 실행 {
  출력(substr("hello", 1, 3), " ", substr("hello", 2))
  출력(str_replace("a-b-c", "-", "+"))
  출력(trim("   여백   ") + "|")
  출력(str_upper("Ling"), " ", str_lower("LING"))
  출력(str_repeat("하", 3), " ", str_strip_prefix("v1.2", "v"))
}
```
```output
ell llo
a+b+c
여백|
LING ling
하하하 1.2
```

### `split(text, sep)`

문자열 리스트를 돌려줍니다. 구분자를 생략하면(또는 `""`를 주면) 줄바꿈으로 나눕니다. 공백을 없애지 않으므로
구분자가 두 번 연달아 나오면 빈 문자열이 생깁니다.

```ling
바인드 start = 실행 {
  출력(split("하나 둘 셋", " "))
  출력(split("a,b,,c", ","))
  출력(길이(split("첫째 줄\n둘째 줄")))
}
```
```output
[하나, 둘, 셋]
[a, b, , c]
2
```

### 문자와 해시

`ord`는 첫 글자의 코드 포인트(빈 텍스트면 `-1`)를 돌려주고, `chr`은 코드 포인트를 한 글자짜리 텍스트로 되돌립니다.
`hash_str`과 `hash_int`는 같은 텍스트에 대해 실행할 때마다 같은 값을 주므로, 이름으로 정해진 색이나 변형을 고를 때 유용합니다.

```ling
바인드 start = 실행 {
  출력(문자코드("A"), " ", 문자(97))
  출력(hash_str("사과") == hash_str("사과"))
  출력(hash_int("apple", 10))
}
```
```output
65 a
true
5
```

## 리스트

### 만들기와 읽기

리스트는 `[1, 2, 3]`처럼 바로 쓰거나, `list_new()`에서 시작해 `list_push`로 항목을 더합니다.
항목은 `xs[i]`(0부터)나 `list_get(xs, i)`로 읽습니다. 차이는 범위를 벗어났을 때입니다.
`list_get`은 `""`를 돌려주고, `xs[i]`는 인터프리터에서 오류가 됩니다. `list_set`은 항목 하나를 바꾼 사본을 돌려주며, 범위 밖의 인덱스는 무시합니다.

```ling
바인드 start = 실행 {
  바인드 목록 = 새목록()
  바인드 목록 = 목록추가(목록, "가")
  바인드 목록 = 목록추가(목록, "나")
  바인드 목록 = 요소설정(목록, 0, "다")
  출력(목록, " ", 길이(목록))
  출력(목록[1], " ", 요소가져오기(목록, 0))
  출력(요소가져오기(목록, 9) == "")
}
```
```output
[다, 나] 2
나 다
true
```

메서드 `xs.push(value)`는 `list_push`와 같은 일을 합니다. 결과는 항상 다시 바인딩하세요. 인터프리터는 원래 리스트를 바꾸지 않지만
기본 백엔드는 제자리에서 바꿀 수도 있으며, 프로그램이 어느 쪽에도 기대서는 안 됩니다.

### 합치기

```ling
바인드 start = 실행 {
  출력(연결(["가", "나", "다"], ", "))
  출력(연결([1, 2, 3], "-"))
  출력(list_cat([1, 2], [3]), " ", list_iota(4))
  출력(list_max([3, 9, 2], 0), " ", list_min([], 0 - 1))
}
```
```output
가, 나, 다
1-2-3
[1, 2, 3] [0, 1, 2, 3]
9 -1
```

### map과 filter 대신 반복문

`list_map`, `list_filter`, `list_find`는 함수를 받는데, 내장 함수에 넘긴 함수는 인터프리터
(`ling run --interp`)에서만 동작합니다. 기본 백엔드는 대신 `()`를 넘깁니다. `list_filter`는 함수가 정확히 `true`를 돌려줄 때만 항목을 남깁니다.

```ling-module
함수 두배(목록) { list_map(목록, |x| x * 2) }
```

`sort`, `slice`, `reverse` 내장 함수도 없습니다. 모두 `while` 반복문으로 할 수 있고, 모든 백엔드에서 동작합니다.
값을 누적할 때는 `for` 대신 `while`을 쓰세요. `for` 본문 안의 `bind`는 바깥 스코프에 닿지 않습니다.

```ling
바인드 start = 실행 {
  바인드 수들 = [3, 1, 2, 4]
  바인드 합계 = 0
  바인드 역순 = 새목록()
  바인드 i = 길이(수들) - 1
  동안 i >= 0 {
    바인드 합계 = 합계 + 수들[i]
    바인드 역순 = 목록추가(역순, 수들[i])
    바인드 i = i - 1
  }
  출력(합계, " ", 역순)
}
```
```output
10 [4, 2, 1, 3]
```
