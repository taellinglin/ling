# 입력과 마이크

Ling은 **폴링**으로 입력을 읽습니다. 매 프레임 루프 안에서 "플레이어가 지금 무엇을 하고
있는지" 묻습니다. 콜백은 없습니다. 이 페이지에서는 키보드와 마우스, 문자 입력, 게임
컨트롤러(`gilrs` 라이브러리와 `ling-input` 크레이트를 통해), 마이크(`ling-mic` 크레이트)를
다룹니다.

장치가 없어도 모든 입력 내장 함수는 안전하게 호출할 수 있습니다. 키와 버튼은 눌리지 않은
것으로, 축은 `0`으로, 마이크는 무음으로 읽힙니다. 그래서 게임은 특별한 처리 없이 키보드로
대신할 수 있습니다. 하드웨어가 있는지 알아보려면 `mic_open`이나 `pad_poll`의 반환값을
확인하세요.

키보드, 마우스, 문자 입력이 이벤트를 받으려면 창이 열려 있어야 합니다. 창이 없으면 아무
일도 없는 상태로 읽힙니다.

```ling
바인드 시작 = 실행 {
  출력(키누름("space"))
  출력(키눌림("enter"))
  출력(mouse_down())
  출력(스크롤())
  출력(마이크RMS())
  출력(실시간FFT(4))
}
```

```output
false
false
false
0
0
[0, 0, 0, 0]
```

## 키보드

### `key_down(name)`과 `key_pressed(name)`

`key_down`은 키를 누르고 있는 동안 계속 참이라 이동에 알맞습니다. `key_pressed`는 키가
눌린 그 한 프레임에만 참이고, 누르고 있어도 반복되지 않습니다. 토글, 메뉴, 한 번 누를
때마다 발사하는 동작에 알맞습니다.

둘 다 소문자 키 이름을 받습니다. 알 수 없는 이름은 그냥 `false`입니다. 다른 창에 포커스가
있는 동안에는 둘 다 `false`입니다. 게임 컨트롤러의 Start 버튼도 `key_pressed("enter")`로
치므로, Enter를 기다리는 메뉴는 패드로도 조작할 수 있습니다.

| 묶음 | 이름 |
|---|---|
| 글자, 숫자 | `"a"`~`"z"`, `"0"`~`"9"` |
| 화살표와 이동 | `"left"`, `"right"`, `"up"`, `"down"`, `"home"`, `"end"`, `"pageup"`, `"pagedown"`, `"insert"`, `"delete"` |
| 편집 | `"space"`, `"enter"`, `"escape"`, `"tab"`, `"backspace"`, `"capslock"` |
| 보조 키 | `"lshift"`, `"rshift"`, `"lctrl"`, `"rctrl"`, `"lalt"`, `"ralt"` |
| 기능 키 | `"f1"`~`"f12"` |
| 숫자 패드 | `"numpad0"`~`"numpad9"`(또는 `"kp0"`~`"kp9"`), `"numpad+"`, `"numpad-"`, `"numpad*"`, `"numpad/"` |
| 문장 부호 | `"minus"`, `"equals"`, `"comma"`, `"period"`, `"slash"`, `"semicolon"`, `"quote"`, `"lbracket"`, `"rbracket"`, `"backslash"`, `"grave"`(기호 자체도 됩니다) |

```ling-gui
바인드 시작 = 실행 {
  창열기(800, 600)
  바인드 x = 400
  바인드 일시정지 = 0
  동안 창열림() {
    만약 키눌림("p") { 바인드 일시정지 = 1 - 일시정지 }
    만약 일시정지 == 0 {
      만약 키누름("left") { 바인드 x = x - 4 }
      만약 키누름("right") { 바인드 x = x + 4 }
    }
    채우기(0, 0, 0)
    색설정(255, 255, 255)
    원채우기(x, 300, 20)
    표시()
  }
}
```

### 문자 입력

이름 입력이나 채팅에는 Ling이 문자를 모아 주게 할 수 있습니다. `text_poll()`은 지난 호출
이후 입력된 키를 텍스트 버퍼에 더하고(Backspace는 지우고, 누르고 있으면 반복) 버퍼 전체를
반환합니다. 입력란이 활성인 동안 매 프레임 한 번 호출하세요. `text_get()`은 폴링 없이
버퍼를 읽고, `text_set(s)`는 바꾸고, `text_clear()`는 비웁니다.

```ling
바인드 시작 = 실행 {
  text_set("에이다")
  출력(text_get())
  text_clear()
  출력("[" + text_get() + "]")
}
```

```output
에이다
[]
```

## 마우스

- `mouse_x()`, `mouse_y()`: 창 안의 커서 위치(픽셀). 창이 생기기 전에는 둘 다 `0`입니다.
- `mouse_down()`, `mouse_down_right()`, `mouse_down_middle()`: 그 버튼을 누르고 있는 동안 참.
  상태만 보므로, 클릭을 감지하려면 이전 프레임의 값과 비교하세요.
- `mouse_scroll()`, `mouse_scroll_x()`: 지난 프레임의 휠 이동량. 가만히 있으면 `0`.
- `mouse_dx()`, `mouse_dy()`: 지난 프레임 이후 마우스가 움직인 거리. `dx`가 양수면 오른쪽,
  `dy`가 양수면 아래쪽입니다. 마우스를 캡처한 동안에만 0이 아닙니다.
- `capture_mouse()`는 커서를 숨기고 상대 이동으로 바꾸므로, 마우스를 아무리 멀리 움직여도
  `mouse_dx`와 `mouse_dy`가 계속 값을 알려 줍니다. 1인칭 시점의 기본입니다.
  `release_mouse()`로 되돌립니다. Esc 키로는 여전히 창이 닫힙니다.
- `cursor_hide()`, `cursor_show()`는 포인터만 숨기거나 보입니다. 위치는 평소대로 추적되므로,
  커서를 직접 그리는 게임에 알맞습니다.

```ling-gui
바인드 시작 = 실행 {
  창열기(800, 600)
  바인드 이전 = 거짓
  동안 창열림() {
    바인드 지금 = mouse_down()
    만약 지금 && !이전 {
      출력("클릭 위치 " + str(mouse_x()) + ", " + str(mouse_y()))
    }
    바인드 이전 = 지금
    채우기(0, 0, 0)
    표시()
  }
}
```

## 게임 컨트롤러

계열이 두 가지 있습니다. 써야 할 것은 **`pad_*`** 계열입니다. 최대 4명, 엣지 감지 버튼,
아날로그 트리거를 지원하고, 데스크톱과 브라우저(W3C Gamepad API 사용)에서 같은 코드로
동작합니다. 이전 **`gamepad_*`** 계열은 가장 최근에 쓴 컨트롤러를 이름으로 읽으며,
컨트롤러를 진동시킬 수 있는 쪽이 이것입니다.

### `pad_*` 계열

무엇이든 읽기 전에 매 프레임 한 번 `pad_poll()`을 호출하세요. 컨트롤러 이벤트를 꺼내고,
엣지 감지를 진행하고, 연결된 패드 수를 반환합니다. 플레이어 슬롯은 `0`~`3`입니다. 첫 호출이
컨트롤러 백엔드를 엽니다. 실패하면 `0`을 반환하고 이후 모든 읽기는 중립 값을 유지합니다.

- `pad_button(player, name)`: 버튼을 누르고 있는 동안 참.
- `pad_pressed(player, name)`: 누른 프레임에만 참. 브라우저 빌드에서는 현재 상태만 알 수
  있어서 `pad_button`처럼 동작합니다.
- `pad_lx`, `pad_ly`, `pad_rx`, `pad_ry`: 스틱 축, `-1`~`1`. 스틱을 **위로** 밀면 `y`가
  **음수**가 되어 화면 방향과 맞습니다. 데드존이 없으므로 작은 값은 직접 무시하세요.
- `pad_lt`, `pad_rt`: 아날로그 트리거, `0`(놓음)~`1`(끝까지 당김).
- `pad_connected(player)`, `pad_count()`: 어느 슬롯이 차 있는지.
- `pad_rumble(player, low, high)`: 현재 데스크톱과 브라우저 모두에서 아무 일도 하지 않습니다.
  진동에는 `gamepad_rumble`을 쓰세요.

버튼 이름은 대소문자를 구분하지 않고, 같은 버튼을 가리키는 이름이 여럿 있습니다.
데스크톱에서 페이스 버튼은 위치로 정해지므로, 어느 제조사든 아래쪽 버튼이 `a`입니다.

| 버튼 | 이름 |
|---|---|
| 아래 페이스 버튼 | `a`, `south`, `cross` |
| 오른쪽 페이스 버튼 | `b`, `east`, `circle` |
| 왼쪽 페이스 버튼 | `x`, `west`, `square` |
| 위 페이스 버튼 | `y`, `north`, `triangle` |
| 숄더 | `lb`, `l1`, `left_shoulder`; `rb`, `r1`, `right_shoulder` |
| 트리거(디지털) | `lt`, `l2`, `left_trigger`; `rt`, `r2`, `right_trigger` |
| 시작 / 선택 | `start`, `menu`, `options`; `select`, `back`, `share`, `view` |
| 가이드 | `guide`, `home` |
| 스틱 누르기 | `l3`, `left_stick`; `r3`, `right_stick` |
| 방향 패드 | `up`/`dpad_up`, `down`/`dpad_down`, `left`/`dpad_left`, `right`/`dpad_right` |

```ling-gui
바인드 시작 = 실행 {
  창열기(800, 600)
  바인드 x = 400.0
  바인드 y = 300.0
  동안 창열림() {
    패드폴링()
    만약 패드연결(0) {
      바인드 x = x + 패드왼X(0) * 5.0
      바인드 y = y + 패드왼Y(0) * 5.0
      만약 패드눌림(0, "a") { 출력("점프") }
    }
    채우기(0, 0, 0)
    색설정(255, 255, 255)
    원채우기(x, y, 20)
    표시()
  }
}
```

### `gamepad_*` 계열

매 프레임 한 번 `gamepad_poll()`을 호출하세요. 가장 최근에 조작한 컨트롤러가 현재
컨트롤러가 됩니다. 브라우저 빌드에서는 `gamepad_poll`과 `gamepad_rumble`이 아무 일도 하지
않으므로, 거기서는 `pad_*`를 쓰세요.

- `gamepad_button(name)`: 누르고 있으면 `1`, 아니면 `0`. 이름: `a`, `b`, `x`, `y`, `l1`, `r1`,
  `l2`, `r2`, `l3`, `r3`, `start`, `select`, `dup`, `ddown`, `dleft`, `dright`.
- `gamepad_axis(name)`: `lx`, `ly`, `rx`, `ry`(스틱, `-1`~`1`)와 `l2`, `r2`(트리거). 여기서는
  스틱을 위로 밀면 `y`가 **양수**가 되어 `pad_ly`와 반대입니다.
- `gamepad_rumble(low, high, ms)`: 무거운 모터(`low`)와 가벼운 모터(`high`)를 각각 `0`~`1`의
  세기로 `ms`밀리초(기본값 200) 동안 진동시킵니다. 포스 피드백이 없는 컨트롤러에서는 아무
  일도 일어나지 않습니다.
- `gamepad_list()`: 시스템이 보는 컨트롤러마다 한 줄씩 이름, 연결 여부, 진동 가능 여부,
  버튼 매핑의 출처를 알려 줍니다. 이상하게 동작하는 컨트롤러를 진단할 때 쓰세요.
- `gamepad_any()`: 표준 버튼 중 하나라도 눌려 있으면 `1`.

```ling-gui
바인드 시작 = 실행 {
  출력(gamepad_list())
  gamepad_poll()
  만약 gamepad_button("a") == 1 {
    gamepad_rumble(0.4, 0.8, 250)
  }
}
```

## 마이크

`mic_open()`은 기본 입력 장치에서 44.1 kHz 모노로 녹음을 시작하고, 성공하면 `1`, 장치가
없거나 접근이 거부되면 `0`을 반환합니다. 한 번만 호출하세요. 그 뒤로 레벨을 읽는 데는
비용이 거의 들지 않습니다.

- `mic_rms()`: 최신 버퍼의 음량(제곱평균제곱근), `0`~`1`.
- `mic_peak()`: 최신 버퍼에서 절댓값이 가장 큰 샘플, `0`~`1`.
- `mic_fft(bands)`: 20 Hz부터 로그 간격으로 나눈 `bands`개(기본값 8) 대역의 평활화된 크기
  리스트. 저음부터 나옵니다. 마이크가 닫혀 있으면 모두 0입니다.

```ling-gui
바인드 시작 = 실행 {
  창열기(640, 240)
  만약 마이크열기() == 0 { 출력("마이크가 없습니다") }
  동안 창열림() {
    바인드 대역 = 실시간FFT(16)
    채우기(0, 0, 0)
    색설정(80, 200, 255)
    바인드 i = 0
    동안 i < 길이(대역) {
      바인드 높이 = 대역[i] * 200.0
      바인드 x = i * 40
      삼각형그리기(x, 230, x + 30, 230, x + 30, 230 - 높이)
      삼각형그리기(x, 230, x + 30, 230 - 높이, x, 230 - 높이)
      바인드 i = i + 1
    }
    표시()
  }
}
```

노래에 점수를 매기려면 마이크와 음악 내장 함수를 함께 쓰세요. `music_mic_pitch()`
(`마이크음정`)가 매 프레임 부른 주파수를 알려 줍니다. [음악](../reference/music.md)을 보세요.

### 시드 녹음하기

`mic_capture()`는 최신 샘플을 녹음 버퍼에 덧붙이고(최근 96000개 샘플 유지) 그 길이를
반환합니다. 녹음하는 동안 매 프레임 호출하세요. `mic_seed()`는 버퍼에 담긴 오디오의
SHA3-256 해시를 16진수 64자로 반환하며, 그대로 난수 생성기의 시드로 쓸 수 있습니다.
`mic_clear()`는 버퍼를 비웁니다. 마이크가 닫혀 있으면 버퍼는 빈 채로 남고, 시드는 빈
입력의 해시가 됩니다.

```ling
바인드 시작 = 실행 {
  출력(mic_capture())
  출력(mic_seed())
  출력(mic_clear())
}
```
