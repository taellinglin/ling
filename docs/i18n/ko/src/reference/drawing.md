# 2D 그리기와 이미지

이 내장 함수들은 창의 프레임 버퍼에 화면 픽셀 단위로 바로 그립니다. 선, 삼각형, 원, 다각형,
그라데이션, 부드러운 그림자, 그리고 파일에서 불러오거나 픽셀 하나하나 만든 이미지를 다룹니다.
모두 열린 창이 필요하며 `fill()`과 `present()` 사이에 두어야 합니다
([창과 카메라](window.md) 참고).

## 2D 그리기의 동작 방식

- **좌표**는 픽셀입니다. 원점은 왼쪽 위 모서리이고, +x는 오른쪽, **+y는 아래**를 향합니다.
  창 밖의 좌표는 그냥 그려지지 않습니다.
- **펜 색.** 도형은 `set_color`로 정한 현재 펜 색으로 그려집니다. 바꿀 때까지 그대로 유지됩니다.
  3D 도형도 이 색을 기본색으로 씁니다.
- **색 값**은 0부터 255까지의 숫자입니다. **범위로 자르지 않습니다.** 런타임은
  `(r << 16) | (g << 8) | b`로 묶으므로, 255를 넘는 값은 옆 채널로 넘칩니다. 음수는 0이 됩니다.
- **즉시 쓰기.** 2D 호출은 픽셀을 곧바로 씁니다. 대기 중인 3D 도형은 나중에 `present()`에서
  그려지므로 2D 그림을 덮습니다. 3D 장면 위에 2D를 그리려면 먼저 `flush_3d()`를 호출하십시오.
- **묶은 색.** 일부 내장 함수는 숫자 하나 `0xRRGGBB`를 받습니다. Ling에는 16진수 리터럴이 없으므로
  `r * 65536 + g * 256 + b`로 쓰십시오(예: `51 * 65536 + 102 * 256 + 255`).

```ling-gui
바인드 start = 실행 {
    창열기(640, 360, "2D")
    동안 창열림() {
        채우기(12, 14, 30)
        색설정(230, 90, 90)
        삼각형그리기(60, 300, 160, 140, 260, 300)
        색설정(90, 200, 255)
        draw_circle(380, 150, 60)
        색설정(120, 255, 160)
        원채우기(520, 150, 40)
        색설정(255, 220, 90)
        draw_arc(380, 280, 50, 0, 3.14159)
        그라데사각(20, 320, 600, 24, 255, 80, 0, 0, 80, 255, 0)
        표시()
    }
}
```

## 펜과 혼합

### `fill(r, g, b)`

프레임 버퍼 전체를 한 색으로 지우고 깊이 버퍼를 초기화합니다. 매 프레임 가장 먼저 호출하십시오.
각 채널의 기본값은 0이므로 `fill()`은 검은색으로 지웁니다. 펜 색은 바꾸지 않습니다.
`clear`는 영어 동의어입니다.

### `set_color(r, g, b)`, `set_color_hsl(h, s, l)`, `mix_color(...)`

`set_color`는 펜 색을 설정합니다(각 채널 기본값 255).

`set_color_hsl`은 도 단위 색상(0~360), 채도와 명도(0~100, 기본값 70과 50)로 설정합니다.
색상을 조금씩 바꾸면 손쉽게 무지개를 만들 수 있습니다.

`mix_color(r0, g0, b0, r1, g1, b1, t)`는 펜을 두 색의 혼합으로 설정하며, `t`는 0부터 1까지입니다
(기본값 0.5). OkLab 색 공간에서 섞기 때문에 중간 색이 탁하지 않고 깨끗합니다.

```ling-gui
바인드 start = 실행 {
    창열기(700, 300, "무지개")
    채우기(0, 0, 0)
    바인드 i = 0
    동안 i < 12 {
        HSL색설정(i * 30, 80, 55)
        원채우기(60 + i * 50, 150, 20)
        바인드 i = i + 1
    }
    표시()
    wait_window()
}
```

### `set_alpha(a)`

0(투명)부터 1(불투명)까지의 펜 불투명도이며 기본값은 1입니다. 그라데이션 채우기와 대기 중인 3D
도형에 적용됩니다.

### `set_blend(mode)`

새 픽셀을 기존 픽셀과 어떻게 합칠지 정합니다. `0`은 일반(기본값), `1`은 가산입니다. 가산 혼합에서는
겹치는 도형이 더 밝아지며, 모든 발광 효과의 바탕이 됩니다. 대기 중인 3D 그리기는 `2` 곱하기,
`3` 스크린, `4` 빼기, `5` 오버레이도 받습니다. 다 쓰면 0으로 되돌리십시오.

```ling-gui
바인드 start = 실행 {
    블렌드모드(1)
    색설정(60, 40, 20)
    원채우기(500, 280, 40)
    원채우기(530, 280, 40)       # 겹친 부분이 더 밝음
    블렌드모드(0)
}
```

### `set_antialias(on)`와 `get_antialias()`

선, 호, 원 윤곽선, 3D 모서리 같은 선 획을 부드럽게 합니다. 기본값은 꺼짐이라 또렷한 픽셀 선이
그려지며, 인수 없이 `set_antialias()`를 호출하면 켜집니다. `get_antialias()`는 설정을 읽어 옵니다.
글자 부드럽게 하기는 별개입니다([폰트와 UI](fonts-ui.md) 참고).

## 도형

### `draw_pixel(x, y)`와 `draw_line(x0, y0, x1, y1)`

`draw_pixel`은 픽셀 하나를 칠합니다. `draw_line`은 두 점 사이에 1픽셀 선을 그리며,
`set_antialias`와 가산 혼합을 따릅니다.

### `triangle(x0, y0, x1, y1, x2, y2)`

채운 삼각형입니다. 사각형은 삼각형 두 개로 만들거나 `draw_poly`를 쓰십시오. `draw_triangle`은
영어 동의어입니다.

```ling-gui
바인드 start = 실행 {
    색설정(230, 90, 90)
    삼각형그리기(100, 100, 300, 100, 300, 200)
    삼각형그리기(100, 100, 300, 200, 100, 200)      # 합치면 사각형
}
```

### `draw_circle(cx, cy, r)`와 `draw_disc(cx, cy, r)`

원 윤곽선과 채운 원으로, 중심과 반지름은 픽셀 단위입니다(반지름 기본값 10). `draw_disc`는 혼합
모드를 따르므로 `set_blend(1)`과 함께 쓰면 빛나는 원이 됩니다.

### `draw_arc(cx, cy, r, a0, a1, segments)`

라디안 각도 `a0`부터 `a1`까지 원의 일부를 그립니다(기본값 0부터 2π, 즉 완전한 원). `segments`는
선택 사항입니다. +y가 아래이므로 각도는 화면에서 **시계 방향**으로 커집니다. 0은 오른쪽,
`pi() / 2`는 바로 아래입니다.

### `draw_poly(points)`

스스로 닫히는 채운 다각형입니다. `points`는 평평한 리스트 `[x0, y0, x1, y1, ...]`입니다.
`project_3d`와 함께 쓰면 투영된 3D 점 사이를 채울 수 있습니다.

```ling-gui
바인드 start = 실행 {
    색설정(200, 140, 255)
    다각형채우기([100, 100, 200, 120, 180, 200, 90, 180])
}
```

### `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)`와 `grad_triangle(...)`

`grad_rect`는 첫 번째 색에서 두 번째 색으로 가는 그라데이션으로 사각형을 채웁니다. `dir`이 `0`이면
왼쪽에서 오른쪽, 그 밖의 값이면 위에서 아래입니다(기본값 1).

`grad_triangle(x0, y0, r0, g0, b0, x1, y1, r1, g1, b1, x2, y2, r2, g2, b2)`는 꼭짓점마다 색을 주고
그 사이를 부드럽게 섞습니다. 값싸게 "조명받은" 면을 만들 수 있습니다.

둘 다 `set_alpha`를 따릅니다. 그라데이션은 기본적으로 지각적으로 섞이며,
`set_gradient_space(0)`으로 일반 sRGB로 바꿀 수 있습니다.

### `shadow_blob`, `cast_shadow`, `shadow_params`

`shadow_blob(cx, cy, rx, ry, alpha)`는 펜 색으로 부드러운 타원을 그립니다(반지름 기본값 16과 8,
`alpha` 기본값 0.5). 어두운 펜이면 평범한 그림자, 다른 색이면 색이 든 그림자가 됩니다.

`cast_shadow(cx, cy, height)`는 지면 위 물체의 높이에 따라 크기와 부드러움이 바뀌는 접촉 그림자를
그립니다. 낮은 물체는 작고 진하고 선명한 그림자, 높은 물체는 크고 옅은 그림자를 얻습니다.
`shadow_params(base, grow, alpha, fade, soft)`로 조정하며, 생략한 인수는 값을 유지합니다.

```ling-gui
바인드 start = 실행 {
    색설정(0, 0, 20)
    그림자드리우기(320, 330, 24)
}
```

### `depth_triangle(x0, y0, x1, y1, x2, y2, z)`와 `depth_line(x0, y0, x1, y1, z)`

2D 삼각형이나 선을 대기열에 넣어 3D 도형과 함께 깊이 정렬한 뒤 `present()`에서 그립니다. `z`가
클수록 멉니다. 3D 물체의 앞뒤를 오가야 하는 2D 스프라이트에 쓰십시오.

### `set_frame_blur(amount)`

잔상 효과입니다. 각 프레임을 이전 프레임의 흐려진 사본과 섞습니다. `amount`는 0부터 0.95까지이며,
약 0.9면 초당 60프레임에서 대략 1초 동안 잔상이 남습니다. `0`이면 꺼집니다.

## 이미지

이미지는 런타임 안의 표에 저장됩니다. 불러오거나 만들 때마다 **핸들**, 즉 다른 `image_*` 내장
함수에 넘기는 작은 숫자를 반환합니다. `-1`은 실패를 뜻합니다.

| 내장 함수 | 용도 |
|---|---|
| `image_load(path)` | PNG, JPEG 등 래스터 이미지를 불러옴. 핸들 또는 `-1` |
| `image_draw(id, x, y, w, h)` | `w` x `h` 픽셀로 늘려 그리기 |
| `image_new(w, h)` | 새 투명 이미지 |
| `image_set_pixel(id, x, y, r, g, b, a)` | 픽셀 하나 칠하기 |
| `image_pixel_r(id, x, y)`, `_g`, `_b`, `_a` | 채널 하나 읽기(0~255) |
| `image_width(id)`, `image_height(id)` | 픽셀 단위 크기 |
| `image_save(id, path)` | PNG로 쓰기. `1` 또는 `-1` |
| `image_replace(id, path)` | 기존 핸들에 새 파일 불러오기 |
| `image_tint(id, color)` | 알파 모양을 따른 단색 사본 |
| `image_resized(id, w, h)` | 크기를 바꾼 사본 |
| `image_svg(svg_text, w, h)` | SVG 소스 텍스트를 이미지로 렌더링 |
| `image_free(id)` | 픽셀 해제 |

### `image_load(path)`

래스터 이미지를 불러와 핸들을 반환하고, 파일을 읽을 수 없으면 `-1`을 반환합니다(오류 스트림에
메시지가 나옴). 경로는 주어진 그대로 먼저 시도하고, 다음으로 스크립트 폴더 기준으로 시도합니다.
같은 경로를 다시 불러오면 캐시된 핸들을 반환하므로 프레임 루프 안에서 호출해도 안전합니다.

### `image_draw(id, x, y, w, h, cx, cy, cw, ch, opacity)`

이미지의 왼쪽 위 모서리를 `x, y`에 두고 `w` x `h` 픽셀로 (최근접 이웃 방식으로) 늘려서, 프레임 위에
알파 혼합으로 그립니다. **`w`와 `h`는 필수입니다.** 0이면 아무것도 그려지지 않으므로, 원래 크기로
그리려면 `image_width(id)`와 `image_height(id)`를 넘기십시오. 선택 사항으로, 그 밖에는 그리지 않는
클리핑 사각형 `cx, cy, cw, ch`와 그 뒤에 0부터 1까지의 `opacity`를 줄 수 있습니다. 이미지는 후처리가
3D에 적용하는 툰 셰이딩 없이 그대로 표시됩니다.

```ling-gui
바인드 start = 실행 {
    창열기(640, 400, "스프라이트")
    바인드 영웅 = image_load("hero.png")
    바인드 x = 0
    동안 창열림() {
        채우기(20, 24, 40)
        만약 영웅 >= 0 {
            image_draw(영웅, x, 160, image_width(영웅) * 2, image_height(영웅) * 2)
        }
        표시()
        바인드 x = (x + 2) % 640
    }
}
```

### `image_new`, `image_set_pixel`, 픽셀 읽기 함수

`image_new(w, h)`는 완전히 투명한 빈 이미지를 만듭니다. `image_set_pixel(id, x, y, r, g, b, a)`는
픽셀 하나를 칠합니다(`a` 기본값 255). `image_pixel_r`, `image_pixel_g`, `image_pixel_b`,
`image_pixel_a`는 픽셀의 채널 하나를 읽습니다. 범위를 벗어난 위치와 잘못된 핸들은 쓸 때 무시되고
읽을 때 0이 됩니다. 이 함수들은 창 없이도 동작합니다.

```ling
바인드 start = 실행 {
    바인드 그림 = image_new(8, 4)
    image_set_pixel(그림, 2, 1, 255, 128, 0)
    println("크기: " + str(image_width(그림)) + " x " + str(image_height(그림)))
    println("픽셀: " + str(image_pixel_r(그림, 2, 1)) + ", " + str(image_pixel_g(그림, 2, 1)))
    println("투명: " + str(image_pixel_a(그림, 0, 0)))
    바인드 파랑 = image_tint(그림, 51 * 65536 + 102 * 256 + 255)
    println("색조: " + str(image_pixel_b(파랑, 2, 1)))
}
```

```output
크기: 8 x 4
픽셀: 255, 128
투명: 0
색조: 255
```

`image_pixel_u16(id, x, y)`는 16비트 높이 맵용으로 `r * 256 + g`를 한 번에 반환합니다.

### `image_save(id, path)`와 `image_replace(id, path)`

`image_save`는 (불러왔거나 만든) 이미지를 알파를 유지한 채 파일로 쓰고, 없는 폴더는 만듭니다.
경로는 프로그램을 실행한 곳 기준입니다. `1`을, 실패하면 `-1`을 반환합니다. `image_replace`는 새 파일을
기존 핸들에 디코딩하므로, 자주 다시 불러오는 그림 때문에 이미지 표가 커지지 않습니다. `1` 또는 `-1`을
반환합니다.

창 자체를 저장하려면 `screenshot`을 쓰십시오([창과 카메라](window.md) 참고).

### `image_tint`, `image_resized`, `image_svg`, `image_free`

`image_tint(id, color)`는 원본의 알파 모양을 따라 묶은 색 하나로 칠한 새 이미지를 반환합니다. 아이콘을
아무 색으로나 다시 칠할 수 있습니다. `image_resized(id, w, h)`는 크기를 바꾼 사본을 반환합니다.
`image_svg(svg_text, w, h)`는 경로가 아니라 SVG **소스 텍스트**를 새 이미지로 렌더링합니다. 파일은 먼저
`read_file`로 읽으십시오. 세 함수 모두 새 핸들이나 `-1`을 반환합니다.

`image_free(id)`는 이미지의 픽셀을 해제합니다. 핸들은 유효하게 남지만 아무것도 그리지 않습니다.

## 텍스트

텍스트에는 벡터 폰트나 내장 스트로크 폰트를 쓰며, 둘 다 [폰트와 UI](fonts-ui.md)에 있습니다.
폰트 파일 없이 화면에 라벨을 가장 빨리 띄우는 방법은 다음과 같습니다.

```ling-gui
바인드 start = 실행 {
    색설정(120, 255, 160)
    UI텍스트(30, 30, 16, "SCORE 0420")
}
```

`ui_text`는 글자를 대문자로 그리고 기본 ASCII 문자만 압니다. 그 밖의 문자는 작은 상자로 나옵니다.
다른 문자 체계에는 `font_load`로 폰트를 불러와 `font_text_fill`로 그리십시오.
