# 3D 도형과 메시

이 내장 함수들은 3D 장면에 물체를 넣습니다. 스무 가지가 넘는 매개변수형 입체, 날것의 삼각형과 선,
평면에 까는 `vtex_*` 벡터 무늬, `tex_*` 픽셀 텍스처, 그리고 파일에서 불러오는 메시(Ling 고유 형식과
glTF)를 다룹니다. 모두 열린 창과 [창과 카메라](window.md)의 카메라가 필요합니다. 조명, 셰이딩
스타일, 후처리는 [포스트 FX와 조명](postfx.md)에 있습니다.

3D 호출은 즉시 그리지 않습니다. **깊이 대기열**에 들어가 `present()`(또는 `flush_3d()`)에서 정렬되어
그려지므로, 한 프레임 안에서는 어떤 순서로 호출해도 됩니다.

## 기본 입체

모든 입체는 같은 인수를 받습니다.

```text
name(cx, cy, cz,  sx, sy, sz,  rx, ry, rz,  mode,  e0, e1, e2)
```

| 인수 | 의미 |
|---|---|
| `cx, cy, cz` | 월드 좌표의 중심 |
| `sx, sy, sz` | 축별 배율(기본값 1). 도형의 반지름이 약 한 단위이므로 배율은 대략 크기의 절반입니다. `cube(0, 0, 8, 1, 1, 1)`은 한 변이 2인 정육면체입니다 |
| `rx, ry, rz` | 라디안 단위 회전(기본값 0). X, Y, Z 순으로 적용 |
| `mode` | `0` 채움(기본값), `1` 와이어프레임, `2` 둘 다 |
| `e0, e1, e2` | 도형별 추가 인수(아래 표 참고). 0이나 생략은 기본값 |

위치만 필수이며 뒤쪽 인수는 생략할 수 있습니다. 펜 색(`set_color`)이 채움과 와이어 색이 됩니다.
입체는 장면의 조명을 받고 툰 스타일로 셰이딩됩니다.

+y가 아래를 향한다는 점을 기억하십시오. `cone`은 꼭짓점이 +y에 있어서, 회전하지 않으면 화면 아래를
가리킵니다. x축으로 π만큼 회전하면 뒤집힙니다. `gear`와 `torus`는 x-z 평면에 놓여 있으므로, 카메라를
향하게 하려면 x축으로 약 1.57 회전하십시오.

```ling-gui
바인드 start = 실행 {
    창열기(900, 600, "도형")
    깊이테스트(1)
    바인드 n = 0
    동안 창열림() {
        채우기(8, 10, 24)
        카메라설정(1, 0, 1, 0)
        조명초기화()
        조명추가(-2, -6, -2, 1.0, 0.95, 0.85, 0.6, 0)
        바인드 각 = n * 0.03
        색설정(230, 120, 90)
        정육면체(-2.8, 0, 7.5, 0.8, 0.8, 0.8, 각, 각 * 0.7, 0, 0)
        색설정(120, 200, 255)
        구(0, 0, 7.5, 0.9, 0.9, 0.9, 0, 0, 0, 0)
        색설정(190, 190, 200)
        톱니바퀴(2.8, 0, 7.5, 0.9, 0.3, 0.9, 1.57, 각 * 2, 0, 0, 14, 0.3)
        표시()
        바인드 n = n + 1
    }
}
```

### 입체별 참고 사항

- **`cylinder`**는 로컬 y를 따라 -1부터 1까지 뻗으므로 높이가 `2 * sy`입니다. `sy`를 0.05처럼 작게
  하면 원판이나 접시가 됩니다.
- **`torus`**: `tube`는 바깥 반지름에 대한 관 반지름의 비율입니다(0.02~0.9).
- **`frustum`**: 윗면 비율은 밑면 반지름에 대한 윗면 반지름입니다. 0에 가까우면 원뿔, 1이면 원기둥이며,
  비율을 작게 하고 `sy`를 크게 하면 오벨리스크가 됩니다.
- **`gear`**: 두께는 `sy`에서 나옵니다. 톱니 수는 3~96, 톱니 깊이는 0.02~0.6입니다.
- **`stairs`**: 계단마다 +y와 +z로 한 칸씩 더 나아갑니다. +y가 아래이므로 멀어질수록 내려가는 것처럼
  보입니다. `rz`로 π만큼 회전하면 뒤집힙니다.
- **`gyro`**는 축을 번갈아 가며 짐벌 고리를 겹치고, **`capsule_chain`**은 x를 따라 구슬을 늘어놓습니다.
- 주사위 도형(`tetrahedron`~`icosahedron`)은 `mode` 2와 밝은 색을 주면 보석처럼 보입니다.

```ling-gui
바인드 start = 실행 {
    색설정(255, 140, 180)
    정이십면체(0, 0, 8, 1, 1, 1, 0.4, 0.7, 0, 2)
    원뿔(3, 0, 8, 0.8, 1, 0.8, 3.14159, 0, 0, 0)       # 꼭짓점이 위로
}
```

## 삼각형, 선, 깊이 테스트

| 내장 함수 | 中文 | 日本語 | 한국어 | ไทย | 용도 |
|---|---|---|---|---|---|
| `draw_triangle_3d(ax, ay, az, bx, by, bz, cx, cy, cz)` | — | — | — | — | 조명받는 삼각형 하나 |
| `draw_quad_3d(...)`, `draw_polygon_3d(...)` | — | — | — | — | 조명받는 볼록 다각형 |
| `draw_line_3d(ax, ay, az, bx, by, bz)` | — | — | — | — | 깊이 정렬되는 선 |
| `set_depth_test(on)` | `深度测试` | `深度テスト` | `깊이테스트` | `ทดสอบความลึก` | 픽셀 단위 깊이 버퍼 |
| `clear_depth()` | — | — | — | — | 프레임 도중 깊이 버퍼 지우기 |

### `draw_triangle_3d`, `draw_quad_3d`, `draw_polygon_3d`

월드 공간 도형을 펜 색으로, 조명과 안개를 적용하고 근평면에서 잘라 그립니다. `draw_triangle_3d`는 점
세 개를 받으며, 감기 순서가 어느 면이 빛을 향하는지 정합니다. `draw_quad_3d`는 `x, y, z` 세 쌍 네 개
(숫자 12개)를 받고, `draw_pent_3d`와 `draw_hex_3d`는 5개와 6개를 받습니다. 이들은 `draw_polygon_3d`와
구현을 공유하며, `draw_polygon_3d`는 평평한 리스트 `[x0, y0, z0, x1, y1, z1, ...]` 하나도 받습니다.
꼭짓점은 최대 8개까지 쓰입니다.

```ling-gui
바인드 start = 실행 {
    색설정(120, 200, 255)
    draw_quad_3d(-2, 1, 8, 2, 1, 8, 2, 1, 12, -2, 1, 12)     # 바닥 타일
    draw_polygon_3d([0, -1, 8, 1, 0, 8, 0, 1, 8, -1, 0, 8])  # 마름모
}
```

### `draw_line_3d(ax, ay, az, bx, by, bz)`

월드의 두 점 사이의 선으로, 다른 도형과 함께 깊이 정렬되고 근평면에서 잘립니다. 부드러운 선을 원하면
`set_antialias(1)`을 쓰십시오.

### `set_depth_test(on)`와 `clear_depth()`

깊이 테스트는 기본적으로 꺼져 있어서 대기 중인 도형을 먼 것부터 가까운 것 순으로 칠합니다. 입체가 서로
겹칠 수 있을 때, 그리고 앰비언트 오클루전, 윤곽선, 피사계 심도를 쓸 때는 켜십시오(`1`). `fill()`이 이미
매 프레임 깊이 버퍼를 지우므로, `clear_depth()`는 프레임 도중에 새 깊이 패스를 시작할 때 씁니다.

## 벡터 무늬: `vtex_*`

각 `vtex_*` 호출은 **3D 공간의 평면** 위에 움직이는 선 무늬를 그립니다. 앞의 아홉 인수는 모두 같고,
마지막 두 인수는 언제나 `fr`과 `hue`입니다.

```text
vtex_name(cx, cy, cz,  ux, uy, uz,  vx, vy, vz,  ...무늬 인수...,  fr, hue)
```

`cx, cy, cz`는 중심입니다. `u`는 무늬에서 "오른쪽"이 향하는 방향, `v`는 "위쪽"이 향하는 방향입니다.
`fr`은 직접 넘기는 프레임 카운터로 색과 움직임을 구동하고, `hue`는 색을 어긋나게 해서 이웃한 무늬가
서로 달라 보이게 합니다. 색은 저절로 무지개를 돌며 펜 색은 쓰지 않습니다.

| 평면 | `u` | `v` |
|---|---|---|
| 바닥 또는 천장 | `1, 0, 0` | `0, 0, 1` |
| 카메라를 향한 벽, 똑바로 | `1, 0, 0` | `0, -1, 0` |
| 옆벽, 똑바로 | `0, 0, 1` | `0, -1, 0` |

+y가 아래이므로 똑바로 선 무늬는 `v = (0, -1, 0)`을 씁니다. 무늬는 단순한 선분이라 가볍고, 카메라 쪽으로
살짝 당겨 그려지므로 같은 자리의 면 위에 올라갑니다.

| 내장 함수 | 中文 | 日本語 | 한국어 | ไทย | 무늬 인수(기본값) |
|---|---|---|---|---|---|

## 픽셀 텍스처: `tex_*`

`tex_*` 내장 함수는 화면의 사각형을 절차적 무늬로 한 픽셀씩 **즉시** 채웁니다. 다른 2D 호출처럼
대기 중인 3D 도형에 덮입니다. 모두 픽셀 단위 사각형 `x, y, w, h`로 시작합니다(기본값 0, 0, 256, 256).

호출할 때마다 모든 픽셀을 계산하므로 큰 텍스처는 느립니다. 작게 유지하거나, 한 번 그린 뒤 화면에 그대로
두십시오.

`palette`를 받는 곳에서는 `"rainbow"`, `"fire"`, `"ocean"`, `"psychedelic"`, `"neon"`, `"forest"` 중
하나를 씁니다. 모르는 이름은 rainbow로 처리됩니다.

| 내장 함수 | 용도 |
|---|---|
| `tex_checkerboard(x, y, w, h, tiles, r1, g1, b1, r2, g2, b2)` | 두 색 체커보드(타일 8개, 흰색과 검은색) |
| `tex_gradient(x, y, w, h, angle_deg, r1, g1, b1, r2, g2, b2)` | 각도를 따른 선형 그라데이션(0은 왼쪽에서 오른쪽) |
| `tex_noise(x, y, w, h, scale, octaves, seed, palette)` | 프랙탈 노이즈(scale 4, octaves 1~8) |
| `tex_spiral(x, y, w, h, freq, bands, time, palette)` | `time`에 따라 도는 나선 띠 |
| `tex_ripple(x, y, w, h, freq, cx, cy, time, palette)` | `cx, cy`(사각형 안에서 0~1)에서 퍼지는 물결 |
| `tex_mandelbrot(x, y, w, h, zoom, cx, cy, max_iter, palette)` | 망델브로 집합 |
| `tex_julia(x, y, w, h, c_re, c_im, max_iter, palette)` | 쥘리아 집합(c = -0.7 + 0.27i) |
| `tex_voronoi(x, y, w, h, cells, seed, palette)` | 보로노이 셀(셀 16개) |
| `tex_halftone(x, y, w, h, dot_size, time, palette)` | 하프톤 점 |
| `tex_freq_map(x, y, w, h, time, speed, palette)` | 마지막 `fft_bands` 호출의 스펙트럼([오디오](audio.md) 참고) |

`tex_mandelbrot`은 복소 평면을 양 방향으로 `1 / zoom` 단위만큼 보여 주므로, `zoom` 1은 주 카디오이드만
보입니다. 집합 전체를 보려면 약 0.4를 쓰십시오.

```ling-gui
바인드 start = 실행 {
    창열기(660, 340, "tex")
    채우기(0, 0, 0)
    tex_checkerboard(10, 10, 200, 150, 8, 240, 240, 240, 30, 30, 60)
    tex_noise(230, 10, 200, 150, 5, 4, 7, "fire")
    tex_mandelbrot(450, 10, 200, 150, 0.4, -0.5, 0, 64, "psychedelic")
    표시()
    wait_window()
}
```

## 메시

Ling은 리스트로 만든 메시, 고유한 바이너리 메시 형식, glTF 모델을 그릴 수 있습니다. 모두 카메라로
투영되어 3D 장면의 나머지와 함께 대기열에 들어갑니다.

### `draw_mesh(positions, indices, ox, oy, oz, scale, mode)`

두 리스트에 저장된 삼각형 메시를 그립니다. `positions`는 평평한 `[x0, y0, z0, x1, y1, z1, ...]`이고,
`indices`는 삼각형마다 꼭짓점 번호 세 개를 나열합니다. 모든 꼭짓점은 `scale`(기본값 1)로 배율이 적용되고
`ox, oy, oz`만큼 이동합니다. `mode` `0`은 펜 색으로 조명을 주고, `1`은 삼각형마다 무지개 색을 줍니다.
잘못된 인덱스는 무시됩니다.

```ling-gui
바인드 start = 실행 {
    바인드 위치 = [0, -1, 8, 1, 1, 8, -1, 1, 8, 0, 0, 10]
    바인드 색인 = [0, 1, 2, 0, 2, 3, 0, 3, 1]
    색설정(200, 160, 255)
    draw_mesh(위치, 색인, 0, 0, 0, 1, 0)
}
```

### `mesh_load(path)`와 `mesh_draw(id, x, y, z, scale, yaw)`

`mesh_load`는 `.lmesh` 파일(삼각형마다 단색 하나를 가진 간결한 형식)을 읽어 핸들이나 `-1`을 반환합니다.
`mesh_draw`는 그 메시를 자체 색 그대로 **조명 없이**, 위치, 균일 배율, 요 각도를 적용해 그립니다.
그 뒤의 선택 인수(`sway`, `arm`, `lean`, `leg`, `tuck`, 기본값 0)는 캐릭터 메시를 변형합니다. `sway`는
상체를 기울이고 `arm`은 팔을 흔듭니다. `mesh_free(id)`는 도형 데이터를 해제합니다. `mesh_load`의 별칭:
zh `载入网格`, ja `メッシュ読込`, ko `메시로드`, th `โหลดเมช`.

### glTF 모델: `gltf_*`

`gltf_load(path)`는 `.glb`나 `.gltf` 파일을 스켈레톤, 스킨, 애니메이션까지 읽어 핸들이나 `-1`을
반환합니다. glTF는 Y가 위쪽이지만, 그리기 호출이 알아서 Ling의 Y가 아래인 월드로 뒤집어 줍니다.

| 내장 함수 | 용도 |
|---|---|
| `gltf_load(path)` | 모델 불러오기. 핸들 또는 `-1` |
| `gltf_draw(h, x, y, z, scale, yaw)` | 기본 자세로 조명을 주어 그리기 |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | 애니메이션 클립의 `time`초 자세로 텍스처를 입혀 그리기 |
| `gltf_anim_count(h)`, `gltf_anim_name(h, i)`, `gltf_anim_dur(h, i)` | 애니메이션 클립: 개수, 이름, 초 단위 길이 |
| `gltf_bounds(h, clip, time)` | 그려진 모습의 `[minx, miny, minz, maxx, maxy, maxz]`(glTF 공간) |
| `gltf_tris(h)` | 삼각형 수 |
| `gltf_mesh_count(h)`, `gltf_mesh_name(h, i)` | 모델의 메시들 |
| `gltf_mesh_show(h, i, on)` | 이후 그리기에서 메시 하나를 보이거나 숨기기(장비, 의상) |
| `gltf_mesh_tint(h, i, color)` | 메시 하나에 묶은 색을 곱하기 |
| `gltf_joint_count(h)`, `gltf_joint_name(h, j)` | 스켈레톤 뼈대 |

`gltf_bounds`에서는 y가 위쪽이므로, 지면 높이 `gy`에 배율 `s`로 그린 모델의 꼭대기는 `gy - maxy * s`에
있습니다.

```ling-gui
바인드 start = 실행 {
    창열기(800, 600, "모델")
    깊이테스트(1)
    바인드 여우 = gltf_load("models/fox.glb")
    바인드 클립 = 0
    동안 창열림() {
        채우기(20, 24, 40)
        조명초기화()
        조명추가(-3, -6, 2, 1.0, 1.0, 1.0, 1.0, 0)
        만약 여우 >= 0 {
            바인드 재생길이 = gltf_anim_dur(여우, 클립)
            gltf_anim_draw_tex(여우, 0, 2, 8, 0.02, 현재시간(), 클립, 현재시간() % 최댓값(재생길이, 0.01))
        }
        표시()
    }
}
```

## 텍스처 메시: `tm_*`

`tm_*` 계열은 3D 게임용 텍스처 도형을 그립니다. 텍스처와 메시는 각각 핸들을 받습니다.

| 내장 함수 | 용도 |
|---|---|
| `tm_tex_load(path, size)` | PNG, SVG, SVGZ를 `size` 픽셀(기본값 256) 정사각형 텍스처로 불러옴. id 또는 `-1` |
| `tm_load(path)` | `.ltm` 메시(이름 붙은 텍스처 삼각형 그룹들)를 불러옴. id 또는 `-1` |
| `tm_groups(m)`, `tm_group(m, name)`, `tm_group_name(m, g)`, `tm_group_tris(m, g)` | 메시의 그룹 살펴보기 |
| `tm_bounds(m, g)` | 그룹 하나(`g = -1`이면 전체)의 `[minx, miny, minz, maxx, maxy, maxz]` |
| `tm_edges(m, g, max)` | 미니맵과 와이어프레임용 윤곽 모서리를 평평한 선분 리스트로 |
| `tm_draw(m, g, tex, x, y, z, scale, rot, tint, alpha, ...)` | 그룹을 텍스처 삼각형으로 대기열에 넣기 |
| `tm_sprite(tex, cx, cy, w, h, rot, tint, alpha, blend)` | 화면에 바로 그리는 회전된 텍스처 사각형 |
| `tm_billboard(tex, x, y, z, size, rot, tint, alpha, blend)` | 3D에서 카메라를 향하는 텍스처 정사각형 |
| `tm_quad(tex, x, y, z, ux, uy, uz, vx, vy, vz, tint, alpha, blend)` | 아무 방향의 텍스처 사각형(데칼) |
| `tm_wire(kind, x, y, z, size, rx, ry, rz, color, detail, thick)` | 와이어프레임 도형 |
| `tm_solid(kind, x, y, z, size, rx, ry, rz, color, alpha, blend)` | 면마다 평평하게 셰이딩한 결정 입체 |

공통 규칙: `tint`와 `color`는 묶은 `0xRRGGBB` 숫자(기본값 흰색), `alpha`는 0부터 1까지, `blend`는 `0`
일반 또는 `1` 가산입니다. 텍스처 id가 `-1`이면 내장된 부드러운 빛 점을 뜻하며, `tm_quad`에서 `-2`는
부드러운 둥근 그림자입니다.

- **`tm_draw`**는 이어서 `uoff, voff, uscale, vscale`(텍스처 스크롤과 배율), `shade`(0~1, 빛을 등진 면을
  어둡게), `blend`, `cull`(`0` 없음, `1` 또는 `2` 한쪽 감기 방향)을 받습니다. `rot`는 요 각도이거나 행 우선
  3 x 3 리스트입니다. 대기열에 넣은 삼각형 수를 반환합니다.
- **`tm_sprite`**는 2D 프레임 버퍼에 그리므로, HUD나 타이틀 카드라면 `flush_3d()` 다음에 호출하십시오.
- **`tm_wire`** 종류: `0` 정육면체, `1` 정사면체, `2` 정팔면체, `3` 정이십면체, `4` 토러스, `5` 구,
  `6` 고리, `7` 별기둥, `8` 격자. `size`는 반지름이고, `thick` 1은 획을 두 겹으로 그립니다.
- **`tm_solid`** 종류: `0` 정육면체, `1` 정사면체, `2` 정팔면체, `3` 정이십면체, `9` 파편(늘인 정팔면체).

```ling-gui
바인드 start = 실행 {
    창열기(800, 600, "결정")
    바인드 t = 0.0
    동안 창열림() {
        채우기(6, 8, 20)
        블렌드모드(1)
        tm_wire(3, -2, 0, 8, 1, t, t * 0.7, 0, 65535, 12, 1)
        블렌드모드(0)
        tm_solid(9, 2, 0, 8, 0.8, 0, t, 0, 16744576, 0.8, 1)
        표시()
        바인드 t = t + 0.02
    }
}
```
