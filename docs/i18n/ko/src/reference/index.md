# 개요

내장 함수는 Ling에 처음부터 들어 있는 함수입니다. 출력, 수학, 텍스트, 파일, 창, 소리, 웹 서버 등 많은 것이 있습니다.
이 섹션에서는 내장 함수를 주제별로 정리하고, 언어별 이름, 받는 값과 돌려주는 값, 그리고 바로 실행해 볼 수 있는 짧은 예제를 보여 줍니다.

## 내장 함수의 동작 방식

**언제나 쓸 수 있습니다.** 내장 함수는 가져올 필요가 없습니다. 프로그램 어디서든 이름으로 호출하세요.

```ling
바인드 start = 실행 {
  출력(제곱근(16) + 최댓값(2, 5))
}
```
```output
9
```

**인수는 위치로 전달합니다.** 인수에는 이름이 없으며 순서가 중요합니다. 끝쪽 인수를 생략하면 대개 오류 대신
문서에 적힌 기본값이 쓰입니다. 그래서 `clamp(1.5)`는 0..1 범위로 제한합니다.

**실패도 값입니다.** 대부분의 내장 함수는 확인할 수 있는 값을 돌려주어 문제를 알립니다: `false`, `0`, `-1`, 빈 리스트,
또는 `bad(...)` 결과입니다. 어떤 값인지는 항목마다 적혀 있습니다. 실패하는 방식이 복잡한 내장 함수는 `ok(value)`나 `bad(reason)`을 돌려줍니다.
[오류와 결과](../language/errors.md)를 보세요.

**다섯 가지 언어의 이름.** 많은 내장 함수에는 영어 외에도 중국어, 일본어, 한국어, 태국어 이름이 있습니다. 모두 같은 함수를 호출하며,
영어 이름은 어떤 파일에서든, 다른 어떤 언어와 섞어 써도 항상 동작합니다.

```ling
바인드 start = 실행 {
  print(sqrt(16))
  印(根(16))
  印刷(平方根(16))
  출력(제곱근(16))
  พิมพ์(รากที่สอง(16))
}
```
```output
4
4
4
4
4
```

`lingfu normalize --to <lang>`은 프로그램의 키워드와 내장 함수를 한 언어로 다시 씁니다. [다섯 가지 언어로 작성하기](../language/multilingual.md)를 보세요.
런타임은 다른 언어(프랑스어, 독일어, 러시아어, 아랍어, 페르시아어, 히브리어, 우르두어)의 이름도 일부 알고 있지만,
이 페이지들에는 문서화된 다섯 가지 언어만 싣습니다.

## 프로필

`cargo install ling-lang`은 모든 내장 함수가 들어 있는 `full` 프로필을 설치합니다. 더 작은
[프로필](../getting-started/install.md)로 설치했다면 일부 내장 함수 계열이 빌드에서 빠집니다.
그런 함수를 호출하면 추가해야 할 프로필을 알려 주는 오류와 함께 프로그램이 멈춥니다.

```text
'http_get' needs the `web` profile, which this build of ling leaves out (reinstall with: cargo install ling-lang --features web, or the default full install)
```

| 프로필 | 내장 함수 계열(예) |
|---|---|
| `core` | 출력, 텍스트, 파일 페이지(프로세스 제외), 창, 2D 그리기, 폰트, 이미지, 메시 |
| `web` | `http_*`, `db_*`, `zip_*`, `tar_gz_*`, `video_*`, `run_process`, `proc_*`, 해시와 암호 |
| `privacy` | `p2p_*`, `lingtp_*`, `ssh_*`, `lw_*` |
| `game` | `rb_*`, `soft_*`, `liquid_*`, `gltf_*`, `gpu_*`, `body_*`, `pad_*`, `dialog_*`, `ui_*` |
| `ai` | `nn_*`, `bt_*`, `stt_*`, 학습형 대화 모델 |
| `audio` | `audio_*`, `music_*`, `mic_*`, `fft_*` |

`llm_*`(로컬 언어 모델)이나 `vision_*` 같은 무거운 추가 기능은 어떤 프로필 위에든 따로 선택해서 넣습니다.

## 페이지 읽는 법

레퍼런스 페이지는 모두 같은 구성입니다.

1. 페이지 전체에 적용되는 규칙을 설명하는 소개.
2. **요약 표.** 첫 열은 `clamp(x, low, high)` 같은 시그니처입니다. 언어 열에는 현지화된 이름이 있으며,
   `—`는 아직 현지화된 이름이 없다는 뜻이니 영어 이름을 쓰세요. 번역된 페이지에서는 읽고 있는 언어의 열만 보입니다.
3. **내장 함수나 그룹마다 하나의 절**: 매개변수, 반환값, 주의할 점, 예제.

`ling`으로 표시된 예제는 `ling run`으로 실행한 것이며, 아래에 보이는 출력은 실제 결과입니다. 창, 소리, 네트워크, 서버가 필요한 예제는
문법만 검사하므로 출력 블록이 없습니다. `start` 블록이 없는 조각은 더 큰 프로그램의 일부입니다.

Ling에는 두 가지 백엔드가 있습니다. 기본 컴파일 백엔드와 인터프리터(`ling run --interp`)입니다.
인수로 넘긴 함수가 인터프리터에서만 동작하는 것처럼 둘의 동작이 다른 곳은 항목에 적혀 있습니다. [알려진 제한 사항](../language/limits.md)에 이런 차이를 모아 두었습니다.
