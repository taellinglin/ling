# 오디오

오디오 엔진은 게임에 필요한 소리를 모두 냅니다. 3D 공간에 놓인 지속음, 짧은 비프음과 효과음, 샘플 파일, 반복되는 배경 음악, 마스터 이펙트 체인입니다. 별도의 FFT 분석기는 샘플 데이터를 주파수 대역으로 바꿔, 소리에 반응하는 시각 효과를 만들 수 있게 합니다.

곡 전체, 악기 패치, MIDI, DAW는 [음악](music.md)을 보세요. 마이크는 [입력과 마이크](input.md)를 보세요.

먼저 알아 둘 것:

- 런타임은 프로그램이 시작될 때 오디오 장치를 엽니다. 출력 장치가 없으면 `audio_*` 내장 함수는 조용히 아무것도 하지 않습니다.
- 시간 단위는 초입니다. 시그니처에서 기본값이 적힌 지점부터 뒤의 인자는 생략할 수 있습니다.
- 오디오는 네이티브 전용입니다. 브라우저 빌드에서는 FFT 내장 함수가 아무것도 하지 않고, 일부 호출은 인자를 더 적게 받습니다(아래에 적어 두었습니다).
- 이 예제들은 소리를 내므로 `ling-gui` 프로그램입니다. 맨 끝의 FFT 예제는 어디서나 실행됩니다.

## 엔진의 믹싱 방식

출력 스트림 하나에 네 종류의 소리가 실립니다.

- **지속음**: 번호가 붙은 슬롯에 있는 오래 사는 발진기로, 공간에 놓입니다(`audio_tone`).
- **단발음**: 비프음(`audio_blip`, `ui_sound`), 위치가 있는 효과음(`audio_sfx`), 모프 음(`morph_note`).
- **샘플**: 디코드한 파일을 3D 또는 평면으로 재생합니다(`audio_sample_*`).
- **배경 음악**: 반복되는 WAV 하나(`audio_bgm`).

청취자는 카메라입니다. 팬은 카메라에 대한 소리 위치로 정하는 등전력 좌우 팬이고, 크기는 거리에 따라 줄어듭니다. `set_camera_pos`는 청취자를 옮기고, `audio_listener`는 돌립니다. 최종 믹스는 소프트 클리핑되므로, 큰 믹스도 딱 잘리지 않고 부드럽게 일그러집니다.

지속음 슬롯은 필요할 때 늘어납니다. 비프음 보이스는 32개, 효과음 보이스 64개, 모프 보이스 32개, 샘플 보이스 64개이며, 풀이 가득 차면 가장 오래된 보이스가 빠집니다.

## 음량과 배경 음악

### `audio_volume(level)`

이 엔진이 믹싱하는 모든 소리의 마스터 게인입니다(기본값 0.7, 1.0이 원래 크기). 음악 엔진에는 영향이 없으며, 그쪽은 `music_volume`을 따로 씁니다.

### `audio_bgm(path, volume)`과 `audio_bgm_volume(level)`

`audio_bgm`은 **WAV** 파일을 불러와 배경 음악으로 반복합니다(기본 음량 0.5). 다시 부르면 곡이 바뀝니다. 파일을 읽지 못하면 오류가 표준 오류로 나가고 프로그램은 조용히 계속됩니다. 경로는 주어진 그대로 씁니다. MP3, OGG, FLAC, AAC는 `audio_sample_load`나 `music_load`를 쓰세요.

`audio_bgm_volume`은 다시 불러오지 않고 음량만 바꿉니다.

```ling-gui
바인드 시작 = 실행 {
    음량(0.6)
    배경음악("theme.wav", 0.4)
    배경음악음량(0.15)
}
```

## 지속음

### `audio_tone(slot, x, y, z, w, freq, amp, lfo_rate, lfo_depth, wave, duty)`

지속 발진기를 만들거나 다시 조율합니다. 같은 슬롯을 다시 쓰면 그 음이 제자리에서 바뀌고, 주파수와 진폭은 새 값으로 미끄러지듯 옮겨 가므로 매 프레임 불러도 됩니다.

| 매개변수 | 기본값 | 의미 |
|---|---|---|
| `slot` | 0 | 지속음 슬롯 번호. |
| `x, y, z` | 0 | 음원의 월드 위치. |
| `w` | 1 | 4차원 값. 음을 교차 변조하는 느린 보조 발진기를 움직입니다. 0이면 끕니다. |
| `freq` | 220 | 주파수(Hz). |
| `amp` | 0.15 | 진폭. 0을 넣으면 슬롯이 조용해집니다(삭제 함수는 없습니다). |
| `lfo_rate` | 0.5 | 비브라토 속도(Hz). |
| `lfo_depth` | 0.02 | `freq`에 대한 비율로 나타낸 비브라토 깊이. |
| `wave` | `"sine"` | `"sine"`, `"square"`, `"saw"`, `"triangle"`, `"noise"`(`freq` 높이로 계단식 변하는 노이즈). |
| `duty` | 0.5 | 사각파 펄스 폭. 칩튠 음색에는 0.125, 0.25, 0.5, 0.75 등을 씁니다. |

### `audio_glide(amp_ms, freq_ms)`

지속음의 진폭과 주파수가 새 값으로 옮겨 가는 시간을 밀리초로 정합니다(0 이하면 기본값 유지). 매 프레임 한 번씩 음을 갱신하는 칩튠 플레이어는 10 ms 정도에서 더 매끄럽게 들립니다.

### `audio_listener(cos_yaw, sin_yaw, cos_pitch, sin_pitch)`

청취자를 돌립니다. `set_camera`에 넘기는 네 숫자를 그대로 넘기세요(기본값 1, 0, 1, 0). 카메라가 돌 때 매 프레임 부르세요.

```ling-gui
바인드 시작 = 실행 {
    창열기(640, 360, "지속음")
    음조(0, 0, 0, 6, 0, 261.63, 0.10, 0.5, 0.01)
    음조(1, 0, 0, 6, 0, 440.0, 0.06, 0, 0, "square", 0.25)
    바인드 방향 = 0.0
    동안 창열림() {
        바인드 방향 = 방향 + 0.01
        카메라설정(코사인(방향), 사인(방향), 1, 0)
        오디오리스너(코사인(방향), 사인(방향), 1, 0)
        채우기(10, 12, 28)
        표시()
    }
}
```

## 단발음

### `audio_blip(freq, duration, wave, amp)`

어택과 감쇠가 빠른, 위치 없는 짧은 비프음입니다. 기본값은 `freq` 660 Hz, `duration` 0.08초(최소 0.01), `wave` `"sine"`, `amp` 0.25입니다. 파형 이름: `"sine"`, `"square"`(`"sq"`), `"saw"`(`"sawtooth"`), `"tri"`(`"triangle"`), `"noise"`. 모르는 이름은 사인파로 재생됩니다.

### `ui_sound(name)`

내장 인터페이스 소리 중 하나입니다. `"click"`(기본값), `"hover"`, `"confirm"`, `"error"`, `"toggle"`, `"tick"`. 다른 이름은 `"click"`으로 재생됩니다.

### `audio_sfx(x, y, z, w, freq, amp, duration, wave)`

월드 위치에서 나는 합성 단발음으로, 지속음처럼 팬과 감쇠가 적용됩니다. 기본값은 위치 0, `w` 1, `freq` 440, `amp` 0.3, `duration` 0.15, `wave` `"sine"`입니다.

### `morph_note(x, y, z, w, freq, amp, duration, material, morph)`

물리 모델과 디지털 모델을 섞는 "음양" 음입니다. `material`은 0 활로 켜는 현, 1 뜯는 현, 2 관악, 3 때리는 금속입니다. `morph`는 0(밝고 어쿠스틱)부터 1(어둡고 디지털: FM, 비트 크러시, 드라이브)까지입니다. 기본값은 `freq` 220, `amp` 0.3, `duration` 0.6입니다.

### `audio_stop_sfx()`

모든 단발 효과음, 모프 음, 샘플 보이스를 한 번에 멈춰서, 장면이 바뀔 때 잔향이 새지 않게 합니다. 지속음, 배경 음악, 음악 엔진은 계속 재생됩니다.

```ling-gui
바인드 시작 = 실행 {
    인터페이스음("confirm")
    효과음(880, 0.06, "square", 0.2)
    공간효과음(1.5, 0, 4, 1, 330, 0.3, 0.2, "triangle")
    morph_note(0, 0, 5, 1, 220, 0.3, 1.2, 1, 0.4)
}
```

## 샘플

### `audio_sample_load(path)`

WAV, FLAC, OGG, MP3, AAC 파일을 모노로 믹스다운해 메모리에 디코드합니다. 주어진 경로에 파일이 없으면 스크립트 폴더를 기준으로 다시 찾습니다. 샘플 ID(0부터)를 돌려주며, 실패하거나 오디오 장치가 없으면 `-1`입니다.

### `audio_sample_play(id, x, y, z, w, volume, loop, pitch)`

불러온 샘플을 월드 위치에서 재생하며, 청취자에 대해 팬과 감쇠가 적용됩니다. `volume`의 기본값은 1, `loop`가 0.5보다 크면 반복, `pitch`는 재생 속도 배율입니다(2는 한 옥타브 위, 0.5는 한 옥타브 아래). `w`는 샘플에서는 들리는 효과가 없습니다. 보이스 ID를 돌려주며, 실패하면 0입니다. 브라우저 빌드에서는 시그니처가 `(id, x, y, z, w, volume, loop)`이고 pitch가 없습니다.

### `audio_sample_play_flat(id, volume, loop, pitch)`

팬도 거리 감쇠도 없이 샘플을 재생합니다. 내레이션, 보이스오버, 인터페이스 신호음에 씁니다. 보이스 ID나 0을 돌려줍니다.

### `audio_sample_stop(voice)`와 `audio_sample_duration(id)`

`audio_sample_stop`은 재생 호출이 돌려준 보이스를 멈춥니다. `audio_sample_duration`은 샘플 길이를 초로 돌려주며(모르는 ID는 0), 실제로 불러온 클립 길이에 컷신 속도를 맞출 때 편리합니다.

```ling-gui
바인드 시작 = 실행 {
    바인드 발소리 = 샘플로드("step.ogg")
    바인드 웅웅 = 샘플로드("hum.wav")
    샘플재생(발소리, 1.0, 0.0, 3.0, 1.0, 0.8, 0, 1.2)
    바인드 보이스 = audio_sample_play_flat(웅웅, 0.5, 1, 1.0)
    출력(audio_sample_duration(웅웅))
    샘플정지(보이스)
}
```

## 마스터 이펙트

마스터 체인은 딜레이, 리버브, 로우패스 필터 순서입니다. 셋 다 꺼져 있거나 완전히 열린 상태로 시작합니다.

| 내장 함수 | 매개변수 |
|---|---|
| `audio_fx_delay(time, feedback, mix)` | 에코 시간(초, 기본값 0.3), 피드백 0~0.95(기본값 0.3), 웻 믹스 0~1(기본값 0.3, 0이면 끔). |
| `audio_fx_reverb(mix)` | 리버브 웻 믹스, 0~1(기본값 0.3). |
| `audio_fx_lowpass(cutoff)` | 0~1. 1이면 열림, 낮출수록 소리가 먹먹해져 물속 같은 느낌이 납니다. 필터는 새 값으로 미끄러지듯 옮겨 갑니다. |

```ling-gui
바인드 시작 = 실행 {
    딜레이(0.35, 0.4, 0.25)
    리버브(0.4)
    저역통과(0.15)
}
```

## FFT 분석

FFT 분석기는 여러분이 넘겨준 샘플로 동작합니다. `fft_push`로 모노 샘플 블록(-1과 1 사이의 숫자, 44.1 kHz)을 넣은 뒤 결과를 읽습니다.

| 내장 함수 | 반환값 |
|---|---|
| `fft_bands(n)` | 로그 간격 크기 대역 `n`개의 리스트(기본값 32), 저음부터. |
| `fft_beat()` | 마지막 블록이 비트이면 `true`. |
| `fft_beat_ratio()` | 비트 세기. 1이 검출 기준이고, 1보다 크면 강한 비트입니다. |
| `fft_rms()` | 신호의 RMS(제곱평균제곱근) 크기. |
| `fft_dominant_freq()` | 가장 센 주파수(Hz). |

이 프로그램은 1000 Hz 사인파를 만들어 분석합니다. 답은 1000에 가깝고, 차이는 분석기의 주파수 분해능 때문입니다.

```ling
바인드 시작 = 실행 {
    바인드 샘플들 = []
```
