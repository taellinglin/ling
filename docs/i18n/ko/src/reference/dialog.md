# 대화

Ling에는 대화 도구가 두 가지 있습니다. **대화 상자**는 캐릭터가 하는 말을 보여 줍니다.
어드벤처 게임 스타일의 텍스트 상자로, 글자가 한 자씩 찍히고, 페이지를 넘기며, 이름·장소·
아이템을 색으로 강조합니다. **대화 모델**은 캐릭터가 무슨 말을 할지 정합니다. 그 캐릭터의
대사로 1초도 안 걸려 학습하는 작은 언어 모델로, NPC마다 하나씩 가질 수 있습니다. 학습
데이터는 **Ling 대화 표준**(`.lingdialog`)이라는 일반 텍스트 형식을 씁니다.

`dialog_draw`를 빼면 둘 다 창 없이 동작하므로, 대화 전체를 헤드리스로 시험할 수 있습니다.

## 대화 상자

상자의 상태는 그리기와 따로 런타임에 있습니다. `dialog_show`가 열고, `dialog_step`이 시간을
진행하고, `dialog_advance`가 플레이어에 반응하고, `dialog_draw`가 그립니다.
`dialog_active()`가 참인 동안에는 게임 세계를 멈춰 두세요.

### 마크업

| 마크업 | 뜻 |
|---|---|
| `{n}...{/}` | 캐릭터 이름(색 역할 1). |
| `{p}...{/}` | 장소(역할 2). |
| `{i}...{/}` | 아이템(역할 3). |
| 줄바꿈 문자 | 상자 안에서 줄을 바꿉니다. |
| `\|\|` | 페이지 나눔. |

태그는 정확히 세 글자, `{`, 영문자 하나, `}`이며, `{/}`는 일반 텍스트(역할 0)로 돌아갑니다.
그 밖의 내용은 쓴 그대로 보입니다.

다 찍힌 페이지는 1.4초 뒤 저절로 다음으로 넘어가고, 마지막 페이지 다음에는 상자가 닫힙니다.

### `dialog_show(text, cps)`

`text`로 상자를 열고 초당 `cps`자(기본값 32, 최소 1)의 속도로 찍습니다. 이미 열린 상자는
교체됩니다.

### `dialog_step(dt)`

타자기 효과와 자동 넘김 타이머를 `dt`초(기본값 `0.016`) 진행합니다. 상자가 열려 있는 동안
매 프레임 호출하세요.

### `dialog_advance()`

플레이어가 확인 키를 눌렀을 때 호출하세요. 페이지가 아직 찍히는 중이면 나머지가 한 번에
나타나고, 아니면 다음 페이지로 넘어가거나 마지막 페이지 다음에 닫힙니다. 누르고 있는 키가
아니라 키를 누른 순간(`key_pressed`)으로 호출해야 한 번 눌러서 여러 페이지를 건너뛰지
않습니다.

### `dialog_active()`, `dialog_typing()`, `dialog_close()`

`dialog_active()`는 상자가 열려 있는 동안 `true`입니다. `dialog_typing()`은 현재 페이지가
아직 나타나는 중이면 `true`입니다. `dialog_close()`는 상자를 바로 닫습니다.

```ling
바인드 시작 = 실행 {
  대화표시("안녕, {n}링{/}.||두 번째 페이지.", 100)
  출력("열림: " + str(대화중()))
  출력("타이핑 중: " + str(대화타이핑()))
  대화스텝(0.5)
  출력("0.5초 뒤 타이핑 중: " + str(대화타이핑()))
  대화진행()
  출력("2쪽 타이핑 중: " + str(대화타이핑()))
  대화진행()
  대화진행()
  출력("마지막에 열림: " + str(대화중()))
}
```

```output
열림: true
타이핑 중: true
0.5초 뒤 타이핑 중: false
2쪽 타이핑 중: true
마지막에 열림: false
```

초당 100자면 첫 페이지는 0.5초 만에 다 찍힙니다. 첫 번째 `대화진행`은 2쪽으로 넘기고,
두 번째는 2쪽 전체를 드러내고, 세 번째는 상자를 닫습니다.

### `dialog_color(role, r, g, b)`

역할의 색을 정합니다. `0` 일반 텍스트, `1` 이름, `2` 장소, `3` 아이템입니다(3보다 큰 값은
3으로 칩니다). `r`, `g`, `b`는 0~255(기본값 255)입니다.

### `dialog_draw(x, y, w, h, font)`

왼쪽 위 모서리를 `(x, y)`(기본값 40, 0), 크기를 `w` × `h`(기본값 720 × 150)로 하여 모서리를
깎은 상자와 지금까지 드러난 텍스트를 그립니다. `font`는 `font_load`의 핸들이며, 빼거나
`-1`을 넘기면 내장 글자 그리기를 씁니다.

```ling-gui
바인드 시작 = 실행 {
  창열기(800, 600)
  바인드 화면글꼴 = 글꼴로드("assets/fonts/NotoSansKR.ttf", 600.0)
  바인드 대사 = "이봐, {n}링크{/}! {i}마스터 소드{/}를 {p}하이랄 평원{/}으로 가져가게.||밤을 조심하게."
  대화색(1, 255, 210, 80)
  동안 창열림() {
    만약 키눌림("space") {
      만약 대화중() { 대화진행() } 아니면 { 대화표시(대사, 34.0) }
    }
    채우기(10, 10, 20)
    만약 대화중() {
      대화스텝(0.016)
      대화그리기(50.0, 420.0, 700.0, 150.0, 화면글꼴)
    } 아니면 {
      // 여기서 평소의 게임 업데이트를 합니다
    }
    표시()
  }
}
```

## 대화 모델

대화 모델은 Ling에 내장된 몇 KB짜리 작은 "다음 단어 예측" 언어 모델(`ling_ai::dialog_lm`)
입니다. 캐릭터의 대사를 주고 학습시킨 뒤, 프롬프트에 이어서 말하게 합니다. 사실이 아니라
말투와 어휘를 배우므로, 주변 잡담, 짧은 외침, 분위기를 살리는 글에 알맞습니다. 작은 말뭉치는
1초도 안 걸려 학습합니다. 온도를 `0`으로 하면 출력이 결정적입니다.

```ling
바인드 시작 = 실행 {
  바인드 주인 = 대화모델생성(3, 32, 64, 1)
  대화학습(주인, "어서 오게 나그네")
  대화학습(주인, "칼을 잘 갈아 두게")
  대화학습(주인, "어서 돌아오게 나그네")
  바인드 손실 = 대화훈련(주인, 60, 0.1)
  출력(손실 < 2.0)
  출력(대화생성(주인, "어서", 6, 0.0))
}
```

```output
true
오게 나그네
```

### `dialog_new(ctx, embed, hidden, seed)`

빈 모델을 만들고 핸들을 반환합니다. `ctx`(기본값 3)는 앞의 몇 단어를 볼지, `embed`
(기본값 32)와 `hidden`(기본값 64)은 신경망 크기, `seed`(기본값 1)는 학습을 똑같이 되풀이할 수
있게 하는 값입니다.

### `dialog_learn(m, text)`와 `dialog_load(m, path)`

`dialog_learn`은 말뭉치에 한 줄을 더합니다. `dialog_load`는 `.lingdialog` 파일 전체를 더하고,
더한 학습 줄 수(대화 하나당 한 줄)를 반환합니다. 파일을 읽을 수 없으면 `-1`입니다.

### `dialog_train(m, epochs, lr)`

학습률 `lr`(기본값 0.1)로 말뭉치 전체를 `epochs`번(기본값 20) 학습합니다. 최종 손실을
반환하며, 낮을수록 모델이 대사에 잘 맞습니다.

### `dialog_say(m, prompt, max, temp)`

`prompt`에 이어 최대 `max`단어(기본값 24)를 생성하고, 새로 만든 단어만 반환합니다. 발언이
끝나는 곳에 이르면 일찍 멈춥니다. `temp`(기본값 0.8)는 온도로, `0`이면 늘 가장 그럴듯한
단어를 고르고 높을수록 다양해집니다.

토크나이저는 텍스트를 공백과 문장 부호에서 나누고 소문자로 바꿉니다. 한국어는 띄어쓰기를
하므로 평소처럼 쓰면 됩니다. 단어는 어절 단위로 학습되며, 대답도 어절 사이에 공백을 넣어
돌려줍니다.

### `dialog_save(m, path)`와 `dialog_load_model(path)`

`dialog_save`는 학습된 모델을 파일(기본값 `"model.llm"`)에 쓰고, 성공하면 `true`를 반환합니다.
`dialog_load_model`은 그것을 다시 읽어 새 핸들을 반환하며, 실패하면 `-1`입니다. 게임을
만들 때 한 번 학습해 두고, 출시할 때는 이 작은 모델 파일을 함께 넣어 불러오세요.

## Ling 대화 표준

`.lingdialog`는 줄 단위로 사람이 쓰기 쉬운 말뭉치 형식입니다. 작가가 손으로 고치거나
스프레드시트에서 만들어 낼 수 있고, 리뷰에서 변경 내용이 깔끔하게 보이며, 다른 텍스트
파일처럼 현지화할 수 있습니다.

```text
# Ling Dialog Standard v1
@meta title: 주막 주인
@meta speaker: 브람

= 환영
브람: 어서 오게 나그네
영웅: 길에서 무슨 소식 있나요
브람: 북쪽 고개에 산적이 나온다네
      내 국밥이면 못 고칠 게 없지

= 소문
브람: 칼을 잘 갈아 두게
```

| 줄 | 뜻 |
|---|---|
| `# ...` | 줄 끝까지 주석. |
| `@meta key: value` | 데이터셋의 메타데이터. 여러 번 쓸 수 있습니다. |
| `= label` | 새 대화를 시작합니다. 라벨은 생략할 수 있습니다. |
| `speaker: text` | 발언 하나. 화자는 **첫** 쌍점 앞의 글자입니다. |
| `:`가 없는 줄 | 앞 발언에 이어집니다(공백으로 연결). |
| 빈 줄 | 무시합니다. |

해석은 절대 실패하지 않습니다. 형식이 틀린 줄은 건너뛰므로, 엉뚱한 글자 하나 때문에 학습이
멈추지 않습니다. 첫 `=` 앞의 발언은 암묵적인 대화 하나로 묶입니다.

대화는 하나씩 학습 줄 하나가 되고, 발언 사이는 예약 토큰 `<eos>`로 이어집니다. 그래서
모델은 발언을 **넘어서** 이어 말하는 법을 배웁니다. 직접 `<eos>`라고 써도 발언의 경계가
됩니다. 예약 토큰은 `<pad>`, `<bos>`, `<eos>`, `<unk>`입니다.

```ling
바인드 시작 = 실행 {
  write_file("bram.lingdialog", "# Ling Dialog Standard v1\n@meta speaker: 브람\n\n= 환영\n브람: 어서 오게 나그네\n영웅: 길에서 무슨 소식 있나요\n브람: 북쪽 고개에 산적이 나온다네\n\n= 소문\n브람: 칼을 잘 갈아 두게\n")
  바인드 주인 = 대화모델생성(3, 32, 64, 1)
  출력(대화불러오기(주인, "bram.lingdialog"))
  대화훈련(주인, 80, 0.1)
  출력(대화생성(주인, "북쪽 고개에", 8, 0.0))
  출력(대화모델저장(주인, "bram.llm"))
  바인드 다시 = 대화모델불러오기("bram.llm")
  출력(대화생성(다시, "칼을 잘", 8, 0.0))
}
```

```output
2
산적이 나온다네
true
갈아 두게
```

### 좋은 말뭉치 쓰기

- **양보다 일관성.** 목소리가 분명한 작은 말뭉치가 크고 평범한 말뭉치보다 기억에 남는
  캐릭터를 만듭니다.
- **입버릇은 되풀이하세요.** 캐릭터가 자주 했으면 하는 대사는 여러 대화에 몇 번씩 넣으세요.
- **목소리마다 파일 하나.** 캐릭터마다 파일을 나누면 각자 자기 모델과 개성을 갖습니다.
- **자연스럽게 쓰세요.** 대소문자와 문장 부호는 토크나이저가 처리합니다.

## 함께 쓰기

모델이 대사를 쓰고, 상자가 그것을 보여 줍니다.

```ling-gui
바인드 시작 = 실행 {
  창열기(800, 600)
  바인드 브람 = 대화모델불러오기("npc/bram.llm")
  동안 창열림() {
    만약 키눌림("e") && !대화중() {
      대화표시("{n}브람{/}: " + 대화생성(브람, "어서", 12, 0.7))
    }
    만약 키눌림("space") && 대화중() { 대화진행() }
    채우기(10, 10, 20)
    대화스텝(0.016)
    만약 대화중() { 대화그리기(50, 420, 700, 150) }
    표시()
  }
}
```
