# 애니메이션

Anima는 Ling의 애니메이션 시스템입니다. 2D 그림이든 3D 메시든 파티클이든 그냥 숫자든, 움직이는 것은 모두 작은 **드라이버**가 움직입니다. 드라이버는 매 프레임 현재 시간을 넣어 호출하는 함수입니다. 드라이버는 숫자 하나를 돌려주고, 여러분은 그 숫자를 크기, 위치, 각도, 패턴 인자에 넣습니다.

드라이버는 두 가지 기질로 나뉩니다.

- **유기적** 드라이버(灵, "영")는 부드럽고 살아 있는 듯한 움직임을 만듭니다. 호흡, 흔들림, 걷기, 탄력 있는 잔동작, 2본 역운동학이 여기에 속합니다.
- **기계적** 드라이버(机, "기")는 정확하고 단단한 움직임을 만듭니다. 맞물린 기어, 캠, 슬라이더 크랭크, 랙과 피니언이 여기에 속합니다.

한 캐릭터 안에서 두 가지를 섞어 쓸 수 있습니다. 예를 들어 가슴은 숨 쉬고 턱은 기계처럼 움직이는 생물을 만들 수 있습니다. 스켈레톤이 있는 3D 캐릭터를 가져왔다면, 이 페이지 끝의 `gltf_*` 내장 함수로 스켈레탈 애니메이션 클립을 재생할 수 있습니다.

## 드라이버의 동작 방식

드라이버는 **순수 함수**입니다. 숨겨진 상태가 없으므로 같은 인자를 넣으면 언제나 같은 답이 나옵니다.

- 시간 기반 드라이버(`breathe`, `wobble`, `gait_*`)는 현재 시간을 여러분에게서 받습니다. 보통 `time_now()`나, 매 프레임 `1/60`씩 늘리는 변수를 넘깁니다. 뒤에서 몰래 재생되는 것은 없습니다.
- 스프링 드라이버(`spring_to`)는 새 상태를 돌려주고, 여러분은 다음 프레임에 그것을 다시 넘깁니다. 상태는 프로그램이 가집니다.

각도는 라디안입니다. 길이는 그림에서 쓰는 단위를 그대로 씁니다. 드라이버는 단정밀도로 계산하므로, 예제에서는 작은 도우미 함수 `소수3`으로 결과를 반올림합니다.

## 보간

### `tween(a, b, t)`와 `tween_ease(a, b, t, curve)`

`tween`은 `a + (b - a) * t`를 돌려줍니다. 진행도 `t`는 0..1로 **잘리므로**, 1을 넘겨 계속 늘려도 값은 `b`에 머뭅니다.

`tween_ease`는 같은 일을 이징 곡선을 거쳐 합니다. `curve`는 아래 Anima 표의 이름입니다(기본값 `"linear"`). elastic과 back 곡선은 `b`를 넘어설 수 있습니다.

### `ease(curve, t)`

진행도 `t`(0..1로 잘림)에서 UI 툴킷 이징 곡선의 값을 그대로 돌려줍니다. 시작에서 0, 끝에서 1입니다. 곡선 이름이 **먼저** 옵니다. 두 색을 섞을 때처럼 곡선 값 자체가 필요할 때 씁니다. 현지화된 이름은 없습니다.

```ling
함수 소수3(x: number) -> number {
    반올림(x * 1000) / 1000
}

바인드 시작 = 실행 {
    출력(트윈(0, 10, 0.25))
    출력(트윈(0, 10, 2.0))
    출력(소수3(이징트윈(0, 100, 0.5, "cubic_in")))
    출력(소수3(이징트윈(0, 100, 0.5, "bounce_out")))
    출력(ease("quad_in", 0.5))
    출력(소수3(ease("smooth", 0.25)))
}
```

```output
2.5
10
12.5
76.563
0.25
0.125
```

### 이징 곡선 이름

두 내장 함수는 **서로 다른 이름 집합**을 씁니다. 둘 다 대소문자를 구분하지 않습니다.

**`tween_ease`**(Anima 곡선). 밑줄은 생략해도 됩니다. 모르는 이름은 `linear`가 됩니다.

| 계열 | 이름 |
|---|---|
| 기본 | `linear`, `step` |
| 2차 | `quad_in`, `quad_out`, `quad_in_out` |
| 3차 | `cubic_in`, `cubic_out`, `cubic_in_out` (`smooth`도 가능) |
| 사인 | `sine_in`, `sine_out`, `sine_in_out` |
| 지수 | `expo_in`, `expo_out`, `expo_in_out` |
| 탄성 | `elastic_in`, `elastic_out` (`elastic`도 가능) |
| 백 | `back_in`, `back_out`, `back_in_out` (`overshoot`도 가능) |
| 바운스 | `bounce_in`, `bounce_out` (`bounce`도 가능) |

**`ease`**(UI 곡선). 대시와 밑줄은 서로 바꿔 써도 됩니다. 모르는 이름은 `quad_inout`이 됩니다.

| 이름 | 모양 |
|---|---|
| `linear` | 직선 |
| `quad_in`, `ease_in` | 느린 시작 |
| `quad_out`, `ease_out` | 느린 끝 |
| `quad_inout`, `ease`, `smooth` | 느린 시작과 끝(기본값) |
| `cubic_in`, `cubic_out`, `cubic_inout` | 더 강한 버전 |
| `quart_out` | 빠른 시작, 길고 느린 끝 |
| `sine`, `sine_inout` | 부드러운 사인 인아웃 |
| `expo`, `expo_out` | 지수 감쇠 |
| `back`, `back_out` | 넘어갔다가 자리 잡음 |
| `elastic`, `elastic_out` | 탄력 있게 넘어감 |
| `bounce`, `bounce_out` | 끝에서 튐 |

## 유기적 드라이버

### `breathe(t, rate, depth)`

1을 중심으로 한 호흡 배율 `1 + depth * sin(2π * rate * t)`입니다. `rate`는 초당 호흡 수(기본값 1), `depth`는 진폭(기본값 0.1)입니다. 크기나 패턴 반지름에 곱해서 씁니다.

### `wobble(t, freq, amp, phase)`

보조 동작을 위한 사인 흔들림 `amp * sin(2π * (freq * t + phase))`입니다. 기본값은 `freq` 1, `amp` 1, `phase` 0입니다. 위상의 단위는 주기이므로 `0.25`는 4분의 1주기만큼 어긋납니다. 팔다리마다 위상을 다르게 주면 몸 전체가 엇갈리며 흔들립니다.

### `gait_phase(t, speed)`, `gait_swing(t, speed, stride)`, `gait_lift(t, speed, height)`

걷기 주기입니다. `speed`는 초당 주기 수입니다(기본값 1).

- `gait_phase`는 주기의 현재 위치를 0 이상 1 미만으로 돌려줍니다.
- `gait_swing`은 다리의 앞뒤 흔들림을 `-stride`와 `stride` 사이 값으로 돌려줍니다. 다른 쪽 다리에는 `t + 0.5 / speed`를 씁니다.
- `gait_lift`는 발을 든 높이를 돌려줍니다. 흔드는 반주기 동안은 양수, 발을 디딘 동안은 0입니다. 화면의 y축은 아래쪽이므로 빼야 합니다. `발_y = 땅_y - gait_lift(...)`

```ling
함수 소수3(x: number) -> number {
    반올림(x * 1000) / 1000
}

바인드 시작 = 실행 {
    바인드 시각 = 0.125
    출력(소수3(호흡(시각, 1, 0.2)))
    출력(소수3(흔들림(시각, 1, 10, 0)))
    출력(소수3(걸음위상(시각, 2)))
    출력(소수3(걸음흔들(시각, 1, 30)))
    출력(소수3(발들기(시각, 1, 10)))
}
```

```output
1.141
7.071
0.25
21.213
7.071
```

### `spring_to(pos, vel, target, stiffness, damping, dt)`

`pos`를 `target` 쪽으로 당기는 감쇠 스프링의 한 단계입니다. 잔동작, 카메라 스무딩, 꼬리 등에 씁니다. 기본값은 `stiffness` 120, `damping` 14, `dt` 1/60입니다. 두 원소 리스트 `[새_위치, 새_속도]`를 돌려줍니다. 두 숫자를 보관했다가 다음 프레임에 다시 넘기세요.

기본값으로는 값이 조금 넘어갔다가 1초쯤 안에 자리를 잡습니다.

```ling
바인드 시작 = 실행 {
    바인드 위치 = 0.0
    바인드 속도 = 0.0
    바인드 프레임 = 0
    동안 프레임 < 60 {
        바인드 결과 = 스프링이동(위치, 속도, 1.0, 120, 14, 1 / 60)
        바인드 위치 = 결과[0]
        바인드 속도 = 결과[1]
        바인드 프레임 = 프레임 + 1
        만약 프레임 % 15 == 0 {
            출력(str(프레임) + "프레임: " + str(반올림(위치 * 1000) / 1000))
        }
    }
}
```

```output
15프레임: 0.982
30프레임: 1.021
45프레임: 0.997
60프레임: 1
```

### `ik2(l1, l2, tx, ty)`

평면 2본 역운동학입니다. 두 마디로 된 팔이나 다리의 끝을 목표에 닿게 하는 어깨 각도와 팔꿈치 각도를 구합니다. `l1`과 `l2`는 뼈 길이(기본값 1)이고, `(tx, ty)`는 어깨를 기준으로 한 목표 위치입니다.

`[어깨, 팔꿈치]`를 라디안으로 돌려줍니다. `어깨`는 첫 번째 뼈의 각도이고, `팔꿈치`는 두 번째 뼈가 **첫 번째 뼈에 대해** 굽은 각도입니다. 닿지 않는 목표는 잘려서, 팔다리가 목표 쪽으로 쭉 뻗습니다. 관절 위치는 다음과 같이 구합니다.

- 팔꿈치 = 어깨 위치 + `l1 * (cos(어깨), sin(어깨))`
- 손 = 팔꿈치 + `l2 * (cos(어깨 + 팔꿈치), sin(어깨 + 팔꿈치))`

```ling
함수 소수3(x: number) -> number {
    반올림(x * 1000) / 1000
}

바인드 시작 = 실행 {
    바인드 각 = 역운동(1, 1, 1, 1)
    출력([소수3(각[0]), 소수3(각[1])])
}
```

```output
[1.571, -1.571]
```

## 기계적 드라이버

| 내장 함수 | 반환값 |
|---|---|
| `gear_couple(angle, teeth_in, teeth_out)` | 구동되는 기어의 각도 `-angle * teeth_in / teeth_out`(`teeth_out`이 0이면 0). 맞물린 기어는 반대 방향으로 돕니다. |
| `gear_train(angle, teeth)` | 기어 사슬에 있는 모든 기어의 각도 리스트. `teeth`는 톱니 수 리스트이고, 결과의 첫 원소는 `angle` 자신입니다. |
| `cam_lift(angle, lift)` | 캠 종동절의 높이 `lift * (1 - cos(angle)) / 2`. 각도 0에서 0, π에서 `lift`입니다. |
| `piston(angle, crank, rod)` | 크랭크 중심에서 실린더를 따라 잰 피스톤 핀 위치. 기본값은 `crank` 1, `rod` 2입니다(로드는 크랭크보다 길어야 합니다). |
| `rack(angle, radius)` | 랙의 이동 거리 `angle * radius`. |

톱니 12개짜리 기어가 36개짜리 기어를 돌리면, 큰 기어는 3분의 1 속도로 반대 방향으로 돕니다.

```ling
함수 소수3(x: number) -> number {
    반올림(x * 1000) / 1000
}

바인드 시작 = 실행 {
    출력(소수3(기어연동(3, 12, 36)))
    바인드 기어들 = 기어열(1, [12, 36, 12])
    출력([소수3(기어들[0]), 소수3(기어들[1]), 소수3(기어들[2])])
    출력(소수3(캠리프트(3.14159265, 2)))
    출력(소수3(피스톤(0, 1, 3)))
    출력(랙(2, 0.5))
}
```

```output
-1
[1, -0.333, 1]
2
4
1
```

## 움직이는 장면

이 창은 숨 쉬는 원, 걷는 발, 움직이는 목표를 쫓는 스프링을 함께 보여 줍니다. 스프링의 위치와 속도는 프레임에서 프레임으로 이어집니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(640, 360, "아니마")
    바인드 시각 = 0.0
    바인드 위치 = 0.0
    바인드 속도 = 0.0
    동안 창열림() {
        채우기(10, 12, 28)
        # 유기적: 숨 쉬는 원
        색설정(120, 220, 255)
        원채우기(120, 120, 40 * 호흡(시각, 0.4, 0.12))
        # 유기적: 걷는 발
        바인드 흔듦 = 걸음흔들(시각, 1.0, 30)
        바인드 들림 = 발들기(시각, 1.0, 20)
        색설정(255, 210, 90)
        선그리기(120, 200, 120 + 흔듦, 260 - 들림)
        원채우기(120 + 흔듦, 260 - 들림, 10)
        # 유기적: 목표를 쫓는 스프링
        바인드 목표 = 400 + 80 * 사인(시각 * 1.3)
        바인드 결과 = 스프링이동(위치, 속도, 목표, 120, 10, 0.016)
        바인드 위치 = 결과[0]
        바인드 속도 = 결과[1]
        색설정(120, 255, 160)
        원채우기(위치, 180, 12)
        표시()
        바인드 시각 = 시각 + 0.016
    }
}
```

## 스켈레탈 애니메이션(glTF)

`.glb`나 `.gltf`로 내보낸 리깅된 캐릭터에는 스켈레톤, 스킨 가중치, 애니메이션 클립이 들어 있습니다. 아래 내장 함수는 그런 모델을 불러와 스키닝해서 그립니다. 현지화된 이름은 없지만, 텍스처를 입히는 두 그리기 함수는 예외입니다. `gltf_anim_draw_tex`는 `骨骼动画纹理绘制`(zh), `スキンアニメ描画`(ja), `글꼴애니텍스처`(ko), `วาดแอนิเมชันมีพื้นผิว`(th)로도 쓸 수 있고, `gltf_pose_draw_tex`는 `骨骼姿势纹理绘制`, `スキンポーズ描画`, `글꼴포즈텍스처`, `วาดสกินมีพื้นผิว`로도 쓸 수 있습니다.

| 내장 함수 | 용도 |
|---|---|
| `gltf_load(path)` | 모델을 불러옵니다. 핸들을 돌려주며, 실패하면 `-1`입니다. |
| `gltf_anim_count(h)` | 애니메이션 클립 수. |
| `gltf_anim_name(h, i)` | 클립 `i`의 이름. |
| `gltf_anim_dur(h, i)` | 클립 `i`의 길이(초). |
| `gltf_joint_count(h)` | 스킨 관절(뼈) 수. |
| `gltf_joint_name(h, j)` | 관절 `j`의 이름. |
| `gltf_autorig(h)` | 스켈레톤이 없는 모델에 절차적 20본 인간형 리그를 붙입니다. 뼈 수를 돌려줍니다. |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | 클립 `clip`의 `time`초 시점으로 스키닝해 텍스처를 입혀 그립니다. |
| `gltf_pose_draw(h, x, y, z, scale, yaw, pose)` | 직접 만든 포즈로 스키닝해 그립니다(단색). |
| `gltf_pose_draw_tex(h, x, y, z, scale, yaw, pose)` | 위와 같지만 텍스처를 입힙니다. |
| `gltf_bounds(h, clip, time)` | 그 클립과 시간으로 그렸을 때 모델의 `[minX, minY, minZ, maxX, maxY, maxZ]`. |

참고:

- 클립 시간은 되감기므로, 계속 커지는 시간을 넘기면 클립이 반복됩니다.
- `pose`는 뼈마다 세 개(X, Y, Z)씩 라디안 오일러 각을 이어 붙인 평평한 리스트입니다.
- glTF 모델은 Y축이 위입니다. 그리기 함수는 모델을 렌더러의 y-아래 공간으로 뒤집으므로, `(x, y, z)`는 모델 원점(보통 발)이 놓일 위치입니다.
- `gltf_anim_draw_tex`는 `time` 뒤에 선택 인자를 더 받습니다. 환경광, 뒷면 컬링(`1`이면 컬링), 이 모델을 움직일 클립을 가진 원본 모델(관절 이름으로 맞춰 장비를 따라 움직이게 할 때), 뼈별 추가 회전 리스트, `0xRRGGBB` 색조입니다.
- `gltf_draw(h, x, y, z, scale, yaw)`는 모델을 스키닝 없이 그립니다. `gltf_mesh_count`, `gltf_mesh_name`, `gltf_mesh_show(h, i, on)`, `gltf_mesh_tint(h, i, 0xRRGGBB)`로 개별 메시를 보이거나 숨기거나 색을 입힐 수 있습니다. 장비를 바꿔 끼울 때 유용합니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(960, 540, "걷기")
    깊이테스트(1)
    바인드 영웅 = gltf_load("hero.glb")
    바인드 번호 = 0
    동안 번호 < gltf_anim_count(영웅) {
        출력(gltf_anim_name(영웅, 번호) + ": " + str(gltf_anim_dur(영웅, 번호)) + "초")
        바인드 번호 = 번호 + 1
    }
    동안 창열림() {
        채우기(20, 24, 40)
        gltf_anim_draw_tex(영웅, 0, 2, 6, 1, 0.5, 0, 현재시간())
        flush_3d()
        표시()
    }
}
```

## 내장 함수가 아닌 것

`ling-animation` 크레이트에는 키프레임 트랙과 타임라인, 스키닝 행렬을 가진 관절 리그, 절차적 2족·4족 보행, 4절 링크 해석기, 얼굴 리그도 있습니다. 이것들은 임베더를 위한 Rust API이지 Ling 내장 함수가 아닙니다. 예전 문서에 나오는 `rig_load`나 `anim_play` 같은 이름은 존재하지 않고, `delta_time()`은 구현되어 있지 않습니다. 시간에는 `time_now()`를 쓰세요.
