# 창과 카메라

그래픽을 쓰는 Ling 프로그램은 모두 창을 열고, 프레임 루프를 돌리고, 하나뿐인 3D 카메라를 조준합니다.
이 페이지는 그 세 가지를 다룹니다. 창과 프레임 루프, 프레임 속도와 시간 측정, 그리고 3D 점을 화면에
투영하는 카메라입니다. 그리기는 다음 페이지에 있습니다:
[2D 그리기와 이미지](drawing.md), [3D 도형과 메시](shapes.md).

## 프레임 루프

그래픽 프로그램의 구조는 언제나 같습니다. 창을 열고, 창이 닫힐 때까지 지우기, 그리기, `present()`를
반복합니다.

```ling-gui
바인드 start = 실행 {
    창열기(800, 600, "프레임 루프")
    바인드 프레임 = 0
    동안 창열림() {
        채우기(10, 12, 30)                  # 1. 배경색으로 지우기
        색설정(255, 200, 80)                # 2. 그리기
        원채우기(400 + 200 * 사인(프레임 * 0.05), 300, 40)
        표시()                              # 3. 프레임 보여 주기
        바인드 프레임 = 프레임 + 1
    }
}
```

기억해 둘 사실이 세 가지 있습니다.

1. `window_is_open()`은 사용자가 창을 닫거나 **Escape 키를 누르면** 거짓이 됩니다.
   Escape를 직접 처리할 필요는 없습니다.
2. 화면에 픽셀을 내보내는 호출은 `present()`뿐입니다. 이 호출은 대기열에 쌓인 3D 도형도 그리고,
   후처리를 실행하고, 마우스를 읽습니다. `present()`가 없는 프레임은 보이지 않습니다.
3. 델타 타임 내장 함수는 없습니다. 현재 `time_now()`에서 이전 값을 빼거나,
   `frame_count()`로 프레임을 세십시오.

존재하지 않는 내장 함수(예를 들어 Ling에 없는 `draw_rect`)를 호출하면 아무 일 없이 무시됩니다.
그리기 호출이 아무것도 하지 않는 것 같으면 먼저 철자를 확인하십시오.

### 좌표

| 공간 | 원점 | +x | +y | +z |
|---|---|---|---|---|
| 화면 (2D) | 왼쪽 위 픽셀 | 오른쪽 | **아래** | 사용 안 함 |
| 월드 (3D) | 카메라 피벗 | 오른쪽 | **아래** | 카메라에서 멀어지는 쪽 |

+y가 아래를 향하므로 "위쪽"은 음수 y입니다. 천장은 `y = -3`에, 바닥은 `y = 3`에 있습니다.

기본 투영은 시야를 창 중앙에 맞추고, 초점 거리를 창 높이(픽셀)와 같게 하며, 원근 나눗셈 전에
깊이 오프셋 `zdist = 5`를 더합니다.

```text
screen_x = width/2  + height * x / (z + zdist)
screen_y = height/2 + height * y / (z + zdist)
```

## 창과 프레임

### `open_window(w, h, title, resizable)`

프로그램의 창을 열고 프레임 버퍼를 할당합니다.

- **매개변수:** `w`, `h` 픽셀 단위 크기(기본값 800 x 600), `title`(기본값 `"Ling"`),
  `resizable`은 선택 사항이며 `1`이면 크기를 조절할 수 있는 창이 됩니다(기본값 0).
- **반환값:** 없음.
- **참고:** 숫자가 먼저 오고 제목은 세 번째입니다. 창을 열면 카메라 투영도 기본값으로
  초기화됩니다. 크기 조절 가능한 창이라면 매 프레임 `get_width()`와 `get_height()`를 읽으십시오.
  창을 만들 수 없으면 프로그램은 `cannot open window`로 멈춥니다.

```ling-gui
바인드 start = 실행 {
    창열기(1024, 640, "내 게임", 1)
}
```

### `open_fullscreen(title, w, h)`와 `open_fullscreen_scaled(title, scale)`

`open_fullscreen`은 기본 모니터 전체를 덮는 테두리 없는 창을 엽니다. `w`와 `h`는 선택
사항입니다(기본값: 모니터 해상도). 여기서는 **제목이 첫 번째**라는 점에 주의하십시오.

`open_fullscreen_scaled`는 모니터 해상도의 일부로 렌더링한 뒤 결과를 확대해서, 선명도 대신
속도를 얻습니다. `scale`은 `1`, `2`, `4` 중 하나이며(그 밖의 값은 1로 취급), `get_width()`와
`get_height()`는 줄어든 크기를 알려 줍니다.

```ling-gui
바인드 start = 실행 {
    open_fullscreen_scaled("레트로", 2)
}
```

### `window_is_open()`

창이 열려 있는 동안 `true`이고, 사용자가 창을 닫거나 Escape를 누르거나 코드가 `quit()`을
호출하면 `false`입니다. 창을 열기 전에는 `false`를 반환하므로, 이 함수로 감싼 루프는 실행되지 않습니다.

### `present()`

프레임을 마칩니다. 대기열의 모든 3D 기본 도형을 그리고, 후처리를 적용하고, 프레임 버퍼를 창에
복사하고, 마우스를 읽습니다.

3D 도형(`cube`, `vtex_*`, `draw_line_3d` 등)은 깊이 순으로 정렬되어 여기서만 래스터화되므로,
어떤 순서로 호출해도 됩니다. 직접 그리는 2D 호출(`draw_line`, `triangle`, `draw_disc`, `tex_*`,
`image_draw`)은 프레임 버퍼에 즉시 쓰기 때문에, 대기 중인 3D 도형이 그 **위에** 그려집니다.
3D 장면 위에 HUD를 그리려면 먼저 `flush_3d()`를 호출하십시오. `ui_*` 위젯은 여러 프레임에 걸쳐
클릭을 감지하므로 프레임마다 한 번씩 `present()`가 필요합니다.

### `flush_3d()`와 `flush_post()`

`flush_3d()`는 대기 중인 3D 도형을 표시하지 않고 지금 프레임 버퍼에 그립니다. 그 뒤에 그리는
것은 모두 위에 올라갑니다. `flush_post()`는 같은 일을 한 다음 후처리 체인을 즉시 실행하므로,
그 뒤에 그린 HUD는 블룸으로 번지지 않습니다. [포스트 FX와 조명](postfx.md)을 참고하십시오.

```ling-gui
바인드 start = 실행 {
    정육면체(0, 0, 8, 1, 1, 1, 0, 0, 0, 0)
    flush_3d()                          # 이제 정육면체가 프레임 버퍼에 있음
    막대(20, 20, 200, 14, 0.5, 1)       # 그 위에 그려짐
    표시()
}
```

### `quit()`

Escape를 누른 것과 똑같이, 코드에서 창을 닫습니다. `exit_game`과 `close_window`는 영어 동의어입니다.

```ling-gui
바인드 start = 실행 {
    만약 버튼(20, 20, 100, 32) == 1 { quit() }
}
```

### `get_width()`와 `get_height()`

현재 프레임 버퍼의 크기(픽셀)입니다. 고정 크기 창이라면 `open_window`의 인수와 같고, 크기 조절
가능한 창이라면 사용자가 크기를 바꿀 때 달라집니다. 창이 없으면 0을 반환합니다.

```ling-gui
바인드 start = 실행 {
    바인드 중심x = 너비() / 2
    바인드 중심y = 높이() / 2
}
```

### `set_fps(n)`와 `set_vsync(on)`

`set_fps(n)`은 프레임 속도를 제한합니다(기본값 60, 최솟값 1). `open_window` 다음에 호출하십시오.
`set_vsync(on)`은 대신 루프를 모니터 주사율에 맞춥니다. 이것은 프레임 페이싱이지, 티어링 없는
수직 동기화가 아닙니다. 명시적인 `set_fps`나 환경 변수 `LING_FPS_CAP`이 우선합니다.

```ling-gui
바인드 start = 실행 {
    창열기(800, 600, "제한")
    프레임설정(30)
}
```

### `monitor_width()`, `monitor_height()`, `monitor_refresh()`, `monitor_info()`

기본 모니터의 너비와 높이(픽셀), 주사율(헤르츠)입니다. `monitor_info()`는 세 값을 리스트
`[width, height, hz]`로 반환합니다. 창을 열기 전에도 호출할 수 있으므로, 예를 들어 창 크기를
정하는 데 쓸 수 있습니다.

```ling-gui
바인드 start = 실행 {
    바인드 정보 = 화면정보()
    창열기(정보[0] / 2, 정보[1] / 2, "화면의 절반")
}
```

### `wait_window()`

창이 닫히거나 Escape를 누를 때까지 마지막 프레임을 화면에 둔 채로 멈춥니다. 정지 화면 한 장을
그리는 프로그램에 편리합니다.

```ling-gui
바인드 start = 실행 {
    창열기(400, 300, "정지 화면")
    채우기(20, 40, 80)
    표시()
    wait_window()
}
```

### `screenshot(tag)`

현재 프레임 버퍼를 PNG로 저장하고 그 경로
`screenshots/ss_<unix-time>_<tag>_<width>x<height>.png`를 반환합니다. `tag`의 기본값은
`"game"`이며, 문자와 숫자가 아닌 글자는 밑줄로 바뀝니다. 폴더는 프로그램을 실행한 곳에 만들어집니다.
완전한 프레임을 담으려면 `present()` 다음에 호출하십시오.

```ling-gui
바인드 start = 실행 {
    표시()
    println(screenshot("title-screen"))
}
```

### `record_frame()`와 `record_count()`

`record_frame()`은 나중에 동영상으로 합칠 수 있도록 현재 프레임 버퍼를
`recordings/frame_00000.ppm`, `frame_00001.ppm` 순으로 쓰고, 방금 쓴 프레임의 번호를 반환합니다.
`record_count()`는 지금까지 쓴 프레임 수를 반환합니다.

### `frame_count()`와 `time_now()`

`frame_count()`는 프로그램 시작 후 표시한 프레임 수입니다. `time_now()`는 프로그램 시작 후 경과한
초를 소수로 나타냅니다. 프레임 간 시간 차이를 구하려면 이전 값을 기억해 두십시오.

```ling-gui
바인드 start = 실행 {
    바인드 이전 = 현재시간()
    동안 창열림() {
        바인드 지금 = 현재시간()
        바인드 간격 = 지금 - 이전
        바인드 이전 = 지금
        채우기(0, 0, 0)
        표시()
    }
}
```

## 카메라

모든 3D 내장 함수는 하나의 전역 카메라를 통해 월드의 점을 투영합니다. 카메라는 세 가지로 정해집니다.

* **피벗** `(x, y, z)`: `set_camera_pos`로 설정하며, 모든 점에서 뺍니다.
* **방향**: `set_camera`로 요(yaw)와 피치(pitch) 각도의 코사인과 사인을 넘겨 설정합니다.
* **깊이 오프셋** `zdist`: `set_zdist`로 설정하며, 원근 나눗셈 전에 더합니다.

요가 양수이면 카메라가 오른쪽으로 돌아서, 정면에 있던 것이 화면 왼쪽으로 밀립니다. 피치가
양수이면 카메라가 아래로 기울어서, 정면에 있던 것이 위로 올라갑니다. 요 각도가 `a`일 때 월드에서의
"앞쪽"은 x-z 평면의 `(sin a, cos a)`입니다. 3D 도형을 그리기 전에 매 프레임 카메라를 설정하십시오.

| 내장 함수 | 中文 | 日本語 | 한국어 | ไทย | 용도 |
|---|---|---|---|---|---|
| `set_camera(cy, sy, cp, sp)` | `设镜` | `カメラ設定` | `카메라설정` | `ตั้งกล้อง` | 요와 피치의 cos/sin으로 방향 설정 |
| `set_camera_pos(x, y, z)` | `镜坐标` | `カメラ座標` | `카메라좌표` | `ตั้งตำแหน่งกล้อง` | 피벗 이동 |
| `move_camera(dx, dy, dz)` | — | — | — | — | 피벗을 오프셋만큼 이동 |
| `set_zdist(d)` | `镜距` | `Z距離設定` | `Z거리설정` | `ตั้งระยะห่าง` | 깊이 오프셋 |
| `set_projection(cx, cy, focal, zdist)` | `投影` | `投影設定` | `투영설정` | `ตั้งโปรเจกชัน` | 렌즈 매개변수를 한꺼번에 |
| `tm_fov(degrees, width)` | — | — | — | — | 시야각으로 초점 거리 설정 |
| `set_camera_roll(angle)` | — | — | — | — | 시선 축을 중심으로 회전 |
| `set_camera_hyper(R, saddle, px, mid_y, pz)` | — | — | — | — | 쌍곡 공간 뷰 |
| `project_3d(x, y, z)` | `投影3D` | `3D投影` | `3D투영` | `ฉาย3มิติ` | 월드 점을 화면으로 |
| `mouse_ray()` | — | — | — | — | 화면(마우스)에서 월드로 향하는 광선 |

### `set_camera(cy, sy, cp, sp)`

미리 계산한 값으로 방향을 설정합니다. `cy`, `sy`는 요 각도의 코사인과 사인, `cp`, `sp`는 피치
각도의 코사인과 사인입니다(기본값 `1, 0, 1, 0`, +z 방향을 똑바로 봄). 각도가 아니라 네 개의 숫자를
넘기십시오.

```ling-gui
바인드 start = 실행 {
    바인드 요 = 0.3
    바인드 피치 = 0.1
    카메라설정(코사인(요), 사인(요), 코사인(피치), 사인(피치))
}
```

### `set_camera_pos(x, y, z)`와 `move_camera(dx, dy, dz)`

`set_camera_pos`는 카메라 피벗을 월드 위치로 옮기고(기본값 0, 0, 0), `move_camera`는 거기에
오프셋을 더합니다. y는 아래쪽이라는 점을 기억하십시오. 카메라를 높이려면 y를 줄입니다. 오디오가
실행 중이면 오디오 리스너가 카메라 위치를 따라갑니다.

```ling-gui
바인드 start = 실행 {
    카메라좌표(0, -2, -6)      # 두 단위 위로, 여섯 단위 뒤로
}
```

### `set_zdist(d)`, `set_projection(cx, cy, focal, zdist)`, `tm_fov(degrees, width)`

`set_zdist(d)`는 깊이 오프셋을 설정합니다(기본값 5, 창을 열면 초기화). 값이 클수록 장면이 멀어지고
원근감이 평평해집니다. `-zdist`보다 가까운 도형은 잘립니다.

`set_projection`은 렌즈 매개변수를 모두 덮어씁니다. `cx`, `cy`는 광학 중심(픽셀), `focal`은 초점
거리(픽셀, 클수록 확대), 그리고 `zdist`입니다. 화면 분할 같은 특이한 구성에서만 필요합니다.

`tm_fov(degrees, width)`는 시야가 지정한 수평 각도를 덮도록 초점 거리를 설정합니다. `width`는
뷰포트 너비(픽셀, 기본값: 창 너비)입니다. `tm_fov(0)`은 기본 초점 거리로 되돌립니다.

```ling-gui
바인드 start = 실행 {
    투영설정(너비() / 2, 높이() / 2, 높이() * 1.5, 5)   # 확대
}
```

### `set_camera_roll(angle)`와 `set_camera_hyper(R, saddle, px, mid_y, pz)`

`set_camera_roll`은 시야를 앞쪽 축을 중심으로 라디안 단위만큼 굴립니다(별칭 `camera_roll`).
`set_camera_hyper`는 피벗 `(px, mid_y, pz)`를 중심으로 쌍곡 뷰를 켭니다. 지면 거리가
`R * tanh(d / R)`로 압축되고, 공간이 세기 `saddle`의 말안장처럼 휩니다. `R = 0`이면 꺼집니다.

### `project_3d(x, y, z)`

현재 카메라로 월드의 점을 투영해 `[screen_x, screen_y, depth]`를 반환합니다. 카메라 뒤에 있는 점은
`[-99999, -99999, depth]`가 됩니다. 3D 물체에 2D 라벨을 붙일 때 쓰십시오. 창이 없으면 투영은
1920 x 1080 프레임을 가정하므로, 이 예제는 터미널에서 실행됩니다. 별칭 `3D투영`은 숫자로 시작해서
숫자로 읽히므로 호출할 수 없습니다. 그래서 코드에서는 영어 이름 `project_3d`를 씁니다.

```ling
바인드 start = 실행 {
    카메라설정(1, 0, 1, 0)
    println("정면:   " + str(project_3d(0, 0, 5)))
    println("오른쪽: " + str(project_3d(1, 0, 5)))
    카메라좌표(2, 0, 0)
    println("이동:   " + str(project_3d(0, 0, 5)))
    카메라좌표(0, 0, 0)
    println("뒤쪽:   " + str(project_3d(0, 0, -20)))
}
```

```output
정면:   [960, 540, 5]
오른쪽: [1068, 540, 5]
이동:   [744, 540, 5]
뒤쪽:   [-99999, -99999, -20]
```

깊이 10(5에 `zdist`를 더한 값)에서 오른쪽으로 한 단위는, 초점 거리 1080일 때 108픽셀 이동합니다.

### `mouse_ray()`

카메라 피벗에서 마우스 아래 픽셀을 지나는 월드 공간 광선을 리스트 `[ox, oy, oz, dx, dy, dz]`, 즉
원점과 방향으로 반환합니다. `project_3d`의 역입니다. 광선을 따라가면 클릭해서 이동하기에 필요한
커서 아래 지면을 찾을 수 있습니다.

```ling-gui
바인드 start = 실행 {
    바인드 광선 = mouse_ray()
    바인드 t = (2 - 광선[1]) / 광선[4]          # 광선이 y = 2 바닥과 만나는 지점
    바인드 바닥x = 광선[0] + 광선[3] * t
    바인드 바닥z = 광선[2] + 광선[5] * t
}
```

## 자유 비행 카메라

마우스로 둘러보고, WASD로 걷고, 회전하는 정육면체를 바라봅니다. `(sin yaw, cos yaw)` 방향으로
움직이면 걷는 방향이 시선과 맞춰집니다. 마우스와 키보드 내장 함수는
[입력과 마이크](input.md)에, 조명은 [포스트 FX와 조명](postfx.md)에 있습니다.

```ling-gui
바인드 start = 실행 {
    창열기(900, 600, "비행")
    마우스잡기()
    깊이테스트(1)
    바인드 요 = 0.0
    바인드 피치 = 0.0
    바인드 px = 0.0
    바인드 pz = -4.0
    바인드 t = 0.0
    동안 창열림() {
        바인드 요 = 요 + mouse_dx() * 0.003
        바인드 피치 = 범위제한(피치 + mouse_dy() * 0.003, -1.5, 1.5)
        바인드 fx = 사인(요) * 0.08
        바인드 fz = 코사인(요) * 0.08
        만약 키누름("w") { 바인드 px = px + fx  바인드 pz = pz + fz }
        만약 키누름("s") { 바인드 px = px - fx  바인드 pz = pz - fz }
        만약 키누름("d") { 바인드 px = px + fz  바인드 pz = pz - fx }
        만약 키누름("a") { 바인드 px = px - fz  바인드 pz = pz + fx }
        카메라설정(코사인(요), 사인(요), 코사인(피치), 사인(피치))
        카메라좌표(px, 0, pz)
        채우기(8, 10, 24)
        조명초기화()
        조명추가(-3, -6, 0, 1.0, 0.95, 0.85, 1.0, 0)
        격자무늬(0, 2, 8, 1, 0, 0, 0, 0, 1, 20, 20, 1, 1, t, 0)
        색설정(240, 150, 110)
        정육면체(0, 0, 8, 1, 1, 1, t * 0.5, t, 0, 0)
        표시()
        바인드 t = t + 0.02
    }
}
```
