# 폰트와 UI

이 페이지는 텍스트와 인터페이스를 다룹니다. 선명한 벡터 윤곽으로 그리는 TrueType·OpenType 폰트, 내장
스트로크 폰트, 그리고 미터·게이지·컨트롤로 이루어진 `ui_*` 툴킷입니다. 모두 [2D 그리기](drawing.md)
호출과 같은 프레임 버퍼에 그리므로 `fill()`과 `present()` 사이에 둡니다. 3D 장면 위에 그리려면 먼저
`flush_3d()`를 호출하십시오. 타자기 효과의 대화 상자는 별도 페이지 [대화](dialog.md)에 있습니다.

## 폰트

Ling은 두 종류의 텍스트를 그립니다.

* **벡터 폰트.** `font_load`가 `.ttf`나 `.otf` 파일을 읽고, `font_text_fill`, `font_text`,
  `font_text_3d`가 글리프 윤곽을 그립니다. 곡선이 유지되므로 어떤 크기에서도 글자가 선명합니다. 폰트에
  글리프가 있다면 라틴 문자, 중국어, 일본어, 한국어, 타이어 모두 쓸 수 있습니다.
* **스트로크 폰트.** `ui_text`는 폰트 파일 없이 간단한 고정폭 "홀로그램" 서체로 기본 ASCII 텍스트를
  그립니다.

글리프를 처음 쓸 때 그 윤곽이 프로그램을 실행한 폴더의 `cache/fonts/` 아래 디스크에 캐시되므로, 다음
실행부터는 더 빨리 시작합니다. 웹 런타임에서는 `font_load`가 `-1`을 반환합니다. 두 환경 모두에서 돌아가는
프로그램을 원하면 핸들을 확인하고 `ui_text`로 대체하십시오.

```ling-gui
바인드 start = 실행 {
    창열기(720, 320, "폰트")
    바인드 글꼴 = 글꼴로드("assets/fonts/Exo2.ttf", 600)
    바인드 한중일 = 글꼴로드("assets/fonts/NotoSansKR.ttf")
    동안 창열림() {
        채우기(8, 10, 24)
        색설정(0, 230, 255)
        글꼴채움(글꼴, 30, 40, 48, "Hello Ling")
        색설정(255, 200, 80)
        글꼴텍스트(글꼴, 30, 110, 48, "Stroked Outline")
        색설정(255, 255, 255)
        글꼴채움(한중일, 30, 180, 40, "안녕하세요 Ling")
        색설정(120, 255, 160)
        UI텍스트(30, 260, 16, "UI TEXT 0123")
        표시()
    }
}
```

### `font_load(path, weight)`

폰트를 불러와 핸들(첫 폰트는 0, 다음은 1, 이런 식)을 반환하고, 읽을 수 없으면 `-1`을 반환합니다. 이때
오류 스트림에 메시지가 나옵니다. 경로는 주어진 그대로 먼저 시도하고, 다음으로 스크립트 폴더 기준으로
시도합니다. `weight`는 선택 사항입니다. 가변 폰트라면 600 같은 숫자로 굵은 모양을 얻을 수 있고, 0이나
생략은 폰트의 기본값을 씁니다.

Ling 저장소는 `assets/fonts/`에 Exo2, Orbitron, Rajdhani, Noto Sans(SC, JP, KR, Thai), Galmuri를
포함합니다. 프로그램이 여러 폴더에서 시작될 수 있다면 두 번째 경로를 시도하십시오.

```ling-gui
바인드 start = 실행 {
    바인드 글꼴 = 글꼴로드("assets/fonts/Exo2.ttf", 600)
    만약 글꼴 < 0 { 바인드 글꼴 = 글꼴로드("../../assets/fonts/Exo2.ttf", 600) }
}
```

### `font_text_fill(font, x, y, px, text)`와 `font_text(font, x, y, px, text)`

`font_text_fill`은 펜 색으로 채운 글리프를 그리고, `font_text`는 그 윤곽선을 그립니다. 윤곽선 쪽이
가볍고 `set_blend`와 `set_antialias`를 따릅니다. `x, y`는 기준선이 아니라 줄의 **왼쪽 위**입니다.
대문자는 `y`에서 약 `0.3 * px` 아래에서 시작하고, 기준선은 약 `0.97 * px` 아래에 있습니다. `px`는 픽셀
단위 크기입니다(기본값 16). `set_font_antialias(1)`을 호출하지 않으면 가장자리가 또렷합니다. 잘못된
핸들은 아무것도 그리지 않습니다.

### `font_text_3d(font, cx, cy, cz, ux, uy, uz, vx, vy, vz, size, text, fill_rows)`

3D 평면 위에 텍스트를 그립니다. 장면과 함께 깊이 정렬되므로 카메라를 따라 돕니다. `c`는 줄이 시작하는
곳, `u`는 글자가 나아가는 방향(기본값 `1, 0, 0`), `v`는 글리프의 위쪽 방향(기본값 `0, 1, 0`), `size`는
월드 단위의 1em 높이(기본값 1)입니다. +y가 아래이므로 똑바로 선 텍스트에는 `v = (0, -1, 0)`이 필요합니다.
`fill_rows`가 0보다 크지 않으면 윤곽선만 그리고, 크면 각 글리프를 그만큼의 주사선으로 채웁니다.

```ling-gui
바인드 start = 실행 {
    바인드 글꼴 = 글꼴로드("assets/fonts/Exo2.ttf", 600)
    색설정(120, 230, 255)
    글꼴3D(글꼴, -2, 0, 8, 1, 0, 0, 0, -1, 0, 0.6, "LING 3D")
}
```

### `font_width(font, px, text)`

문자열의 너비(픽셀)입니다(잘못된 핸들이면 0). 순서에 주의하십시오. 크기가 텍스트보다 **앞에** 옵니다.
상자 `bx, by, bw, bh` 가운데에 라벨을 두려면 `x = bx + (bw - font_width(f, px, text)) / 2`,
`y = by + bh / 2 - 0.64 * px`에 그리십시오.

### `font_advance(font, char)`와 `font_glyph_outline(font, char, tol)`

`font_advance`는 문자 하나의 전진 폭을 em 단위로 줍니다(픽셀 크기를 곱하십시오).
`font_glyph_outline`은 직접 효과를 만들 수 있도록 문자의 윤곽을 반환합니다. 윤곽선들의 리스트이며, 각
윤곽선은 em 단위의 평평한 리스트 `[x0, y0, x1, y1, ...]`이고 기준선은 0, **y는 위쪽**입니다. `tol`은
폴리라인이 실제 곡선에서 벗어날 수 있는 거리입니다(기본값 0.01em). 실패하면 빈 리스트입니다.

### `font_fallback(primary, fallback, scale)`

`primary`에 없는 모든 문자에 `fallback`을 씁니다. 예를 들어 멋스러운 라틴 폰트 뒤에 유니코드 범위가
넓은 폰트를 둘 수 있습니다. `scale`은 주 폰트 대비 대체 폰트의 크기입니다(기본값 1). `fallback`에
`-1`을 넘기면 해제됩니다. 주 폰트 핸들을, 핸들이 잘못되었으면 `-1`을 반환합니다.

```ling-gui
바인드 start = 실행 {
    바인드 라틴 = 글꼴로드("assets/fonts/Orbitron.ttf", 600)
    바인드 넓은글꼴 = 글꼴로드("assets/fonts/NotoSansKR.ttf")
    font_fallback(라틴, 넓은글꼴, 0.9)
}
```

### `set_font_antialias(on)`와 `get_font_antialias()`

글리프를 부드럽게 할지 정합니다(기본값은 꺼짐이라 글자가 또렷함). 인수 없이 `set_font_antialias()`를
호출하면 켜집니다. 선 획에 영향을 주는 `set_antialias`와는 별개입니다.

### `ui_text(x, y, scale, text)`

내장 스트로크 폰트로 펜 색을 써서 텍스트를 그립니다. `x, y`는 왼쪽 위이고, 글리프 높이는 `scale`
픽셀(기본값 16), 폭은 각각 `scale * 0.62`, 간격은 `scale * 0.24`입니다. 글자는 대문자로 그려지며, 서체에
없는 문자(한글을 포함한 모든 비 ASCII 텍스트)는 작은 상자로 나옵니다.

## UI 툴킷

`ui_*` 내장 함수는 **즉시 모드** 툴킷입니다. 프레임 사이에 아무것도 저장하지 않습니다. 매 프레임 현재
값을 넘겨 각 위젯을 호출하면 위젯이 스스로를 그리고, 상호작용하는 컨트롤은 새 값을 반환합니다. 모든 상태는
프로그램이 평범한 변수로 가지고 있습니다.

```ling-gui
바인드 start = 실행 {
    창열기(480, 220, "컨트롤")
    바인드 음량 = 0.4
    바인드 켜짐 = 0
    동안 창열림() {
        채우기(6, 10, 22)
        바인드 음량 = 슬라이더(40, 60, 280, 음량, 0, 1)
        바인드 켜짐 = 토글(40, 100, 52, 24, 켜짐)
        만약 버튼(40, 150, 120, 36) == 1 { println("클릭됨") }
        색설정(220, 240, 255)
        UI텍스트(64, 160, 14, "PLAY")
        표시()
    }
}
```

공통 규칙:

* **좌표**는 화면 픽셀입니다. 사각형 위젯은 `x, y, w, h`를, 원형 위젯은 중심 `cx, cy`와 반지름 `r`을 받습니다.
* **색**은 테마(`ui_theme`)에서 옵니다. 대부분의 위젯은 그 호출에서만 주 색을 바꾸는 선택적인 마지막
  `r, g, b`를 받습니다. 셋 다 넘기거나 하나도 넘기지 마십시오.
* **위젯은 텍스트를 그리지 않습니다.** 버튼에는 라벨이, 탭 줄에는 제목이 없습니다. 라벨은 `ui_text`나
  `font_text_fill`로 직접 그리십시오.
* **상호작용**은 마우스 왼쪽 버튼을 읽습니다. 버튼은 마우스가 그 위에서 눌린 바로 그 프레임에만 `1`을
  반환하므로 `== 1`과 비교하십시오. 이를 위해 프레임마다 한 번 `present()`가 필요합니다.
* **혼합.** 위젯은 `set_blend`를 따르므로 `set_blend(1)`이면 빛납니다.

| `ui_slotgrid(x, y, cols, rows, cell, selected)` | `物品格` | `スロットグリッド` | `슬롯격자` | `ช่องไอเทม` | 인벤토리 격자 |
| `ui_vignette(intensity)` | `暗角` | `ビネット` | `비네트` | `ขอบมืด` | 화면 가장자리 경고 빛 |
| `ui_gauge3d(cx, cy, r, value, max, spin)` | `立体仪表` | `立体ゲージ` | `입체게이지` | `มาตรวัด3มิติ` | 회전하는 고리 게이지 |
| `ui_panel3d(x, y, w, h, depth)` | `立体面板` | `立体パネル` | `입체패널` | `แผง3มิติ` | 돌출된 패널 |
| `ui_radar3d(cx, cy, r, tilt, sweep)` | `立体雷达` | `立体レーダー` | `입체레이더` | `เรดาร์3มิติ` | 기울어진 레이더 접시 |
| `ui_sound(name)` | `界面音` | `UI音` | `인터페이스음` | `เสียงปุ่ม` | 짧은 인터페이스 소리 |

### `ui_theme(...)`와 `ui_theme_colors()`

`ui_theme`은 모든 위젯이 쓰는 색을 설정합니다. `r, g, b` 세 쌍 여섯 개를 primary(주 색), accent(강조),
track(미터의 어두운 배경), warn(경고), text(텍스트), bg(패널 채움) 순으로 넘깁니다. 생략한 세 쌍은 값을
유지하므로 `ui_theme(255, 0, 128)`은 주 색만 바꿉니다. `ui_theme_colors()`는 현재 테마를 숫자 18개의
리스트로 반환하므로, 직접 그린 인터페이스를 테마에 맞출 수 있습니다.

```ling
바인드 start = 실행 {
    인터페이스테마(255, 0, 128)
    println(ui_theme_colors())
}
```

```output
[255, 0, 128, 40, 255, 180, 44, 62, 100, 255, 90, 90, 190, 235, 255, 10, 16, 24]
```

출력에서 나머지 다섯 색의 내장 기본값도 볼 수 있습니다.

### 레이아웃 도우미: `ui_hot`, `ui_frame`, `ui_bevel`, `ui_panel`, `ui_scanlines`

`ui_hot`은 마우스가 사각형 안에 있으면 `true`를 반환합니다. 호버 효과와 직접 만든 컨트롤에 쓰십시오.
`ui_frame`(괄호 팔 길이, 기본값 14)과 `ui_bevel`(모서리 깎기, 기본값 10)은 펜 색으로 윤곽선을 그립니다.
`ui_panel`은 테마의 bg 색으로 채운 베벨 패널을 그립니다(베벨 기본값 12, 여섯 번째 인수부터 선택적인 테두리
색). `ui_scanlines`는 가로선 `density`개를 그립니다(기본값 24).

```ling-gui
바인드 start = 실행 {
    패널(20, 20, 340, 200, 14)
    만약 핫존(40, 140, 120, 36) { 색설정(255, 255, 255) } 아니면 { 색설정(120, 140, 160) }
    베벨틀(40, 140, 120, 36, 8)
}
```

### HUD: `ui_radar`, `ui_compass`, `ui_reticle`, `ui_target`

`ui_radar`는 거리 고리와 라디안 각도 `sweep`의 스윕을 그립니다. `time_now()`로 구동하십시오.
`ui_compass`는 **도** 단위 `heading`을 가운데로 하는 띠를 15도마다 눈금을 넣어 보여 줍니다. `ui_reticle`은
`spread`가 0에서 1로 갈수록 틈이 벌어지는 고리를 그립니다. `ui_target`은 `lock`이 0에서 1로 갈수록 좁혀지는
괄호를 그립니다.

### 미터: `ui_bar`, `ui_segbar`, `ui_gauge`, `ui_ring`, `ui_vu`, `ui_spark`, `ui_battery`, `ui_progress`

각 미터는 `max`(기본값 1) 중 `value`를 보여 줍니다. `ui_segbar`는 막대를 블록 `segments`개(기본값 10)로
나눕니다. `ui_gauge`는 바늘 달린 다이얼이고, `ui_ring`은 시계 방향으로 채워집니다. `ui_vu`는 0부터 1까지의
레벨 리스트를 받아 막대를 하나씩 그리며, 레벨이 오를수록 경고 색으로 물듭니다. `ui_spark`는 숫자가 두 개
이상인 리스트를 상자에 맞게 늘입니다. `ui_battery`는 25퍼센트 미만에서 경고 색으로 바뀝니다. `ui_progress`는
0부터 1까지의 `fraction` 하나를 받습니다.

```ling-gui
바인드 start = 실행 {
    막대(40, 70, 280, 14, 70, 100)
    분할막대(40, 96, 280, 14, 6, 10, 10)
    게이지(450, 120, 50, 62, 100)
    음량막대(330, 330, 160, 60, [0.2, 0.5, 0.8, 1.0, 0.7, 0.3])
}
```

### 컨트롤: `ui_button`, `ui_toggle`, `ui_slider`, `ui_checkbox`, `ui_tabs`, `ui_stepper`, `ui_tooltip`

- `ui_button`은 호버하면 강조되고, 클릭된 프레임에 `1`을, 그 밖에는 `0`을 반환합니다.
- `ui_toggle`과 `ui_checkbox`는 현재 상태를 받아 새 상태 `1` 또는 `0`을 반환합니다.
- `ui_slider`에는 높이 인수가 없습니다(잡는 영역은 높이 20픽셀). 새 값을 반환하며, 버튼을 누르고 있는
  동안 값이 커서를 따라갑니다.
- `ui_tabs`는 같은 크기의 탭 `count`개를 그리고 활성 인덱스(0부터)를 반환합니다. 제목을 놓으려면 너비를
  `count`로 나누십시오.
- `ui_stepper`는 한쪽이 클릭되면 `value`에 `step`을 더하거나 뺀 값을 반환합니다. 숫자는 그리지 않습니다.
- `ui_tooltip`은 말풍선입니다. 무언가에 호버할 때 커서 근처에 그리십시오.

```ling-gui
바인드 start = 실행 {
    바인드 선택탭 = 0
    바인드 개수 = 3
    바인드 선택탭 = 탭(20, 250, 300, 28, 3, 선택탭)
    바인드 개수 = 스테퍼(160, 178, 140, 28, 개수, 1)
    UI텍스트(222, 186, 14, str(개수))
}
```

### 게임 UI: `ui_healthbar`, `ui_cooldown`, `ui_counter`, `ui_minimap`, `ui_dpad`, `ui_slotgrid`, `ui_vignette`

`ui_healthbar`는 비었을 때 경고 색에서 가득 찼을 때 강조 색으로 바뀌며, `pulse`(0~1)는 30퍼센트 미만에서
흰색 쪽으로 깜빡이게 합니다. `ui_cooldown`은 12시 방향부터 시계 방향으로 파이 조각을 채웁니다.
`ui_counter`는 `value`를 7세그먼트 숫자 `digits`자리로 보여 줍니다. `ui_minimap`은 빈 지도 틀을 그리며,
점은 `draw_disc`로 직접 찍으십시오. `ui_dpad`는 마우스를 누르고 있는 동안 `0` 없음, `1` 위, `2` 오른쪽,
`3` 아래, `4` 왼쪽을 반환합니다. `ui_slotgrid`는 칸 `selected`를 강조합니다(`-1`이면 없음).
`ui_vignette`는 화면 가장자리를 빛나게 해서 피격 효과로 쓸 수 있습니다.

```ling-gui
바인드 start = 실행 {
    바인드 체력 = 24
    체력바(20, 300, 220, 16, 체력, 100, 0.5 + 0.5 * 사인(현재시간() * 8))
    카운터(20, 340, 16, 28, 1234, 5)
    슬롯격자(400, 260, 5, 2, 40, 1)
}
```

### 의사 3D: `ui_gauge3d`, `ui_panel3d`, `ui_radar3d`

`ui_gauge3d`는 `spin`에 따라 도는 와이어프레임 띠를 그리고 `value`까지 불을 켭니다. `ui_panel3d`는 베벨
패널을 화면에서 `depth`픽셀(기본값 14)만큼 띄웁니다. `ui_radar3d`는 레이더를 화면 안쪽으로 기울입니다
(`tilt` 0~1, 기본값 0.9).

### `ui_sound(name)`

짧게 합성한 인터페이스 소리를 냅니다. `"click"`(모르는 이름의 대체값이기도 함), `"hover"`, `"confirm"`,
`"toggle"`, `"tick"`, `"error"` 중 하나입니다. 오디오가 실행 중이 아니면 소리가 나지 않습니다.

```ling-gui
바인드 start = 실행 {
    만약 버튼(20, 400, 120, 36) == 1 { 인터페이스음("confirm") }
}
```
