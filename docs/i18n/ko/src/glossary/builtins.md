# 크레이트별 내장 함수

각 언어의 내장 함수 이름을 제공하는 크레이트별로 묶었습니다. 런타임이 실제로 제공하고 어휘 파일에 이름이 있는 내장 함수만 실었습니다. 매개변수와 예제는 [내장 함수 레퍼런스](../reference/index.md)를 보세요.
