# 쌍곡 3D

소스: [`examples/physics/hyperbolic3d.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic3d.ling)

파일 이름과 달리, 이 데모의 현재 버전은 보통의(유클리드) 3D 공간 속 물리 미로입니다. 공을 굴려 와이어프레임 미로를
지나가고, 벽에 튕기고, 힘을 모아 점프합니다. 그동안 공의 움직임을 따라 소리가 변합니다. 진짜 쌍곡 기하는
[쌍곡 세계](hyperbolic-world.md)에서 볼 수 있습니다.

저장소 루트에서 실행합니다.

```sh
ling run examples/physics/hyperbolic3d.ling
```

## 조작

| 키 | 동작 |
|---|---|
| `W` / `S` | 공을 앞 / 뒤로 밀기 |
| `A` / `D` | 공을 왼쪽 / 오른쪽으로 밀기 |
| `Space` | 누르고 있으면 힘을 모으고, 떼면 점프 |
| `←` / `→` | 카메라를 공 주위로 돌리기 |
| `↑` / `↓` | 카메라 기울이기 |
| `Z` / `X` | 확대 / 축소 |

## 작동 방식

- **물리.** 매 프레임 중력을 더하고, 속도에 감쇠 계수(`DAMPING = 0.99`)를 곱한 뒤 공을 움직입니다. 공이 벽을 넘으면
  프로그램이 공을 다시 밀어내고 속도를 반대로 바꾼 다음 `ELASTICITY = 0.80`을 곱합니다.
- **미로.** 300 × 200 × 300 크기의 바깥 상자와 안쪽 벽 다섯 개입니다. 벽은 사각형으로 충돌을 검사하고 `draw_line_3d`로
  선을 그려 표시합니다.
- **점프.** 땅 위에서 `Space`를 누르고 있으면 `MAX_CHARGE`까지 힘이 모입니다. 떼면 공이 튀어 오릅니다. 공에 붙은 작은
  미터가 모인 힘을 보여 줍니다.
- **공.** 회전하는 `vtex_chakra` 바퀴로 그리며, 높이에 따라 색이 바뀝니다. 바닥의 십자 그림자, 바닥까지 내린 선, 빨간
  속도 화살표가 공의 위치를 알기 쉽게 해 줍니다.
- **물리를 따라가는 소리.** `audio_tone` 성부 하나가 매 프레임 바뀝니다. 음높이는 높이와 속도에 따라 올라가고 튕길
  때마다 잠깐 치솟습니다. 음량은 속도와 함께 커지고, 좌우 위치는 공의 x 좌표를 따라갑니다.
- **조명.** 천천히 떠다니는 따뜻한 빛, 차가운 보조광, 공을 따라다니는 보라색 빛, 이렇게 세 개입니다.

## 해 볼 만한 것

- 파일 맨 위의 `GRAVITY`, `DAMPING`, `ELASTICITY`를 바꿔 차이를 느껴 보세요.
- 벽을 추가해 보세요. 벽 충돌 검사 하나를 복사하고, 맞는 `draw_line_3d` 호출로 그리면 됩니다.
- 다른 값을 소리에 연결해 보세요. 예를 들어 모은 힘의 크기로 음높이를 바꿔 보세요.
