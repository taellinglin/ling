# 쌍곡 세계 (H²×ℝ)

소스: [`examples/physics/hyperbolic_world.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic_world.ling)

땅이 **쌍곡 평면**인 작은 블록 세계입니다. [Hypermine](https://github.com/Ralith/hypermine)에서 영감을 받았습니다.
Hypermine의 무대는 완전한 3차원 쌍곡 공간(H³)이지만, 이 데모는 가장 간단하게 플레이할 수 있는 사촌 격인
**H²×ℝ**를 씁니다. 쌍곡 평면(푸앵카레 원판으로 그림) 위를 걷고, 수직 방향의 중력은 평소와 똑같이 작용합니다.

저장소 루트에서 실행합니다.

```sh
ling run examples/physics/hyperbolic_world.ling
```

## 조작

| 키 | 동작 |
|---|---|
| `W` / `S` | 앞으로 / 뒤로 걷기 |
| `A` / `D` | 왼쪽 / 오른쪽으로 옆걸음 |
| `Q` / `E` | 왼쪽 / 오른쪽으로 돌기 |
| `Space` | 점프 |

## 무엇이 쌍곡적인가

- **가장자리로 갈수록 빽빽해집니다.** 블록은 여러 겹의 고리 위에 있고, 바깥 고리일수록 블록이 많습니다
  (`cells = 6 * ring`). 원판의 가장자리는 무한히 먼 곳을 뜻하며, 가장자리에 가까울수록 블록이 몰리고 `1 − |z|²` 비율로 작아집니다.
- **뫼비우스 이동.** 여러분은 원판 가운데에 그대로 있고, 세계가 뫼비우스 평행 이동 `z ↦ (z + a) / (1 + ā z)`로 발밑을
  미끄러져 갑니다. 방향을 바꾸면 세계가 중심을 축으로 회전합니다.
- **홀로노미.** 정사각형 같은 닫힌 경로를 한 바퀴 돌면 돌아왔을 때 방향이 바뀌어 있습니다. 음의 곡률을 가진 공간을
  지나갈 때 생기는 현상입니다.
- **평범한 중력.** 점프와 낙하는 보통의 수직 축을 쓰므로 다른 게임과 똑같은 느낌입니다.

## 텍스처 없는 블록

각 블록은 자신의 고리와 위치를 해시(`hash01`, `fract(sin(...))` 방식의 해시)해서 종류(풀, 돌, 흙, 수정)와 높이를
정합니다. 색은 종류에 따라 정해지고, 나머지는 셀 셰이딩 설정(`set_shade_mode`, `set_cel_bands`, `set_rim`)이
마무리합니다. 텍스처 파일은 필요 없습니다. [포스트 FX와 조명](../reference/postfx.md)을 보세요.

## 해 볼 만한 것

- 블록은 `cube`로 그립니다. `cylinder`나 [3D 도형과 메시](../reference/shapes.md)의 다른 도형도 써 보세요.
- 고리 개수 제한(`ring <= 4`)을 늘리면 세계가 커집니다.
- `STEP`과 `TURN`을 바꿔 더 빨리 걷거나 돌아 보세요.

다른 종류의 3D 데모는 [쌍곡 3D](hyperbolic-3d.md)를 보세요.
