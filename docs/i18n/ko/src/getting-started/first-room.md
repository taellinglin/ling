# 첫 번째 3D 방

이제 터미널을 벗어날 차례입니다. 이 페이지에서는 창을 열고, 모든 Ling 화면을 움직이는 프레임
루프를 배우고, 화살표 키로 걸어 다닐 수 있는 작은 3D 방을 만듭니다. Ling은 내장 소프트웨어
렌더러로 모든 것을 그리므로 게임 엔진이나 GPU가 필요 없습니다.

창을 여는 프로그램은 터미널에서 검사할 수 없으므로 코드 블록에 출력이 없습니다. **Escape**를
누르거나 창을 닫으면 멈춥니다.

## 프레임 루프

창은 한 번에 정지된 그림(프레임) 하나를 보여 줍니다. 프로그램은 프레임을 그려서 보여 주고, 곧바로
다음 프레임을 시작합니다. 모든 그래픽 프로그램은 같은 리듬을 따릅니다.

1. 창을 **엽니다**. 한 번만 합니다.
2. `채우기`로 화면을 **지웁니다**. 이전 프레임이 남지 않게 합니다.
3. 도형을 **그립니다**.
4. `표시()`로 프레임을 **보여 줍니다**.

루프 조건은 `동안 창열림()`입니다. 창을 닫거나 Escape를 누르면 거짓이 되므로 종료 코드를 직접
작성할 필요가 없습니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(640, 400, "나의 첫 창")
    바인드 각도 = 0
    동안 창열림() {
        채우기(15, 18, 40)
        색설정(255, 120, 60)
        정육면체(0, 0, 3, 1, 1, 1, 각도, 각도 * 0.7, 0, 0)
        표시()
        바인드 각도 = 각도 + 0.02
    }
}
```

- `창열기(640, 400, "나의 첫 창")`은 640 x 400 크기의 창을 엽니다. 크기를 먼저, 제목을 마지막에
  씁니다.
- `채우기(15, 18, 40)`은 창 전체를 칠합니다. 색은 0부터 255까지의 빨강, 초록, 파랑입니다.
- `색설정(...)`은 뒤에 오는 도형의 색을 고릅니다.
- `정육면체(...)`는 정육면체를 그립니다. 인수는 세 개씩 묶어서 봅니다. 중심 `x, y, z`, 크기,
  라디안 단위의 회전, 마지막으로 모드(`0` 채움, `1` 와이어프레임, `2` 둘 다)입니다.
- `표시()`는 프레임을 보여 줍니다. 호출하지 않으면 아무것도 보이지 않습니다.
- 매 프레임 `각도`를 다시 바인딩하기 때문에 정육면체가 돕니다.

## 좌표계

Ling의 3D 세계에서 **x**는 오른쪽, **y**는 **아래쪽**, **z**는 화면 안쪽으로 멀어지는 방향입니다.
그래서 "위"는 음수 y입니다. 아래 방에서 바닥은 `y = 3`, 천장은 `y = -3`에 있습니다.

카메라는 원점에서 z 방향을 바라봅니다. 세 가지 호출로 카메라가 보는 장면을 바꿉니다.

| 호출 | 하는 일 |
|---|---|
| `카메라좌표(x, y, z)` | 카메라를 옮깁니다. |
| `카메라설정(cos_yaw, sin_yaw, cos_pitch, sin_pitch)` | 카메라를 돌립니다. 각도의 코사인과 사인을 넘기므로, `a`만큼 돌리려면 `카메라설정(코사인(a), 사인(a), 1, 0)`을 호출합니다. |
| `Z거리설정(d)` | 눈이 그림 뒤로 얼마나 떨어져 있는지 정합니다. `0.5` 같은 작은 값이 1인칭 시점에 어울립니다. |

카메라 함수는 매 프레임, 그리기 전에 호출하십시오.

## 걸어 다닐 수 있는 방

다음 프로그램은 지금까지의 내용을 모두 합칩니다. 격자로 된 바닥과 천장, 벽 네 개, 기둥 네 개,
조명 하나, 회전하는 중앙 장식, 그리고 키보드 조작이 있습니다. `room.ling`으로 저장하십시오.

```ling-gui
# 걸어 다닐 수 있는 방.
# 좌우 화살표로 회전, 상하 화살표로 이동. Escape로 종료.

함수 기둥(x, z) {
    색설정(200, 190, 170)
    원기둥(x, 0, z, 0.5, 3, 0.5, 0, 0, 0, 0)
}

함수 벽(프레임) {
    # 바닥과 천장 (y는 아래쪽이므로 바닥은 y = 3)
    격자무늬(0, 3, 0,   1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  프레임, 0)
    격자무늬(0, -3, 0,  1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  프레임, 2)
    # 세워진 벽 네 개
    격자무늬(0, 0, 8,   1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  프레임, 1)
    격자무늬(0, 0, -8,  1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  프레임, 1)
    격자무늬(-8, 0, 0,  0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  프레임, 3)
    격자무늬(8, 0, 0,   0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  프레임, 3)
    # 안쪽 벽의 꽃
    꽃무늬(0, 0, 7.9,  1, 0, 0,  0, -1, 0,  1.6, 24,  프레임, 0)
}

바인드 시작 = 실행 {
    창열기(960, 600, "나의 3D 방")
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    환경광설정(0.3)

    바인드 위치x = 0
    바인드 위치z = -5
    바인드 방향 = 0
    바인드 프레임 = 0

    동안 창열림() {
        # 입력: 회전과 이동
        만약 키누름("left") {
            바인드 방향 = 방향 - 0.03
        }
        만약 키누름("right") {
            바인드 방향 = 방향 + 0.03
        }
        만약 키누름("up") {
            바인드 위치x = 위치x + 사인(방향) * 0.1
            바인드 위치z = 위치z + 코사인(방향) * 0.1
        }
        만약 키누름("down") {
            바인드 위치x = 위치x - 사인(방향) * 0.1
            바인드 위치z = 위치z - 코사인(방향) * 0.1
        }

        # 그리기
        채우기(8, 8, 20)
        카메라설정(코사인(방향), 사인(방향), 1, 0)
        카메라좌표(위치x, 0, 위치z)
        Z거리설정(0.5)
        조명초기화()
        조명추가(0, -2.5, 0, 1.0, 0.85, 0.6, 1.0, 14)

        벽(프레임 * 0.3)
        기둥(-6, -6)
        기둥(6, -6)
        기둥(-6, 6)
        기둥(6, 6)

        색설정(240, 200, 80)
        토러스(0, 1.5, 0, 0.7, 0.7, 0.7, 1.2, 프레임 * 0.03, 0)

        표시()
        바인드 프레임 = 프레임 + 1
    }
}
```

실행합니다.

```sh
ling run room.ling
```

동작 방식:

- `기둥`과 `벽`은 방의 일부를 그리는 함수입니다. 루프 안에서 호출되므로 매 프레임 다시 그립니다.
  함수는 자신의 매개변수와 최상위 이름만 볼 수 있으므로 `벽`에 `프레임`을 매개변수로 넘깁니다.
- `창열기` 다음의 네 줄은 차분하고 정확한 색으로 바꿉니다. 이 줄이 없으면 Ling의 기본 스타일이
  그림자를 남색으로 물들이고 빛나는 테두리를 더합니다.
- `위치x`, `위치z`, `방향`은 카메라의 위치와 방향을 담습니다. `키누름("left")`은 왼쪽 키를
  누르고 있는 동안 참입니다. 걸을 때는 x로 `사인(방향)`, z로 `코사인(방향)`만큼, 즉 바라보는
  방향으로 움직입니다.
- `조명초기화()`와 `조명추가(x, y, z, r, g, b, 세기, 반경)`는 매 프레임 호출합니다. 그렇지 않으면
  조명이 계속 쌓입니다. 조명은 천장 근처인 `y = -2.5`에 있습니다.
- `격자무늬`와 `꽃무늬`는 평면 위에 선 무늬를 그립니다. 처음 세 숫자는 중심, 다음 여섯 숫자는
  평면의 "오른쪽"과 "위쪽" 방향입니다. y가 아래쪽이므로 세워진 벽의 "위쪽"은 `0, -1, 0`입니다.

벽은 그려져 있을 뿐 단단하지 않습니다. 그대로 통과해 걸어갈 수 있습니다.

## 해 보기

- 각 `격자무늬` 호출의 마지막 숫자(색조)를 바꿔 다른 색을 만들어 보십시오.
- 기둥을 하나 더 세우거나, 다른 색의 `조명추가`를 하나 더 넣어 보십시오.
- `표시()` 뒤에 `만약 키눌림("p") { screenshot("room") }`을 추가하십시오. P를 누르면
  `screenshots` 폴더에 PNG가 저장됩니다.
