# 헬로 월드

모든 Ling 프로그램은 값이 `실행` 블록인 시작 바인딩에서 출발합니다. 한국어로 시작 바인딩의
이름은 `시작`입니다. 무언가를 출력하는 가장 작은 프로그램은 다음과 같습니다.

## 첫 프로그램

다음 코드를 `hello.ling`으로 저장합니다.

```ling
바인드 시작 = 실행 {
    출력("안녕하세요, 세계!")
}
```
```output
안녕하세요, 세계!
```

실행합니다.

```sh
ling run hello.ling
```

- `바인드 시작 = ...`은 값에 `시작`이라는 이름을 붙입니다. Ling은 이 이름으로 프로그램의
  출발점을 찾습니다(영어로는 `start`).
- `실행 { ... }`은 차례대로 실행되는 단계들의 블록입니다.
- `출력(...)`은 터미널에 한 줄을 씁니다.

## 조금 더

바인딩은 `시작` 바깥에도 둘 수 있습니다. 다음 프로그램은 이름에 인사한 뒤 리스트를 돌며
인사합니다.

```ling
# 친구 몇 명에게 인사하기
바인드 이름 = "령"
바인드 시작 = 실행 {
    출력("안녕하세요, " + 이름 + "!")
    위해 친구 안에 ["민준", "서연", "지우"] {
        출력("안녕, " + 친구)
    }
}
```
```output
안녕하세요, 령!
안녕, 민준
안녕, 서연
안녕, 지우
```

`+`는 텍스트를 이어 붙이고, `위해 ... 안에`는 리스트의 항목마다 블록을 한 번씩 실행합니다.

한국어 프로그램을 실행하면 `ling`은 감지한 언어를 표준 오류에 알려 줍니다. 예를 들면
`[detected language: Korean (한국어)]`입니다. 프로그램 실행에는 영향을 주지 않습니다.

## 여러 언어 섞어 쓰기

모든 키워드와 내장 함수에는 영어, 중국어, 일본어, 한국어, 태국어 이름이 있고, 한 파일 안에서
자유롭게 섞어 쓸 수 있습니다. 다음 프로그램은 다섯 언어를 모두 사용합니다.

```ling
令 名字 = "Ling"
bind start = do {
    พิมพ์("สวัสดี " + 名字)
    만약 참 {
        印刷("こんにちは")
    }
}
```
```output
สวัสดี Ling
こんにちは
```

다섯 언어가 어떻게 함께 동작하는지는 [다섯 가지 언어로 작성하기](../language/multilingual.md)를
읽어 보십시오.
