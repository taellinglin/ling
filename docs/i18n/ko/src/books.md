# Ling 북 (PDF)

Ling 북은 Ling 2030.1.53을 기준으로 쓴 네 권짜리 시리즈입니다. 모든 권을 무료 PDF로 내려받을 수 있습니다.
책은 영어로 쓰여 있습니다.

| 권 | 수준 | 쪽수 | 다운로드 |
|---|---|---|---|
| **Learn Ling** (Ling 배우기) | 입문 | 321 | [ling-beginner.pdf](https://ling-lang.org/books/ling-beginner.pdf) (13 MB) |
| **Build with Ling** (Ling으로 만들기) | 중급 | 716 | [ling-intermediate.pdf](https://ling-lang.org/books/ling-intermediate.pdf) (27 MB) |
| **Mastering Ling** (Ling 마스터하기) | 고급 | 452 | [ling-advanced.pdf](https://ling-lang.org/books/ling-advanced.pdf) (16 MB) |
| **The Ling Reference** (Ling 레퍼런스) | 완전한 레퍼런스 | 650 | [ling-reference.pdf](https://ling-lang.org/books/ling-reference.pdf) (26 MB) |

## 각 권의 내용

### Learn Ling (입문)

값과 바인딩, 조건과 반복, 함수, 리스트와 텍스트, 첫 번째 3D 방, 그리기와 게임, 소리와 음악. 마지막에는 프로젝트
하나를 완성합니다.

### Build with Ling (중급)

레코드(`form`), 오류와 결과, 모듈과 프로젝트 구조, 데이터와 파일, UI 앱, 애니메이션과 입력, 게임과 물리, 음악 도구,
테스트와 디버깅, 패키징과 배포.

### Mastering Ling (고급)

Ling이 실행되는 방식, 동시성과 격리(isolate), 네트워크 서비스, Rust 크레이트로 만드는 웹 앱, 암호화, P2P 프로토콜,
AI와 텐서, Rust에서 크레이트 사용하기, Ling 확장하기, Ling OS와 임베디드 대상, 대규모 앱 설계.

### The Ling Reference

모든 키워드와 내장 함수의 매개변수, 반환값, 별칭, 예제를 담았습니다. 마지막 장에는 알려진 제한 사항과 주의할 점이
정리되어 있습니다.

## 무엇을 읽을까요

- **프로그래밍이나 Ling이 처음이라면:** *Learn Ling*부터 시작하세요.
- **실제 프로그램을 만든다면:** *Build with Ling*을 읽으세요.
- **깊이 알고 싶다면:** *Mastering Ling*을 읽으세요.
- **무언가를 찾아본다면:** *The Ling Reference*를 곁에 두세요.

이 문서는 짧은 온라인 안내서입니다. 책은 더 깊이 다루며 하나의 Ling 버전에 맞춰 쓰였습니다. 빠르게 찾아볼 때는
[내장 함수 레퍼런스](reference/index.md)와 [알려진 제한 사항](language/limits.md) 페이지가 더 빠를 때가 많습니다.
