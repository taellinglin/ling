# 값과 바인딩

모든 프로그램은 정보를 다룹니다. 점수, 이름, "예" 또는 "아니요" 같은 대답이 그렇습니다. 이번
수업에서는 Ling의 기본 값 종류를 알아보고, `바인드`(`bind`)로 이름을 붙이고, 다시 바인딩해서
값을 "바꾸고", 화면에 출력해 봅니다. 단계마다 작은 프로그램이 있으니 파일에 복사해서
`ling run`으로 실행해 보세요.

## 값

정보 하나를 **값**이라고 합니다. 가장 자주 쓰는 종류는 다음과 같습니다.

| 종류 | 담는 것 | 예 |
|---|---|---|
| 숫자 | 정수나 소수 같은 모든 수 | `42`, `3.14`, `-7` |
| 텍스트 | 글자, 단어, 문장 (*문자열*이라고도 합니다) | `"안녕"`, `"101호"` |
| 불리언 | 두 대답 중 하나: 예 또는 아니요 | `참`, `거짓` |
| 리스트 | 한 줄로 늘어선 여러 값 | `[1, 2, 3]`, `["빨강", "파랑"]` |

종류별로 하나씩 출력해 봅시다.

```ling
바인드 시작 = 실행 {
  출력(42)
  출력(3.14)
  출력("텍스트 한 조각")
  출력(참)
  출력([1, 2, 3])
}
```
```output
42
3.14
텍스트 한 조각
true
[1, 2, 3]
```

숫자는 그대로 씁니다. 텍스트는 큰따옴표로 감쌉니다. `참`과 `거짓`은 텍스트가 아니므로 따옴표를
붙이지 않습니다. 출력하면 `true`와 `false`로 보입니다. 리스트는 대괄호로 감싸고 항목 사이에
쉼표를 넣습니다.

값을 쓰는 몇 가지 규칙입니다.

- 숫자는 보통 숫자로 쓰고 소수점은 하나까지만 씁니다. `.5`가 아니라 `0.5`로 씁니다. `1e3`이나
  `0xff` 같은 표기는 없습니다.
- 텍스트에는 큰따옴표만 씁니다. 텍스트 안에서 `\n`은 줄바꿈, `\"`는 따옴표입니다.

## 바인딩: 값에 이름 붙이기

`바인드`로 값에 이름을 붙입니다. 그 뒤로는 이름이 값을 대신합니다.

```ling
바인드 시작 = 실행 {
  바인드 이름 = "미나"
  바인드 나이 = 12
  출력("안녕, " + 이름)
  출력(이름, "는 ", 나이, "살")
  출력("내년: ", 나이 + 1)
}
```
```output
안녕, 미나
미나는 12살
내년: 13
```

`바인드 나이 = 12`는 "이름 `나이`를 값 12에 바인딩한다"라고 읽습니다. 이름에는 글자, 숫자,
밑줄을 쓸 수 있지만 숫자로 시작할 수는 없습니다. 값의 의미를 알려 주는 이름을 고르세요.
`a`보다 `나이`가 낫습니다.

여러분이 쓰는 모든 프로그램은 `바인드 시작 = 실행 { ... }`으로 시작합니다. 중괄호 안의 명령이
위에서 아래로 실행됩니다.

## 다시 바인딩하기: Ling에서 "바꾸는" 방법

Ling에는 **대입문이 없습니다**. `점수 = 점수 + 5`라고 쓰면 구문 오류입니다. 이름에 새 값을
주려면 다시 바인딩합니다.

```ling
바인드 시작 = 실행 {
  바인드 점수 = 10
  출력("점수: ", 점수)
  바인드 점수 = 점수 + 5
  출력("점수: ", 점수)
  바인드 점수 = 점수 * 2
  출력("점수: ", 점수)
}
```
```output
점수: 10
점수: 15
점수: 30
```

`바인드 점수 = 점수 + 5`는 먼저 지금의 `점수` 값으로 오른쪽을 계산한 다음, 그 결과에 `점수`라는
이름표를 붙입니다. 무언가를 바꾸고 싶을 때마다 `바인드`를 쓰는 습관을 들이세요.

## 출력

`출력`은 인수를 화면에 쓰고 줄을 바꿉니다. 영어 `println`도 똑같이 동작합니다. Ling에서는 둘 다
줄바꿈으로 끝납니다. 인수를 여러 개 넘기면 차례대로 출력되는데, **사이에 아무것도 넣지 않습니다**.
공백도 넣지 않습니다.

```ling
바인드 시작 = 실행 {
  출력("합계", 1 + 2)
  출력("합계: ", 1 + 2)
  출력("가", "나", "다")
  출력("첫째 줄\n둘째 줄")
  출력("그녀가 \"안녕\"이라고 했다")
}
```
```output
합계3
합계: 3
가나다
첫째 줄
둘째 줄
그녀가 "안녕"이라고 했다
```

공백이 필요하면 `"합계: "`처럼 텍스트 안에 넣으세요.

## 산술

Ling은 익숙한 기호를 씁니다. `+`, `-`, `*`, `/`, 그리고 나머지를 구하는 `%`입니다.

```ling
바인드 시작 = 실행 {
  출력(7 + 3)
  출력(7 / 2)
  출력(7 % 2)
  출력(2 + 3 * 4)
  출력((2 + 3) * 4)
  출력(반올림(3.7))
  출력(제곱근(81))
}
```
```output
10
3.5
1
14
20
4
9
```

나눗셈은 버림 없이 정확한 답(`3.5`)을 줍니다. 곱셈이 덧셈보다 먼저 계산되므로 `2 + 3 * 4`는
`14`입니다. 다른 순서를 원하면 괄호를 쓰세요. `반올림`과 `제곱근`은 **내장 함수**, 즉 Ling에
처음부터 들어 있는 함수입니다.

## 텍스트와 숫자 변환

`+`로 텍스트 두 개를 이어 붙일 수 있습니다. 숫자를 텍스트에 붙이려면 먼저 `str`로 텍스트로
바꿉니다(`to_str`도 같은 함수입니다). 반대로 `to_number`는 텍스트를 숫자로 바꿉니다.

```ling
바인드 시작 = 실행 {
  바인드 사과 = 3
  출력("사과가 " + str(사과) + "개 있어요")
  바인드 입력 = "12"
  출력(to_number(입력) + 1)
  출력(서식("{} + {} = {}", 2, 3, 2 + 3))
  출력(서식("약 {:.2}", 3.14159))
}
```
```output
사과가 3개 있어요
13
2 + 3 = 5
약 3.14
```

`서식`(`format`)은 템플릿의 `{}`를 뒤의 인수로 차례대로 채웁니다. `{:.2}`는 숫자를 소수점 아래
두 자리로 보여 줍니다.

## 비교와 불리언

비교는 "예 또는 아니요" 질문을 하고 `참`이나 `거짓`을 돌려줍니다.

```ling
바인드 시작 = 실행 {
  출력(5 > 3)
  출력(5 == 5)
  출력(5 != 5)
  출력("고양이" == "고양이")
  바인드 크다 = 100 > 50
  출력("크다: ", 크다)
  출력(참 && 거짓)
  출력(참 || 거짓)
  출력(!참)
}
```
```output
true
true
false
true
크다: true
false
true
false
```

비교 연산자는 `==`, `!=`, `<`, `>`, `<=`, `>=`입니다. `=` 하나는 절대 비교가 아니며 `바인드`
안에만 나옵니다. 대답은 `&&`(그리고: 둘 다 참), `||`(또는: 적어도 하나가 참), `!`(부정)로
조합합니다. 수학처럼 비교를 이어 쓰지 마세요. `1 < x < 10`이 아니라 `x > 1 && x < 10`으로 씁니다.

## 주석

한 줄에서 `#`나 `//` 뒤는 모두 주석입니다. Ling은 이를 무시합니다. 사람을 위한 메모입니다.

```ling
# 작은 더치페이 계산기
바인드 시작 = 실행 {
  바인드 금액 = 84.50
  바인드 인원 = 4      // 함께 먹은 친구들
  바인드 일인당 = 금액 / 인원
  출력("한 사람당 ", 반올림(일인당 * 100) / 100)
}
```
```output
한 사람당 21.13
```

`반올림(x * 100) / 100`은 화면에 보여 주기 좋게 숫자를 소수점 아래 두 자리로 반올림합니다.
