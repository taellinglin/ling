# 리스트와 텍스트

지금까지는 이름 하나가 값 하나를 담았습니다. 이번 수업에서는 여러 값을 **리스트**에 함께 담고,
반복문으로 하나씩 살펴보고, 텍스트를 나누었다가 다시 합쳐 봅니다. 마지막으로 작은 단어 세기
프로그램을 만듭니다.

## 리스트 만들기

리스트는 대괄호로 감싸고 항목 사이에 쉼표를 넣어 씁니다.

```ling
바인드 시작 = 실행 {
  바인드 과일 = ["사과", "바나나", "체리"]
  출력(과일)
  출력(길이(과일))
  출력(요소가져오기(과일, 0))
  출력(과일[2])
}
```
```output
[사과, 바나나, 체리]
3
사과
체리
```

- 리스트를 출력하면 항목이 대괄호 안에 보입니다.
- `길이(과일)`은 항목의 개수입니다.
- `요소가져오기(과일, 0)`은 위치 0의 항목을 읽습니다. `과일[2]`는 `요소가져오기(과일, 2)`를 짧게 쓴 것입니다.

**위치는 0부터 시작합니다.** 첫 항목은 위치 0이고, 세 항목 중 마지막은 위치 2입니다. 위치를
"몇 개를 건너뛰는가"로 생각하면 쉽습니다. 위치는 0부터 `길이(xs) - 1` 사이로 유지하세요. 없는
위치를 요청하면 기본 엔진에서는 빈 값이 나오고, 인터프리터에서는 오류가 납니다.

## 리스트 바꾸기: 항상 다시 바인딩하기

`목록추가`(`list_push`)는 끝에 항목을 더하고, `list_set`은 어떤 위치의 항목을 바꿉니다. 둘 다
**새** 리스트를 돌려줍니다. 그것을 남기려면 이름을 다시 바인딩하세요.

```ling
바인드 시작 = 실행 {
  바인드 과일 = ["사과", "바나나", "체리"]
  바인드 과일 = 목록추가(과일, "대추")
  출력(과일)
  바인드 과일 = list_set(과일, 1, "블루베리")
  출력(과일)
  출력("이제 과일이 ", 길이(과일), "가지")
}
```
```output
[사과, 바나나, 체리, 대추]
[사과, 블루베리, 체리, 대추]
이제 과일이 4가지
```

항상 `바인드 과일 = 목록추가(과일, "대추")`로 쓰고, `목록추가(과일, "대추")`만 따로 쓰지 마세요.
[값과 바인딩](values.md)에서 배운 다시 바인딩하는 습관과 같습니다.

## 반복문으로 리스트 만들기

`새목록()`으로 빈 리스트를 만들고 항목을 넣어 갑니다. [조건과 반복](control-flow.md)의 스코프 규칙을
기억하세요. `위해` 본문은 결과를 남길 수 없으므로 리스트는 `동안`으로 만듭니다.

```ling
바인드 시작 = 실행 {
  바인드 제곱수 = 새목록()
  바인드 i = 1
  동안 i < 8 {
    바인드 제곱수 = 목록추가(제곱수, i * i)
    바인드 i = i + 1
  }
  출력(제곱수)
}
```
```output
[1, 4, 9, 16, 25, 36, 49]
```

## 리스트 훑어보기

리스트를 **읽기만** 할 때는 `위해`로 충분합니다. 결과도 모아야 한다면 위치를 쓰는 `동안`을 쓰세요.

```ling
바인드 시작 = 실행 {
  바인드 점수들 = [72, 95, 88, 61, 79]
  위해 s 안에 점수들 {
    출력("점수: ", s)
  }
  바인드 합계 = 0
  바인드 최고 = 점수들[0]
  바인드 i = 0
  동안 i < 길이(점수들) {
    바인드 s = 점수들[i]
    바인드 합계 = 합계 + s
    만약 s > 최고 {
      바인드 최고 = s
    }
    바인드 i = i + 1
  }
  출력("합계: ", 합계)
  출력("평균: ", 합계 / 길이(점수들))
  출력("최고: ", 최고)
  출력("list_max의 답: ", list_max(점수들, 0))
}
```
```output
점수: 72
점수: 95
점수: 88
점수: 61
점수: 79
합계: 395
평균: 79
최고: 95
list_max의 답: 95
```

`최고`는 첫 항목에서 시작해서, 더 큰 항목이 나올 때마다 그 항목으로 바뀝니다. 내장 함수
`list_max`와 `list_min`도 같은 일을 합니다. 두 번째 인수는 리스트가 비었을 때의 답입니다.

## 텍스트 도구

Ling에는 텍스트를 다루는 내장 함수가 여럿 있습니다.

```ling
바인드 시작 = 실행 {
  바인드 s = "  안녕, Ling 세상  "
  출력(길이(s))
  바인드 s = trim(s)
  출력("[" + s + "]")
  출력(str_upper(s))
  출력(str_lower(s))
  출력(substr(s, 0, 2))
  출력(str_find(s, "Ling"))
  출력(str_find(s, "Python"))
  출력(str_replace(s, "세상", "친구"))
  출력(starts_with(s, "안녕"))
  출력(str_repeat("하", 3))
}
```
```output
15
[안녕, Ling 세상]
안녕, LING 세상
안녕, ling 세상
안녕
4
-1
안녕, Ling 친구
true
하하하
```

| 내장 함수 | 용도 |
|---|---|
| `길이(s)` | 글자 수 |
| `trim(s)` | 양 끝의 공백 제거 |
| `str_upper(s)`, `str_lower(s)` | 대소문자 바꾸기 |
| `substr(s, 시작, 개수)` | 위치 `시작`(0부터)에서 `개수`만큼의 글자 |
| `str_find(s, 부분)` | 처음 찾은 위치, 없으면 `-1` |
| `str_replace(s, 원래, 새것)` | 모든 `원래`를 `새것`으로 바꾸기 |
| `starts_with(s, 부분)`, `ends_with(s, 부분)` | `참` 또는 `거짓` |
| `str_repeat(s, n)` | 텍스트를 `n`번 반복 |

리스트 내장 함수처럼 이 함수들도 원래 텍스트를 바꾸지 않습니다. 새 텍스트를 돌려주므로 결과를
바인딩하세요: `바인드 s = trim(s)`.

## 나누기와 합치기

`split`은 구분자가 나오는 곳마다 텍스트를 잘라 리스트로 만듭니다. `list_join`은 리스트를 다시 하나의
텍스트로 붙입니다(`join`도 같은 내장 함수입니다).

```ling
바인드 시작 = 실행 {
  바인드 한줄 = "빨강,초록,파랑"
  바인드 조각 = split(한줄, ",")
  출력(조각)
  출력(길이(조각))
  출력(list_join(조각, " | "))
  바인드 숫자들 = split("3 8 15", " ")
  출력(to_number(숫자들[1]) + 1)
}
```
```output
[빨강, 초록, 파랑]
3
빨강 | 초록 | 파랑
9
```

`split`이 만든 조각은 텍스트입니다. 계산하기 전에 `to_number`로 바꾸세요.

## 한 글자씩

`substr(s, i, 1)`은 위치 `i`의 글자 하나를 돌려줍니다. 이것으로 텍스트를 뒤집어 봅시다.

```ling
함수 뒤집기(s) {
  바인드 결과 = ""
  바인드 i = 길이(s) - 1
  동안 i >= 0 {
    바인드 결과 = 결과 + substr(s, i, 1)
    바인드 i = i - 1
  }
  반환 결과
}

바인드 시작 = 실행 {
  출력(뒤집기("가나다"))
  출력(뒤집기("기러기") == "기러기")
}
```
```output
다나가
true
```

## 단어 세기

Ling에는 아직 사전 타입이 없으므로 리스트 두 개를 나란히 둡니다. `단어들`에는 서로 다른 단어를 하나씩,
`횟수들`에는 각 단어가 몇 번 나왔는지를 담습니다. 도우미 함수가 단어의 위치를 찾습니다.

```ling
함수 위치(항목들, 대상) {
  바인드 i = 0
  동안 i < 길이(항목들) {
    만약 항목들[i] == 대상 {
      반환 i
    }
    바인드 i = i + 1
  }
  반환 -1
}

바인드 시작 = 실행 {
  바인드 전체 = split("고양이 개 새 고양이 개 고양이 물고기", " ")
  바인드 단어들 = 새목록()
  바인드 횟수들 = 새목록()
  바인드 i = 0
  동안 i < 길이(전체) {
    바인드 w = 전체[i]
    바인드 p = 위치(단어들, w)
    만약 p == -1 {
      바인드 단어들 = 목록추가(단어들, w)
      바인드 횟수들 = 목록추가(횟수들, 1)
    } 아니면 {
      바인드 횟수들 = list_set(횟수들, p, 횟수들[p] + 1)
    }
    바인드 i = i + 1
  }
  바인드 k = 0
  동안 k < 길이(단어들) {
    출력(단어들[k], ": ", 횟수들[k])
    바인드 k = k + 1
  }
}
```
```output
고양이: 3
개: 2
새: 1
물고기: 1
```

> **참고:** `==`는 숫자, 텍스트, 불리언을 비교합니다. 리스트 두 개를 `==`로 비교하면 항목이 같아도
> 항상 `거짓`입니다. 항목을 하나씩 비교하세요.
