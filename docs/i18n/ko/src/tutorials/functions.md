# 함수

함수는 이름이 붙은 요리법입니다. 단계를 한 번 써 두면 원하는 만큼 다시 쓸 수 있습니다. `출력`,
`반올림`, `str` 같은 내장 함수는 이미 써 보았습니다. 이번 수업에서는 `함수`(`fn`)로 직접 함수를
만들고, 매개변수를 주고, `반환`(`return`)으로 답을 돌려받고, 함수가 자기 자신을 호출하게 해 봅니다.

## 함수 정의하고 호출하기

```ling
함수 인사(이름) {
  출력("안녕하세요, " + 이름 + "님!")
}

바인드 시작 = 실행 {
  인사("에이다")
  인사("그레이스")
  인사("미나")
}
```
```output
안녕하세요, 에이다님!
안녕하세요, 그레이스님!
안녕하세요, 미나님!
```

- `함수`는 "지금부터 함수를 정의한다"는 뜻입니다.
- `인사`는 함수의 이름입니다.
- 괄호 안의 `이름`은 **매개변수**입니다. 함수를 호출할 때마다 채워지는 빈칸입니다.
- 중괄호 안은 **본문**, 즉 함수가 실행하는 단계입니다.

함수를 정의하는 것만으로는 실행되지 않습니다. 본문은 `인사("에이다")`처럼 함수를 **호출**할 때만
실행됩니다. 괄호 안의 값을 **인수**라고 하며, 그 호출 동안 `이름`의 값이 됩니다.

함수는 파일의 최상위, 즉 `바인드 시작` 바깥에 둡니다. 실제로 일을 하는 명령은 `시작` 안에 둡니다.

## `반환`으로 답 돌려받기

함수가 무언가를 계산해서 답을 돌려주기를 바랄 때가 많습니다. 그게 `반환`이 하는 일입니다.
매개변수는 쉼표로 구분해 여러 개 받을 수 있습니다.

```ling
함수 제곱(n) {
  반환 n * n
}

함수 평균(a, b) {
  반환 (a + b) / 2
}

바인드 시작 = 실행 {
  출력(제곱(7))
  출력(평균(10, 25))
  출력(제곱(평균(2, 4)))
}
```
```output
49
17.5
9
```

`제곱(7)`은 값을 가지므로 값이 들어갈 수 있는 곳이면 어디든 쓸 수 있습니다. `출력` 안, 더 큰 식
안, 또는 다른 호출의 인수로도 씁니다. `제곱(평균(2, 4))`는 안쪽부터 계산됩니다. `평균(2, 4)`는 3이고
`제곱(3)`은 9입니다.

### 일찍 반환하기

처음 실행된 `반환`에서 함수가 끝납니다. 이를 이용해 특별한 경우를 먼저 처리하세요.

```ling
함수 설명(n) {
  만약 n < 0 {
    반환 "음수"
  }
  만약 n == 0 {
    반환 "영"
  }
  반환 "양수"
}

함수 세제곱(n) { n * n * n }

바인드 시작 = 실행 {
  출력(설명(-5))
  출력(설명(0))
  출력(설명(12))
  출력(세제곱(3))
}
```
```output
음수
영
양수
27
```

`설명`에는 `아니면`이 필요 없습니다. `반환`이 이미 함수를 빠져나가기 때문입니다. `세제곱`은
줄여 쓰는 방법을 보여 줍니다. `반환`이 없으면 함수는 마지막 식의 값을 돌려줍니다. `인사`처럼
아무것도 계산하지 않는 함수는 "없음" 값 `()`을 돌려줍니다.

## 함수가 볼 수 있는 것

호출될 때마다 함수는 자기만의 이름을 가집니다. 매개변수와 함수 안에서 바인딩한 것들입니다. 이
이름들은 호출한 쪽 코드의 이름과 부딪히지 않습니다.

```ling
바인드 세율 = 0.2

함수 세금포함(가격) {
  바인드 합계 = 가격 + 가격 * 세율
  반환 합계
}

바인드 시작 = 실행 {
  바인드 합계 = 99
  출력(세금포함(50))
  출력("내 합계는 여전히 ", 합계)
}
```
```output
60
내 합계는 여전히 99
```

함수는 `세율`처럼 파일 최상위에 있는 바인딩을 볼 수 있습니다. 상수를 두기 좋은 곳입니다. 하지만
호출한 함수의 지역 이름은 **볼 수 없습니다**. 필요한 것은 인수로 넘겨 주세요.

## 자기 자신을 호출하는 함수

함수는 자기 자신을 호출할 수 있습니다. 이것을 **재귀**라고 합니다. 재귀에는 두 부분이 필요합니다.

1. **기저 사례**: 답을 바로 알 수 있을 만큼 단순한 경우입니다.
2. **재귀 사례**: 자기 자신을 호출해 더 작은 문제를 푸는 경우입니다.

5의 계승은 `5 * 4 * 3 * 2 * 1`이고, 이는 `5 * 계승(4)`와 같습니다.

```ling
함수 계승(n) {
  만약 n <= 1 {
    반환 1
  }
  반환 n * 계승(n - 1)
}

함수 피보나치(n) {
  만약 n < 2 {
    반환 n
  }
  반환 피보나치(n - 1) + 피보나치(n - 2)
}

바인드 시작 = 실행 {
  출력("5! = ", 계승(5))
  출력("10! = ", 계승(10))
  위해 i 안에 0..10 {
    출력("피보나치(", i, ") = ", 피보나치(i))
  }
}
```
```output
5! = 120
10! = 3628800
피보나치(0) = 0
피보나치(1) = 1
피보나치(2) = 1
피보나치(3) = 2
피보나치(4) = 3
피보나치(5) = 5
피보나치(6) = 8
피보나치(7) = 13
피보나치(8) = 21
피보나치(9) = 34
```

`계승(3)`을 손으로 따라가 봅시다. `3 * 계승(2)`를 돌려주는데, 그러려면 `2 * 계승(1)`이 필요하고,
`계승(1)`은 기저 사례라서 1입니다. 그다음 답이 거슬러 올라갑니다. `2 * 1 = 2`, 이어서 `3 * 2 = 6`입니다.
기저 사례가 없으면 함수는 공간이 바닥날 때까지 자기 자신을 계속 호출합니다.

## 종합 연습: FizzBuzz

1부터 15까지 셉니다. 3의 배수면 `Fizz`, 5의 배수면 `Buzz`, 둘 다의 배수면 `FizzBuzz`를 출력하고,
그 밖에는 숫자를 출력합니다.

```ling
함수 fizzbuzz(n) {
  만약 n % 15 == 0 {
    반환 "FizzBuzz"
  }
  만약 n % 3 == 0 {
    반환 "Fizz"
  }
  만약 n % 5 == 0 {
    반환 "Buzz"
  }
  반환 str(n)
}

바인드 시작 = 실행 {
  위해 n 안에 1..16 {
    출력(fizzbuzz(n))
  }
}
```
```output
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

15 검사를 가장 먼저 둡니다. 그렇지 않으면 15가 3 검사에서 멈춰 `Fizz`만 출력됩니다. 함수는 숫자를
낱말로 바꾸고, `시작`은 반복하며 출력하기만 합니다. 좋은 함수는 한 가지 일만 하고, 필요한 것을
매개변수로 받고, 무엇을 하는지 알려 주는 이름을 가집니다.

## 값으로서의 함수

어떤 언어에서는 함수를 바인딩에 담거나 다른 함수에 넘길 수 있습니다. Ling에도 이를 위한 짧은
클로저 문법 `|x| x * 2`가 있지만, 현재 버전에서 함수 값은 언어에서 가장 불안정한 부분입니다.
바인딩에 담은 클로저나 인수로 넘긴 함수는 `()`를 돌려주거나 `unknown function`을 보고할 수
있습니다. 항상 동작하는 형태는 클로저를 쓴 자리에서 바로 호출하는 것뿐입니다.

```ling
바인드 시작 = 실행 {
  출력((|x| x + 1)(5))
}
```
```output
6
```

지금은 이름 있는 `함수`를 만들고 이름으로 호출하세요. 자세한 내용은 [알려진 제한 사항](../language/limits.md)을 참고하세요.

> **팁:** 함수 이름의 철자가 틀리면 기본 엔진은 오류 대신 `()`를 출력합니다. 함수가 "아무것도 하지
> 않는" 것처럼 보이면 `ling run --interp yourfile.ling`으로 프로그램을 실행하세요. `unknown function`을
> 알려 줍니다.
