# 그리기와 게임

이 페이지에서는 원, 삼각형, 선, 그라데이션으로 평면 2D 그림을 그리고, 그림이 키보드와 마우스에
반응하게 만든 다음, 이 모든 것을 합쳐 직접 해 보고 고칠 수 있는 작은 게임을 만듭니다. 여기서
쓰는 것은 모두 Ling에 들어 있는 내장 함수이므로 이미지 파일이나 게임 엔진이 필요 없습니다.

이 프로그램들은 창을 열기 때문에 코드 블록에 출력이 없습니다. **Escape**를 누르거나 창을 닫으면
멈춥니다.

## 창을 열고 프레임 루프 돌리기

그래픽 프로그램은 모두 같은 모양입니다. 창을 한 번 열고, 창이 닫힐 때까지 **지우기, 그리기,
표시하기**를 반복합니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(640, 400, "프레임 루프")
    바인드 t = 0
    동안 창열림() {
        채우기(10, 12, 30)                         # 1. 지우기
        색설정(255, 200, 80)                       # 2. 그리기
        원채우기(320 + 200 * 사인(t * 0.05), 200, 30)
        표시()                                     # 3. 프레임 보여 주기
        바인드 t = t + 1
    }
}
```

- `창열기(너비, 높이, 제목)`(`open_window`)으로 창을 엽니다. 크기가 먼저, 제목이 마지막입니다.
- 창을 닫거나 Escape를 누르면 `창열림()`(`window_is_open`)이 거짓이 됩니다.
- `채우기(r, g, b)`(`fill`)는 창 전체를 한 색으로 칠합니다. 색은 0부터 255까지의 빨강, 초록,
  파랑입니다.
- `표시()`(`present`)는 완성된 프레임을 화면에 올립니다. `표시()`가 없는 프레임은 보이지 않습니다.
- `t`는 프레임을 셉니다. `사인(t * 0.05)`은 -1과 1 사이를 부드럽게 오가므로 원이 좌우로 움직입니다.

프레임 간격을 알려 주는 내장 함수는 없습니다. 실제 초가 필요하면 `현재시간()`(`time_now`,
프로그램 시작 후 지난 초)이나 `프레임수()`(`frame_count`)를 쓰세요.

## 2D 캔버스

창은 픽셀 격자입니다. 수학 시간과 두 가지가 다릅니다.

- 원점 `(0, 0)`은 **왼쪽 위** 모서리입니다.
- **y는 아래로 갈수록 커집니다.** `y = 300`은 `y = 100`보다 화면에서 더 아래입니다.

그림은 **펜**으로 그립니다. `색설정(r, g, b)`(`set_color`)로 펜 색을 고르면, 다시 바꿀 때까지
그 뒤의 모든 도형이 그 색으로 그려집니다.

| 내장 함수 | 그리는 것 |
|---|---|
| `fill(r, g, b)` / `채우기` | 창 전체를 한 색으로 |
| `draw_disc(cx, cy, r)` / `원채우기` | 채운 원 |
| `draw_circle(cx, cy, r)` | 원 윤곽선 |
| `triangle(x0, y0, x1, y1, x2, y2)` / `삼각형그리기` | 채운 삼각형 |
| `draw_line(x0, y0, x1, y1)` / `선그리기` | 가는 선 |
| `draw_arc(cx, cy, r, a0, a1, segments)` | 원 윤곽선의 일부. 각도는 라디안, 시계 방향 |
| `draw_poly([x0, y0, x1, y1, ...])` / `다각형채우기` | 납작한 점 리스트로 만든 채운 다각형 |
| `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` / `그라데사각` | 두 색 사이로 변하는 사각형. `dir`이 1이면 위에서 아래, 0이면 왼쪽에서 오른쪽 |
| `set_color_hsl(h, s, l)` / `HSL색설정` | 색상 0-360, 채도 0-100, 명도 0-100으로 펜 색 지정 |

단색 사각형을 채우는 내장 함수는 없습니다. 한 색에서 같은 색으로 가는 그라데이션은 단색 사각형이
되므로 도우미 함수를 직접 만듭니다.

```ling-module
함수 사각형(x, y, 너비, 높이, r, g, b) {
    그라데사각(x, y, 너비, 높이, r, g, b, r, g, b, 1)
}
```

> **팁:** 그리기 호출이 아무것도 하지 않는 것 같으면 철자를 확인하세요. `draw_rect` 같은 알 수
> 없는 이름은 조용히 무시됩니다.

### 풍경화

뒤에서 앞으로 층을 쌓아 그립니다. 나중에 그린 도형이 먼저 그린 도형 위를 덮습니다.

```ling-gui
함수 사각형(x, y, 너비, 높이, r, g, b) {
    그라데사각(x, y, 너비, 높이, r, g, b, r, g, b, 1)
}

함수 나무(x, 땅) {
    사각형(x - 6, 땅 - 50, 12, 50, 110, 70, 40)
    색설정(40, 150, 70)
    원채우기(x, 땅 - 70, 32)
    원채우기(x - 20, 땅 - 50, 24)
    원채우기(x + 20, 땅 - 50, 24)
}

바인드 시작 = 실행 {
    창열기(800, 500, "풍경")
    바인드 t = 0
    동안 창열림() {
        그라데사각(0, 0, 800, 380, 30, 40, 110, 250, 150, 140, 1)   # 하늘
        색설정(255, 220, 120)
        원채우기(600, 300, 60)                                       # 해
        색설정(70, 60, 110)
        삼각형그리기(0, 380, 150, 190, 300, 380)                     # 산
        삼각형그리기(200, 380, 380, 150, 560, 380)
        사각형(0, 380, 800, 120, 50, 110, 60)                        # 땅
        나무(120, 440)
        나무(330, 460)
        나무(690, 450)
        색설정(20, 20, 30)                                           # 새
        바인드 날갯짓 = 사인(t * 0.15) * 6
        draw_arc(150, 120 - 날갯짓, 18, 3.4, 6.0, 16)
        draw_arc(186, 120 - 날갯짓, 18, 3.4, 6.0, 16)
        표시()
        바인드 t = t + 1
    }
}
```

`나무(x, 땅)`는 인수를 기준으로 줄기와 잎을 놓으므로 나무를 원하는 만큼 심을 수 있습니다. 새의
날개는 호 두 개입니다. y가 아래를 향하므로 각도는 시계 방향으로 커집니다. `0`은 오른쪽, `3.14`는
왼쪽을 가리킵니다.

## 키보드 읽기

Ling에는 이벤트 핸들러가 없습니다. 프레임마다 키가 눌려 있는지 **물어봅니다**.

- `키누름("left")`(`key_down`)은 키를 누르고 있는 동안 계속 참입니다.
- `키눌림("space")`(`key_pressed`)은 키가 눌린 바로 그 한 프레임에만 참입니다. 점프나 다시 시작처럼
  한 번 누를 때 한 번만 일어나는 일에 쓰세요.

키 이름은 영어 소문자 문자열입니다. `"a"`부터 `"z"`, 숫자, `"left"`, `"right"`, `"up"`, `"down"`,
`"space"`, `"enter"`, `"escape"`, `"lshift"` 등이 있습니다. 알 수 없는 이름은 그냥 거짓입니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(640, 400, "공 움직이기")
    바인드 x = 320
    바인드 y = 200
    동안 창열림() {
        바인드 속도 = 3
        만약 키누름("lshift") {
            바인드 속도 = 8
        }
        만약 키누름("left") {
            바인드 x = x - 속도
        }
        만약 키누름("right") {
            바인드 x = x + 속도
        }
        만약 키누름("up") {
            바인드 y = y - 속도
        }
        만약 키누름("down") {
            바인드 y = y + 속도
        }
        바인드 x = 범위제한(x, 20, 620)
        바인드 y = 범위제한(y, 20, 380)

        채우기(10, 10, 30)
        색설정(255, 180, 60)
        원채우기(x, y, 20)
        표시()
    }
}
```

거의 모든 게임에는 이 세 부분이 있습니다.

1. **상태:** `x`와 `y`는 루프 밖에 있으므로 프레임에서 프레임으로 값이 유지됩니다.
2. **입력과 갱신:** `키누름` 검사가 상태를 바꾸고, `범위제한`(`clamp`)이 공을 창 안에 붙잡아 둡니다.
3. **그리기:** 상태로부터 그림을 만듭니다.

프레임마다 입력, 갱신, 그리기 순서를 지키세요.

## 마우스 읽기

`mouse_x()`와 `mouse_y()`는 포인터 위치를 픽셀로 알려 줍니다. `mouse_down()`은 왼쪽 버튼을 누르고
있는 동안, `mouse_down_right()`는 오른쪽 버튼을 누르고 있는 동안 참입니다. 이 함수들에는 한국어
별칭이 없어서 영어 이름을 그대로 씁니다.

```ling-gui
바인드 시작 = 실행 {
    창열기(640, 400, "마우스 그림판")
    채우기(245, 240, 225)
    바인드 색상 = 0
    동안 창열림() {
        만약 mouse_down() {
            HSL색설정(색상, 80, 50)
            원채우기(mouse_x(), mouse_y(), 10)
            바인드 색상 = (색상 + 3) % 360
        }
        만약 mouse_down_right() {
            채우기(245, 240, 225)
        }
        표시()
    }
}
```

이 프로그램은 매 프레임 `채우기`를 부르지 않으므로 그린 물감이 캔버스에 남습니다. 오른쪽 클릭은
`채우기`를 한 번 불러 지웁니다.

## 작은 게임: 별 받기

하늘에서 별이 떨어지고, 바구니를 좌우로 움직여 받습니다. 하나 받을 때마다 1점을 얻고 다음 별은
더 빨라집니다. 세 개를 놓치면 게임 오버이고, 스페이스를 누르면 다시 시작합니다.

게임을 만들기 전에 **상태**(바구니의 x, 별의 위치, 떨어지는 속도, 점수, 남은 목숨), **규칙**
(프레임마다 상태가 어떻게 바뀌는지), **그림**(상태를 어떻게 그리는지)을 적어 봅니다.

```ling-gui
함수 사각형(x, y, 너비, 높이, r, g, b) {
    그라데사각(x, y, 너비, 높이, r, g, b, r, g, b, 1)
}

# 오각별: 꼭짓점이 열 개인 다각형.
함수 별(cx, cy, 크기, 회전) {
    바인드 점들 = []
    바인드 i = 0
    동안 i < 10 {
        바인드 각도 = 회전 + i * 0.6283185
        바인드 반지름 = 크기
        만약 i % 2 == 1 {
            바인드 반지름 = 크기 * 0.45
        }
        바인드 점들 = 목록추가(점들, cx + 코사인(각도) * 반지름)
        바인드 점들 = 목록추가(점들, cy + 사인(각도) * 반지름)
        바인드 i = i + 1
    }
    다각형채우기(점들)
}

바인드 시작 = 실행 {
    창열기(640, 480, "별 받기")
    바인드 바구니x = 320
    바인드 별x = 100 + 난수() * 440
    바인드 별y = 0
    바인드 낙하 = 3
    바인드 점수 = 0
    바인드 목숨 = 3
    바인드 t = 0

    동안 창열림() {
        만약 목숨 > 0 {
            # 입력
            만약 키누름("left") || 키누름("a") {
                바인드 바구니x = 바구니x - 7
            }
            만약 키누름("right") || 키누름("d") {
                바인드 바구니x = 바구니x + 7
            }
            바인드 바구니x = 범위제한(바구니x, 50, 590)
            # 갱신
            바인드 별y = 별y + 낙하
            만약 별y > 440 {
                만약 절댓값(별x - 바구니x) < 55 {
                    바인드 점수 = 점수 + 1
                    바인드 낙하 = 낙하 + 0.25
                } 아니면 {
                    바인드 목숨 = 목숨 - 1
                }
                바인드 별x = 50 + 난수() * 540
                바인드 별y = 0
            }
        } 아니면 {
            만약 키눌림("space") {
                바인드 목숨 = 3
                바인드 점수 = 0
                바인드 낙하 = 3
                바인드 별y = 0
            }
        }

        # 그리기
        그라데사각(0, 0, 640, 480, 15, 15, 50, 40, 25, 80, 1)
        색설정(255, 220, 80)
        별(별x, 별y, 24, t * 0.05)
        사각형(바구니x - 50, 445, 100, 14, 90, 190, 255)
        색설정(255, 255, 255)
        UI텍스트(16, 14, 22, "SCORE " + to_str(점수))
        UI텍스트(500, 14, 22, "LIVES " + to_str(목숨))
        만약 목숨 <= 0 {
            색설정(255, 110, 110)
            UI텍스트(170, 200, 36, "GAME OVER")
        }
        표시()
        바인드 t = t + 1
    }
    출력("최종 점수: ", 점수)
}
```

동작 방식:

- **별.** `별`은 `코사인`과 `사인`으로 꼭짓점 열 개의 좌표를 계산해 긴 반지름과 짧은 반지름을
  번갈아 쓰는 납작한 리스트를 만들고, `다각형채우기`(`draw_poly`)에 넘깁니다. `회전` 각도 덕분에
  별이 돌면서 떨어집니다.
- **게임 상태.** `만약 목숨 > 0 { ... } 아니면 { ... }`가 "진행 중"과 "게임 오버"를 오갑니다.
  게임 오버 상태에서는 다시 시작 키만 확인합니다.
- **받기.** 별이 바구니 높이에 닿으면 `절댓값(별x - 바구니x) < 55`로 받았는지 판단합니다.
  `난수()`(`rand`)는 0 이상 1 미만의 수를 돌려주므로 `50 + 난수() * 540`은 50과 590 사이의 무작위
  x입니다.
- **난이도.** `바인드 낙하 = 낙하 + 0.25`로 다음 별이 조금씩 빨라집니다.
- **글자.** `UI텍스트(x, y, 크기, 텍스트)`(`ui_text`)는 내장된 선 글꼴로 펜 색 글자를 그립니다.
  글꼴 파일이 필요 없지만 라틴 대문자와 숫자만 그릴 수 있어서 화면의 글자는 영어로 둡니다.
- **끝.** 창을 닫으면 루프가 끝나고 마지막 줄이 터미널에 점수를 출력합니다.

## 직접 해 보기

1. 얼굴을 그려 보세요. 커다란 노란 원, 눈이 될 작은 어두운 원 두 개, 입이 될 호 하나
   (중심이 `(200, 200)`인 얼굴이라면 `draw_arc(200, 210, 60, 0.4, 2.74, 24)`를 써 보세요).
2. 공이 튕기게 만드세요. 속도 `vx`와 `vy`를 두고 프레임마다 `x`와 `y`에 더한 뒤, 벽에 닿으면
   부호를 뒤집습니다(`바인드 vx = 0 - vx`).
3. 그림판에서 색이 포인터의 x 위치를 따라가게 하세요: `바인드 색상 = mouse_x() / 640 * 360`.
4. 별 받기에 최고 점수를 추가하고 `UI텍스트`로 점수 아래에 보여 주세요.
5. 폭탄을 추가하세요. 어두운 원으로 그리는 두 번째 낙하물로, 받으면 목숨이 하나 줄어듭니다.
