# 조건과 반복

프로그램은 동작을 고르고 되풀이할 수 있을 때 재미있어집니다. 이번 수업에서는 `만약`과 `아니면`으로
판단하고, `동안`과 `위해`로 일을 반복하고, `매치`로 여러 경우 중 하나를 고릅니다. 그리고 Ling을
처음 배우는 사람 대부분이 놀라는 스코프 규칙 하나도 배웁니다.

## `만약`으로 판단하기

```ling
바인드 시작 = 실행 {
  바인드 기온 = 31
  만약 기온 > 30 {
    출력("더워요. 물을 마시세요.")
  }
  출력("확인 끝.")
}
```
```output
더워요. 물을 마시세요.
확인 끝.
```

형태는 `만약 조건 { ... }`입니다. 조건은 `참`이나 `거짓`이 되는 것이면 무엇이든 되며, 보통은
비교입니다. 참이면 블록이 실행되고, 아니면 Ling이 건너뜁니다. 조건에 괄호는 필요 없지만 중괄호는
꼭 써야 합니다.

`기온`을 `20`으로 바꾸고 다시 실행해 보세요. `확인 끝.`만 출력됩니다.

## `아니면`과 `아니면 만약`

`아니면`은 다른 쪽 길입니다. `아니면 만약`으로 판단을 이어 붙일 수 있습니다. Ling은 위에서부터
차례로 확인하고, 조건이 처음으로 참인 블록을 실행합니다.

```ling
바인드 시작 = 실행 {
  바인드 점수 = 83
  만약 점수 >= 90 {
    출력("등급 A")
  } 아니면 만약 점수 >= 80 {
    출력("등급 B")
  } 아니면 만약 점수 >= 70 {
    출력("등급 C")
  } 아니면 {
    출력("계속 연습하세요")
  }
}
```
```output
등급 B
```

83은 70 이상이기도 하지만 `점수 >= 80` 분기가 먼저 나와서 선택됩니다. 가장 큰 기준을 먼저 쓰세요.

조건은 `&&`(그리고), `||`(또는), `!`(부정)로 조합합니다.

```ling
바인드 시작 = 실행 {
  바인드 시각 = 14
  바인드 비 = 참
  바인드 우산있음 = 거짓
  만약 시각 >= 9 && 시각 < 17 {
    출력("가게가 열려 있어요")
  }
  만약 비 && !우산있음 {
    출력("비에 젖겠어요")
  }
  만약 시각 < 6 || 시각 > 22 {
    출력("이제 자야 해요")
  } 아니면 {
    출력("아직 깨어 있어도 돼요")
  }
}
```
```output
가게가 열려 있어요
비에 젖겠어요
아직 깨어 있어도 돼요
```

## `동안`으로 반복하기

`동안`(`while`) 반복문은 조건이 참인 동안 블록을 계속 반복합니다.

```ling
바인드 시작 = 실행 {
  바인드 i = 1
  동안 i <= 5 {
    출력("카운트: ", i)
    바인드 i = i + 1
  }
  출력("발사!")
}
```
```output
카운트: 1
카운트: 2
카운트: 3
카운트: 4
카운트: 5
발사!
```

`동안` 반복문에는 항상 세 부분이 있습니다.

1. 반복 전에 카운터를 준비합니다(`바인드 i = 1`).
2. 반복을 계속할 조건입니다(`i <= 5`).
3. 반복 안에서 일을 하고 **카운터를 앞으로 옮깁니다**(`바인드 i = i + 1`).

3단계를 잊으면 조건이 영원히 참으로 남습니다. 끝나지 않는 프로그램은 **Ctrl+C**로 멈추세요.

### 결과 모으기

`동안`(또는 `만약`) 블록 안의 `바인드`는 블록 바깥의 이름을 바꿉니다. 그래서 누적 합계를 구할 때는
`동안`이 알맞습니다.

```ling
바인드 시작 = 실행 {
  바인드 합계 = 0
  바인드 n = 1
  동안 n <= 100 {
    바인드 합계 = 합계 + n
    바인드 n = n + 1
  }
  출력("1 + 2 + ... + 100 = ", 합계)
}
```
```output
1 + 2 + ... + 100 = 5050
```

## `위해`로 세기

몇 번 반복할지 알 때는 `위해`(`for`)가 더 짧습니다. 숫자의 **범위**나 리스트의 항목을 차례로
지나갑니다.

```ling
바인드 시작 = 실행 {
  위해 i 안에 0..4 {
    출력("i는 ", i)
  }
  위해 k 안에 1..4 {
    출력(k, " x 7 = ", k * 7)
  }
  위해 색 안에 ["빨강", "초록", "파랑"] {
    출력("나는 ", 색, "이 좋아요")
  }
}
```
```output
i는 0
i는 1
i는 2
i는 3
1 x 7 = 7
2 x 7 = 14
3 x 7 = 21
나는 빨강이 좋아요
나는 초록이 좋아요
나는 파랑이 좋아요
```

`0..4`는 0, 1, 2, 3을 뜻합니다. 범위는 두 번째 숫자 **바로 앞**에서 멈춥니다. 그래서
`위해 i 안에 0..4`는 정확히 네 번 실행됩니다.

범위의 끝은 숫자, 이름, 또는 괄호로 감싼 것이어야 합니다. `0..(n + 1)`이나 `0..(길이(xs))`처럼
쓰고, `0..길이(xs)`는 절대 쓰지 마세요. 그렇게 쓰면 아무 말 없이 한 번도 실행되지 않습니다.

### `위해`의 스코프 규칙

모두가 놀라는 규칙입니다. `위해` 반복의 각 회차는 주변 이름의 새 복사본을 받습니다. `위해` 본문
안의 `바인드`는 바깥 이름을 **바꾸지 않습니다**.

```ling
바인드 시작 = 실행 {
  바인드 합계 = 0
  위해 i 안에 1..5 {
    바인드 합계 = 합계 + i
  }
  출력("위해 다음: ", 합계)

  바인드 합계 = 0
  바인드 i = 1
  동안 i < 5 {
    바인드 합계 = 합계 + i
    바인드 i = i + 1
  }
  출력("동안 다음: ", 합계)
}
```
```output
위해 다음: 0
동안 다음: 10
```

기억하기 쉬운 규칙은 이렇습니다. 무언가를 **하기만** 하는 반복(출력, 그리기, 음 연주)에는 `위해`를
쓰세요. **결과를 남겨야** 하는 반복(합계, 개수, 늘어나는 리스트)에는 `동안`을 쓰세요.

Ling에는 동작하는 `break`나 `continue`가 없습니다. `동안` 반복을 일찍 끝내려면
`바인드 찾는중 = 거짓` 같은 플래그로 조건을 거짓으로 만드세요.

### 반복 안의 반복

반복문은 다른 반복문 안에 들어갈 수 있습니다. 여기서 바깥쪽 `위해`는 출력만 하고, 안쪽 `동안`이
각 줄의 텍스트를 만듭니다.

```ling
바인드 시작 = 실행 {
  위해 줄 안에 1..5 {
    바인드 글 = ""
    바인드 칸 = 0
    동안 칸 < 줄 {
      바인드 글 = 글 + "*"
      바인드 칸 = 칸 + 1
    }
    출력(글)
  }
}
```
```output
*
**
***
****
```

## `매치`로 고르기

값 하나를 여러 후보와 비교할 때는 긴 `아니면 만약` 사슬보다 `매치`(`match`)가 깔끔합니다. 각
**갈래**는 `패턴 => 동작`으로 씁니다. Ling은 처음으로 들어맞는 갈래를 실행하며, `_`는 무엇에나
들어맞습니다.

```ling
바인드 시작 = 실행 {
  바인드 요일 = 3
  매치 요일 {
    1 => 출력("월요일")
    2 => 출력("화요일")
    3 => 출력("수요일")
    _ => 출력("다른 요일")
  }
  바인드 신호 = 매치 "초록" {
    "빨강" => "멈춤"
    "초록" => "출발"
    _ => "대기"
  }
  출력(신호)
}
```
```output
수요일
출발
```

`매치`는 숫자와 텍스트에 쓸 수 있고, 바인딩할 수 있는 값을 돌려줄 수도 있습니다. 마지막에는 항상
`_` 갈래를 두세요. 아무것도 들어맞지 않으면 `매치`는 조용히 "없음" 값 `()`을 돌려줍니다.
