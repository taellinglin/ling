# 소개

Ling은 자신의 언어로 쓸 수 있는 프로그래밍 언어입니다. 키워드와 내장 함수에는 중국어, 일본어, 한국어, 태국어,
영어, 아랍어, 히브리어, 러시아어 등 16개가 넘는 언어의 이름이 있고, 한 파일 안에서 섞어 쓸 수 있습니다.
이 문서는 그중 English, 中文, 日本語, 한국어, ไทย 다섯 가지를 다룹니다. 페이지 위쪽의 언어 선택기에서 바꿀 수 있습니다.

이 가이드는 Ling 2030.1.53을 기준으로 합니다.

## 첫 만남

작은 프로그램을 하나 보겠습니다. 모든 프로그램은 `바인드 시작 = 실행 { ... }`에서 시작합니다.

```ling
# 친구들에게 인사하기
바인드 시작 = 실행 {
    바인드 친구들 = ["민준", "서연", "지호"]
    위해 이름 안에 친구들 {
        출력("안녕, " + 이름 + "!")
    }
    출력(길이(친구들))
}
```

```output
안녕, 민준!
안녕, 서연!
안녕, 지호!
3
```

같은 프로그램을 영어, 중국어, 일본어, 태국어 키워드로도 쓸 수 있습니다. 페이지 언어를 바꿔 보거나
[다섯 가지 언어로 작성하기](language/multilingual.md)를 읽어 보세요.

## 무엇을 할 수 있나요

`ling` 하나에 다음이 모두 들어 있습니다.

- **JIT 컴파일러와 인터프리터.** 프로그램은 Cranelift로 네이티브 코드로 컴파일되고, 나머지는 인터프리터가 실행합니다.
- **그래픽과 3D.** 창, 2D 그리기, 이미지, 폰트, 그리고 카메라, 조명, 셀 셰이딩, 벡터 지오메트리(`vtex_*`)를 갖춘 소프트웨어 3D 렌더러.
- **오디오와 음악.** 톤, 공간 사운드, WAV 재생, 음악 디코딩, BPM과 조성 분석, GM 스타일 신시사이저, MIDI.
- **물리.** 강체, 소프트 바디, 액체 시뮬레이션.
- **UI.** HUD, 미터, 버튼 등 여러 위젯.
- **웹 서버.** `http_*`와 `db_*` 내장 함수로 라우트, 정적 파일, SQLite를 다룹니다.
- **암호화.** 해시, 암호화, 서명, 양자 내성 키 교환.
- **AI.** 신경망, 행동 트리, 선택적인 언어 모델 지원.

프로젝트 관리 도구 `lingfu`로 프로젝트를 만들고 실행하고 테스트할 수 있으며, `lingfu normalize`는 프로젝트 전체를
한 가지 언어로 바꿔 씁니다.

## 설치

macOS 또는 Linux:

```sh
curl --proto '=https' --tlsv1.2 -sSf https://ling-lang.org/install.sh | sh
```

Windows(PowerShell):

```powershell
irm https://ling-lang.org/install.ps1 | iex
```

Rust가 없으면 스크립트가 먼저 설치한 다음 `ling`과 `lingfu`를 빌드합니다. 다른 방법과 설치 프로필은
[설치](getting-started/install.md)를 보세요.
