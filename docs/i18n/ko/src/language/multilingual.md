# 다섯 가지 언어로 작성하기

Ling은 영어, 중국어, 일본어, 한국어, 태국어 중 어느 언어로든 작성할 수 있습니다. 모든 키워드에
각 언어의 이름이 있고, 자주 쓰는 내장 함수 대부분도 마찬가지입니다. 인터프리터는 이 이름들을
모두 동시에 받아들입니다. 바꿔야 할 설정이 없고, 한 파일은 물론 한 줄 안에서도 여러 언어를
섞어 쓸 수 있습니다.

## 같은 프로그램, 다섯 번

같은 작은 프로그램을 각 언어로 작성한 것입니다. 키워드, 내장 함수, 이름, 주석, 텍스트가 모두
그 언어로 되어 있으며, 각 버전은 그대로 실행됩니다.

**English**

```ling
# Count the fruit in a basket
fn describe(n) {
    if n == 1 {
        return "1 fruit"
    } else {
        return to_str(n) + " fruits"
    }
}

bind start = do {
    bind basket = ["apple", "pear", "plum"]
    for fruit in basket {
        print("- ", fruit)
    }
    print(describe(len(basket)))
    print("square root of 16: ", sqrt(16))
}
```

```output
- apple
- pear
- plum
3 fruits
square root of 16: 4
```

**中文**

```ling
# 数一数篮子里的水果
函 描述(数量) {
    若 数量 == 1 {
        归 "1 个水果"
    } 否则 {
        归 to_str(数量) + " 个水果"
    }
}

令 始 = 执 {
    令 篮子 = ["苹果", "梨", "李子"]
    历 水果 于 篮子 {
        打印("- ", 水果)
    }
    打印(描述(长度(篮子)))
    打印("16 的平方根：", 平方根(16))
}
```

```output
- 苹果
- 梨
- 李子
3 个水果
16 的平方根：4
```

**日本語**

```ling
# かごの果物を数える
関数 説明(個数) {
    もし 個数 == 1 {
        戻る "果物 1 個"
    } 他 {
        戻る "果物 " + to_str(個数) + " 個"
    }
}

束縛 開始 = 実行 {
    束縛 かご = ["りんご", "なし", "すもも"]
    繰 果物 の中 かご {
        印刷("- ", 果物)
    }
    印刷(説明(長さ(かご)))
    印刷("16 の平方根：", 平方根(16))
}
```

```output
- りんご
- なし
- すもも
果物 3 個
16 の平方根：4
```

**한국어**

```ling
# 바구니 속 과일 세기
함수 설명(개수) {
    만약 개수 == 1 {
        반환 "과일 1개"
    } 아니면 {
        반환 "과일 " + to_str(개수) + "개"
    }
}

바인드 시작 = 실행 {
    바인드 바구니 = ["사과", "배", "자두"]
    위해 과일 안에 바구니 {
        출력("- ", 과일)
    }
    출력(설명(길이(바구니)))
    출력("16의 제곱근: ", 제곱근(16))
}
```

```output
- 사과
- 배
- 자두
과일 3개
16의 제곱근: 4
```

**ไทย**

```ling
# นับผลไม้ในตะกร้า
ฟังก์ชัน บรรยาย(จำนวน) {
    ถ้า จำนวน == 1 {
        คืน "ผลไม้ 1 ผล"
    } มิฉะนั้น {
        คืน "ผลไม้ " + to_str(จำนวน) + " ผล"
    }
}

ผูก เริ่ม = ทำ {
    ผูก ตะกร้า = ["แอปเปิล", "สาลี่", "พลัม"]
    สำหรับ ผลไม้ ใน ตะกร้า {
        พิมพ์("- ", ผลไม้)
    }
    พิมพ์(บรรยาย(ความยาว(ตะกร้า)))
    พิมพ์("รากที่สองของ 16: ", รากที่สอง(16))
}
```

```output
- แอปเปิล
- สาลี่
- พลัม
ผลไม้ 3 ผล
รากที่สองของ 16: 4
```

눈여겨볼 점이 몇 가지 있습니다.

- 직접 짓는 이름(`describe`, `篮子`, `かご`, `바구니`, `ตะกร้า`)에는 이 문자들 중 어느 것이든
  쓸 수 있습니다.
- 프로그램은 값이 `do` 블록인 바인딩에서 시작하므로, 그 이름을 `start`, `始`, `開始`, `시작`,
  `เริ่ม` 중 무엇으로 지어도 됩니다.
- `to_str`은 모든 버전에서 영어 그대로입니다. 이 언어들에는 별칭이 없기 때문입니다. 영어 이름은
  언제나 동작합니다.
- 다른 언어로 쓴 파일을 `ling run`으로 실행하면 `[detected language: Thai (ภาษาไทย)]` 같은 짧은
  메시지가 표준 오류에 출력됩니다. 프로그램의 출력은 바뀌지 않습니다.

## 키워드

가장 많이 쓰는 키워드:

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `bind` | `令` | `束縛` | `바인드` | `ผูก` |
| `do` | `执` | `実行` | `실행` | `ทำ` |
| `fn` | `函` | `関数` | `함수` | `ฟังก์ชัน` |
| `return` | `归` | `戻る` | `반환` | `คืน` |
| `if` | `若` | `もし` | `만약` | `ถ้า` |
| `else` | `否则` | `他` | `아니면` | `มิฉะนั้น` |
| `while` | `循` | `間` | `동안` | `ขณะที่` |
| `for` | `历` | `繰` | `위해` | `สำหรับ` |
| `in` | `于` | `の中` | `안에` | `ใน` |
| `match` | `配` | `一致` | `매치` | `จับคู่` |
| `form` | `形` | `形` | `구조` | `โครงสร้าง` |
| `ok` | `好` | `良い` | `좋아` | `ตกลง` |
| `bad` | `坏` | `悪い` | `나쁨` | `ผิดพลาด` |
| `true` | `真` | `真` | `참` | `จริง` |
| `false` | `假` | `偽` | `거짓` | `เท็จ` |

철자가 둘 이상인 키워드도 있습니다(중국어 `如`도 `if`이고, 한국어 `반복`도 `while`입니다).
전체 목록은 [키워드](../glossary/keywords.md)를 참고하세요.

## 내장 함수

내장 함수도 같은 방식입니다. `print`, `打印`, `印刷`, `출력`, `พิมพ์`은 모두 같은 함수입니다.

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `print` | `打印` | `印刷` | `출력` | `พิมพ์` |
| `len` | `长度` | `長さ` | `길이` | `ความยาว` |
| `sqrt` | `平方根` | `平方根` | `제곱근` | `รากที่สอง` |
| `abs` | `绝对值` | `絶対値` | `절댓값` | `ค่าสัมบูรณ์` |
| `max` | `最大` | `最大` | `최댓값` | `สูงสุด` |
| `rand` | `随机` | `乱数` | `난수` | `สุ่ม` |
| `list_push` | `列表添加` | `リスト追加` | `목록추가` | `เพิ่มรายการ` |
| `open_window` | `开窗` | `ウィンドウ開く` | `창열기` | `เปิดหน้าต่าง` |
| `window_is_open` | `窗开` | `開いている` | `창열림` | `หน้าต่างเปิดอยู่` |
| `fill` | `填` | `塗り潰し` | `채우기` | `เติม` |
| `present` | `显` | `表示` | `표시` | `แสดงผล` |
| `set_color` | `设色` | `色設定` | `색설정` | `สีดินสอ` |
| `key_down` | `按键` | `キー押す` | `키누름` | `กดค้าง` |
| `audio_blip` | `提示音` | `ビープ音` | `효과음` | `เสียงบี๊บ` |
| `time_now` | `当前时间` | `経過時間` | `현재시간` | `เวลาปัจจุบัน` |

별칭이 있는 내장 함수:

- **다섯 언어 모두:** 출력, 수학, 리스트, 창과 프레임 루프, 2D와 3D 그리기, 대부분의 키보드 입력,
  오디오와 음악 재생, 시간, `ui_*` 위젯.
- **영어만:** 대부분의 텍스트 도우미(`to_str`, `to_number`, `str_upper`, `str_split` 등),
  `write_file` 같은 파일 함수, 음악 스튜디오(`daw_*`), 그리고 웹 서버, 데이터베이스, 요청 도우미의
  대부분(`http_*`, `db_*`, `query_param`, `json_escape`). 이 중 일부에는 태국어 별칭이 있지만
  (`http_route`는 `เว็บเส้นทาง`, `db_open`은 `ฐานข้อมูลเปิด`으로도 쓸 수 있습니다) 중국어, 일본어,
  한국어 별칭은 없습니다.

[크레이트별 내장 함수](../glossary/builtins.md) 페이지에 각 내장 함수와 별칭이 정리되어 있습니다.

> **팁:** 기본 엔진에서는 철자가 틀리거나 알 수 없는 이름이 오류가 되지 않고, 호출이 `()`를
> 돌려줄 뿐입니다. 예를 들어 `长`은 내장 함수가 아닙니다(`len`의 중국어는 `长度`입니다).
> 호출이 아무 일도 하지 않는 것 같으면 `ling run --interp yourfile.ling`을 실행하세요.
> `unknown function`을 알리며 멈춥니다.

## 한 파일에서 언어 섞기

여러 언어를 함께 써도 아무 문제가 없습니다.

```ling
# English, Chinese, Japanese, Korean and Thai in one file
函 double(x) {
    归 x * 2
}

bind start = do {
    束縛 n = 21
    만약 n > 10 {
        พิมพ์("double: ", double(n))
    }
    print(长度([1, 2, 3]))
}
```

```output
double: 42
3
```

다른 언어로 된 예제를 보며 배우거나 팀에서 코드를 공유할 때 편리합니다. 오래 유지할 프로젝트라면
프로젝트마다 한 언어만 쓰는 편이 읽기 쉽습니다.

## lingfu normalize로 프로젝트 변환하기

`lingfu normalize`는 프로젝트 전체를 한 언어로 다시 씁니다. 프로젝트 폴더에서 실행합니다.

```sh
lingfu normalize --dry-run ko    # 무엇이 바뀔지 보여 주기만 함
lingfu normalize ko              # 한국어로 다시 쓰기
lingfu normalize en              # 다시 영어로
```

언어는 `en`, `zh`, `ja`, `ko`, `th`(또는 `thai` 같은 이름)로 지정합니다.

- 현재 폴더(하위 폴더 포함)에 있는 모든 `.ling` 파일의 키워드와 내장 함수 이름을 번역합니다.
- 번역할 줄 아는 이름의 파일과 폴더도 **이름을 바꿉니다**. 파일 내용만 바꾸려면
  `--content-only`를, 이름만 바꾸려면 `--files-only`를 붙입니다.
- 직접 지은 이름, 주석, 텍스트는 번역하지 않습니다. 이것들은 손으로 고치세요.
- 대상 언어에 별칭이 없는 내장 함수는 영어 이름을 유지합니다.

> **경고:** `normalize`는 파일을 그 자리에서 바꿉니다. 먼저 작업을 커밋하거나 사본을 만들고,
> 프로젝트 자체 폴더에서만 실행하세요.

변환한 뒤에는 프로그램을 한 번 실행해 확인하세요. 특히 `form`, `ok`, `bad`를 살펴보세요. 새 철자가
파싱되지 않거나 아무 일도 하지 않으면 위의 키워드 표에 있는 철자로 바꾸세요.
내장 함수도 영향을 받을 수 있습니다. 변환 후 어떤 호출이 갑자기 `()`를 돌려준다면
`ling run --interp`를 실행해 알 수 없는 함수 이름을 확인하고, 그 호출을 영어 이름으로 되돌리세요.
