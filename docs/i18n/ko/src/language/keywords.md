# 키워드

Ling의 모든 키워드에는 영어 철자와 함께 중국어, 일본어, 한국어, 태국어 철자가 있습니다. 렉서는
어느 철자든 같은 토큰으로 바꾸므로, 프로그램 전체를 한 언어로 쓸 수도 있고 여러 언어를 섞을 수도
있습니다. 이 페이지는 모든 키워드와 그 철자, 그리고 지금 실제로 하는 일을 정리합니다.

일부 키워드는 앞으로의 기능을 위해 예약되어 있어 아직 아무 일도 하지 않습니다. 아래에 표시해
두었으니 `멈춤`(`stop`)으로 루프를 빠져나가지 못해도 놀라지 않으셔도 됩니다.

## 철자

한 칸에 철자가 여러 개 있으면 모두 동작하며, 첫 번째가 일반적인 철자입니다. 이 철자들은 렉서
(`src/lexer/mod.rs`)에서 가져온 것으로, 런타임이 실제로 받아들이는 철자입니다. `lexicons/*.ling`과
다른 곳이 몇 군데 있으며, 그 경우 렉서가 맞습니다. 예를 들어 일본어 `choose`는 `選択`, 한국어
`form`은 `구조`, 태국어 `form`은 `โครงสร้าง`입니다.

## 각 키워드가 하는 일

| 키워드 | 상태 | 하는 일 |
|---|---|---|
| `바인드` (`bind`) | 활성 | 바인딩을 만들거나 바꿉니다. 전역 값과 진입점을 정의할 때도 씁니다. |
| `실행` (`do`) | 활성 | 마지막 문장의 값을 값으로 갖는 블록입니다. |
| `함수` (`fn`) | 활성 | 함수를 선언합니다. |
| `만약` / `아니면` (`if` / `else`) | 활성 | 조건식입니다. |
| `동안` (`while`) | 활성 | 조건이 성립하는 동안 반복합니다. 본문은 바깥 범위를 공유합니다. |
| `위해` / `안에` (`for` / `in`) | 활성 | 범위나 리스트를 순회합니다. 매번 새 범위를 받습니다. |
| `매치` (`match`) | 활성 | 패턴 매칭입니다. |
| `반환` (`return`) | 활성 | 값을 가지고 현재 함수를 빠져나갑니다. |
| `구조` (`form`) | 활성 | 레코드 타입을 선언합니다. |
| `선택` (`choose`) | 활성 | 값을 가질 수 있는 변형들로 이루어진 열거형을 선언합니다. |
| `모듈` (`mod`) | 활성 | 함수를 네임스페이스로 묶습니다(`이름::f()`). |
| `사용` / `로서` (`use` / `as`) | 활성 | 다른 파일을 불러옵니다. 별칭을 붙일 수도 있습니다. |
| `좋아` / `나쁨` (`ok` / `bad`) | 활성 | 결과를 만들고, 패턴으로 결과와 맞춰 봅니다. |
| `참` / `거짓` (`true` / `false`) | 활성 | 불리언 값입니다. |
| `시도` (`try`) | 내장 함수 | 문법이 아니라 내장 함수 `시도(f, 인수...)`입니다. 인터프리터에서만 동작합니다. |
| `타입` (`type`) | 무시 | `타입 이름 로서 T`는 파싱된 뒤 버려집니다. 뒤따르는 내용을 삼키므로 쓰지 마십시오. |
| `단` (`where`) | 무시 | `함수 f(x) 단 ... { }`: `{`까지의 내용을 건너뜁니다. |
| `비동기` (`async`) | 무시 | `비동기 함수`는 보통 함수처럼 동기적으로 실행됩니다. |
| `기다려` (`wait`) | 불안정 | 인터프리터에서는 값이 되고 JIT에서는 `()`가 됩니다. 쓰지 마십시오. |
| `소유` `빌려` `공유` `이동` `복사` (`own` `lend` `share` `move` `copy`) | 무시 | 피연산자를 그대로 돌려주는 전위 단어입니다. 소유권 검사는 전혀 하지 않습니다. |
| `asm` | 무시 | `asm("...")`은 베어메탈 빌드용입니다. 일반 실행에서는 사실상 아무것도 하지 않습니다. |
| `멈춤` (`stop`) | 예약 | 루프를 빠져나가지 **않습니다**. |
| `계속` (`again`) | 예약 | 다음 반복으로 넘어가지 **않습니다**. |
| `변경` (`change`) | 예약 | 아무 일도 하지 않습니다. `바인드`로 다시 바인딩하십시오. |
| `게시` `전달` `적합` `가능` `확실` `아마도` `순수` (`post` `give` `fit` `can` `sure` `maybe` `pure`) | 예약 | 아무 일도 하지 않습니다. 파서에게는 평범한 이름입니다. |
| `생성` (`spawn`) | 예약 | 아무 일도 하지 않으며, `spawn` 내장 함수도 없습니다. |
| `없음` (`none`) | 예약 | 값이 아닙니다. 인터프리터는 `undefined: 'none'`을 보고합니다. "아무것도 없음"에는 `()`를 쓰십시오. |

**예약**어는 파서에게 평범한 이름이므로 `바인드 멈춤 = 2`는 올바른 코드입니다. 인터프리터에서는
루프 안에 단독으로 쓴 `멈춤`이나 `계속`이 `undefined` 오류가 되고, JIT에서는 조용히 무시되어 루프가
계속 돌아갑니다.

## 활성 키워드

### 바인드(bind)

`바인드 이름 = 식`은 변수를 만들거나 "바꾸는" 유일한 방법입니다. 같은 이름을 다시 바인딩하면
바뀝니다. [바인딩과 재바인딩](syntax.md#바인딩과-재바인딩)을 참고하십시오.

```ling
바인드 시작 = 실행 {
  바인드 가격 = 40
  바인드 가격 = 가격 + 2
  출력(가격)
}
```
```output
42
```

### 실행(do)

`실행 { ... }`은 문장을 차례로 실행하고 마지막 문장의 값을 돌려줍니다. 진입점은 `시작`에 바인딩된
`실행` 블록입니다. [블록](syntax.md#블록)을 참고하십시오.

### 함수와 반환(fn, return)

`함수 이름(매개변수) { 본문 }`은 함수를 선언합니다. 마지막 식이 결과이고, `반환`으로 일찍
빠져나갑니다.

```ling
함수 설명(n) {
  만약 n > 100 { 반환 "큼" }
  "작음"
}
바인드 시작 = 실행 {
  출력(설명(500))
  출력(설명(5))
}
```
```output
큼
작음
```

진입점 안에 바로 쓴 `반환`은 JIT에서는 조용히 프로그램을 끝내고, 인터프리터에서는 오류
(`unexpected top-level return`)가 됩니다.

### 만약, 아니면, 동안, 위해, 안에(if, else, while, for, in)

제어 흐름 키워드는 [제어 흐름](syntax.md#제어-흐름)에서 설명합니다. `break`나 `continue`는 없습니다.
`멈춤`과 `계속`은 예약어일 뿐입니다. 루프를 일찍 빠져나가려면 함수에서 `반환`하십시오.

```ling
함수 찾기(목록, 대상) {
  위해 x 안에 목록 {
    만약 x == 대상 { 반환 참 }
  }
  거짓
}
바인드 시작 = 실행 {
  출력(찾기([1, 2, 3], 2))
  출력(찾기([1, 2, 3], 9))
}
```
```output
true
false
```

### 매치(match)

`매치 값 { 패턴 => 식, ... }`은 처음 맞는 갈래를 평가합니다. 패턴은 `_`, 리터럴, 이름,
`좋아(p)` / `나쁨(p)`, 열거형 변형입니다. [match](syntax.md#match)를 참고하십시오.

### 구조와 선택(form, choose)

`구조`는 레코드 타입을, `선택`은 열거형을 선언합니다.
[레코드와 열거형](syntax.md#레코드와-열거형)을 참고하십시오.

```ling
선택 신호등 { 빨강, 노랑, 초록 }
함수 행동(불) {
  매치 불 {
    빨강() => "멈춤",
    노랑() => "천천히",
    초록() => "출발"
  }
}
바인드 시작 = 실행 {
  출력(행동(초록()))
  출력(빨강().tag)
}
```
```output
출발
빨강
```

### 모듈, 사용, 로서(mod, use, as)

`모듈 이름 { ... }`은 함수를 묶고 `이름::f()`로 호출합니다. `사용 "파일.ling"`은 다른 파일을
불러오고, `사용 "파일.ling" 로서 m`은 그 함수들을 `m::f()`로 쓸 수 있게 합니다.
[모듈과 프로젝트](modules.md)를 참고하십시오.

### 좋아와 나쁨(ok, bad)

`좋아(값)`과 `나쁨(이유)`는 결과를 만듭니다. `매치` 안에서는 패턴이 됩니다. `나쁨` 결과는
`Err(...)`로 출력됩니다. [오류와 결과](errors.md)를 참고하십시오.

```ling
함수 절반(n) {
  만약 n % 2 == 0 { 좋아(n / 2) } 아니면 { 나쁨("홀수") }
}
바인드 시작 = 실행 {
  출력(절반(10))
  출력(매치 절반(7) { 좋아(v) => v, 나쁨(e) => "오류: " + e })
}
```
```output
Ok(5)
오류: 홀수
```

### 참과 거짓(true, false)

불리언 리터럴입니다. `만약`과 `동안`의 조건에는 이것을 쓰십시오.

## 파싱되지만 무시되는 키워드

소유권 단어 `소유`, `빌려`, `공유`, `이동`, `복사`는 식(또는 매개변수 이름) 앞에 올 수 있지만
무시됩니다. 빌림 검사기는 없으며, `이동` 뒤에 원래 값을 써도 괜찮습니다.

```ling
바인드 시작 = 실행 {
  바인드 a = 소유 [1, 2, 3]
  바인드 b = 이동 a
  출력(a)
  출력(b)
}
```
```output
[1, 2, 3]
[1, 2, 3]
```

`비동기 함수`는 호출하면 바로 실행되는 보통 함수를 선언합니다. 함수 매개변수 뒤의 `단` 절은
건너뜁니다.

```ling
비동기 함수 작업(n) { n * 2 }
함수 다음(x) 단 x { x + 1 }
바인드 시작 = 실행 {
  출력(작업(4))
  출력(다음(2))
}
```
```output
8
3
```

진짜 병렬 작업에는 `thread_*` 내장 함수를 쓰십시오.

## 키워드처럼 보이지만 키워드가 아닌 단어

- `start`, `main`, `启`, `เริ่ม`, `시작`은 키워드가 아니라 이름입니다. 런타임은 이 이름으로
  진입점을 찾습니다. [진입점](syntax.md#진입점)을 참고하십시오.
- `result`, `loop`, `break`, `continue`, `struct`, `enum`, `let`, `const` 같은 단어는 일부 어휘
  파일에 나오지만 키워드가 아닙니다. Ling에는 `loop`도 `let`도 없습니다. `동안`과 `바인드`를
  쓰십시오.
- `number`, `text`, `bool`, `list`, `map`, `tuple`은 문서용 단어일 뿐입니다. Ling은 동적 타입
  언어입니다. [타입과 값](types.md)을 참고하십시오.
