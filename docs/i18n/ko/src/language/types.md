# 타입과 값

Ling은 동적 타입 언어입니다. 타입을 선언할 필요가 없습니다. 모든 값은 자기 타입을 가지고 있고,
연산자와 내장 함수가 실행할 때 그것을 확인합니다. 이 페이지는 값의 종류, 출력되는 모양, 조건과
비교에서의 동작, 그리고 타입 사이의 변환 방법을 설명합니다.

## 값의 종류

| 타입 | 예 | 만드는 방법 | 출력 |
|---|---|---|---|
| 숫자 | `3`, `2.5`, `-7` | 숫자 리터럴, 산술 연산 | `3`, `2.5` |
| 텍스트 | `"abc"` | 텍스트 리터럴, `+`, 텍스트 내장 함수 | `abc` |
| 불리언 | `참`, `거짓` | 리터럴, 비교 | `true` |
| 유닛 | `()` | `()`, 결과가 없는 함수, 실패한 조회 | `()` |
| 리스트 | `[1, "a", 참]` | 리스트 리터럴, `새목록`, 리스트 내장 함수 | `[1, a, true]` |
| 레코드 | `점(3, 4)` | `구조` 이름을 호출 | `점 { x: 3, y: 4 }` |
| 열거 값 | `원(2)`, `점하나()` | `선택` 변형을 호출 | `원(2)` |
| 결과 | `좋아(5)`, `나쁨("e")` | `좋아`와 `나쁨` | `Ok(5)`, `Err(e)` |
| 함수 | `\|x\| x + 1` | 클로저 | |

맵(사전), 집합, 튜플, 문자 타입, `null`은 없습니다. 키-값 데이터에는 리스트, 레코드, 나란한
리스트를 쓰거나, `db_*` 내장 함수로 SQLite에 저장하십시오. `x: number`나 `-> text` 같은 타입
표기는 파서가 받아들인 뒤 무시합니다.

```ling
구조 점 { x, y }
바인드 시작 = 실행 {
  출력(42)
  출력("텍스트")
  출력(참)
  출력(())
  출력([1, "a", 참])
  출력(점(3, 4))
  출력(좋아(5))
  출력(나쁨("안 됨"))
}
```
```output
42
텍스트
true
()
[1, a, true]
점 { x: 3, y: 4 }
Ok(5)
Err(안 됨)
```

### 숫자

모든 숫자는 64비트 부동소수점입니다. 정수는 소수점 없이 출력되고, 2^53까지의 정수는 정확하며,
나눗셈은 항상 정확한 몫을 돌려줍니다.

```ling
바인드 시작 = 실행 {
  출력(7 / 2)
  출력(10 / 5)
  출력(7 % 3)
  출력(0.1 + 0.2)
  출력(1000000 * 1000000)
}
```
```output
3.5
2
1
0.30000000000000004
1000000000000
```

0으로 나누어도 오류가 아닙니다. 인터프리터에서 `1 / 0`은 `inf`이고 JIT에서는 `()`입니다. 둘 다
`0 / 0`은 `NaN`입니다.

### 텍스트

텍스트는 유니코드 문자의 나열입니다. `길이`는 바이트가 아니라 문자 수를 세고, `+`는 텍스트를
잇습니다. `+`의 한쪽이 텍스트이면 다른 쪽도 텍스트로 바뀝니다.

```ling
바인드 시작 = 실행 {
  출력(길이("héllo"))
  출력("가" + "나")
  출력("n=" + 5)
  출력(5 + "!")
}
```
```output
5
가나
n=5
5!
```

`s[i]`로 한 글자를 읽는 것은 인터프리터에서만 동작합니다. 두 엔진 모두에서 한 글자를 얻으려면
`substr(s, i, 1)`을 쓰십시오.

### 리스트

리스트에는 어떤 타입의 값이든 담을 수 있고, 번호는 0부터 시작합니다. 리스트 내장 함수는 새
리스트를 돌려주므로 결과를 꼭 바인딩하십시오: `바인드 xs = 목록추가(xs, v)`. 끝을 넘어서 읽으면
JIT에서는 빈 값이 되고, 인터프리터에서는 `index N out of bounds`로 멈춥니다. 리스트 내장 함수는
[텍스트와 리스트](../reference/text-lists.md)를 참고하십시오.

### 유닛

`()`는 "아무것도 없음"을 뜻합니다. 마지막 식이 값을 내지 않는 함수는 `()`를 돌려줍니다. `아니면`이
없고 조건이 거짓인 `만약`, 맞는 갈래가 없는 `매치`도 `()`가 됩니다.

### 레코드, 열거 값, 결과

레코드는 `구조`에서, 열거 값은 `선택`에서, 결과는 `좋아`와 `나쁨`에서 나옵니다. 레코드 필드는
`.이름`으로, 열거 값의 변형 이름은 `.tag`로 읽고, 결과는 `매치`로 엽니다.
[레코드와 열거형](syntax.md#레코드와-열거형)과 [오류와 결과](errors.md)를 참고하십시오.

## 참거짓 판정

`만약`과 `동안`에는 진짜 불리언을 주십시오. 다른 값도 동작하지만 두 엔진의 판단이 완전히 같지는
않습니다.

| 조건 안의 값 | JIT(기본) | 인터프리터 |
|---|---|---|
| `참` / `거짓` | 참 / 거짓 | 참 / 거짓 |
| `0` | 거짓 | 거짓 |
| `()` | 거짓 | 거짓 |
| 다른 숫자, 비어 있지 않은 텍스트, 비어 있지 않은 리스트 | 참 | 참 |
| `""`(빈 텍스트) | **참** | 거짓 |
| `[]`(빈 리스트) | **참** | 거짓 |

비어 있는지는 `길이(xs) == 0`이나 `s == ""`로 명시적으로 확인하십시오. 또한 `!x`는 `x == 거짓`이라는
뜻이라서 `!0`과 `!""`는 모두 `false`입니다. `!`는 불리언에만 쓰십시오.

## 값 비교

`==`와 `!=`는 숫자, 텍스트, 불리언, `()`를 값으로 비교합니다. 타입이 다른 값은 절대 같지 않습니다.
`1 == "1"`은 `false`입니다.

**리스트, 레코드, 열거 값, 결과는 내용이 같아도 절대 같지 않습니다.** 요소나 필드를 직접
비교하십시오.

```ling
구조 P { x }
바인드 시작 = 실행 {
  출력("abc" == "abc")
  출력(1 == "1")
  출력([1, 2] == [1, 2])
  출력(P(1) == P(1))
  출력(P(1).x == P(1).x)
}
```
```output
true
false
false
false
true
```

`<`, `>`, `<=`, `>=`는 숫자용입니다. 텍스트의 크기 비교(`"a" < "b"`)는 JIT에서는 `false`이고
인터프리터에서는 오류입니다.

## 형 변환

| 내장 함수 | 변환 | 설명 |
|---|---|---|
| `str(v)` | 어떤 값이든 텍스트로 | `출력`이 보여 주는 텍스트와 같습니다. `to_str`이라고도 씁니다. |
| `to_number(s)` | 텍스트를 숫자로 | 앞뒤 공백은 무시합니다. 숫자가 아니면 `0`을 돌려줍니다. |
| `hex_to_number(s)` | 16진 텍스트를 숫자로 | `0x`는 붙이지 않습니다: `hex_to_number("ff")`는 `255`. |
| `정수(x)` | 숫자를 정수로 | 소수 부분을 0 쪽으로 버립니다. 영어로는 `int`(`trunc`라고도 함). |
| `내림(x)` / `올림(x)` | 숫자를 정수로 | 내림 / 올림. 영어로는 `floor` / `ceil`. |
| `반올림(x)` | 숫자를 정수로 | 0.5는 0에서 먼 쪽으로 반올림합니다. 영어로는 `round`. |

```ling
바인드 시작 = 실행 {
  출력(str(3) + "!")
  출력(to_number(" 4 ") + 1)
  출력(to_number("abc"))
  출력(정수(-3.7))
  출력(내림(-2.5))
  출력(반올림(2.5))
  출력(hex_to_number("ff"))
}
```
```output
3!
5
0
-3
-3
3
255
```

값의 타입을 알려 주는 내장 함수는 없고, 값을 불리언으로 바꾸는 내장 함수도 없습니다. `to_number`는
잘못된 입력에 `0`을 돌려주므로, `0`도 올바른 답일 수 있다면 먼저 텍스트를 확인하십시오. 방법은
[오류와 결과](errors.md#입력-검증)에 있습니다.
