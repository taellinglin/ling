# ไฟล์ เวลา และระบบ

ฟังก์ชันในตัวกลุ่มนี้ใช้อ่านและเขียนไฟล์ ตรวจสอบพาธ บอกเวลา อ่านบรรทัดคำสั่งและตัวแปรแวดล้อม เปิดโปรแกรมอื่น
และรันงานบนเธรดอื่น ทั้งหมดใช้ในเทอร์มินัลธรรมดาได้ ไม่ต้องใช้หน้าต่าง

พาธเป็นข้อความ พาธสัมพัทธ์เริ่มนับจากไดเรกทอรีที่คุณรัน `ling` ฟังก์ชันในตัวเกี่ยวกับไฟล์ส่วนใหญ่แจ้งความล้มเหลวผ่านค่าที่คืน
(`false` `0` หรือรายการว่าง) แทนการหยุดโปรแกรม แต่ละหัวข้อจะบอกว่าได้ค่าไหน

## ไฟล์

### การอ่านและเขียนข้อความ

`write_file` สร้างหรือเขียนทับไฟล์ ส่วน `read_file` คืนเนื้อหาเป็นข้อความ ถ้าไม่มีไฟล์ บนอินเทอร์พรีเตอร์จะเป็นข้อผิดพลาด
แต่บนแบ็กเอนด์ปริยายจะคืน `()` จึงควรตรวจด้วย `file_exists` ก่อน

```ling
ผูก start = ทำ {
  เขียนไฟล์("notes.txt", "บรรทัดแรก\nบรรทัดสอง")
  พิมพ์(file_exists("notes.txt"), " ", ขนาดไฟล์("notes.txt"))
  ถ้า file_exists("notes.txt") {
    ผูก บรรทัด = แยก(อ่านไฟล์("notes.txt"), "\n")
    พิมพ์(ความยาว(บรรทัด), " บรรทัด บรรทัดแรกคือ ", บรรทัด[0])
  }
  พิมพ์(ลบไฟล์("notes.txt"), " ", ลบไฟล์("notes.txt"))
}
```
```output
true 55
2 บรรทัด บรรทัดแรกคือ บรรทัดแรก
true false
```

ถ้าไม่มีอะไรให้ลบ `remove_file` จะคืน `false`

### ไบต์

สำหรับไฟล์ไบนารี `read_file_bytes` คืนรายการตัวเลข 0 ถึง 255 (ถ้าผิดพลาดได้รายการว่าง)
และ `write_file_bytes` เขียนรายการนั้นกลับลงไฟล์ คืน `true` เมื่อสำเร็จ `file_write_bytes(path, bytes, true)` จะต่อท้ายแทนการเขียนทับ

```ling
ผูก start = ทำ {
  พิมพ์(เขียนไบต์("hi.bin", [72, 105]))
  พิมพ์(อ่านไบต์("hi.bin"))
  file_write_bytes("hi.bin", [33], จริง)
  พิมพ์(อ่านไฟล์("hi.bin"))
  พิมพ์(มายาไฟล์("hi.bin"), " ", มายาไฟล์("nothing.bin"))
}
```
```output
true
[72, 105]
Hi!
other missing
```

### ไดเรกทอรี

`make_dir` สร้างไดเรกทอรี (รวมถึงไดเรกทอรีแม่ที่ยังไม่มี) และคืน `true` เมื่อสำเร็จ `list_dir` คืนแต่ละรายการเป็นพาธ
ที่ขึ้นต้นด้วยไดเรกทอรีที่คุณส่งเข้าไป `copy_file` และ `rename_file` คืน `true` เมื่อสำเร็จ

```ling
ผูก start = ทำ {
  สร้างไดเรกทอรี("out")
  เขียนไฟล์("out/a.txt", "ก")
  คัดลอกไฟล์("out/a.txt", "out/b.txt")
  เปลี่ยนชื่อไฟล์("out/b.txt", "out/c.txt")
  พิมพ์(รายการไดเรกทอรี("out"))
  พิมพ์(เป็นไดเรกทอรี("out"), " ", เป็นไฟล์("out"))
  พิมพ์(ลบไดเรกทอรีทั้งหมด("out"), " ", file_exists("out"))
}
```
```output
[out/a.txt, out/c.txt]
true false
true false
```

`remove_dir_all` ลบไดเรกทอรีพร้อมทุกอย่างข้างในและย้อนกลับไม่ได้ พาธที่ไม่มีอยู่ก็นับว่าสำเร็จ

### พาธ

`path_name` และ `path_ext` คืนส่วนสุดท้ายของพาธและนามสกุล (ถ้าไม่มีได้ข้อความว่าง) `absolute_path` เติมไดเรกทอรีปัจจุบัน
ไว้หน้าพาธสัมพัทธ์ และไม่ได้ตรวจว่าพาธนั้นมีอยู่จริง

```ling
ผูก start = ทำ {
  พิมพ์(ชื่อไฟล์("photos/cat.png"), " ", นามสกุลไฟล์("photos/cat.png"))
  พิมพ์(นามสกุลไฟล์("README"), "|")
}
```
```output
cat.png png
|
```

## เวลา

### `time_now()` และ `epoch_now()`

`time_now` นับวินาที (มีทศนิยม) ตั้งแต่โปรแกรมเริ่ม เหมาะกับการจับเวลาและแอนิเมชัน ส่วน `epoch_now` คือเวลาจริงในหน่วยวินาทียูนิกซ์
ไม่มีฟังก์ชันในตัวสำหรับจัดรูปแบบวันที่

```ling
ผูก start = ทำ {
  ผูก เริ่ม = เวลาปัจจุบัน()
  นอน(20)
  พิมพ์(เวลาปัจจุบัน() - เริ่ม >= 0.02)
  พิมพ์(เวลาโลก() > 1700000000)
}
```
```output
true
true
```

### `random_hex(bytes)`

คืนไบต์สุ่มที่ปลอดภัยทางการเข้ารหัสจำนวน `bytes` ไบต์ เป็นเลขฐานสิบหกตัวพิมพ์เล็ก (ค่าปริยาย 16 ไบต์ คือ 32 ตัวอักษร)
ใช้กับโทเคนและ ID ส่วนเกมให้ใช้ `rand()`

```ling
ผูก start = ทำ {
  พิมพ์(ความยาว(random_hex(16)))
  พิมพ์(random_hex(4) == random_hex(4))
}
```
```output
32
false
```

## บรรทัดคำสั่งและสภาพแวดล้อม

### `cli_arg(name, default)` และ `get_args()`

`cli_arg("port", "8080")` คืนค่าที่อยู่หลัง `--port` ในบรรทัดคำสั่ง หรือค่าปริยายถ้าไม่มี เข้าใจเฉพาะรูปแบบสองคำ `--port 9000`
`get_args()` คืนบรรทัดคำสั่งทั้งหมด สำหรับ `ling run app.ling a b` จะเริ่มด้วยไฟล์โปรแกรม `ling` ตามด้วย `run` สคริปต์ แล้วจึงเป็นอาร์กิวเมนต์ของคุณ

```ling
ผูก start = ทำ {
  พิมพ์(อาร์กิวเมนต์("port", "8080"))
  พิมพ์(รับอาร์กิวเมนต์()[1])
}
```
```output
8080
run
```

### `env_get(name, default)`

อ่านตัวแปรแวดล้อม หรือคืนค่าปริยาย (ถ้าไม่ใส่ได้ข้อความว่าง)

```ling
ผูก start = ทำ {
  พิมพ์(รับตัวแปรแวดล้อม("MY_APP_MODE", "พัฒนา"))
}
```
```output
พัฒนา
```

## โปรเซส

`run_process(cmd, args, timeout, log)` รันโปรแกรมโดยตรง (ไม่ผ่านเชลล์ จึงไม่มีปัญหาเรื่องเครื่องหมายคำพูดหรือการแทรกคำสั่ง)
ต่อท้ายเอาต์พุตลงไฟล์ `log` แล้วรอจนจบ คืนรหัสออก หรือ `-1` ถ้าเริ่มโปรแกรมไม่ได้ หรือ `-2` ถ้าถูกหยุดเพราะเกิน `timeout` วินาที

`proc_start(cmd, args, log)` เริ่มโปรแกรมโดยไม่รอ และคืน id (`-1` ถ้าล้มเหลว) `proc_poll(id)` คืน `-2` ระหว่างที่ยังทำงาน
และคืนรหัสออกเมื่อจบ ส่วน `proc_kill(id)` หยุดโปรแกรม

```ling-gui
ผูก start = ทำ {
  พิมพ์(รันโปรเซส("git", ["--version"], 10, "git.log"))
  พิมพ์(ตัดช่องว่าง(อ่านไฟล์("git.log")))
  ผูก หมายเลข = proc_start("git", ["status"], "status.log")
  ขณะที่ proc_poll(หมายเลข) == -2 { นอน(100) }
  พิมพ์("เสร็จแล้ว")
}
```

ฟังก์ชันในตัวเกี่ยวกับโปรเซสอยู่ใน[โปรไฟล์](index.md) `web` ถ้าบิลด์ไม่มีโปรไฟล์นี้ การเรียกจะเกิดข้อผิดพลาดที่บอกวิธีติดตั้งใหม่

## เธรดและแชนเนล

เธรดของ Ling เป็นไอโซเลต แต่ละเธรดรันอินเทอร์พรีเตอร์ของตัวเอง และไม่แชร์อะไรกันเลยนอกจากแชนเนลกับที่เก็บค่าที่เขียนได้ครั้งเดียว
จึงไม่เกิดการแย่งกันใช้ข้อมูล ค่าที่ส่งข้ามเธรดจะถูกคัดลอก และส่งฟังก์ชันไม่ได้

| Builtin | Purpose |
|---|---|
| `thread_spawn(file, fn_name, args, caps)` | รันฟังก์ชันจากไฟล์ `.ling` อื่นบนเธรดใหม่ คืน `ok(handle)` |
| `thread_join(handle)` | รอให้เธรดจบ คืน `ok(value)` หรือ `bad(error)` |
| `thread_cpus()` | จำนวนเธรดของฮาร์ดแวร์ |
| `chan_new(capacity)` | แชนเนลใหม่ในรูป `[send_handle, receive_handle]` |
| `chan_send(send, value)` | ส่งค่า (รอถ้าแชนเนลเต็ม) |
| `chan_recv(receive)` | รับค่าถัดไปเป็น `ok(value)` หรือ `bad("closed")` |
| `chan_close(handle)` | ปิดปลายด้านหนึ่งของแชนเนล |
| `chan_len(handle)` | จำนวนข้อความที่รออยู่ |
| `shared_put(key, value)` | เก็บค่าได้ครั้งเดียว ได้ `bad("exists")` ถ้ามีคีย์นี้แล้ว |
| `shared_get(key, default)` | อ่านค่าที่เก็บไว้ |

แชนเนลใช้ภายในโปรแกรมเดียวก็ได้

```ling
ผูก start = ทำ {
  ผูก ช่อง = chan_new(4)
  chan_send(ช่อง[0], "สวัสดี")
  chan_send(ช่อง[0], 42)
  พิมพ์(chan_len(ช่อง[1]))
  พิมพ์(chan_recv(ช่อง[1]), " ", chan_recv(ช่อง[1]))
  chan_close(ช่อง[0])
  พิมพ์(chan_recv(ช่อง[1]))
  พิมพ์(shared_put("ตั้งค่า", [1, 2]), " ", shared_put("ตั้งค่า", 0))
  พิมพ์(shared_get("ตั้งค่า", []))
}
```
```output
2
Ok(สวัสดี) Ok(42)
Err(closed)
Ok(()) Err(exists)
[1, 2]
```

`thread_spawn` โหลดฟังก์ชันจากไฟล์แยก โดยพาธนับจากไฟล์ที่เรียก `caps` คือรายการสิ่งที่เธรดนั้นทำได้ เลือกจาก
`fs db net p2p proc keys clipboard` เธรดลูกไม่มีวันได้สิทธิ์ที่เธรดแม่ไม่มี ก่อน join ให้แกะแฮนเดิลออกด้วย `match`

```ling-module
// main.ling วางคู่กับ worker.ling ซึ่งนิยามไว้ว่า ฟังก์ชัน ยกกำลังสอง(n) { n * n }
ฟังก์ชัน ยกกำลังสองบนเธรด(n) {
  ผูก แฮนเดิล = จับคู่ thread_spawn("worker.ling", "ยกกำลังสอง", [n], []) { ok(v) => v, bad(e) => e }
  thread_join(แฮนเดิล)
}
```
