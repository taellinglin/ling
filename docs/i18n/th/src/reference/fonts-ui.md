# ฟอนต์และ UI

หน้านี้ว่าด้วยข้อความและส่วนติดต่อผู้ใช้ ได้แก่ ฟอนต์ TrueType และ OpenType ที่วาดเป็นเส้นขอบเวกเตอร์คมชัด
ฟอนต์เส้นในตัว และชุดเครื่องมือ `ui_*` ที่มีมาตรวัด เกจ และตัวควบคุม ทั้งหมดวาดลง
เฟรมบัฟเฟอร์เดียวกับคำสั่ง [การวาด 2 มิติ](drawing.md) จึงควรอยู่ระหว่าง `fill()`
กับ `present()` ถ้าจะวาดทับฉาก 3 มิติ ให้เรียก `flush_3d()` ก่อน กล่องบทสนทนาแบบพิมพ์ทีละตัว
มีหน้าของตัวเอง: [บทสนทนา](dialog.md)

## ฟอนต์

Ling วาดข้อความได้สองแบบ:

* **ฟอนต์เวกเตอร์** `font_load` อ่านไฟล์ `.ttf` หรือ `.otf` ส่วน `font_text_fill`, `font_text` และ
  `font_text_3d` วาดเส้นขอบของตัวอักษร เส้นโค้งถูกเก็บไว้ครบ ข้อความจึงคมชัดทุกขนาด อักษรละติน
  จีน ญี่ปุ่น เกาหลี และไทยใช้ได้หมด ถ้าฟอนต์มีตัวอักษรนั้น
* **ฟอนต์เส้น** `ui_text` วาดตัวอักษรแบบ "โฮโลกราฟิก" ความกว้างคงที่อย่างง่าย ไม่ต้องใช้ไฟล์
  ฟอนต์ ใช้กับข้อความ ASCII พื้นฐาน

ครั้งแรกที่ใช้ตัวอักษรใด เส้นขอบของมันจะถูกแคชลงดิสก์ใน `cache/fonts/` ในโฟลเดอร์ที่
โปรแกรมรันอยู่ การรันครั้งต่อไปจึงเริ่มเร็วขึ้น ในรันไทม์บนเว็บ `font_load` คืน `-1` ให้ตรวจ
แฮนเดิลแล้วถอยไปใช้ `ui_text` ถ้าต้องการให้โปรแกรมรันได้ทั้งสองที่

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(720, 320, "ฟอนต์")
    ผูก ฟอนต์ = โหลดฟอนต์("assets/fonts/Exo2.ttf", 600)
    ผูก ฟอนต์ไทย = โหลดฟอนต์("assets/fonts/NotoSansThai.ttf")
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(8, 10, 24)
        สีดินสอ(0, 230, 255)
        เติมฟอนต์(ฟอนต์, 30, 40, 48, "Hello Ling")
        สีดินสอ(255, 200, 80)
        ข้อความฟอนต์(ฟอนต์, 30, 110, 48, "Stroked Outline")
        สีดินสอ(255, 255, 255)
        เติมฟอนต์(ฟอนต์ไทย, 30, 180, 40, "สวัสดี หลิง")
        สีดินสอ(120, 255, 160)
        ข้อความหน้าจอ(30, 260, 16, "UI TEXT 0123")
        แสดงผล()
    }
}
```

### `font_load(path, weight)`

โหลดฟอนต์และคืนแฮนเดิล (0 สำหรับฟอนต์แรก 1 สำหรับฟอนต์ถัดไป และต่อไปเรื่อยๆ) หรือ `-1` ถ้า
อ่านไม่ได้ ซึ่งจะมีข้อความในสตรีมข้อผิดพลาด พาธจะถูกลองตามที่ให้มาก่อน แล้วจึงเทียบกับ
โฟลเดอร์ของสคริปต์ `weight` ไม่บังคับ: สำหรับฟอนต์แบบแปรผัน ตัวเลขอย่าง 600 ให้ตัวหนา
0 หรือไม่ใส่คือใช้ค่าเริ่มต้นของฟอนต์

รีโพซิทอรีของ Ling มี Exo2, Orbitron, Rajdhani, Noto Sans (SC, JP, KR, Thai) และ Galmuri อยู่ใน
`assets/fonts/` ถ้าโปรแกรมอาจถูกเรียกจากโฟลเดอร์ต่างกัน ให้ลองพาธที่สองด้วย:

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก ฟอนต์ = โหลดฟอนต์("assets/fonts/Exo2.ttf", 600)
    ถ้า ฟอนต์ < 0 { ผูก ฟอนต์ = โหลดฟอนต์("../../assets/fonts/Exo2.ttf", 600) }
}
```

### `font_text_fill(font, x, y, px, text)` และ `font_text(font, x, y, px, text)`

`font_text_fill` วาดตัวอักษรทึบด้วยสีดินสอ ส่วน `font_text` วาดเส้นขอบ ซึ่ง
ประหยัดกว่าและเคารพ `set_blend` กับ `set_antialias` `x, y` คือ **มุมซ้ายบน** ของบรรทัด ไม่ใช่
เส้นฐาน: ตัวพิมพ์ใหญ่เริ่มต่ำกว่า `y` ราว `0.3 * px` และเส้นฐานอยู่ต่ำกว่า `y` ราว `0.97 * px`
`px` คือขนาดเป็นพิกเซล (ค่าเริ่มต้น 16) ขอบจะคมจนกว่าคุณจะเรียก `set_font_antialias(1)`
แฮนเดิลที่ผิดจะไม่วาดอะไร

### `font_text_3d(font, cx, cy, cz, ux, uy, uz, vx, vy, vz, size, text, fill_rows)`

วาดข้อความบนระนาบใน 3 มิติ เรียงความลึกร่วมกับฉากจึงหมุนไปตามกล้อง `c` คือจุดเริ่ม
บรรทัด `u` คือทิศที่ข้อความเดินไป (ค่าเริ่มต้น `1, 0, 0`) `v` คือทิศขึ้นของตัวอักษร
(ค่าเริ่มต้น `0, 1, 0`) และ `size` คือความสูงหนึ่ง em เป็นหน่วยโลก (ค่าเริ่มต้น 1) เพราะ +y ชี้ลง
ข้อความที่ตั้งตรงจึงต้องใช้ `v = (0, -1, 0)` วาดเฉพาะเส้นขอบ เว้นแต่ `fill_rows` มากกว่า 0
ซึ่งจะเติมตัวอักษรแต่ละตัวด้วยเส้นสแกนตามจำนวนนั้น

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก ฟอนต์ = โหลดฟอนต์("assets/fonts/NotoSansThai.ttf")
    สีดินสอ(120, 230, 255)
    ข้อความฟอนต์3มิติ(ฟอนต์, -2, 0, 8, 1, 0, 0, 0, -1, 0, 0.6, "หลิง 3 มิติ")
}
```

### `font_width(font, px, text)`

ความกว้างของสตริงเป็นพิกเซล (0 ถ้าแฮนเดิลผิด) สังเกตลำดับ: ขนาดมา **ก่อน**
ข้อความ ถ้าจะจัดป้ายให้อยู่กลางกล่อง `bx, by, bw, bh` ให้วาดที่
`x = bx + (bw - font_width(f, px, text)) / 2` และ `y = by + bh / 2 - 0.64 * px`

### `font_advance(font, char)` และ `font_glyph_outline(font, char, tol)`

`font_advance` ให้ระยะเลื่อนของอักขระหนึ่งตัวเป็น em (คูณด้วยขนาดพิกเซล)
`font_glyph_outline` คืนเส้นขอบของอักขระเพื่อทำเอฟเฟกต์ของคุณเอง: เป็นรายการของเส้นรอบรูป แต่ละเส้นเป็น
รายการแบน `[x0, y0, x1, y1, ...]` ในหน่วย em โดยเส้นฐานอยู่ที่ 0 และ **y ชี้ขึ้น** `tol` คือ
ระยะที่เส้นหลายส่วนเบี่ยงจากเส้นโค้งจริงได้ (ค่าเริ่มต้น 0.01 em) ถ้าล้มเหลวจะได้รายการว่าง

### `font_fallback(primary, fallback, scale)`

ใช้ `fallback` กับอักขระทุกตัวที่ `primary` ไม่มี เช่นฟอนต์ยูนิโค้ดที่ครอบคลุมกว้างอยู่หลังฟอนต์
ละตินที่มีสไตล์ `scale` กำหนดขนาดของฟอนต์สำรองเทียบกับฟอนต์หลัก (ค่าเริ่มต้น 1) ส่ง `-1` เป็น `fallback` เพื่อ
ยกเลิก คืนแฮนเดิลของฟอนต์หลัก หรือ `-1` ถ้ามีแฮนเดิลผิด

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก ละติน = โหลดฟอนต์("assets/fonts/Orbitron.ttf", 600)
    ผูก ไทย = โหลดฟอนต์("assets/fonts/NotoSansThai.ttf")
    font_fallback(ละติน, ไทย, 0.9)
}
```

### `set_font_antialias(on)` และ `get_font_antialias()`

เปิดหรือปิดการทำให้ขอบตัวอักษรเรียบ (ค่าเริ่มต้นปิด เพื่อข้อความที่คมชัด) `set_font_antialias()` แบบไม่ใส่
อาร์กิวเมนต์คือเปิด ส่วนนี้แยกจาก `set_antialias` ซึ่งมีผลกับเส้น

### `ui_text(x, y, scale, text)`

วาดข้อความด้วยฟอนต์เส้นในตัวด้วยสีดินสอ `x, y` คือมุมซ้ายบน ตัวอักษรสูง `scale`
พิกเซล (ค่าเริ่มต้น 16) แต่ละตัวกว้าง `scale * 0.62` และเว้นช่อง `scale * 0.24` ตัวอักษรถูกวาดเป็น
ตัวพิมพ์ใหญ่ ส่วนอักขระที่ฟอนต์นี้ไม่มี (รวมถึงข้อความที่ไม่ใช่ ASCII ทั้งหมด เช่นภาษาไทย) จะแสดงเป็นกล่องเล็กๆ

## ชุดเครื่องมือ UI

ฟังก์ชัน `ui_*` เป็นชุดเครื่องมือแบบ **immediate mode** ไม่มีอะไรถูกเก็บไว้ข้ามเฟรม: คุณเรียก
วิดเจ็ตแต่ละตัวทุกเฟรมพร้อมค่าปัจจุบัน มันจะวาดตัวเอง และตัวควบคุมแบบโต้ตอบจะคืน
ค่าใหม่ โปรแกรมของคุณเก็บสถานะทั้งหมดไว้ในตัวแปรธรรมดา

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(480, 220, "ตัวควบคุม")
    ผูก ระดับเสียง = 0.4
    ผูก เปิดใช้ = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(6, 10, 22)
        ผูก ระดับเสียง = แถบเลื่อน(40, 60, 280, ระดับเสียง, 0, 1)
        ผูก เปิดใช้ = สวิตช์(40, 100, 52, 24, เปิดใช้)
        ถ้า ปุ่ม(40, 150, 120, 36) == 1 { println("คลิกแล้ว") }
        สีดินสอ(220, 240, 255)
        ข้อความหน้าจอ(64, 160, 14, "PLAY")
        แสดงผล()
    }
}
```

ข้อตกลงที่ใช้ร่วมกัน:

* **พิกัด** เป็นพิกเซลบนจอ วิดเจ็ตสี่เหลี่ยมรับ `x, y, w, h` วิดเจ็ตทรงกลมรับจุดศูนย์กลาง
  `cx, cy` และรัศมี `r`
* **สี** มาจากธีม (`ui_theme`) วิดเจ็ตส่วนใหญ่รับ `r, g, b` ต่อท้ายได้โดยไม่บังคับ
  เพื่อแทนสีหลักในการเรียกครั้งนั้น ให้ใส่ครบทั้งสามหรือไม่ใส่เลย
* **วิดเจ็ตไม่วาดข้อความ** ปุ่มไม่มีป้าย และแถบแท็บไม่มีหัวข้อ ให้วาดป้ายเอง
  ด้วย `ui_text` หรือ `font_text_fill`
* **การโต้ตอบ** อ่านปุ่มซ้ายของเมาส์ ปุ่มคืน `1` เฉพาะในเฟรมที่เมาส์
  กดลงบนมัน จึงต้องเทียบด้วย `== 1` ซึ่งต้องเรียก `present()` เฟรมละครั้ง
* **การผสมสี** วิดเจ็ตเคารพ `set_blend` ดังนั้น `set_blend(1)` จะทำให้มันเรืองแสง

### `ui_theme(...)` และ `ui_theme_colors()`

`ui_theme` ตั้งสีที่วิดเจ็ตทุกตัวใช้วาด: `r, g, b` หกชุดตามลำดับ primary (สีหลัก),
accent (สีเน้น), track (พื้นหลังจางของมาตรวัด), warn (สีเตือน), text (สีข้อความ) และ bg (สีเติมแผง) ชุดที่ไม่ใส่
จะคงค่าเดิม ดังนั้น `ui_theme(255, 0, 128)` เปลี่ยนเฉพาะสีหลัก `ui_theme_colors()` คืน
ธีมปัจจุบันเป็นรายการตัวเลข 18 ตัว ส่วนติดต่อที่วาดเองจึงใช้สีให้เข้ากันได้:

```ling
ผูก เริ่ม = ทำ {
    ธีมส่วนติดต่อ(255, 0, 128)
    println(ui_theme_colors())
}
```

```output
[255, 0, 128, 40, 255, 180, 44, 62, 100, 255, 90, 90, 190, 235, 255, 10, 16, 24]
```

ผลลัพธ์ยังแสดงค่าเริ่มต้นในตัวของอีกห้าสีด้วย

### ตัวช่วยจัดวาง: `ui_hot`, `ui_frame`, `ui_bevel`, `ui_panel`, `ui_scanlines`

`ui_hot` คืน `true` เมื่อเมาส์อยู่ในสี่เหลี่ยม ใช้ทำเอฟเฟกต์ตอนชี้และตัวควบคุมที่คุณสร้างเอง
`ui_frame` (ความยาวแขนวงเล็บ ค่าเริ่มต้น 14) และ `ui_bevel` (ขนาดมุมตัด ค่าเริ่มต้น 10) วาด
เส้นขอบด้วยสีดินสอ `ui_panel` วาดแผงตัดมุมที่เติมด้วยสี bg ของธีม
(มุมตัดค่าเริ่มต้น 12 สีขอบไม่บังคับเริ่มที่อาร์กิวเมนต์ที่หก) `ui_scanlines` วาดเส้นแนวนอน
`density` เส้น (ค่าเริ่มต้น 24)

```ling-gui
ผูก เริ่ม = ทำ {
    แผง(20, 20, 340, 200, 14)
    ถ้า พื้นที่สัมผัส(40, 140, 120, 36) { สีดินสอ(255, 255, 255) } มิฉะนั้น { สีดินสอ(120, 140, 160) }
    กรอบเฉียง(40, 140, 120, 36, 8)
}
```

### HUD: `ui_radar`, `ui_compass`, `ui_reticle`, `ui_target`

`ui_radar` วาดวงระยะและเส้นกวาดที่มุม `sweep` เป็นเรเดียน ขับด้วย `time_now()`
`ui_compass` แสดงแถบที่มี `heading` อยู่ตรงกลางเป็น **องศา** มีขีดทุก 15 องศา
`ui_reticle` วาดวงที่ช่องว่างเปิดกว้างขึ้นเมื่อ `spread` จาก 0 ไป 1 `ui_target` วาดวงเล็บ
ที่หุบเข้าเมื่อ `lock` จาก 0 ไป 1

### มาตรวัด: `ui_bar`, `ui_segbar`, `ui_gauge`, `ui_ring`, `ui_vu`, `ui_spark`, `ui_battery`, `ui_progress`

มาตรวัดแต่ละตัวแสดง `value` จาก `max` (ค่าเริ่มต้น 1) `ui_segbar` แบ่งแถบเป็น `segments` ช่อง
(ค่าเริ่มต้น 10) `ui_gauge` เป็นหน้าปัดมีเข็ม `ui_ring` เติมตามเข็มนาฬิกา `ui_vu` รับรายการ
ระดับจาก 0 ถึง 1 ตัวละแท่ง และเปลี่ยนไปทางสีเตือนเมื่อสูงขึ้น `ui_spark` ย่อขยายรายการ
ตัวเลขอย่างน้อยสองตัวให้พอดีกล่อง `ui_battery` เปลี่ยนเป็นสีเตือนเมื่อต่ำกว่า 25 เปอร์เซ็นต์
`ui_progress` รับ `fraction` ค่าเดียวจาก 0 ถึง 1

```ling-gui
ผูก เริ่ม = ทำ {
    แถบ(40, 70, 280, 14, 70, 100)
    แถบแบ่ง(40, 96, 280, 14, 6, 10, 10)
    มาตรวัด(450, 120, 50, 62, 100)
    มาตรเสียง(330, 330, 160, 60, [0.2, 0.5, 0.8, 1.0, 0.7, 0.3])
}
```

### ตัวควบคุม: `ui_button`, `ui_toggle`, `ui_slider`, `ui_checkbox`, `ui_tabs`, `ui_stepper`, `ui_tooltip`

- `ui_button` สว่างขึ้นเมื่อชี้ และคืน `1` ในเฟรมที่ถูกคลิก นอกนั้นคืน `0`
- `ui_toggle` และ `ui_checkbox` รับสถานะปัจจุบันและคืนสถานะใหม่ `1` หรือ `0`
- `ui_slider` ไม่มีอาร์กิวเมนต์ความสูง (พื้นที่จับสูง 20 พิกเซล) คืนค่าใหม่
  ซึ่งตามเคอร์เซอร์ขณะกดปุ่มค้างไว้
- `ui_tabs` วาดแท็บเท่ากัน `count` แท็บ และคืนลำดับแท็บที่เลือก (เริ่มจาก 0) หารความกว้างด้วย
  `count` เพื่อวางหัวข้อ
- `ui_stepper` คืน `value` บวกหรือลบ `step` เมื่อคลิกด้านใดด้านหนึ่ง และไม่วาดตัวเลข
- `ui_tooltip` เป็นกล่องคำอธิบาย ให้วาดใกล้เคอร์เซอร์เมื่อชี้ที่อะไรสักอย่าง

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก แท็บที่เลือก = 0
    ผูก จำนวน = 3
    ผูก แท็บที่เลือก = แท็บ(20, 250, 300, 28, 3, แท็บที่เลือก)
    ผูก จำนวน = ตัวปรับค่า(160, 178, 140, 28, จำนวน, 1)
    ข้อความหน้าจอ(222, 186, 14, str(จำนวน))
}
```

### UI ในเกม: `ui_healthbar`, `ui_cooldown`, `ui_counter`, `ui_minimap`, `ui_dpad`, `ui_slotgrid`, `ui_vignette`

`ui_healthbar` เปลี่ยนจากสีเตือนเมื่อว่างไปเป็นสีเน้นเมื่อเต็ม `pulse` (0 ถึง 1)
ทำให้กะพริบไปทางสีขาวเมื่อต่ำกว่า 30 เปอร์เซ็นต์ `ui_cooldown` เติมชิ้นวงกลมตามเข็มนาฬิกาจาก
ตำแหน่งสิบสองนาฬิกา `ui_counter` แสดง `value` เป็นตัวเลขเจ็ดส่วน `digits` หลัก `ui_minimap` วาดกรอบ
แผนที่เปล่า ให้จุดตำแหน่งเองด้วย `draw_disc` `ui_dpad` คืน `0` ไม่มี `1` ขึ้น `2` ขวา `3` ลง
หรือ `4` ซ้าย ขณะกดเมาส์ค้างบนมัน `ui_slotgrid` ไฮไลต์ช่อง `selected` (`-1` คือไม่มี)
`ui_vignette` เรืองแสงตามขอบจอ ใช้เป็นแสงวาบตอนโดนโจมตี

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก พลังชีวิต = 24
    แถบพลังชีวิต(20, 300, 220, 16, พลังชีวิต, 100, 0.5 + 0.5 * ไซน์(เวลาปัจจุบัน() * 8))
    ตัวนับ(20, 340, 16, 28, 1234, 5)
    ช่องไอเทม(400, 260, 5, 2, 40, 1)
}
```

### กึ่ง 3 มิติ: `ui_gauge3d`, `ui_panel3d`, `ui_radar3d`

`ui_gauge3d` วาดแถบโครงลวดที่หมุนตาม `spin` และสว่างขึ้นถึง `value` `ui_panel3d` ยก
แผงตัดมุมให้ลอยจากจอ `depth` พิกเซล (ค่าเริ่มต้น 14) `ui_radar3d` เอียงเรดาร์เข้าไปใน
จอ (`tilt` 0 ถึง 1 ค่าเริ่มต้น 0.9)

### `ui_sound(name)`

เล่นเสียงส่วนติดต่อสั้นๆ ที่สังเคราะห์ขึ้น: `"click"` (ใช้แทนชื่อที่ไม่รู้จักด้วย)
`"hover"`, `"confirm"`, `"toggle"`, `"tick"` หรือ `"error"` จะเงียบถ้าระบบเสียงไม่ได้ทำงาน

```ling-gui
ผูก เริ่ม = ทำ {
    ถ้า ปุ่ม(20, 400, 120, 36) == 1 { เสียงปุ่ม("confirm") }
}
```
