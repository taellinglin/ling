# แอนิเมชัน

Anima คือระบบแอนิเมชันของ Ling สิ่งที่เคลื่อนไหวทุกอย่าง ไม่ว่าจะเป็นภาพวาด 2 มิติ เมช 3 มิติ อนุภาค หรือแค่ตัวเลข ล้วนขับเคลื่อนด้วย **ตัวขับ** (driver) เล็กๆ ตัวขับคือฟังก์ชันที่คุณเรียกทุกเฟรมพร้อมเวลาปัจจุบัน แต่ละตัวคืนตัวเลขหนึ่งค่า แล้วคุณนำตัวเลขนั้นไปใส่ขนาด ตำแหน่ง มุม หรืออาร์กิวเมนต์ของลวดลาย

ตัวขับแบ่งเป็นสองอุปนิสัย:

- ตัวขับแบบ **ธรรมชาติ** (灵 "จิตวิญญาณ") สร้างการเคลื่อนไหวที่นุ่มนวลเหมือนมีชีวิต เช่น การหายใจ การโยก การเดิน การเด้งตามแบบสปริง และจลนศาสตร์ผกผันแบบสองกระดูก
- ตัวขับแบบ **กลไก** (机 "เครื่องจักร") สร้างการเคลื่อนไหวที่แม่นยำและแข็งแรง เช่น เฟืองขบกัน ลูกเบี้ยว ข้อเหวี่ยงลูกสูบ และแร็คกับพิเนียน

คุณผสมทั้งสองแบบในตัวละครเดียวได้ เช่น สัตว์ที่อกหายใจได้แต่ขากรรไกรขยับแบบกลไก สำหรับตัวละคร 3 มิติที่นำเข้ามาพร้อมโครงกระดูก ฟังก์ชันในตัว `gltf_*` ท้ายหน้านี้ใช้เล่นคลิปแอนิเมชันโครงกระดูกได้

## ตัวขับทำงานอย่างไร

ตัวขับเป็น **ฟังก์ชันบริสุทธิ์** ไม่มีสถานะซ่อนอยู่ อาร์กิวเมนต์เดิมจึงให้คำตอบเดิมเสมอ

- ตัวขับที่อิงเวลา (`breathe`, `wobble`, `gait_*`) รับเวลาปัจจุบันจากคุณ ปกติคือ `time_now()` หรือตัวแปรที่คุณเพิ่มทีละ `1/60` ทุกเฟรม ไม่มีอะไรเล่นอยู่เบื้องหลัง
- ตัวขับสปริง (`spring_to`) คืนสถานะใหม่ แล้วคุณส่งกลับเข้าไปในเฟรมถัดไป โปรแกรมของคุณเป็นผู้ถือสถานะ

มุมมีหน่วยเป็นเรเดียน ความยาวใช้หน่วยเดียวกับภาพวาดของคุณ ตัวขับคำนวณแบบความแม่นยำเดี่ยว ตัวอย่างจึงปัดผลลัพธ์ด้วยฟังก์ชันช่วยเล็กๆ ชื่อ `ปัด3`

## การประมาณค่า

### `tween(a, b, t)` และ `tween_ease(a, b, t, curve)`

`tween` คืน `a + (b - a) * t` ค่าความคืบหน้า `t` ถูก **บีบ** ให้อยู่ในช่วง 0..1 คุณจึงเพิ่มเกิน 1 ไปเรื่อยๆ ได้โดยค่ายังคงอยู่ที่ `b`

`tween_ease` ทำแบบเดียวกันแต่ผ่านเส้นโค้งผ่อน `curve` คือชื่อจากตาราง Anima ด้านล่าง (ค่าเริ่มต้น `"linear"`) เส้นโค้งแบบ elastic และ back อาจเลย `b` ไปได้

### `ease(curve, t)`

ค่าดิบของเส้นโค้งผ่อนของชุดเครื่องมือ UI ที่ความคืบหน้า `t` (บีบให้อยู่ใน 0..1) คือ 0 ที่จุดเริ่มและ 1 ที่จุดจบ ชื่อเส้นโค้งมา **ก่อน** ใช้เมื่อคุณต้องการค่าของเส้นโค้งเอง เช่น เพื่อผสมสองสี ฟังก์ชันนี้ไม่มีชื่อภาษาอื่น

```ling
ฟังก์ชัน ปัด3(x: number) -> number {
    ปัดเศษ(x * 1000) / 1000
}

ผูก เริ่ม = ทำ {
    พิมพ์(แทรกค่า(0, 10, 0.25))
    พิมพ์(แทรกค่า(0, 10, 2.0))
    พิมพ์(ปัด3(แทรกนุ่ม(0, 100, 0.5, "cubic_in")))
    พิมพ์(ปัด3(แทรกนุ่ม(0, 100, 0.5, "bounce_out")))
    พิมพ์(ease("quad_in", 0.5))
    พิมพ์(ปัด3(ease("smooth", 0.25)))
}
```

```output
2.5
10
12.5
76.563
0.25
0.125
```

### ชื่อเส้นโค้งผ่อน

ฟังก์ชันในตัวทั้งสองใช้ **ชุดชื่อต่างกัน** และไม่สนตัวพิมพ์เล็กใหญ่ทั้งคู่

**`tween_ease`** (เส้นโค้ง Anima) จะใส่ขีดล่างหรือไม่ก็ได้ ชื่อที่ไม่รู้จักจะได้ `linear`

| ตระกูล | ชื่อ |
|---|---|
| พื้นฐาน | `linear`, `step` |
| กำลังสอง | `quad_in`, `quad_out`, `quad_in_out` |
| กำลังสาม | `cubic_in`, `cubic_out`, `cubic_in_out` (หรือ `smooth`) |
| ไซน์ | `sine_in`, `sine_out`, `sine_in_out` |
| เอกซ์โพเนนเชียล | `expo_in`, `expo_out`, `expo_in_out` |
| ยืดหยุ่น | `elastic_in`, `elastic_out` (หรือ `elastic`) |
| ถอยกลับ | `back_in`, `back_out`, `back_in_out` (หรือ `overshoot`) |
| เด้ง | `bounce_in`, `bounce_out` (หรือ `bounce`) |

**`ease`** (เส้นโค้ง UI) ใช้ขีดกลางหรือขีดล่างแทนกันได้ ชื่อที่ไม่รู้จักจะได้ `quad_inout`

| ชื่อ | รูปร่าง |
|---|---|
| `linear` | เส้นตรง |
| `quad_in`, `ease_in` | เริ่มช้า |
| `quad_out`, `ease_out` | จบช้า |
| `quad_inout`, `ease`, `smooth` | เริ่มและจบช้า (ค่าเริ่มต้น) |
| `cubic_in`, `cubic_out`, `cubic_inout` | แบบที่แรงขึ้น |
| `quart_out` | เริ่มเร็ว จบช้านาน |
| `sine`, `sine_inout` | ไซน์เข้าออกแบบนุ่ม |
| `expo`, `expo_out` | ลดลงแบบเอกซ์โพเนนเชียล |
| `back`, `back_out` | เลยไปแล้วค่อยเข้าที่ |
| `elastic`, `elastic_out` | เลยไปแบบเด้งสปริง |
| `bounce`, `bounce_out` | เด้งตอนท้าย |

## ตัวขับแบบธรรมชาติ

### `breathe(t, rate, depth)`

ตัวคูณการหายใจรอบค่า 1 คือ `1 + depth * sin(2π * rate * t)` โดย `rate` คือจำนวนครั้งที่หายใจต่อวินาที (ค่าเริ่มต้น 1) และ `depth` คือแอมพลิจูด (ค่าเริ่มต้น 0.1) นำไปคูณกับขนาดหรือรัศมีของลวดลาย

### `wobble(t, freq, amp, phase)`

การโยกแบบไซน์สำหรับการเคลื่อนไหวรอง คือ `amp * sin(2π * (freq * t + phase))` ค่าเริ่มต้นคือ `freq` 1, `amp` 1, `phase` 0 เฟสมีหน่วยเป็นรอบ ดังนั้น `0.25` คือเลื่อนไปหนึ่งในสี่รอบ ให้แขนขาแต่ละข้างมีเฟสต่างกัน แล้วร่างกายจะโยกไม่พร้อมกัน

### `gait_phase(t, speed)`, `gait_swing(t, speed, stride)` และ `gait_lift(t, speed, height)`

รอบการเดิน `speed` คือจำนวนรอบต่อวินาที (ค่าเริ่มต้น 1)

- `gait_phase` คืนตำแหน่งในรอบ ตั้งแต่ 0 ถึง (แต่ไม่รวม) 1
- `gait_swing` คืนการแกว่งขาไปหน้าและหลัง อยู่ระหว่าง `-stride` ถึง `stride` สำหรับขาอีกข้างให้ใช้ `t + 0.5 / speed`
- `gait_lift` คืนความสูงที่ยกเท้า เป็นค่าบวกช่วงครึ่งรอบที่แกว่ง และเป็น 0 ขณะเท้าวางพื้น แกน y ของจอชี้ลง จึงต้องลบออก: `เท้า_y = พื้น_y - gait_lift(...)`

```ling
ฟังก์ชัน ปัด3(x: number) -> number {
    ปัดเศษ(x * 1000) / 1000
}

ผูก เริ่ม = ทำ {
    ผูก เวลา = 0.125
    พิมพ์(ปัด3(หายใจ(เวลา, 1, 0.2)))
    พิมพ์(ปัด3(โยก(เวลา, 1, 10, 0)))
    พิมพ์(ปัด3(เฟสก้าว(เวลา, 2)))
    พิมพ์(ปัด3(ก้าวแกว่ง(เวลา, 1, 30)))
    พิมพ์(ปัด3(ยกเท้า(เวลา, 1, 10)))
}
```

```output
1.141
7.071
0.25
21.213
7.071
```

### `spring_to(pos, vel, target, stiffness, damping, dt)`

สปริงหน่วงหนึ่งขั้นที่ดึง `pos` เข้าหา `target` ใช้กับการเคลื่อนไหวตามหลัง การทำให้กล้องนุ่มนวล และหาง ค่าเริ่มต้นคือ `stiffness` 120, `damping` 14, `dt` 1/60 คืนรายการสองสมาชิก `[ตำแหน่งใหม่, ความเร็วใหม่]` เก็บตัวเลขทั้งสองไว้แล้วส่งกลับเข้าไปในเฟรมถัดไป

เมื่อใช้ค่าเริ่มต้น ค่าจะเลยเป้าไปเล็กน้อย แล้วเข้าที่ภายในราวหนึ่งวินาที:

```ling
ผูก เริ่ม = ทำ {
    ผูก ตำแหน่ง = 0.0
    ผูก ความเร็ว = 0.0
    ผูก รอบ = 0
    ขณะที่ รอบ < 60 {
        ผูก ผล = สปริงไป(ตำแหน่ง, ความเร็ว, 1.0, 120, 14, 1 / 60)
        ผูก ตำแหน่ง = ผล[0]
        ผูก ความเร็ว = ผล[1]
        ผูก รอบ = รอบ + 1
        ถ้า รอบ % 15 == 0 {
            พิมพ์("เฟรมที่ " + str(รอบ) + ": " + str(ปัดเศษ(ตำแหน่ง * 1000) / 1000))
        }
    }
}
```

```output
เฟรมที่ 15: 0.982
เฟรมที่ 30: 1.021
เฟรมที่ 45: 0.997
เฟรมที่ 60: 1
```

### `ik2(l1, l2, tx, ty)`

จลนศาสตร์ผกผันสองกระดูกบนระนาบ หามุมไหล่และมุมศอกที่ทำให้ปลายแขนหรือขาสองท่อนไปถึงเป้าหมาย `l1` และ `l2` คือความยาวกระดูก (ค่าเริ่มต้น 1) และ `(tx, ty)` คือเป้าหมายเทียบกับไหล่

คืน `[ไหล่, ศอก]` เป็นเรเดียน `ไหล่` คือมุมของกระดูกท่อนแรก ส่วน `ศอก` คือมุมงอของท่อนที่สอง **เทียบกับท่อนแรก** เป้าหมายที่เอื้อมไม่ถึงจะถูกบีบ แขนขาจึงเหยียดตรงไปทางเป้าหมาย วิธีวางข้อต่อ:

- ศอก = ตำแหน่งไหล่ + `l1 * (cos(ไหล่), sin(ไหล่))`
- มือ = ศอก + `l2 * (cos(ไหล่ + ศอก), sin(ไหล่ + ศอก))`

```ling
ฟังก์ชัน ปัด3(x: number) -> number {
    ปัดเศษ(x * 1000) / 1000
}

ผูก เริ่ม = ทำ {
    ผูก มุม = ไอเค2(1, 1, 1, 1)
    พิมพ์([ปัด3(มุม[0]), ปัด3(มุม[1])])
}
```

```output
[1.571, -1.571]
```

## ตัวขับแบบกลไก

| ฟังก์ชันในตัว | ค่าที่คืน |
|---|---|
| `gear_couple(angle, teeth_in, teeth_out)` | มุมของเฟืองที่ถูกขับ: `-angle * teeth_in / teeth_out` (เป็น 0 ถ้า `teeth_out` เป็น 0) เฟืองที่ขบกันหมุนสวนทางกัน |
| `gear_train(angle, teeth)` | รายการมุมของเฟืองทุกตัวในชุด `teeth` คือรายการจำนวนฟัน สมาชิกตัวแรกของผลลัพธ์คือ `angle` เอง |
| `cam_lift(angle, lift)` | ความสูงของตัวตามลูกเบี้ยว: `lift * (1 - cos(angle)) / 2` จาก 0 ที่มุม 0 ถึง `lift` ที่ π |
| `piston(angle, crank, rod)` | ตำแหน่งสลักลูกสูบตามแนวกระบอกสูบจากศูนย์กลางข้อเหวี่ยง ค่าเริ่มต้น `crank` 1, `rod` 2 (ก้านสูบควรยาวกว่าข้อเหวี่ยง) |
| `rack(angle, radius)` | ระยะเลื่อนของแร็ค: `angle * radius` |

เฟือง 12 ฟันที่ขับเฟือง 36 ฟัน จะทำให้เฟืองใหญ่หมุนช้าลงเหลือหนึ่งในสาม และหมุนสวนทาง:

```ling
ฟังก์ชัน ปัด3(x: number) -> number {
    ปัดเศษ(x * 1000) / 1000
}

ผูก เริ่ม = ทำ {
    พิมพ์(ปัด3(เฟืองทด(3, 12, 36)))
    ผูก เฟืองทั้งหมด = ชุดเฟือง(1, [12, 36, 12])
    พิมพ์([ปัด3(เฟืองทั้งหมด[0]), ปัด3(เฟืองทั้งหมด[1]), ปัด3(เฟืองทั้งหมด[2])])
    พิมพ์(ปัด3(ยกลูกเบี้ยว(3.14159265, 2)))
    พิมพ์(ปัด3(ลูกสูบ(0, 1, 3)))
    พิมพ์(แร็ค(2, 0.5))
}
```

```output
-1
[1, -0.333, 1]
2
4
1
```

## ฉากที่เคลื่อนไหว

หน้าต่างนี้รวมวงกลมที่หายใจ เท้าที่เดิน และสปริงที่ไล่ตามเป้าหมายที่เคลื่อนที่ ตำแหน่งและความเร็วของสปริงถูกส่งต่อจากเฟรมหนึ่งไปอีกเฟรม

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 360, "อนิมา")
    ผูก เวลา = 0.0
    ผูก ตำแหน่ง = 0.0
    ผูก ความเร็ว = 0.0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(10, 12, 28)
        # ธรรมชาติ: วงกลมที่หายใจ
        สีดินสอ(120, 220, 255)
        วาดวงกลมทึบ(120, 120, 40 * หายใจ(เวลา, 0.4, 0.12))
        # ธรรมชาติ: เท้าที่เดิน
        ผูก แกว่ง = ก้าวแกว่ง(เวลา, 1.0, 30)
        ผูก ยก = ยกเท้า(เวลา, 1.0, 20)
        สีดินสอ(255, 210, 90)
        วาดเส้น(120, 200, 120 + แกว่ง, 260 - ยก)
        วาดวงกลมทึบ(120 + แกว่ง, 260 - ยก, 10)
        # ธรรมชาติ: สปริงไล่ตามเป้าหมาย
        ผูก เป้าหมาย = 400 + 80 * ไซน์(เวลา * 1.3)
        ผูก ผล = สปริงไป(ตำแหน่ง, ความเร็ว, เป้าหมาย, 120, 10, 0.016)
        ผูก ตำแหน่ง = ผล[0]
        ผูก ความเร็ว = ผล[1]
        สีดินสอ(120, 255, 160)
        วาดวงกลมทึบ(ตำแหน่ง, 180, 12)
        แสดงผล()
        ผูก เวลา = เวลา + 0.016
    }
}
```

## แอนิเมชันโครงกระดูก (glTF)

ตัวละครที่ทำริกแล้วส่งออกเป็น `.glb` หรือ `.gltf` จะมีโครงกระดูก น้ำหนักสกิน และคลิปแอนิเมชัน ฟังก์ชันในตัวเหล่านี้โหลดโมเดลแบบนั้นแล้ววาดพร้อมสกินนิง ฟังก์ชันกลุ่มนี้ไม่มีชื่อภาษาอื่น ยกเว้นฟังก์ชันวาดแบบมีพื้นผิวสองตัว: `gltf_anim_draw_tex` เขียนเป็น `骨骼动画纹理绘制` (zh), `スキンアニメ描画` (ja), `글꼴애니텍스처` (ko), `วาดแอนิเมชันมีพื้นผิว` (th) ได้ด้วย และ `gltf_pose_draw_tex` เขียนเป็น `骨骼姿势纹理绘制`, `スキンポーズ描画`, `글꼴포즈텍스처`, `วาดสกินมีพื้นผิว` ได้ด้วย

| ฟังก์ชันในตัว | หน้าที่ |
|---|---|
| `gltf_load(path)` | โหลดโมเดล คืนแฮนเดิล หรือ `-1` เมื่อล้มเหลว |
| `gltf_anim_count(h)` | จำนวนคลิปแอนิเมชัน |
| `gltf_anim_name(h, i)` | ชื่อของคลิป `i` |
| `gltf_anim_dur(h, i)` | ความยาวของคลิป `i` เป็นวินาที |
| `gltf_joint_count(h)` | จำนวนข้อต่อ (กระดูก) ของสกิน |
| `gltf_joint_name(h, j)` | ชื่อของข้อต่อ `j` |
| `gltf_autorig(h)` | ใส่ริกมนุษย์แบบโพรซีเดอรัล 20 กระดูกให้โมเดลที่ไม่มีโครงกระดูก คืนจำนวนกระดูก |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | วาดโมเดลแบบมีพื้นผิว สกินด้วยคลิป `clip` ที่เวลา `time` วินาที |
| `gltf_pose_draw(h, x, y, z, scale, yaw, pose)` | วาดโมเดลที่สกินด้วยท่าทางของคุณเอง (สีเรียบ) |
| `gltf_pose_draw_tex(h, x, y, z, scale, yaw, pose)` | เหมือนข้างบนแต่มีพื้นผิว |
| `gltf_bounds(h, clip, time)` | `[minX, minY, minZ, maxX, maxY, maxZ]` ของโมเดลเมื่อวาดด้วยคลิปและเวลานั้น |

หมายเหตุ:

- เวลาของคลิปวนรอบ คุณจึงส่งเวลาที่เพิ่มขึ้นเรื่อยๆ ได้ และคลิปจะเล่นวน
- `pose` คือรายการแบนของมุมออยเลอร์เป็นเรเดียน กระดูกละสามค่า (X, Y, Z)
- โมเดล glTF ใช้แกน Y ชี้ขึ้น ฟังก์ชันวาดจะพลิกให้เข้ากับพื้นที่ y ชี้ลงของตัวเรนเดอร์ ดังนั้น `(x, y, z)` คือตำแหน่งที่จุดกำเนิดของโมเดล (ปกติคือเท้า) จะไปอยู่
- `gltf_anim_draw_tex` รับอาร์กิวเมนต์เสริมเพิ่มเติมหลัง `time` ได้แก่ แสงแวดล้อม การตัดหน้าหลัง (`1` เพื่อตัด) โมเดลต้นทางที่ใช้คลิปขับโมเดลนี้ (สำหรับอุปกรณ์สวมใส่ที่จับคู่ด้วยชื่อข้อต่อ) รายการการหมุนเพิ่มเติมต่อกระดูก และสีย้อม `0xRRGGBB`
- `gltf_draw(h, x, y, z, scale, yaw)` วาดโมเดลแบบไม่สกิน ส่วน `gltf_mesh_count`, `gltf_mesh_name`, `gltf_mesh_show(h, i, on)` และ `gltf_mesh_tint(h, i, 0xRRGGBB)` ใช้แสดง ซ่อน หรือย้อมสีเมชทีละชิ้น เช่น เพื่อสลับอุปกรณ์สวมใส่

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(960, 540, "เดิน")
    ทดสอบความลึก(1)
    ผูก ฮีโร่ = gltf_load("hero.glb")
    ผูก ลำดับ = 0
    ขณะที่ ลำดับ < gltf_anim_count(ฮีโร่) {
        พิมพ์(gltf_anim_name(ฮีโร่, ลำดับ) + ": " + str(gltf_anim_dur(ฮีโร่, ลำดับ)) + " วินาที")
        ผูก ลำดับ = ลำดับ + 1
    }
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(20, 24, 40)
        gltf_anim_draw_tex(ฮีโร่, 0, 2, 6, 1, 0.5, 0, เวลาปัจจุบัน())
        flush_3d()
        แสดงผล()
    }
}
```

## สิ่งที่ไม่ใช่ฟังก์ชันในตัว

crate `ling-animation` ยังมีแทร็กคีย์เฟรมและไทม์ไลน์ ริกข้อต่อพร้อมเมทริกซ์สกินนิง ท่าเดินสองขาและสี่ขาแบบโพรซีเดอรัล ตัวแก้ระบบก้านต่อสี่ชิ้น และริกใบหน้า สิ่งเหล่านี้เป็น Rust API สำหรับผู้ฝังระบบ ไม่ใช่ฟังก์ชันในตัวของ Ling ชื่ออย่าง `rig_load` หรือ `anim_play` ที่ปรากฏในเอกสารเก่าไม่มีอยู่จริง และ `delta_time()` ยังไม่ได้ทำ ให้ใช้ `time_now()` สำหรับเวลา
