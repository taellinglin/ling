# หน้าต่างและกล้อง

โปรแกรมกราฟิกทุกตัวของ Ling จะเปิดหน้าต่าง วนลูปเฟรม และเล็งกล้อง 3 มิติตัวเดียว
หน้านี้อธิบายสามเรื่องนั้น ได้แก่ หน้าต่างกับลูปเฟรม การคุมจังหวะเฟรมและการจับเวลา
และกล้องที่ฉายจุด 3 มิติลงบนจอ ส่วนการวาดอยู่ในหน้าถัดไป:
[การวาด 2 มิติและรูปภาพ](drawing.md) และ [รูปทรงและเมช 3 มิติ](shapes.md)

## ลูปเฟรม

โปรแกรมกราฟิกมีรูปแบบเดียวกันเสมอ คือเปิดหน้าต่าง แล้ววนซ้ำจนกว่าหน้าต่างจะปิด:
ล้างจอ วาด แล้ว `present()`

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(800, 600, "ลูปเฟรม")
    ผูก เฟรม = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(10, 12, 30)                  # 1. ล้างจอด้วยสีพื้นหลัง
        สีดินสอ(255, 200, 80)           # 2. วาด
        วาดวงกลมทึบ(400 + 200 * ไซน์(เฟรม * 0.05), 300, 40)
        แสดงผล()                         # 3. แสดงเฟรม
        ผูก เฟรม = เฟรม + 1
    }
}
```

มีสามข้อที่ควรจำ:

1. `window_is_open()` จะกลายเป็นเท็จเมื่อผู้ใช้ปิดหน้าต่าง **หรือกด Escape**
   คุณไม่ต้องจัดการปุ่ม Escape เอง
2. `present()` เป็นคำสั่งเดียวที่ทำให้พิกเซลขึ้นจอ มันยังวาดรูปทรง 3 มิติที่รอคิวอยู่
   รันโพสต์โพรเซสซิง และอ่านค่าเมาส์ด้วย เฟรมที่ไม่มี `present()` จะมองไม่เห็น
3. ไม่มีฟังก์ชันในตัวสำหรับเวลาต่อเฟรม ให้เอาค่า `time_now()` ปัจจุบันลบค่าก่อนหน้า
   หรือนับเฟรมด้วย `frame_count()`

การเรียกฟังก์ชันในตัวที่ไม่มีอยู่จริง (เช่น `draw_rect` ซึ่ง Ling ไม่มี) จะถูกข้ามไปเงียบๆ
ถ้าคำสั่งวาดดูเหมือนไม่ทำอะไรเลย ให้ตรวจการสะกดก่อน

### พิกัด

| ปริภูมิ | จุดกำเนิด | +x | +y | +z |
|---|---|---|---|---|
| จอ (2 มิติ) | พิกเซลมุมซ้ายบน | ขวา | **ลง** | ไม่ใช้ |
| โลก (3 มิติ) | จุดหมุนของกล้อง | ขวา | **ลง** | ห่างออกจากกล้อง |

เพราะ +y ชี้ลง "ข้างบน" จึงเป็น y ติดลบ เพดานอยู่ที่ `y = -3` และพื้นอยู่ที่ `y = 3`

โปรเจกชันเริ่มต้นจัดภาพให้อยู่กลางหน้าต่าง ใช้ความยาวโฟกัสเท่ากับความสูงหน้าต่างเป็นพิกเซล
และบวกระยะชดเชยความลึก `zdist = 5` ก่อนหารเพอร์สเปกทีฟ:

```text
screen_x = width/2  + height * x / (z + zdist)
screen_y = height/2 + height * y / (z + zdist)
```

## หน้าต่างและเฟรม

### `open_window(w, h, title, resizable)`

เปิดหน้าต่างของโปรแกรมและจองเฟรมบัฟเฟอร์

- **พารามิเตอร์:** `w`, `h` ขนาดเป็นพิกเซล (ค่าเริ่มต้น 800 x 600); `title` (ค่าเริ่มต้น `"Ling"`);
  `resizable` ไม่บังคับ ใส่ `1` เพื่อให้ปรับขนาดหน้าต่างได้ (ค่าเริ่มต้น 0)
- **ค่าที่คืน:** ไม่มี
- **หมายเหตุ:** ตัวเลขมาก่อน ชื่อหน้าต่างอยู่ลำดับที่สาม การเปิดหน้าต่างจะรีเซ็ตโปรเจกชันของกล้อง
  กลับเป็นค่าเริ่มต้นด้วย ถ้าหน้าต่างปรับขนาดได้ ให้อ่าน `get_width()` และ `get_height()`
  ทุกเฟรม ถ้าสร้างหน้าต่างไม่ได้ โปรแกรมจะหยุดพร้อมข้อความ `cannot open window`

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(1024, 640, "เกมของฉัน", 1)
}
```

### `open_fullscreen(title, w, h)` และ `open_fullscreen_scaled(title, scale)`

`open_fullscreen` เปิดหน้าต่างไร้ขอบที่คลุมจอหลัก `w` และ `h` ไม่บังคับ
(ค่าเริ่มต้นคือความละเอียดของจอ) สังเกตว่าที่นี่ **ชื่อหน้าต่างมาก่อน**

`open_fullscreen_scaled` เรนเดอร์ที่ความละเอียดเป็นเศษส่วนของจอแล้วขยายขึ้น
แลกความคมชัดกับความเร็ว `scale` คือ `1`, `2` หรือ `4` (ค่าอื่นนับเป็น 1)
และ `get_width()` กับ `get_height()` จะรายงานขนาดที่ลดลงแล้ว

```ling-gui
ผูก เริ่ม = ทำ {
    open_fullscreen_scaled("ย้อนยุค", 2)
}
```

### `window_is_open()`

เป็น `true` ขณะหน้าต่างเปิดอยู่ และเป็น `false` หลังผู้ใช้ปิดหน้าต่าง กด Escape หรือโค้ดของคุณ
เรียก `quit()` ก่อนเปิดหน้าต่างใดๆ จะคืน `false` ลูปที่ใช้มันเป็นเงื่อนไขจึงไม่ทำงาน

### `present()`

จบเฟรม: วาดรูปทรง 3 มิติทุกชิ้นที่รอคิว ใส่โพสต์โพรเซสซิง คัดลอกเฟรมบัฟเฟอร์ไปที่หน้าต่าง
และอ่านค่าเมาส์

รูปทรง 3 มิติ (`cube`, `vtex_*`, `draw_line_3d` และอื่นๆ) จะถูกเรียงตามความลึกและแรสเตอร์
ที่นี่เท่านั้น คุณจึงสั่งวาดในลำดับใดก็ได้ ส่วนคำสั่ง 2 มิติโดยตรง (`draw_line`, `triangle`, `draw_disc`,
`tex_*`, `image_draw`) เขียนลงเฟรมบัฟเฟอร์ทันที รูปทรง 3 มิติที่รอคิวจึง **ทับอยู่บน** มัน
ถ้าจะวาด HUD ทับฉาก 3 มิติ ให้เรียก `flush_3d()` ก่อน วิดเจ็ต `ui_*` ตรวจการคลิกข้ามเฟรม
จึงต้องเรียก `present()` เฟรมละครั้ง

### `flush_3d()` และ `flush_post()`

`flush_3d()` วาดรูปทรง 3 มิติที่รอคิวลงเฟรมบัฟเฟอร์ทันทีโดยยังไม่แสดงผล สิ่งที่วาดหลังจากนั้น
จะอยู่ด้านบน `flush_post()` ทำแบบเดียวกันแล้วรันโพสต์โพรเซสซิงทันที HUD ที่วาดหลังจากนั้น
จึงไม่ถูกบลูมทำให้เบลอ ดู [โพสต์เอฟเฟกต์และแสง](postfx.md)

```ling-gui
ผูก เริ่ม = ทำ {
    ลูกบาศก์(0, 0, 8, 1, 1, 1, 0, 0, 0, 0)
    flush_3d()                          # ตอนนี้ลูกบาศก์อยู่ในเฟรมบัฟเฟอร์แล้ว
    แถบ(20, 20, 200, 14, 0.5, 1)     # วาดทับลูกบาศก์
    แสดงผล()
}
```

### `quit()`

ปิดหน้าต่างจากโค้ด เหมือนกด Escape ทุกประการ `exit_game` และ `close_window`
เป็นชื่อพ้องภาษาอังกฤษ

```ling-gui
ผูก เริ่ม = ทำ {
    ถ้า ปุ่ม(20, 20, 100, 32) == 1 { quit() }
}
```

### `get_width()` และ `get_height()`

ขนาดเฟรมบัฟเฟอร์ปัจจุบันเป็นพิกเซล สำหรับหน้าต่างขนาดคงที่จะเท่ากับอาร์กิวเมนต์ของ `open_window`
ส่วนหน้าต่างที่ปรับขนาดได้จะเปลี่ยนตามที่ผู้ใช้ปรับ ถ้าไม่มีหน้าต่างจะคืน 0

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก กลางx = ความกว้าง() / 2
    ผูก กลางy = ความสูง() / 2
}
```

### `set_fps(n)` และ `set_vsync(on)`

`set_fps(n)` จำกัดอัตราเฟรม (ค่าเริ่มต้น 60 ต่ำสุด 1) ให้เรียกหลัง `open_window`
`set_vsync(on)` คุมจังหวะลูปตามอัตรารีเฟรชของจอแทน ซึ่งเป็นการคุมจังหวะเฟรม
ไม่ใช่ vertical sync แบบกันภาพฉีก ถ้ามีการเรียก `set_fps` หรือตั้งตัวแปรสภาพแวดล้อม `LING_FPS_CAP` ไว้ ค่านั้นจะชนะ

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(800, 600, "จำกัดเฟรม")
    ตั้งเฟรมเรต(30)
}
```

### `monitor_width()`, `monitor_height()`, `monitor_refresh()`, `monitor_info()`

ความกว้างและความสูงของจอหลักเป็นพิกเซล และอัตรารีเฟรชเป็นเฮิรตซ์
`monitor_info()` คืนทั้งสามค่าเป็นรายการ `[width, height, hz]` เรียกได้ก่อนเปิดหน้าต่าง
เช่นเพื่อกำหนดขนาดหน้าต่าง

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก จอ = ข้อมูลจอ()
    เปิดหน้าต่าง(จอ[0] / 2, จอ[1] / 2, "ครึ่งจอ")
}
```

### `wait_window()`

หยุดรอโดยค้างเฟรมสุดท้ายไว้บนจอ จนกว่าหน้าต่างจะถูกปิดหรือกด Escape
เหมาะกับโปรแกรมที่วาดภาพนิ่งภาพเดียว

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(400, 300, "ภาพนิ่ง")
    เติม(20, 40, 80)
    แสดงผล()
    wait_window()
}
```

### `screenshot(tag)`

บันทึกเฟรมบัฟเฟอร์ปัจจุบันเป็น PNG และคืนพาธของไฟล์
`screenshots/ss_<unix-time>_<tag>_<width>x<height>.png` ค่าเริ่มต้นของ `tag` คือ `"game"`
อักขระที่ไม่ใช่ตัวอักษรหรือตัวเลขจะกลายเป็นขีดล่าง โฟลเดอร์จะถูกสร้างในที่ที่โปรแกรมรันอยู่
ให้เรียกหลัง `present()` เพื่อเก็บเฟรมที่สมบูรณ์

```ling-gui
ผูก เริ่ม = ทำ {
    แสดงผล()
    println(screenshot("title-screen"))
}
```

### `record_frame()` และ `record_count()`

`record_frame()` เขียนเฟรมบัฟเฟอร์ปัจจุบันลง `recordings/frame_00000.ppm`,
`frame_00001.ppm` ไปเรื่อยๆ เพื่อนำไปประกอบเป็นวิดีโอภายหลัง และคืนลำดับของเฟรมที่เขียน
`record_count()` คืนจำนวนเฟรมที่เขียนไปแล้ว

### `frame_count()` และ `time_now()`

`frame_count()` คือจำนวนเฟรมที่แสดงไปแล้วนับจากโปรแกรมเริ่ม `time_now()` คือจำนวนวินาที
นับจากโปรแกรมเริ่มเป็นเลขทศนิยม ถ้าต้องการเวลาต่อเฟรม ให้จำค่าก่อนหน้าไว้:

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก ครั้งก่อน = เวลาปัจจุบัน()
    ขณะที่ หน้าต่างเปิดอยู่() {
        ผูก ตอนนี้ = เวลาปัจจุบัน()
        ผูก ช่วงเวลา = ตอนนี้ - ครั้งก่อน
        ผูก ครั้งก่อน = ตอนนี้
        เติม(0, 0, 0)
        แสดงผล()
    }
}
```

## กล้อง

ฟังก์ชันในตัว 3 มิติทั้งหมดฉายจุดในโลกผ่านกล้องส่วนกลางตัวเดียว ซึ่งกำหนดด้วยสามอย่าง:

* **จุดหมุน** `(x, y, z)` ตั้งด้วย `set_camera_pos` ซึ่งจะถูกลบออกจากทุกจุด
* **การหันทิศ** ตั้งด้วย `set_camera` เป็นโคไซน์และไซน์ของมุมหันซ้ายขวา (yaw) และมุมก้มเงย (pitch)
* **ระยะชดเชยความลึก** `zdist` ตั้งด้วย `set_zdist` ซึ่งบวกเข้าไปก่อนหารเพอร์สเปกทีฟ

yaw ที่เป็นบวกหมุนกล้องไปทางขวา สิ่งที่อยู่ตรงหน้าจึงเลื่อนไปทางซ้ายของจอ
pitch ที่เป็นบวกก้มกล้องลง สิ่งที่อยู่ข้างหน้าจึงเลื่อนขึ้น สำหรับมุม yaw `a` ทิศ "ไปข้างหน้า"
ในโลกคือ `(sin a, cos a)` บนระนาบ x-z ให้ตั้งกล้องทุกเฟรมก่อนวาดรูปทรง 3 มิติ

| ฟังก์ชันในตัว | 中文 | 日本語 | 한국어 | ไทย | หน้าที่ |
|---|---|---|---|---|---|
| `set_camera(cy, sy, cp, sp)` | `设镜` | `カメラ設定` | `카메라설정` | `ตั้งกล้อง` | หันทิศจาก cos/sin ของ yaw และ pitch |
| `set_camera_pos(x, y, z)` | `镜坐标` | `カメラ座標` | `카메라좌표` | `ตั้งตำแหน่งกล้อง` | ย้ายจุดหมุน |

### `set_camera(cy, sy, cp, sp)`

ตั้งการหันทิศจากค่าที่คำนวณไว้แล้ว: `cy`, `sy` คือโคไซน์และไซน์ของมุม yaw
`cp`, `sp` คือโคไซน์และไซน์ของมุม pitch (ค่าเริ่มต้น `1, 0, 1, 0` คือมองตรงไปตาม +z)
ให้ส่งตัวเลขสี่ตัวนี้ ไม่ใช่ตัวมุม

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก มุมหัน = 0.3
    ผูก มุมก้ม = 0.1
    ตั้งกล้อง(โคไซน์(มุมหัน), ไซน์(มุมหัน), โคไซน์(มุมก้ม), ไซน์(มุมก้ม))
}
```

### `set_camera_pos(x, y, z)` และ `move_camera(dx, dy, dz)`

`set_camera_pos` ย้ายจุดหมุนของกล้องไปยังตำแหน่งในโลก (ค่าเริ่มต้น 0, 0, 0) ส่วน `move_camera` บวก
ระยะเพิ่มเข้าไป อย่าลืมว่า y ชี้ลง ถ้าจะยกกล้องขึ้นให้ลดค่า y เมื่อระบบเสียงทำงานอยู่
ตำแหน่งผู้ฟังเสียงจะตามตำแหน่งกล้อง

```ling-gui
ผูก เริ่ม = ทำ {
    ตั้งตำแหน่งกล้อง(0, -2, -6)      # สูงขึ้นสองหน่วย ถอยหลังหกหน่วย
}
```

### `set_zdist(d)`, `set_projection(cx, cy, focal, zdist)` และ `tm_fov(degrees, width)`

`set_zdist(d)` ตั้งระยะชดเชยความลึก (ค่าเริ่มต้น 5 และรีเซ็ตเมื่อเปิดหน้าต่าง) ค่าที่มากขึ้นดันฉาก
ออกไปไกลและทำให้เพอร์สเปกทีฟแบนลง รูปทรงที่ใกล้กว่า `-zdist` จะถูกตัดทิ้ง

`set_projection` เขียนทับค่าเลนส์ทุกตัว: `cx`, `cy` จุดศูนย์กลางภาพเป็นพิกเซล `focal`
ความยาวโฟกัสเป็นพิกเซล (มากขึ้นคือซูมเข้า) และ `zdist` ต้องใช้เฉพาะกรณีพิเศษ
เช่นการแบ่งจอ

`tm_fov(degrees, width)` ตั้งความยาวโฟกัสให้ภาพกว้างตามมุมแนวนอนที่กำหนด `width` คือ
ความกว้างของวิวพอร์ตเป็นพิกเซล (ค่าเริ่มต้นคือความกว้างหน้าต่าง) `tm_fov(0)` คืนค่าความยาวโฟกัสเริ่มต้น

```ling-gui
ผูก เริ่ม = ทำ {
    ตั้งโปรเจกชัน(ความกว้าง() / 2, ความสูง() / 2, ความสูง() * 1.5, 5)   # ซูมเข้า
}
```

### `set_camera_roll(angle)` และ `set_camera_hyper(R, saddle, px, mid_y, pz)`

`set_camera_roll` หมุนภาพรอบแกนที่มองไปข้างหน้า เป็นเรเดียน (ชื่อพ้อง `camera_roll`)
`set_camera_hyper` เปิดมุมมองไฮเพอร์โบลิกรอบจุดหมุน `(px, mid_y, pz)`: ระยะบนพื้นถูกบีบเป็น
`R * tanh(d / R)` และปริภูมิโค้งเหมือนอานม้าด้วยความแรง `saddle`
`R = 0` คือปิด

### `project_3d(x, y, z)`

ฉายจุดในโลกด้วยกล้องปัจจุบัน แล้วคืน `[screen_x, screen_y, depth]` จุดที่อยู่หลังกล้อง
ให้ผล `[-99999, -99999, depth]` ใช้ตรึงป้ายข้อความ 2 มิติไว้กับวัตถุ 3 มิติ
เมื่อไม่มีหน้าต่าง โปรเจกชันจะสมมติว่าเฟรมมีขนาด 1920 x 1080 ตัวอย่างนี้จึงรันในเทอร์มินัลได้:

```ling
ผูก เริ่ม = ทำ {
    ตั้งกล้อง(1, 0, 1, 0)
    println("ข้างหน้า:  " + str(ฉาย3มิติ(0, 0, 5)))
    println("ทางขวา:   " + str(ฉาย3มิติ(1, 0, 5)))
    ตั้งตำแหน่งกล้อง(2, 0, 0)
    println("ย้ายกล้อง: " + str(ฉาย3มิติ(0, 0, 5)))
    ตั้งตำแหน่งกล้อง(0, 0, 0)
    println("ข้างหลัง:  " + str(ฉาย3มิติ(0, 0, -20)))
}
```

```output
ข้างหน้า:  [960, 540, 5]
ทางขวา:   [1068, 540, 5]
ย้ายกล้อง: [744, 540, 5]
ข้างหลัง:  [-99999, -99999, -20]
```

ระยะหนึ่งหน่วยไปทางขวาที่ความลึก 10 (5 บวก `zdist`) เลื่อนไป 108 พิกเซลเมื่อความยาวโฟกัสเป็น 1080

ชื่อพ้องภาษาญี่ปุ่นและเกาหลี `3D投影` และ `3D투영` ขึ้นต้นด้วยตัวเลข จึงถูกอ่านเป็นเลข 3
และเรียกใช้ไม่ได้ ในโค้ดภาษาญี่ปุ่นและเกาหลีให้ใช้ `project_3d` แทน

### `mouse_ray()`

รังสีในพิกัดโลกจากจุดหมุนของกล้องผ่านพิกเซลใต้เมาส์ เป็นรายการ
`[ox, oy, oz, dx, dy, dz]` คือจุดเริ่มกับทิศทาง เป็นการทำงานย้อนกลับของ `project_3d`
เดินไปตามรังสีเพื่อหาพื้นใต้เคอร์เซอร์สำหรับการคลิกเพื่อเดิน

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก รังสี = mouse_ray()
    ผูก t = (2 - รังสี[1]) / รังสี[4]          # จุดที่รังสีชนพื้นที่ y = 2
    ผูก พื้นx = รังสี[0] + รังสี[3] * t
    ผูก พื้นz = รังสี[2] + รังสี[5] * t
}
```

## กล้องบินอิสระ

มองด้วยเมาส์ เดินด้วย WASD และมีลูกบาศก์หมุนอยู่ การเคลื่อนที่ตาม `(sin yaw, cos yaw)` ทำให้ทิศการเดิน
ตรงกับทิศที่มอง ฟังก์ชันเมาส์และคีย์บอร์ดอยู่ที่ [อินพุตและไมโครโฟน](input.md)
ส่วนแสงอยู่ที่ [โพสต์เอฟเฟกต์และแสง](postfx.md)

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(900, 600, "บิน")
    จับเมาส์()
    ทดสอบความลึก(1)
    ผูก มุมหัน = 0.0
    ผูก มุมก้ม = 0.0
    ผูก ตำแหน่งx = 0.0
    ผูก ตำแหน่งz = -4.0
    ผูก t = 0.0
    ขณะที่ หน้าต่างเปิดอยู่() {
        ผูก มุมหัน = มุมหัน + mouse_dx() * 0.003
        ผูก มุมก้ม = จำกัด(มุมก้ม + mouse_dy() * 0.003, -1.5, 1.5)
        ผูก หน้าx = ไซน์(มุมหัน) * 0.08
        ผูก หน้าz = โคไซน์(มุมหัน) * 0.08
        ถ้า กดค้าง("w") { ผูก ตำแหน่งx = ตำแหน่งx + หน้าx  ผูก ตำแหน่งz = ตำแหน่งz + หน้าz }
        ถ้า กดค้าง("s") { ผูก ตำแหน่งx = ตำแหน่งx - หน้าx  ผูก ตำแหน่งz = ตำแหน่งz - หน้าz }
        ถ้า กดค้าง("d") { ผูก ตำแหน่งx = ตำแหน่งx + หน้าz  ผูก ตำแหน่งz = ตำแหน่งz - หน้าx }
        ถ้า กดค้าง("a") { ผูก ตำแหน่งx = ตำแหน่งx - หน้าz  ผูก ตำแหน่งz = ตำแหน่งz + หน้าx }
        ตั้งกล้อง(โคไซน์(มุมหัน), ไซน์(มุมหัน), โคไซน์(มุมก้ม), ไซน์(มุมก้ม))
        ตั้งตำแหน่งกล้อง(ตำแหน่งx, 0, ตำแหน่งz)
        เติม(8, 10, 24)
        ล้างแสง()
        เพิ่มแสง(-3, -6, 0, 1.0, 0.95, 0.85, 1.0, 0)
        ลายตาราง(0, 2, 8, 1, 0, 0, 0, 0, 1, 20, 20, 1, 1, t, 0)
        สีดินสอ(240, 150, 110)
        ลูกบาศก์(0, 0, 8, 1, 1, 1, t * 0.5, t, 0, 0)
        แสดงผล()
        ผูก t = t + 0.02
    }
}
```
