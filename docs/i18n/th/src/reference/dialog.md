# บทสนทนา

Ling มีเครื่องมือด้านบทสนทนาสองแบบ **กล่องบทสนทนา** แสดงสิ่งที่ตัวละครพูด เป็นกล่องข้อความสไตล์เกมผจญภัย
ที่พิมพ์ทีละตัวอักษร แบ่งหน้าได้ และไฮไลต์ชื่อคน สถานที่ และไอเท็มด้วยสี ส่วน **โมเดลบทสนทนา**
เป็นตัวตัดสินว่าตัวละครจะพูดอะไร เป็นโมเดลภาษาจิ๋วที่ฝึกจากบทพูดของตัวละครนั้นเองได้ในไม่ถึงวินาที
NPC ทุกตัวพกไว้ได้ ข้อมูลฝึกของมันใช้รูปแบบข้อความธรรมดาชื่อ **มาตรฐานบทสนทนาของ Ling** (`.lingdialog`)

ทั้งสองแบบทำงานได้โดยไม่ต้องมีหน้าต่าง ยกเว้น `dialog_draw` คุณจึงทดสอบบทสนทนาทั้งเรื่องแบบไม่มีหน้าจอได้

| `dialog_step(dt)` | `对话步进` | `会話更新` | `대화스텝` | `ก้าวบทสนทนา` | เดินการพิมพ์และตัวจับเวลาเลื่อนหน้าอัตโนมัติ |
| `dialog_advance()` | `对话推进` | `会話送り` | `대화진행` | `เลื่อนบทสนทนา` | ผู้เล่นกดปุ่มยืนยัน |
| `dialog_active()` | `对话激活` | `会話中` | `대화중` | `บทสนทนาทำงาน` | กล่องเปิดอยู่หรือไม่ |

| `dialog_load(m, path)` | `对话载入` | `対話読込` | `대화불러오기` | `โหลดชุดสนทนา` | เพิ่มไฟล์ `.lingdialog` ลงคลังข้อความ |
| `dialog_train(m, epochs, lr)` | `对话训练` | `対話訓練` | `대화훈련` | `ฝึกสนทนา` | ฝึกจากคลังข้อความ คืนค่าความสูญเสีย |
| `dialog_say(m, prompt, max, temp)` | `对话生成` | `対話生成` | `대화생성` | `พูดสนทนา` | สร้างคำตอบ |

## กล่องบทสนทนา

สถานะของกล่องเก็บอยู่ในรันไทม์ แยกจากการวาด `dialog_show` เปิดกล่อง `dialog_step` เดินเวลา
`dialog_advance` ตอบสนองผู้เล่น และ `dialog_draw` วาดออกมา ระหว่างที่ `dialog_active()` เป็นจริง
ให้หยุดโลกในเกมไว้

### มาร์กอัป

| มาร์กอัป | ความหมาย |
|---|---|
| `{n}...{/}` | ชื่อตัวละคร (บทบาทสี 1) |
| `{p}...{/}` | สถานที่ (บทบาท 2) |
| `{i}...{/}` | ไอเท็ม (บทบาท 3) |
| อักขระขึ้นบรรทัดใหม่ | ขึ้นบรรทัดใหม่ในกล่อง |
| `\|\|` | ขึ้นหน้าใหม่ |

แท็กมีสามอักขระพอดี คือ `{` ตัวอักษรอังกฤษหนึ่งตัว และ `}` ส่วน `{/}` กลับไปเป็นข้อความธรรมดา
(บทบาท 0) นอกนั้นแสดงตามที่เขียน

หน้าที่พิมพ์เสร็จแล้วจะเลื่อนไปหน้าถัดไปเองหลัง 1.4 วินาที และหลังหน้าสุดท้ายกล่องจะปิด

### `dialog_show(text, cps)`

เปิดกล่องด้วย `text` พิมพ์ด้วยความเร็ว `cps` ตัวอักษรต่อวินาที (ค่าเริ่มต้น 32 อย่างน้อย 1)
กล่องที่เปิดอยู่แล้วจะถูกแทนที่

### `dialog_step(dt)`

เดินการพิมพ์และตัวจับเวลาเลื่อนหน้าอัตโนมัติไป `dt` วินาที (ค่าเริ่มต้น `0.016`) ให้เรียกทุกเฟรม
ระหว่างที่กล่องเปิดอยู่

### `dialog_advance()`

เรียกเมื่อผู้เล่นกดปุ่มยืนยัน ถ้าหน้านั้นยังพิมพ์อยู่ ส่วนที่เหลือจะปรากฏทันที ไม่อย่างนั้นจะไปหน้าถัดไป
หรือปิดหลังหน้าสุดท้าย ให้เรียกตามจังหวะกดปุ่ม (`key_pressed`) ไม่ใช่ปุ่มที่กดค้าง
การกดหนึ่งครั้งจะได้ไม่ข้ามหลายหน้า

### `dialog_active()` `dialog_typing()` และ `dialog_close()`

`dialog_active()` เป็น `true` ระหว่างที่กล่องเปิดอยู่ `dialog_typing()` เป็น `true` ระหว่างที่หน้าปัจจุบัน
ยังปรากฏไม่ครบ `dialog_close()` ปิดกล่องทันที

```ling
ผูก เริ่ม = ทำ {
  แสดงบทสนทนา("สวัสดี {n}หลิง{/}||หน้าที่สอง", 100)
  พิมพ์("เปิดอยู่: " + str(บทสนทนาทำงาน()))
  พิมพ์("กำลังพิมพ์: " + str(กำลังพิมพ์บทสนทนา()))
  ก้าวบทสนทนา(0.5)
  พิมพ์("กำลังพิมพ์หลัง 0.5 วินาที: " + str(กำลังพิมพ์บทสนทนา()))
  เลื่อนบทสนทนา()
  พิมพ์("หน้า 2 กำลังพิมพ์: " + str(กำลังพิมพ์บทสนทนา()))
  เลื่อนบทสนทนา()
  เลื่อนบทสนทนา()
  พิมพ์("ตอนจบยังเปิดอยู่: " + str(บทสนทนาทำงาน()))
}
```

```output
เปิดอยู่: true
กำลังพิมพ์: true
กำลังพิมพ์หลัง 0.5 วินาที: false
หน้า 2 กำลังพิมพ์: true
ตอนจบยังเปิดอยู่: false
```

ที่ความเร็ว 100 ตัวอักษรต่อวินาที หน้าแรกพิมพ์เสร็จภายใน 0.5 วินาที `เลื่อนบทสนทนา` ครั้งแรกพลิกไปหน้า 2
ครั้งที่สองแสดงหน้า 2 ทั้งหมด และครั้งที่สามปิดกล่อง

### `dialog_color(role, r, g, b)`

ตั้งสีของบทบาท `0` ข้อความธรรมดา `1` ชื่อ `2` สถานที่ `3` ไอเท็ม (ค่าที่มากกว่า 3 นับเป็น 3)
`r` `g` `b` มีค่า 0 ถึง 255 (ค่าเริ่มต้น 255)

### `dialog_draw(x, y, w, h, font)`

วาดกล่องขอบลบมุมโดยมุมซ้ายบนอยู่ที่ `(x, y)` (ค่าเริ่มต้น 40, 0) ขนาด `w` คูณ `h`
(ค่าเริ่มต้น 720 คูณ 150) พร้อมข้อความที่แสดงถึงตอนนี้ `font` คือแฮนเดิลจาก `font_load`
ถ้าละไว้หรือส่ง `-1` จะใช้การวาดตัวอักษรในตัว

```ling-gui
ผูก เริ่ม = ทำ {
  เปิดหน้าต่าง(800, 600)
  ผูก ฟอนต์กล่อง = โหลดฟอนต์("assets/fonts/NotoSansThai.ttf", 600.0)
  ผูก บทพูด = "เฮ้ {n}ลิงก์{/}! เอา{i}ดาบมาสเตอร์{/}ไปที่{p}ทุ่งไฮรูล{/}||ระวังตอนกลางคืนด้วย"
  สีบทสนทนา(1, 255, 210, 80)
  ขณะที่ หน้าต่างเปิดอยู่() {
    ถ้า กดปุ่ม("space") {
      ถ้า บทสนทนาทำงาน() { เลื่อนบทสนทนา() } ไม่งั้น { แสดงบทสนทนา(บทพูด, 34.0) }
    }
    เติม(10, 10, 20)
    ถ้า บทสนทนาทำงาน() {
      ก้าวบทสนทนา(0.016)
      วาดบทสนทนา(50.0, 420.0, 700.0, 150.0, ฟอนต์กล่อง)
    } ไม่งั้น {
      // อัปเดตเกมตามปกติตรงนี้
    }
    แสดงผล()
  }
}
```

## โมเดลบทสนทนา

โมเดลบทสนทนาคือโมเดลภาษาจิ๋วแบบ "ทายคำถัดไป" ขนาดไม่กี่กิโลไบต์ที่มีมาใน Ling (`ling_ai::dialog_lm`)
คุณป้อนบทพูดของตัวละคร ฝึกมัน แล้วให้มันพูดต่อจากข้อความนำ มันเรียนรู้จังหวะการพูดและคำศัพท์ ไม่ใช่ข้อเท็จจริง
จึงเหมาะกับบทพูดลอยๆ เสียงตะโกนสั้นๆ และข้อความเพิ่มบรรยากาศ คลังข้อความเล็กๆ ฝึกเสร็จในเวลาไม่ถึงวินาที
เมื่ออุณหภูมิเป็น `0` ผลลัพธ์จะเหมือนเดิมทุกครั้ง

```ling
ผูก เริ่ม = ทำ {
  ผูก เจ้าของร้าน = สร้างโมเดลสนทนา(3, 32, 64, 1)
  เรียนรู้สนทนา(เจ้าของร้าน, "ยินดี ต้อนรับ นักเดินทาง")
  เรียนรู้สนทนา(เจ้าของร้าน, "ลับ ดาบ ให้ คม ไว้")
  เรียนรู้สนทนา(เจ้าของร้าน, "ยินดี ที่ กลับมา นักเดินทาง")
  ผูก ค่าสูญเสีย = ฝึกสนทนา(เจ้าของร้าน, 60, 0.1)
  พิมพ์(ค่าสูญเสีย < 2.0)
  พิมพ์(พูดสนทนา(เจ้าของร้าน, "ยินดี", 6, 0.0))
}
```

```output
true
ที่ กลับมา นักเดินทาง
```

### `dialog_new(ctx, embed, hidden, seed)`

สร้างโมเดลเปล่าและคืนแฮนเดิล `ctx` (ค่าเริ่มต้น 3) คือจำนวนคำก่อนหน้าที่มันมอง `embed` (ค่าเริ่มต้น 32)
และ `hidden` (ค่าเริ่มต้น 64) คือขนาดของโครงข่าย และ `seed` (ค่าเริ่มต้น 1) ทำให้ผลการฝึกซ้ำได้

### `dialog_learn(m, text)` และ `dialog_load(m, path)`

`dialog_learn` เพิ่มหนึ่งบรรทัดลงคลังข้อความ `dialog_load` เพิ่มไฟล์ `.lingdialog` ทั้งไฟล์
และคืนจำนวนบรรทัดฝึกที่เพิ่ม (บทสนทนาละหนึ่งบรรทัด) หรือ `-1` ถ้าอ่านไฟล์ไม่ได้

### `dialog_train(m, epochs, lr)`

ฝึกจากทุกอย่างในคลังข้อความ `epochs` รอบ (ค่าเริ่มต้น 20) ด้วยอัตราการเรียนรู้ `lr` (ค่าเริ่มต้น 0.1)
คืนค่าความสูญเสียสุดท้าย ยิ่งต่ำยิ่งแปลว่าโมเดลเข้ากับบทพูดได้ดี

### `dialog_say(m, prompt, max, temp)`

พูดต่อจาก `prompt` ได้ไม่เกิน `max` คำ (ค่าเริ่มต้น 24) และคืนเฉพาะคำใหม่ มันหยุดก่อนได้เมื่อถึงจุดจบของการพูดหนึ่งครั้ง
`temp` (ค่าเริ่มต้น 0.8) คืออุณหภูมิ `0` จะเลือกคำที่น่าจะเป็นที่สุดเสมอ ค่าสูงขึ้นจะหลากหลายขึ้น

ตัวตัดคำแยกข้อความที่ช่องว่างและเครื่องหมายวรรคตอน แล้วแปลงเป็นตัวพิมพ์เล็ก ภาษาไทยไม่เว้นวรรคระหว่างคำ
จึงต้องเว้นวรรคระหว่างคำในคลังข้อความและข้อความนำ และคำตอบจะมีช่องว่างคั่นระหว่างคำ
ตัวตัดคำนับเครื่องหมายวรรณยุกต์เป็นเครื่องหมายวรรคตอน คำที่มีวรรณยุกต์อยู่กลางคำ (เช่น ช่องเขา)
จึงอาจมีช่องว่างแทรกในคำตอบ

### `dialog_save(m, path)` และ `dialog_load_model(path)`

`dialog_save` เขียนโมเดลที่ฝึกแล้วลงไฟล์ (ค่าเริ่มต้น `"model.llm"`) และคืน `true` เมื่อสำเร็จ
`dialog_load_model` อ่านกลับมาและคืนแฮนเดิลใหม่ หรือ `-1` เมื่อล้มเหลว ฝึกครั้งเดียวตอนสร้างเกม
แล้วแนบไฟล์โมเดลเล็กๆ นี้ไปตอนเผยแพร่และโหลดมันขึ้นมา

## มาตรฐานบทสนทนาของ Ling

`.lingdialog` เป็นรูปแบบคลังข้อความที่เขียนทีละบรรทัดและมนุษย์เขียนได้ง่าย นักเขียนแก้ด้วยมือ
หรือสร้างจากสเปรดชีตก็ได้ เห็นส่วนต่างได้ชัดในการรีวิว และแปลเป็นภาษาอื่นได้เหมือนไฟล์ข้อความทั่วไป

```text
# Ling Dialog Standard v1
@meta title: เจ้าของโรงเตี๊ยม
@meta speaker: บราม

= ต้อนรับ
บราม: ยินดี ต้อนรับ นักเดินทาง
ฮีโร่: มี ข่าว อะไร จาก ทาง บ้าง
บราม: มี โจร ที่ ภูเขา ทาง เหนือ
      สตู ของ ข้า รักษา ได้ ทุก โรค

= ข่าวลือ
บราม: ลับ ดาบ ให้ คม ไว้
```

| บรรทัด | ความหมาย |
|---|---|
| `# ...` | หมายเหตุจนจบบรรทัด |
| `@meta key: value` | ข้อมูลเมตาของชุดข้อมูล เขียนซ้ำได้ |
| `= label` | เริ่มบทสนทนาใหม่ ป้ายชื่อจะใส่หรือไม่ก็ได้ |
| `speaker: text` | การพูดหนึ่งครั้ง ผู้พูดคือข้อความก่อนเครื่องหมายทวิภาค **ตัวแรก** |
| บรรทัดที่ไม่มี `:` | ต่อจากการพูดครั้งก่อน (เชื่อมด้วยช่องว่าง) |
| บรรทัดว่าง | ไม่สนใจ |

การแยกวิเคราะห์ไม่มีวันล้มเหลว บรรทัดที่ผิดรูปแบบจะถูกข้าม อักขระแปลกปลอมตัวเดียวจึงไม่ทำให้การฝึกพัง
การพูดที่อยู่ก่อน `=` ตัวแรกจะรวมเป็นบทสนทนาโดยนัยหนึ่งบท

บทสนทนาแต่ละบทกลายเป็นบรรทัดฝึกหนึ่งบรรทัด โดยการพูดแต่ละครั้งเชื่อมด้วยโทเค็นสงวน `<eos>`
โมเดลจึงเรียนรู้การพูดต่อ **ข้าม** การพูดแต่ละครั้ง การเขียน `<eos>` เองก็นับเป็นรอยต่อของการพูดเช่นกัน
โทเค็นสงวนได้แก่ `<pad>` `<bos>` `<eos>` และ `<unk>`

```ling
ผูก เริ่ม = ทำ {
  เขียนไฟล์("bram.lingdialog", "# Ling Dialog Standard v1\n@meta speaker: บราม\n\n= ต้อนรับ\nบราม: ยินดี ต้อนรับ นักเดินทาง\nฮีโร่: มี ข่าว อะไร จาก ทาง บ้าง\nบราม: มี โจร ที่ ภูเขา ทาง เหนือ\n\n= ข่าวลือ\nบราม: ลับ ดาบ ให้ คม ไว้\n")
  ผูก เจ้าของร้าน = สร้างโมเดลสนทนา(3, 32, 64, 1)
  พิมพ์(โหลดชุดสนทนา(เจ้าของร้าน, "bram.lingdialog"))
  ฝึกสนทนา(เจ้าของร้าน, 80, 0.1)
  พิมพ์(พูดสนทนา(เจ้าของร้าน, "มี โจร", 8, 0.0))
  พิมพ์(บันทึกโมเดลสนทนา(เจ้าของร้าน, "bram.llm"))
  ผูก อีกครั้ง = โหลดโมเดลสนทนา("bram.llm")
  พิมพ์(พูดสนทนา(อีกครั้ง, "ลับ ดาบ", 8, 0.0))
}
```

```output
2
ที่ ภูเขา ทาง เหนือ
true
ให้ คม ไว้
```

### เขียนคลังข้อความให้ดี

- **ความสม่ำเสมอสำคัญกว่าปริมาณ** คลังข้อความเล็กๆ ที่มีน้ำเสียงชัดเจนสร้างตัวละครที่จดจำได้ดีกว่าคลังใหญ่ที่จืดชืด
- **พูดประโยคเด่นซ้ำ** ประโยคที่อยากให้ตัวละครพูดบ่อยควรปรากฏหลายครั้งในบทสนทนาต่างๆ
- **หนึ่งไฟล์ต่อหนึ่งน้ำเสียง** แยกตัวละครแต่ละตัวไว้คนละไฟล์ แต่ละตัวจะได้โมเดลและบุคลิกของตัวเอง
- **เขียนอย่างเป็นธรรมชาติ** ตัวพิมพ์ใหญ่เล็กและเครื่องหมายวรรคตอนตัวตัดคำจัดการให้

## ใช้ร่วมกัน

โมเดลเขียนบทพูด กล่องแสดงบทพูดนั้น

```ling-gui
ผูก เริ่ม = ทำ {
  เปิดหน้าต่าง(800, 600)
  ผูก บราม = โหลดโมเดลสนทนา("npc/bram.llm")
  ขณะที่ หน้าต่างเปิดอยู่() {
    ถ้า กดปุ่ม("e") && !บทสนทนาทำงาน() {
      แสดงบทสนทนา("{n}บราม{/}: " + พูดสนทนา(บราม, "ยินดี", 12, 0.7))
    }
    ถ้า กดปุ่ม("space") && บทสนทนาทำงาน() { เลื่อนบทสนทนา() }
    เติม(10, 10, 20)
    ก้าวบทสนทนา(0.016)
    ถ้า บทสนทนาทำงาน() { วาดบทสนทนา(50, 420, 700, 150) }
    แสดงผล()
  }
}
```
