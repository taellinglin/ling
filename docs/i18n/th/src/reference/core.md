# เอาต์พุต คณิตศาสตร์ และตรรกะ

ฟังก์ชันในตัวกลุ่มนี้ใช้พิมพ์ออกคอนโซล สร้างข้อความ คำนวณ และหยุดโปรแกรมชั่วคราว
ไม่ต้องใช้หน้าต่าง ตัวอย่างทุกอันในหน้านี้จึงรันในเทอร์มินัลธรรมดาด้วย `ling run` ได้

ตัวเลขทุกตัวใน Ling เป็นทศนิยมลอยตัว 64 บิต ค่าที่เป็นจำนวนเต็มจะพิมพ์โดยไม่มีจุดทศนิยม (`3` ไม่ใช่ `3.0`)
มุมใช้หน่วยเรเดียน ถ้าไม่ใส่อาร์กิวเมนต์ตัวเลขตัวท้าย ส่วนใหญ่จะใช้ค่าเริ่มต้นแทนการแจ้งข้อผิดพลาด

## เอาต์พุต

### `print(value, ...)` และ `println(value, ...)`

`print` กับ `println` คือฟังก์ชันในตัวเดียวกัน อาร์กิวเมนต์แต่ละตัวจะถูกแปลงเป็นข้อความ แล้วนำมาต่อกัน**โดยไม่มีตัวคั่น**
จากนั้นจึงขึ้นบรรทัดใหม่ รายการพิมพ์เป็น `[1, 2, 3]` ผลลัพธ์พิมพ์เป็น `Ok(v)` และ `Err(e)`

```ling
ผูก start = ทำ {
  พิมพ์("สวัสดี Ling!")
  พิมพ์(42, " ", 3.5, " ", จริง)
  พิมพ์([1, 2, 3])
  พิมพ์("ผลรวม", 1 + 2)
  พิมพ์("ผลรวม ", 1 + 2)
}
```
```output
สวัสดี Ling!
42 3.5 true
[1, 2, 3]
ผลรวม3
ผลรวม 3
```

ใส่ช่องว่างไว้ในสตริงเอง หรือใช้ `format` สร้างทั้งบรรทัด

### `print_file(text)`

พิมพ์อาร์กิวเมนต์ตัวแรก**โดยไม่**ขึ้นบรรทัดใหม่ ถึงจะชื่อแบบนี้ แต่ไม่ได้ยุ่งกับไฟล์เลย
เป็นวิธีเดียวที่จะพิมพ์ต่อในบรรทัดเดิม

```ling
ผูก start = ทำ {
  สำหรับ i ใน 1..4 {
    พิมพ์ไฟล์(i)
    พิมพ์ไฟล์(" ")
  }
  พิมพ์("ไปเลย!")
}
```
```output
1 2 3 ไปเลย!
```

### `print_color(color, value, ...)`

พิมพ์หนึ่งบรรทัดด้วยสี ANSI ตัวหนาและสว่าง `color` มีค่า 0 ถึง 7 ได้แก่ ดำ แดง เขียว เหลือง น้ำเงิน ม่วงแดง ฟ้า ขาว
อาร์กิวเมนต์ที่เหลือจะต่อกันแบบเดียวกับ `print` รหัสเอสเคปจะถูกเขียนออกไปตรงๆ ถ้าเปลี่ยนทางเอาต์พุตไปลงไฟล์ จะเห็นเป็นอักขระควบคุม

```ling-gui
ผูก start = ทำ {
  พิมพ์สี(2, "สำเร็จ: ", "ผ่านการทดสอบทั้งหมด")
  พิมพ์สี(1, "ผิดพลาด!")
}
```

### `format(template, value, ...)`

คืนข้อความที่แทน `{}` แต่ละช่องด้วยอาร์กิวเมนต์ตัวถัดไป `{:.N}` จัดรูปตัวเลขให้มีทศนิยม `N` ตำแหน่ง
`{}` ที่ไม่มีอาร์กิวเมนต์คู่จะกลายเป็นว่าง ส่วนอาร์กิวเมนต์ที่เกินมาจะถูกละไว้ รองรับเฉพาะ `{}` และ `{:.N}`
(ไม่มีการกำหนดความกว้าง ไม่มี `{0}` หรือ `{name}` และเอสเคปวงเล็บปีกกาไม่ได้)

```ling
ผูก start = ทำ {
  พิมพ์(รูปแบบ("{} + {} = {}", 2, 3, 2 + 3))
  พิมพ์(รูปแบบ("พายประมาณ {:.3}", พาย()))
  พิมพ์(รูปแบบ("{:.1}%", 45.678))
  พิมพ์(รูปแบบ("{} และ {}", "มีแค่อันเดียว"))
}
```
```output
2 + 3 = 5
พายประมาณ 3.142
45.7%
มีแค่อันเดียว และ 
```

`format::join(list)` ต่อสมาชิกทุกตัวเป็นข้อความโดยไม่มีตัวคั่น ถ้าต้องการใส่อะไรคั่นระหว่างสมาชิก
ให้ใช้ `list_join` (ดู[ข้อความและรายการ](text-lists.md))

## ผลลัพธ์

### `ok(value)` และ `bad(reason)`

Ling ไม่มีเอ็กเซปชัน ฟังก์ชันที่อาจล้มเหลวจะคืน `ok(value)` หรือ `bad(reason)` แล้วผู้เรียกแกะดูด้วย `match`
พิมพ์ออกมาเป็น `Ok(...)` และ `Err(...)` ส่วน `err` เป็นชื่อแทนภาษาอังกฤษของ `bad`
อ่านรายละเอียดทั้งหมดได้ที่[ข้อผิดพลาดและผลลัพธ์](../language/errors.md)

```ling
ฟังก์ชัน ครึ่งหนึ่ง(n) {
  ถ้า n % 2 == 0 { โอเค(n / 2) } มิฉะนั้น { ผิด("เป็นเลขคี่") }
}
ผูก start = ทำ {
  พิมพ์(ครึ่งหนึ่ง(10))
  พิมพ์(ครึ่งหนึ่ง(7))
  พิมพ์(จับคู่ ครึ่งหนึ่ง(7) { ok(v) => v, bad(e) => "ล้มเหลว: " + e })
}
```
```output
Ok(5)
Err(เป็นเลขคี่)
ล้มเหลว: เป็นเลขคี่
```

> ในแพตเทิร์นของ `match` ให้เขียน `ok(...)` และ `bad(...)` เป็นภาษาอังกฤษ ตอนนี้แพตเทิร์น `โอเค(...)` และ `ผิด(...)`
> ยังจับคู่ไม่ได้ ส่วนการสร้างค่าด้วย `โอเค(...)` และ `ผิด(...)` ใช้ได้ตามปกติ

### `try(function, arg, ...)`

เรียก `function` ด้วยอาร์กิวเมนต์ที่เหลือ คืน `ok(result)` ถ้าสำเร็จ หรือ `bad(message)` ถ้าเกิดข้อผิดพลาดขณะรัน

> **ใช้ได้เฉพาะอินเทอร์พรีเตอร์** แบ็กเอนด์ปริยายจะส่งฟังก์ชันและโคลเชอร์ที่เป็นอาร์กิวเมนต์ไปเป็น `()`
> ทำให้ `try` คืน `Err(try: first argument must be a function)` โปรแกรมที่ใช้ `try` ให้รันด้วย `ling run --interp`
> โคลเชอร์ที่ไม่มีพารามิเตอร์ให้เขียนเป็น `| | expr` โดยเว้นวรรคตรงกลาง

```ling-module
ฟังก์ชัน อ่านอย่างปลอดภัย(พาธ) { ลอง(| | อ่านไฟล์(พาธ)) }
```

## คณิตศาสตร์

### การปัดเศษ

`floor` ปัดลง `ceil` ปัดขึ้น `round` ปัดไปหาจำนวนเต็มที่ใกล้ที่สุด (ครึ่งพอดีปัดออกจากศูนย์) `trunc` ตัดส่วนทศนิยมทิ้ง
และ `fract` เก็บไว้เฉพาะส่วนทศนิยม `int` เป็นชื่อแทนภาษาอังกฤษของ `trunc` ไม่ได้แปลงข้อความเป็นตัวเลข (ถ้าจะแปลงให้ใช้ `to_number`)

```ling
ผูก start = ทำ {
  พิมพ์(ปัดลง(2.7), " ", ปัดลง(0 - 2.1))
  พิมพ์(ปัดขึ้น(2.1), " ", ปัดขึ้น(0 - 2.9))
  พิมพ์(ปัดเศษ(2.5), " ", ปัดเศษ(2.4), " ", ปัดเศษ(0 - 2.5))
  พิมพ์(ตัดทศนิยม(2.9), " ", ตัดทศนิยม(0 - 2.9), " ", int(7.99))
  พิมพ์(fract(2.25))
}
```
```output
2 -3
3 -2
3 2 -3
2 -2 7
0.25
```

### `min` `max` `clamp` `sign` `abs`

`min` และ `max` รับตัวเลขสองตัวพอดี ถ้าเป็นรายการให้ใช้ `list_min` และ `list_max` `clamp` มีช่วงปริยายเป็น 0..1
และจะสลับขอบเขตให้เองถ้า `low > high` `sign(0)` ได้ `1` ไม่ใช่ `0`

```ling
ผูก start = ทำ {
  พิมพ์(ต่ำสุด(3, 1), " ", สูงสุด(3, 1))
  พิมพ์(จำกัด(15, 0, 10), " ", จำกัด(0 - 3, 0, 10))
  พิมพ์(เครื่องหมาย(0 - 4), " ", เครื่องหมาย(0), " ", ค่าสัมบูรณ์(0 - 7))
}
```
```output
1 3
10 0
-1 1 7
```

### เลขยกกำลัง ราก และลอการิทึม

`sqrt` ของจำนวนลบได้ `NaN` ส่วน `log` คือลอการิทึม**ธรรมชาติ** (เหมือน `ln`) ถ้าต้องการฐาน 10 ให้ใช้ `log10`

```ling
ผูก start = ทำ {
  พิมพ์(รากที่สอง(16), " ", ยกกำลัง(2, 10), " ", ยกกำลัง(9, 0.5))
  พิมพ์(รากที่สาม(27), " ", hypot(3, 4), " ", exp(1))
  พิมพ์(ลอการิทึม(exp(2)), " ", ลอการิทึม(1), " ", log2(8), " ", log10(1000))
  พิมพ์(รากที่สอง(0 - 1))
}
```
```output
4 1024 3
3 5 2.718281828459045
2 0 3 3
NaN
```

### ตรีโกณมิติและค่าคงที่

มุมใช้หน่วยเรเดียน เรียก `pi()` และ `tau()` พร้อมวงเล็บเสมอ เพราะบนแบ็กเอนด์ปริยาย `pi` เปล่าๆ จะได้ `()`

```ling
ผูก start = ทำ {
  พิมพ์(ไซน์(พาย() / 2), " ", โคไซน์(พาย()))
  พิมพ์(atan2(1, 1) * 4)
  พิมพ์(ทาว())
}
```
```output
1 -1
3.141592653589793
6.283185307179586
```

### การประมาณค่าระหว่างจุดและนอยส์

`lerp(a, b, t)` ไม่จำกัดค่า `t` ส่วน `smoothstep(low, high, x)` คืน 0 เมื่อต่ำกว่า `low` คืน 1 เมื่อสูงกว่า `high`
และเป็นเส้นโค้งนุ่มนวลในช่วงระหว่างนั้น ฟังก์ชันนอยส์ให้ผลแน่นอน อาร์กิวเมนต์เดิมได้ค่าเดิมเสมอ จึงเหมาะกับการสร้างภูมิประเทศและเท็กซ์เจอร์

```ling
ผูก start = ทำ {
  พิมพ์(ค่าระหว่าง(0, 10, 0.25), " ", เปลี่ยนแบบนุ่ม(0, 1, 0.5), " ", เปลี่ยนแบบนุ่ม(0, 1, 2))
  พิมพ์(นอยส์2ดี(1.5, 2.5, 0) == นอยส์2ดี(1.5, 2.5, 0))
  พิมพ์(นอยส์ออร์แกนิก(0.3, 0.7, 4, 1) >= 0)
}
```
```output
2.5 0.5 1
true
true
```

### `rand()`

คืนตัวเลขสุ่มเทียมตั้งแต่ 0 ถึงไม่เกิน 1 ไม่มีการกำหนดซีดและไม่มีแบบจำนวนเต็ม จึงต้องคูณและปัดเอง
ไม่เหมาะกับงานด้านความปลอดภัย ถ้าต้องการค่าที่เดาไม่ได้ให้ใช้ `random_hex` (ดู[ไฟล์ เวลา และระบบ](files.md))

```ling
ผูก start = ทำ {
  ผูก ลูกเต๋า = ปัดลง(สุ่ม() * 6) + 1
  พิมพ์(ลูกเต๋า >= 1 && ลูกเต๋า <= 6)
}
```
```output
true
```

## ตรรกะและการเปรียบเทียบ

ตรรกะและการเปรียบเทียบเป็นตัวดำเนินการ ไม่ใช่ฟังก์ชันในตัว ได้แก่ `==` `!=` `<` `<=` `>` `>=` `&&` `||` และ `!`
ตัวเลข ข้อความ และค่าบูลีนเปรียบเทียบกันด้วยค่า มีสองเรื่องที่ต้องระวัง รายการจะไม่เท่ากันเลยเมื่อใช้ `==` (ให้เทียบทีละสมาชิกแทน)
และการเรียงลำดับข้อความด้วย `<` เชื่อถือไม่ได้

```ling
ผูก start = ทำ {
  พิมพ์(1 < 2 && !(3 == 4))
  พิมพ์("ก" == "ก", " ", 2 != 3)
  พิมพ์([1, 2] == [1, 2])
}
```
```output
true
true true
false
```
