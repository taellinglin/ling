# โพสต์เอฟเฟกต์และแสง

หน้านี้อธิบายว่า Ling ให้แสงกับฉาก 3 มิติอย่างไร และปิดท้ายแต่ละเฟรมอย่างไร แสงและการแรเงากำหนดสีของสามเหลี่ยมแต่ละรูปขณะวาด จากนั้น **ห่วงโซ่โพสต์** แบบพื้นที่หน้าจอจะทำงานบนภาพที่เสร็จแล้ว ได้แก่ การบดบังแสงแวดล้อม เส้นขอบหมึก ทางลาดโทน บลูม และการลบรอยหยัก นอกจากนี้คุณยังเพิ่มระยะชัดลึก การบิดหน้าจอ และลำแสงเชิงปริมาตรแบบนุ่มได้

ทุกอย่างในหน้านี้วาดลงหน้าต่างที่เปิดอยู่ ตัวอย่างจึงเป็นโปรแกรม `ling-gui`

## แสง

แสงใช้ขั้นตอนต่อเฟรมแบบเดียวกับการวาด คือ ล้าง เพิ่ม แล้ววาด

### `set_ambient(level)`

แสงที่ส่องถึงทุกพื้นผิวโดยไม่ขึ้นกับแหล่งแสง ค่า 0 ถึง 1 (ค่าเริ่มต้น 0.15)

### `add_light(x, y, z, r, g, b, intensity, radius)`

เพิ่มแหล่งแสงจุดที่มีสีที่ตำแหน่งในโลก สีใช้ช่วง 0 ถึง 1 หรือ 0 ถึง 255 ก็ได้ ถ้าช่องใดเกิน 1.5 ทั้งสามช่องจะอ่านเป็น 0 ถึง 255 `intensity` คือตัวคูณความสว่าง (ค่าเริ่มต้น 1) `radius` คือระยะที่แสงจางจนหมด ถ้าเป็น 0 แสงจะไม่ลดลงตามระยะ (ค่าเริ่มต้น)

ลำดับคือ ตำแหน่ง **สี** ความเข้ม รัศมี แสงจะสะสมไปเรื่อยๆ จนกว่าคุณจะเรียก `clear_lights()` ดังนั้นให้ล้างและเพิ่มใหม่ทุกเฟรม

### `set_fog(r, g, b, start, end)`

หมอกตามระยะ วัตถุจะจางเข้าหาสี (0 ถึง 255) ระหว่างความลึกกล้อง `start` และ `end` ถ้า `end` เป็น 0 หรือน้อยกว่า หมอกจะปิด แสงเชิงปริมาตรด้านล่างก็จางตามหมอกด้วย

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(720, 420, "แสง")
    ทดสอบความลึก(1)
    ตั้งแสงรอบข้าง(0.2)
    set_fog(8, 10, 24, 10, 40)
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(8, 10, 24)
        ล้างแสง()
        เพิ่มแสง(0, -5, 4, 1.0, 0.85, 0.6, 1.2, 20)
        สีดินสอ(240, 150, 110)
        ลูกบาศก์(0, 0, 8, 1, 1, 1, 0.3, เวลาปัจจุบัน(), 0, 0)
        แสดงผล()
    }
}
```

## การแรเงา

สำหรับแต่ละจุดยอด ตัวแรเงาจะผสมสีดินสอของคุณเข้ากับแสงแวดล้อม (ย้อมด้วยสีเงาในด้านที่หันหนีแสงทั้งหมด) แสงจากแต่ละแหล่ง แสงเรืองขอบที่สว่างขึ้นเมื่อใกล้เงาร่าง และในโหมดเริ่มต้นจะมีประกายรุ้งจางๆ ด้วย ผลลัพธ์ถูกแบ่งเป็นแถบความสว่างไม่กี่ระดับ

ค่าเริ่มต้นตั้งใจให้มีสไตล์ คือ เงาสีครามเย็น ขอบเรืองสีฟ้าอมเขียว และประกายโฮโลแกรม ถ้าต้องการสีที่ตรงกับสีดินสอ ให้ใช้ `set_shade_mode(1)`, `set_rim(0, 0, 0, 0)` และ `set_shadow_color` สีเข้มเป็นกลาง

| ฟังก์ชันในตัว | พารามิเตอร์ |
|---|---|
| `set_shade_mode(m)` | `0` เรียบ สามเหลี่ยมละหนึ่งแถบ, `1` เซลแบบนุ่ม ไม่มีประกาย ขอบเรืองลดลง, `2` โฮโลแกรม (ค่าเริ่มต้น) |
| `set_cel_bands(n)` | จำนวนแถบ อย่างน้อย 2 (ค่าเริ่มต้น 4) |
| `set_shadow_color(r, g, b)` | สีย้อมบริเวณที่ไม่โดนแสง 0 ถึง 255 (ค่าเริ่มต้น 26, 33, 77) |
| `set_rim(strength, r, g, b)` | ความแรงขอบเรือง (ค่าเริ่มต้น 0.6, 0 คือปิด) และสี 0 ถึง 255 (ค่าเริ่มต้น 115, 217, 255) |
| `set_flat_shade(on)` | ค่าที่ไม่ใช่ 0 จะข้ามการคำนวณแสงทั้งหมดและวาดด้วยสีดินสอตรงๆ ใช้สำหรับทดสอบประสิทธิภาพ |

### `set_material(key, value)` และ `reset_material()`

`set_material` เปิดวัสดุตูนแบบอิงฟิสิกส์ให้กับการวาด `draw_triangle_3d` และรูปหลายเหลี่ยมที่ตามมา `key` เป็นสตริงและ `value` เป็นตัวเลข คีย์สีใช้ตัวเลขแบบ `0xRRGGBB` คีย์ได้แก่ `albedo`, `roughness`, `metallic`, `emission`, `emission_strength`, `specular`, `specular_tint`, `subsurface`, `subsurface_color`, `clearcoat`, `clearcoat_roughness`, `transmission`, `ior`, `iridescence`, `sheen`, `anisotropy`, `anisotropy_angle`, `toon_bands`, `shadow_softness`, `outline_px`, `outline_color`, `highlight_color` คีย์ที่ไม่รู้จักจะถูกละเว้น `reset_material()` สลับกลับไปใช้แสงแบบปกติ รูปทรงพื้นฐาน (`cube`, `sphere` ...) ไม่อ่านวัสดุ

## ห่วงโซ่โพสต์

ห่วงโซ่โพสต์ทำงานภายใน `present()` ตามลำดับนี้:

1. **การบดบังแสงแวดล้อม** (`set_ssao`): เงาสัมผัสนุ่มๆ จากบัฟเฟอร์ความลึก
2. **เส้นขอบ** (`toon_outlines`): เส้นหมึกตรงที่ความลึกกระโดด
3. **ทางลาดโทน** (`tone_*`): แปลงความสว่างเป็นแถบเซล
4. **บลูม** (`set_bloom`): แสงฟุ้งที่ซึมออกจากพิกเซลสว่าง
5. **FXAA** (`set_fxaa`): ลบรอยหยักตามขอบบนภาพสุดท้าย

การบดบังแสงแวดล้อม เส้นขอบ บลูม และ FXAA ปิดอยู่จนกว่าคุณจะเปิด ส่วนทางลาดโทนทำงานเสมอ โดยเริ่มจากทางลาดสามแถบเริ่มต้น การบดบังแสงและเส้นขอบอ่านบัฟเฟอร์ความลึก จึงต้องเรียก `set_depth_test(1)` ก่อน

เส้นเวกเตอร์และข้อความไม่ผ่านทางลาดโทน ข้อความของส่วนติดต่อและโครงลวดจึงไม่ถูกตัดเป็นแถบ

### `set_ssao(strength, radius_px, zrange)`

ทำให้มุม รอยพับ และใต้วัตถุมืดลงอย่างนุ่มนวล คำนวณที่ความละเอียดครึ่งหนึ่งแล้วทำให้เรียบ `strength` 0 ถึง 1 (0 คือปิด) `radius_px` คือรัศมีการสุ่มตัวอย่างเป็นพิกเซล (ค่าเริ่มต้น 6) `zrange` คือช่วงความลึกที่จุดข้างเคียงนับเป็นตัวบดบัง (ค่าเริ่มต้น 12)

### `toon_outlines(thickness, color, threshold)`

เส้นหมึกตรงที่ความลึกไม่ต่อเนื่อง `thickness` คือครึ่งความกว้างเป็นพิกเซล (0 คือปิด 1.5 เป็นค่าแบบอนิเมะที่ดี) `color` คือตัวเลข `0xRRGGBB` (ค่าเริ่มต้น 0 สีดำ) `threshold` คือระยะความลึกที่กระโดดแล้วนับเป็นขอบ (ค่าเริ่มต้น 0.05)

### ทางลาดโทน

ทางลาดโทนคือรายการจุดหยุด แต่ละจุดจับคู่ความสว่างขาเข้า `t` กับความสว่างขาออก `value` (ทั้งคู่ 0 ถึง 1) ทางลาดเริ่มต้นมีสามแถบ คือ 0.08 เมื่อต่ำกว่า 0.25, 0.50 เมื่อต่ำกว่า 0.60 และ 1.00 เมื่อสูงกว่านั้น

- `tone_stop(t, value)` เพิ่มจุดหยุด จุดหยุดจะเรียงตาม `t` เสมอ
- `tone_ramp_clear()` ลบจุดหยุดทั้งหมดเพื่อให้คุณสร้างเอง `tone_ramp_reset()` คืนค่าเริ่มต้น
- `tone_smooth(on)`: `0` ตัดแข็งระหว่างจุดหยุด (ค่าเริ่มต้น) `1` ผสมอย่างนุ่มนวล
- `tone_bezier(y1, y2)` แปลงความสว่างขาเข้าผ่านเส้นโค้งเบซิเยร์กำลังสามก่อนค้นหา ประมาณ `0.333, 0.667` คือเป็นกลาง (ค่าเริ่มต้น) `0, 0` เน้นเงา `1, 1` เน้นไฮไลต์ และ `0.1, 0.9` คือเส้นโค้งตัว S `tone_bezier_off()` ลบเส้นโค้งนี้
- `tone_soft(soft, sheen)`: `soft` (0 ถึง 1 ค่าเริ่มต้น 0.32) คือสัดส่วนของช่องว่างระหว่างแถบที่ผสมข้ามขอบ ตั้งแต่คมกริบที่ 0 ถึงขอบเงานุ่มที่ราว 0.3 `sheen` (0 ถึง 1 ค่าเริ่มต้น 0.65) ให้พิกเซลสว่างคงการไล่สีไว้ ไฮไลต์จึงดูเป็นประกายเนียนแทนแถบหยาบๆ

สองลุคที่ใช้บ่อย:

| ลุค | การเรียก |
|---|---|
| เซลอนิเมะคมชัด | `tone_smooth(0)`, `tone_soft(0.32, 0.65)` |
| แบบภาพวาด นุ่มนวล | `tone_smooth(1)`, `tone_bezier(0.12, 0.88)`, `tone_soft(0.32, 0.65)` |

### `set_bloom(strength, threshold)`

พิกเซลสว่างจะมีแสงฟุ้งนุ่มๆ ซึมออกมา คำนวณที่ความละเอียดหนึ่งในสี่ `strength` ค่าเริ่มต้น 0.45 (0 คือปิด) `threshold` คือเกณฑ์ความสว่างจาก 0 ถึง 0.99 (ค่าเริ่มต้น 0.74)

### `set_fxaa(on)`

การลบรอยหยักแบบเบาทั่วทั้งภาพ (อาร์กิวเมนต์ค่าเริ่มต้น 1) ช่วยลดขั้นบันไดของรูปหลายเหลี่ยมและรอยหยักของเส้นขอบ โดยไม่แตะพื้นที่สีเรียบ ต่างจาก `set_antialias` ที่ทำให้เส้นโครงลวดเรียบขณะวาด

### `flush_post()`

ล้างคิว 3 มิติแบบเดียวกับ `flush_3d()` แล้วรันห่วงโซ่โพสต์ทันที เฟรมนั้น `present()` จะข้ามห่วงโซ่ HUD ที่วาดหลัง `flush_post()` จึงคมชัด ไม่มีบลูมหรือความเบลอ เรียกด้วยชื่ออังกฤษอีกชื่อว่า `post_now()` ได้

```ling-gui
ผูก เริ่ม = ทำ {
```

## เอฟเฟกต์หน้าจอ

### `depth_blur(focus, range, radius, oil)`

ระยะชัดลึกบนเฟรมโดยใช้บัฟเฟอร์ความลึก ภาพคมชัดที่ความลึกกล้อง `focus` (ค่าเริ่มต้น 30) และเบลอเต็มที่ `radius` พิกเซล (ค่าเริ่มต้น 3) เมื่อความลึกห่างออกไป `range` (ค่าเริ่มต้น 60) พื้นหลังที่ไม่มีวัตถุจะเบลอเต็มที่ `oil` (0 ถึง 1 ค่าเริ่มต้น 0) เพิ่มขอบสีรุ้งแบบคราบน้ำมันและการหมุนวนของสีให้บริเวณที่เบลอ เหมาะกับน้ำหรือไอร้อน ใช้ชื่ออังกฤษ `dof` และ `depth_of_field` ได้ด้วย

เรียก **หลัง** `flush_3d()` (เพื่อให้บัฟเฟอร์ความลึกมีข้อมูล) และ **ก่อน** วาดส่วนติดต่อ ต้องใช้ `set_depth_test(1)`

### `screen_distort(amount, t, step)`

การบิดหน้าจอทั้งจอแบบหนืดที่ต่อเนื่องที่ขอบ สำหรับเมือก ไอร้อน และความฝัน `amount` คือการเลื่อนสูงสุดเป็นพิกเซล (ค่าเริ่มต้น 8) `t` คือค่าเวลาเพื่อให้การบิดเคลื่อนไหว (ค่าเริ่มต้น 0) และ `step` คือ 1 สำหรับความละเอียดเต็ม หรือ 2 ขึ้นไปสำหรับการบิดเป็นบล็อกที่ประหยัดกว่า (ค่าเริ่มต้น 1) เรียกหลังการ flush 3 มิติและก่อนส่วนติดต่อเช่นเดียวกับ `depth_blur` ไม่มีในบิลด์เบราว์เซอร์

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(960, 540, "ไอร้อน")
    ทดสอบความลึก(1)
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(10, 20, 40)
        สีดินสอ(120, 200, 255)
        ลูกบาศก์(0, 0, 8, 1, 1, 1, 0, เวลาปัจจุบัน(), 0, 0)
        ลูกบาศก์(3, 0, 20, 1, 1, 1, 0, เวลาปัจจุบัน(), 0, 0)
        flush_3d()
        depth_blur(8, 6, 4, 0.3)
        screen_distort(4, เวลาปัจจุบัน(), 2)
        แสดงผล()
    }
}
```

## แสงเชิงปริมาตร

`light_pool` และ `light_beam` วาดการไล่สีแบบบวกที่นุ่มนวล ดูเหมือนแสงที่แผ่ผ่านน้ำหรืออากาศที่มีฝุ่น ขอบนอกจางเป็นสีดำ เมื่อผสมแบบบวกจึงไม่เห็นขอบ ทั้งคู่จางตามหมอกระยะ และต้นทุนอยู่ที่ fill rate ยิ่งใหญ่บนจอยิ่งแพง

### `light_pool(x, y, z, radius, r, g, b, intensity)`

แอ่งแสงสีที่โคมไฟฉายลงบนพื้นที่ความสูง `y` ค่าเริ่มต้นคือ ตำแหน่ง 0, `radius` 20, สี 255 (ช่องละ 0 ถึง 255), `intensity` 1 (ราว 0.2 ถึง 1.5 ดูดี)

### `light_beam(x, y, z, floor_y, radius, r, g, b, intensity)`

ลำแสงแบบ god-ray คือกรวยคู่จากตำแหน่งแสงลงไปถึงระนาบพื้นที่ `floor_y` โดยกว้างออกเป็น `radius` (ค่าเริ่มต้น 14) ใช้คู่กับ `light_pool` ที่ฐาน

วาดทั้งสองด้วย `set_blend(1)` (แบบบวก) แล้วกลับเป็น `set_blend(0)` หลังจากนั้น จะดูดีที่สุดเมื่อใช้ `tone_smooth(1)` เพราะแถบแข็งจะเปลี่ยนการไล่สีนุ่มๆ ให้เป็นขั้นเรียบ

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(720, 420, "แสงเชิงปริมาตร")
    ทดสอบความลึก(1)
    ตั้งแสงรอบข้าง(0.2)
    set_shade_mode(1)
    tone_smooth(1)
    set_bloom(0.5, 0.74)
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(6, 8, 18)
        ตั้งกล้อง(1, 0, โคไซน์(0.25), ไซน์(0.25))
        ตั้งตำแหน่งกล้อง(0, -3, 0)
        ล้างแสง()
        เพิ่มแสง(0, -5, 8, 1.0, 0.9, 0.7, 0.8, 0)
        สีดินสอ(220, 180, 120)
        ทรงกระบอก(0, 1.3, 9, 0.8, 0.7, 0.8, 0, 0, 0, 0)
        โหมดผสม(1)
        light_beam(0, -6, 9, 2, 3.0, 255, 220, 160, 0.8)
        light_pool(0, 2, 9, 5.0, 255, 220, 160, 0.9)
        โหมดผสม(0)
        flush_3d()
        แสดงผล()
    }
}
```

## ชื่อเก่า
