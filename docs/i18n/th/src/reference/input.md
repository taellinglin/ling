# อินพุตและไมโครโฟน

Ling อ่านอินพุตด้วย **การโพล** คือในทุกเฟรมคุณถามภายในลูปว่าผู้เล่นกำลังทำอะไรอยู่ตอนนี้
ไม่มีคอลแบ็ก หน้านี้ครอบคลุมคีย์บอร์ดและเมาส์ การพิมพ์ข้อความ จอยเกม (ผ่านไลบรารี `gilrs`
และ crate `ling-input`) และไมโครโฟน (crate `ling-mic`)

ฟังก์ชันในตัวด้านอินพุตทุกตัวเรียกได้อย่างปลอดภัยแม้ไม่มีอุปกรณ์ ปุ่มจะอ่านว่าไม่ได้กด แกนอ่านเป็น `0`
และไมโครโฟนอ่านเป็นความเงียบ เกมจึงถอยกลับไปใช้คีย์บอร์ดได้โดยไม่ต้องเขียนกรณีพิเศษ
ถ้าอยากรู้ว่ามีฮาร์ดแวร์หรือไม่ ให้ตรวจค่าที่ `mic_open` หรือ `pad_poll` คืนมา

คีย์บอร์ด เมาส์ และการพิมพ์ข้อความต้องมีหน้าต่างเปิดอยู่จึงจะรับเหตุการณ์ได้ ถ้าไม่มีหน้าต่าง
ทุกอย่างจะอ่านเป็นสถานะว่าง

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(กดค้าง("space"))
  พิมพ์(กดปุ่ม("enter"))
  พิมพ์(mouse_down())
  พิมพ์(ล้อเมาส์())
  พิมพ์(เสียงRMS())
  พิมพ์(วิเคราะห์เสียงสด(4))
}
```

```output
false
false
false
0
0
[0, 0, 0, 0]
```

## คีย์บอร์ด

### `key_down(name)` และ `key_pressed(name)`

`key_down` เป็นจริงตลอดที่กดปุ่มค้างไว้ เหมาะกับการเคลื่อนที่ ส่วน `key_pressed` เป็นจริงเฉพาะเฟรมเดียว
ที่ปุ่มถูกกดลง การกดค้างจึงไม่ทำซ้ำ เหมาะกับการสลับสถานะ เมนู และการยิงหนึ่งครั้งต่อการกดหนึ่งครั้ง

ทั้งสองรับชื่อปุ่มตัวพิมพ์เล็ก ชื่อที่ไม่รู้จักจะได้ `false` ทั้งสองอ่านเป็น `false` ระหว่างที่หน้าต่างอื่นได้โฟกัส
การกด Start บนจอยเกมนับเป็น `key_pressed("enter")` ด้วย เมนูที่รอปุ่ม Enter จึงใช้กับจอยได้ทันที

| กลุ่ม | ชื่อ |
|---|---|
| ตัวอักษร ตัวเลข | `"a"` ถึง `"z"` `"0"` ถึง `"9"` |
| ลูกศรและการนำทาง | `"left"` `"right"` `"up"` `"down"` `"home"` `"end"` `"pageup"` `"pagedown"` `"insert"` `"delete"` |
| การแก้ไข | `"space"` `"enter"` `"escape"` `"tab"` `"backspace"` `"capslock"` |
| ปุ่มปรับ | `"lshift"` `"rshift"` `"lctrl"` `"rctrl"` `"lalt"` `"ralt"` |
| ปุ่มฟังก์ชัน | `"f1"` ถึง `"f12"` |
| แป้นตัวเลข | `"numpad0"` ถึง `"numpad9"` (หรือ `"kp0"` ถึง `"kp9"`) `"numpad+"` `"numpad-"` `"numpad*"` `"numpad/"` |
| เครื่องหมาย | `"minus"` `"equals"` `"comma"` `"period"` `"slash"` `"semicolon"` `"quote"` `"lbracket"` `"rbracket"` `"backslash"` `"grave"` (ใช้ตัวสัญลักษณ์เองก็ได้) |

```ling-gui
ผูก เริ่ม = ทำ {
  เปิดหน้าต่าง(800, 600)
  ผูก x = 400
  ผูก หยุดชั่วคราว = 0
  ขณะที่ หน้าต่างเปิดอยู่() {
    ถ้า กดปุ่ม("p") { ผูก หยุดชั่วคราว = 1 - หยุดชั่วคราว }
    ถ้า หยุดชั่วคราว == 0 {
      ถ้า กดค้าง("left") { ผูก x = x - 4 }
      ถ้า กดค้าง("right") { ผูก x = x + 4 }
    }
    เติม(0, 0, 0)
    สีดินสอ(255, 255, 255)
    วาดวงกลมทึบ(x, 300, 20)
    แสดงผล()
  }
}
```

### การพิมพ์ข้อความ

สำหรับการกรอกชื่อและแชต ให้ Ling เก็บอักขระให้คุณ `text_poll()` เพิ่มปุ่มที่พิมพ์ตั้งแต่การเรียกครั้งก่อน
ลงบัฟเฟอร์ข้อความ (Backspace ลบ และกดค้างจะพิมพ์ซ้ำ) แล้วคืนบัฟเฟอร์ทั้งหมด ให้เรียกเฟรมละครั้ง
ระหว่างที่ช่องกรอกทำงานอยู่ `text_get()` อ่านบัฟเฟอร์โดยไม่โพล `text_set(s)` แทนที่ และ `text_clear()` ล้างทิ้ง

```ling
ผูก เริ่ม = ทำ {
  text_set("เอดา")
  พิมพ์(text_get())
  text_clear()
  พิมพ์("[" + text_get() + "]")
}
```

```output
เอดา
[]
```

## เมาส์

- `mouse_x()` `mouse_y()` ตำแหน่งเคอร์เซอร์ภายในหน้าต่างเป็นพิกเซล เป็น `0` ทั้งคู่จนกว่าจะมีหน้าต่าง
- `mouse_down()` `mouse_down_right()` `mouse_down_middle()` เป็นจริงตลอดที่กดปุ่มนั้นค้าง
  ฟังก์ชันเหล่านี้ดูแค่สถานะ ถ้าจะจับการคลิกให้เทียบกับค่าของเฟรมก่อน
- `mouse_scroll()` `mouse_scroll_x()` การหมุนล้อในเฟรมล่าสุด เป็น `0` เมื่อไม่ได้หมุน
- `mouse_dx()` `mouse_dy()` ระยะที่เมาส์เลื่อนตั้งแต่เฟรมก่อน `dx` บวกคือไปทางขวา `dy` บวกคือลงล่าง
  จะไม่เป็นศูนย์เฉพาะตอนที่จับเมาส์อยู่
- `capture_mouse()` ซ่อนเคอร์เซอร์และเปลี่ยนเป็นการเคลื่อนที่แบบสัมพัทธ์ `mouse_dx` และ `mouse_dy`
  จึงรายงานต่อไปไม่ว่าเมาส์จะเลื่อนไกลแค่ไหน นี่คือพื้นฐานของมุมมองบุคคลที่หนึ่ง `release_mouse()` ยกเลิกสิ่งนี้
  ปุ่ม Escape ยังคงปิดหน้าต่างได้
- `cursor_hide()` `cursor_show()` ซ่อนหรือแสดงเฉพาะตัวชี้ ตำแหน่งยังติดตามตามปกติ
  เหมาะกับเกมที่วาดเคอร์เซอร์เอง

```ling-gui
ผูก เริ่ม = ทำ {
  เปิดหน้าต่าง(800, 600)
  ผูก ก่อนหน้า = เท็จ
  ขณะที่ หน้าต่างเปิดอยู่() {
    ผูก ตอนนี้ = mouse_down()
    ถ้า ตอนนี้ && !ก่อนหน้า {
      พิมพ์("คลิกที่ " + str(mouse_x()) + ", " + str(mouse_y()))
    }
    ผูก ก่อนหน้า = ตอนนี้
    เติม(0, 0, 0)
    แสดงผล()
  }
}
```

## จอยเกม

มีสองตระกูล ตระกูลที่ควรใช้คือ **`pad_*`** รองรับผู้เล่นได้สี่คน ปุ่มมีการตรวจจังหวะกด มีไกแบบแอนะล็อก
และใช้โค้ดเดียวกันทั้งบนเดสก์ท็อปและในเบราว์เซอร์ (ซึ่งใช้ W3C Gamepad API) ส่วนตระกูลเก่า
**`gamepad_*`** อ่านจอยที่ใช้ล่าสุดตามชื่อ และเป็นตระกูลที่สั่งให้จอยสั่นได้

### ตระกูล `pad_*`

เรียก `pad_poll()` เฟรมละครั้งก่อนอ่านค่าใดๆ มันดึงเหตุการณ์ของจอย เดินการตรวจจังหวะกด
และคืนจำนวนแพดที่เชื่อมต่อ ช่องผู้เล่นคือ `0` ถึง `3` การเรียกครั้งแรกจะเปิดแบ็กเอนด์ของจอย
ถ้าล้มเหลวจะคืน `0` และการอ่านทุกครั้งหลังจากนั้นจะเป็นค่ากลาง

- `pad_button(player, name)` เป็นจริงตลอดที่กดปุ่มค้าง
- `pad_pressed(player, name)` เป็นจริงเฉพาะเฟรมที่กด ในบิลด์เบราว์เซอร์รู้ได้แค่สถานะปัจจุบัน
  มันจึงทำงานเหมือน `pad_button`
- `pad_lx` `pad_ly` `pad_rx` `pad_ry` แกนสติก `-1` ถึง `1` การดันสติก **ขึ้น** ให้ `y` เป็น **ลบ**
  ตรงกับทิศของจอ ไม่มีการตัดค่าเล็กๆ ให้ จึงควรละค่าเล็กๆ เอง
- `pad_lt` `pad_rt` ไกแบบแอนะล็อก `0` (ปล่อย) ถึง `1` (ดึงสุด)
- `pad_connected(player)` `pad_count()` ช่องไหนมีแพดอยู่
- `pad_rumble(player, low, high)` ตอนนี้ยังไม่ทำอะไรทั้งบนเดสก์ท็อปและในเบราว์เซอร์ ถ้าจะสั่นให้ใช้ `gamepad_rumble`

ชื่อปุ่มไม่สนตัวพิมพ์ใหญ่เล็ก และมีหลายชื่อที่หมายถึงปุ่มเดียวกัน บนเดสก์ท็อปปุ่มหน้าจอยกำหนดตามตำแหน่ง
ปุ่มล่างคือ `a` เสมอไม่ว่าจอยยี่ห้อใด

| ปุ่ม | ชื่อ |
|---|---|
| ปุ่มหน้าด้านล่าง | `a` `south` `cross` |
| ปุ่มหน้าด้านขวา | `b` `east` `circle` |
| ปุ่มหน้าด้านซ้าย | `x` `west` `square` |
| ปุ่มหน้าด้านบน | `y` `north` `triangle` |
| ปุ่มไหล่ | `lb` `l1` `left_shoulder`; `rb` `r1` `right_shoulder` |
| ไก (ดิจิทัล) | `lt` `l2` `left_trigger`; `rt` `r2` `right_trigger` |
| เริ่ม / เลือก | `start` `menu` `options`; `select` `back` `share` `view` |
| ปุ่มโฮม | `guide` `home` |
| กดสติก | `l3` `left_stick`; `r3` `right_stick` |
| ปุ่มทิศทาง | `up`/`dpad_up` `down`/`dpad_down` `left`/`dpad_left` `right`/`dpad_right` |

```ling-gui
ผูก เริ่ม = ทำ {
  เปิดหน้าต่าง(800, 600)
  ผูก x = 400.0
  ผูก y = 300.0
  ขณะที่ หน้าต่างเปิดอยู่() {
    อัปเดตแพด()
    ถ้า แพดเชื่อม(0) {
      ผูก x = x + แพดซ้ายX(0) * 5.0
      ผูก y = y + แพดซ้ายY(0) * 5.0
      ถ้า แพดกด(0, "a") { พิมพ์("กระโดด") }
    }
    เติม(0, 0, 0)
    สีดินสอ(255, 255, 255)
    วาดวงกลมทึบ(x, y, 20)
    แสดงผล()
  }
}
```

### ตระกูล `gamepad_*`

เรียก `gamepad_poll()` เฟรมละครั้ง จอยที่ใช้งานล่าสุดจะกลายเป็นจอยปัจจุบัน ในบิลด์เบราว์เซอร์
`gamepad_poll` และ `gamepad_rumble` จะไม่ทำอะไร ที่นั่นจึงควรใช้ `pad_*`

- `gamepad_button(name)` เป็น `1` ตลอดที่กดค้าง นอกนั้นเป็น `0` ชื่อปุ่มคือ `a` `b` `x` `y` `l1` `r1`
  `l2` `r2` `l3` `r3` `start` `select` `dup` `ddown` `dleft` `dright`
- `gamepad_axis(name)` คือ `lx` `ly` `rx` `ry` (สติก `-1` ถึง `1`) และ `l2` `r2` (ไก) ที่นี่การดันสติกขึ้น
  ให้ `y` เป็น **บวก** ตรงข้ามกับ `pad_ly`
- `gamepad_rumble(low, high, ms)` สั่นมอเตอร์หนัก (`low`) และมอเตอร์เบา (`high`) ที่ความแรง `0` ถึง `1`
  เป็นเวลา `ms` มิลลิวินาที (ค่าเริ่มต้น 200) ถ้าจอยไม่รองรับการสั่นจะไม่มีอะไรเกิดขึ้น
- `gamepad_list()` คืนหนึ่งบรรทัดต่อจอยหนึ่งตัวที่ระบบมองเห็น ได้แก่ชื่อ เชื่อมต่ออยู่หรือไม่ สั่นได้หรือไม่
  และการแมปปุ่มมาจากไหน ใช้วินิจฉัยจอยที่ทำงานแปลกๆ
- `gamepad_any()` เป็น `1` ถ้ามีปุ่มมาตรฐานใดถูกกด

```ling-gui
ผูก เริ่ม = ทำ {
  พิมพ์(จอยรายการ())
  จอยโพล()
  ถ้า จอยปุ่ม("a") == 1 {
    จอยสั่น(0.4, 0.8, 250)
  }
}
```

## ไมโครโฟน

`mic_open()` (`เปิดไมค์`) เริ่มรับเสียงจากอุปกรณ์อินพุตเริ่มต้นที่ 44.1 kHz โมโน แล้วคืน `1`
หรือคืน `0` ถ้าไม่มีอุปกรณ์หรือถูกปฏิเสธสิทธิ์ เรียกครั้งเดียวพอ หลังจากนั้นการอ่านระดับเสียงแทบไม่มีต้นทุน

- `mic_rms()` ความดังของบัฟเฟอร์ล่าสุด (รากที่สองของค่าเฉลี่ยกำลังสอง) `0` ถึง `1`
- `mic_peak()` แซมเปิลที่มีค่าสัมบูรณ์สูงสุดในบัฟเฟอร์ล่าสุด `0` ถึง `1`
- `mic_fft(bands)` รายการขนาดที่ปรับให้เรียบแล้วของ `bands` ย่าน (ค่าเริ่มต้น 8) ซึ่งแบ่งแบบลอการิทึม
  ตั้งแต่ 20 Hz ขึ้นไป เสียงทุ้มมาก่อน เป็นศูนย์ทั้งหมดเมื่อไมโครโฟนปิดอยู่

```ling-gui
ผูก เริ่ม = ทำ {
  เปิดหน้าต่าง(640, 240)
  ถ้า เปิดไมค์() == 0 { พิมพ์("ไม่มีไมโครโฟน") }
  ขณะที่ หน้าต่างเปิดอยู่() {
    ผูก ย่าน = วิเคราะห์เสียงสด(16)
    เติม(0, 0, 0)
    สีดินสอ(80, 200, 255)
    ผูก i = 0
    ขณะที่ i < ความยาว(ย่าน) {
      ผูก สูง = ย่าน[i] * 200.0
      ผูก x = i * 40
      วาดสามเหลี่ยม(x, 230, x + 30, 230, x + 30, 230 - สูง)
      วาดสามเหลี่ยม(x, 230, x + 30, 230 - สูง, x, 230 - สูง)
      ผูก i = i + 1
    }
    แสดงผล()
  }
}
```

ถ้าจะให้คะแนนการร้องตาม ให้ใช้ไมโครโฟนคู่กับฟังก์ชันในตัวด้านดนตรี `music_mic_pitch()`
(`ระดับเสียงไมค์`) ให้ความถี่ที่ร้องในทุกเฟรม ดู[ดนตรี](../reference/music.md)

### การบันทึกค่าเมล็ด

`mic_capture()` ต่อแซมเปิลล่าสุดเข้าบัฟเฟอร์บันทึก (เก็บไว้ 96000 แซมเปิลล่าสุด) แล้วคืนความยาวของบัฟเฟอร์
ให้เรียกทุกเฟรมระหว่างบันทึก `mic_seed()` คืนแฮช SHA3-256 ของเสียงในบัฟเฟอร์เป็นเลขฐานสิบหก 64 ตัว
ใช้เป็นค่าเมล็ดของตัวสุ่มได้ทันที `mic_clear()` ล้างบัฟเฟอร์ เมื่อไมโครโฟนปิดอยู่ บัฟเฟอร์จะว่างตลอด
และค่าเมล็ดคือแฮชของอินพุตว่าง

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(mic_capture())
  พิมพ์(mic_seed())
  พิมพ์(mic_clear())
}
```
