# การวาด 2 มิติและรูปภาพ

ฟังก์ชันในตัวเหล่านี้วาดลงเฟรมบัฟเฟอร์ของหน้าต่างโดยตรงเป็นพิกเซลบนจอ ทั้งเส้น สามเหลี่ยม
วงกลม รูปหลายเหลี่ยม การไล่สี และเงานุ่ม รวมถึงรูปภาพที่โหลดจากไฟล์หรือสร้างทีละพิกเซล
ทั้งหมดต้องมีหน้าต่างเปิดอยู่ และควรอยู่ระหว่าง `fill()` กับ `present()`
(ดู [หน้าต่างและกล้อง](window.md))

## การวาด 2 มิติทำงานอย่างไร

- **พิกัด** เป็นพิกเซล จุดกำเนิดอยู่มุมซ้ายบน +x ชี้ไปทางขวา และ **+y ชี้ลง**
  พิกัดที่อยู่นอกหน้าต่างจะไม่ถูกวาด
- **สีดินสอ** รูปทรงจะวาดด้วยสีดินสอปัจจุบันที่ตั้งด้วย `set_color` สีนี้มีผล
  จนกว่าคุณจะเปลี่ยน รูปทรง 3 มิติก็ใช้สีนี้เป็นสีพื้นฐานด้วย
- **ค่าสี** เป็นตัวเลข 0 ถึง 255 และ **ไม่ถูกจำกัดช่วง**: รันไทม์จะรวมค่าเป็น
  `(r << 16) | (g << 8) | b` ค่าที่เกิน 255 จึงล้นไปช่องสีถัดไป ค่าติดลบ
  กลายเป็น 0
- **เขียนทันที** คำสั่ง 2 มิติเขียนพิกเซลทันที ส่วนรูปทรง 3 มิติที่รอคิวจะวาดทีหลังตอน
  `present()` จึงทับภาพ 2 มิติของคุณ ถ้าจะวาด 2 มิติทับฉาก 3 มิติ ให้เรียก `flush_3d()` ก่อน
- **สีแบบรวมค่า** ฟังก์ชันบางตัวรับตัวเลขเดียวแบบ `0xRRGGBB` แต่ Ling ไม่มีเลขฐานสิบหก
  จึงต้องเขียนเป็น `r * 65536 + g * 256 + b` (เช่น `51 * 65536 + 102 * 256 + 255`)

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 360, "2 มิติ")
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(12, 14, 30)
        สีดินสอ(230, 90, 90)
        วาดสามเหลี่ยม(60, 300, 160, 140, 260, 300)
        สีดินสอ(90, 200, 255)
        draw_circle(380, 150, 60)
        สีดินสอ(120, 255, 160)
        วาดวงกลมทึบ(520, 150, 40)
        สีดินสอ(255, 220, 90)
        draw_arc(380, 280, 50, 0, 3.14159)
        สี่เหลี่ยมไล่สี(20, 320, 600, 24, 255, 80, 0, 0, 80, 255, 0)
        แสดงผล()
    }
}
```

## ดินสอและการผสมสี

### `fill(r, g, b)`

ล้างเฟรมบัฟเฟอร์ทั้งหมดด้วยสีเดียวและรีเซ็ตบัฟเฟอร์ความลึก ให้เรียกเป็นอย่างแรกของทุกเฟรม
ค่าเริ่มต้นของแต่ละช่องสีคือ 0 ดังนั้น `fill()` จะล้างเป็นสีดำ และไม่เปลี่ยนสีดินสอ
`clear` เป็นชื่อพ้องภาษาอังกฤษ

### `set_color(r, g, b)`, `set_color_hsl(h, s, l)` และ `mix_color(...)`

`set_color` ตั้งสีดินสอ (ค่าเริ่มต้นแต่ละช่องคือ 255)

`set_color_hsl` ตั้งสีจากเฉดสีเป็นองศา (0 ถึง 360) ความอิ่มสีและความสว่าง (0 ถึง 100
ค่าเริ่มต้น 70 และ 50) การขยับเฉดสีทีละขั้นเป็นวิธีง่ายที่สุดในการทำสีรุ้ง

`mix_color(r0, g0, b0, r1, g1, b1, t)` ตั้งสีดินสอเป็นสีผสมของสองสี `t` อยู่ระหว่าง 0 ถึง 1
(ค่าเริ่มต้น 0.5) การผสมทำในปริภูมิสี OkLab สีกลางๆ จึงดูสะอาด ไม่หม่น

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(700, 300, "สีรุ้ง")
    เติม(0, 0, 0)
    ผูก ลำดับ = 0
    ขณะที่ ลำดับ < 12 {
        สีHSLวาด(ลำดับ * 30, 80, 55)
        วาดวงกลมทึบ(60 + ลำดับ * 50, 150, 20)
        ผูก ลำดับ = ลำดับ + 1
    }
    แสดงผล()
    wait_window()
}
```

### `set_alpha(a)`

ความทึบของดินสอจาก 0 (มองไม่เห็น) ถึง 1 (ทึบ) ค่าเริ่มต้น 1 มีผลกับการไล่สี
และรูปทรง 3 มิติที่รอคิว

### `set_blend(mode)`

วิธีที่พิกเซลใหม่รวมกับสิ่งที่มีอยู่แล้ว: `0` ปกติ (ค่าเริ่มต้น) `1` แบบบวก เมื่อผสมแบบบวก
รูปทรงที่ซ้อนกันจะสว่างขึ้น ซึ่งเป็นพื้นฐานของเอฟเฟกต์เรืองแสงทุกแบบ
รูปทรง 3 มิติที่รอคิวยังรับ `2` คูณ `3` สกรีน `4` ลบ และ `5` โอเวอร์เลย์ ด้วย ใช้เสร็จแล้ว
ให้ตั้งกลับเป็น 0

```ling-gui
ผูก เริ่ม = ทำ {
    โหมดผสม(1)
    สีดินสอ(60, 40, 20)
    วาดวงกลมทึบ(500, 280, 40)
    วาดวงกลมทึบ(530, 280, 40)       # ส่วนที่ซ้อนกันสว่างกว่า
    โหมดผสม(0)
}
```

### `set_antialias(on)` และ `get_antialias()`

ทำให้เส้นเรียบ ทั้งเส้นตรง ส่วนโค้ง เส้นรอบวงกลม และขอบของรูปทรง 3 มิติ ค่าเริ่มต้นปิดอยู่ ซึ่งให้
เส้นพิกเซลคมชัด `set_antialias()` แบบไม่ใส่อาร์กิวเมนต์คือเปิด `get_antialias()` อ่านค่าที่ตั้งไว้
การทำให้ตัวอักษรเรียบแยกเป็นอีกเรื่อง (ดู [ฟอนต์และ UI](fonts-ui.md))

## รูปทรง

### `draw_pixel(x, y)` และ `draw_line(x0, y0, x1, y1)`

`draw_pixel` ตั้งค่าหนึ่งพิกเซล `draw_line` วาดเส้นหนาหนึ่งพิกเซลระหว่างสองจุด โดยเคารพ
`set_antialias` และการผสมแบบบวก

### `triangle(x0, y0, x1, y1, x2, y2)`

สามเหลี่ยมทึบ ถ้าต้องการสี่เหลี่ยมให้ใช้สามเหลี่ยมสองรูป หรือใช้ `draw_poly` `draw_triangle` เป็น
ชื่อพ้องภาษาอังกฤษ

```ling-gui
ผูก เริ่ม = ทำ {
    สีดินสอ(230, 90, 90)
    วาดสามเหลี่ยม(100, 100, 300, 100, 300, 200)
    วาดสามเหลี่ยม(100, 100, 300, 200, 100, 200)      # รวมกันเป็นสี่เหลี่ยม
}
```

### `draw_circle(cx, cy, r)` และ `draw_disc(cx, cy, r)`

เส้นรอบวงกลมและวงกลมทึบ กำหนดจุดศูนย์กลางและรัศมีเป็นพิกเซล (รัศมีค่าเริ่มต้น 10)
`draw_disc` เคารพโหมดผสม เมื่อใช้ `set_blend(1)` จึงวาดเป็นแสงเรือง

### `draw_arc(cx, cy, r, a0, a1, segments)`

วาดส่วนหนึ่งของวงกลมจากมุม `a0` ถึง `a1` เป็นเรเดียน (ค่าเริ่มต้น 0 ถึง 2π คือเต็มวง)
`segments` ไม่บังคับ เพราะ +y ชี้ลง มุมจึงเพิ่ม **ตามเข็มนาฬิกา** บนจอ: 0 อยู่ทางขวา
`pi() / 2` ชี้ตรงลง

### `draw_poly(points)`

รูปหลายเหลี่ยมทึบที่ปิดตัวเอง `points` เป็นรายการแบน `[x0, y0, x1, y1, ...]` ใช้ร่วมกับ
`project_3d` เพื่อเติมรูปทรงระหว่างจุด 3 มิติที่ฉายแล้ว

```ling-gui
ผูก เริ่ม = ทำ {
    สีดินสอ(200, 140, 255)
    เติมรูปหลายเหลี่ยม([100, 100, 200, 120, 180, 200, 90, 180])
}
```

### `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` และ `grad_triangle(...)`

`grad_rect` เติมสี่เหลี่ยมด้วยการไล่สีจากสีแรกไปสีที่สอง `dir` เป็น `0` สำหรับ
ซ้ายไปขวา และค่าอื่นสำหรับบนลงล่าง (ค่าเริ่มต้น 1)

`grad_triangle(x0, y0, r0, g0, b0, x1, y1, r1, g1, b1, x2, y2, r2, g2, b2)` ให้แต่ละมุมมีสี
ของตัวเองและผสมกลมกลืนระหว่างกัน เป็นพื้นผิว "มีแสง" แบบประหยัด

ทั้งสองเคารพ `set_alpha` การไล่สีผสมตามการรับรู้เป็นค่าเริ่มต้น `set_gradient_space(0)` เปลี่ยน
เป็น sRGB ธรรมดา

### `shadow_blob`, `cast_shadow` และ `shadow_params`

`shadow_blob(cx, cy, rx, ry, alpha)` วาดวงรีขอบนุ่มด้วยสีดินสอ (รัศมีค่าเริ่มต้น 16 และ 8
`alpha` ค่าเริ่มต้น 0.5) ดินสอสีเข้มให้เงาธรรมดา ส่วนสีอื่นให้เงาที่มีสี

`cast_shadow(cx, cy, height)` วาดเงาสัมผัสที่ขนาดและความนุ่มเปลี่ยนตามความสูงของวัตถุ
เหนือพื้น วัตถุที่อยู่ต่ำได้เงาเล็ก เข้ม คม วัตถุที่อยู่สูงได้เงาใหญ่และจาง
`shadow_params(base, grow, alpha, fade, soft)` ใช้ปรับค่า อาร์กิวเมนต์ที่ไม่ใส่จะคงค่าเดิม

```ling-gui
ผูก เริ่ม = ทำ {
    สีดินสอ(0, 0, 20)
    ทอดเงา(320, 330, 24)
}
```

### `depth_triangle(x0, y0, x1, y1, x2, y2, z)` และ `depth_line(x0, y0, x1, y1, z)`

ใส่สามเหลี่ยมหรือเส้น 2 มิติเข้าคิวเพื่อเรียงความลึกร่วมกับรูปทรง 3 มิติและวาดตอน
`present()` ค่า `z` ที่มากกว่าคืออยู่ไกลกว่า ใช้กับสไปรต์ 2 มิติที่ต้องผ่านด้านหน้าและ
ด้านหลังวัตถุ 3 มิติ

### `set_frame_blur(amount)`

ภาพติดตาเป็นหาง: แต่ละเฟรมจะผสมกับสำเนาจางๆ ของเฟรมก่อน `amount` อยู่ระหว่าง 0 ถึง
0.95 ประมาณ 0.9 ให้หางที่อยู่ราวหนึ่งวินาทีที่ 60 เฟรมต่อวินาที `0` คือปิด

## รูปภาพ

รูปภาพเก็บอยู่ในตารางภายในรันไทม์ การโหลดหรือสร้างแต่ละครั้งจะคืน **แฮนเดิล** ซึ่งเป็นตัวเลขเล็กๆ
ที่ส่งต่อให้ฟังก์ชัน `image_*` อื่นๆ `-1` หมายถึงล้มเหลว

| ฟังก์ชันในตัว | หน้าที่ |
|---|---|
| `image_load(path)` | โหลด PNG, JPEG หรือภาพแรสเตอร์อื่น คืนแฮนเดิลหรือ `-1` |
| `image_draw(id, x, y, w, h)` | วาดภาพโดยย่อขยายเป็น `w` x `h` พิกเซล |
| `image_new(w, h)` | ภาพใหม่แบบโปร่งใส |
| `image_set_pixel(id, x, y, r, g, b, a)` | ระบายสีหนึ่งพิกเซล |
| `image_pixel_r(id, x, y)`, `_g`, `_b`, `_a` | อ่านช่องสีเดียว (0 ถึง 255) |
| `image_width(id)`, `image_height(id)` | ขนาดเป็นพิกเซล |
| `image_save(id, path)` | เขียนไฟล์ PNG คืน `1` หรือ `-1` |
| `image_replace(id, path)` | โหลดไฟล์ใหม่เข้าแฮนเดิลเดิม |
| `image_tint(id, color)` | สำเนาสีเดียวตามรูปร่างของค่าอัลฟา |
| `image_resized(id, w, h)` | สำเนาที่ปรับขนาดแล้ว |
| `image_svg(svg_text, w, h)` | เรนเดอร์ซอร์ส SVG เป็นภาพ |
| `image_free(id)` | ปล่อยพิกเซลคืน |

### `image_load(path)`

โหลดภาพแรสเตอร์แล้วคืนแฮนเดิล หรือ `-1` (พร้อมข้อความในสตรีมข้อผิดพลาด) ถ้าอ่าน
ไฟล์ไม่ได้ พาธจะถูกลองตามที่ให้มาก่อน แล้วจึงลองเทียบกับโฟลเดอร์ของสคริปต์ การโหลด
พาธเดิมซ้ำจะได้แฮนเดิลที่แคชไว้ จึงเรียกในลูปเฟรมได้อย่างปลอดภัย

### `image_draw(id, x, y, w, h, cx, cy, cw, ch, opacity)`

วาดภาพโดยให้มุมซ้ายบนอยู่ที่ `x, y` ย่อขยาย (แบบเพื่อนบ้านใกล้สุด) เป็น `w` x `h` พิกเซล
และผสมอัลฟาทับเฟรม **ต้องใส่ `w` และ `h`**: ถ้าเป็น 0 จะไม่วาดอะไรเลย
ถ้าต้องการขนาดจริงให้ส่ง `image_width(id)` และ `image_height(id)` อาร์กิวเมนต์ที่ไม่บังคับคือ
สี่เหลี่ยมตัดขอบ `cx, cy, cw, ch` ซึ่งนอกนั้นจะไม่วาด และ `opacity` จาก 0 ถึง 1 ต่อท้าย ภาพจะ
แสดงตามจริง ไม่ผ่านการแรเงาแบบทูนที่โพสต์โพรเซสซิงใช้กับ 3 มิติ

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 400, "สไปรต์")
    ผูก ฮีโร่ = image_load("hero.png")
    ผูก x = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(20, 24, 40)
        ถ้า ฮีโร่ >= 0 {
            image_draw(ฮีโร่, x, 160, image_width(ฮีโร่) * 2, image_height(ฮีโร่) * 2)
        }
        แสดงผล()
        ผูก x = (x + 2) % 640
    }
}
```

### `image_new`, `image_set_pixel` และตัวอ่านพิกเซล

`image_new(w, h)` สร้างภาพเปล่าที่โปร่งใสทั้งหมด `image_set_pixel(id, x, y, r, g, b, a)`
ระบายสีหนึ่งพิกเซล (`a` ค่าเริ่มต้น 255) `image_pixel_r`, `image_pixel_g`, `image_pixel_b` และ
`image_pixel_a` อ่านช่องสีเดียวของพิกเซล ตำแหน่งที่อยู่นอกขอบและแฮนเดิลที่ผิดจะถูกข้าม
เมื่อเขียน และอ่านได้ 0 ฟังก์ชันเหล่านี้ทำงานได้โดยไม่ต้องมีหน้าต่าง:

```ling
ผูก เริ่ม = ทำ {
    ผูก ภาพ = image_new(8, 4)
    image_set_pixel(ภาพ, 2, 1, 255, 128, 0)
    println("ขนาด:   " + str(image_width(ภาพ)) + " x " + str(image_height(ภาพ)))
    println("พิกเซล: " + str(image_pixel_r(ภาพ, 2, 1)) + ", " + str(image_pixel_g(ภาพ, 2, 1)))
    println("ว่าง:    " + str(image_pixel_a(ภาพ, 0, 0)))
    ผูก สีฟ้า = image_tint(ภาพ, 51 * 65536 + 102 * 256 + 255)
    println("ย้อมสี:  " + str(image_pixel_b(สีฟ้า, 2, 1)))
}
```

```output
ขนาด:   8 x 4
พิกเซล: 255, 128
ว่าง:    0
ย้อมสี:  255
```

`image_pixel_u16(id, x, y)` คืน `r * 256 + g` ในการเรียกครั้งเดียว สำหรับแผนที่ความสูง 16 บิต

### `image_save(id, path)` และ `image_replace(id, path)`

`image_save` เขียนภาพ (ที่โหลดหรือสร้างขึ้น) ลงไฟล์โดยเก็บค่าอัลฟาไว้ และสร้างโฟลเดอร์ที่ยัง
ไม่มี พาธเทียบกับที่ที่โปรแกรมรันอยู่ คืน `1` หรือ `-1` ถ้าล้มเหลว
`image_replace` ถอดรหัสไฟล์ใหม่เข้าแฮนเดิลเดิม ภาพที่โหลดซ้ำบ่อยจึงไม่ทำให้ตารางภาพ
โตขึ้นเรื่อยๆ คืน `1` หรือ `-1`

ถ้าจะบันทึกตัวหน้าต่างเอง ให้ใช้ `screenshot` (ดู [หน้าต่างและกล้อง](window.md))

### `image_tint`, `image_resized`, `image_svg` และ `image_free`

`image_tint(id, color)` คืนภาพใหม่ที่เป็นสีรวมค่าสีเดียว ตามรูปร่างของอัลฟาในภาพต้นฉบับ
เช่นไอคอนที่วาดใหม่เป็นสีใดก็ได้ `image_resized(id, w, h)` คืนสำเนาที่ปรับขนาดแล้ว
`image_svg(svg_text, w, h)` เรนเดอร์ **ข้อความซอร์ส** SVG (ไม่ใช่พาธ) เป็นภาพใหม่ ถ้ามีเป็นไฟล์
ให้อ่านด้วย `read_file` ก่อน ทั้งสามคืนแฮนเดิลใหม่หรือ `-1`

`image_free(id)` ปล่อยพิกเซลของภาพคืน แฮนเดิลยังใช้ได้แต่จะวาดไม่ออกอะไร

## ข้อความ

สำหรับข้อความ ให้ใช้ฟอนต์เวกเตอร์หรือฟอนต์เส้นในตัว ทั้งสองอยู่ใน [ฟอนต์และ UI](fonts-ui.md)
วิธีที่เร็วที่สุดในการแสดงป้ายข้อความบนจอไม่ต้องใช้ไฟล์ฟอนต์:

```ling-gui
ผูก เริ่ม = ทำ {
    สีดินสอ(120, 255, 160)
    ข้อความหน้าจอ(30, 30, 16, "SCORE 0420")
}
```

`ui_text` วาดตัวอักษรเป็นตัวพิมพ์ใหญ่และรู้จักเฉพาะอักขระ ASCII พื้นฐาน อักขระอื่น (รวมถึงภาษาไทย)
จะแสดงเป็นกล่องเล็กๆ ป้ายในตัวอย่างนี้จึงเป็นภาษาอังกฤษ สำหรับอักษรอื่นให้โหลดฟอนต์ด้วย
`font_load` แล้ววาดด้วย `font_text_fill`
