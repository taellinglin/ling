# เสียง

เอนจินเสียงเล่นทุกอย่างที่เกมต้องการ ได้แก่ โทนต่อเนื่องที่วางในพื้นที่ 3 มิติ เสียงบี๊บสั้นๆ และเสียงเอฟเฟกต์ ไฟล์ตัวอย่างเสียง เพลงพื้นหลังที่เล่นวน และห่วงโซ่เอฟเฟกต์หลัก ตัววิเคราะห์ FFT ที่แยกต่างหากจะแปลงข้อมูลตัวอย่างเสียงเป็นแถบความถี่ สำหรับภาพที่ตอบสนองต่อเสียง

สำหรับเพลงทั้งเพลง แพตช์เครื่องดนตรี MIDI และ DAW ดูที่ [ดนตรี](music.md) สำหรับไมโครโฟน ดูที่ [อินพุตและไมโครโฟน](input.md)

สิ่งที่ควรรู้ก่อน:

- รันไทม์จะเปิดอุปกรณ์เสียงเมื่อโปรแกรมเริ่ม ถ้าไม่มีอุปกรณ์เอาต์พุต ฟังก์ชันในตัว `audio_*` จะไม่ทำอะไรโดยเงียบๆ
- เวลามีหน่วยเป็นวินาที อาร์กิวเมนต์ในซิกเนเจอร์ตั้งแต่ตัวที่ระบุค่าเริ่มต้นเป็นต้นไปละได้
- เสียงใช้ได้เฉพาะแบบเนทีฟ ในบิลด์เบราว์เซอร์ฟังก์ชัน FFT ไม่ทำอะไร และบางคำสั่งรับอาร์กิวเมนต์น้อยกว่า (ระบุไว้ด้านล่าง)
- ตัวอย่างเหล่านี้ส่งเสียง จึงเป็นโปรแกรม `ling-gui` ส่วนตัวอย่าง FFT ท้ายหน้ารันได้ทุกที่

## เอนจินผสมเสียงอย่างไร

สตรีมเอาต์พุตเดียวรับเสียงสี่ประเภท:

- **โทน**: ออสซิลเลเตอร์อายุยาวในช่องที่มีหมายเลข วางไว้ในพื้นที่ (`audio_tone`)
- **เสียงครั้งเดียว**: เสียงบี๊บ (`audio_blip`, `ui_sound`) เอฟเฟกต์ที่มีตำแหน่ง (`audio_sfx`) และโน้ตมอร์ฟ (`morph_note`)
- **ตัวอย่างเสียง**: ไฟล์ที่ถอดรหัสแล้ว เล่นแบบ 3 มิติหรือแบบเรียบ (`audio_sample_*`)
- **เพลงพื้นหลัง**: WAV หนึ่งไฟล์ที่เล่นวน (`audio_bgm`)

ผู้ฟังคือกล้อง การแพนเป็นแบบซ้าย/ขวากำลังเท่ากันตามตำแหน่งเสียงเทียบกับกล้อง และระดับเสียงลดลงตามระยะ `set_camera_pos` ย้ายผู้ฟัง ส่วน `audio_listener` หมุนผู้ฟัง เสียงผสมสุดท้ายผ่านการตัดยอดแบบนุ่ม เสียงดังมากจึงเพี้ยนเบาๆ แทนการตัดแข็ง

ช่องโทนเพิ่มได้ตามต้องการ มีเสียงบี๊บ 32 เสียง เอฟเฟกต์ 64 เสียง โน้ตมอร์ฟ 32 เสียง และตัวอย่างเสียง 64 เสียง เมื่อกลุ่มใดเต็ม เสียงที่เก่าที่สุดจะถูกตัดทิ้ง

## ระดับเสียงและเพลงพื้นหลัง

### `audio_volume(level)`

อัตราขยายหลักของทุกเสียงที่เอนจินนี้ผสม (ค่าเริ่มต้น 0.7 โดย 1.0 คือเท่าเดิม) ไม่มีผลกับเอนจินดนตรี ซึ่งมี `music_volume` ของตัวเอง

### `audio_bgm(path, volume)` และ `audio_bgm_volume(level)`

`audio_bgm` โหลดไฟล์ **WAV** แล้วเล่นวนเป็นเพลงพื้นหลัง (ระดับเสียงเริ่มต้น 0.5) การเรียกครั้งที่สองจะแทนที่เพลงเดิม ถ้าอ่านไฟล์ไม่ได้ ข้อผิดพลาดจะไปที่ standard error และโปรแกรมทำงานต่อแบบเงียบ เส้นทางใช้ตามที่ให้มาเป๊ะๆ สำหรับ MP3, OGG, FLAC หรือ AAC ให้ใช้ `audio_sample_load` หรือ `music_load`

`audio_bgm_volume` เปลี่ยนระดับเสียงโดยไม่ต้องโหลดใหม่

```ling-gui
ผูก เริ่ม = ทำ {
    ระดับเสียง(0.6)
    เพลงประกอบ("theme.wav", 0.4)
    ระดับเพลงประกอบ(0.15)
}
```

## โทน

### `audio_tone(slot, x, y, z, w, freq, amp, lfo_rate, lfo_depth, wave, duty)`

สร้างหรือปรับจูนออสซิลเลเตอร์ต่อเนื่อง การใช้ช่องเดิมซ้ำจะอัปเดตโทนนั้นในที่เดิม ความถี่และแอมพลิจูดจะค่อยๆ เลื่อนไปค่าใหม่ คุณจึงเรียกได้ทุกเฟรม

| พารามิเตอร์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `slot` | 0 | หมายเลขช่องโทน |
| `x, y, z` | 0 | ตำแหน่งของแหล่งเสียงในโลก |
| `w` | 1 | ค่ามิติที่สี่ ขับออสซิลเลเตอร์ย่อยช้าๆ ที่มอดูเลตไขว้กับโทน 0 คือปิด |
| `freq` | 220 | ความถี่เป็น Hz |
| `amp` | 0.15 | แอมพลิจูด ใส่ 0 เพื่อให้ช่องเงียบ (ไม่มีคำสั่งลบ) |
| `lfo_rate` | 0.5 | ความเร็วไวบราโตเป็น Hz |
| `lfo_depth` | 0.02 | ความลึกไวบราโตเป็นสัดส่วนของ `freq` |
| `wave` | `"sine"` | `"sine"`, `"square"`, `"saw"`, `"triangle"` หรือ `"noise"` (นอยส์เป็นขั้นที่ระดับเสียง `freq`) |
| `duty` | 0.5 | ความกว้างพัลส์ของคลื่นสี่เหลี่ยม เช่น 0.125, 0.25, 0.5, 0.75 สำหรับเสียงชิปทูน |

### `audio_glide(amp_ms, freq_ms)`

ตั้งเวลาที่แอมพลิจูดและความถี่ของโทนใช้เลื่อนไปค่าใหม่ เป็นมิลลิวินาที (0 หรือน้อยกว่าคือใช้ค่าเริ่มต้น) เครื่องเล่นชิปทูนที่อัปเดตโทนเฟรมละครั้งจะฟังเนียนขึ้นที่ราว 10 ms

### `audio_listener(cos_yaw, sin_yaw, cos_pitch, sin_pitch)`

หมุนผู้ฟัง ส่งตัวเลขสี่ตัวเดียวกับที่ให้ `set_camera` (ค่าเริ่มต้น 1, 0, 1, 0) เรียกทุกเฟรมเมื่อกล้องหมุน

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 360, "โทน")
    เสียงโทน(0, 0, 0, 6, 0, 261.63, 0.10, 0.5, 0.01)
    เสียงโทน(1, 0, 0, 6, 0, 440.0, 0.06, 0, 0, "square", 0.25)
    ผูก ทิศทาง = 0.0
    ขณะที่ หน้าต่างเปิดอยู่() {
        ผูก ทิศทาง = ทิศทาง + 0.01
        ตั้งกล้อง(โคไซน์(ทิศทาง), ไซน์(ทิศทาง), 1, 0)
        ผู้ฟัง(โคไซน์(ทิศทาง), ไซน์(ทิศทาง), 1, 0)
        เติม(10, 12, 28)
        แสดงผล()
    }
}
```

## เสียงครั้งเดียว

### `audio_blip(freq, duration, wave, amp)`

เสียงบี๊บสั้นไม่มีตำแหน่ง เข้าเร็วและจางเร็ว ค่าเริ่มต้นคือ `freq` 660 Hz, `duration` 0.08 วินาที (ต่ำสุด 0.01), `wave` `"sine"`, `amp` 0.25 ชื่อคลื่น: `"sine"`, `"square"` (`"sq"`), `"saw"` (`"sawtooth"`), `"tri"` (`"triangle"`), `"noise"` ชื่อที่ไม่รู้จักจะเล่นเป็นไซน์

### `ui_sound(name)`

เสียงส่วนติดต่อในตัวหนึ่งเสียง: `"click"` (ค่าเริ่มต้น), `"hover"`, `"confirm"`, `"error"`, `"toggle"`, `"tick"` ชื่ออื่นจะเล่นเป็น `"click"`

### `audio_sfx(x, y, z, w, freq, amp, duration, wave)`

เสียงสังเคราะห์ครั้งเดียวที่ตำแหน่งในโลก แพนและลดระดับแบบเดียวกับโทน ค่าเริ่มต้นคือ ตำแหน่ง 0, `w` 1, `freq` 440, `amp` 0.3, `duration` 0.15, `wave` `"sine"`

### `morph_note(x, y, z, w, freq, amp, duration, material, morph)`

โน้ต "หยินหยาง" ที่ผสมแบบจำลองกายภาพกับแบบดิจิทัล `material` คือ 0 สายสี 1 สายดีด 2 เครื่องเป่า 3 โลหะตี `morph` ไล่จาก 0 (สว่าง อะคูสติก) ถึง 1 (มืด ดิจิทัล: FM บิตครัช ไดรฟ์) ค่าเริ่มต้นคือ `freq` 220, `amp` 0.3, `duration` 0.6

### `audio_stop_sfx()`

หยุดเอฟเฟกต์ครั้งเดียว โน้ตมอร์ฟ และตัวอย่างเสียงทั้งหมดในครั้งเดียว เสียงค้างจึงไม่รั่วข้ามการเปลี่ยนฉาก โทน เพลงพื้นหลัง และเอนจินดนตรียังเล่นต่อ

```ling-gui
ผูก เริ่ม = ทำ {
    เสียงปุ่ม("confirm")
    เสียงบี๊บ(880, 0.06, "square", 0.2)
    เสียงเอฟเฟกต์(1.5, 0, 4, 1, 330, 0.3, 0.2, "triangle")
    morph_note(0, 0, 5, 1, 220, 0.3, 1.2, 1, 0.4)
}
```

## ตัวอย่างเสียง

### `audio_sample_load(path)`

ถอดรหัสไฟล์ WAV, FLAC, OGG, MP3 หรือ AAC ลงหน่วยความจำ โดยมิกซ์ลงเป็นโมโน ถ้าไม่พบไฟล์ตามเส้นทางที่ให้ จะลองหาเทียบกับโฟลเดอร์ของสคริปต์ คืนรหัสตัวอย่างเสียง (เริ่มจาก 0) หรือ `-1` เมื่อล้มเหลวหรือไม่มีอุปกรณ์เสียง

### `audio_sample_play(id, x, y, z, w, volume, loop, pitch)`

เล่นตัวอย่างเสียงที่โหลดแล้วที่ตำแหน่งในโลก แพนและลดระดับเทียบกับผู้ฟัง `volume` ค่าเริ่มต้น 1, `loop` มากกว่า 0.5 คือเล่นวน และ `pitch` คือตัวคูณอัตราการเล่น (2 คือสูงขึ้นหนึ่งอ็อกเทฟ 0.5 คือต่ำลงหนึ่งอ็อกเทฟ) `w` ไม่มีผลที่ได้ยินกับตัวอย่างเสียง คืนรหัสเสียงที่เล่น หรือ 0 เมื่อล้มเหลว ในบิลด์เบราว์เซอร์ซิกเนเจอร์คือ `(id, x, y, z, w, volume, loop)` ไม่มี pitch

### `audio_sample_play_flat(id, volume, loop, pitch)`

เล่นตัวอย่างเสียงโดยไม่แพนและไม่ลดตามระยะ ใช้กับเสียงบรรยาย เสียงพากย์ และสัญญาณของส่วนติดต่อ คืนรหัสเสียงที่เล่น หรือ 0

### `audio_sample_stop(voice)` และ `audio_sample_duration(id)`

`audio_sample_stop` หยุดเสียงที่ได้จากคำสั่งเล่น `audio_sample_duration` คืนความยาวของตัวอย่างเสียงเป็นวินาที (0 สำหรับรหัสที่ไม่รู้จัก) สะดวกสำหรับกำหนดจังหวะคัตซีนให้ตรงกับคลิปที่โหลดจริง

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก เสียงก้าว = โหลดตัวอย่างเสียง("step.ogg")
    ผูก เสียงหึ่ง = โหลดตัวอย่างเสียง("hum.wav")
    เล่นตัวอย่างเสียง(เสียงก้าว, 1.0, 0.0, 3.0, 1.0, 0.8, 0, 1.2)
    ผูก เสียงเล่น = audio_sample_play_flat(เสียงหึ่ง, 0.5, 1, 1.0)
    พิมพ์(audio_sample_duration(เสียงหึ่ง))
    หยุดตัวอย่างเสียง(เสียงเล่น)
}
```

## เอฟเฟกต์หลัก

ห่วงโซ่หลักคือ ดีเลย์ แล้วเสียงก้อง แล้วฟิลเตอร์ความถี่ต่ำผ่าน ทั้งสามเริ่มต้นแบบปิดหรือเปิดเต็ม

| ฟังก์ชันในตัว | พารามิเตอร์ |
|---|---|
| `audio_fx_delay(time, feedback, mix)` | เวลาสะท้อนเป็นวินาที (ค่าเริ่มต้น 0.3) ฟีดแบ็ก 0 ถึง 0.95 (ค่าเริ่มต้น 0.3) สัดส่วนเสียงเอฟเฟกต์ 0 ถึง 1 (ค่าเริ่มต้น 0.3 และ 0 คือปิด) |
| `audio_fx_reverb(mix)` | สัดส่วนเสียงก้อง 0 ถึง 1 (ค่าเริ่มต้น 0.3) |
| `audio_fx_lowpass(cutoff)` | 0 ถึง 1 โดย 1 คือเปิด ค่าต่ำลงทำให้เสียงอู้อี้ เหมือนอยู่ใต้น้ำ ฟิลเตอร์จะค่อยๆ เลื่อนไปค่าใหม่ |

```ling-gui
ผูก เริ่ม = ทำ {
    เสียงสะท้อน(0.35, 0.4, 0.25)
    เสียงก้อง(0.4)
    กรองความถี่ต่ำ(0.15)
}
```

## การวิเคราะห์ FFT

ตัววิเคราะห์ FFT ทำงานกับตัวอย่างเสียงที่คุณป้อนให้ ใช้ `fft_push` ป้อนบล็อกตัวอย่างเสียงโมโน (ตัวเลขระหว่าง -1 ถึง 1 ที่ 44.1 kHz) แล้วอ่านผลลัพธ์:

| ฟังก์ชันในตัว | ค่าที่คืน |
|---|---|
| `fft_bands(n)` | รายการแถบขนาด `n` แถบแบบลอการิทึม (ค่าเริ่มต้น 32) เริ่มจากเสียงต่ำ |
| `fft_beat()` | `true` เมื่อบล็อกล่าสุดเป็นจังหวะ |
| `fft_beat_ratio()` | ความแรงของจังหวะ 1 คือที่เกณฑ์ตรวจจับ มากกว่า 1 คือจังหวะแรง |
| `fft_rms()` | ระดับรากกำลังสองเฉลี่ย (RMS) ของสัญญาณ |
| `fft_dominant_freq()` | ความถี่ที่แรงที่สุดเป็น Hz |

โปรแกรมนี้สร้างคลื่นไซน์ 1000 Hz แล้ววิเคราะห์ คำตอบใกล้ 1000 โดยจำกัดด้วยความละเอียดความถี่ของตัววิเคราะห์:

```ling
ผูก เริ่ม = ทำ {
    ผูก ตัวอย่าง = []
    ผูก i = 0
    ขณะที่ i < 4096 {
        ผูก ตัวอย่าง = ตัวอย่าง.เพิ่ม(ไซน์(i * 6.2831853 * 1000 / 44100))
        ผูก i = i + 1
    }
    วิเคราะห์เสียง(ตัวอย่าง)
    พิมพ์(ปัดเศษ(ความถี่หลัก()))
    พิมพ์(ปัดเศษ(ระดับRMS() * 1000) / 1000)
    ผูก ชุดแถบ = แถบความถี่(8)
    ผูก ดังสุด = 0
    ผูก k = 1
    ขณะที่ k < ความยาว(ชุดแถบ) {
        ถ้า ชุดแถบ[k] > ชุดแถบ[ดังสุด] {
            ผูก ดังสุด = k
        }
        ผูก k = k + 1
    }
    พิมพ์("แถบที่ดังที่สุด: " + str(ดังสุด))
}
```

```output
991
0.707
แถบที่ดังที่สุด: 4
```
