# ดนตรี

ฟังก์ชันในตัว `music_*` ทำงานกับดนตรีทั้งชิ้น ได้แก่ ถอดรหัสและวิเคราะห์ไฟล์เสียง เล่นทีละหนึ่งแทร็ก เล่นโน้ตด้วยแพตช์เครื่องดนตรี แปลงระหว่างโน้ตกับความถี่ อ่านไฟล์ MIDI และไฟล์เนื้อเพลง `.lrc` และตัดสินจังหวะในเกมดนตรี ฟังก์ชันในตัว `daw_*` ไปไกลกว่านั้น คือขับเอนจินของ LingStationX ซึ่งเป็นเวิร์กสเตชันเสียงดิจิทัล สคริปต์จึงสร้างเพลง ใส่เอฟเฟกต์ และเรนเดอร์ออกเป็นไฟล์ได้

สำหรับโทน เสียงเอฟเฟกต์ และไฟล์ตัวอย่างเสียง ดูที่ [เสียง](audio.md)

ข้อตกลง:

- แฮนเดิลของแทร็ก แพตช์ MIDI และเนื้อเพลงเป็นจำนวนเต็มเล็กๆ นับจาก 0 การโหลดที่ล้มเหลวคืน `-1` แฮนเดิลที่ไม่รู้จักจะได้ `0` สตริงว่าง หรือรายการว่าง ไม่เกิดข้อผิดพลาด
- เส้นทางใช้ตามที่ให้ถ้ามีไฟล์อยู่ ไม่เช่นนั้นจะหาเทียบกับโฟลเดอร์ของสคริปต์ที่กำลังรัน
- **ระดับเสียง** (pitch) คือหมายเลข MIDI (60 คือโดกลาง 69 คือ A4) หรือชื่อโน้ต เช่น `"C4"`, `"A#3"` หรือ `"Db5"`
- การวิเคราะห์ MIDI เนื้อเพลง และงาน DAW แบบออฟไลน์ไม่ต้องใช้อุปกรณ์เสียง ตัวอย่างเหล่านั้นจึงรันได้ทุกที่

## โน้ตและความถี่

`music_hz(pitch)` แปลงหมายเลข MIDI หรือชื่อโน้ตเป็น Hz โดย A4 (69) คือ 440 ชื่อที่อ่านไม่ได้นับเป็น 69 `music_note_name(hz)` คืนโน้ตที่ใกล้ที่สุดโดยสะกดแบบชาร์ป หรือสตริงว่างถ้า `hz` ไม่เป็นบวก อ็อกเทฟใช้ระบบวิทยาศาสตร์ ซึ่ง C4 คือ MIDI 60

```ling
ผูก เริ่ม = ทำ {
    พิมพ์(ความถี่โน้ต("A4"))
    พิมพ์(ปัดเศษ(ความถี่โน้ต(60) * 100) / 100)
    พิมพ์(ปัดเศษ(ความถี่โน้ต("C5") * 100) / 100)
    พิมพ์(ชื่อโน้ต(440.0))
    พิมพ์(ชื่อโน้ต(262.0))
    พิมพ์(ชื่อโน้ต(466.2))
}
```

```output
440
261.63
523.25
A4
C4
A#4
```

ไม่มีฟังก์ชันในตัวสำหรับบันไดเสียง แต่บันไดเสียงก็เป็นแค่รายการของระยะครึ่งเสียง ตัวอย่างนี้พิมพ์บันไดเสียงเพนทาโทนิก C เมเจอร์:

```ling
ผูก เริ่ม = ทำ {
    ผูก ระยะ = [0, 2, 4, 7, 9]
    ผูก ผล = []
    ผูก i = 0
    ขณะที่ i < ความยาว(ระยะ) {
        ผูก ผล = ผล.เพิ่ม(ชื่อโน้ต(ความถี่โน้ต(60 + ระยะ[i])))
        ผูก i = i + 1
    }
    พิมพ์(ผล)
}
```

```output
[C4, D4, E4, G4, A4]
```

## การโหลดและการวิเคราะห์

| ฟังก์ชันในตัว | ค่าที่คืน |
|---|---|
| `music_load(path)` | แฮนเดิลแทร็ก หรือ `-1` รับ WAV, FLAC, OGG (Vorbis), MP3 และ AAC/M4A ถอดรหัสทั้งไฟล์ลงหน่วยความจำ |
| `music_duration(track)` | ความยาวเป็นวินาที |
| `music_bpm(track)` | เทมโปโดยประมาณ ปัดเป็นทศนิยม 0.1 และพับให้อยู่ในช่วง 70 ถึง 170 BPM บางเพลงอาจคลาดไปหนึ่งอ็อกเทฟ |
| `music_key(track)` | สตริง เช่น `"A minor"` หรือ `"C major"` (เฉพาะเมเจอร์และไมเนอร์) |
| `music_onsets(track)` | รายการเวลา (วินาที) ที่โน้ตหรือเสียงตีเริ่มต้น |
| `music_beat_grid(track)` | ตารางเวลาจังหวะที่สม่ำเสมอตามเทมโปที่ตรวจพบ เริ่มจากจุดเริ่มเสียงแรก ไม่ตามการเปลี่ยนเทมโป |
| `music_fft(track, bands)` | ขนาดที่ปรับเรียบแล้ว `bands` ค่าแบบลอการิทึม (ค่าเริ่มต้น 16) เริ่มจากเสียงต่ำ จากหน้าต่าง 2048 ตัวอย่างที่ตำแหน่งเล่นปัจจุบัน เงียบจนกว่า `music_play` จะเริ่ม |
| `music_fft_groups(track, size, groups)` | ค่าความดัง `groups` ค่า (ค่าเริ่มต้น 7) ระหว่าง 30 Hz ถึง 16 kHz จาก FFT ขนาด `size` ตัวอย่างหนึ่งครั้ง (ค่าเริ่มต้น 8192) คลื่นไซน์เต็มสเกลอ่านได้ราว 0.5 ช่วงที่เบาก็ยังเบา |

ตัวอย่างนี้ไม่ต้องใช้ไฟล์ใดเลย มันเรนเดอร์ลูปกระเดื่องสองห้องด้วย DAW (ดูด้านล่าง) แล้ววิเคราะห์:

```ling
ผูก เริ่ม = ทำ {
    daw_new()
    daw_set_bpm(120)
    ผูก กลอง = daw_track_add("drums")
    ผูก คลิป = daw_clip_add_midi(กลอง, 0, 8)
    ผูก จังหวะ = 0
    ขณะที่ จังหวะ < 16 {
        daw_note_add(กลอง, คลิป, จังหวะ * 0.5, 0.25, 36, 0.9)
        ผูก จังหวะ = จังหวะ + 1
    }
    daw_bounce("loop.wav", 0, 8, 0.0, 16, "wav", 0.5)

    ผูก แทร็ก = โหลดเพลง("loop.wav")
    พิมพ์("วินาที: " + str(ปัดเศษ(ความยาวเพลง(แทร็ก))))
    พิมพ์("BPM: " + str(ปัดเศษ(จังหวะต่อนาที(แทร็ก))))
    พิมพ์("จุดเริ่มเสียง: " + str(ความยาว(จุดเริ่มเสียง(แทร็ก))))
    พิมพ์("จังหวะในกริด: " + str(ความยาว(กริดจังหวะ(แทร็ก))))
    พิมพ์(โหลดเพลง("missing.wav"))
}
```

```output
วินาที: 4
BPM: 120
จุดเริ่มเสียง: 15
จังหวะในกริด: 8
-1
```

## การเล่น

เอนจินดนตรีเปิดสตรีมเอาต์พุตของตัวเองเมื่อใช้ครั้งแรก แยกจากเอนจิน[เสียง](audio.md) และเล่นทีละหนึ่งแทร็ก

- `music_play(track)` ตั้ง `track` เป็นแทร็กปัจจุบันและเล่น **ตั้งแต่ต้น** เรียกซ้ำคือเริ่มใหม่ การเล่นหยุดเมื่อจบเพลง (ไม่วน)
- `music_pause()` หยุดชั่วคราวโดยจำตำแหน่งไว้ ถ้าจะเล่นต่อ ให้เรียก `music_play(-1)` รหัสที่ไม่ใช่แทร็กที่โหลดไว้จะเล่นแทร็กปัจจุบันต่อ
- `music_stop()` หยุดและกรอกลับ `music_seek(seconds)` ข้ามไปยังตำแหน่ง `music_pos()` คืนตำแหน่งเป็นวินาที
- `music_volume(level)` ตั้งระดับเสียงของเอนจินดนตรี ทั้งแทร็กและซินธิไซเซอร์ (ค่าเริ่มต้น 0.8 บีบให้อยู่ใน 0..2) เอาต์พุตผ่านการตัดยอดแบบนุ่ม ระดับที่เกิน 1 จึงเพี้ยนเบาๆ

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 360, "ภาพตามเสียง")
    ผูก บทเพลง = โหลดเพลง("song.ogg")
    ระดับเพลง(0.8)
    เล่นเพลง(บทเพลง)
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(10, 10, 20)
        ผูก แท่ง = สเปกตรัมเพลง(บทเพลง, 16)
        ผูก i = 0
        ขณะที่ i < 16 {
            ผูก สูงแท่ง = ต่ำสุด(300, แท่ง[i] * 40)
            สีดินสอ(80 + i * 10, 200, 255)
            วาดเส้น(30 + i * 38, 340, 30 + i * 38, 340 - สูงแท่ง)
            ผูก i = i + 1
        }
        แสดงผล()
    }
}
```

## การสังเคราะห์เสียง

เอนจินดนตรีมีซินธิไซเซอร์หลายเสียงแบบ FM/ซับแทรกทีฟ เครื่องดนตรีคือไฟล์ **แพตช์** ประกอบด้วยโทเค็น `key=value` ธรรมดา โดย `#` เริ่มคอมเมนต์ โอเปอเรเตอร์มีหมายเลขเริ่มจาก 1 และโอเปอเรเตอร์หนึ่งมอดูเลตความถี่ของอีกตัวได้ด้วย `opN.fm`

```text
name = "Rhodes EP"
poly = 16
op1.wave=sine  op1.ratio=1.0  op1.level=1.0  op1.adsr=0.002,1.2,0.0,0.4
op2.wave=sine  op2.ratio=14.0 op2.level=0.5  op2.fm=op1  op2.adsr=0.001,0.2,0.0,0.2
filter.cutoff=0.8 filter.reso=0.2 filter.env=0.3 filter.adsr=0,0.5,0.2,0.3
lfo.rate=5.0 lfo.pitch=0.05
amp = 0.7
```

คีย์: `name`, `gm` (โปรแกรม General MIDI), `poly` (จำนวนเสียง ค่าเริ่มต้น 16), `amp`, `lfo.rate`, `lfo.pitch`, `lfo.cutoff`, `lfo.amp`, `filter.cutoff`, `filter.reso`, `filter.env`, `filter.adsr`, `filter.on` และต่อโอเปอเรเตอร์ `opN.wave` (`sine`, `saw`, `square`/`pulse`, `tri`, `noise`), `opN.ratio`, `opN.fixed` (Hz), `opN.level`, `opN.detune`, `opN.adsr` (attack, decay, sustain, release) และ `opN.fm` คีย์ที่ไม่รู้จักจะถูกละเว้น แพตช์สำเร็จรูปอยู่ในโฟลเดอร์ `instruments/` ของรีโพซิทอรี

- `music_patch(path)` โหลดแพตช์และคืนแฮนเดิลเครื่องดนตรี (แยกจากแฮนเดิลแทร็ก) หรือ `-1`
- `music_note(inst, pitch, duration, velocity)` เล่นโน้ตค้างไว้ `duration` วินาที (ค่าเริ่มต้น 0.5) ที่ `velocity` 0 ถึง 1 (ค่าเริ่มต้น 0.9) แล้วตามด้วยช่วงปล่อยของแพตช์
- `music_note_on(inst, pitch, velocity)` กดคีย์ ส่วน `music_note_off(inst, pitch)` ปล่อยคีย์ ใช้เป็นคู่

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก เปียโน = แพตช์เครื่องดนตรี("instruments/grand_piano.ling")
    เล่นโน้ต(เปียโน, "C4", 0.5, 0.9)
    เล่นโน้ต(เปียโน, "E4", 0.5, 0.8)
    โน้ตเริ่ม(เปียโน, 55, 0.7)
    นอน(1000)

}
```

## การร้องเพลงและเกมดนตรี

`music_mic_pitch()` คืนความถี่มูลฐานที่ไมโครโฟนได้ยิน (55 ถึง 1000 Hz) หรือ 0 ถ้าไมโครโฟนปิด สัญญาณเบาเกินไป หรือหาระดับเสียงชัดเจนไม่ได้ ต้องเปิดไมโครโฟนด้วย `mic_open()` ก่อน

`music_pitch_score(sung_hz, target_hz)` ให้คะแนนระดับเสียงที่ร้องจาก 0 ถึง 1 โดย 1 คือตรงเป๊ะ และ 0 คือเพี้ยนครึ่งเสียงขึ้นไป ความคลาดเคลื่อนพับเข้าหาอ็อกเทฟที่ใกล้ที่สุด ร้องต่างไปหนึ่งอ็อกเทฟจึงยังได้คะแนนดี

`music_judge(delta_ms)` ตัดสินการกดจากความคลาดเคลื่อนของเวลาเป็นมิลลิวินาที (ไม่สนเครื่องหมาย): 0 Perfect (ไม่เกิน 30 ms), 1 Great (60), 2 Good (100), 3 Ok (140), 4 Miss ส่วน `music_grade_name(index)` คืน `"PERFECT"`, `"GREAT"`, `"GOOD"`, `"OK"` หรือ `"MISS"`

```ling
ผูก เริ่ม = ทำ {
    พิมพ์(คะแนนเสียง(440.0, 440.0))
    พิมพ์(ปัดเศษ(คะแนนเสียง(450.0, 440.0) * 100) / 100)
    พิมพ์(ตัดสินจังหวะ(12.0))
    พิมพ์(ชื่อการตัดสิน(ตัดสินจังหวะ(-45.0)))
    พิมพ์(ชื่อการตัดสิน(ตัดสินจังหวะ(500.0)))
}
```

```output
1
0.61
0
GREAT
MISS
```

## เนื้อเพลงและไฟล์ MIDI

`music_lrc(path)` โหลดไฟล์เนื้อเพลงที่มีเวลากำกับ ซึ่งแต่ละบรรทัดเป็นแบบ `[mm:ss.xx] ข้อความ` แล้วคืนแฮนเดิล `music_lyric(lyrics, time)` คืนบรรทัดล่าสุดที่เวลาไม่เกิน `time` (ปกติคือ `music_pos()`) หรือสตริงว่างก่อนบรรทัดแรก

```ling
ผูก เริ่ม = ทำ {
    write_file("song.lrc", "[00:01.00] บรรทัดแรก\n[00:03.50] บรรทัดที่สอง\n")
    ผูก เนื้อร้อง = โหลดเนื้อเพลง("song.lrc")
    พิมพ์("[" + เนื้อเพลงปัจจุบัน(เนื้อร้อง, 0.5) + "]")
    พิมพ์(เนื้อเพลงปัจจุบัน(เนื้อร้อง, 2.0))
    พิมพ์(เนื้อเพลงปัจจุบัน(เนื้อร้อง, 99.0))
}
```

```output
[]
บรรทัดแรก
บรรทัดที่สอง
```

`music_midi_load(path)` โหลด Standard MIDI File เป็นข้อมูล ไม่มีอะไรเล่น ใช้โน้ตเพื่อสร้างเหรียญ วาดแท่งที่ตกลงมา หรือเรียกสัญญาณต่างๆ `music_midi_count` คืนจำนวนโน้ต `music_midi_notes` คืนรายการแบน `[เวลา, คีย์, เวลา, คีย์, ...]` และ `music_midi_bars` คืนรายการแบน `[เวลา, คีย์, ความยาว, ...]` ทั้งหมดเป็นวินาที

```ling
ผูก เริ่ม = ทำ {
    daw_new()
    daw_set_bpm(120)
    ผูก แทร็ก = daw_track_add("synth")
    ผูก คลิป = daw_clip_add_midi(แทร็ก, 0, 4)
    daw_note_add(แทร็ก, คลิป, 0, 1, 60, 0.8)
    daw_note_add(แทร็ก, คลิป, 2, 2, 67, 0.8)
    daw_midi_export_project("song.mid")

    ผูก มิดี = โหลดมิดี("song.mid")
    พิมพ์(จำนวนมิดี(มิดี))
    พิมพ์(โน้ตมิดี(มิดี))
    พิมพ์(แท่งมิดี(มิดี))
}
```

```output
2
[0, 60, 1, 67]
[0, 60, 0.5, 1, 67, 1]
```

## DAW

ฟังก์ชันในตัว `daw_*` ขับเอนจินของ LingStationX ซึ่งเป็นเวิร์กสเตชันเสียงดิจิทัลที่มาพร้อม Ling สคริปต์ใดก็ใช้ได้ ไม่ว่าจะมีหน้าต่างหรือไม่ เพื่อสร้างโปรเจกต์ แก้ไขโน้ต ใส่เอฟเฟกต์ และเรนเดอร์เสียง เอนจินถูกสร้างเมื่อเรียกฟังก์ชันในตัว `daw_*` ครั้งแรก

สิ่งที่ควรรู้:

- ตำแหน่งคลิป ความยาว จุดลูป และช่วงเรนเดอร์มีหน่วยเป็น **จังหวะ** (beat) `daw_secs_at(beat)` แปลงเป็นวินาที
- แทร็ก คลิป โน้ต และเอฟเฟกต์อ้างอิงด้วยดัชนีที่เริ่มจากศูนย์ ดัชนีจะเลื่อนเมื่อคุณแทรกหรือลบรายการ
- คำตอบใช่/ไม่ใช่คืนเป็น `1` และ `0` ฟังก์ชันที่สร้างบางอย่างจะคืนดัชนีของสิ่งนั้น หรือ `-1`
- การแก้ไขและการเรนเดอร์ไม่ต้องใช้อุปกรณ์เสียง `daw_play()` เล่นแบบเรียลไทม์เมื่อมีอุปกรณ์
- `daw_status()` คืนข้อความที่การทำงานล่าสุดทิ้งไว้
- *เป้าหมาย* ของเอฟเฟกต์คือดัชนีแทร็ก หรือ `-1` สำหรับบัสหลัก

กลุ่มหลัก:

| กลุ่ม | ฟังก์ชันในตัว |
|---|---|
| โปรเจกต์ | `daw_new`, `daw_project_save(path)`, `daw_project_load(path)`, `daw_set_project_name(name)`, `daw_status` |
| การเล่นและเทมโป | `daw_play`, `daw_pause`, `daw_stop`, `daw_seek(beat)`, `daw_position`, `daw_bpm`, `daw_set_bpm(bpm)`, `daw_set_loop(on, start, end)`, `daw_end_beat`, `daw_tempo_add(beat, bpm)`, `daw_secs_at(beat)` |
| แทร็ก | `daw_track_add(kind, path)`, `daw_track_count`, `daw_track_remove(track)`, `daw_track_name(track)`, `daw_track_set_name(track, name)`, `daw_track_get(track, field)`, `daw_track_set(track, field, value)` |
| คลิปและโน้ต | `daw_clip_add_midi(track, start, length)`, `daw_clip_add_audio(track, path, start)`, `daw_clip_notes(track, clip)`, `daw_note_add(track, clip, start, length, key, velocity)`, `daw_note_remove(track, clip, note)` |
| เครื่องดนตรี | `daw_inst_presets(track)`, `daw_inst_preset(track, name)`, `daw_inst_params(track)`, `daw_inst_set(track, name, value)` |
| เอฟเฟกต์ | `daw_fx_types`, `daw_fx_add(target, name)`, `daw_fx_params(target, index)`, `daw_fx_set(target, index, param, value)`, `daw_fx_set_wet(target, index, wet)`, `daw_fx_bypass(target, index, on)` |
| การเรนเดอร์และย้อนกลับ | `daw_bounce(path, start, end, tail, bits, format, quality)`, `daw_render_start(...)`, `daw_undo_push`, `daw_undo`, `daw_redo` |
| MIDI | `daw_midi_import(path, beat)`, `daw_midi_export(track, path)`, `daw_midi_export_project(path)`, `daw_midi_inputs`, `daw_midi_open(index)` |

ชนิดแทร็กของ `daw_track_add` ได้แก่ `"synth"`, `"drums"`, `"audio"`, `"sf2"` (พร้อมเส้นทาง SoundFont), `"growl"`, `"voice"`, `"prism"`, `"sampler"`, `"pluck"`, `"chip"`, `"cinema"` และ `"script"` เอนจินยังมีฟังก์ชันในตัว `daw_*` อีกหลายร้อยตัวสำหรับออโตเมชัน เสียงร้อง การสร้างเพลง การมิกซ์ และการส่งออก ส่วนใหญ่ใช้กับแอปพลิเคชัน LingStationX เอง

เซสชันออฟไลน์ที่สมบูรณ์:

```ling
ผูก เริ่ม = ทำ {
    daw_new()
    daw_set_project_name("Demo")
    daw_set_bpm(100)

    ผูก ลีด = daw_track_add("synth")
    daw_inst_preset(ลีด, "FM Bell")
    ผูก คลิป = daw_clip_add_midi(ลีด, 0, 4)
    ผูก ระดับโน้ต = [60, 64, 67, 72]
    ผูก i = 0
    ขณะที่ i < 4 {
        daw_note_add(ลีด, คลิป, i, 0.75, ระดับโน้ต[i], 0.8)
        ผูก i = i + 1
    }

    ผูก ห้องก้อง = daw_fx_add(ลีด, "Reverb")
    daw_fx_set_wet(ลีด, ห้องก้อง, 0.3)

    พิมพ์("แทร็ก: " + str(daw_track_count()))
    พิมพ์("โปรเจกต์จบที่จังหวะ " + str(daw_end_beat()))
    พิมพ์("เรนเดอร์สำเร็จ: " + str(daw_bounce("demo.wav", 0, 4, 1.0, 16, "wav", 0.5)))
}
```

```output
แทร็ก: 1
โปรเจกต์จบที่จังหวะ 4
เรนเดอร์สำเร็จ: 1
```
