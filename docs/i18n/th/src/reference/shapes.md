# รูปทรงและเมช 3 มิติ

ฟังก์ชันในตัวเหล่านี้ใส่สิ่งต่างๆ เข้าไปในฉาก 3 มิติ ได้แก่ รูปทรงตันแบบพารามิเตอร์ราวยี่สิบกว่าแบบ
สามเหลี่ยมและเส้นแบบดิบ ลายเวกเตอร์ `vtex_*` ที่วางบนระนาบ เท็กซ์เจอร์พิกเซล `tex_*`
และเมชที่โหลดจากไฟล์ (ทั้งฟอร์แมตของ Ling เองและ glTF) ทุกอย่างในหน้านี้ต้องมีหน้าต่างเปิดอยู่
และใช้กล้องจาก [หน้าต่างและกล้อง](window.md) ส่วนแสง รูปแบบการแรเงา และโพสต์โพรเซสซิงอยู่ที่
[โพสต์เอฟเฟกต์และแสง](postfx.md)

คำสั่ง 3 มิติไม่วาดทันที แต่จะเข้า **คิวความลึก** ซึ่งถูกเรียงและวาดตอน
`present()` (หรือ `flush_3d()`) คุณจึงสั่งวาดในลำดับใดก็ได้ภายในเฟรมเดียว

## รูปทรงตันพื้นฐาน

รูปทรงตันทุกแบบรับอาร์กิวเมนต์ชุดเดียวกัน:

```text
name(cx, cy, cz,  sx, sy, sz,  rx, ry, rz,  mode,  e0, e1, e2)
```

| อาร์กิวเมนต์ | ความหมาย |
|---|---|
| `cx, cy, cz` | จุดศูนย์กลางในพิกัดโลก |
| `sx, sy, sz` | สเกลแต่ละแกน (ค่าเริ่มต้น 1) รูปทรงมีรัศมีราวหนึ่งหน่วย สเกลจึงประมาณครึ่งหนึ่งของขนาด: `cube(0, 0, 8, 1, 1, 1)` คือลูกบาศก์ขนาด 2 หน่วย |
| `rx, ry, rz` | การหมุนเป็นเรเดียน (ค่าเริ่มต้น 0) ทำตามลำดับ X แล้ว Y แล้ว Z |
| `mode` | `0` ทึบ (ค่าเริ่มต้น) `1` โครงลวด `2` ทั้งสองแบบ |
| `e0, e1, e2` | ค่าพิเศษเฉพาะรูปทรง (ดูตารางด้านล่าง) 0 หรือไม่ใส่คือค่าเริ่มต้น |

บังคับใส่แค่ตำแหน่ง อาร์กิวเมนต์ท้ายๆ ละไว้ได้ สีดินสอ (`set_color`) คือสีเนื้อและ
สีโครงลวด รูปทรงตันได้รับแสงจากแสงในฉากและแรเงาแบบทูน

อย่าลืมว่า +y ชี้ลง `cone` มียอดอยู่ที่ +y ถ้าไม่หมุนจะชี้ลงจอ
ให้หมุน π รอบแกน x เพื่อกลับหัว `gear` และ `torus` วางอยู่บนระนาบ x-z ให้หมุนราว 1.57 รอบแกน x
เพื่อหันเข้าหากล้อง

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(900, 600, "รูปทรง")
    ทดสอบความลึก(1)
    ผูก เฟรม = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(8, 10, 24)
        ตั้งกล้อง(1, 0, 1, 0)
        ล้างแสง()
        เพิ่มแสง(-2, -6, -2, 1.0, 0.95, 0.85, 0.6, 0)
        ผูก มุม = เฟรม * 0.03
        สีดินสอ(230, 120, 90)
        ลูกบาศก์(-2.8, 0, 7.5, 0.8, 0.8, 0.8, มุม, มุม * 0.7, 0, 0)
        สีดินสอ(120, 200, 255)
        ทรงกลม(0, 0, 7.5, 0.9, 0.9, 0.9, 0, 0, 0, 0)
        สีดินสอ(190, 190, 200)
        เฟือง(2.8, 0, 7.5, 0.9, 0.3, 0.9, 1.57, มุม * 2, 0, 0, 14, 0.3)
        แสดงผล()
        ผูก เฟรม = เฟรม + 1
    }
}
```

### หมายเหตุของรูปทรงแต่ละแบบ

- **`cylinder`** ยาวตามแกน y ของตัวเองจาก -1 ถึง 1 จึงสูง `2 * sy` ถ้าใช้ `sy` เล็กๆ เช่น 0.05
  จะได้แผ่นกลมหรือจาน
- **`torus`**: `tube` คือรัศมีของท่อเป็นสัดส่วนของรัศมีวงนอก (0.02 ถึง 0.9)
- **`frustum`**: อัตราส่วนด้านบนคือรัศมีด้านบนหารด้วยรัศมีฐาน ใกล้ 0 คือกรวย 1 คือ
  ทรงกระบอก อัตราส่วนเล็กกับ `sy` สูงๆ ได้เสาโอเบลิสก์
- **`gear`**: ความหนามาจาก `sy` จำนวนฟัน 3 ถึง 96 ความลึกฟัน 0.02 ถึง 0.6
- **`stairs`**: แต่ละขั้นเลื่อนไปทาง +y และ +z หนึ่งขั้น เพราะ +y ชี้ลง บันไดจึงดูเหมือนลาดลง
  เมื่อไกลออกไป ให้หมุน π รอบ `rz` เพื่อกลับด้าน
- **`gyro`** ซ้อนวงแหวนกิมบอลบนแกนสลับกัน **`capsule_chain`** เรียงลูกปัดตามแกน x
- ลูกเต๋า (`tetrahedron` ถึง `icosahedron`) จะดูเหมือนอัญมณีเมื่อใช้ `mode` 2 กับสีสว่าง

```ling-gui
ผูก เริ่ม = ทำ {
    สีดินสอ(255, 140, 180)
    ทรงยี่สิบหน้า(0, 0, 8, 1, 1, 1, 0.4, 0.7, 0, 2)
    กรวย(3, 0, 8, 0.8, 1, 0.8, 3.14159, 0, 0, 0)       # ยอดชี้ขึ้น
}
```

## สามเหลี่ยม เส้น และการทดสอบความลึก

| ฟังก์ชันในตัว | 中文 | 日本語 | 한국어 | ไทย | หน้าที่ |
|---|---|---|---|---|---|
| `draw_triangle_3d(ax, ay, az, bx, by, bz, cx, cy, cz)` | — | — | — | — | สามเหลี่ยมหนึ่งรูปที่ได้รับแสง |
| `draw_quad_3d(...)`, `draw_polygon_3d(...)` | — | — | — | — | รูปหลายเหลี่ยมนูนที่ได้รับแสง |
| `draw_line_3d(ax, ay, az, bx, by, bz)` | — | — | — | — | เส้นที่เรียงตามความลึก |
| `set_depth_test(on)` | `深度测试` | `深度テスト` | `깊이테스트` | `ทดสอบความลึก` | บัฟเฟอร์ความลึกรายพิกเซล |
| `clear_depth()` | — | — | — | — | ล้างบัฟเฟอร์ความลึกกลางเฟรม |

### `draw_triangle_3d`, `draw_quad_3d` และ `draw_polygon_3d`

วาดรูปทรงในพิกัดโลกด้วยสีดินสอ โดยได้รับแสง มีหมอก และถูกตัดที่ระนาบใกล้
`draw_triangle_3d` รับสามจุด ลำดับการวนของจุดกำหนดว่าด้านไหนหันรับแสง
`draw_quad_3d` รับ `x, y, z` สี่ชุด (12 ตัวเลข) `draw_pent_3d` และ `draw_hex_3d` รับ 5 และ 6 ชุด
ทั้งหมดใช้โค้ดเดียวกับ `draw_polygon_3d` ซึ่งรับรายการแบนรายการเดียวได้ด้วย
`[x0, y0, z0, x1, y1, z1, ...]` ใช้จุดยอดได้มากสุด 8 จุด

```ling-gui
ผูก เริ่ม = ทำ {
    สีดินสอ(120, 200, 255)
    draw_quad_3d(-2, 1, 8, 2, 1, 8, 2, 1, 12, -2, 1, 12)     # แผ่นพื้นหนึ่งแผ่น
    draw_polygon_3d([0, -1, 8, 1, 0, 8, 0, 1, 8, -1, 0, 8])  # รูปข้าวหลามตัด
}
```

### `draw_line_3d(ax, ay, az, bx, by, bz)`

เส้นระหว่างสองจุดในโลก เรียงความลึกร่วมกับสิ่งอื่นและถูกตัดที่ระนาบใกล้ ใช้
`set_antialias(1)` เพื่อให้เส้นเรียบ

### `set_depth_test(on)` และ `clear_depth()`

การทดสอบความลึกปิดเป็นค่าเริ่มต้น รูปทรงที่รอคิวจึงถูกวาดจากไกลมาใกล้ ให้เปิด (`1`) เมื่อ
รูปทรงตันอาจตัดกัน และเมื่อใช้ ambient occlusion เส้นขอบ และระยะชัดลึก `fill()` ล้าง
บัฟเฟอร์ความลึกทุกเฟรมอยู่แล้ว `clear_depth()` มีไว้เริ่มรอบความลึกใหม่กลางเฟรม

## ลายเวกเตอร์: `vtex_*`

`vtex_*` แต่ละตัววาดลายเส้นเคลื่อนไหวบน **ระนาบในปริภูมิ 3 มิติ** อาร์กิวเมนต์เก้าตัวแรก
เหมือนกันทุกตัว และสองตัวสุดท้ายเป็น `fr` กับ `hue` เสมอ:

```text
vtex_name(cx, cy, cz,  ux, uy, uz,  vx, vy, vz,  ...pattern arguments...,  fr, hue)
```

`cx, cy, cz` คือจุดศูนย์กลาง `u` คือทิศที่ "ขวา" ของลายวิ่งไป และ `v` คือทิศที่ "บน"
วิ่งไป `fr` คือตัวนับเฟรมที่คุณส่งให้ ซึ่งขับสีและการเคลื่อนไหว `hue` เลื่อนเฟสสี
เพื่อให้ลายที่อยู่ติดกันต่างกัน สีจะวนไล่เป็นสีรุ้งเอง ไม่ใช้สีดินสอ

| ระนาบ | `u` | `v` |
|---|---|---|
| พื้นหรือเพดาน | `1, 0, 0` | `0, 0, 1` |
| ผนังที่หันหากล้อง ตั้งตรง | `1, 0, 0` | `0, -1, 0` |
| ผนังด้านข้าง ตั้งตรง | `0, 0, 1` | `0, -1, 0` |

ลายที่ตั้งตรงใช้ `v = (0, -1, 0)` เพราะ +y ชี้ลง ลายเหล่านี้เป็นแค่เส้นตรงสั้นๆ จึง
ประหยัด และถูกวาดเยื้องเข้าหากล้องเล็กน้อย จึงอยู่ด้านบนพื้นผิวที่ตำแหน่งเดียวกัน

|---|---|---|---|---|---|
| `vtex_grid` | `纹格` | `格子模様` | `격자무늬` | `ลายตาราง` | cols 10, rows 10, cell_w 1, cell_h 1 |

รายละเอียดบางอย่าง: `vtex_rings` หมุนแต่ละวงมากกว่าวงก่อน `twist` เรเดียน จึงเกิดเป็นวังวน
ความหนาแน่นของ `vtex_halftone` อยู่ระหว่าง 0 (มองไม่เห็น) ถึง 1 (แรเงาเต็ม) `vtex_tessellated` เขย่า

```ling-gui
        ลายตาราง(0, 3, 9, 1, 0, 0, 0, 0, 1, 12, 8, 1, 1, เฟรม, 0)
        ลายวงซ้อน(-3, -1, 8, 1, 0, 0, 0, -1, 0, 6, 6, 1.2, 0.2, เฟรม, 0)
        ลายดอกบัว(0, -1, 8, 1, 0, 0, 0, -1, 0, 0.4, 1.2, 12, เฟรม, 1)
        เจดีย์(3, 1.9, 8, 1, 0, 0, 0, -1, 0, 5, 1.6, 0.5, 0.72, 0.2, เฟรม, 2)
        แสดงผล()
        ผูก เฟรม = เฟรม + 1
    }
}
```

`orb_shell(cx, cy, cz, radius, rot_y, rot_x, density, r, g, b)` เป็นญาติของลายเหล่านี้: เปลือก
โปร่งแสงจากเกลียวสอดประสานที่พันรอบทรงกลม (`density` 1 ถึง 48 ค่าเริ่มต้น 10
สีค่าเริ่มต้นเป็นเทาอ่อน) ชื่อพ้อง: zh `球壳`, ja `オーブ殻`, ko `오브껍질`, th `เปลือกทรงกลม`

## เท็กซ์เจอร์พิกเซล: `tex_*`

ฟังก์ชัน `tex_*` เติมสี่เหลี่ยมบนจอด้วยลายเชิงกระบวนการทีละพิกเซล
**ทันที** เหมือนคำสั่ง 2 มิติอื่นๆ ลายเหล่านี้จะถูกรูปทรง 3 มิติที่รอคิวทับ ทุกตัวเริ่มด้วย
สี่เหลี่ยม `x, y, w, h` เป็นพิกเซล (ค่าเริ่มต้น 0, 0, 256, 256)

ทุกพิกเซลถูกคำนวณใหม่ทุกครั้งที่เรียก เท็กซ์เจอร์ขนาดใหญ่จึงช้า ให้ใช้ขนาดเล็ก หรือวาด
ครั้งเดียวแล้วค้างไว้บนจอ

ที่ใดรับ `palette` ได้ จะเป็นหนึ่งใน `"rainbow"`, `"fire"`, `"ocean"`, `"psychedelic"`,
`"neon"` หรือ `"forest"` ชื่อที่ไม่รู้จักจะใช้ rainbow แทน

| ฟังก์ชันในตัว | หน้าที่ |
|---|---|
| `tex_checkerboard(x, y, w, h, tiles, r1, g1, b1, r2, g2, b2)` | ตารางหมากรุกสองสี (8 ช่อง ขาวและดำ) |
| `tex_gradient(x, y, w, h, angle_deg, r1, g1, b1, r2, g2, b2)` | ไล่สีเชิงเส้นตามมุม (0 คือซ้ายไปขวา) |
| `tex_noise(x, y, w, h, scale, octaves, seed, palette)` | นอยส์แบบแฟรกทัล (scale 4, octaves 1 ถึง 8) |
| `tex_spiral(x, y, w, h, freq, bands, time, palette)` | แถบเกลียวที่หมุนตาม `time` |
| `tex_ripple(x, y, w, h, freq, cx, cy, time, palette)` | ระลอกคลื่นจาก `cx, cy` (0 ถึง 1 ภายในสี่เหลี่ยม) |
| `tex_mandelbrot(x, y, w, h, zoom, cx, cy, max_iter, palette)` | เซตแมนเดลบรอต |
| `tex_julia(x, y, w, h, c_re, c_im, max_iter, palette)` | เซตจูเลีย (c = -0.7 + 0.27i) |
| `tex_voronoi(x, y, w, h, cells, seed, palette)` | เซลล์โวโรนอย (16 เซลล์) |
| `tex_halftone(x, y, w, h, dot_size, time, palette)` | จุดฮาล์ฟโทน |
| `tex_freq_map(x, y, w, h, time, speed, palette)` | สเปกตรัมจากการเรียก `fft_bands` ครั้งล่าสุด (ดู [เสียง](audio.md)) |

`tex_mandelbrot` แสดงระนาบเชิงซ้อนกว้าง `1 / zoom` หน่วยทั้งสองทิศ `zoom` 1 จึงเห็น
แค่คาร์ดิออยด์หลัก ให้ใช้ประมาณ 0.4 เพื่อดูทั้งเซต

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(660, 340, "tex")
    เติม(0, 0, 0)
    tex_checkerboard(10, 10, 200, 150, 8, 240, 240, 240, 30, 30, 60)
    tex_noise(230, 10, 200, 150, 5, 4, 7, "fire")
    tex_mandelbrot(450, 10, 200, 150, 0.4, -0.5, 0, 64, "psychedelic")
    แสดงผล()
    wait_window()
}
```

## เมช

Ling วาดเมชที่คุณสร้างในรายการ ฟอร์แมตเมชแบบไบนารีของ Ling เอง และโมเดล glTF ได้ ทั้งหมด
ถูกฉายผ่านกล้องและเข้าคิวร่วมกับฉาก 3 มิติส่วนอื่น

### `draw_mesh(positions, indices, ox, oy, oz, scale, mode)`

วาดเมชสามเหลี่ยมที่เก็บในสองรายการ: `positions` เป็นรายการแบน `[x0, y0, z0, x1, y1, z1, ...]`
และ `indices` ระบุหมายเลขจุดยอดสามตัวต่อสามเหลี่ยมหนึ่งรูป จุดยอดทุกจุดถูกคูณด้วย `scale`
(ค่าเริ่มต้น 1) และเลื่อนไป `ox, oy, oz` `mode` `0` ให้แสงด้วยสีดินสอ `1` ให้สามเหลี่ยม
แต่ละรูปมีสีรุ้ง ดัชนีที่ผิดจะถูกข้าม

```ling-gui
ผูก เริ่ม = ทำ {
    ผูก จุดยอด = [0, -1, 8, 1, 1, 8, -1, 1, 8, 0, 0, 10]
    ผูก ดัชนี = [0, 1, 2, 0, 2, 3, 0, 3, 1]
    สีดินสอ(200, 160, 255)
    draw_mesh(จุดยอด, ดัชนี, 0, 0, 0, 1, 0)
}
```

### `mesh_load(path)` และ `mesh_draw(id, x, y, z, scale, yaw)`

`mesh_load` อ่านไฟล์ `.lmesh` (ฟอร์แมตกะทัดรัดที่สามเหลี่ยมแต่ละรูปมีสีเรียบหนึ่งสี) และคืน
แฮนเดิลหรือ `-1` `mesh_draw` วาดเมชนั้นแบบ **ไม่รับแสง** ด้วยสีของมันเอง ที่ตำแหน่ง สเกลเท่ากันทุกแกน
และมุม yaw ที่กำหนด อาร์กิวเมนต์ที่ไม่บังคับต่อจากนั้น (`sway`, `arm`, `lean`, `leg`, `tuck` ค่าเริ่มต้น 0) ใช้ดัด
เมชตัวละคร: `sway` เอนลำตัวท่อนบน และ `arm` แกว่งแขน `mesh_free(id)` ปล่อย
รูปทรงคืน ชื่อพ้องของ `mesh_load`: zh `载入网格`, ja `メッシュ読込`, ko `메시로드`, th `โหลดเมช`

### โมเดล glTF: `gltf_*`

`gltf_load(path)` อ่านไฟล์ `.glb` หรือ `.gltf` รวมถึงโครงกระดูก สกิน และแอนิเมชัน แล้ว
คืนแฮนเดิลหรือ `-1` glTF ใช้แกน Y ชี้ขึ้น คำสั่งวาดจะพลิกให้เข้ากับโลกแบบ Y ชี้ลงของ Ling ให้เอง

| ฟังก์ชันในตัว | หน้าที่ |
|---|---|
| `gltf_load(path)` | โหลดโมเดล คืนแฮนเดิลหรือ `-1` |
| `gltf_draw(h, x, y, z, scale, yaw)` | วาดแบบรับแสงในท่าพัก |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | วาดพร้อมเท็กซ์เจอร์ ในท่าจากคลิปแอนิเมชันที่เวลา `time` วินาที |
| `gltf_anim_count(h)`, `gltf_anim_name(h, i)`, `gltf_anim_dur(h, i)` | คลิปแอนิเมชัน: จำนวน ชื่อ ความยาวเป็นวินาที |
| `gltf_bounds(h, clip, time)` | `[minx, miny, minz, maxx, maxy, maxz]` ตามที่วาด ในพิกัด glTF |
| `gltf_tris(h)` | จำนวนสามเหลี่ยม |
| `gltf_mesh_count(h)`, `gltf_mesh_name(h, i)` | เมชต่างๆ ในโมเดล |
| `gltf_mesh_show(h, i, on)` | แสดงหรือซ่อนเมชหนึ่งในการวาดครั้งต่อไป (อุปกรณ์ ชุด) |
| `gltf_mesh_tint(h, i, color)` | คูณเมชหนึ่งด้วยสีแบบรวมค่า |
| `gltf_joint_count(h)`, `gltf_joint_name(h, j)` | กระดูกของโครงกระดูก |

ใน `gltf_bounds` แกน y ชี้ขึ้น ยอดของโมเดลที่วาดที่ระดับพื้น `gy` ด้วยสเกล `s` จึงอยู่ที่
`gy - maxy * s`

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(800, 600, "โมเดล")
    ทดสอบความลึก(1)
    ผูก จิ้งจอก = gltf_load("models/fox.glb")
    ผูก คลิป = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(20, 24, 40)
        ล้างแสง()
        เพิ่มแสง(-3, -6, 2, 1.0, 1.0, 1.0, 1.0, 0)
        ถ้า จิ้งจอก >= 0 {
            ผูก ความยาว = gltf_anim_dur(จิ้งจอก, คลิป)
            gltf_anim_draw_tex(จิ้งจอก, 0, 2, 8, 0.02, เวลาปัจจุบัน(), คลิป, เวลาปัจจุบัน() % สูงสุด(ความยาว, 0.01))
        }
        แสดงผล()
    }
}
```

## เมชมีเท็กซ์เจอร์: `tm_*`

ตระกูล `tm_*` วาดรูปทรงที่มีเท็กซ์เจอร์สำหรับเกม 3 มิติ เท็กซ์เจอร์และเมชต่างก็มีแฮนเดิลของตัวเอง

| ฟังก์ชันในตัว | หน้าที่ |
|---|---|
| `tm_tex_load(path, size)` | โหลด PNG, SVG หรือ SVGZ เป็นเท็กซ์เจอร์จัตุรัสขนาด `size` พิกเซล (ค่าเริ่มต้น 256) คืน id หรือ `-1` |
| `tm_load(path)` | โหลดเมช `.ltm` (กลุ่มสามเหลี่ยมมีเท็กซ์เจอร์ที่มีชื่อ) คืน id หรือ `-1` |
| `tm_groups(m)`, `tm_group(m, name)`, `tm_group_name(m, g)`, `tm_group_tris(m, g)` | ตรวจดูกลุ่มในเมช |
| `tm_bounds(m, g)` | `[minx, miny, minz, maxx, maxy, maxz]` ของกลุ่มหนึ่ง หรือทุกกลุ่มเมื่อ `g = -1` |
| `tm_edges(m, g, max)` | ขอบรอบนอกเป็นรายการแบนของเส้น สำหรับแผนที่ย่อและโครงลวด |
| `tm_draw(m, g, tex, x, y, z, scale, rot, tint, alpha, ...)` | ใส่กลุ่มเข้าคิวเป็นสามเหลี่ยมมีเท็กซ์เจอร์ |
| `tm_sprite(tex, cx, cy, w, h, rot, tint, alpha, blend)` | สี่เหลี่ยมมีเท็กซ์เจอร์ที่หมุนได้ วาดลงจอโดยตรง |
| `tm_billboard(tex, x, y, z, size, rot, tint, alpha, blend)` | จัตุรัสมีเท็กซ์เจอร์ใน 3 มิติที่หันหากล้องเสมอ |
| `tm_quad(tex, x, y, z, ux, uy, uz, vx, vy, vz, tint, alpha, blend)` | สี่เหลี่ยมมีเท็กซ์เจอร์ในทิศใดก็ได้ (ลายแปะ) |
| `tm_wire(kind, x, y, z, size, rx, ry, rz, color, detail, thick)` | รูปทรงโครงลวด |
| `tm_solid(kind, x, y, z, size, rx, ry, rz, color, alpha, blend)` | รูปทรงคริสตัลเหลี่ยมแรเงาเรียบ |

ข้อตกลงร่วม: `tint` และ `color` เป็นตัวเลขสีแบบรวมค่า `0xRRGGBB` (ค่าเริ่มต้นสีขาว) `alpha` อยู่
ระหว่าง 0 ถึง 1 และ `blend` คือ `0` ปกติหรือ `1` แบบบวก id เท็กซ์เจอร์ `-1` หมายถึงจุดเรืองแสง
นุ่มในตัว สำหรับ `tm_quad` ค่า `-2` คือเงากลมขอบนุ่ม

- **`tm_draw`** มีอาร์กิวเมนต์ต่อด้วย `uoff, voff, uscale, vscale` (เลื่อนและย่อขยายเท็กซ์เจอร์) `shade`
  (0 ถึง 1 ทำให้ด้านที่หันหนีแสงมืดลง) `blend` และ `cull` (`0` ไม่ตัด `1` หรือ `2` ตัดตาม
  ทิศการวนแบบหนึ่ง) `rot` เป็นมุม yaw หรือรายการ 3 x 3 แบบเรียงแถว คืนจำนวนสามเหลี่ยมที่เข้าคิว
- **`tm_sprite`** วาดลงเฟรมบัฟเฟอร์ 2 มิติ ให้เรียกหลัง `flush_3d()` สำหรับ HUD หรือหน้าชื่อเรื่อง
- ชนิดของ **`tm_wire`**: `0` ลูกบาศก์ `1` ทรงสี่หน้า `2` ทรงแปดหน้า `3` ทรงยี่สิบหน้า `4` ทอรัส
  `5` ทรงกลม `6` วงแหวน `7` แท่งดาว `8` ตาราง `size` คือรัศมี `thick` 1 ทำให้เส้นหนาสองเท่า
- ชนิดของ **`tm_solid`**: `0` ลูกบาศก์ `1` ทรงสี่หน้า `2` ทรงแปดหน้า `3` ทรงยี่สิบหน้า `9` เศษคริสตัล
  (ทรงแปดหน้าที่ยืดออก)

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(800, 600, "คริสตัล")
    ผูก t = 0.0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(6, 8, 20)
        โหมดผสม(1)
        tm_wire(3, -2, 0, 8, 1, t, t * 0.7, 0, 65535, 12, 1)
        โหมดผสม(0)
        tm_solid(9, 2, 0, 8, 0.8, 0, t, 0, 16744576, 0.8, 1)
        แสดงผล()
        ผูก t = t + 0.02
    }
}
```
