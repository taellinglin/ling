# วัตถุเสียง

ฟังก์ชันในตัว `body_*` เปิดให้ใช้ `ling-body` ชุดเครื่องมือที่ปลูกผิวหนังรูปร่างมนุษย์ขึ้นจากเสียง โครงร่างของร่างกาย (รูปคนท่า T แบบพารามิเตอร์ หรือโมเดลที่นำเข้า) ถูกแปลงเป็นวอกเซลเพื่อสร้างสนามระยะทางแบบมีเครื่องหมาย แหล่งเสียงที่วางบนร่างกายจะกระตุ้นคลื่นความดันทั้งภายในและรอบร่างกาย เยื่อยืดหยุ่นบางๆ ตอบสนองต่อคลื่นนั้น แล้วพื้นผิวของเยื่อจะถูกดึงออกมาเป็นเมชสามเหลี่ยมที่ปิดสนิท (watertight)

สูตรนี้ไปกลับผ่านไฟล์ WAV ได้ WAV ที่ส่งออกเล่นเป็นเสียงได้และยังเก็บพารามิเตอร์กับเมชไว้ด้วย จึงโหลดกลับมาเป็นร่างเดิมได้ ไฟล์เสียงอื่นใดก็วิเคราะห์ออกมาเป็นพารามิเตอร์ของแหล่งเสียงได้

สิ่งที่ควรรู้:

- มีชุดเครื่องมือหนึ่งชุดต่อโปรแกรม การเรียก `body_*` ทุกครั้งทำงานกับชุดนั้น
- การทำงานที่อาจล้มเหลวจะคืน `1` เมื่อสำเร็จและ `0` เมื่อล้มเหลว และทิ้งข้อความไว้ให้อ่านด้วย `body_message()`
- ค่าที่ส่งข้ามขอบเขตเป็นตัวเลข สตริง และรายการแบน
- หน่วยเป็นเมตร เมชใช้แกน Y ชี้ขึ้น รูปคนหันไปทาง +Z และด้านซ้ายของรูปคือ +X
- ทุกอย่างยกเว้น `body_draw` และ `body_draw_creases` รันได้โดยไม่ต้องมีหน้าต่าง
- ฟังก์ชันในตัวกลุ่มนี้ไม่มีชื่อภาษาอื่น

## ร่างแรก

ตั้งพารามิเตอร์สองสามตัว เพิ่มแหล่งเสียง รันการจำลองทีละช่วง แล้วอ่านและส่งออกเมช:

```ling
ผูก เริ่ม = ทำ {
    body_param_set("sr", 8000)
    body_param_set("steps", 60)
    body_param_set("seal", 1)
    body_src_add(0.0, 1.0, 0.0, 0, 220)
    พิมพ์("ขั้น: " + str(body_sim_begin()))

    ผูก คืบหน้า = [0, 1]
    ขณะที่ คืบหน้า[0] < คืบหน้า[1] {
        ผูก คืบหน้า = body_sim_step(40)
    }
    พิมพ์("เสร็จ: " + str(body_sim_done()))
    พิมพ์("เมช: " + str(body_mesh_update()) + " " + body_message())
    ผูก จำนวน = body_mesh_counts()
    พิมพ์("ปิดสนิท: " + str(จำนวน[2]))
    พิมพ์(body_grid_info())
    พิมพ์("ส่งออก: " + str(body_export_mesh("body.obj")) + " " + body_message())
}
```

```output
ขั้น: 60
เสร็จ: 1
เมช: 1 mesh updated
ปิดสนิท: 1
109x107x75 @ 41.3 mm
ส่งออก: 1 10008 triangles → body.obj
```

ข้อความจาก `body_message()` แสดงเป็นภาษาอังกฤษ

## พารามิเตอร์

พารามิเตอร์เป็นตารางตายตัวของตัวเลขที่มีชื่อ 47 ตัว แต่ละตัวมีกลุ่ม ค่าเริ่มต้น และช่วง การตั้งค่าจะบีบให้อยู่ในช่วง `body_param_set` คืน `1` สำหรับชื่อที่รู้จัก และ `0` ในกรณีอื่น ฟังก์ชันแสดงรายการรับดัชนีตั้งแต่ 0 ถึง 46 หรือชื่อ

| กลุ่ม | ชื่อ (ค่าเริ่มต้น) | ความหมาย |
|---|---|---|
| body | `height` (1.7), `build` (1), `arm_span` (1), `head_scale` (1) | สัดส่วนโครงร่าง `height` ยังปรับขนาดโมเดลที่นำเข้าด้วย |
| body | `seal` (3) | รัศมีวอกเซลที่ใช้ปิดช่องเปิดของโมเดลที่นำเข้า |
| sim | `sr` (22050), `steps` (800), `margin` (16), `up` (2) | อัตราสุ่มตัวอย่าง จำนวนขั้นเวลา ขอบอากาศเป็นเซลล์ ความละเอียดกริดของเยื่อ |
| medium | `c_air` (343), `c_body` (1), `rho_body` (4), `damping` (0.002), `sponge` (8) | ความเร็วเสียง อัตราส่วนความเร็วและความหนาแน่นของร่างกาย การสูญเสีย ชั้นดูดซับ |
| mic | `mic_sep` (0.18), `mic_dist` (0.15) | ระยะห่างของหูและระยะหน้าใบหน้า |
| membrane | `relief`, `coupling`, `threshold`, `tension`, `stiffness`, `mem_time`, `mem_every`, `reinit_every`, `band`, `drive_mode`, `drive_tau` | ผิวหนังตามคลื่นอย่างไร |
| mesh | `smooth` (3), `decimate` (0), `iso` (0) | จำนวนรอบการทำให้เรียบ ขนาดเซลล์รวมจุดยอดเป็นเมตร ค่าชดเชยระดับพื้นผิว |
| audio | `wav_bits` (16), `wav_gain` (0.9), `wav_repeat` (4), `wav_gap` (0.25) | การส่งออก WAV |
| detail | `crease_mode`, `crease_levels`, `crease_tol`, `crease_min`, `detail_level`, `crease_depth`, `crease_width`, `noise_amp`, `noise_freq` | การตรวจหาและแกะรอยย่น |
| listen | `sig_dur`, `sig_sr`, `sig_rho`, `sig_excite` | การฟัง |

```ling
ผูก เริ่ม = ทำ {
    พิมพ์(body_param_count())
    พิมพ์(body_param_get("height"))
    พิมพ์(body_param_set("height", 5))
    พิมพ์(body_param_get("height"))
    พิมพ์(body_param_set("nope", 1))
    พิมพ์(body_joint_count())
    พิมพ์(body_joint_name(4))
}
```


## แหล่งเสียงและข้อต่อ

แหล่งเสียงคือตัวกระตุ้นในพื้นที่ ฟิลด์ได้แก่ `x`, `y`, `z` (เมตร), `wave` (`0` เวฟเล็ตริกเกอร์, `1` ไซน์เบิสต์, `2` อิมพัลส์), `freq` (Hz), `amp`, `phase`, `start` และ `dur` (วินาที)

- `body_src_add(x, y, z, wave, freq)` เพิ่มแหล่งเสียงหนึ่งตัว (ค่าเริ่มต้น 0, 1, 0, wave 0, 220 Hz) และคืนดัชนี
- `body_src_at_joint(joint, wave, freq)` เพิ่มแหล่งเสียงที่ข้อต่อตามชื่อและตั้งชื่อแหล่งเสียงตามข้อต่อนั้น คืน `-1` ถ้าไม่รู้จักข้อต่อ

โครงร่างมีข้อต่อ 21 จุด ได้แก่ `hips`, `spine`, `chest`, `neck`, `head` และแบบ `l_` / `r_` ของ `shoulder`, `elbow`, `wrist`, `hand`, `hip`, `knee`, `ankle` และ `toe` `body_joint_pos(i)` คืน `[x, y, z]` ที่ปรับตามขนาดร่างกายปัจจุบัน และ `body_joint_parent(i)` คืนดัชนีของข้อต่อแม่ (`-1` สำหรับราก)

## โมเดลที่นำเข้า

`body_model_load(path)` โหลดไฟล์ `.glb`, `.gltf`, `.lmesh` หรือ `.obj` และคืนแฮนเดิล (หรือ `-1`) การโหลดไม่ได้เลือกโมเดล ต้องเรียก `body_model_use(h)` หรือส่งแฮนเดิลติดลบเพื่อกลับไปใช้โครงร่าง ไฟล์ glTF อ่านเฉพาะรูปทรงและการแปลงของโหนด ไฟล์ที่ต้องใช้ส่วนขยายพื้นผิวจึงยังโหลดได้ ชิ้นส่วนประดับ เช่น ดอกไม้และลูกบาศก์ เริ่มต้นแบบปิด สลับชิ้นส่วนด้วย `body_model_part_set(h, i, on)`

## การจำลอง

การจำลองทำงานเป็นช่วงที่จำกัดเวลา หน้าต่างจึงอัปเดตต่อไปได้

- `body_preview()` แปลงร่างกายเป็นวอกเซลและดึงรูปร่างที่ยังไม่ถูกรบกวนออกมาโดยไม่จำลอง
- `body_sim_begin()` เริ่มการจำลองและคืนจำนวนขั้นทั้งหมด หรือ `-1`
- `body_sim_step(ms)` ทำงานราว `ms` มิลลิวินาที (ค่าเริ่มต้น 30) และคืน `[ขั้นที่ทำแล้ว, ทั้งหมด]`
- `body_mesh_update()` ดึงเยื่อในสภาพปัจจุบันออกมา เรียกขณะการจำลองกำลังทำงานได้เพื่อดูผิวหนังเติบโต
- `body_displacement()` คืน `[เข้าใน_mm, ออกนอก_mm]` `body_slice(axis, frac)` คืน `[w, h, v0, v1, ...]` ซึ่งเป็นภาพตัดของสนามความดันที่ปรับให้อยู่ใน -1..1 `body_mic_tail(n)` คืนตัวอย่างเสียง `n` ตัวล่าสุดของไมโครโฟนตัวแรก

## รอยย่นและรายละเอียด

หลังการจำลองเสร็จ `body_crease_detect()` สุ่มสนามเสียงบนเมช ไล่เส้นชั้นความสูง แล้วปรับให้เข้ากับเส้นโค้งเบซิเยร์กำลังสาม `body_crease_apply()` แบ่งเมชให้ละเอียดขึ้นและแกะร่องนุ่มๆ ตามเส้นโค้งทุกเส้น พร้อมนอยส์ละเอียดที่ถ่วงน้ำหนักด้วยสนามเสียง `body_detail_reset()` คืนเมชเรียบ `body_crease_export(path)` เขียนเส้นโค้งเป็น `.json` หรือเป็นสคริปต์ `.py` สำหรับ Blender ที่สร้างออบเจกต์เส้นโค้ง

## การฟัง

`body_listen_begin()` ยิงอิมพัลส์ด้านหน้าปากและบันทึกด้วยไมโครโฟนสองตัวข้างศีรษะ เรียก `body_listen_step(ms)` จนกว่าจะเสร็จ (คืน `[เสร็จ, ทั้งหมด]`) จากนั้น `body_listen_finish(path)` เขียน WAV ของเสียงร่างกาย และเติมข้อมูลให้ `body_listen_spectrum()` และ `body_notes()` (เรโซแนนซ์ที่แรงที่สุด)

## ไฟล์

- `body_export_mesh(path)` เขียน OBJ, STL หรือ GLB ตามนามสกุล GLB มีโครงกระดูกท่า T และน้ำหนักสกิน
- `body_export_wav(path)` เขียนสัญญาณไมโครโฟนสเตอริโอ พร้อมชังก์เพิ่มสองชังก์ที่เก็บสูตรทั้งหมดและเมชที่บีบอัด
- `body_import_wav(path, analyze_only)` กู้คืนทั้งสองชังก์ถ้ามี เมื่อ `analyze_only` เป็น 1 หรือไม่มีชังก์ จะประมาณแหล่งเสียงจากเสียงแทน และ `body_notes()` อธิบายการประมาณแต่ละรายการ รับ WAV, FLAC, Ogg และ MP3
- `body_project_save(path)` และ `body_project_load(path)` เก็บพารามิเตอร์ แหล่งเสียง และร่างที่เลือกเป็น JSON

## การวาด

`body_draw(mode, yaw, x, y, z, scale, extra)` วาดเมชที่ใช้งานด้วยสีดินสอ โดยพลิกให้เข้ากับพื้นที่ y ชี้ลงของตัวเรนเดอร์ โหมด:

| โหมด | ลักษณะ |
|---|---|
| 0 | ทึบ นอร์มอลเรียบ |
| 1 | โครงลวดของสามเหลี่ยมทุกๆ `extra` รูป |
| 2 | ย้อมสีตามการเคลื่อนของผิว `extra` คือระยะดันเต็มสเกลเป็นมิลลิเมตร (ค่าเริ่มต้น 10) |
| 3 | ลงสีตามนอร์มอลของพื้นผิว |
| 4 | แรเงาแบบดินปั้นด้วยแสงเดียว |

โหมด 3 และ 4 ช่วยให้เห็นรายละเอียดนูนต่ำได้ง่าย `body_draw_creases(yaw, x, y, z, scale)` วาดเส้นโค้งรอยย่นที่ตรวจพบทับลงไป

หน้าต่างนี้ปลูกร่างขึ้นขณะที่คุณดู:

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 480, "ร่าง")
    body_param_set("steps", 400)
    body_src_at_joint("chest", 1, 180)
    body_sim_begin()
    ผูก ทิศทาง = 0.0
    ขณะที่ หน้าต่างเปิดอยู่() {
        ถ้า body_sim_done() == 0 {
            body_sim_step(20)
            body_mesh_update()
```
