# ข้อความและรายการ

ข้อความ (สตริง) และรายการเป็นคอลเลกชันสองแบบที่ใช้กันทุกวันใน Ling หน้านี้รวบรวมฟังก์ชันในตัวสำหรับวัด ค้นหา ตัด และแปลงข้อความ
รวมถึงฟังก์ชันในตัวสำหรับสร้างและอ่านรายการ ถ้าต้องการบทนำที่ง่ายกว่านี้ ดูบทเรียน[รายการและข้อความ](../tutorials/lists-text.md)

มีกฎสองข้อที่ใช้ทั้งหน้า

- **ฟังก์ชันในตัวไม่เปลี่ยนค่าที่รับเข้ามา** แต่จะคืนค่าใหม่ ดังนั้นให้ผูกผลลัพธ์ใหม่ทุกครั้ง
  `ผูก xs = เพิ่มรายการ(xs, 5)`
- **ค่าที่ผิดแทบไม่ทำให้เกิดข้อผิดพลาด** ดัชนีที่เกินขอบเขตหรือตัวเลขที่อ่านไม่ได้จะได้ค่าสำรอง (`""` `0` `-1`)
  แทนข้อผิดพลาด แต่ละหัวข้อจะบอกว่าได้ค่าไหน

## ข้อความ

### การต่อและการแปลง

`+` ใช้ต่อข้อความ และแปลงตัวเลขที่อยู่ฝั่งใดฝั่งหนึ่งเป็นข้อความให้ `to_str` แปลงค่าใดก็ได้เป็นข้อความอย่างชัดเจน
`to_number` ไม่สนช่องว่างหัวท้าย และคืน **`0`** เมื่ออ่านไม่ได้ จึงแยก `"0"` ออกจากข้อมูลที่ผิดไม่ได้
และอ่านเลขฐานสิบหกไม่ได้ ถ้าต้องการให้ใช้ `hex_to_number`

```ling
ผูก start = ทำ {
  พิมพ์("คะแนน: " + 10)
  พิมพ์(แปลงสตริง(3) + "!")
  พิมพ์(to_number(" 42 ") + 1, " ", to_number("abc"))
  พิมพ์(hex_to_number("ff"))
}
```
```output
คะแนน: 10
3!
43 0
255
```

### `len(value)`

นับจำนวนอักขระของข้อความหรือจำนวนสมาชิกของรายการ ค่าอื่นได้ `0` รูปแบบเมธอด `"ข้อความ".len()` นับเป็น**ไบต์**
ผลจึงต่างกันเมื่อข้อความไม่ใช่ ASCII สระและวรรณยุกต์ไทยแต่ละตัวนับเป็นหนึ่งอักขระ

```ling
ผูก start = ทำ {
  พิมพ์(ความยาว("Ling"), " ", ความยาว([1, 2, 3]))
  พิมพ์(ความยาว("ไทย"), " ", "ไทย".len())
}
```
```output
4 3
3 9
```

### การค้นหา

`starts_with` `ends_with` และ `str_contains` คืน `true` หรือ `false` ส่วน `str_find` คืนดัชนีอักขระ (เริ่มที่ 0)
ของตำแหน่งแรกที่พบ หรือ `-1` ถ้าไม่พบ ใช้เมธอด `text.contains(part)` ก็ได้

```ling
ผูก start = ทำ {
  ผูก คำ = "สวัสดีครับ"
  พิมพ์(เริ่มด้วย(คำ, "สวัส"), " ", ลงท้ายด้วย(คำ, "ครับ"))
  พิมพ์(มีข้อความ(คำ, "ดีค"), " ", คำ.contains("ลาก่อน"))
  พิมพ์(หาในสตริง(คำ, "ครับ"), " ", หาในสตริง(คำ, "ค่ะ"))
}
```
```output
true true
true false
6 -1
```

### การตัดและการเปลี่ยน

`substr(text, start, length)` นับอักขระโดยเริ่มที่ 0 ถ้าไม่ใส่ `length` จะตัดไปจนสุด
ค่าที่เกินขอบเขตจะถูกปรับให้อยู่ในช่วง ไม่มีข้อผิดพลาด `str_replace` แทนที่ทุกตำแหน่งที่พบ

```ling
ผูก start = ทำ {
  พิมพ์(ส่วนสตริง("hello", 1, 3), " ", ส่วนสตริง("hello", 2))
  พิมพ์(แทนสตริง("a-b-c", "-", "+"))
  พิมพ์(ตัดช่องว่าง("   ว่าง   ") + "|")
  พิมพ์(str_upper("Ling"), " ", str_lower("LING"))
  พิมพ์(ทำซ้ำสตริง("ฮ่า", 3), " ", ตัดคำนำหน้า("v1.2", "v"))
}
```
```output
ell llo
a+b+c
ว่าง|
LING ling
ฮ่าฮ่าฮ่า 1.2
```

### `split(text, sep)`

คืนรายการของสตริง ถ้าไม่ใส่ตัวคั่น (หรือใส่ `""`) จะแยกตามบรรทัด และไม่ตัดช่องว่างให้
ตัวคั่นสองตัวติดกันจึงได้สตริงว่าง

```ling
ผูก start = ทำ {
  พิมพ์(แยก("หนึ่ง สอง สาม", " "))
  พิมพ์(แยก("a,b,,c", ","))
  พิมพ์(ความยาว(แยก("บรรทัดแรก\nบรรทัดสอง")))
}
```
```output
[หนึ่ง, สอง, สาม]
[a, b, , c]
2
```

### อักขระและแฮช

`ord` ให้โค้ดพอยต์ของอักขระตัวแรก (ข้อความว่างได้ `-1`) และ `chr` แปลงโค้ดพอยต์กลับเป็นข้อความหนึ่งอักขระ
`hash_str` และ `hash_int` ให้ค่าเดิมทุกครั้งสำหรับข้อความเดิม เหมาะกับการเลือกสีหรือแบบที่คงที่ตามชื่อ

```ling
ผูก start = ทำ {
  พิมพ์(รหัสอักขระ("A"), " ", อักขระ(97))
  พิมพ์(แฮช("แอปเปิล") == แฮช("แอปเปิล"))
  พิมพ์(แฮชจำนวน("apple", 10))
}
```
```output
65 a
true
5
```

## รายการ

### การสร้างและการอ่าน

เขียนรายการตรงๆ ได้เป็น `[1, 2, 3]` หรือเริ่มจาก `list_new()` แล้วเพิ่มสมาชิกด้วย `list_push`
อ่านสมาชิกด้วย `xs[i]` (เริ่มที่ 0) หรือ `list_get(xs, i)` ความต่างอยู่ที่กรณีเกินขอบเขต
`list_get` คืน `""` ส่วน `xs[i]` เป็นข้อผิดพลาดบนอินเทอร์พรีเตอร์ `list_set` คืนสำเนาที่แทนที่สมาชิกหนึ่งตัว และไม่สนดัชนีที่เกินขอบเขต

```ling
ผูก start = ทำ {
  ผูก ผลไม้ = รายการใหม่()
  ผูก ผลไม้ = เพิ่มรายการ(ผลไม้, "มะม่วง")
  ผูก ผลไม้ = เพิ่มรายการ(ผลไม้, "กล้วย")
  ผูก ผลไม้ = ตั้งรายการ(ผลไม้, 0, "ส้ม")
  พิมพ์(ผลไม้, " ", ความยาว(ผลไม้))
  พิมพ์(ผลไม้[1], " ", รับรายการ(ผลไม้, 0))
  พิมพ์(รับรายการ(ผลไม้, 9) == "")
}
```
```output
[ส้ม, กล้วย] 2
กล้วย ส้ม
true
```

เมธอด `xs.push(value)` ทำงานเหมือน `list_push` ต้องผูกผลลัพธ์ใหม่เสมอ อินเทอร์พรีเตอร์ไม่แก้รายการเดิม
แต่แบ็กเอนด์ปริยายอาจแก้รายการเดิมโดยตรง โปรแกรมของคุณไม่ควรพึ่งพฤติกรรมแบบใดแบบหนึ่ง

### การรวม

```ling
ผูก start = ทำ {
  พิมพ์(รวมรายการ(["ก", "ข", "ค"], ", "))
  พิมพ์(รวมรายการ([1, 2, 3], "-"))
  พิมพ์(list_cat([1, 2], [3]), " ", list_iota(4))
  พิมพ์(list_max([3, 9, 2], 0), " ", list_min([], 0 - 1))
}
```
```output
ก, ข, ค
1-2-3
[1, 2, 3] [0, 1, 2, 3]
9 -1
```

### ใช้ลูปแทน map และ filter

`list_map` `list_filter` และ `list_find` รับฟังก์ชัน แต่ฟังก์ชันที่ส่งให้ฟังก์ชันในตัวทำงานได้เฉพาะบนอินเทอร์พรีเตอร์
(`ling run --interp`) แบ็กเอนด์ปริยายจะส่ง `()` ไปแทน `list_filter` เก็บสมาชิกไว้เฉพาะเมื่อฟังก์ชันคืน `true` พอดี

```ling-module
ฟังก์ชัน คูณสอง(ตัวเลข) { list_map(ตัวเลข, |x| x * 2) }
```

ไม่มีฟังก์ชันในตัว `sort` `slice` หรือ `reverse` เช่นกัน ลูป `while` ทำได้ทั้งหมดและทำงานบนทุกแบ็กเอนด์
เวลาสะสมค่าให้ใช้ `while` แทน `for` เพราะ `bind` ในตัวลูป `for` ไม่ส่งผลถึงขอบเขตด้านนอก

```ling
ผูก start = ทำ {
  ผูก ตัวเลข = [3, 1, 2, 4]
  ผูก ผลรวม = 0
  ผูก กลับด้าน = รายการใหม่()
  ผูก i = ความยาว(ตัวเลข) - 1
  ขณะที่ i >= 0 {
    ผูก ผลรวม = ผลรวม + ตัวเลข[i]
    ผูก กลับด้าน = เพิ่มรายการ(กลับด้าน, ตัวเลข[i])
    ผูก i = i - 1
  }
  พิมพ์(ผลรวม, " ", กลับด้าน)
}
```
```output
10 [4, 2, 1, 3]
```
