# ภาพรวม

ฟังก์ชันในตัวคือฟังก์ชันที่มาพร้อมกับ Ling เช่น การพิมพ์ คณิตศาสตร์ ข้อความ ไฟล์ หน้าต่าง เสียง เว็บเซิร์ฟเวอร์ และอีกมากมาย
ส่วนนี้รวบรวมฟังก์ชันเหล่านั้นตามหัวข้อ พร้อมชื่อในแต่ละภาษา ค่าที่รับและค่าที่คืน และตัวอย่างสั้นๆ ที่รันได้ทันที

## ฟังก์ชันในตัวทำงานอย่างไร

**ใช้ได้เสมอ** ไม่ต้องนำเข้าฟังก์ชันในตัว เรียกด้วยชื่อได้จากทุกที่ในโปรแกรม

```ling
ผูก start = ทำ {
  พิมพ์(รากที่สอง(16) + สูงสุด(2, 5))
}
```
```output
9
```

**ส่งอาร์กิวเมนต์ตามตำแหน่ง** อาร์กิวเมนต์ไม่มีชื่อ ลำดับจึงสำคัญ ถ้าไม่ใส่อาร์กิวเมนต์ตัวท้าย ส่วนใหญ่จะใช้ค่าปริยายที่ระบุไว้ในเอกสาร
แทนการเกิดข้อผิดพลาด เช่น `clamp(1.5)` จะจำกัดค่าให้อยู่ในช่วง 0..1

**ความล้มเหลวก็เป็นค่า** ฟังก์ชันในตัวส่วนใหญ่แจ้งปัญหาด้วยการคืนค่าที่ตรวจสอบได้ เช่น `false` `0` `-1` รายการว่าง
หรือผลลัพธ์ `bad(...)` แต่ละหัวข้อจะบอกว่าได้ค่าไหน ฟังก์ชันในตัวที่ล้มเหลวได้หลายแบบจะคืน `ok(value)` หรือ `bad(reason)`
ดู[ข้อผิดพลาดและผลลัพธ์](../language/errors.md)

**ชื่อในห้าภาษา** ฟังก์ชันในตัวจำนวนมากมีชื่อภาษาจีน ญี่ปุ่น เกาหลี และไทย นอกจากชื่อภาษาอังกฤษ ทุกชื่อเรียกฟังก์ชันเดียวกัน
และชื่อภาษาอังกฤษใช้ได้เสมอ ในไฟล์ไหนก็ได้ ปนกับภาษาอื่นก็ได้

```ling
ผูก start = ทำ {
  print(sqrt(16))
  印(根(16))
  印刷(平方根(16))
  출력(제곱근(16))
  พิมพ์(รากที่สอง(16))
}
```
```output
4
4
4
4
4
```

`lingfu normalize --to <lang>` เขียนคำสงวนและฟังก์ชันในตัวของโปรแกรมใหม่ให้เป็นภาษาเดียว ดู[เขียนได้ห้าภาษา](../language/multilingual.md)
รันไทม์ยังรู้จักชื่อในภาษาอื่นอีกบางส่วน (ฝรั่งเศส เยอรมัน รัสเซีย อาหรับ เปอร์เซีย ฮีบรู อูรดู) แต่หน้าเหล่านี้แสดงเฉพาะห้าภาษาที่มีเอกสาร

## โปรไฟล์

`cargo install ling-lang` ติดตั้งโปรไฟล์ `full` ซึ่งมีฟังก์ชันในตัวครบทุกตัว ถ้าคุณติดตั้ง[โปรไฟล์](../getting-started/install.md)ที่เล็กกว่า
ฟังก์ชันในตัวบางกลุ่มจะไม่อยู่ในบิลด์ เมื่อเรียกฟังก์ชันเหล่านั้น โปรแกรมจะหยุดพร้อมข้อผิดพลาดที่บอกว่าต้องเพิ่มโปรไฟล์ไหน

```text
'http_get' needs the `web` profile, which this build of ling leaves out (reinstall with: cargo install ling-lang --features web, or the default full install)
```

| โปรไฟล์ | กลุ่มฟังก์ชันในตัว (ตัวอย่าง) |
|---|---|
| `core` | หน้าเอาต์พุต ข้อความ และไฟล์ (ยกเว้นโปรเซส) หน้าต่าง การวาด 2 มิติ ฟอนต์ รูปภาพ เมช |
| `web` | `http_*` `db_*` `zip_*` `tar_gz_*` `video_*` `run_process` `proc_*` แฮชและการเข้ารหัส |
| `privacy` | `p2p_*` `lingtp_*` `ssh_*` `lw_*` |
| `game` | `rb_*` `soft_*` `liquid_*` `gltf_*` `gpu_*` `body_*` `pad_*` `dialog_*` `ui_*` |
| `ai` | `nn_*` `bt_*` `stt_*` โมเดลบทสนทนาแบบเรียนรู้ |
| `audio` | `audio_*` `music_*` `mic_*` `fft_*` |

ส่วนเสริมขนาดใหญ่อย่าง `llm_*` (โมเดลภาษาในเครื่อง) และ `vision_*` ต้องเลือกเปิดเพิ่มเองบนโปรไฟล์ใดก็ได้

## วิธีอ่านหน้าเหล่านี้

หน้าอ้างอิงทุกหน้ามีโครงสร้างเหมือนกัน

1. บทนำที่อธิบายกฎซึ่งใช้กับทั้งหน้า
2. **ตารางสรุป** คอลัมน์แรกคือรูปแบบการเรียก เช่น `clamp(x, low, high)` คอลัมน์ภาษาแสดงชื่อที่แปลแล้ว
   `—` หมายความว่ายังไม่มีชื่อในภาษานั้น ให้ใช้ชื่อภาษาอังกฤษ เมื่ออ่านหน้าที่แปลแล้ว จะเห็นเฉพาะคอลัมน์ภาษาที่คุณอ่านอยู่
3. **หนึ่งหัวข้อต่อฟังก์ชันในตัวหนึ่งตัวหรือหนึ่งกลุ่ม** ได้แก่ พารามิเตอร์ ค่าที่คืน ข้อควรระวัง และตัวอย่าง

ตัวอย่างที่ระบุว่า `ling` รันด้วย `ling run` แล้ว และเอาต์พุตที่แสดงด้านล่างเป็นของจริง ตัวอย่างที่ต้องใช้หน้าต่าง เสียง เครือข่าย หรือเซิร์ฟเวอร์
ตรวจเฉพาะไวยากรณ์ จึงไม่มีบล็อกเอาต์พุต ส่วนโค้ดที่ไม่มีบล็อก `start` เป็นชิ้นส่วนของโปรแกรมที่ใหญ่กว่า

Ling มีแบ็กเอนด์สองแบบ คือแบ็กเอนด์คอมไพล์ที่เป็นค่าปริยาย และอินเทอร์พรีเตอร์ (`ling run --interp`)
จุดที่ทั้งสองทำงานต่างกัน เช่น ฟังก์ชันที่ส่งเป็นอาร์กิวเมนต์ใช้ได้เฉพาะบนอินเทอร์พรีเตอร์ หัวข้อนั้นจะบอกไว้ [ข้อจำกัดที่ทราบ](../language/limits.md)รวบรวมความต่างเหล่านี้ไว้
