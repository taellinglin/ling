## แต่ละเล่มมีอะไรบ้าง

### Learn Ling (เริ่มต้น)

ค่าและการผูก การตัดสินใจและการวนซ้ำ ฟังก์ชัน รายการและข้อความ ห้อง 3 มิติห้องแรก การวาดและเกม เสียงและดนตรี
แล้วปิดท้ายด้วยโปรเจกต์ที่ทำเสร็จสมบูรณ์

### Build with Ling (ระดับกลาง)

เรคคอร์ด (`form`) ข้อผิดพลาดและผลลัพธ์ โมดูลและโครงสร้างโปรเจกต์ ข้อมูลและไฟล์ แอป UI แอนิเมชันและอินพุต
เกมและฟิสิกส์ เครื่องมือดนตรี การทดสอบและดีบัก รวมถึงการแพ็กเกจและเผยแพร่

### Mastering Ling (ขั้นสูง)

Ling ทำงานอย่างไร การทำงานพร้อมกันและไอโซเลต เซอร์วิสเครือข่าย เว็บแอปด้วย Rust crate วิทยาการเข้ารหัส
โปรโตคอลแบบเพียร์ทูเพียร์ AI และเทนเซอร์ การใช้ crate จาก Rust การขยาย Ling ระบบ Ling OS และอุปกรณ์ฝังตัว
และการออกแบบแอปขนาดใหญ่

### The Ling Reference

คำสงวนและฟังก์ชันในตัวทุกตัว พร้อมพารามิเตอร์ ค่าที่คืน ชื่อแทน และตัวอย่าง บทสุดท้ายรวบรวมข้อจำกัดที่ทราบและจุดที่ต้องระวัง

## ควรอ่านเล่มไหน

- **เพิ่งเริ่มเขียนโปรแกรม หรือเพิ่งรู้จัก Ling:** เริ่มจาก *Learn Ling*
- **จะสร้างโปรแกรมจริงจัง:** อ่าน *Build with Ling*
- **อยากเจาะลึก:** อ่าน *Mastering Ling*
- **ต้องการค้นหาข้อมูล:** เปิด *The Ling Reference* ไว้ใกล้ตัว

เอกสารนี้เป็นคู่มือออนไลน์ฉบับย่อ ส่วนหนังสือลงรายละเอียดมากกว่าและอ้างอิง Ling เวอร์ชันเดียว ถ้าต้องการค้นหาอย่างรวดเร็ว
