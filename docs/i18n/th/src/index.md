# บทนำ

Ling เป็นภาษาโปรแกรมที่คุณเขียนด้วยภาษาของตัวเองได้ คำสงวนและฟังก์ชันในตัวมีชื่อในภาษามนุษย์มากกว่า 16 ภาษา
เช่น จีน ญี่ปุ่น เกาหลี ไทย อังกฤษ อาหรับ ฮีบรู และรัสเซีย และใช้ปนกันในไฟล์เดียวได้ เอกสารนี้ครอบคลุมห้าภาษา
ได้แก่ English, 中文, 日本語, 한국어 และ ไทย เลือกภาษาได้จากตัวเลือกภาษาด้านบนของหน้า

คู่มือนี้อ้างอิง Ling 2030.1.53

## ทำความรู้จักครั้งแรก

ลองดูโปรแกรมเล็ก ๆ นี้ ทุกโปรแกรมเริ่มต้นที่ `ผูก เริ่ม = ทำ { ... }`

```ling
# ทักทายเพื่อนๆ
ผูก เริ่ม = ทำ {
    ผูก เพื่อน = ["สมชาย", "มะลิ", "ต้น"]
    สำหรับ ชื่อ ใน เพื่อน {
        พิมพ์("สวัสดี " + ชื่อ + "!")
    }
    พิมพ์(ความยาว(เพื่อน))
}
```

```output
สวัสดี สมชาย!
สวัสดี มะลิ!
สวัสดี ต้น!
3
```

โปรแกรมเดียวกันนี้เขียนด้วยคำสงวนภาษาอังกฤษ จีน ญี่ปุ่น หรือเกาหลีก็ได้ ลองเปลี่ยนภาษาของหน้าดู หรืออ่าน
[เขียนได้ห้าภาษา](language/multilingual.md)

## สิ่งที่คุณได้

ในโปรแกรม `ling` ตัวเดียวมี:

- **คอมไพเลอร์ JIT และอินเทอร์พรีเตอร์** โปรแกรมถูกคอมไพล์เป็นโค้ดเนทีฟผ่าน Cranelift และส่วนที่เหลือทำงานด้วยอินเทอร์พรีเตอร์
- **กราฟิกและ 3 มิติ** หน้าต่าง การวาด 2 มิติ รูปภาพ ฟอนต์ และตัวเรนเดอร์ 3 มิติแบบซอฟต์แวร์ที่มีกล้อง แสง การแรเงาแบบเซล และเรขาคณิตเวกเตอร์ (`vtex_*`)
- **เสียงและดนตรี** เสียงโทน เสียงเชิงพื้นที่ การเล่นไฟล์ WAV การถอดรหัสเพลง การวิเคราะห์ BPM และคีย์ ซินธ์แบบ GM และ MIDI
- **ฟิสิกส์** วัตถุแข็งเกร็ง วัตถุนิ่ม และการจำลองของเหลว
- **UI** HUD มาตรวัด ปุ่ม และวิดเจ็ตอื่น ๆ
- **เว็บเซิร์ฟเวอร์** เส้นทาง ไฟล์สแตติก และ SQLite ผ่านฟังก์ชันในตัว `http_*` และ `db_*`
- **วิทยาการเข้ารหัส** แฮช การเข้ารหัส ลายเซ็น และการแลกเปลี่ยนกุญแจแบบหลังควอนตัม
- **AI** โครงข่ายประสาทเทียม ต้นไม้พฤติกรรม และการรองรับโมเดลภาษาแบบเลือกติดตั้งได้

`lingfu` เครื่องมือจัดการโปรเจกต์ ใช้สร้าง รัน และทดสอบโปรเจกต์ ส่วน `lingfu normalize` จะเขียนโปรเจกต์ทั้งหมดใหม่ให้เป็นภาษาเดียว

## การติดตั้ง

บน macOS หรือ Linux:

```sh
curl --proto '=https' --tlsv1.2 -sSf https://ling-lang.org/install.sh | sh
```

บน Windows (PowerShell):

```powershell
irm https://ling-lang.org/install.ps1 | iex
```

ถ้ายังไม่มี Rust สคริปต์จะติดตั้ง Rust ให้ก่อน แล้วจึงบิลด์ `ling` และ `lingfu` ดูวิธีอื่นและโปรไฟล์การติดตั้งได้ที่
[การติดตั้ง](getting-started/install.md)
