# ผลงานตัวอย่าง

แอปและเดโมเหล่านี้เขียนด้วย Ling และทำงานบนรันไทม์ของ Ling ดูภาพหน้าจอของแอปได้ที่เว็บไซต์
[ling-lang.org/#apps](https://ling-lang.org/#apps)

## แอป

| แอป | คืออะไร |
|---|---|
| **LingStationX** | เวิร์กสเตชันเสียงดิจิทัล มีหน้าจัดเรียงเพลง เปียโนโรล แทร็กเกอร์ มุมมองเซสชัน แพตเชอร์แบบกราฟโหนด มิกเซอร์ และซินธ์ Nova, Prism และ Growl นำเข้า MIDI ได้ และมีตัวตัดเสียง การยืดเวลา และสายการมาสเตอร์ |
| **LingDev** | โปรแกรมแก้ไขเกม 3 มิติที่มีต้นไม้โหนด ไทม์ไลน์ และแทร็กคัตซีนสำหรับกล้อง บทสนทนา และเอฟเฟกต์ เกมที่สร้างด้วยโปรแกรมนี้ได้แก่ Dance Ling, Ling Hazard, Ling Breaker, Moko, Ling Agent และซีรีส์ Soul Symphony |
| **LingModeler** | การขึ้นโมเดล การใส่โครงกระดูก การระบายน้ำหนัก การจัดท่า และแอนิเมชัน รวมถึงภาพประกอบเวกเตอร์ แอนิเมชัน 2 มิติแบบออเนียนสกิน และเท็กซ์เจอร์เชิงกระบวนการ ทำงานภายใน LingOS บน x86-64 และ Raspberry Pi ได้ด้วย |
| **LingForFun** | เกม RPG แอ็กชันออนไลน์ที่มีแผนที่โลก เมือง ดันเจียน การบิน การต่อสู้ และภารกิจ มีไคลเอนต์เดสก์ท็อป ไคลเอนต์เบราว์เซอร์แบบ WASM และกลุ่มเซิร์ฟเวอร์ ทั้งหมดเขียนด้วย Ling โดยใช้คำสงวนภาษาจีน กำลังพัฒนาอยู่ |
| **Ling Arcade** | คลังเกมคอนโซลที่มีอีมูเลเตอร์ NES เขียนด้วย Ling ทั้ง CPU 6502, PPU, แมปเปอร์ และ APU เป็นโค้ด `.ling` ธรรมดาที่รันบน JIT ของ Ling ผ่านล็อก nestest ครบทั้งหมด (8,991 คำสั่ง แม่นยำระดับไซเคิล) |
| **Ling Wallet** | กระเป๋าเงินด้านความเป็นส่วนตัวแบบหลังควอนตัมสำหรับ LNG ที่เป็นทั้งฟูลโหนดและเครื่องขุด ใช้ตัวตนแบบ ML-DSA-87 และการแลกเปลี่ยนกุญแจแบบผสม ML-KEM-1024 + X25519 ยังเป็นรุ่นทดลองและยังไม่ผ่านการตรวจสอบความปลอดภัย |

## โปรเจกต์จากชุมชน

| โปรเจกต์ | คืออะไร |
|---|---|
| [**Soul Symphony**](https://github.com/taellinglin/soul-symphony-ling-edition) | เกมฟิสิกส์แนวอาร์เคดผสม RPG กลิ้งลูกแก้วผ่านด่านที่สร้างแบบเชิงกระบวนการ 9 ด่าน และสู้กับบอสหลังจบแต่ละด่าน มีโหมดประลองแบบอาร์เคด เล่นผ่านเครือข่าย และเล่นร่วมกัน รองรับ 5 ภาษา |
| [**LingSoul**](https://github.com/taellinglin/LingSoul) | เกมจำลองการรักษาสมดุลของวิญญาณที่ให้บรรยากาศ วาดในสไตล์โครงลวดของ Ling และใช้ตัวอักษรที่ประดิษฐ์ขึ้นเองบน HUD ในเกม |

## เดโมในรีโพซิทอรี

[รีโพซิทอรีของ Ling](https://github.com/taellinglin/ling) มีตัวอย่างที่รันได้ทันทีอยู่มากมาย ลองเริ่มจากตัวเหล่านี้

| เดโม | สิ่งที่แสดง |
|---|---|
| `examples/music/hallway_runner.ling` | เกมวิ่งไม่รู้จบที่ตอบสนองต่อเพลง เหรียญเล่นทำนองเป็นเสียงเชิงพื้นที่ |
| `examples/music/karaoke_hero.ling` | แถบระดับเสียงคาราโอเกะจาก MIDI เสียงร้อง พร้อมตัวตั้งเสียงจากไมโครโฟนแบบสด |
| `examples/music/synth_jam.ling` | เครื่องดนตรี GM ที่สังเคราะห์จากแพตช์ `.ling` |
| `examples/physics/bouncy_ball.ling` | วัตถุนิ่มแบบมวลและสปริงที่บี้ตัวเมื่อเด้ง |
| `examples/physics/tumbling.ling` | วัตถุแข็งเกร็งที่หมุนคว้างและกลิ้ง |
| `examples/physics/liquid_marble.ling` | การจำลองน้ำและน้ำมันบนทรงกลม กรวย และโดมที่หมุนอยู่ |
| `examples/ui/hud_showcase.ling` | ชุดเครื่องมือ UI: HUD มาตรวัด ตัวควบคุม และวิดเจ็ตสำหรับเกม |
| `examples/crypto/crypto_donut_physics.ling` | ปมทอรัสที่เด้งได้ซึ่งรูปร่างมาจากแฮช SHA3 พร้อมเสียงที่ตอบสนอง |

รันสักตัวจากโฟลเดอร์รากของรีโพซิทอรี:

```sh
ling run examples/physics/liquid_marble.ling
```

ส่วน[ตัวอย่าง](examples/dao-chamber.md)ของเอกสารนี้อธิบายฉาก 3 มิติสี่ฉากอย่างละเอียดขึ้น
