# การแปลงแอสเซต

`ling convert` แปลงแอสเซตภายนอก (โมเดล 3 มิติ เสียง เพลง MIDI หรือภาพวาด SVG) ให้เป็นไฟล์ `.ling` ที่ใช้งานได้ในตัวเอง
เมื่อ `ใช้` ไฟล์นั้นในโปรแกรม มันจะสร้างแอสเซตขึ้นใหม่ด้วยฟังก์ชันในตัวของ Ling เอง
ขณะรันไม่ต้องมีตัวโหลดหรือไฟล์ต้นฉบับ

```sh
ling convert model.glb                  # เขียน model.ling (บีบอัด ไม่สูญเสียข้อมูล)
ling convert sfx.wav -o sfx.ling        # เลือกไฟล์ผลลัพธ์เอง
ling convert logo.svg --no-compression  # อาร์เรย์ธรรมดาที่อ่านและเทียบความต่างได้
lingfu convert song.mid                 # lingfu ส่งต่อให้ ling convert
```

| ตัวเลือก | ความหมาย |
|---|---|
| `-o <out.ling>` (หรือ `--out`) | ไฟล์ผลลัพธ์ ค่าเริ่มต้นคือชื่อไฟล์ต้นทางที่เปลี่ยนนามสกุลเป็น `.ling` |
| `--no-compression` | เขียนตัวเลขเป็นรายการธรรมดาแทนก้อนข้อมูลที่บีบอัด |

## แต่ละรูปแบบกลายเป็นอะไร

| ไฟล์ต้นทาง | การผูกที่สร้างขึ้น | โปรไฟล์ |
|---|---|---|
| `.gltf`, `.glb` | ต่อเมช: `<name>_<mesh>_pos`, `_nrm`, `_uv`, `_idx` และฟังก์ชันวาดโครงลวด `draw_<name>_<mesh>(ox, oy, oz, scale)` ส่วน `draw_<name>(ox, oy, oz, scale)` วาดทั้งโมเดล ชื่อโหนดและการแปลงเก็บไว้เป็นคอมเมนต์ | `game` |
| `.wav`, `.ogg`, `.flac`, `.mp3` | `<name>_pcm` (ตัวอย่างเสียงโมโน), `<name>_rate`, `<name>_dur` | `audio` |
| `.mid`, `.midi` | `<name>_notes` รายการแบนที่มี `[time, dur, midi, vel, channel]` ต่อโน้ต และ `<name>_dur` | `audio` |
| `.svg` | `<name>_xy` (จุด), `<name>_lens` (จำนวนจุดต่อเส้นหลายส่วน) และ `draw_<name>(ox, oy, scale)` | ใดก็ได้ |
| `.blend` | ให้ Blender ส่งออกเป็น glTF ก่อน แล้วแปลงเหมือน `.glb` ต้องมี Blender ใน `PATH` หรือใน `$BLENDER` | `game` |

`<name>` คือชื่อไฟล์ต้นทางที่ปรับให้เป็นชื่อที่ใช้ได้ในโค้ด สำหรับ SVG ข้อมูล `<path>` (`M`, `L`, `H`, `V`, `C`, `Q`, `Z`)
และอิลิเมนต์ `<line>`, `<rect>`, `<polyline>`, `<polygon>` จะถูกแปลงเป็นเส้นหลายส่วน
นามสกุลอื่นจะล้มเหลวด้วย `unsupported extension`

## บีบอัดหรือไม่บีบอัด

โดยค่าเริ่มต้น รายการตัวเลขยาว ๆ จะเก็บแบบไม่สูญเสียข้อมูลเป็นข้อความที่บีบอัดด้วย zlib และเข้ารหัส base64
ถอดกลับด้วยฟังก์ชันในตัวสองตัว:

- `blob_f32("...")` ถอดเป็นรายการตัวเลข (ทศนิยม 32 บิตแบบ little-endian)
- `blob_i32("...")` ถอดเป็นรายการจำนวนเต็ม (จำนวนเต็ม 32 บิต) ใช้กับดัชนีและความยาว

`--no-compression` เขียนตัวเลขชุดเดียวกันเป็นรายการ `[ ... ]` ตรง ๆ ไฟล์ใหญ่กว่าแต่อ่านง่าย
รายการที่มีตัวเลขไม่เกินแปดตัวจะเขียนแบบธรรมดาเสมอ

## ตัวอย่าง: SVG

สมมติว่ามี `logo.svg` เล็ก ๆ ที่มี `<rect>` หนึ่งอันและ `<path>` หนึ่งอัน:

```text
$ ling convert logo.svg
[convert] logo.svg → logo.ling  (1 KB, deflate+base64 lossless)
```

ไฟล์ `logo.ling` ที่สร้างขึ้นเริ่มต้นแบบนี้:

```ling-module
# 2 polylines, 7 points
bind logo_xy = blob_f32("eNpdibENAAAIgzjFV/RmDzTRwaYDAwCRLF2Huvf/A/L0CM0=")
bind logo_lens = [2, 5]
```

ตามด้วยฟังก์ชัน `draw_logo(ox, oy, scale)` นำไปใช้ในโปรแกรมได้แบบนี้:

```ling-gui
ใช้ "logo.ling"

ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(400, 400, "โลโก้")
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(0, 0, 0)
        สีดินสอ(255, 255, 255)
        draw_logo(100, 100, 2.0)
        แสดงผล()
    }
}
```

## หมายเหตุ

- เสียงเก็บเป็นการมิกซ์ลงโมโนที่อัตราสุ่มของต้นฉบับ ไฟล์ที่สร้างเก็บแค่ตัวอย่างเสียง การเล่นหรือวิเคราะห์เป็นหน้าที่ของโปรแกรมคุณ
- โค้ดที่สร้างขึ้นใช้คำสงวนภาษาไทย (`ฟังก์ชัน`) สำหรับฟังก์ชัน และใช้ `bind` สำหรับการผูก ซึ่งเป็นเรื่องปกติ
  เพราะทุกภาษาใช้ได้ในทุกไฟล์
- ฟังก์ชันวาดของโมเดลวาดโครงลวดด้วย `draw_line_3d` ถ้าต้องการเมชทึบที่มีพื้นผิว ดู[รูปทรงและเมช 3 มิติ](../reference/shapes.md)
