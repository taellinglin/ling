# ห้อง 3 มิติห้องแรก

ได้เวลาออกจากเทอร์มินัลแล้ว ในหน้านี้คุณจะเปิดหน้าต่าง เรียนรู้ลูปเฟรมที่ขับเคลื่อนภาพทุกภาพใน Ling
และสร้างห้อง 3 มิติเล็ก ๆ ที่เดินไปมาได้ด้วยปุ่มลูกศร Ling วาดทุกอย่างด้วยตัวเรนเดอร์แบบซอฟต์แวร์ในตัว
คุณจึงไม่ต้องใช้เกมเอนจินหรือ GPU

โปรแกรมที่เปิดหน้าต่างตรวจสอบในเทอร์มินัลไม่ได้ บล็อกโค้ดของโปรแกรมเหล่านี้จึงไม่มีเอาต์พุต
กด **Escape** หรือปิดหน้าต่างเพื่อหยุดโปรแกรม

## ลูปเฟรม

หน้าต่างแสดงภาพนิ่งทีละภาพ (หนึ่งเฟรม) โปรแกรมวาดหนึ่งเฟรม แสดงผล แล้วเริ่มเฟรมถัดไป
โปรแกรมกราฟิกทุกโปรแกรมมีจังหวะเดียวกัน:

1. **เปิด**หน้าต่าง ครั้งเดียว
2. **ล้าง**ภาพด้วย `เติม` เพื่อไม่ให้เฟรมก่อนหน้าค้างอยู่
3. **วาด**รูปทรงต่าง ๆ
4. **แสดง**เฟรมด้วย `แสดงผล()`

ลูปทำงานด้วย `ขณะที่ หน้าต่างเปิดอยู่()` ซึ่งจะกลายเป็นเท็จเมื่อปิดหน้าต่างหรือกด Escape
คุณจึงไม่ต้องเขียนโค้ดออกจากโปรแกรมเอง

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 400, "หน้าต่างแรกของฉัน")
    ผูก มุม = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(15, 18, 40)
        สีดินสอ(255, 120, 60)
        ลูกบาศก์(0, 0, 3, 1, 1, 1, มุม, มุม * 0.7, 0, 0)
        แสดงผล()
        ผูก มุม = มุม + 0.02
    }
}
```

- `เปิดหน้าต่าง(640, 400, "หน้าต่างแรกของฉัน")` เปิดหน้าต่างขนาด 640 x 400 ใส่ขนาดก่อน แล้วจึงใส่ชื่อหน้าต่าง
- `เติม(15, 18, 40)` ระบายสีทั้งหน้าต่าง สีกำหนดด้วยค่าแดง เขียว น้ำเงิน ตั้งแต่ 0 ถึง 255
- `สีดินสอ(...)` เลือกสีของรูปทรงที่จะวาดต่อจากนี้
- `ลูกบาศก์(...)` วาดลูกบาศก์ อาร์กิวเมนต์มาเป็นกลุ่มละสามตัว: จุดศูนย์กลาง `x, y, z` ขนาด
  การหมุนเป็นเรเดียน และสุดท้ายคือโหมด (`0` ทึบ `1` โครงลวด `2` ทั้งสองแบบ)
- `แสดงผล()` แสดงเฟรม ถ้าไม่เรียกจะไม่เห็นอะไรเลย
- การผูก `มุม` ใหม่ทุกเฟรมทำให้ลูกบาศก์หมุน

## สิ่งต่าง ๆ อยู่ตรงไหน

ในโลก 3 มิติของ Ling แกน **x** ชี้ไปทางขวา แกน **y** ชี้**ลง** และแกน **z** ชี้เข้าไปในจอ ห่างออกจากตัวคุณ
ดังนั้น "ขึ้น" คือ y ติดลบ ในห้องด้านล่าง พื้นอยู่ที่ `y = 3` และเพดานอยู่ที่ `y = -3`

กล้องอยู่ที่จุดกำเนิดและมองไปตามแกน z มีสามคำสั่งที่เปลี่ยนสิ่งที่กล้องเห็น:

| คำสั่ง | หน้าที่ |
|---|---|
| `ตั้งตำแหน่งกล้อง(x, y, z)` | ย้ายกล้อง |
| `ตั้งกล้อง(cos_yaw, sin_yaw, cos_pitch, sin_pitch)` | หมุนกล้อง โดยส่งค่าโคไซน์และไซน์ของแต่ละมุม ถ้าจะหมุนไป `a` ให้เรียก `ตั้งกล้อง(โคไซน์(a), ไซน์(a), 1, 0)` |
| `ตั้งระยะห่าง(d)` | ระยะที่ตาอยู่หลังภาพ ค่าเล็ก ๆ อย่าง `0.5` เหมาะกับมุมมองบุคคลที่หนึ่ง |

เรียกฟังก์ชันกล้องทุกเฟรมก่อนวาด

## ห้องที่เดินไปมาได้

โปรแกรมนี้รวมทุกอย่างเข้าด้วยกัน: พื้นและเพดานที่ทำจากตาราง ผนังสี่ด้าน เสาสี่ต้น ไฟหนึ่งดวง
ของตกแต่งตรงกลางที่หมุนได้ และการควบคุมด้วยคีย์บอร์ด บันทึกเป็นไฟล์ `room.ling`

```ling-gui
# ห้องที่เดินไปมาได้
# ลูกศรซ้าย/ขวาเพื่อหมุน ลูกศรขึ้น/ลงเพื่อเดิน กด Escape เพื่อออก

ฟังก์ชัน เสา(x, z) {
    สีดินสอ(200, 190, 170)
    ทรงกระบอก(x, 0, z, 0.5, 3, 0.5, 0, 0, 0, 0)
}

ฟังก์ชัน ผนัง(เฟรม) {
    # พื้นและเพดาน (แกน y ชี้ลง พื้นจึงอยู่ที่ y = 3)
    ลายตาราง(0, 3, 0,   1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  เฟรม, 0)
    ลายตาราง(0, -3, 0,  1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  เฟรม, 2)
    # ผนังตั้งสี่ด้าน
    ลายตาราง(0, 0, 8,   1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  เฟรม, 1)
    ลายตาราง(0, 0, -8,  1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  เฟรม, 1)
    ลายตาราง(-8, 0, 0,  0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  เฟรม, 3)
    ลายตาราง(8, 0, 0,   0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  เฟรม, 3)
    # ดอกไม้บนผนังด้านไกล
    ลายดอกไม้(0, 0, 7.9,  1, 0, 0,  0, -1, 0,  1.6, 24,  เฟรม, 0)
}

ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(960, 600, "ห้อง 3 มิติของฉัน")
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    ตั้งแสงรอบข้าง(0.3)

    ผูก ตำแหน่งx = 0
    ผูก ตำแหน่งz = -5
    ผูก ทิศ = 0
    ผูก เฟรม = 0

    ขณะที่ หน้าต่างเปิดอยู่() {
        # รับคำสั่ง: หมุนและเดิน
        ถ้า กดค้าง("left") {
            ผูก ทิศ = ทิศ - 0.03
        }
        ถ้า กดค้าง("right") {
            ผูก ทิศ = ทิศ + 0.03
        }
        ถ้า กดค้าง("up") {
            ผูก ตำแหน่งx = ตำแหน่งx + ไซน์(ทิศ) * 0.1
            ผูก ตำแหน่งz = ตำแหน่งz + โคไซน์(ทิศ) * 0.1
        }
        ถ้า กดค้าง("down") {
            ผูก ตำแหน่งx = ตำแหน่งx - ไซน์(ทิศ) * 0.1
            ผูก ตำแหน่งz = ตำแหน่งz - โคไซน์(ทิศ) * 0.1
        }

        # วาด
        เติม(8, 8, 20)
        ตั้งกล้อง(โคไซน์(ทิศ), ไซน์(ทิศ), 1, 0)
        ตั้งตำแหน่งกล้อง(ตำแหน่งx, 0, ตำแหน่งz)
        ตั้งระยะห่าง(0.5)
        ล้างแสง()
        เพิ่มแสง(0, -2.5, 0, 1.0, 0.85, 0.6, 1.0, 14)

        ผนัง(เฟรม * 0.3)
        เสา(-6, -6)
        เสา(6, -6)
        เสา(-6, 6)
        เสา(6, 6)

        สีดินสอ(240, 200, 80)
        ทอรัส(0, 1.5, 0, 0.7, 0.7, 0.7, 1.2, เฟรม * 0.03, 0)

        แสดงผล()
        ผูก เฟรม = เฟรม + 1
    }
}
```

รันโปรแกรม:

```sh
ling run room.ling
```

การทำงาน:

- `เสา` และ `ผนัง` เป็นฟังก์ชันที่วาดส่วนต่าง ๆ ของห้อง ถูกเรียกภายในลูป จึงวาดใหม่ทุกเฟรม
  `ผนัง` รับ `เฟรม` เป็นพารามิเตอร์ เพราะฟังก์ชันมองเห็นเฉพาะพารามิเตอร์ของตัวเองและชื่อระดับบนสุดเท่านั้น
- สี่บรรทัดหลัง `เปิดหน้าต่าง` เปลี่ยนเป็นสีที่นุ่มนวลและตรงตามจริง ถ้าไม่มีบรรทัดเหล่านี้
  รูปแบบเริ่มต้นของ Ling จะย้อมเงาเป็นสีคราม และเพิ่มขอบเรืองแสง
- `ตำแหน่งx` `ตำแหน่งz` และ `ทิศ` เก็บตำแหน่งและทิศทางของกล้อง `กดค้าง("left")` เป็นจริงขณะกดปุ่มค้างไว้
  การเดินจะขยับ `ไซน์(ทิศ)` ตามแกน x และ `โคไซน์(ทิศ)` ตามแกน z ซึ่งเป็นทิศที่คุณหันหน้าไป
- `ล้างแสง()` และ `เพิ่มแสง(x, y, z, r, g, b, ความเข้ม, รัศมี)` ต้องเรียกทุกเฟรม ไม่เช่นนั้นแสงจะสะสมเพิ่มขึ้นเรื่อย ๆ
  โคมไฟอยู่ที่ `y = -2.5` ใกล้เพดาน
- `ลายตาราง` และ `ลายดอกไม้` วาดลวดลายเส้นบนแผ่นระนาบ ตัวเลขสามตัวแรกคือจุดศูนย์กลาง
  อีกหกตัวถัดไปคือทิศ "ขวา" และ "ขึ้น" ของแผ่น สำหรับผนังตั้ง ทิศ "ขึ้น" คือ `0, -1, 0` เพราะแกน y ชี้ลง

ผนังเป็นแค่ภาพที่วาดขึ้น ไม่ใช่ของแข็ง คุณเดินทะลุผ่านได้เลย

## ลองทำดู

- เปลี่ยนตัวเลขตัวสุดท้ายของแต่ละ `ลายตาราง` (ค่าเฉดสี) เพื่อให้ได้สีอื่น
- เพิ่มเสาต้นที่ห้า หรือเพิ่ม `เพิ่มแสง` อีกดวงที่สีต่างกัน
- เพิ่ม `ถ้า กดปุ่ม("p") { screenshot("room") }` หลัง `แสดงผล()` เมื่อกด P จะบันทึกไฟล์ PNG
  ไว้ในโฟลเดอร์ `screenshots`
