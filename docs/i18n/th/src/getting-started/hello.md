# สวัสดีชาวโลก

โปรแกรม Ling ทุกโปรแกรมเริ่มที่การผูกจุดเริ่มต้น ซึ่งมีค่าเป็นบล็อก `ทำ` ในภาษาไทยชื่อจุดเริ่มต้นคือ `เริ่ม`
นี่คือโปรแกรมที่เล็กที่สุดที่พิมพ์ข้อความออกมาได้

## โปรแกรมแรกของคุณ

บันทึกโค้ดนี้เป็นไฟล์ `hello.ling`:

```ling
ผูก เริ่ม = ทำ {
    พิมพ์("สวัสดีชาวโลก")
}
```
```output
สวัสดีชาวโลก
```

รันโปรแกรม:

```sh
ling run hello.ling
```

- `ผูก เริ่ม = ...` ตั้งชื่อ `เริ่ม` ให้กับค่าหนึ่ง Ling ใช้ชื่อนี้หาว่าโปรแกรมเริ่มที่ไหน
  (ภาษาอังกฤษเขียนว่า `start`)
- `ทำ { ... }` คือบล็อกของขั้นตอนที่ทำงานตามลำดับ
- `พิมพ์(...)` เขียนข้อความหนึ่งบรรทัดออกทางเทอร์มินัล

## เพิ่มอีกนิด

การผูกเขียนไว้นอก `เริ่ม` ก็ได้ โปรแกรมนี้ทักทายชื่อหนึ่ง แล้ววนลูปไปตามรายการ:

```ling
# ทักทายเพื่อนสองสามคน
ผูก ชื่อ = "ลิง"
ผูก เริ่ม = ทำ {
    พิมพ์("สวัสดี " + ชื่อ + "!")
    สำหรับ เพื่อน ใน ["สมชาย", "มะลิ", "นก"] {
        พิมพ์("หวัดดี " + เพื่อน)
    }
}
```
```output
สวัสดี ลิง!
หวัดดี สมชาย
หวัดดี มะลิ
หวัดดี นก
```

`+` ใช้ต่อข้อความ และ `สำหรับ ... ใน` จะรันบล็อกหนึ่งครั้งต่อสมาชิกแต่ละตัวในรายการ

เมื่อรันโปรแกรมภาษาไทย `ling` จะแจ้งภาษาที่ตรวจพบทางเอาต์พุตข้อผิดพลาดมาตรฐาน เช่น
`[detected language: Thai (ภาษาไทย)]` ซึ่งไม่มีผลต่อการทำงานของโปรแกรม

## ผสมหลายภาษา

คำสงวนและฟังก์ชันในตัวทุกตัวมีชื่อทั้งภาษาอังกฤษ จีน ญี่ปุ่น เกาหลี และไทย และใช้ปนกันในไฟล์เดียวได้อย่างอิสระ
โปรแกรมนี้ใช้ครบทั้งห้าภาษา:

```ling
令 名字 = "Ling"
bind start = do {
    พิมพ์("สวัสดี " + 名字)
    만약 참 {
        印刷("こんにちは")
    }
}
```
```output
สวัสดี Ling
こんにちは
```

ถ้าอยากรู้ว่าห้าภาษาทำงานร่วมกันอย่างไร อ่าน[เขียนได้ห้าภาษา](../language/multilingual.md)
