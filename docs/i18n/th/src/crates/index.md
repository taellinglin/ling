# ภาพรวม Crate

Ling เขียนด้วย Rust และแบ่งเป็นเวิร์กสเปซที่มีหลาย crate crate หลักคือ `ling-lang` ซึ่งมีส่วนหน้าของคอมไพเลอร์
อินเทอร์พรีเตอร์ ตัวขับ JIT และคำสั่ง `ling` ส่วน crate ด้านล่างให้ชิ้นส่วนของภาษาและไลบรารีของฟังก์ชันในตัว
คุณต้องใช้หน้านี้ก็ต่อเมื่ออยากใช้ crate เหล่านี้จากโค้ด Rust ของคุณเอง หรืออยากรู้ว่า crate ไหนอยู่เบื้องหลังฟังก์ชันในตัวตัวไหน

เวอร์ชันด้านล่างคือเวอร์ชันใน repository ขณะที่เขียน crate ส่วนใหญ่ใช้เลขเวอร์ชันแบบ `2030.x` ของ Ling
ส่วน `ling-http` และ `ling-web` มีเลขเวอร์ชันของตัวเอง

## crate หลัก

| Crate | เวอร์ชัน | คืออะไร |
|---|---|---|
| `ling-lang` | 2030.1.53 | ตัวภาษา: ตัวแยกคำ ตัวแจงไวยากรณ์ อินเทอร์พรีเตอร์ Cranelift JIT และ AOT และฟังก์ชันในตัว ชื่อไลบรารีคือ `ling` ไฟล์โปรแกรมคือ `ling`, `lingc`, `lx`, `ling-repl` |
| `lingfu` (`crates/ling-fu`) | 2030.1.19 | ตัวจัดการโปรเจกต์: `lingfu new`, `run`, `build`, `normalize` และอื่น ๆ ดู [lingfu](../tools/lingfu.md) |

## โปรไฟล์ไหนดึง crate ไหนเข้ามา

[โปรไฟล์การติดตั้ง](../getting-started/install.md)กำหนดว่า crate ใดบ้างจะถูกคอมไพล์รวมเข้าไปใน `ling`:

| โปรไฟล์ | Crate |
|---|---|
| `web` | `ling-http`, `ling-crypto`, `ling-icon`, `lingfu` |
| `privacy` | `web` และเพิ่ม `ling-net`, `ling-ui` |
| `game` | `ling-physics`, `ling-gpu`, `ling-game`, `ling-animation`, `ling-input`, `ling-body`, `ling-ui`, `ling-icon` |
| `ai` | `ling-ai`, `ling-music` |
| `audio` | `ling-audio`, `ling-music`, `ling-mic`, `ling-daw` |
| `art` (อยู่ใน `full`) | `ling-paint` |
