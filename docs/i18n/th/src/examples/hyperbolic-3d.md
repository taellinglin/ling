# ไฮเพอร์โบลิก 3 มิติ

ซอร์ส: [`examples/physics/hyperbolic3d.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic3d.ling)

แม้จะมีชื่อไฟล์แบบนี้ แต่เดโมเวอร์ชันปัจจุบันเป็นเขาวงกตฟิสิกส์ในปริภูมิ 3 มิติแบบปกติ (ยุคลิด) คุณกลิ้งลูกบอลผ่าน
เขาวงกตโครงลวด เด้งชนผนัง และสะสมแรงเพื่อกระโดด ระหว่างนั้นเสียงโทนจะเปลี่ยนไปตามการเคลื่อนที่ของลูกบอล ถ้าอยากเห็น
เรขาคณิตไฮเพอร์โบลิกจริง ๆ ดู[โลกไฮเพอร์โบลิก](hyperbolic-world.md)

รันจากโฟลเดอร์รากของรีโพซิทอรี:

```sh
ling run examples/physics/hyperbolic3d.ling
```

## การควบคุม

| ปุ่ม | การกระทำ |
|---|---|
| `W` / `S` | ดันลูกบอลไปข้างหน้า / ข้างหลัง |
| `A` / `D` | ดันลูกบอลไปทางซ้าย / ขวา |
| `Space` | กดค้างเพื่อสะสมแรง ปล่อยเพื่อกระโดด |
| `←` / `→` | หมุนกล้องรอบลูกบอล |
| `↑` / `↓` | เอียงกล้อง |
| `Z` / `X` | ซูมเข้า / ซูมออก |

## ทำงานอย่างไร

- **ฟิสิกส์** ทุกเฟรมจะเพิ่มแรงโน้มถ่วง คูณความเร็วด้วยตัวหน่วง (`DAMPING = 0.99`) แล้วเลื่อนลูกบอล เมื่อลูกบอลทะลุผนัง
  โปรแกรมจะดันกลับ กลับทิศความเร็ว แล้วคูณด้วย `ELASTICITY = 0.80`
- **เขาวงกต** กล่องด้านนอกขนาด 300 × 200 × 300 หน่วย และผนังด้านในห้าแผ่น ผนังตรวจการชนแบบสี่เหลี่ยม และวาดเป็นเส้นด้วย
  `draw_line_3d`
- **การกระโดด** กด `Space` ค้างไว้ขณะอยู่บนพื้นเพื่อสะสมแรงได้สูงสุดถึง `MAX_CHARGE` ปล่อยเมื่อไรลูกบอลก็พุ่งขึ้น มาตรวัด
  เล็ก ๆ ที่ลูกบอลบอกว่าสะสมแรงไปเท่าไร
- **ลูกบอล** วาดเป็นวงล้อ `vtex_chakra` ที่หมุนอยู่ และเปลี่ยนสีตามความสูง เงารูปกากบาทบนพื้น เส้นที่ลากลงถึงพื้น และลูกศร
  ความเร็วสีแดงช่วยให้เห็นตำแหน่งได้ชัด
- **เสียงที่ตามฟิสิกส์** เสียง `audio_tone` หนึ่งเสียงเปลี่ยนทุกเฟรม ระดับเสียงสูงขึ้นตามความสูงและความเร็ว และพุ่งขึ้นสั้น ๆ
  ทุกครั้งที่เด้ง ความดังเพิ่มตามความเร็ว และตำแหน่งเสียงซ้ายขวาตามพิกัด x ของลูกบอล
- **แสง** มีสามดวง ได้แก่ แสงอุ่นที่ลอยไปช้า ๆ แสงเติมโทนเย็น และแสงสีม่วงที่ตามลูกบอล

## ลองทำดู

- เปลี่ยน `GRAVITY`, `DAMPING` และ `ELASTICITY` ที่ต้นไฟล์ แล้วสัมผัสความแตกต่าง
- เพิ่มผนัง: คัดลอกการตรวจการชนของผนังหนึ่งแผ่น แล้ววาดด้วยการเรียก `draw_line_3d` ที่ตรงกัน
- จับคู่ค่าอื่นเข้ากับเสียง เช่น ให้ระดับแรงที่สะสมควบคุมระดับเสียง
