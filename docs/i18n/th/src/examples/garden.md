# สวน

ซอร์ส: [`examples/audiovisual/Garden.ling`](https://github.com/taellinglin/ling/blob/master/examples/audiovisual/Garden.ling)

สวนกลางแจ้งที่เปิดโล่ง มีพื้นดิน ท้องฟ้า สระน้ำตรงกลาง ต้นไม้สองต้นด้านหน้า แปลงดอกไม้ แนวต้นไม้ด้านหลัง และโรงเก็บของไม้
ไม่มีผนังหรือเพดาน ทุกอย่างวาดด้วยเรขาคณิตเวกเตอร์ (`vtex_*`) และรูปทรงแต่ละแบบมีเสียงโทนของตัวเอง ฉากนี้จึงทั้งดูได้และฟังได้

รันจากโฟลเดอร์รากของรีโพซิทอรี:

```sh
ling run examples/audiovisual/Garden.ling
```

## ฉาก

| ส่วน | ฟังก์ชันในไฟล์ |
|---|---|
| หญ้า ทางเดินหิน และแปลงดอกไม้ | `draw_ground` |
| ดวงอาทิตย์ เมฆที่ลอยไป และแสงที่ขอบฟ้า | `draw_sky` |
| ต้นไม้ลำต้นเกลียวและพุ่มดอกไม้ | `draw_tree`, `draw_trees` |
| แปลงดอกไม้ที่กระจายอยู่ | `draw_flowers` |
| สระที่มีดอกบัวลอย น้ำพุ และระลอกคลื่น | `draw_pond` |
| โรงเก็บของไม้ที่มีประตู หน้าต่าง และหลังคา | `draw_shed` |
| "เงาสะท้อน" จาง ๆ สองชั้นจากเฟรมก่อนหน้า | `draw_echo` |

รูปทรงมาจาก `vtex_flower`, `vtex_lotus`, `vtex_chakra`, `vtex_rings`, `vtex_grid`, `vtex_spiral`, `vtex_star`,
`vtex_yantra`, `vtex_hyperbolic_uv` และ `vtex_tessellated` ฟังก์ชันแฮชเล็ก ๆ ชื่อ `sm2_hash` ทำให้พื้นแต่ละแปลง
และแผ่นไม้แต่ละแผ่นของโรงเก็บของมีรายละเอียดไม่เท่ากัน

## เสียง

เสียงโทนหกเสียงใช้บันไดเสียงเพนทาโทนิก G เมเจอร์ (G A B D E) แต่ละเสียงถูกวางไว้ที่จุดของตัวเองในฉากด้วย `audio_tone`
รอบสระน้ำ โรงเก็บของ และท้องฟ้า และ `audio_listener` ขยับตามกล้อง

## กล้อง

กล้องลอยไปตามเส้นทางคดเคี้ยวช้า ๆ รอบสระน้ำ และมองไปที่กลางสวนเสมอ สีจะวนครบทุกเฉดประมาณทุกสองวินาที

## ลองทำดู

- เปลี่ยน `orbit_h` และ `orbit_v` เพื่อให้กล้องเข้าใกล้หรือถอยออกไป
- ย้ายสระด้วย `PX` และ `PZ` หรือย้ายโรงเก็บของด้วย `SX` และ `SZ`
- เปลี่ยนความถี่เพนทาโทนิก `PG3` ถึง `PE4` เพื่อเปลี่ยนคีย์ของสวน
