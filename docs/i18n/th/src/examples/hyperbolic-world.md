# โลกไฮเพอร์โบลิก (H²×ℝ)

ซอร์ส: [`examples/physics/hyperbolic_world.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic_world.ling)

โลกบล็อกเล็ก ๆ ที่พื้นเป็น**ระนาบไฮเพอร์โบลิก** ได้แรงบันดาลใจจาก [Hypermine](https://github.com/Ralith/hypermine)
ซึ่งเกิดขึ้นในปริภูมิไฮเพอร์โบลิก 3 มิติเต็มรูปแบบ (H³) เดโมนี้ใช้ญาติที่ง่ายที่สุดที่ยังเล่นได้ คือ **H²×ℝ** คุณเดินบนระนาบ
ไฮเพอร์โบลิก (วาดเป็นจานปวงกาเร) และแรงโน้มถ่วงในแนวตั้งทำงานตามปกติ

รันจากโฟลเดอร์รากของรีโพซิทอรี:

```sh
ling run examples/physics/hyperbolic_world.ling
```

## การควบคุม

| ปุ่ม | การกระทำ |
|---|---|
| `W` / `S` | เดินหน้า / ถอยหลัง |
| `A` / `D` | เลี่ยงไปซ้าย / ขวา |
| `Q` / `E` | หันซ้าย / ขวา |
| `Space` | กระโดด |

## อะไรทำให้มันเป็นไฮเพอร์โบลิก

- **ยิ่งใกล้ขอบยิ่งแน่น** บล็อกวางอยู่บนวงแหวนหลายชั้น และวงนอกมีบล็อกมากกว่าวงใน (`cells = 6 * ring`) ขอบจานแทน
  ระยะอนันต์ ยิ่งใกล้ขอบ บล็อกยิ่งอัดแน่นและหดลงตามตัวประกอบ `1 − |z|²`
- **การเคลื่อนที่แบบเมอบิอุส** คุณอยู่ที่กลางจานตลอด และโลกทั้งใบเลื่อนผ่านใต้เท้าคุณด้วยการเลื่อนแบบเมอบิอุส
  `z ↦ (z + a) / (1 + ā z)` การหันตัวคือการหมุนโลกรอบจุดกลาง
- **โฮโลโนมี** เดินเป็นวงปิด เช่น เป็นรูปสี่เหลี่ยม แล้วคุณจะกลับมาในทิศที่หมุนไป นี่คือความรู้สึกของการเคลื่อนที่ในปริภูมิ
  ที่มีความโค้งเป็นลบ
- **แรงโน้มถ่วงปกติ** การกระโดดและการตกใช้แกนแนวตั้งธรรมดา จึงรู้สึกเหมือนเกมทั่วไป

## บล็อกที่ไม่ต้องใช้เท็กซ์เจอร์

แต่ละบล็อกนำวงแหวนและตำแหน่งของตัวเองไปแฮช (`hash01` ซึ่งเป็นแฮชแบบ `fract(sin(...))`) เพื่อกำหนดชนิด (หญ้า หิน ดิน
หรือคริสตัล) และความสูง สีมาจากชนิด ส่วนที่เหลือเป็นหน้าที่ของการตั้งค่าการแรเงาแบบเซล (`set_shade_mode`, `set_cel_bands`,
`set_rim`) ไม่ต้องใช้ไฟล์เท็กซ์เจอร์เลย ดู[โพสต์เอฟเฟกต์และแสง](../reference/postfx.md)

## ลองทำดู

- บล็อกวาดด้วย `cube` ลองใช้ `cylinder` หรือรูปทรงอื่นจาก[รูปทรงและเมช 3 มิติ](../reference/shapes.md)
- เพิ่มจำนวนวงแหวนสูงสุด (`ring <= 4`) เพื่อให้โลกใหญ่ขึ้น
- เปลี่ยน `STEP` และ `TURN` เพื่อให้เดินหรือหันเร็วขึ้น

ถ้าอยากดูเดโม 3 มิติอีกแบบ ดู[ไฮเพอร์โบลิก 3 มิติ](hyperbolic-3d.md)
