# 道场 — ห้องศาลเจ้า

ซอร์ส: [`examples/3d-rooms/ling-dao-chamber.ling`](https://github.com/taellinglin/ling/blob/master/examples/3d-rooms/ling-dao-chamber.ling)

ศาลเจ้าแบบจีนผสมญี่ปุ่นที่เงียบสงบ วาดด้วยเรขาคณิตเวกเตอร์ (`vtex_*`) ล้วน ๆ ไม่มีการเติมพิกเซลเลย ทุกอย่างเคลื่อนไหวช้า ๆ
ในโทนสีทอง หยก และแดงเข้ม พร้อมเสียงระฆังบันไดเสียงเพนทาโทนิกเบา ๆ เป็นพื้นหลัง โปรแกรมนี้เขียนด้วยคำสงวนและฟังก์ชันในตัว
ภาษาไทยเป็นหลัก และมีชื่อภาษาจีนปนอยู่บ้าง

รันจากโฟลเดอร์รากของรีโพซิทอรี:

```sh
ling run examples/3d-rooms/ling-dao-chamber.ling
```

## ในห้องมีอะไรบ้าง

| ส่วน | ฟังก์ชันในตัวที่ใช้ |
|---|---|
| ประตูโทริอิที่ปลายห้อง | `vtex_torii` |
| เจดีย์ห้าชั้นหลังประตู | `vtex_pagoda` |
| มณฑลบนแท่นบูชา: วงฟันเฟือง ธรรมจักร ดอกบัว วงแหวน | `vtex_spiked_cog`, `vtex_chakra`, `vtex_lotus`, `vtex_rings` |
| พื้นกระเบื้องหินที่มีขอบลายยันต์ | `vtex_grid`, `vtex_yantra` |
| โคมรูปดาวบนเพดาน | `vtex_star`, `vtex_rings` |
| แผงลายพู่กันหมึกบนผนังสองข้าง | `vtex_letter_rain`, `vtex_lotus` |
| เสาสี่มุมห้อง | `vtex_rings`, `vtex_spiked_cog`, `vtex_lotus` |

## เสียง

เสียงห้าเสียงเรียงเป็นบันไดเสียงเพนทาโทนิกแบบจีน 宫 商 角 徵 羽 (C4, D4, E4, G4, A4) และมีเสียงทุ้มต่ำจาง ๆ อีกหนึ่งเสียง
แต่ละเสียงถูกวางในพื้นที่ 3 มิติด้วย `audio_tone` และ `audio_listener` ขยับตามกล้อง เสียงระฆังจึงเปลี่ยนทิศไปตามมุมมองที่แกว่ง

## กล้องและแสง

กล้องแกว่งเหมือนลูกตุ้มช้า ๆ ไปทางละประมาณ 30 องศา และหันหน้าเข้าหาแท่นบูชาเสมอ แสงห้าดวง (`add_light`) ได้แก่
โคมทองบนเพดาน แสงอุ่นจากแท่นบูชา แสงสีหยกและสีแดงเข้มที่เสา และโคมที่ประตู

## ลองทำดู

- เปลี่ยนค่าเฉดสีหลัก `GOLD`, `JADE` และ `CRIMSON` ที่ต้นไฟล์
- เพิ่มค่า `orbit_spd` ให้กล้องเคลื่อนเร็วขึ้น
- เปลี่ยนความถี่ใน `init_audio` เพื่อลองบันไดเสียงอื่น

ดูฟังก์ชันในตัวที่ใช้ในตัวอย่างนี้ได้ที่[รูปทรงและเมช 3 มิติ](../reference/shapes.md)และ[เสียง](../reference/audio.md)
