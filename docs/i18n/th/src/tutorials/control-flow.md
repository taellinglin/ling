# การตัดสินใจและการวนซ้ำ

โปรแกรมจะน่าสนใจขึ้นเมื่อเลือกได้ว่าจะทำอะไรและทำซ้ำได้ ในบทเรียนนี้คุณจะใช้ `ถ้า` และ `มิฉะนั้น`
เพื่อตัดสินใจ ใช้ `ขณะที่` และ `สำหรับ` เพื่อทำงานซ้ำ และใช้ `จับคู่` เพื่อเลือกจากหลายกรณี
คุณจะได้เรียนกฎขอบเขตข้อหนึ่งที่ทำให้มือใหม่หัด Ling แทบทุกคนประหลาดใจด้วย

## ตัดสินใจด้วย `ถ้า`

```ling
ผูก เริ่ม = ทำ {
  ผูก อุณหภูมิ = 31
  ถ้า อุณหภูมิ > 30 {
    พิมพ์("อากาศร้อน ดื่มน้ำด้วย")
  }
  พิมพ์("ตรวจเสร็จแล้ว")
}
```
```output
อากาศร้อน ดื่มน้ำด้วย
ตรวจเสร็จแล้ว
```

รูปแบบคือ `ถ้า เงื่อนไข { ... }` เงื่อนไขเป็นอะไรก็ได้ที่ให้ค่า `จริง` หรือ `เท็จ` ส่วนใหญ่เป็นการเปรียบเทียบ
ถ้าเป็นจริง บล็อกจะทำงาน ถ้าไม่ใช่ Ling จะข้ามไป เงื่อนไขไม่ต้องมีวงเล็บ แต่ต้องมีวงเล็บปีกกาเสมอ

ลองเปลี่ยน `อุณหภูมิ` เป็น `20` แล้วรันอีกครั้ง จะพิมพ์แค่ `ตรวจเสร็จแล้ว`

## `มิฉะนั้น` และ `มิฉะนั้น ถ้า`

`มิฉะนั้น` คืออีกทางหนึ่ง ใช้ `มิฉะนั้น ถ้า` ต่อการตรวจเพิ่มได้ Ling จะตรวจจากบนลงล่าง
แล้วรันบล็อกแรกที่เงื่อนไขเป็นจริง

```ling
ผูก เริ่ม = ทำ {
  ผูก คะแนน = 83
  ถ้า คะแนน >= 90 {
    พิมพ์("เกรด A")
  } มิฉะนั้น ถ้า คะแนน >= 80 {
    พิมพ์("เกรด B")
  } มิฉะนั้น ถ้า คะแนน >= 70 {
    พิมพ์("เกรด C")
  } มิฉะนั้น {
    พิมพ์("ฝึกต่อไปนะ")
  }
}
```
```output
เกรด B
```

83 ก็ไม่น้อยกว่า 70 เหมือนกัน แต่ทาง `คะแนน >= 80` มาก่อนจึงถูกเลือก ให้วางเกณฑ์ที่สูงที่สุดไว้ก่อน

รวมเงื่อนไขด้วย `&&` (และ) `||` (หรือ) และ `!` (ไม่)

```ling
ผูก เริ่ม = ทำ {
  ผูก ชั่วโมง = 14
  ผูก ฝนตก = จริง
  ผูก มีร่ม = เท็จ
  ถ้า ชั่วโมง >= 9 && ชั่วโมง < 17 {
    พิมพ์("ร้านเปิดอยู่")
  }
  ถ้า ฝนตก && !มีร่ม {
    พิมพ์("คุณจะเปียก")
  }
  ถ้า ชั่วโมง < 6 || ชั่วโมง > 22 {
    พิมพ์("ไปนอนได้แล้ว")
  } มิฉะนั้น {
    พิมพ์("ยังตื่นอยู่ได้")
  }
}
```
```output
ร้านเปิดอยู่
คุณจะเปียก
ยังตื่นอยู่ได้
```

## ทำซ้ำด้วย `ขณะที่`

ลูป `ขณะที่` (`while`) จะทำบล็อกซ้ำไปเรื่อยๆ ตราบที่เงื่อนไขยังเป็นจริง

```ling
ผูก เริ่ม = ทำ {
  ผูก i = 1
  ขณะที่ i <= 5 {
    พิมพ์("นับ: ", i)
    ผูก i = i + 1
  }
  พิมพ์("ปล่อยจรวด!")
}
```
```output
นับ: 1
นับ: 2
นับ: 3
นับ: 4
นับ: 5
ปล่อยจรวด!
```

ลูป `ขณะที่` ทุกลูปมีสามส่วน

1. ตั้งตัวนับก่อนเข้าลูป (`ผูก i = 1`)
2. เงื่อนไขที่ทำให้ลูปทำงานต่อ (`i <= 5`)
3. ในลูป ทำงานแล้ว**ขยับตัวนับ** (`ผูก i = i + 1`)

ถ้าลืมขั้นที่ 3 เงื่อนไขจะเป็นจริงตลอดไป กด **Ctrl+C** เพื่อหยุดโปรแกรมที่ไม่ยอมจบ

### สะสมผลลัพธ์

`ผูก` ในบล็อก `ขณะที่` (หรือ `ถ้า`) จะเปลี่ยนชื่อที่อยู่นอกบล็อก จึงทำให้ `ขณะที่` เหมาะกับการหาผลรวมสะสม

```ling
ผูก เริ่ม = ทำ {
  ผูก ผลรวม = 0
  ผูก n = 1
  ขณะที่ n <= 100 {
    ผูก ผลรวม = ผลรวม + n
    ผูก n = n + 1
  }
  พิมพ์("1 + 2 + ... + 100 = ", ผลรวม)
}
```
```output
1 + 2 + ... + 100 = 5050
```

## นับด้วย `สำหรับ`

เมื่อรู้ว่าต้องทำซ้ำกี่ครั้ง `สำหรับ` (`for`) จะสั้นกว่า มันเดินผ่าน**ช่วง**ของตัวเลข หรือผ่านแต่ละรายการในรายการ

```ling
ผูก เริ่ม = ทำ {
  สำหรับ i ใน 0..4 {
    พิมพ์("i คือ ", i)
  }
  สำหรับ k ใน 1..4 {
    พิมพ์(k, " x 7 = ", k * 7)
  }
  สำหรับ สี ใน ["แดง", "เขียว", "น้ำเงิน"] {
    พิมพ์("ฉันชอบสี", สี)
  }
}
```
```output
i คือ 0
i คือ 1
i คือ 2
i คือ 3
1 x 7 = 7
2 x 7 = 14
3 x 7 = 21
ฉันชอบสีแดง
ฉันชอบสีเขียว
ฉันชอบสีน้ำเงิน
```

`0..4` หมายถึง 0, 1, 2 และ 3 ช่วงจะหยุด**ก่อน**ตัวเลขตัวที่สองพอดี ดังนั้น `สำหรับ i ใน 0..4` จึงทำงานสี่ครั้งพอดี

ปลายของช่วงต้องเป็นตัวเลข ชื่อ หรือสิ่งที่อยู่ในวงเล็บ ให้เขียน `0..(n + 1)` และ `0..(ความยาว(xs))`
ห้ามเขียน `0..ความยาว(xs)` เพราะแบบนั้นจะไม่ทำงานเลยสักรอบโดยไม่มีคำเตือน

### กฎขอบเขตของ `สำหรับ`

นี่คือกฎที่ทำให้ทุกคนประหลาดใจ ลูป `สำหรับ` แต่ละรอบจะได้สำเนาใหม่ของชื่อรอบๆ ตัว `ผูก` ในตัวลูป `สำหรับ`
จึง**ไม่เปลี่ยน**ชื่อข้างนอก

```ling
ผูก เริ่ม = ทำ {
  ผูก ผลรวม = 0
  สำหรับ i ใน 1..5 {
    ผูก ผลรวม = ผลรวม + i
  }
  พิมพ์("หลัง สำหรับ: ", ผลรวม)

  ผูก ผลรวม = 0
  ผูก i = 1
  ขณะที่ i < 5 {
    ผูก ผลรวม = ผลรวม + i
    ผูก i = i + 1
  }
  พิมพ์("หลัง ขณะที่: ", ผลรวม)
}
```
```output
หลัง สำหรับ: 0
หลัง ขณะที่: 10
```

หลักง่ายๆ คือ ใช้ `สำหรับ` กับลูปที่แค่**ทำ**อะไรบางอย่าง (พิมพ์ วาด เล่นโน้ต) ส่วนลูปที่ต้อง**ทิ้งผลลัพธ์ไว้**
(ผลรวม จำนวน รายการที่ยาวขึ้นเรื่อยๆ) ให้ใช้ `ขณะที่`

Ling ไม่มี `break` หรือ `continue` ที่ใช้งานได้ ถ้าต้องการออกจากลูป `ขณะที่` ก่อนกำหนด ให้ทำให้เงื่อนไขเป็นเท็จ
เช่น ใช้ตัวแปรธงอย่าง `ผูก กำลังค้นหา = เท็จ`

### ลูปซ้อนลูป

ลูปหนึ่งอยู่ในอีกลูปได้ ในตัวอย่างนี้ `สำหรับ` ด้านนอกแค่พิมพ์ ส่วน `ขณะที่` ด้านในสร้างข้อความของแต่ละแถว

```ling
ผูก เริ่ม = ทำ {
  สำหรับ แถว ใน 1..5 {
    ผูก บรรทัด = ""
    ผูก ช่อง = 0
    ขณะที่ ช่อง < แถว {
      ผูก บรรทัด = บรรทัด + "*"
      ผูก ช่อง = ช่อง + 1
    }
    พิมพ์(บรรทัด)
  }
}
```
```output
*
**
***
****
```

## เลือกด้วย `จับคู่`

เมื่อต้องเทียบค่าหนึ่งกับหลายความเป็นไปได้ `จับคู่` (`match`) จะเรียบร้อยกว่าการต่อ `มิฉะนั้น ถ้า` ยาวๆ
แต่ละ**แขนง**เขียนว่า `รูปแบบ => การกระทำ` Ling จะรันแขนงแรกที่เข้ากันได้ และ `_` เข้ากันได้กับทุกอย่าง

```ling
ผูก เริ่ม = ทำ {
  ผูก วัน = 3
  จับคู่ วัน {
    1 => พิมพ์("วันจันทร์")
    2 => พิมพ์("วันอังคาร")
    3 => พิมพ์("วันพุธ")
    _ => พิมพ์("วันอื่น")
  }
  ผูก สัญญาณ = จับคู่ "เขียว" {
    "แดง" => "หยุด"
    "เขียว" => "ไป"
    _ => "รอ"
  }
  พิมพ์(สัญญาณ)
}
```
```output
วันพุธ
ไป
```

`จับคู่` ใช้กับตัวเลขและข้อความได้ และยังให้ค่ากลับมาเพื่อผูกได้ด้วย ให้จบด้วยแขนง `_` เสมอ
เพราะถ้าไม่มีแขนงใดเข้ากันได้ `จับคู่` จะคืนค่า `()` ซึ่งคือค่า "ว่างเปล่า" อย่างเงียบๆ

## ลองทำดู

1. ผูกตัวเลข `n` แล้วพิมพ์ `บวก` `ลบ` หรือ `ศูนย์`
2. พิมพ์สูตรคูณแม่ 6 ตั้งแต่ `6 x 1` ถึง `6 x 10` ด้วยลูป `สำหรับ`
3. ใช้ลูป `ขณะที่` บวกเลขคู่ตั้งแต่ 2 ถึง 50 (คำตอบคือ 650)
4. เริ่มจาก 1 แล้วคูณสองไปเรื่อยๆ จนมากกว่า 1000 พิมพ์ว่าคูณสองไปกี่ครั้ง
5. เขียนตัวอย่างเกรดใหม่โดยสลับลำดับการตรวจ (ตรวจ `คะแนน >= 70` ก่อน) จะเกิดอะไรผิดพลาด
