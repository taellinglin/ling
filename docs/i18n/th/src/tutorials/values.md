# ค่าและการผูก

ทุกโปรแกรมทำงานกับข้อมูล เช่น คะแนน ชื่อ หรือคำตอบว่าใช่หรือไม่ใช่ ในบทเรียนนี้คุณจะได้รู้จักค่าชนิดพื้นฐานของ
Ling ตั้งชื่อให้ค่าด้วย `ผูก` (`bind`) "เปลี่ยน" ค่าด้วยการผูกใหม่ และพิมพ์ค่าออกมา ทุกขั้นตอนมีโปรแกรมสั้นๆ
ที่คุณคัดลอกไปใส่ไฟล์แล้วรันด้วย `ling run` ได้

## ค่า

ข้อมูลหนึ่งชิ้นเรียกว่า**ค่า** ชนิดที่ใช้บ่อยที่สุดมีดังนี้

| ชนิด | เก็บอะไร | ตัวอย่าง |
|---|---|---|
| ตัวเลข | จำนวนใดๆ ทั้งจำนวนเต็มและทศนิยม | `42`, `3.14`, `-7` |
| ข้อความ | ตัวอักษร คำ ประโยค (เรียกอีกอย่างว่า*สตริง*) | `"สวัสดี"`, `"ห้อง 101"` |
| บูลีน | คำตอบหนึ่งในสองแบบ คือใช่หรือไม่ใช่ | `จริง`, `เท็จ` |
| รายการ | ค่าหลายค่าเรียงกันเป็นแถว | `[1, 2, 3]`, `["แดง", "น้ำเงิน"]` |

ลองพิมพ์ค่าแต่ละชนิดออกมาอย่างละหนึ่ง

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(42)
  พิมพ์(3.14)
  พิมพ์("ข้อความหนึ่งท่อน")
  พิมพ์(จริง)
  พิมพ์([1, 2, 3])
}
```
```output
42
3.14
ข้อความหนึ่งท่อน
true
[1, 2, 3]
```

ตัวเลขเขียนได้เลยโดยไม่มีเครื่องหมายคำพูด ข้อความต้องอยู่ในเครื่องหมายคำพูดคู่ `จริง` และ `เท็จ`
ไม่มีเครื่องหมายคำพูดเพราะไม่ใช่ข้อความ เมื่อพิมพ์ออกมาจะแสดงเป็น `true` และ `false` ส่วนรายการเขียนในวงเล็บเหลี่ยม
และคั่นแต่ละรายการด้วยจุลภาค

กฎการเขียนค่ามีไม่กี่ข้อ

- เขียนตัวเลขด้วยเลขธรรมดา มีจุดทศนิยมได้ไม่เกินหนึ่งจุด ให้เขียน `0.5` ไม่ใช่ `.5` และไม่มีรูปแบบอย่าง `1e3` หรือ `0xff`
- ข้อความใช้เครื่องหมายคำพูดคู่เท่านั้น ในข้อความ `\n` คือขึ้นบรรทัดใหม่ และ `\"` คือเครื่องหมายคำพูด

## การผูก: ตั้งชื่อให้ค่า

ใช้ `ผูก` เพื่อตั้งชื่อให้ค่า หลังจากนั้นชื่อนั้นจะแทนค่านั้น

```ling
ผูก เริ่ม = ทำ {
  ผูก ชื่อ = "มินา"
  ผูก อายุ = 12
  พิมพ์("สวัสดี " + ชื่อ)
  พิมพ์(ชื่อ, " อายุ ", อายุ, " ปี")
  พิมพ์("ปีหน้า: ", อายุ + 1)
}
```
```output
สวัสดี มินา
มินา อายุ 12 ปี
ปีหน้า: 13
```

อ่าน `ผูก อายุ = 12` ว่า "ผูกชื่อ `อายุ` เข้ากับค่า 12" ชื่อประกอบด้วยตัวอักษร ตัวเลข และขีดล่างได้
แต่ห้ามขึ้นต้นด้วยตัวเลข เลือกชื่อที่บอกความหมายของค่า `อายุ` ดีกว่า `a`

ทุกโปรแกรมที่คุณเขียนเริ่มต้นแบบเดียวกัน คือ `ผูก เริ่ม = ทำ { ... }` คำสั่งในวงเล็บปีกกาจะทำงานจากบนลงล่าง

## การผูกใหม่: วิธีที่ Ling "เปลี่ยน" ค่า

Ling **ไม่มีคำสั่งกำหนดค่า** คุณเขียน `คะแนน = คะแนน + 5` ไม่ได้ เพราะจะเกิดข้อผิดพลาดทางไวยากรณ์
ถ้าต้องการให้ชื่อมีค่าใหม่ ให้ผูกอีกครั้ง

```ling
ผูก เริ่ม = ทำ {
  ผูก คะแนน = 10
  พิมพ์("คะแนนคือ ", คะแนน)
  ผูก คะแนน = คะแนน + 5
  พิมพ์("คะแนนคือ ", คะแนน)
  ผูก คะแนน = คะแนน * 2
  พิมพ์("คะแนนคือ ", คะแนน)
}
```
```output
คะแนนคือ 10
คะแนนคือ 15
คะแนนคือ 30
```

`ผูก คะแนน = คะแนน + 5` จะคำนวณด้านขวาก่อนโดยใช้ค่าปัจจุบันของ `คะแนน` แล้วจึงติดป้าย `คะแนน`
ให้ผลลัพธ์นั้น ฝึกให้เป็นนิสัย เมื่อใดที่อยากเปลี่ยนอะไร ให้พิมพ์ `ผูก`

## การพิมพ์

`พิมพ์` จะพิมพ์อาร์กิวเมนต์ออกมาแล้วขึ้นบรรทัดใหม่ `println` ภาษาอังกฤษก็ทำงานเหมือนกันทุกอย่าง ใน Ling
ทั้งสองจบด้วยการขึ้นบรรทัดใหม่ เมื่อส่งอาร์กิวเมนต์หลายตัว จะพิมพ์ต่อกันไป**โดยไม่มีอะไรคั่น** แม้แต่ช่องว่างก็ไม่มี

```ling
ผูก เริ่ม = ทำ {
  พิมพ์("ผลรวม", 1 + 2)
  พิมพ์("ผลรวม: ", 1 + 2)
  พิมพ์("ก", "ข", "ค")
  พิมพ์("บรรทัดแรก\nบรรทัดที่สอง")
  พิมพ์("เธอพูดว่า \"หวัดดี\"")
}
```
```output
ผลรวม3
ผลรวม: 3
กขค
บรรทัดแรก
บรรทัดที่สอง
เธอพูดว่า "หวัดดี"
```

ถ้าต้องการช่องว่าง ให้ใส่ไว้ในข้อความเอง เช่น `"ผลรวม: "`

## เลขคณิต

Ling ใช้สัญลักษณ์ที่คุ้นเคย คือ `+`, `-`, `*`, `/` และ `%` สำหรับเศษจากการหาร

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(7 + 3)
  พิมพ์(7 / 2)
  พิมพ์(7 % 2)
  พิมพ์(2 + 3 * 4)
  พิมพ์((2 + 3) * 4)
  พิมพ์(ปัดเศษ(3.7))
  พิมพ์(รากที่สอง(81))
}
```
```output
10
3.5
1
14
20
4
9
```

การหารให้คำตอบที่แม่นยำ (`3.5`) ไม่ปัดทิ้ง การคูณทำก่อนการบวก ดังนั้น `2 + 3 * 4` คือ `14`
ถ้าต้องการลำดับอื่นให้ใส่วงเล็บ `ปัดเศษ` และ `รากที่สอง` เป็น**ฟังก์ชันในตัว** คือฟังก์ชันที่มากับ Ling

## แปลงระหว่างข้อความกับตัวเลข

ใช้ `+` ต่อข้อความสองท่อนเข้าด้วยกันได้ ถ้าจะต่อตัวเลขเข้ากับข้อความ ให้แปลงเป็นข้อความก่อนด้วย `str`
(`to_str` เป็นฟังก์ชันเดียวกัน) ส่วนทางกลับกัน `to_number` จะแปลงข้อความเป็นตัวเลข

```ling
ผูก เริ่ม = ทำ {
  ผูก แอปเปิล = 3
  พิมพ์("ฉันมีแอปเปิล " + str(แอปเปิล) + " ลูก")
  ผูก ที่พิมพ์มา = "12"
  พิมพ์(to_number(ที่พิมพ์มา) + 1)
  พิมพ์(รูปแบบ("{} + {} = {}", 2, 3, 2 + 3))
  พิมพ์(รูปแบบ("ประมาณ {:.2}", 3.14159))
}
```
```output
ฉันมีแอปเปิล 3 ลูก
13
2 + 3 = 5
ประมาณ 3.14
```

`รูปแบบ` (`format`) จะเติม `{}` แต่ละตัวในแม่แบบด้วยอาร์กิวเมนต์ถัดไปตามลำดับ ส่วน `{:.2}`
แสดงตัวเลขเป็นทศนิยมสองตำแหน่ง

## การเปรียบเทียบและบูลีน

การเปรียบเทียบคือการถามคำถามใช่หรือไม่ใช่ แล้วได้ `จริง` หรือ `เท็จ` กลับมา

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(5 > 3)
  พิมพ์(5 == 5)
  พิมพ์(5 != 5)
  พิมพ์("แมว" == "แมว")
  ผูก ใหญ่ = 100 > 50
  พิมพ์("ใหญ่: ", ใหญ่)
  พิมพ์(จริง && เท็จ)
  พิมพ์(จริง || เท็จ)
  พิมพ์(!จริง)
}
```
```output
true
true
false
true
ใหญ่: true
false
true
false
```

ตัวดำเนินการเปรียบเทียบได้แก่ `==`, `!=`, `<`, `>`, `<=` และ `>=` เครื่องหมาย `=` ตัวเดียวไม่ใช่การเปรียบเทียบ
แต่ปรากฏเฉพาะใน `ผูก` รวมคำตอบเข้าด้วยกันด้วย `&&` (และ: ต้องจริงทั้งคู่) `||` (หรือ: จริงอย่างน้อยหนึ่ง)
และ `!` (ไม่) อย่าเขียนการเปรียบเทียบต่อกันแบบในคณิตศาสตร์ ให้เขียน `x > 1 && x < 10` ไม่ใช่ `1 < x < 10`

## คอมเมนต์

ทุกอย่างหลัง `#` หรือ `//` ในบรรทัดเป็นคอมเมนต์ Ling จะข้ามไป เพราะเป็นบันทึกสำหรับคนอ่าน

```ling
# โปรแกรมหารค่าอาหารแบบง่าย
ผูก เริ่ม = ทำ {
  ผูก ค่าอาหาร = 84.50
  ผูก จำนวนคน = 4      // เพื่อนที่โต๊ะ
  ผูก คนละ = ค่าอาหาร / จำนวนคน
  พิมพ์("จ่ายคนละ ", ปัดเศษ(คนละ * 100) / 100)
}
```
```output
จ่ายคนละ 21.13
```

`ปัดเศษ(x * 100) / 100` ปัดตัวเลขให้เหลือทศนิยมสองตำแหน่งเพื่อแสดงผล

## ลองทำดู

1. ผูกอายุของคุณ แล้วพิมพ์ "อีก 10 ปีฉันจะอายุ ..." พร้อมตัวเลขที่ถูกต้อง
2. สี่เหลี่ยมผืนผ้ากว้าง 12.5 สูง 8 ให้พิมพ์พื้นที่และเส้นรอบรูป พร้อมป้ายกำกับแต่ละค่า
3. ผูก `n` ไว้ที่ 10 แล้วใช้แค่ `ผูก` ทำให้เป็น 11 จากนั้น 22 แล้ว 4 พิมพ์ `n` หลังแต่ละขั้น
4. แปลง 98.6 องศาฟาเรนไฮต์เป็นเซลเซียสด้วย `(f - 32) * 5 / 9` แล้วพิมพ์โดยปัดเป็นทศนิยมหนึ่งตำแหน่ง
5. พิมพ์ `"7" + "3"` แล้วพิมพ์ `to_number("7") + to_number("3")` ทำไมผลจึงต่างกัน
