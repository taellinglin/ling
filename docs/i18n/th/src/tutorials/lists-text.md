# รายการและข้อความ

จนถึงตอนนี้ ชื่อหนึ่งชื่อเก็บค่าได้หนึ่งค่า ในบทเรียนนี้คุณจะเก็บค่าหลายค่าไว้ด้วยกันใน**รายการ** เดินผ่านทีละค่าด้วยลูป
และแยกข้อความออกเป็นส่วนๆ แล้วประกอบกลับ สุดท้ายคุณจะได้โปรแกรมนับคำเล็กๆ หนึ่งโปรแกรม

## สร้างรายการ

เขียนรายการในวงเล็บเหลี่ยม และคั่นแต่ละรายการด้วยจุลภาค

```ling
ผูก เริ่ม = ทำ {
  ผูก ผลไม้ = ["แอปเปิล", "กล้วย", "เชอร์รี"]
  พิมพ์(ผลไม้)
  พิมพ์(ความยาว(ผลไม้))
  พิมพ์(รับรายการ(ผลไม้, 0))
  พิมพ์(ผลไม้[2])
}
```
```output
[แอปเปิล, กล้วย, เชอร์รี]
3
แอปเปิล
เชอร์รี
```

- เมื่อพิมพ์รายการ จะเห็นสมาชิกอยู่ในวงเล็บเหลี่ยม
- `ความยาว(ผลไม้)` คือจำนวนสมาชิก
- `รับรายการ(ผลไม้, 0)` อ่านสมาชิกที่ตำแหน่ง 0 ส่วน `ผลไม้[2]` เป็นวิธีเขียนแบบสั้นของ `รับรายการ(ผลไม้, 2)`

**ตำแหน่งเริ่มที่ 0** สมาชิกตัวแรกอยู่ที่ตำแหน่ง 0 และตัวสุดท้ายของสามตัวอยู่ที่ตำแหน่ง 2 ลองคิดว่าตำแหน่งคือ
"ต้องข้ามไปกี่ตัว" ให้ตำแหน่งอยู่ระหว่าง 0 ถึง `ความยาว(xs) - 1` เสมอ ถ้าขอตำแหน่งที่ไม่มีอยู่
เอนจินค่าเริ่มต้นจะได้ค่าว่าง ส่วนอินเทอร์พรีเตอร์จะแจ้งข้อผิดพลาด

## เปลี่ยนรายการ: ผูกใหม่ทุกครั้ง

`เพิ่มรายการ` (`list_push`) เพิ่มสมาชิกต่อท้าย และ `list_set` แทนที่สมาชิกที่ตำแหน่งหนึ่ง ทั้งสองให้รายการ**ใหม่**
ถ้าจะเก็บไว้ ให้ผูกชื่ออีกครั้ง

```ling
ผูก เริ่ม = ทำ {
  ผูก ผลไม้ = ["แอปเปิล", "กล้วย", "เชอร์รี"]
  ผูก ผลไม้ = เพิ่มรายการ(ผลไม้, "พุทรา")
  พิมพ์(ผลไม้)
  ผูก ผลไม้ = list_set(ผลไม้, 1, "บลูเบอร์รี")
  พิมพ์(ผลไม้)
  พิมพ์("ตอนนี้มีผลไม้ ", ความยาว(ผลไม้), " อย่าง")
}
```
```output
[แอปเปิล, กล้วย, เชอร์รี, พุทรา]
[แอปเปิล, บลูเบอร์รี, เชอร์รี, พุทรา]
ตอนนี้มีผลไม้ 4 อย่าง
```

ให้เขียน `ผูก ผลไม้ = เพิ่มรายการ(ผลไม้, "พุทรา")` เสมอ อย่าเขียน `เพิ่มรายการ(ผลไม้, "พุทรา")` ลอยๆ
นี่คือนิสัยการผูกใหม่แบบเดียวกับที่เรียนใน [ค่าและการผูก](values.md)

## สร้างรายการในลูป

เริ่มจากรายการว่างด้วย `รายการใหม่()` แล้วเพิ่มสมาชิกเข้าไป จำกฎขอบเขตจาก [การตัดสินใจและการวนซ้ำ](control-flow.md)
ไว้ว่า ตัวลูป `สำหรับ` ทิ้งผลลัพธ์ไว้ไม่ได้ จึงต้องสร้างรายการด้วย `ขณะที่`

```ling
ผูก เริ่ม = ทำ {
  ผูก กำลังสอง = รายการใหม่()
  ผูก i = 1
  ขณะที่ i < 8 {
    ผูก กำลังสอง = เพิ่มรายการ(กำลังสอง, i * i)
    ผูก i = i + 1
  }
  พิมพ์(กำลังสอง)
}
```
```output
[1, 4, 9, 16, 25, 36, 49]
```

## เดินผ่านรายการ

ถ้าแค่**อ่าน**รายการ ใช้ `สำหรับ` ได้เลย แต่ถ้าต้องสะสมผลลัพธ์ด้วย ให้ใช้ `ขณะที่` กับตำแหน่ง

```ling
ผูก เริ่ม = ทำ {
  ผูก คะแนน = [72, 95, 88, 61, 79]
  สำหรับ s ใน คะแนน {
    พิมพ์("คะแนน: ", s)
  }
  ผูก รวม = 0
  ผูก มากสุด = คะแนน[0]
  ผูก i = 0
  ขณะที่ i < ความยาว(คะแนน) {
    ผูก s = คะแนน[i]
    ผูก รวม = รวม + s
    ถ้า s > มากสุด {
      ผูก มากสุด = s
    }
    ผูก i = i + 1
  }
  พิมพ์("รวม: ", รวม)
  พิมพ์("เฉลี่ย: ", รวม / ความยาว(คะแนน))
  พิมพ์("มากสุด: ", มากสุด)
  พิมพ์("list_max ตอบว่า ", list_max(คะแนน, 0))
}
```
```output
คะแนน: 72
คะแนน: 95
คะแนน: 88
คะแนน: 61
คะแนน: 79
รวม: 395
เฉลี่ย: 79
มากสุด: 95
list_max ตอบว่า 95
```

`มากสุด` เริ่มจากสมาชิกตัวแรก แล้วถูกแทนที่ทุกครั้งที่เจอตัวที่มากกว่า ฟังก์ชันในตัว `list_max` และ `list_min`
ทำงานเดียวกัน อาร์กิวเมนต์ตัวที่สองคือคำตอบเมื่อรายการว่าง

## เครื่องมือสำหรับข้อความ

Ling มีฟังก์ชันในตัวชุดหนึ่งสำหรับทำงานกับข้อความ

```ling
ผูก เริ่ม = ทำ {
  ผูก s = "  สวัสดี Ling โลก  "
  พิมพ์(ความยาว(s))
  ผูก s = trim(s)
  พิมพ์("[" + s + "]")
  พิมพ์(str_upper(s))
  พิมพ์(str_lower(s))
  พิมพ์(substr(s, 0, 6))
  พิมพ์(str_find(s, "Ling"))
  พิมพ์(str_find(s, "Python"))
  พิมพ์(str_replace(s, "โลก", "เพื่อน"))
  พิมพ์(starts_with(s, "สวัสดี"))
  พิมพ์(str_repeat("ฮ่า", 3))
}
```
```output
19
[สวัสดี Ling โลก]
สวัสดี LING โลก
สวัสดี ling โลก
สวัสดี
7
-1
สวัสดี Ling เพื่อน
true
ฮ่าฮ่าฮ่า
```

สังเกตว่า `ความยาว` นับสระและวรรณยุกต์เป็นตัวอักษรแยกกันด้วย คำว่า `สวัสดี` จึงยาว 6 ตัว ไม่ใช่ 4 พยางค์

| ฟังก์ชันในตัว | หน้าที่ |
|---|---|
| `ความยาว(s)` | จำนวนตัวอักษร |
| `trim(s)` | ตัดช่องว่างที่หัวและท้าย |
| `str_upper(s)`, `str_lower(s)` | เปลี่ยนตัวพิมพ์ใหญ่และเล็ก (อักษรละติน) |
| `substr(s, เริ่ม, จำนวน)` | ตัวอักษร `จำนวน` ตัว เริ่มที่ตำแหน่ง `เริ่ม` (นับจาก 0) |
| `str_find(s, ส่วน)` | ตำแหน่งที่พบครั้งแรก หรือ `-1` ถ้าไม่พบ |
| `str_replace(s, เดิม, ใหม่)` | แทนที่ `เดิม` ทุกตัวด้วย `ใหม่` |
| `starts_with(s, ส่วน)`, `ends_with(s, ส่วน)` | `จริง` หรือ `เท็จ` |
| `str_repeat(s, n)` | ข้อความซ้ำ `n` ครั้ง |

เช่นเดียวกับฟังก์ชันของรายการ ฟังก์ชันเหล่านี้ไม่เปลี่ยนข้อความเดิม แต่คืนข้อความใหม่ จึงต้องผูกผลลัพธ์ไว้ เช่น `ผูก s = trim(s)`

## แยกและรวม

`split` ตัดข้อความเป็นรายการตรงที่เจอตัวคั่น ส่วน `list_join` ต่อรายการกลับเป็นข้อความเดียว (`join` เป็นฟังก์ชันในตัวเดียวกัน)

```ling
ผูก เริ่ม = ทำ {
  ผูก บรรทัด = "แดง,เขียว,น้ำเงิน"
  ผูก ส่วนต่างๆ = split(บรรทัด, ",")
  พิมพ์(ส่วนต่างๆ)
  พิมพ์(ความยาว(ส่วนต่างๆ))
  พิมพ์(list_join(ส่วนต่างๆ, " | "))
  ผูก ตัวเลข = split("3 8 15", " ")
  พิมพ์(to_number(ตัวเลข[1]) + 1)
}
```
```output
[แดง, เขียว, น้ำเงิน]
3
แดง | เขียว | น้ำเงิน
9
```

ส่วนที่ได้จาก `split` เป็นข้อความ ต้องแปลงด้วย `to_number` ก่อนนำไปคำนวณ

## ทีละตัวอักษร

`substr(s, i, 1)` ให้ตัวอักษรหนึ่งตัวที่ตำแหน่ง `i` ลองใช้กลับข้อความ

```ling
ฟังก์ชัน กลับด้าน(s) {
  ผูก ผล = ""
  ผูก i = ความยาว(s) - 1
  ขณะที่ i >= 0 {
    ผูก ผล = ผล + substr(s, i, 1)
    ผูก i = i - 1
  }
  คืน ผล
}

ผูก เริ่ม = ทำ {
  พิมพ์(กลับด้าน("กขคง"))
  พิมพ์(กลับด้าน("นาน") == "นาน")
}
```
```output
งคขก
true
```

## โปรแกรมนับคำ

Ling ยังไม่มีชนิดพจนานุกรม เราจึงวางรายการสองรายการคู่กัน `คำ` เก็บคำที่ไม่ซ้ำกันทีละคำ และ `จำนวน`
เก็บว่าคำนั้นปรากฏกี่ครั้ง ฟังก์ชันช่วยจะหาตำแหน่งของคำ

```ling
ฟังก์ชัน ตำแหน่งของ(สมาชิก, เป้าหมาย) {
  ผูก i = 0
  ขณะที่ i < ความยาว(สมาชิก) {
    ถ้า สมาชิก[i] == เป้าหมาย {
      คืน i
    }
    ผูก i = i + 1
  }
  คืน -1
}

ผูก เริ่ม = ทำ {
  ผูก ทั้งหมด = split("แมว,หมา,นก,แมว,หมา,แมว,ปลา", ",")
  ผูก คำ = รายการใหม่()
  ผูก จำนวน = รายการใหม่()
  ผูก i = 0
  ขณะที่ i < ความยาว(ทั้งหมด) {
    ผูก w = ทั้งหมด[i]
    ผูก p = ตำแหน่งของ(คำ, w)
    ถ้า p == -1 {
      ผูก คำ = เพิ่มรายการ(คำ, w)
      ผูก จำนวน = เพิ่มรายการ(จำนวน, 1)
    } มิฉะนั้น {
      ผูก จำนวน = list_set(จำนวน, p, จำนวน[p] + 1)
    }
    ผูก i = i + 1
  }
  ผูก k = 0
  ขณะที่ k < ความยาว(คำ) {
    พิมพ์(คำ[k], ": ", จำนวน[k])
    ผูก k = k + 1
  }
}
```
```output
แมว: 3
หมา: 2
นก: 1
ปลา: 1
```

> **หมายเหตุ:** `==` ใช้เปรียบเทียบตัวเลข ข้อความ และบูลีน การเปรียบเทียบรายการสองรายการด้วย `==` จะได้ `เท็จ` เสมอ
> แม้สมาชิกจะเหมือนกันทุกตัว ให้เปรียบเทียบทีละสมาชิก

## ลองทำดู

1. สร้างรายการตัวเลขห้าตัว แล้วพิมพ์ผลรวมด้วยลูป `ขณะที่`
2. แยก `"3,8,15,4"` ด้วยจุลภาค แปลงแต่ละส่วนด้วย `to_number` แล้วพิมพ์ตัวที่มากที่สุด
3. เขียน `นับสระ(s)` ที่นับตัวอักษรอังกฤษ a, e, i, o, u (คำใบ้: แปลงข้อความเป็นตัวพิมพ์เล็กก่อน แล้วตรวจแต่ละตัวด้วย
   `str_find("aeiou", ตัวอักษร) != -1`)
4. ใช้ `str_replace` ตัดช่องว่างออกเพื่อทำตัวตรวจพาลินโดรม แล้วลองกับ `"ยาย"` และ `"นา น"`
5. ต่อยอดโปรแกรมนับคำให้พิมพ์คำที่ปรากฏบ่อยที่สุดด้วย
