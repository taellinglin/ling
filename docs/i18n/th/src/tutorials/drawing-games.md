# การวาดและเกม

ในหน้านี้ คุณจะวาดภาพ 2 มิติแบบแบนด้วยวงกลม สามเหลี่ยม เส้น และการไล่สี ทำให้ภาพตอบสนองต่อคีย์บอร์ด
และเมาส์ แล้วรวมทุกอย่างเป็นเกมเล็กๆ ที่เล่นและแก้ไขได้ ทุกอย่างในหน้านี้ใช้ฟังก์ชันในตัวที่มากับ Ling
จึงไม่ต้องมีไฟล์รูปภาพหรือเอนจินเกม

โปรแกรมเหล่านี้เปิดหน้าต่าง บล็อกโค้ดจึงไม่มีผลลัพธ์ กด **Escape** หรือปิดหน้าต่างเพื่อหยุด

## เปิดหน้าต่างและรันลูปเฟรม

โปรแกรมกราฟิกทุกโปรแกรมมีโครงเดียวกัน คือเปิดหน้าต่างครั้งเดียว แล้ววน **ล้าง วาด แสดงผล**
ไปเรื่อยๆ จนกว่าหน้าต่างจะปิด

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 400, "ลูปเฟรม")
    ผูก t = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        เติม(10, 12, 30)                             # 1. ล้าง
        สีดินสอ(255, 200, 80)                        # 2. วาด
        วาดวงกลมทึบ(320 + 200 * ไซน์(t * 0.05), 200, 30)
        แสดงผล()                                     # 3. แสดงเฟรม
        ผูก t = t + 1
    }
}
```

- `เปิดหน้าต่าง(กว้าง, สูง, ชื่อ)` (`open_window`) เปิดหน้าต่าง ขนาดมาก่อน ชื่อมาทีหลัง
- `หน้าต่างเปิดอยู่()` (`window_is_open`) จะเป็นเท็จเมื่อปิดหน้าต่างหรือกด Escape
- `เติม(r, g, b)` (`fill`) ระบายทั้งหน้าต่างด้วยสีเดียว สีคือค่าแดง เขียว น้ำเงิน ตั้งแต่ 0 ถึง 255
- `แสดงผล()` (`present`) นำเฟรมที่วาดเสร็จขึ้นจอ เฟรมที่ไม่มี `แสดงผล()` จะมองไม่เห็น
- `t` นับเฟรม `ไซน์(t * 0.05)` แกว่งไปมาอย่างนุ่มนวลระหว่าง -1 ถึง 1 ทำให้วงกลมเลื่อนไปมา

ไม่มีฟังก์ชันในตัวที่บอกเวลาระหว่างเฟรม ถ้าต้องการวินาทีจริง ให้ใช้ `เวลาปัจจุบัน()` (`time_now`
วินาทีนับจากโปรแกรมเริ่ม) หรือ `เฟรม()` (`frame_count`)

## ผืนผ้าใบ 2 มิติ

หน้าต่างคือตารางพิกเซล มีสองอย่างที่ต่างจากในวิชาคณิตศาสตร์:

- จุดกำเนิด `(0, 0)` อยู่ที่มุม**บนซ้าย**
- **y เพิ่มขึ้นเมื่อลงล่าง** `y = 300` อยู่ต่ำกว่า `y = 100` บนจอ

คุณวาดด้วย**ดินสอ** `สีดินสอ(r, g, b)` (`set_color`) เลือกสีดินสอ และรูปทรงทุกรูปหลังจากนั้นจะใช้สีนี้
จนกว่าคุณจะเปลี่ยน

| ฟังก์ชันในตัว | วาดอะไร |
|---|---|
| `fill(r, g, b)` / `เติม` | ทั้งหน้าต่างด้วยสีเดียว |
| `draw_disc(cx, cy, r)` / `วาดวงกลมทึบ` | วงกลมทึบ |
| `draw_circle(cx, cy, r)` | เส้นขอบวงกลม |
| `triangle(x0, y0, x1, y1, x2, y2)` / `วาดสามเหลี่ยม` | สามเหลี่ยมทึบ |
| `draw_line(x0, y0, x1, y1)` / `วาดเส้น` | เส้นบาง |
| `draw_arc(cx, cy, r, a0, a1, segments)` | ส่วนหนึ่งของเส้นขอบวงกลม มุมเป็นเรเดียน ตามเข็มนาฬิกา |
| `draw_poly([x0, y0, x1, y1, ...])` / `เติมรูปหลายเหลี่ยม` | รูปหลายเหลี่ยมทึบจากรายการจุดแบบแบน |
| `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` / `สี่เหลี่ยมไล่สี` | สี่เหลี่ยมที่ไล่สีระหว่างสองสี `dir` เป็น 1 คือบนลงล่าง 0 คือซ้ายไปขวา |
| `set_color_hsl(h, s, l)` / `สีHSLวาด` | สีดินสอจากเฉดสี 0-360 ความอิ่มสี 0-100 ความสว่าง 0-100 |

ไม่มีฟังก์ชันในตัวสำหรับสี่เหลี่ยมสีทึบ แต่การไล่สีจากสีหนึ่งไปยังสีเดียวกันก็คือสี่เหลี่ยมสีทึบ
จึงเขียนฟังก์ชันช่วยเองได้:

```ling-module
ฟังก์ชัน สี่เหลี่ยม(x, y, กว้าง, สูง, r, g, b) {
    สี่เหลี่ยมไล่สี(x, y, กว้าง, สูง, r, g, b, r, g, b, 1)
}
```

> **เคล็ดลับ:** ถ้าการเรียกวาดดูเหมือนไม่ทำอะไรเลย ให้ตรวจตัวสะกด ชื่อที่ไม่รู้จักอย่าง `draw_rect`
> จะถูกข้ามไปเงียบๆ

### ภาพทิวทัศน์

วาดเป็นชั้นๆ จากด้านหลังมาด้านหน้า รูปที่วาดทีหลังจะทับรูปที่วาดก่อน

```ling-gui
ฟังก์ชัน สี่เหลี่ยม(x, y, กว้าง, สูง, r, g, b) {
    สี่เหลี่ยมไล่สี(x, y, กว้าง, สูง, r, g, b, r, g, b, 1)
}

ฟังก์ชัน ต้นไม้(x, พื้น) {
    สี่เหลี่ยม(x - 6, พื้น - 50, 12, 50, 110, 70, 40)
    สีดินสอ(40, 150, 70)
    วาดวงกลมทึบ(x, พื้น - 70, 32)
    วาดวงกลมทึบ(x - 20, พื้น - 50, 24)
    วาดวงกลมทึบ(x + 20, พื้น - 50, 24)
}

ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(800, 500, "ทิวทัศน์")
    ผูก t = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        สี่เหลี่ยมไล่สี(0, 0, 800, 380, 30, 40, 110, 250, 150, 140, 1)   # ท้องฟ้า
        สีดินสอ(255, 220, 120)
        วาดวงกลมทึบ(600, 300, 60)                                        # ดวงอาทิตย์
        สีดินสอ(70, 60, 110)
        วาดสามเหลี่ยม(0, 380, 150, 190, 300, 380)                        # ภูเขา
        วาดสามเหลี่ยม(200, 380, 380, 150, 560, 380)
        สี่เหลี่ยม(0, 380, 800, 120, 50, 110, 60)                         # พื้นดิน
        ต้นไม้(120, 440)
        ต้นไม้(330, 460)
        ต้นไม้(690, 450)
        สีดินสอ(20, 20, 30)                                              # นก
        ผูก กระพือ = ไซน์(t * 0.15) * 6
        draw_arc(150, 120 - กระพือ, 18, 3.4, 6.0, 16)
        draw_arc(186, 120 - กระพือ, 18, 3.4, 6.0, 16)
        แสดงผล()
        ผูก t = t + 1
    }
}
```

`ต้นไม้(x, พื้น)` วางลำต้นและใบตามอาร์กิวเมนต์ คุณจึงปลูกต้นไม้ได้มากเท่าที่ต้องการ ปีกนกคือส่วนโค้งสองเส้น
เพราะ y ชี้ลง มุมจึงเพิ่มตามเข็มนาฬิกา `0` ชี้ไปทางขวา และ `3.14` ชี้ไปทางซ้าย

## อ่านคีย์บอร์ด

Ling ไม่มีตัวจัดการเหตุการณ์ ในแต่ละเฟรมคุณ**ถาม**ว่าปุ่มถูกกดอยู่หรือไม่:

- `กดค้าง("left")` (`key_down`) เป็นจริงตลอดเวลาที่กดปุ่มค้างไว้
- `กดปุ่ม("space")` (`key_pressed`) เป็นจริงเฉพาะเฟรมเดียวที่ปุ่มถูกกดลง ใช้กับสิ่งที่เกิดครั้งเดียวต่อการกด
  หนึ่งครั้ง เช่น กระโดดหรือเริ่มใหม่

ชื่อปุ่มเป็นสตริงภาษาอังกฤษตัวพิมพ์เล็ก: `"a"` ถึง `"z"` ตัวเลข `"left"` `"right"` `"up"` `"down"`
`"space"` `"enter"` `"escape"` `"lshift"` และอื่นๆ ชื่อที่ไม่รู้จักจะเป็นเท็จเท่านั้น

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 400, "เลื่อนลูกบอล")
    ผูก x = 320
    ผูก y = 200
    ขณะที่ หน้าต่างเปิดอยู่() {
        ผูก ความเร็ว = 3
        ถ้า กดค้าง("lshift") {
            ผูก ความเร็ว = 8
        }
        ถ้า กดค้าง("left") {
            ผูก x = x - ความเร็ว
        }
        ถ้า กดค้าง("right") {
            ผูก x = x + ความเร็ว
        }
        ถ้า กดค้าง("up") {
            ผูก y = y - ความเร็ว
        }
        ถ้า กดค้าง("down") {
            ผูก y = y + ความเร็ว
        }
        ผูก x = จำกัด(x, 20, 620)
        ผูก y = จำกัด(y, 20, 380)

        เติม(10, 10, 30)
        สีดินสอ(255, 180, 60)
        วาดวงกลมทึบ(x, y, 20)
        แสดงผล()
    }
}
```

เกมแทบทุกเกมมีสามส่วนนี้:

1. **สถานะ:** `x` และ `y` อยู่นอกลูป จึงคงค่าไว้จากเฟรมหนึ่งไปอีกเฟรม
2. **รับค่าและอัปเดต:** การตรวจ `กดค้าง` เปลี่ยนสถานะ และ `จำกัด` (`clamp`) กันลูกบอลไว้ในหน้าต่าง
3. **วาด:** สร้างภาพจากสถานะ

ทำตามลำดับนี้ทุกเฟรม: รับค่า อัปเดต วาด

## อ่านเมาส์

`mouse_x()` และ `mouse_y()` บอกตำแหน่งตัวชี้เป็นพิกเซล `mouse_down()` เป็นจริงขณะกดปุ่มซ้ายค้าง
`mouse_down_right()` เป็นจริงขณะกดปุ่มขวาค้าง ในตัวอย่างนี้ใช้ชื่อภาษาอังกฤษตามที่ `lingfu normalize` ให้มา

```ling-gui
ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 400, "วาดด้วยเมาส์")
    เติม(245, 240, 225)
    ผูก เฉดสี = 0
    ขณะที่ หน้าต่างเปิดอยู่() {
        ถ้า mouse_down() {
            สีHSLวาด(เฉดสี, 80, 50)
            วาดวงกลมทึบ(mouse_x(), mouse_y(), 10)
            ผูก เฉดสี = (เฉดสี + 3) % 360
        }
        ถ้า mouse_down_right() {
            เติม(245, 240, 225)
        }
        แสดงผล()
    }
}
```

โปรแกรมนี้ไม่เรียก `เติม` ทุกเฟรม สีที่ระบายจึงค้างอยู่บนผืนผ้าใบ คลิกขวาจะเรียก `เติม` หนึ่งครั้งเพื่อลบ

## เกมเล็กๆ: เก็บดาว

ดาวตกลงมาจากฟ้า คุณเลื่อนตะกร้าไปซ้ายขวาเพื่อรับ รับได้หนึ่งดวงได้หนึ่งคะแนน และดวงต่อไปจะตกเร็วขึ้น
พลาดสามดวงก็จบเกม กด Space เพื่อเล่นใหม่

ก่อนเขียนเกม ให้จดสิ่งเหล่านี้ไว้: **สถานะ** (x ของตะกร้า ตำแหน่งดาว ความเร็วการตก คะแนน ชีวิตที่เหลือ)
**กติกา** (สถานะเปลี่ยนอย่างไรในแต่ละเฟรม) และ**ภาพ** (วาดสถานะออกมาอย่างไร)

```ling-gui
ฟังก์ชัน สี่เหลี่ยม(x, y, กว้าง, สูง, r, g, b) {
    สี่เหลี่ยมไล่สี(x, y, กว้าง, สูง, r, g, b, r, g, b, 1)
}

# ดาวห้าแฉก: รูปหลายเหลี่ยมสิบมุม
ฟังก์ชัน ดาว(cx, cy, ขนาด, หมุน) {
    ผูก จุด = []
    ผูก i = 0
    ขณะที่ i < 10 {
        ผูก มุม = หมุน + i * 0.6283185
        ผูก รัศมี = ขนาด
        ถ้า i % 2 == 1 {
            ผูก รัศมี = ขนาด * 0.45
        }
        ผูก จุด = เพิ่มรายการ(จุด, cx + โคไซน์(มุม) * รัศมี)
        ผูก จุด = เพิ่มรายการ(จุด, cy + ไซน์(มุม) * รัศมี)
        ผูก i = i + 1
    }
    เติมรูปหลายเหลี่ยม(จุด)
}

ผูก เริ่ม = ทำ {
    เปิดหน้าต่าง(640, 480, "เก็บดาว")
    ผูก ตะกร้าx = 320
    ผูก ดาวx = 100 + สุ่ม() * 440
    ผูก ดาวy = 0
    ผูก ความเร็วตก = 3
    ผูก คะแนน = 0
    ผูก ชีวิต = 3
    ผูก t = 0

    ขณะที่ หน้าต่างเปิดอยู่() {
        ถ้า ชีวิต > 0 {
            # รับค่า
            ถ้า กดค้าง("left") || กดค้าง("a") {
                ผูก ตะกร้าx = ตะกร้าx - 7
            }
            ถ้า กดค้าง("right") || กดค้าง("d") {
                ผูก ตะกร้าx = ตะกร้าx + 7
            }
            ผูก ตะกร้าx = จำกัด(ตะกร้าx, 50, 590)
            # อัปเดต
            ผูก ดาวy = ดาวy + ความเร็วตก
            ถ้า ดาวy > 440 {
                ถ้า ค่าสัมบูรณ์(ดาวx - ตะกร้าx) < 55 {
                    ผูก คะแนน = คะแนน + 1
                    ผูก ความเร็วตก = ความเร็วตก + 0.25
                } มิฉะนั้น {
                    ผูก ชีวิต = ชีวิต - 1
                }
                ผูก ดาวx = 50 + สุ่ม() * 540
                ผูก ดาวy = 0
            }
        } มิฉะนั้น {
            ถ้า กดปุ่ม("space") {
                ผูก ชีวิต = 3
                ผูก คะแนน = 0
                ผูก ความเร็วตก = 3
                ผูก ดาวy = 0
            }
        }

        # วาด
        สี่เหลี่ยมไล่สี(0, 0, 640, 480, 15, 15, 50, 40, 25, 80, 1)
        สีดินสอ(255, 220, 80)
        ดาว(ดาวx, ดาวy, 24, t * 0.05)
        สี่เหลี่ยม(ตะกร้าx - 50, 445, 100, 14, 90, 190, 255)
        สีดินสอ(255, 255, 255)
        ข้อความหน้าจอ(16, 14, 22, "SCORE " + to_str(คะแนน))
        ข้อความหน้าจอ(500, 14, 22, "LIVES " + to_str(ชีวิต))
        ถ้า ชีวิต <= 0 {
            สีดินสอ(255, 110, 110)
            ข้อความหน้าจอ(170, 200, 36, "GAME OVER")
        }
        แสดงผล()
        ผูก t = t + 1
    }
    พิมพ์("คะแนนสุดท้าย: ", คะแนน)
}
```

ทำงานอย่างไร:

- **ดาว** `ดาว` คำนวณพิกัดของมุมทั้งสิบด้วย `โคไซน์` และ `ไซน์` สลับรัศมียาวกับสั้น สร้างเป็นรายการแบบแบน
  แล้วส่งให้ `เติมรูปหลายเหลี่ยม` (`draw_poly`) มุม `หมุน` ทำให้ดาวหมุนขณะตก
- **สถานะเกม** `ถ้า ชีวิต > 0 { ... } มิฉะนั้น { ... }` สลับระหว่าง "กำลังเล่น" กับ "จบเกม"
  ตอนจบเกมจะตรวจแค่ปุ่มเริ่มใหม่
- **การรับ** เมื่อดาวตกถึงระดับตะกร้า `ค่าสัมบูรณ์(ดาวx - ตะกร้าx) < 55` จะตัดสินว่ารับได้หรือไม่
  `สุ่ม()` (`rand`) คืนค่าตั้งแต่ 0 แต่ไม่ถึง 1 ดังนั้น `50 + สุ่ม() * 540` คือ x แบบสุ่มระหว่าง 50 ถึง 590
- **ความยาก** `ผูก ความเร็วตก = ความเร็วตก + 0.25` ทำให้ดาวดวงถัดไปเร็วขึ้นทีละนิด
- **ข้อความ** `ข้อความหน้าจอ(x, y, ขนาด, ข้อความ)` (`ui_text`) วาดตัวอักษรด้วยฟอนต์เส้นในตัวตามสีดินสอ
  ไม่ต้องใช้ไฟล์ฟอนต์ แต่วาดได้เฉพาะอักษรละตินตัวพิมพ์ใหญ่และตัวเลข ข้อความบนจอจึงเป็นภาษาอังกฤษ
- **ตอนจบ** เมื่อปิดหน้าต่าง ลูปจะจบ และบรรทัดสุดท้ายจะพิมพ์คะแนนของคุณในเทอร์มินัล

## ลองทำดู

1. วาดหน้าคน: วงกลมสีเหลืองใหญ่ วงกลมสีเข้มเล็กสองวงเป็นตา และส่วนโค้งหนึ่งเส้นเป็นปาก
   (ถ้าหน้าอยู่ที่ `(200, 200)` ลอง `draw_arc(200, 210, 60, 0.4, 2.74, 24)`)
2. ทำให้ลูกบอลเด้ง: เก็บความเร็ว `vx` และ `vy` บวกเข้ากับ `x` และ `y` ทุกเฟรม แล้วกลับเครื่องหมาย
   (`ผูก vx = 0 - vx`) เมื่อชนผนัง
3. ในโปรแกรมวาดภาพ ให้สีเปลี่ยนตามตำแหน่ง x ของตัวชี้: `ผูก เฉดสี = mouse_x() / 640 * 360`
4. เพิ่มคะแนนสูงสุดในเกมเก็บดาว แล้วแสดงไว้ใต้คะแนนด้วย `ข้อความหน้าจอ`
5. เพิ่มระเบิด: วัตถุตกลงมาชิ้นที่สอง วาดเป็นวงกลมสีเข้ม ถ้ารับไว้จะเสียหนึ่งชีวิต
