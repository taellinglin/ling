# ฟังก์ชัน

ฟังก์ชันคือสูตรอาหารที่มีชื่อ เขียนขั้นตอนครั้งเดียวแล้วใช้กี่ครั้งก็ได้ คุณเคยใช้ฟังก์ชันในตัวอย่าง `พิมพ์` `ปัดเศษ`
และ `str` มาแล้ว ในบทเรียนนี้คุณจะเขียนฟังก์ชันของตัวเองด้วย `ฟังก์ชัน` (`fn`) ส่งพารามิเตอร์ให้
รับคำตอบกลับด้วย `คืน` (`return`) และให้ฟังก์ชันเรียกตัวเอง

## นิยามและเรียกใช้ฟังก์ชัน

```ling
ฟังก์ชัน ทักทาย(ชื่อ) {
  พิมพ์("สวัสดี คุณ" + ชื่อ + "!")
}

ผูก เริ่ม = ทำ {
  ทักทาย("เอดา")
  ทักทาย("เกรซ")
  ทักทาย("มินา")
}
```
```output
สวัสดี คุณเอดา!
สวัสดี คุณเกรซ!
สวัสดี คุณมินา!
```

- `ฟังก์ชัน` บอกว่า "กำลังจะนิยามฟังก์ชัน"
- `ทักทาย` คือชื่อของฟังก์ชัน
- `ชื่อ` ในวงเล็บคือ**พารามิเตอร์** เป็นช่องว่างที่จะถูกเติมทุกครั้งที่เรียกฟังก์ชัน
- ในวงเล็บปีกกาคือ**ตัวฟังก์ชัน** ซึ่งเป็นขั้นตอนที่ฟังก์ชันทำ

การนิยามฟังก์ชันไม่ได้ทำให้มันทำงาน ตัวฟังก์ชันจะทำงานเมื่อคุณ**เรียก**ฟังก์ชันเท่านั้น เช่น `ทักทาย("เอดา")`
ค่าในวงเล็บเรียกว่า**อาร์กิวเมนต์** และจะเป็นค่าของ `ชื่อ` ในการเรียกครั้งนั้น

ฟังก์ชันอยู่ที่ระดับบนสุดของไฟล์ นอก `ผูก เริ่ม` ส่วนคำสั่งที่ลงมือทำงานจริงอยู่ใน `เริ่ม`

## รับคำตอบกลับด้วย `คืน`

บ่อยครั้งคุณอยากให้ฟังก์ชันคำนวณบางอย่างแล้วส่งคำตอบกลับมา นั่นคือหน้าที่ของ `คืน` ฟังก์ชันรับพารามิเตอร์ได้หลายตัว
โดยคั่นด้วยจุลภาค

```ling
ฟังก์ชัน กำลังสอง(n) {
  คืน n * n
}

ฟังก์ชัน ค่าเฉลี่ย(a, b) {
  คืน (a + b) / 2
}

ผูก เริ่ม = ทำ {
  พิมพ์(กำลังสอง(7))
  พิมพ์(ค่าเฉลี่ย(10, 25))
  พิมพ์(กำลังสอง(ค่าเฉลี่ย(2, 4)))
}
```
```output
49
17.5
9
```

เพราะ `กำลังสอง(7)` มีค่า คุณจึงใช้มันได้ทุกที่ที่ใส่ค่าได้ ทั้งใน `พิมพ์` ในนิพจน์ที่ใหญ่กว่า
หรือเป็นอาร์กิวเมนต์ของการเรียกอีกครั้ง `กำลังสอง(ค่าเฉลี่ย(2, 4))` คำนวณจากข้างในออกมา `ค่าเฉลี่ย(2, 4)` คือ 3
และ `กำลังสอง(3)` คือ 9

### คืนค่าก่อนกำหนด

`คืน` ตัวแรกที่ทำงานจะจบฟังก์ชันทันที ใช้ข้อนี้จัดการกรณีพิเศษก่อน

```ling
ฟังก์ชัน อธิบาย(n) {
  ถ้า n < 0 {
    คืน "ลบ"
  }
  ถ้า n == 0 {
    คืน "ศูนย์"
  }
  คืน "บวก"
}

ฟังก์ชัน กำลังสาม(n) { n * n * n }

ผูก เริ่ม = ทำ {
  พิมพ์(อธิบาย(-5))
  พิมพ์(อธิบาย(0))
  พิมพ์(อธิบาย(12))
  พิมพ์(กำลังสาม(3))
}
```
```output
ลบ
ศูนย์
บวก
27
```

`อธิบาย` ไม่ต้องใช้ `มิฉะนั้น` เพราะ `คืน` ออกจากฟังก์ชันไปแล้ว `กำลังสาม` แสดงวิธีเขียนแบบย่อ
ถ้าไม่มี `คืน` ฟังก์ชันจะคืนค่าของนิพจน์สุดท้าย ฟังก์ชันที่ไม่ได้คำนวณอะไรอย่าง `ทักทาย` จะคืน `()` ซึ่งคือค่า "ว่างเปล่า"

## ฟังก์ชันมองเห็นอะไรบ้าง

การเรียกแต่ละครั้งมีชื่อส่วนตัวของตัวเอง คือพารามิเตอร์และสิ่งที่ฟังก์ชันผูกไว้เอง ชื่อเหล่านี้ไม่ชนกับชื่อในโค้ดที่เรียกมัน

```ling
ผูก อัตราภาษี = 0.2

ฟังก์ชัน รวมภาษี(ราคา) {
  ผูก ยอดรวม = ราคา + ราคา * อัตราภาษี
  คืน ยอดรวม
}

ผูก เริ่ม = ทำ {
  ผูก ยอดรวม = 99
  พิมพ์(รวมภาษี(50))
  พิมพ์("ยอดรวมของฉันยังเป็น ", ยอดรวม)
}
```
```output
60
ยอดรวมของฉันยังเป็น 99
```

ฟังก์ชันมองเห็นการผูกที่ระดับบนสุดของไฟล์ได้ เช่น `อัตราภาษี` ซึ่งเป็นที่ที่เหมาะกับค่าคงที่ แต่มัน**มองไม่เห็น**
ชื่อเฉพาะที่ของฟังก์ชันที่เรียกมัน จึงต้องส่งสิ่งที่ต้องใช้เข้าไปเป็นอาร์กิวเมนต์

## ฟังก์ชันที่เรียกตัวเอง

ฟังก์ชันเรียกตัวเองได้ เรียกว่า**การเรียกซ้ำ** (recursion) ซึ่งต้องมีสองส่วน

1. **กรณีฐาน** ที่ง่ายจนรู้คำตอบได้ทันที
2. **กรณีเรียกซ้ำ** ที่แก้ปัญหาที่เล็กลงโดยเรียกตัวเอง

แฟกทอเรียลของ 5 คือ `5 * 4 * 3 * 2 * 1` ซึ่งเท่ากับ `5 * แฟกทอเรียล(4)`

```ling
ฟังก์ชัน แฟกทอเรียล(n) {
  ถ้า n <= 1 {
    คืน 1
  }
  คืน n * แฟกทอเรียล(n - 1)
}

ฟังก์ชัน ฟีโบนัชชี(n) {
  ถ้า n < 2 {
    คืน n
  }
  คืน ฟีโบนัชชี(n - 1) + ฟีโบนัชชี(n - 2)
}

ผูก เริ่ม = ทำ {
  พิมพ์("5! = ", แฟกทอเรียล(5))
  พิมพ์("10! = ", แฟกทอเรียล(10))
  สำหรับ i ใน 0..10 {
    พิมพ์("ฟีโบนัชชี(", i, ") = ", ฟีโบนัชชี(i))
  }
}
```
```output
5! = 120
10! = 3628800
ฟีโบนัชชี(0) = 0
ฟีโบนัชชี(1) = 1
ฟีโบนัชชี(2) = 1
ฟีโบนัชชี(3) = 2
ฟีโบนัชชี(4) = 3
ฟีโบนัชชี(5) = 5
ฟีโบนัชชี(6) = 8
ฟีโบนัชชี(7) = 13
ฟีโบนัชชี(8) = 21
ฟีโบนัชชี(9) = 34
```

ลองไล่ `แฟกทอเรียล(3)` ด้วยมือ มันคืน `3 * แฟกทอเรียล(2)` ซึ่งต้องใช้ `2 * แฟกทอเรียล(1)` และ `แฟกทอเรียล(1)`
เป็นกรณีฐานซึ่งได้ 1 จากนั้นคำตอบจะไต่กลับขึ้นไป `2 * 1 = 2` แล้ว `3 * 2 = 6` ถ้าไม่มีกรณีฐาน
ฟังก์ชันจะเรียกตัวเองไปเรื่อยๆ จนหน่วยความจำไม่พอ

## รวมทุกอย่าง: FizzBuzz

นับตั้งแต่ 1 ถึง 15 ถ้าเป็นพหุคูณของ 3 ให้พิมพ์ `Fizz` ถ้าเป็นพหุคูณของ 5 ให้พิมพ์ `Buzz`
ถ้าเป็นพหุคูณของทั้งสองให้พิมพ์ `FizzBuzz` นอกนั้นพิมพ์ตัวเลข

```ling
ฟังก์ชัน fizzbuzz(n) {
  ถ้า n % 15 == 0 {
    คืน "FizzBuzz"
  }
  ถ้า n % 3 == 0 {
    คืน "Fizz"
  }
  ถ้า n % 5 == 0 {
    คืน "Buzz"
  }
  คืน str(n)
}

ผูก เริ่ม = ทำ {
  สำหรับ n ใน 1..16 {
    พิมพ์(fizzbuzz(n))
  }
}
```
```output
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

การตรวจ 15 ต้องมาก่อน ไม่อย่างนั้น 15 จะหยุดที่การตรวจ 3 แล้วพิมพ์แค่ `Fizz` ฟังก์ชันทำหน้าที่แปลงตัวเลขเป็นคำ
ส่วน `เริ่ม` แค่วนลูปและพิมพ์ ฟังก์ชันที่ดีทำเพียงอย่างเดียว รับสิ่งที่ต้องใช้ผ่านพารามิเตอร์ และมีชื่อที่บอกว่ามันทำอะไร

## ฟังก์ชันในฐานะค่า

ในบางภาษา คุณเก็บฟังก์ชันไว้ในการผูกหรือส่งไปให้ฟังก์ชันอื่นได้ Ling มีไวยากรณ์โคลเชอร์แบบสั้นสำหรับเรื่องนี้ คือ `|x| x * 2`
แต่ในเวอร์ชันปัจจุบัน ค่าที่เป็นฟังก์ชันเป็นส่วนที่เชื่อถือได้น้อยที่สุดของภาษา โคลเชอร์ที่เก็บในการผูก หรือฟังก์ชันที่ส่งเป็นอาร์กิวเมนต์
อาจได้ `()` หรือรายงาน `unknown function` รูปแบบเดียวที่ใช้ได้เสมอคือเรียกโคลเชอร์ทันทีตรงที่เขียน

```ling
ผูก เริ่ม = ทำ {
  พิมพ์((|x| x + 1)(5))
}
```
```output
6
```

ตอนนี้ให้เขียน `ฟังก์ชัน` ที่มีชื่อแล้วเรียกด้วยชื่อ ดูรายละเอียดได้ที่ [ข้อจำกัดที่ทราบ](../language/limits.md)

> **เคล็ดลับ:** ถ้าสะกดชื่อฟังก์ชันผิด เอนจินค่าเริ่มต้นจะพิมพ์ `()` แทนที่จะแจ้งข้อผิดพลาด เมื่อฟังก์ชันดูเหมือน
> "ไม่ทำอะไรเลย" ให้รันโปรแกรมด้วย `ling run --interp yourfile.ling` ซึ่งจะรายงาน `unknown function`

## ลองทำดู

1. เขียน `เป็นเลขคู่(n)` ที่คืน `จริง` หรือ `เท็จ` แล้วพิมพ์ `เป็นเลขคู่(10)` และ `เป็นเลขคู่(7)`
2. เขียน `มากสุดสามตัว(a, b, c)` ที่คืนค่ามากที่สุดในสามตัว (ฟังก์ชันในตัว `สูงสุด` รับสองค่า และซ้อนกันได้)
3. เขียน `ผลบวกถึง(n)` ด้วยลูป `ขณะที่` แล้วเขียน `ผลบวกถึงแบบเรียกซ้ำ(n)` ด้วยการเรียกซ้ำ ทั้งสองควรได้ 5050 เมื่อ n เป็น 100
4. เขียน `ยกกำลัง(ฐาน, เลขชี้กำลัง)` แบบเรียกซ้ำโดยใช้แค่การคูณ `ยกกำลัง(2, 10)` คือ 1024
5. เขียน `เกรด(คะแนน)` ที่คืน `"A"` `"B"` `"C"` หรือ `"F"` แล้วพิมพ์เกรดของ 95, 85, 75 และ 40
