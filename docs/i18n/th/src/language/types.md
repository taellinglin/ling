# ชนิดข้อมูลและค่า

Ling เป็นภาษาชนิดข้อมูลแบบไดนามิก คุณไม่ต้องประกาศชนิดเลย ทุกค่ามีชนิดของตัวเอง และตัวดำเนินการกับ
ฟังก์ชันในตัวจะตรวจชนิดตอนทำงาน หน้านี้แสดงชนิดของค่า รูปแบบเวลาพิมพ์ พฤติกรรมในเงื่อนไขและการเปรียบเทียบ
และวิธีแปลงระหว่างชนิด

## ชนิดของค่า

| ชนิด | ตัวอย่าง | สร้างจาก | พิมพ์ออกมาเป็น |
|---|---|---|---|
| ตัวเลข | `3`, `2.5`, `-7` | ลิเทอรัลตัวเลข การคำนวณ | `3`, `2.5` |
| ข้อความ | `"abc"` | ลิเทอรัลข้อความ `+` ฟังก์ชันในตัวด้านข้อความ | `abc` |
| บูลีน | `จริง`, `เท็จ` | ลิเทอรัล การเปรียบเทียบ | `true` |
| ยูนิต | `()` | `()` ฟังก์ชันที่ไม่มีผลลัพธ์ การค้นหาที่ไม่พบ | `()` |
| รายการ | `[1, "a", จริง]` | ลิเทอรัลรายการ `รายการใหม่` ฟังก์ชันในตัวด้านรายการ | `[1, a, true]` |
| เรคคอร์ด | `จุด(3, 4)` | เรียกชื่อที่ประกาศด้วย `โครงสร้าง` | `จุด { x: 3, y: 4 }` |
| ค่าอีนัม | `วงกลม(2)`, `จุดเดี่ยว()` | เรียกแบบที่ประกาศด้วย `เลือกแบบ` | `วงกลม(2)` |
| ผลลัพธ์ | `ตกลง(5)`, `ผิดพลาด("e")` | `ตกลง` และ `ผิดพลาด` | `Ok(5)`, `Err(e)` |
| ฟังก์ชัน | `\|x\| x + 1` | โคลเชอร์ | |

ไม่มีแมป (ดิกชันนารี) เซต ทูเพิล ชนิดตัวอักษร และ `null` ข้อมูลแบบคีย์-ค่าให้ใช้รายการ เรคคอร์ด หรือรายการ
คู่ขนาน หรือเก็บลง SQLite ด้วยฟังก์ชันในตัว `db_*` การระบุชนิดอย่าง `x: number` และ `-> text`
ตัวแยกวิเคราะห์ยอมรับแต่ไม่สนใจ

```ling
โครงสร้าง จุด { x, y }
ผูก เริ่ม = ทำ {
  พิมพ์(42)
  พิมพ์("ข้อความ")
  พิมพ์(จริง)
  พิมพ์(())
  พิมพ์([1, "a", จริง])
  พิมพ์(จุด(3, 4))
  พิมพ์(ตกลง(5))
  พิมพ์(ผิดพลาด("ไม่ได้"))
}
```
```output
42
ข้อความ
true
()
[1, a, true]
จุด { x: 3, y: 4 }
Ok(5)
Err(ไม่ได้)
```

### ตัวเลข

ตัวเลขทุกตัวเป็นจำนวนทศนิยม 64 บิต จำนวนเต็มพิมพ์ออกมาโดยไม่มีจุดทศนิยม จำนวนเต็มไม่เกิน 2^53 แม่นยำ
และการหารให้ผลหารที่แท้จริงเสมอ

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(7 / 2)
  พิมพ์(10 / 5)
  พิมพ์(7 % 3)
  พิมพ์(0.1 + 0.2)
  พิมพ์(1000000 * 1000000)
}
```
```output
3.5
2
1
0.30000000000000004
1000000000000
```

การหารด้วยศูนย์ไม่ใช่ข้อผิดพลาด บนอินเทอร์พรีเตอร์ `1 / 0` คือ `inf` ส่วนบน JIT คือ `()` และทั้งสองเอนจิน
`0 / 0` คือ `NaN`

### ข้อความ

ข้อความคือลำดับของอักขระยูนิโคด `ความยาว` นับจำนวนอักขระ ไม่ใช่จำนวนไบต์ และ `+` ต่อข้อความ ถ้าข้างหนึ่ง
ของ `+` เป็นข้อความ อีกข้างจะถูกแปลงเป็นข้อความ

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(ความยาว("héllo"))
  พิมพ์("ก" + "ข")
  พิมพ์("n=" + 5)
  พิมพ์(5 + "!")
}
```
```output
5
กข
n=5
5!
```

การอ่านอักขระตัวเดียวด้วย `s[i]` ใช้ได้บนอินเทอร์พรีเตอร์เท่านั้น ถ้าต้องการอักขระหนึ่งตัวบนทั้งสองเอนจิน
ให้ใช้ `substr(s, i, 1)`

### รายการ

รายการเก็บค่าชนิดใดก็ได้ เริ่มนับจาก 0 ฟังก์ชันในตัวด้านรายการคืนรายการใหม่ จึงต้องผูกผลลัพธ์ไว้เสมอ:
`ผูก xs = เพิ่มรายการ(xs, v)` การอ่านเลยท้ายรายการได้ค่าว่างบน JIT และทำให้อินเทอร์พรีเตอร์หยุดด้วย
`index N out of bounds` ดูฟังก์ชันในตัวด้านรายการได้ที่[ข้อความและรายการ](../reference/text-lists.md)

### ยูนิต

`()` หมายถึง "ไม่มีอะไร" ฟังก์ชันที่นิพจน์สุดท้ายไม่ให้ค่าจะคืน `()` เช่นเดียวกับ `ถ้า` ที่ไม่มี `มิฉะนั้น`
เมื่อเงื่อนไขเป็นเท็จ และ `จับคู่` ที่ไม่มีแขนไหนตรง

### เรคคอร์ด ค่าอีนัม และผลลัพธ์

เรคคอร์ดมาจาก `โครงสร้าง` ค่าอีนัมมาจาก `เลือกแบบ` และผลลัพธ์มาจาก `ตกลง` กับ `ผิดพลาด` อ่านฟิลด์ของเรคคอร์ด
ด้วย `.ชื่อ` อ่านชื่อแบบของค่าอีนัมด้วย `.tag` และเปิดผลลัพธ์ด้วย `จับคู่` ดู[ไวยากรณ์](syntax.md) และ
[ข้อผิดพลาดและผลลัพธ์](errors.md)

## ค่าความจริงในเงื่อนไข

`ถ้า` และ `ขณะที่` ควรได้รับค่าบูลีนจริงๆ ค่าอื่นก็ใช้ได้ แต่สองเอนจินเห็นไม่ตรงกันทั้งหมด

| ค่าในเงื่อนไข | JIT (ค่าเริ่มต้น) | อินเทอร์พรีเตอร์ |
|---|---|---|
| `จริง` / `เท็จ` | จริง / เท็จ | จริง / เท็จ |
| `0` | เท็จ | เท็จ |
| `()` | เท็จ | เท็จ |
| ตัวเลขอื่น ข้อความที่ไม่ว่าง รายการที่ไม่ว่าง | จริง | จริง |
| `""` (ข้อความว่าง) | **จริง** | เท็จ |
| `[]` (รายการว่าง) | **จริง** | เท็จ |

ตรวจความว่างให้ชัดเจนด้วย `ความยาว(xs) == 0` หรือ `s == ""` และอย่าลืมว่า `!x` หมายถึง `x == เท็จ`
ดังนั้น `!0` และ `!""` ได้ `false` ทั้งคู่ ใช้ `!` กับค่าบูลีนเท่านั้น

## การเปรียบเทียบค่า

`==` และ `!=` เปรียบเทียบตัวเลข ข้อความ บูลีน และ `()` ตามค่า ค่าต่างชนิดกันไม่มีวันเท่ากัน `1 == "1"`
ได้ `false`

**รายการ เรคคอร์ด ค่าอีนัม และผลลัพธ์ไม่มีวันเท่ากัน** แม้เนื้อหาจะเหมือนกันทุกอย่าง ให้เปรียบเทียบสมาชิก
หรือฟิลด์เอง

```ling
โครงสร้าง P { x }
ผูก เริ่ม = ทำ {
  พิมพ์("abc" == "abc")
  พิมพ์(1 == "1")
  พิมพ์([1, 2] == [1, 2])
  พิมพ์(P(1) == P(1))
  พิมพ์(P(1).x == P(1).x)
}
```
```output
true
false
false
false
true
```

`<` `>` `<=` และ `>=` ใช้กับตัวเลข การเรียงลำดับข้อความ (`"a" < "b"`) ได้ `false` บน JIT และเป็น
ข้อผิดพลาดบนอินเทอร์พรีเตอร์

## การแปลงชนิด

| ฟังก์ชันในตัว | แปลง | หมายเหตุ |
|---|---|---|
| `str(v)` | ค่าใดก็ได้เป็นข้อความ | ได้ข้อความเดียวกับที่ `พิมพ์` แสดง เรียกว่า `to_str` ก็ได้ |
| `to_number(s)` | ข้อความเป็นตัวเลข | ไม่สนใจช่องว่างหัวท้าย คืน `0` ถ้าข้อความไม่ใช่ตัวเลข |
| `hex_to_number(s)` | ข้อความฐานสิบหกเป็นตัวเลข | ไม่ต้องมี `0x` นำหน้า: `hex_to_number("ff")` คือ `255` |
| `ตัดทศนิยม(x)` | ตัวเลขเป็นจำนวนเต็ม | ตัดส่วนทศนิยมทิ้งเข้าหาศูนย์ ภาษาอังกฤษคือ `int` (หรือ `trunc`) |
| `ปัดลง(x)` / `ปัดขึ้น(x)` | ตัวเลขเป็นจำนวนเต็ม | ปัดลง / ปัดขึ้น ภาษาอังกฤษคือ `floor` / `ceil` |
| `ปัดเศษ(x)` | ตัวเลขเป็นจำนวนเต็ม | ครึ่งหนึ่งปัดออกห่างจากศูนย์ ภาษาอังกฤษคือ `round` |

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(str(3) + "!")
  พิมพ์(to_number(" 4 ") + 1)
  พิมพ์(to_number("abc"))
  พิมพ์(ตัดทศนิยม(-3.7))
  พิมพ์(ปัดลง(-2.5))
  พิมพ์(ปัดเศษ(2.5))
  พิมพ์(hex_to_number("ff"))
}
```
```output
3!
5
0
-3
-3
3
255
```

ไม่มีฟังก์ชันในตัวที่บอกชนิดของค่า และไม่มีฟังก์ชันในตัวที่แปลงค่าเป็นบูลีน เนื่องจาก `to_number` คืน `0`
เมื่อข้อมูลไม่ถูกต้อง ถ้า `0` เป็นคำตอบที่ถูกได้ด้วย ให้ตรวจข้อความก่อน ดูวิธีได้ในหัวข้อการตรวจสอบข้อมูลเข้า
ของ[ข้อผิดพลาดและผลลัพธ์](errors.md)
