# ไวยากรณ์

หน้านี้อธิบายวิธีเขียนโปรแกรม Ling ได้แก่ โครงสร้างของโปรแกรม ลิเทอรัล ตัวดำเนินการ การผูก ฟังก์ชัน
และการควบคุมการทำงาน ทุกตัวอย่างรันจริงด้วย `ling` เวอร์ชันปัจจุบัน Ling มีเอนจินสองตัว คือ JIT
ซึ่งเป็นค่าเริ่มต้น (`ling run`) และอินเทอร์พรีเตอร์ (`ling run --interp`) ตรงไหนที่สองตัวนี้ทำงานต่างกัน
หน้านี้จะบอกไว้ และ[ข้อจำกัดที่ทราบ](limits.md)รวบรวมความแตกต่างทั้งหมดไว้ในที่เดียว

โค้ดในหน้านี้เขียนด้วยคำสงวนภาษาไทย ดูการสะกดคำสงวนแต่ละคำในภาษาอังกฤษและภาษาอื่นได้ที่[คำสงวน](keywords.md)

## โครงสร้างโปรแกรม

ไฟล์ Ling คือรายการของ**รายการระดับบนสุด** (item) เหล่านี้

| รายการ | รูปแบบ | ดูที่ |
|---|---|---|
| การผูก | `ผูก ชื่อ = นิพจน์` | การผูกและการผูกใหม่ (ด้านล่าง) |
| ฟังก์ชัน | `ฟังก์ชัน ชื่อ(a, b) { ... }` | ฟังก์ชัน (ด้านล่าง) |
| ชนิดเรคคอร์ด | `โครงสร้าง ชื่อ { ฟิลด์, ฟิลด์ }` | เรคคอร์ดและอีนัม (ด้านล่าง) |
| ชนิดอีนัม | `เลือกแบบ ชื่อ { แบบ, แบบ(a) }` | เรคคอร์ดและอีนัม (ด้านล่าง) |
| โมดูล | `โมดูล ชื่อ { ฟังก์ชัน ... }` | [โมดูลและโปรเจกต์](modules.md) |
| การนำเข้า | `ใช้ "ไฟล์.ling"` | [โมดูลและโปรเจกต์](modules.md) |

คำสั่งอย่าง `พิมพ์(...)` เขียนที่ระดับบนสุดไม่ได้ ต้องอยู่ในฟังก์ชันหรือในจุดเริ่มต้นเท่านั้น

### จุดเริ่มต้น

โปรแกรมเริ่มทำงานที่การผูกระดับบนสุดซึ่งมีค่าเป็นบล็อก `ทำ`

```ling
ผูก เริ่ม = ทำ {
  พิมพ์("สวัสดี Ling!")
}
```
```output
สวัสดี Ling!
```

รันไทม์จะมองหาการผูกที่มีชื่อเหล่านี้ตามลำดับ คือ `start` `main` `启` `เริ่ม` `시작` และคำที่มีความหมาย
เดียวกันในภาษาอื่นอีกหลายภาษา ถ้าไม่พบเลย ก็จะรันการผูกระดับบนสุดตัวแรกที่มีค่าเป็นบล็อก `ทำ` ไฟล์ที่ไม่มี
การผูกแบบนี้ถือเป็นไลบรารี และ `ling run` จะแจ้ง `no entry point` แล้วหยุด

```ling
ผูก main = ทำ {
  พิมพ์("ใช้ main ก็ได้")
}
```
```output
ใช้ main ก็ได้
```

> `ฟังก์ชัน main() { ... }` **ไม่ใช่**จุดเริ่มต้น ให้เขียน `ผูก main = ทำ { ... }`

## คอมเมนต์และคำสั่ง

คอมเมนต์เริ่มจาก `#` หรือ `//` ไปจนสุดบรรทัด ไม่มีคอมเมนต์แบบบล็อก คำสั่งแยกกันด้วยการขึ้นบรรทัดใหม่
จะปิดท้ายคำสั่งด้วย `;` ก็ได้ ซึ่งทำให้เขียนสองคำสั่งในบรรทัดเดียวได้

```ling
# คอมเมนต์แบบชาร์ป
// คอมเมนต์แบบสแลช
ผูก เริ่ม = ทำ {
  พิมพ์("ก") // คอมเมนต์ท้ายบรรทัด
  พิมพ์("ข"); พิมพ์("ค")
}
```
```output
ก
ข
ค
```

## ตัวระบุ

ชื่อขึ้นต้นด้วยตัวอักษรหรือ `_` แล้วตามด้วยตัวอักษร ตัวเลข และ `_` ตัวอักษรยูนิโคดใดก็ได้ จึงตั้งชื่อเป็น
ภาษาไทย จีน ญี่ปุ่น หรือเกาหลีได้ ชื่อแยกตัวพิมพ์เล็กและใหญ่

```ling
ผูก เริ่ม = ทำ {
  ผูก 名前 = "Ling"
  ผูก ชื่อ = 3
  พิมพ์(名前)
  พิมพ์(ชื่อ + 1)
}
```
```output
Ling
4
```

คำสงวนที่ยังไม่มีผลอะไร (เช่น `เปลี่ยนแปลง` (`change`) `หยุด` (`stop`) `อาจจะ` (`maybe`) ดู[คำสงวน](keywords.md))
เป็นแค่ชื่อธรรมดาสำหรับตัวแยกวิเคราะห์ ดังนั้น `ผูก หยุด = 2` ใช้ได้ แต่อย่าใช้คำสงวนที่มีผลอย่าง `สำหรับ` (`for`)
หรือ `ถ้า` (`if`) เป็นชื่อ เวลาตั้งชื่อภาษาไทยให้ระวังคำสั้นๆ อย่าง `ทำ` `คืน` `ใน` `ใช้` `ให้` `ส่ง` ด้วย
เพราะคำเหล่านี้เป็นคำสงวน

## ลิเทอรัล

| ลิเทอรัล | รูปแบบ | หมายเหตุ |
|---|---|---|
| ตัวเลข | `42`, `3.14` | ตัวเลขฐานสิบ มีทศนิยมได้ไม่เกินหนึ่งส่วน ตัวเลขทุกตัวเป็นจำนวนทศนิยม 64 บิต |
| ข้อความ | `"สวัสดี"` | ใช้อัญประกาศคู่เท่านั้น เขียนหลายบรรทัดได้ ลำดับหลีก: `\n` `\t` `\r` `\"` `\\` `\0` |
| บูลีน | `จริง`, `เท็จ` | |
| ยูนิต | `()` | ค่าที่หมายถึง "ไม่มีอะไร" |
| รายการ | `[1, "สอง", 3.5]` | สมาชิกเป็นชนิดใดก็ได้ เริ่มนับจาก 0 |
| ช่วง | `0..5` | ไม่รวมตัวท้าย: 0, 1, 2, 3, 4 ใช้กับ `สำหรับ` |
| โคลเชอร์ | `\|x\| x + 1` | ดูหัวข้อโคลเชอร์ด้านล่าง |

ไม่มีรูปแบบ `1e3` `0xff` `1_000` `.5` หรือ `3.` ไม่มีลิเทอรัลตัวอักษรเดี่ยว (`'a'` เป็นข้อผิดพลาดทางไวยากรณ์)
ไม่มีลิเทอรัลแมป และไม่มีทูเพิล ข้อความไม่มีการแทรกค่า `"{x}"` ก็คืออักขระสามตัวนั้นตรงๆ ให้สร้างข้อความด้วย
`+` และ `str()` ลำดับหลีกที่ไม่รู้จักอย่าง `\q` จะถูกเก็บไว้ตามที่เขียน รวมทั้งแบ็กสแลชด้วย

```ling
ผูก เริ่ม = ทำ {
  พิมพ์("บรรทัดแรก\nบรรทัดที่สอง")
  พิมพ์("อัญประกาศ: \"q\" แบ็กสแลช: \\")
  พิมพ์(1.5 + 1)
  พิมพ์([1, "สอง", 3.5, จริง])
  พิมพ์(())
}
```
```output
บรรทัดแรก
บรรทัดที่สอง
อัญประกาศ: "q" แบ็กสแลช: \
2.5
[1, สอง, 3.5, true]
()
```

## ตัวดำเนินการและลำดับความสำคัญ

เรียงจากผูกแน่นที่สุดไปหาหลวมที่สุด

| ระดับ | ตัวดำเนินการ | หมายเหตุ |
|---|---|---|
| 1 | `.` `()` `[]` `::` `..` | ฟิลด์หรือเมธอด การเรียก ดัชนี เส้นทางโมดูล ช่วง |
| 2 | `-x` `!x` | เครื่องหมายลบนำหน้าและนิเสธ |
| 3 | `*` `/` `%` | `%` ใช้กับทศนิยมได้: `7.5 % 2` คือ `1.5` |
| 4 | `+` `-` | `+` ต่อข้อความ ถ้าข้างหนึ่งเป็นข้อความ ตัวเลขอีกข้างจะถูกแปลงเป็นข้อความ |
| 5 | `==` `!=` `<` `>` `<=` `>=` | |
| 6 | `&&` | |
| 7 | `\|\|` | |

ตัวดำเนินการสองตัวถูกดำเนินการทุกตัวจัดกลุ่มจากซ้าย `10 - 3 - 2` ได้ `5`

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(2 + 3 * 4)
  พิมพ์((2 + 3) * 4)
  พิมพ์(10 - 3 - 2)
  พิมพ์(-3 + 5)
  พิมพ์(2 * -4)
  พิมพ์(1 < 2 && 2 < 3)
  พิมพ์("n=" + 5)
  พิมพ์(7 / 2)
}
```
```output
14
20
5
2
-8
true
n=5
3.5
```

สิ่งที่ต้องระวัง

- `&&` และ `||` **ประเมินทั้งสองข้างเสมอ** บนทั้งสองเอนจิน `x != 0 && 10 / x > 1` จึงไม่ได้ป้องกันการหาร
  ให้ใช้ `ถ้า` ซ้อนกันแทน
- การเปรียบเทียบต่อกันจากซ้าย `1 == 1 == 1` หมายถึง `(1 == 1) == 1` ซึ่งได้ `false`
- เครื่องหมายลบนำหน้าซ้อนกันไม่ได้ `- - x` เป็นข้อผิดพลาดทางไวยากรณ์ ส่วน `0 - x` ใช้ได้เสมอ
- `==` ระหว่างรายการ เรคคอร์ด และค่าอีนัมได้ `false` เสมอ ดู[ชนิดข้อมูลและค่า](types.md)

## การผูกและการผูกใหม่

`ผูก ชื่อ = นิพจน์` ตั้งชื่อให้ค่า ไม่มีการกำหนดค่า (assignment) `x = 5` เป็นข้อผิดพลาดทางไวยากรณ์
ถ้าจะ "เปลี่ยน" ค่า ให้ผูกชื่อเดิมอีกครั้ง การผูกใหม่จะแทนที่การผูกเก่าตั้งแต่จุดนั้นเป็นต้นไป

```ling
ผูก เริ่ม = ทำ {
  ผูก x = 1
  ผูก x = x + 10
  ผูก x = x * 2
  พิมพ์(x)
}
```
```output
22
```

การผูกใหม่ภายในบล็อกจะยังมองเห็นหลังบล็อกจบหรือไม่ ขึ้นอยู่กับชนิดของบล็อก

| อยู่ภายใน | การผูกใหม่หลังบล็อกจบ |
|---|---|
| ตัวของ `ถ้า` / `มิฉะนั้น` | ยังอยู่ |
| ตัวของ `ขณะที่` | ยังอยู่ ลูป `ขณะที่` จึงสะสมค่าได้ |
| ตัวของ `สำหรับ` | **หายไป** แต่ละรอบเริ่มจากสำเนาใหม่ |
| แขนของ `จับคู่` | หายไป |
| ตัวฟังก์ชัน | อยู่เฉพาะในการเรียกครั้งนั้น |
| บล็อก `ทำ { }` | หายไปบนอินเทอร์พรีเตอร์ แต่ยังอยู่บน JIT อย่าพึ่งพาแบบใดแบบหนึ่ง |

```ling
ผูก เริ่ม = ทำ {
  ผูก ยอดรวม = 0
  สำหรับ i ใน 1..5 { ผูก ยอดรวม = ยอดรวม + i }
  พิมพ์(ยอดรวม)
  ผูก ผลบวก = 0
  ผูก i = 1
  ขณะที่ i < 5 {
    ผูก ผลบวก = ผลบวก + i
    ผูก i = i + 1
  }
  พิมพ์(ผลบวก)
}
```
```output
0
10
```

`ผูก` ระดับบนสุดเป็นค่าคงที่ส่วนกลาง ฟังก์ชันอ่านค่านี้ได้ แต่จะไม่เห็นการผูกภายในของผู้เรียกเลย

```ling
ผูก อัตรา = 3
ฟังก์ชัน ขยาย(n) { n * อัตรา }
ผูก เริ่ม = ทำ {
  ผูก อัตรา = 100
  พิมพ์(ขยาย(2))
}
```
```output
6
```

## บล็อก

`ทำ { ... }` รันคำสั่งข้างในตามลำดับ และมีค่าเท่ากับคำสั่งสุดท้าย จุดเริ่มต้นก็เป็นบล็อก `ทำ` และใช้บล็อกนี้
ได้ทุกที่ที่เขียนนิพจน์ได้

```ling
ผูก เริ่ม = ทำ {
  ผูก รวมทั้งหมด = ทำ {
    ผูก a = 20
    ผูก b = 22
    a + b
  }
  พิมพ์(รวมทั้งหมด)
}
```
```output
42
```

## ฟังก์ชัน

`ฟังก์ชัน ชื่อ(พารามิเตอร์) { ตัวฟังก์ชัน }` ประกาศฟังก์ชันที่ระดับบนสุด (หรือใน `โมดูล`) ผลลัพธ์คือนิพจน์
สุดท้ายในตัวฟังก์ชัน `คืน ค่า` ออกก่อนกำหนด และ `คืน` เปล่าๆ คืน `()` ฟังก์ชันเรียกตัวเองซ้ำได้และประกาศ
ลำดับใดก็ได้ แต่ซ้อนฟังก์ชันไว้ในฟังก์ชันอื่นไม่ได้

```ling
ฟังก์ชัน ฟีโบนัชชี(n) {
  ถ้า n < 2 { คืน n }
  ฟีโบนัชชี(n - 1) + ฟีโบนัชชี(n - 2)
}
ฟังก์ชัน ทักทาย(ชื่อ) { "สวัสดี " + ชื่อ + "!" }
ผูก เริ่ม = ทำ {
  พิมพ์(ฟีโบนัชชี(15))
  พิมพ์(ทักทาย("Ling"))
}
```
```output
610
สวัสดี Ling!
```

- การระบุชนิดอย่าง `ฟังก์ชัน f(a: number) -> text` ถูกยอมรับแล้วไม่สนใจ
- ถ้าส่งอาร์กิวเมนต์น้อยเกินไป พารามิเตอร์ที่ขาดจะไม่มีค่า ถ้านำไปใช้ อินเทอร์พรีเตอร์จะแจ้งข้อผิดพลาด
  ส่วน JIT จะได้ `()`
- การเรียกฟังก์ชันที่ไม่มีอยู่เป็นข้อผิดพลาดบนอินเทอร์พรีเตอร์ แต่ JIT จะคืน `()` เงียบๆ เมื่อโปรแกรม
  "ไม่ทำอะไรเลย" ให้ลองรันด้วย `ling run --interp`

## โคลเชอร์

โคลเชอร์เขียนแบบ `|พารามิเตอร์| นิพจน์` เช่น `|x| x * 2` โคลเชอร์ที่ไม่มีพารามิเตอร์ต้องเว้นวรรคเป็น `| | 42`
เพราะ `||` คือตัวดำเนินการ "หรือ"

การเรียกนิพจน์โคลเชอร์ทันทีใช้ได้ทุกที่

```ling
ผูก เริ่ม = ทำ {
  พิมพ์((|x| x + 1)(5))
}
```
```output
6
```

โคลเชอร์เป็นส่วนที่เชื่อถือได้น้อยที่สุดของภาษาในตอนนี้ โคลเชอร์ที่เก็บไว้ในตัวแปรเรียกด้วยชื่อบน
อินเทอร์พรีเตอร์ไม่ได้ และ JIT ส่งโคลเชอร์ (หรือชื่อฟังก์ชัน) ให้ฟังก์ชันในตัวอย่าง `list_map` หรือ `ลอง` (`try`)
ไม่ได้ ให้ใช้ `ฟังก์ชัน` ที่มีชื่อแทน ดู[ข้อจำกัดที่ทราบ](limits.md)

## การควบคุมการทำงาน

### if / else

`ถ้า` (`if`) เป็นนิพจน์ ต้องมีวงเล็บปีกกาเสมอ และเงื่อนไขไม่ต้องมีวงเล็บ ถ้าไม่มี `มิฉะนั้น` (`else`)
และเงื่อนไขเป็นเท็จ `ถ้า` จะได้ `()`

```ling
ผูก เริ่ม = ทำ {
  ผูก n = 7
  ผูก ป้าย = ถ้า n < 0 { "ลบ" } มิฉะนั้น ถ้า n == 0 { "ศูนย์" } มิฉะนั้น { "บวก" }
  พิมพ์(ป้าย)
}
```
```output
บวก
```

ให้ใช้ค่าบูลีนจริงๆ ในเงื่อนไข สองเอนจินมอง `""` และ `[]` ต่างกัน ดู[ชนิดข้อมูลและค่า](types.md)

### while

`ขณะที่ เงื่อนไข { ตัวลูป }` (`while`) ทำซ้ำตราบที่เงื่อนไขเป็นจริง ตัวลูปใช้ขอบเขตร่วมกับด้านนอก
จึงเป็นลูปที่ใช้กับตัวนับและผลรวม

```ling
ผูก เริ่ม = ทำ {
  ผูก n = 27
  ผูก จำนวนก้าว = 0
  ขณะที่ n != 1 {
    ผูก n = ถ้า n % 2 == 0 { n / 2 } มิฉะนั้น { 3 * n + 1 }
    ผูก จำนวนก้าว = จำนวนก้าว + 1
  }
  พิมพ์(จำนวนก้าว)
}
```
```output
111
```

### for

`สำหรับ ชื่อ ใน ลำดับ { ตัวลูป }` (`for ... in`) รันตัวลูปหนึ่งครั้งต่อสมาชิกแต่ละตัวของช่วงหรือรายการ
ช่วง `lo..hi` หยุดก่อนถึง `hi`

```ling
ผูก เริ่ม = ทำ {
  สำหรับ i ใน 1..4 { พิมพ์(i * i) }
  สำหรับ ชื่อ ใน ["ada", "lin"] { พิมพ์(str_upper(ชื่อ)) }
}
```
```output
1
4
9
ADA
LIN
```

ไม่มี `break` หรือ `continue` ถ้าจะหยุดก่อน ให้ใส่ลูปไว้ในฟังก์ชันแล้ว `คืน` หรือใช้ลูป `ขณะที่` กับตัวแปรธง

### match

`จับคู่ ค่า { แพตเทิร์น => นิพจน์, ... }` (`match`) ลองแต่ละแขนจากบนลงล่าง แล้วประเมินแขนแรกที่ตรง
แพตเทิร์นมีดังนี้

| แพตเทิร์น | ตรงกับ |
|---|---|
| `_` | ทุกอย่าง |
| `0`, `"ใช่"`, `จริง` | ค่าลิเทอรัลนั้น |
| `ชื่อ` | ทุกอย่าง และผูกค่านั้นกับ `ชื่อ` |
| `ตกลง(p)`, `ผิดพลาด(p)` | ผลลัพธ์ (ดู[ข้อผิดพลาดและผลลัพธ์](errors.md)) |
| `แบบ(p, ...)`, `แบบ()` | ค่าอีนัม |

```ling
ฟังก์ชัน จัดกลุ่ม(n) {
  จับคู่ n {
    0 => "ศูนย์",
    1 => "หนึ่ง",
    อื่นๆ => "หลายตัว (" + str(อื่นๆ) + ")"
  }
}
ผูก เริ่ม = ทำ {
  พิมพ์(จัดกลุ่ม(0))
  พิมพ์(จัดกลุ่ม(9))
}
```
```output
ศูนย์
หลายตัว (9)
```

ถ้าไม่มีแขนไหนตรง `จับคู่` จะได้ `()` ไม่มีเงื่อนไขกำกับ (guard) และไม่มีแพตเทิร์นสำหรับรายการหรือเรคคอร์ด

## เรคคอร์ดและอีนัม

`โครงสร้าง` (`form`) ประกาศชนิดเรคคอร์ด สร้างเรคคอร์ดโดยเรียกชื่อชนิดพร้อมฟิลด์ตามลำดับ และอ่านฟิลด์ด้วย `.`

```ling
โครงสร้าง จุด { x, y }
ผูก เริ่ม = ทำ {
  ผูก p = จุด(3, 4)
  พิมพ์(p)
  พิมพ์(p.x + p.y)
}
```
```output
จุด { x: 3, y: 4 }
7
```

`เลือกแบบ` (`choose`) ประกาศอีนัมที่แต่ละแบบมีค่าติดไปได้ สร้างค่าโดยเรียกแบบนั้น และแยกค่าด้วย `จับคู่`
แบบที่ไม่มีค่าติดไปก็ยังต้องเขียนวงเล็บ เช่น `จุดเดี่ยว()` ชื่อของแบบอ่านได้จาก `.tag`

```ling
เลือกแบบ รูปร่าง { วงกลม(r), สี่เหลี่ยม(w, h), จุดเดี่ยว }
ฟังก์ชัน พื้นที่(s) {
  จับคู่ s {
    วงกลม(r) => 3 * r * r,
    สี่เหลี่ยม(w, h) => w * h,
    จุดเดี่ยว() => 0
  }
}
ผูก เริ่ม = ทำ {
  พิมพ์(พื้นที่(วงกลม(2)))
  พิมพ์(พื้นที่(สี่เหลี่ยม(3, 4)))
  พิมพ์(พื้นที่(จุดเดี่ยว()))
  พิมพ์(สี่เหลี่ยม(1, 2).tag)
}
```
```output
12
12
0
สี่เหลี่ยม
```

เรคคอร์ดแก้ไขไม่ได้ ถ้าต้องการให้สร้างใหม่ ไม่รองรับไวยากรณ์ลิเทอรัลแบบ `จุด { x: 1, y: 2 }` การเรียก
คอนสตรักเตอร์ด้วยจำนวนฟิลด์ผิดเป็นข้อผิดพลาดบนอินเทอร์พรีเตอร์ และได้ `()` บน JIT

## กับดักในการแยกวิเคราะห์

- **บรรทัดที่ขึ้นต้นด้วย `-` หรือ `[` จะต่อจากบรรทัดก่อนหน้า** ถ้าบรรทัดถัดจาก `ผูก x = 5` คือ `-1`
  `x` จะกลายเป็น `4` และบรรทัดที่ขึ้นต้นด้วย `[1, 2]` จะถูกอ่านเป็นการใช้ดัชนี
- **ขอบเขตของช่วง** `0..n + 1` เป็นข้อผิดพลาดทางไวยากรณ์ และ `0..ความยาว(xs)` ทำงานผิดเงียบๆ อะไรที่ไม่ใช่
  ชื่อหรือตัวเลขเดี่ยวๆ ให้ครอบด้วยวงเล็บ: `0..(n + 1)` `0..(ความยาว(xs))`
- **การระบุชนิดฟิลด์ใน `โครงสร้าง`** `โครงสร้าง P { x: number, y: number }` เป็นข้อผิดพลาดทางไวยากรณ์
  เพราะการระบุชนิดที่อยู่ติดกับ `}` จะกลืนวงเล็บปิดไป ให้ปิดท้ายรายการด้วยจุลภาค:
  `โครงสร้าง P { x: number, y: number, }`
- **ไม่มีการกำหนดค่า** `x = x + 1` เป็นข้อผิดพลาดทางไวยากรณ์ ให้เขียน `ผูก x = x + 1`
- **โคลเชอร์ไม่มีพารามิเตอร์** ให้เขียน `| | นิพจน์` ไม่ใช่ `|| นิพจน์`
