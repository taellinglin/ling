# ข้อผิดพลาดและผลลัพธ์

Ling ไม่มีเอ็กเซปชัน ฟังก์ชันที่อาจล้มเหลวจะคืน**ผลลัพธ์** คือ `ตกลง(ค่า)` เมื่อสำเร็จ หรือ `ผิดพลาด(เหตุผล)`
เมื่อไม่สำเร็จ ผู้เรียกเปิดผลลัพธ์ด้วย `จับคู่` หน้านี้อธิบายผลลัพธ์ ฟังก์ชันในตัว `ลอง` ข้อผิดพลาดขณะทำงาน
และเทรซแบ็ก รวมถึงธรรมเนียม "ล้มเหลวแบบนุ่มนวล" ที่ฟังก์ชันในตัวส่วนใหญ่ใช้

| เครื่องมือ | ใช้เมื่อ |
|---|---|
| `ตกลง(ค่า)` / `ผิดพลาด(เหตุผล)` | คืนความสำเร็จหรือความล้มเหลวจากฟังก์ชันของคุณเอง |
| `จับคู่ r { ตกลง(v) => ..., ผิดพลาด(e) => ... }` | จัดการทั้งสองกรณี |
| `ลอง(f, อาร์กิวเมนต์...)` | เปลี่ยนข้อผิดพลาดขณะทำงานเป็นผลลัพธ์ `ผิดพลาด` (อินเทอร์พรีเตอร์เท่านั้น) |
| `ling run --interp` | ดูข้อผิดพลาดขณะทำงานพร้อมเทรซแบ็ก |

## ผลลัพธ์: ตกลงและผิดพลาด

`ตกลง(ค่า)` ห่อค่าที่สำเร็จ และ `ผิดพลาด(เหตุผล)` ห่อความล้มเหลว เหตุผลมักเป็นข้อความ แต่จะเป็นค่าใดก็ได้
ผลลัพธ์พิมพ์ออกมาเป็น `Ok(...)` หรือ `Err(...)` (ตอนสร้างผลลัพธ์ ใช้ `err` แทน `ผิดพลาด` ได้ แต่ในแพตเทิร์น
ต้องใช้ `ผิดพลาด`)

```ling
ฟังก์ชัน หารอย่างปลอดภัย(a, b) {
  ถ้า b == 0 { ผิดพลาด("หารด้วยศูนย์") } มิฉะนั้น { ตกลง(a / b) }
}
ผูก เริ่ม = ทำ {
  พิมพ์(หารอย่างปลอดภัย(6, 3))
  พิมพ์(หารอย่างปลอดภัย(1, 0))
}
```
```output
Ok(2)
Err(หารด้วยศูนย์)
```

## จัดการผลลัพธ์ด้วยจับคู่

`ตกลง(v)` และ `ผิดพลาด(e)` เป็นแพตเทิร์นด้วย ชื่อในวงเล็บจะถูกผูกกับค่าที่ถูกห่อไว้ภายในแขนนั้น

```ling
ฟังก์ชัน หารอย่างปลอดภัย(a, b) {
  ถ้า b == 0 { ผิดพลาด("หารด้วยศูนย์") } มิฉะนั้น { ตกลง(a / b) }
}
ฟังก์ชัน แสดง(r) {
  จับคู่ r {
    ตกลง(v) => "ค่า " + str(v),
    ผิดพลาด(เหตุ) => "ล้มเหลว: " + เหตุ
  }
}
ผูก เริ่ม = ทำ {
  พิมพ์(แสดง(หารอย่างปลอดภัย(8, 2)))
  พิมพ์(แสดง(หารอย่างปลอดภัย(8, 0)))
}
```
```output
ค่า 4
ล้มเหลว: หารด้วยศูนย์
```

`จับคู่` เป็นวิธีเดียวที่จะดูข้างในผลลัพธ์ การเขียนฟังก์ชันช่วยเล็กๆ ไว้จึงคุ้มค่า

```ling
ฟังก์ชัน ค่าหรือ(r, ค่าสำรอง) {
  จับคู่ r {
    ตกลง(v) => v,
    _ => ค่าสำรอง
  }
}
ฟังก์ชัน รากอย่างปลอดภัย(x) {
  ถ้า x < 0 { ผิดพลาด("ติดลบ") } มิฉะนั้น { ตกลง(รากที่สอง(x)) }
}
ผูก เริ่ม = ทำ {
  พิมพ์(ค่าหรือ(รากอย่างปลอดภัย(16), 0))
  พิมพ์(ค่าหรือ(รากอย่างปลอดภัย(-16), 0))
}
```
```output
4
0
```

> การเรียกเมธอดกับผลลัพธ์จะได้ค่าที่ถูกห่อไว้ (`ตกลง(5).anything` คือ `5`) ซึ่งแทบไม่ใช่สิ่งที่คุณต้องการ
> ให้ใช้ `จับคู่`

## การตรวจสอบข้อมูลเข้า

ตรวจกฎทีละข้อ และให้เหตุผลแยกกันสำหรับความล้มเหลวแต่ละแบบ

```ling
ฟังก์ชัน แปลงอายุ(ข้อความ) {
  ผูก t = trim(ข้อความ)
  ถ้า ความยาว(t) == 0 {
    ผิดพลาด("ไม่ได้ป้อนข้อมูล")
  } มิฉะนั้น ถ้า to_number(t) == 0 && t != "0" {
    ผิดพลาด("ไม่ใช่ตัวเลข: " + t)
  } มิฉะนั้น ถ้า to_number(t) > 130 {
    ผิดพลาด("มากเกินไป: " + t)
  } มิฉะนั้น {
    ตกลง(to_number(t))
  }
}
ฟังก์ชัน แสดง(r) {
  จับคู่ r {
    ตกลง(v) => "อายุ " + str(v),
    ผิดพลาด(เหตุ) => "ปฏิเสธ (" + เหตุ + ")"
  }
}
ผูก เริ่ม = ทำ {
  สำหรับ s ใน ["42", " 7 ", "", "สี่สิบ", "200"] {
    พิมพ์(แสดง(แปลงอายุ(s)))
  }
}
```
```output
อายุ 42
อายุ 7
ปฏิเสธ (ไม่ได้ป้อนข้อมูล)
ปฏิเสธ (ไม่ใช่ตัวเลข: สี่สิบ)
ปฏิเสธ (มากเกินไป: 200)
```

เมื่อขั้นตอนหนึ่งขึ้นกับอีกขั้นตอนหนึ่ง ให้ซ้อน `จับคู่` และเติมบริบทให้ `ผิดพลาด` แต่ละตัว ข้อความสุดท้าย
จะได้บอกว่าผิดพลาดที่ตรงไหน

```ling
ฟังก์ชัน แปลงตัวเลข(ข้อความ) {
  ผูก n = to_number(ข้อความ)
  ถ้า n == 0 && ข้อความ != "0" { ผิดพลาด("ไม่ใช่ตัวเลข: " + ข้อความ) } มิฉะนั้น { ตกลง(n) }
}
ฟังก์ชัน พื้นที่(ข้อความกว้าง, ข้อความสูง) {
  จับคู่ แปลงตัวเลข(ข้อความกว้าง) {
    ผิดพลาด(e) => ผิดพลาด("ความกว้าง: " + e),
    ตกลง(w) => จับคู่ แปลงตัวเลข(ข้อความสูง) {
      ผิดพลาด(e) => ผิดพลาด("ความสูง: " + e),
      ตกลง(h) => ตกลง(w * h)
    }
  }
}
ผูก เริ่ม = ทำ {
  พิมพ์(พื้นที่("4", "2.5"))
  พิมพ์(พื้นที่("4", "x"))
}
```
```output
Ok(10)
Err(ความสูง: ไม่ใช่ตัวเลข: x)
```

## ข้อผิดพลาดขณะทำงานและเทรซแบ็ก

ปัญหาบางอย่างจะหยุดโปรแกรมด้วย**ข้อผิดพลาดขณะทำงาน** เช่น เรียกฟังก์ชันที่ไม่รู้จัก อ่านไฟล์ที่ไม่มีอยู่
ใช้ดัชนีเลยท้ายรายการ หรือเรียกคอนสตรักเตอร์ด้วยจำนวนฟิลด์ผิด อินเทอร์พรีเตอร์จะพิมพ์ข้อผิดพลาด ชื่อไฟล์
และเทรซแบ็กที่เรียงการเรียกที่ลึกที่สุดไว้ท้ายสุด

```ling-module
ฟังก์ชัน โหลด(ที่อยู่) { read_file(ที่อยู่) }
ฟังก์ชัน ดำเนินการ() { โหลด("no_such_file.txt") }
ผูก เริ่ม = ทำ {
  พิมพ์(ดำเนินการ())
}
```

```sh
$ ling run --interp broken.ling
[detected language: Thai (ภาษาไทย)]
error[runtime]: read_file 'no_such_file.txt': The system cannot find the file specified. (os error 2)
 --> broken.ling
  traceback (deepest call last):
    0: start
    1: ดำเนินการ
    2: โหลด
```

โปรแกรมหยุดพร้อมรหัสออกที่ไม่ใช่ศูนย์ (ข้อความจากระบบปฏิบัติการหลังเครื่องหมายทวิภาคขึ้นอยู่กับระบบของคุณ)

> **JIT ไม่หยุด** บนเอนจินค่าเริ่มต้น ปัญหาเหล่านี้ส่วนใหญ่จะได้ `()` เงียบๆ และโปรแกรมทำงานต่อ โปรแกรม
> ด้านบนพิมพ์ `()` เมื่อรันด้วย `ling run` เมื่อโปรแกรมทำงานแปลกๆ ให้รันด้วย `ling run --interp` สักครั้ง
> เพื่อดูข้อผิดพลาดจริง

Ling ไม่มีฟังก์ชันในตัว `assert` `panic` หรือ `exit` ถ้าจะแจ้งความล้มเหลว ให้คืนผลลัพธ์ `ผิดพลาด`
และพิมพ์ข้อความที่ชัดเจน

## ลอง: ดักข้อผิดพลาดขณะทำงาน

`ลอง(f, อาร์กิวเมนต์...)` (`try`) เรียก `f` ด้วยอาร์กิวเมนต์ที่ให้ไว้ ถ้าการเรียกสำเร็จจะคืน `ตกลง(ผลลัพธ์)`
ถ้าเกิดข้อผิดพลาดขณะทำงานจะคืน `ผิดพลาด(ข้อความ)` ให้ส่งตัวฟังก์ชันเอง (ชื่อเปล่าๆ ไม่มีวงเล็บ) ตามด้วย
อาร์กิวเมนต์ จะใช้โคลเชอร์ก็ได้ เช่น `ลอง(| | 6 * 7)`

**`ลอง` ใช้ได้บนอินเทอร์พรีเตอร์เท่านั้น** JIT ส่งฟังก์ชันให้ฟังก์ชันในตัวไม่ได้ บน JIT `ลอง` จึงคืน
`ผิดพลาด("try: first argument must be a function")` เสมอ

```ling
ฟังก์ชัน บวกหนึ่ง(x) { x + 1 }
ฟังก์ชัน พัง(x) { ฟังก์ชันที่ไม่มีอยู่(x) }
ผูก เริ่ม = ทำ {
  พิมพ์(ลอง(บวกหนึ่ง, 4))
  พิมพ์(ลอง(พัง, 4))
}
```
```output
Err(try: first argument must be a function)
Err(try: first argument must be a function)
```

โปรแกรมเดียวกันบนอินเทอร์พรีเตอร์

```sh
$ ling run --interp try_demo.ling
[detected language: Thai (ภาษาไทย)]
Ok(5)
Err(unknown function 'ฟังก์ชันที่ไม่มีอยู่')
```

โปรแกรมที่เรียก `http_serve` จะรันบนอินเทอร์พรีเตอร์เสมอ `ลอง` จึงใช้ได้ในตัวจัดการคำขอเว็บ ในที่อื่นๆ
ให้ถือว่า `ลอง` เป็นเครื่องมือช่วยระหว่างพัฒนา และเขียนฟังก์ชันของคุณให้คืน `ตกลง` และ `ผิดพลาด` เอง

## การล้มเหลวแบบนุ่มนวลของฟังก์ชันในตัว

ฟังก์ชันในตัวส่วนใหญ่ไม่คืนผลลัพธ์ เมื่อล้มเหลวจะคืนค่ากลางที่ไม่เป็นอันตรายแล้วทำงานต่อ

| ฟังก์ชันในตัว | เมื่อล้มเหลว |
|---|---|
| `to_number("x")` | `0` |
| `รับรายการ(xs, 99)` | `""` (ข้อความว่าง) |
| `str_find("abc", "z")` | `-1` |
| `file_exists(ที่อยู่)` | `false` |
| `read_file("missing.txt")` | `()` บน JIT และข้อผิดพลาดขณะทำงานบนอินเทอร์พรีเตอร์ |

```ling
ผูก เริ่ม = ทำ {
  พิมพ์(to_number("กล้วย"))
  พิมพ์("[" + รับรายการ([1, 2, 3], 99) + "]")
  พิมพ์(str_find("สวัสดี", "z"))
  พิมพ์(file_exists("no-such-file.txt"))
}
```
```output
0
[]
-1
false
```

ความล้มเหลวอาจดูเหมือนค่าจริง `to_number("0")` และ `to_number("ศูนย์")` ได้ `0` ทั้งคู่ จึงควรถามก่อน
เรียก `file_exists` ก่อน `read_file` เทียบดัชนีกับ `ความยาว(xs)` และตรวจข้อความก่อนเชื่อ `to_number`
ฟังก์ชันห่อเล็กๆ เปลี่ยนการล้มเหลวแบบนุ่มนวลให้เป็นผลลัพธ์จริงได้

```ling
ฟังก์ชัน อ่านข้อความ(ที่อยู่) {
  ถ้า file_exists(ที่อยู่) { ตกลง(read_file(ที่อยู่)) } มิฉะนั้น { ผิดพลาด("ไม่มีไฟล์: " + ที่อยู่) }
}
ผูก เริ่ม = ทำ {
  พิมพ์(อ่านข้อความ("missing.cfg"))
}
```
```output
Err(ไม่มีไฟล์: missing.cfg)
```
