# คำสงวน

คำสงวนทุกคำของ Ling มีตัวสะกดภาษาอังกฤษ และตัวสะกดภาษาจีน ญี่ปุ่น เกาหลี และไทย ตัวแยกคำ (lexer)
จะแปลงทุกตัวสะกดเป็นโทเคนเดียวกัน คุณจึงเขียนทั้งโปรแกรมด้วยภาษาเดียว หรือผสมหลายภาษาก็ได้ หน้านี้แสดง
คำสงวนทุกคำ ตัวสะกดของแต่ละคำ และสิ่งที่คำนั้นทำได้จริงในตอนนี้

คำสงวนบางคำสงวนไว้สำหรับความสามารถในอนาคตและยังไม่ทำอะไรเลย ด้านล่างได้ทำเครื่องหมายไว้ คุณจะได้ไม่แปลกใจ
เมื่อ `หยุด` (`stop`) ไม่ได้พาออกจากลูป

## ตัวสะกด

ถ้าช่องไหนมีหลายตัวสะกด ใช้ได้ทุกตัว โดยตัวแรกคือตัวที่ใช้กันทั่วไป ตัวสะกดเหล่านี้นำมาจากตัวแยกคำ
(`src/lexer/mod.rs`) ซึ่งเป็นสิ่งที่รันไทม์ยอมรับจริง มีบางจุดที่ไม่ตรงกับ `lexicons/*.ling` และในกรณีนั้น
ให้ยึดตัวแยกคำ เช่น `choose` ภาษาญี่ปุ่นคือ `選択` `form` ภาษาเกาหลีคือ `구조` และ `form` ภาษาไทยคือ
`โครงสร้าง` (ไม่ใช่ `รูปแบบ`) ส่วน `choose` ภาษาไทยคือ `เลือกแบบ` (ไม่ใช่ `เลือก`)

## คำสงวนแต่ละคำทำอะไร

| คำสงวน | สถานะ | สิ่งที่ทำ |
|---|---|---|
| `ผูก` (`bind`) | ใช้งานได้ | สร้างหรือแทนที่การผูก ใช้กำหนดค่าส่วนกลางและจุดเริ่มต้นด้วย |
| `ทำ` (`do`) | ใช้งานได้ | บล็อกที่มีค่าเท่ากับคำสั่งสุดท้าย |
| `ฟังก์ชัน` (`fn`) | ใช้งานได้ | ประกาศฟังก์ชัน |
| `ถ้า` / `มิฉะนั้น` (`if` / `else`) | ใช้งานได้ | นิพจน์เงื่อนไข |
| `ขณะที่` (`while`) | ใช้งานได้ | วนซ้ำตราบที่เงื่อนไขเป็นจริง ตัวลูปใช้ขอบเขตร่วมกับด้านนอก |
| `สำหรับ` / `ใน` (`for` / `in`) | ใช้งานได้ | วนผ่านช่วงหรือรายการ แต่ละรอบได้ขอบเขตใหม่ |
| `จับคู่` (`match`) | ใช้งานได้ | การจับคู่แพตเทิร์น |
| `คืน` (`return`) | ใช้งานได้ | ออกจากฟังก์ชันปัจจุบันพร้อมค่า |
| `โครงสร้าง` (`form`) | ใช้งานได้ | ประกาศชนิดเรคคอร์ด |
| `เลือกแบบ` (`choose`) | ใช้งานได้ | ประกาศชนิดอีนัมที่แต่ละแบบมีค่าติดไปได้ |
| `โมดูล` (`mod`) | ใช้งานได้ | รวมฟังก์ชันไว้ในเนมสเปซ (`ชื่อ::f()`) |
| `ใช้` / `เป็น` (`use` / `as`) | ใช้งานได้ | โหลดไฟล์อื่น จะตั้งชื่อแทนก็ได้ |
| `ตกลง` / `ผิดพลาด` (`ok` / `bad`) | ใช้งานได้ | สร้างผลลัพธ์ และใช้เป็นแพตเทิร์นจับคู่ผลลัพธ์ |
| `จริง` / `เท็จ` (`true` / `false`) | ใช้งานได้ | ค่าบูลีน |
| `ลอง` (`try`) | ฟังก์ชันในตัว | ไม่ใช่ไวยากรณ์ แต่เป็นฟังก์ชันในตัว `ลอง(f, อาร์กิวเมนต์...)` ใช้ได้บนอินเทอร์พรีเตอร์เท่านั้น |
| `ชนิด` (`type`) | ถูกละเลย | `ชนิด ชื่อ เป็น T` ถูกแยกวิเคราะห์แล้วทิ้งไป มันกลืนสิ่งที่ตามมาด้วย จึงไม่ควรใช้ |
| `โดยที่` (`where`) | ถูกละเลย | `ฟังก์ชัน f(x) โดยที่ ... { }` ทุกอย่างจนถึง `{` ถูกข้ามไป |
| `ไม่พร้อมกัน` (`async`) | ถูกละเลย | `ไม่พร้อมกัน ฟังก์ชัน` ทำงานแบบซิงโครนัสเหมือนฟังก์ชันธรรมดา |
| `รอ` (`wait`) | ไม่น่าเชื่อถือ | ได้ค่าบนอินเทอร์พรีเตอร์ แต่ได้ `()` บน JIT อย่าใช้ |
| `เป็นเจ้าของ` `ให้ยืม` `แบ่งปัน` `ย้าย` `คัดลอก` (`own` `lend` `share` `move` `copy`) | ถูกละเลย | คำนำหน้าที่คืนตัวถูกดำเนินการโดยไม่เปลี่ยนแปลง ไม่มีการตรวจความเป็นเจ้าของใดๆ |
| `asm` | ถูกละเลย | `asm("...")` มีไว้สำหรับบิลด์แบบ bare-metal ในการรันปกติไม่ได้ทำอะไรที่มีประโยชน์ |
| `หยุด` (`stop`) | สงวนไว้ | **ไม่**ได้พาออกจากลูป |
| `ทำอีก` (`again`) | สงวนไว้ | **ไม่**ได้ข้ามไปรอบถัดไป |
| `เปลี่ยนแปลง` (`change`) | สงวนไว้ | ไม่ทำอะไร ให้ผูกใหม่ด้วย `ผูก` แทน |
| `ส่ง` `ให้` `เหมาะสม` `สามารถ` `แน่นอน` `อาจจะ` `บริสุทธิ์` (`post` `give` `fit` `can` `sure` `maybe` `pure`) | สงวนไว้ | ไม่ทำอะไร เป็นชื่อธรรมดาสำหรับตัวแยกวิเคราะห์ |
| `สร้าง` (`spawn`) | สงวนไว้ | ไม่ทำอะไร และไม่มีฟังก์ชันในตัวชื่อ `spawn` |
| `ไม่มี` (`none`) | สงวนไว้ | ไม่ใช่ค่า อินเทอร์พรีเตอร์แจ้ง `undefined: 'none'` ถ้าต้องการ "ไม่มีอะไร" ให้ใช้ `()` |

คำที่**สงวนไว้**เป็นชื่อธรรมดาสำหรับตัวแยกวิเคราะห์ ดังนั้น `ผูก หยุด = 2` ถูกต้อง บนอินเทอร์พรีเตอร์
`หยุด` หรือ `ทำอีก` ที่เขียนลอยๆ ในลูปจะเป็นข้อผิดพลาด `undefined` ส่วนบน JIT จะถูกละเลยเงียบๆ และลูปทำงานต่อ

## คำสงวนที่ใช้งานได้

### ผูก (bind)

`ผูก ชื่อ = นิพจน์` เป็นวิธีเดียวที่จะสร้างหรือ "เปลี่ยน" ตัวแปร การผูกชื่อเดิมอีกครั้งจะแทนที่ค่าเก่า
ดูหัวข้อการผูกและการผูกใหม่ใน[ไวยากรณ์](syntax.md)

```ling
ผูก เริ่ม = ทำ {
  ผูก ราคา = 40
  ผูก ราคา = ราคา + 2
  พิมพ์(ราคา)
}
```
```output
42
```

### ทำ (do)

`ทำ { ... }` รันคำสั่งตามลำดับแล้วให้ค่าของคำสั่งสุดท้าย จุดเริ่มต้นคือบล็อก `ทำ` ที่ผูกกับ `เริ่ม`
ดูหัวข้อบล็อกใน[ไวยากรณ์](syntax.md)

### ฟังก์ชันและคืน (fn, return)

`ฟังก์ชัน ชื่อ(พารามิเตอร์) { ตัวฟังก์ชัน }` ประกาศฟังก์ชัน นิพจน์สุดท้ายคือผลลัพธ์ และ `คืน` ใช้ออกก่อนกำหนด

```ling
ฟังก์ชัน อธิบาย(n) {
  ถ้า n > 100 { คืน "ใหญ่" }
  "เล็ก"
}
ผูก เริ่ม = ทำ {
  พิมพ์(อธิบาย(500))
  พิมพ์(อธิบาย(5))
}
```
```output
ใหญ่
เล็ก
```

`คืน` ที่เขียนตรงๆ ในจุดเริ่มต้นจะจบโปรแกรมเงียบๆ บน JIT และเป็นข้อผิดพลาด (`unexpected top-level return`)
บนอินเทอร์พรีเตอร์

### ถ้า มิฉะนั้น ขณะที่ สำหรับ ใน (if, else, while, for, in)

คำสงวนควบคุมการทำงานอธิบายไว้ในหัวข้อการควบคุมการทำงานของ[ไวยากรณ์](syntax.md) ไม่มี `break` หรือ
`continue` เพราะ `หยุด` และ `ทำอีก` เป็นแค่คำสงวน ถ้าจะออกจากลูปก่อน ให้ `คืน` จากฟังก์ชัน

```ling
ฟังก์ชัน ค้นหา(รายการ, เป้าหมาย) {
  สำหรับ x ใน รายการ {
    ถ้า x == เป้าหมาย { คืน จริง }
  }
  เท็จ
}
ผูก เริ่ม = ทำ {
  พิมพ์(ค้นหา([1, 2, 3], 2))
  พิมพ์(ค้นหา([1, 2, 3], 9))
}
```
```output
true
false
```

### จับคู่ (match)

`จับคู่ ค่า { แพตเทิร์น => นิพจน์, ... }` ประเมินแขนแรกที่แพตเทิร์นตรง แพตเทิร์นได้แก่ `_` ลิเทอรัล ชื่อ
`ตกลง(p)` / `ผิดพลาด(p)` และแบบของอีนัม ดูหัวข้อ match ใน[ไวยากรณ์](syntax.md)

### โครงสร้างและเลือกแบบ (form, choose)

`โครงสร้าง` ประกาศชนิดเรคคอร์ด และ `เลือกแบบ` ประกาศอีนัม ดูหัวข้อเรคคอร์ดและอีนัมใน[ไวยากรณ์](syntax.md)

```ling
เลือกแบบ ไฟจราจร { แดง, เหลือง, เขียว }
ฟังก์ชัน การกระทำ(ไฟ) {
  จับคู่ ไฟ {
    แดง() => "หยุดรถ",
    เหลือง() => "ชะลอ",
    เขียว() => "ไปได้"
  }
}
ผูก เริ่ม = ทำ {
  พิมพ์(การกระทำ(เขียว()))
  พิมพ์(แดง().tag)
}
```
```output
ไปได้
แดง
```

### โมดูล ใช้ เป็น (mod, use, as)

`โมดูล ชื่อ { ... }` รวมฟังก์ชันไว้ด้วยกันและเรียกด้วย `ชื่อ::f()` ส่วน `ใช้ "ไฟล์.ling"` โหลดไฟล์อื่น
และ `ใช้ "ไฟล์.ling" เป็น m` ทำให้เรียกฟังก์ชันในไฟล์นั้นด้วย `m::f()` ได้ ดู[โมดูลและโปรเจกต์](modules.md)

### ตกลงและผิดพลาด (ok, bad)

`ตกลง(ค่า)` และ `ผิดพลาด(เหตุผล)` สร้างผลลัพธ์ ใน `จับคู่` ทั้งสองคำเป็นแพตเทิร์น ผลลัพธ์ `ผิดพลาด` จะพิมพ์
เป็น `Err(...)` ดู[ข้อผิดพลาดและผลลัพธ์](errors.md)

```ling
ฟังก์ชัน ครึ่ง(n) {
  ถ้า n % 2 == 0 { ตกลง(n / 2) } มิฉะนั้น { ผิดพลาด("เป็นเลขคี่") }
}
ผูก เริ่ม = ทำ {
  พิมพ์(ครึ่ง(10))
  พิมพ์(จับคู่ ครึ่ง(7) { ตกลง(v) => v, ผิดพลาด(e) => "ข้อผิดพลาด: " + e })
}
```
```output
Ok(5)
ข้อผิดพลาด: เป็นเลขคี่
```

### จริงและเท็จ (true, false)

ลิเทอรัลบูลีน เป็นค่าที่ควรให้กับเงื่อนไขของ `ถ้า` และ `ขณะที่`

## คำสงวนที่ถูกแยกวิเคราะห์แต่ถูกละเลย

คำเกี่ยวกับความเป็นเจ้าของ `เป็นเจ้าของ` `ให้ยืม` `แบ่งปัน` `ย้าย` และ `คัดลอก` วางหน้านิพจน์ (หรือชื่อพารามิเตอร์)
ได้ แต่จะถูกละเลย ไม่มีตัวตรวจการยืม และใช้ค่าเดิมหลัง `ย้าย` ได้ตามปกติ

```ling
ผูก เริ่ม = ทำ {
  ผูก a = เป็นเจ้าของ [1, 2, 3]
  ผูก b = ย้าย a
  พิมพ์(a)
  พิมพ์(b)
}
```
```output
[1, 2, 3]
[1, 2, 3]
```

`ไม่พร้อมกัน ฟังก์ชัน` ประกาศฟังก์ชันธรรมดาที่ทำงานทันทีเมื่อถูกเรียก ส่วนคำสั่ง `โดยที่` หลังพารามิเตอร์ของ
ฟังก์ชันจะถูกข้ามไป

```ling
ไม่พร้อมกัน ฟังก์ชัน งาน(n) { n * 2 }
ฟังก์ชัน ถัดไป(x) โดยที่ x { x + 1 }
ผูก เริ่ม = ทำ {
  พิมพ์(งาน(4))
  พิมพ์(ถัดไป(2))
}
```
```output
8
3
```

ถ้าต้องการทำงานขนานกันจริงๆ ให้ใช้ฟังก์ชันในตัว `thread_*`

## คำที่ดูเหมือนคำสงวนแต่ไม่ใช่

- `start` `main` `启` `เริ่ม` และ `시작` เป็นชื่อ ไม่ใช่คำสงวน รันไทม์ใช้ชื่อเหล่านี้หาจุดเริ่มต้น
  ดูหัวข้อจุดเริ่มต้นใน[ไวยากรณ์](syntax.md)
- `result` `loop` `break` `continue` `struct` `enum` `let` `const` และคำทำนองนี้ปรากฏในไฟล์คำศัพท์บางไฟล์
  (รวมถึงไฟล์ภาษาไทย เช่น `วนซ้ำ` `ออก` `ทำต่อ`) แต่ไม่ใช่คำสงวน Ling ไม่มี `loop` และไม่มี `let`
  ให้ใช้ `ขณะที่` และ `ผูก`
- `number` `text` `bool` `list` `map` และ `tuple` เป็นแค่คำที่ใช้ในเอกสาร Ling เป็นภาษาชนิดข้อมูลแบบไดนามิก
  ดู[ชนิดข้อมูลและค่า](types.md)
