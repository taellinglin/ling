# เขียนได้ห้าภาษา

คุณเขียน Ling ได้ทั้งภาษาอังกฤษ จีน ญี่ปุ่น เกาหลี และไทย คำสงวนทุกคำมีชื่อในแต่ละภาษา
และฟังก์ชันในตัวที่ใช้บ่อยส่วนใหญ่ก็เช่นกัน อินเทอร์พรีเตอร์รับทุกชื่อพร้อมกัน ไม่ต้องตั้งค่าอะไร
และคุณผสมหลายภาษาในไฟล์เดียวได้ หรือแม้แต่ในบรรทัดเดียว

## โปรแกรมเดียวกัน ห้าครั้ง

นี่คือโปรแกรมเล็กๆ โปรแกรมเดียวที่เขียนในแต่ละภาษา คำสงวน ฟังก์ชันในตัว ชื่อ คอมเมนต์
และข้อความเป็นภาษานั้นทั้งหมด และทุกเวอร์ชันรันได้ทันที

**English**

```ling
# Count the fruit in a basket
fn describe(n) {
    if n == 1 {
        return "1 fruit"
    } else {
        return to_str(n) + " fruits"
    }
}

bind start = do {
    bind basket = ["apple", "pear", "plum"]
    for fruit in basket {
        print("- ", fruit)
    }
    print(describe(len(basket)))
    print("square root of 16: ", sqrt(16))
}
```

```output
- apple
- pear
- plum
3 fruits
square root of 16: 4
```

**中文**

```ling
# 数一数篮子里的水果
函 描述(数量) {
    若 数量 == 1 {
        归 "1 个水果"
    } 否则 {
        归 to_str(数量) + " 个水果"
    }
}

令 始 = 执 {
    令 篮子 = ["苹果", "梨", "李子"]
    历 水果 于 篮子 {
        打印("- ", 水果)
    }
    打印(描述(长度(篮子)))
    打印("16 的平方根：", 平方根(16))
}
```

```output
- 苹果
- 梨
- 李子
3 个水果
16 的平方根：4
```

**日本語**

```ling
# かごの果物を数える
関数 説明(個数) {
    もし 個数 == 1 {
        戻る "果物 1 個"
    } 他 {
        戻る "果物 " + to_str(個数) + " 個"
    }
}

束縛 開始 = 実行 {
    束縛 かご = ["りんご", "なし", "すもも"]
    繰 果物 の中 かご {
        印刷("- ", 果物)
    }
    印刷(説明(長さ(かご)))
    印刷("16 の平方根：", 平方根(16))
}
```

```output
- りんご
- なし
- すもも
果物 3 個
16 の平方根：4
```

**한국어**

```ling
# 바구니 속 과일 세기
함수 설명(개수) {
    만약 개수 == 1 {
        반환 "과일 1개"
    } 아니면 {
        반환 "과일 " + to_str(개수) + "개"
    }
}

바인드 시작 = 실행 {
    바인드 바구니 = ["사과", "배", "자두"]
    위해 과일 안에 바구니 {
        출력("- ", 과일)
    }
    출력(설명(길이(바구니)))
    출력("16의 제곱근: ", 제곱근(16))
}
```

```output
- 사과
- 배
- 자두
과일 3개
16의 제곱근: 4
```

**ไทย**

```ling
# นับผลไม้ในตะกร้า
ฟังก์ชัน บรรยาย(จำนวน) {
    ถ้า จำนวน == 1 {
        คืน "ผลไม้ 1 ผล"
    } มิฉะนั้น {
        คืน "ผลไม้ " + to_str(จำนวน) + " ผล"
    }
}

ผูก เริ่ม = ทำ {
    ผูก ตะกร้า = ["แอปเปิล", "สาลี่", "พลัม"]
    สำหรับ ผลไม้ ใน ตะกร้า {
        พิมพ์("- ", ผลไม้)
    }
    พิมพ์(บรรยาย(ความยาว(ตะกร้า)))
    พิมพ์("รากที่สองของ 16: ", รากที่สอง(16))
}
```

```output
- แอปเปิล
- สาลี่
- พลัม
ผลไม้ 3 ผล
รากที่สองของ 16: 4
```

สิ่งที่ควรสังเกต:

- ชื่อที่คุณตั้งเอง (`describe`, `篮子`, `かご`, `바구니`, `ตะกร้า`) ใช้อักษรใดก็ได้ในบรรดาภาษาเหล่านี้
- โปรแกรมเริ่มทำงานที่การผูกซึ่งมีค่าเป็นบล็อก `do` คุณจึงตั้งชื่อว่า `start`, `始`, `開始`, `시작`
  หรือ `เริ่ม` ก็ได้
- `to_str` เป็นภาษาอังกฤษในทุกเวอร์ชัน เพราะไม่มีชื่อแทนในภาษาเหล่านี้ ชื่อภาษาอังกฤษใช้ได้เสมอ
- เมื่อไฟล์ใช้ภาษาอื่น `ling run` จะพิมพ์ข้อความสั้นๆ เช่น `[detected language: Thai (ภาษาไทย)]`
  ไปที่ standard error ผลลัพธ์ของโปรแกรมไม่เปลี่ยน

## คำสงวน

คำสงวนที่ใช้บ่อยที่สุด:

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `bind` | `令` | `束縛` | `바인드` | `ผูก` |
| `do` | `执` | `実行` | `실행` | `ทำ` |
| `fn` | `函` | `関数` | `함수` | `ฟังก์ชัน` |
| `return` | `归` | `戻る` | `반환` | `คืน` |
| `if` | `若` | `もし` | `만약` | `ถ้า` |
| `else` | `否则` | `他` | `아니면` | `มิฉะนั้น` |
| `while` | `循` | `間` | `동안` | `ขณะที่` |
| `for` | `历` | `繰` | `위해` | `สำหรับ` |
| `in` | `于` | `の中` | `안에` | `ใน` |
| `match` | `配` | `一致` | `매치` | `จับคู่` |
| `form` | `形` | `形` | `구조` | `โครงสร้าง` |
| `ok` | `好` | `良い` | `좋아` | `ตกลง` |
| `bad` | `坏` | `悪い` | `나쁨` | `ผิดพลาด` |
| `true` | `真` | `真` | `참` | `จริง` |
| `false` | `假` | `偽` | `거짓` | `เท็จ` |

คำสงวนบางคำสะกดได้มากกว่าหนึ่งแบบ (ภาษาจีน `如` ก็แปลว่า `if` ภาษาเกาหลี `반복` ก็แปลว่า `while`)
ดูรายการทั้งหมดได้ที่ [คำสงวน](../glossary/keywords.md)

## ฟังก์ชันในตัว

ฟังก์ชันในตัวก็ทำงานแบบเดียวกัน `print`, `打印`, `印刷`, `출력` และ `พิมพ์` คือฟังก์ชันเดียวกัน

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `print` | `打印` | `印刷` | `출력` | `พิมพ์` |
| `len` | `长度` | `長さ` | `길이` | `ความยาว` |
| `sqrt` | `平方根` | `平方根` | `제곱근` | `รากที่สอง` |
| `abs` | `绝对值` | `絶対値` | `절댓값` | `ค่าสัมบูรณ์` |
| `max` | `最大` | `最大` | `최댓값` | `สูงสุด` |
| `rand` | `随机` | `乱数` | `난수` | `สุ่ม` |
| `list_push` | `列表添加` | `リスト追加` | `목록추가` | `เพิ่มรายการ` |
| `open_window` | `开窗` | `ウィンドウ開く` | `창열기` | `เปิดหน้าต่าง` |
| `window_is_open` | `窗开` | `開いている` | `창열림` | `หน้าต่างเปิดอยู่` |
| `fill` | `填` | `塗り潰し` | `채우기` | `เติม` |
| `present` | `显` | `表示` | `표시` | `แสดงผล` |
| `set_color` | `设色` | `色設定` | `색설정` | `สีดินสอ` |
| `key_down` | `按键` | `キー押す` | `키누름` | `กดค้าง` |
| `audio_blip` | `提示音` | `ビープ音` | `효과음` | `เสียงบี๊บ` |
| `time_now` | `当前时间` | `経過時間` | `현재시간` | `เวลาปัจจุบัน` |

ฟังก์ชันในตัวกลุ่มไหนมีชื่อแทน:

- **มีครบทั้งห้าภาษา:** การพิมพ์ คณิตศาสตร์ รายการ หน้าต่างและลูปเฟรม การวาด 2D และ 3D
  การรับค่าจากคีย์บอร์ดส่วนใหญ่ การเล่นเสียงและเพลง เวลา และวิดเจ็ต `ui_*`
- **มีแต่ภาษาอังกฤษ:** ตัวช่วยจัดการข้อความส่วนใหญ่ (`to_str`, `to_number`, `str_upper`, `str_split` ฯลฯ)
  ฟังก์ชันไฟล์อย่าง `write_file` สตูดิโอดนตรี (`daw_*`) และตัวช่วยด้านเว็บเซิร์ฟเวอร์ ฐานข้อมูล
  และคำขอส่วนใหญ่ (`http_*`, `db_*`, `query_param`, `json_escape`) บางตัวในกลุ่มนี้มีชื่อแทนภาษาไทย
  (`http_route` เขียนเป็น `เว็บเส้นทาง` ได้ `db_open` เขียนเป็น `ฐานข้อมูลเปิด` ได้)
  แต่ไม่มีชื่อภาษาจีน ญี่ปุ่น หรือเกาหลี

หน้า [ฟังก์ชันในตัวตาม Crate](../glossary/builtins.md) แสดงฟังก์ชันในตัวทุกตัวพร้อมชื่อแทน

> **เคล็ดลับ:** บนเอนจินเริ่มต้น ชื่อที่สะกดผิดหรือไม่รู้จักจะไม่เกิดข้อผิดพลาด การเรียกจะแค่คืนค่า `()`
> เช่น `长` ไม่ใช่ฟังก์ชันในตัว (`len` ในภาษาจีนคือ `长度`) ถ้าการเรียกดูเหมือนไม่ทำอะไรเลย
> ให้รัน `ling run --interp yourfile.ling` ซึ่งจะหยุดพร้อมข้อความ `unknown function`

## ผสมหลายภาษาในไฟล์เดียว

คุณใช้หลายภาษาร่วมกันได้โดยไม่มีปัญหา:

```ling
# English, Chinese, Japanese, Korean and Thai in one file
函 double(x) {
    归 x * 2
}

bind start = do {
    束縛 n = 21
    만약 n > 10 {
        พิมพ์("double: ", double(n))
    }
    print(长度([1, 2, 3]))
}
```

```output
double: 42
3
```

แบบนี้สะดวกเมื่อคุณเรียนจากตัวอย่างในภาษาอื่น หรือเมื่อทีมแบ่งปันโค้ดกัน แต่สำหรับโปรเจกต์ที่จะดูแลต่อไป
ใช้ภาษาเดียวต่อโปรเจกต์จะอ่านง่ายกว่า

## แปลงโปรเจกต์ด้วย lingfu normalize

`lingfu normalize` เขียนโปรเจกต์ทั้งหมดใหม่เป็นภาษาเดียว ให้รันในโฟลเดอร์ของโปรเจกต์:

```sh
lingfu normalize --dry-run th    # แสดงว่าจะเปลี่ยนอะไรบ้าง
lingfu normalize th              # เขียนใหม่เป็นภาษาไทย
lingfu normalize en              # แล้วเปลี่ยนกลับเป็นภาษาอังกฤษ
```

ภาษาที่ใช้ได้คือ `en`, `zh`, `ja`, `ko` หรือ `th` (หรือชื่ออย่าง `thai`)

- มันแปลคำสงวนและชื่อฟังก์ชันในตัวในไฟล์ `.ling` ทุกไฟล์ใต้โฟลเดอร์ปัจจุบัน รวมถึงโฟลเดอร์ย่อย
- มัน**เปลี่ยนชื่อไฟล์และโฟลเดอร์**ที่มันรู้วิธีแปลด้วย เพิ่ม `--content-only` เพื่อเปลี่ยนเฉพาะเนื้อหาไฟล์
  หรือ `--files-only` เพื่อเปลี่ยนชื่ออย่างเดียว
- มันไม่แปลชื่อที่คุณตั้งเอง คอมเมนต์ หรือข้อความ ส่วนนี้ต้องแก้เอง
- ฟังก์ชันในตัวที่ไม่มีชื่อแทนในภาษาเป้าหมายจะคงชื่อภาษาอังกฤษไว้

> **คำเตือน:** `normalize` แก้ไฟล์ในที่เดิมโดยตรง ให้ commit งานหรือทำสำเนาไว้ก่อน
> และรันเฉพาะในโฟลเดอร์ของโปรเจกต์นั้นเท่านั้น

หลังแปลงแล้ว ให้รันโปรแกรมหนึ่งครั้งเพื่อตรวจสอบ โดยเฉพาะ `form`, `ok` และ `bad` ถ้าคำสะกดใหม่
แยกวิเคราะห์ไม่ได้หรือไม่ทำงาน ให้เปลี่ยนเป็นคำสะกดในตารางคำสงวนด้านบน
ฟังก์ชันในตัวก็อาจได้รับผลกระทบ ถ้าการเรียกที่แปลงแล้วคืนค่า `()` ขึ้นมาเฉยๆ ให้รัน `ling run --interp`
เพื่อดูชื่อฟังก์ชันที่ไม่รู้จัก แล้วเปลี่ยนการเรียกนั้นกลับเป็นชื่อภาษาอังกฤษ
