# はじめての 3D ルーム

ターミナルから飛び出しましょう。このページでは、ウィンドウを開き、Ling のすべての画面を動かす
フレームループを学び、矢印キーで歩き回れる小さな 3D ルームを作ります。Ling は組み込みの
ソフトウェアレンダラーですべてを描くので、ゲームエンジンも GPU も必要ありません。

ウィンドウを開くプログラムはターミナルでは確認できないため、コードブロックに出力はありません。
止めるときは **Escape** を押すか、ウィンドウを閉じてください。

## フレームループ

ウィンドウは一度に 1 枚の静止画（フレーム）を表示します。プログラムはフレームを描いて表示し、
すぐに次のフレームに取りかかります。グラフィックのプログラムはどれも同じリズムで動きます。

1. ウィンドウを**開く**（1 回だけ）。
2. `塗り潰し` で画面を**消す**。前のフレームが残らないようにします。
3. 図形を**描く**。
4. `表示()` でフレームを**見せる**。

ループは `間 開いている()` の間続きます。ウィンドウが閉じられるか Escape が押されると偽になるので、
終了処理を自分で書く必要はありません。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(640, 400, "はじめてのウィンドウ")
    束縛 角度 = 0
    間 開いている() {
        塗り潰し(15, 18, 40)
        色設定(255, 120, 60)
        立方体(0, 0, 3, 1, 1, 1, 角度, 角度 * 0.7, 0, 0)
        表示()
        束縛 角度 = 角度 + 0.02
    }
}
```

- `ウィンドウ開く(640, 400, "はじめてのウィンドウ")` は 640 x 400 のウィンドウを開きます。
  サイズが先で、タイトルは最後です。
- `塗り潰し(15, 18, 40)` はウィンドウ全体を塗ります。色は赤・緑・青をそれぞれ 0 から 255 で指定します。
- `色設定(...)` はこのあとに描く図形の色を選びます。
- `立方体(...)` は立方体を描きます。引数は 3 つずつのまとまりです：中心 `x, y, z`、大きさ、
  ラジアン単位の回転、そして最後にモード（`0` は塗りつぶし、`1` はワイヤーフレーム、`2` は両方）。
- `表示()` はフレームを表示します。これを呼ばないと何も見えません。
- 毎フレーム `角度` を束縛し直すことで、立方体が回ります。

## どこに何があるか

Ling の 3D 世界では、**x** は右、**y** は**下**、**z** は画面の奥（あなたから離れる方向）を指します。
つまり「上」は y がマイナスの方向です。下のルームでは、床が `y = 3`、天井が `y = -3` にあります。

カメラは原点にあり、z の方向を向いています。見え方は 3 つの呼び出しで変えられます。

| 呼び出し | 内容 |
|---|---|
| `カメラ座標(x, y, z)` | カメラを動かします。 |
| `カメラ設定(cos_yaw, sin_yaw, cos_pitch, sin_pitch)` | カメラの向きを変えます。角度そのものではなくコサインとサインを渡すので、角度 `a` だけ回すには `カメラ設定(コサイン(a), サイン(a), 1, 0)` と書きます。 |
| `Z距離設定(d)` | 目が画面からどれだけ後ろにあるか。一人称視点には `0.5` のような小さな値が向いています。 |

カメラの関数は毎フレーム、描画の前に呼び出してください。

## 歩き回れるルーム

次のプログラムはここまでの内容をすべて組み合わせたものです。格子でできた床と天井、4 枚の壁、
4 本の柱、照明、回転する飾り、そしてキーボード操作があります。`room.ling` として保存してください。

```ling-gui
# 歩き回れる部屋。
# 左右の矢印キーで向きを変え、上下の矢印キーで歩く。Escape で終了。

関数 柱(x, z) {
    色設定(200, 190, 170)
    円柱(x, 0, z, 0.5, 3, 0.5, 0, 0, 0, 0)
}

関数 壁(フレーム) {
    # 床と天井（y は下向きなので、床は y = 3）
    格子模様(0, 3, 0,   1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  フレーム, 0)
    格子模様(0, -3, 0,  1, 0, 0,  0, 0, 1,   16, 16, 1, 1,  フレーム, 2)
    # 立っている 4 枚の壁
    格子模様(0, 0, 8,   1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  フレーム, 1)
    格子模様(0, 0, -8,  1, 0, 0,  0, -1, 0,  16, 6, 1, 1,  フレーム, 1)
    格子模様(-8, 0, 0,  0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  フレーム, 3)
    格子模様(8, 0, 0,   0, 0, 1,  0, -1, 0,  16, 6, 1, 1,  フレーム, 3)
    # 奥の壁に花
    花模様(0, 0, 7.9,  1, 0, 0,  0, -1, 0,  1.6, 24,  フレーム, 0)
}

束縛 開始 = 実行 {
    ウィンドウ開く(960, 600, "わたしの 3D ルーム")
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    環境光設定(0.3)

    束縛 位置x = 0
    束縛 位置z = -5
    束縛 向き = 0
    束縛 フレーム = 0

    間 開いている() {
        # 入力：向きを変えて歩く
        もし キー押す("left") {
            束縛 向き = 向き - 0.03
        }
        もし キー押す("right") {
            束縛 向き = 向き + 0.03
        }
        もし キー押す("up") {
            束縛 位置x = 位置x + サイン(向き) * 0.1
            束縛 位置z = 位置z + コサイン(向き) * 0.1
        }
        もし キー押す("down") {
            束縛 位置x = 位置x - サイン(向き) * 0.1
            束縛 位置z = 位置z - コサイン(向き) * 0.1
        }

        # 描画
        塗り潰し(8, 8, 20)
        カメラ設定(コサイン(向き), サイン(向き), 1, 0)
        カメラ座標(位置x, 0, 位置z)
        Z距離設定(0.5)
        ライト消去()
        ライト追加(0, -2.5, 0, 1.0, 0.85, 0.6, 1.0, 14)

        壁(フレーム * 0.3)
        柱(-6, -6)
        柱(6, -6)
        柱(-6, 6)
        柱(6, 6)

        色設定(240, 200, 80)
        トーラス(0, 1.5, 0, 0.7, 0.7, 0.7, 1.2, フレーム * 0.03, 0)

        表示()
        束縛 フレーム = フレーム + 1
    }
}
```

実行します。

```sh
ling run room.ling
```

しくみ：

- `柱` と `壁` はルームの各部分を描く関数です。ループの中で呼ばれるので、毎フレーム描き直されます。
  関数から見えるのは自分の引数とトップレベルの名前だけなので、`壁` には `フレーム` を引数で渡しています。
- `ウィンドウ開く` のあとの 4 行は、落ち着いた正確な色に切り替えます。これがないと、Ling の
  デフォルトの見た目では影が藍色に染まり、輪郭が光ります。
- `位置x`、`位置z`、`向き` はカメラの位置と向きを保持します。`キー押す("left")` は左矢印キーを
  押している間だけ真になります。歩くときは、向いている方向に x へ `サイン(向き)`、z へ `コサイン(向き)` だけ進みます。
- `ライト消去()` と `ライト追加(x, y, z, r, g, b, 強さ, 半径)` は毎フレーム呼び出します。
  そうしないと照明がどんどん積み重なります。ランプは天井近くの `y = -2.5` にあります。
- `格子模様` と `花模様` は平面の上に線の模様を描きます。最初の 3 つの数が中心で、次の 6 つが
  平面の「右」と「上」の向きです。立っている壁では「上」は `0, -1, 0` です。y が下を向いているからです。

壁は描かれているだけで、実体はありません。そのまま通り抜けられます。

## 試してみよう

- `格子模様` の呼び出しの最後の数（色相）を変えて、別の色にしてみましょう。
- 5 本目の柱や、違う色の `ライト追加` を加えてみましょう。
- `表示()` のあとに `もし キー押した("p") { screenshot("room") }` を追加します。P を押すと
  `screenshots` フォルダーに PNG が保存されます。
