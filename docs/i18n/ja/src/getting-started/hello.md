# ハローワールド

Ling のプログラムは、値が `実行` ブロックである束縛から始まります。
ここでは、何かを表示する最小のプログラムを紹介します。

## 最初のプログラム

次のコードを `hello.ling` として保存します。

```ling
束縛 開始 = 実行 {
    印刷("こんにちは、世界！")
}
```
```output
こんにちは、世界！
```

実行します。

```sh
ling run hello.ling
```

- `束縛 開始 = ...` は値に `開始` という名前を付けます。Ling は、値が `実行` ブロックである
  最初の束縛（または `start` のような開始用の名前）からプログラムを始めます。
- `実行 { ... }` は、順番に実行される手順のまとまりです。
- `印刷(...)` はターミナルに 1 行書き出します。

## もう少しだけ

束縛は `開始` の外にも書けます。次のプログラムは名前にあいさつし、リストを順にたどります。

```ling
# 何人かの友だちにあいさつする
束縛 名前 = "霊"
束縛 開始 = 実行 {
    印刷("こんにちは、" + 名前 + "！")
    繰 友だち の中 ["さくら", "けん", "ゆい"] {
        印刷("やあ、" + 友だち)
    }
}
```
```output
こんにちは、霊！
やあ、さくら
やあ、けん
やあ、ゆい
```

`+` はテキストをつなぎ、`繰 ... の中` はリストの各要素についてブロックを 1 回ずつ実行します。

日本語のプログラムを実行すると、`ling` は検出した言語を標準エラー出力に表示します。
たとえば `[detected language: Japanese (日本語)]` です。プログラムの動作には影響しません。

## 言語を混ぜる

キーワードと組み込み関数には、英語、中国語、日本語、韓国語、タイ語の名前があり、
1 つのファイルの中で自由に混ぜられます。次のプログラムは 5 つの言語をすべて使っています。

```ling
令 名字 = "Ling"
bind start = do {
    พิมพ์("สวัสดี " + 名字)
    만약 참 {
        印刷("こんにちは")
    }
}
```
```output
สวัสดี Ling
こんにちは
```

5 つの言語がどう組み合わさるかは、[5 つの言語で書く](../language/multilingual.md)を読んでください。
