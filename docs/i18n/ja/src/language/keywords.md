# キーワード

Ling のキーワードにはどれも英語の綴りと、中国語、日本語、韓国語、タイ語の綴りがあります。字句解析器は
どの綴りも同じトークンに変換するので、プログラム全体を 1 つの言語で書くことも、複数の言語を混ぜる
こともできます。このページでは、すべてのキーワードとその綴り、そして現時点で実際に何をするかを
示します。

一部のキーワードは将来の機能のために予約されていて、まだ何もしません。下に印を付けてあるので、
`停止`（`stop`）でループを抜けられなくても驚かずに済みます。

## 綴り

1 つのセルに複数の綴りがある場合は、どれでも使えます。最初のものが一般的な綴りです。これらの綴りは
字句解析器（`src/lexer/mod.rs`）から取ったもので、ランタイムが実際に受け付ける綴りです。
`lexicons/*.ling` と食い違う箇所がいくつかあり、その場合は字句解析器が正しいものです。たとえば
日本語の `choose` は `選択`、韓国語の `form` は `구조`、タイ語の `form` は `โครงสร้าง` です。

## 各キーワードの働き

| キーワード | 状態 | 働き |
|---|---|---|
| `束縛` (`bind`) | 有効 | 束縛を作る、または置き換えます。グローバルな値やエントリポイントの定義にも使います。 |
| `実行` (`do`) | 有効 | 最後の文の値を値とするブロックです。 |
| `関数` (`fn`) | 有効 | 関数を宣言します。 |
| `もし` / `他` (`if` / `else`) | 有効 | 条件式です。 |
| `間` (`while`) | 有効 | 条件が成り立つ間ループします。本体は外側のスコープを共有します。 |
| `繰` / `の中` (`for` / `in`) | 有効 | 範囲やリストをたどります。毎回新しいスコープになります。 |
| `一致` (`match`) | 有効 | パターンマッチです。 |
| `戻る` (`return`) | 有効 | 値を持って現在の関数を抜けます。 |
| `構造` (`form`) | 有効 | レコード型を宣言します。 |
| `選択` (`choose`) | 有効 | 値を持てる変種からなる列挙型を宣言します。 |
| `モジュール` (`mod`) | 有効 | 関数を名前空間にまとめます（`名前::f()`）。 |
| `使う` / `として` (`use` / `as`) | 有効 | 別のファイルを読み込みます。別名も付けられます。 |
| `良い` / `悪い` (`ok` / `bad`) | 有効 | 結果を作り、パターンとして結果に一致させます。 |
| `真` / `偽` (`true` / `false`) | 有効 | 真偽値です。 |
| `試す` (`try`) | 組み込み関数 | 構文ではなく、組み込み関数 `試す(f, 引数...)` です。インタプリタでのみ動きます。 |
| `型` (`type`) | 無視 | `型 名前 として T` は解析されて捨てられます。後ろに続くものを飲み込むので、使わないでください。 |
| `但し` (`where`) | 無視 | `関数 f(x) 但し ... { }`：`{` までが読み飛ばされます。 |
| `非同期` (`async`) | 無視 | `非同期 関数` は普通の関数と同じく同期的に動きます。 |
| `待つ` (`wait`) | 不安定 | インタプリタでは値になり、JIT では `()` になります。使わないでください。 |
| `所有` `貸す` `共有` `移動` `複製` (`own` `lend` `share` `move` `copy`) | 無視 | 被演算子をそのまま返す前置語です。所有権の検査は一切行われません。 |
| `asm` | 無視 | `asm("...")` はベアメタル向けのビルド用です。通常の実行では実質的に何もしません。 |
| `停止` (`stop`) | 予約 | ループを**抜けません**。 |
| `継続` (`again`) | 予約 | 次の回に**進みません**。 |
| `変える` (`change`) | 予約 | 何もしません。`束縛` で再束縛してください。 |
| `投稿` `渡す` `適合` `できる` `確か` `多分` `純粋` (`post` `give` `fit` `can` `sure` `maybe` `pure`) | 予約 | 何もしません。パーサにとっては普通の名前です。 |
| `起動` (`spawn`) | 予約 | 何もしません。`spawn` という組み込み関数もありません。 |
| `なし` (`none`) | 予約 | 値ではありません。インタプリタは `undefined: 'none'` を報告します。「何もない」には `()` を使います。 |

**予約**語はパーサにとって普通の名前なので、`束縛 停止 = 2` は正しいコードです。インタプリタでは、
ループの中に単独で書いた `停止` や `継続` は `undefined` エラーになり、JIT では黙って無視されて
ループはそのまま続きます。

## 有効なキーワード

### 束縛（bind）

`束縛 名前 = 式` は、変数を作る、または「変える」唯一の方法です。同じ名前をもう一度束縛すると
置き換わります。[束縛と再束縛](syntax.md#束縛と再束縛)を参照してください。

```ling
束縛 開始 = 実行 {
  束縛 値段 = 40
  束縛 値段 = 値段 + 2
  印刷(値段)
}
```
```output
42
```

### 実行（do）

`実行 { ... }` は文を順に実行し、最後の文の値を返します。エントリポイントは `実行` ブロックを
束縛したものです。[ブロック](syntax.md#ブロック)を参照してください。

### 関数と戻る（fn、return）

`関数 名前(引数) { 本体 }` で関数を宣言します。最後の式が結果で、`戻る` で途中で抜けます。

```ling
関数 説明(n) {
  もし n > 100 { 戻る "大きい" }
  "小さい"
}
束縛 開始 = 実行 {
  印刷(説明(500))
  印刷(説明(5))
}
```
```output
大きい
小さい
```

エントリポイントの中に直接書いた `戻る` は、JIT では黙ってプログラムを終了し、インタプリタでは
エラー（`unexpected top-level return`）になります。

### もし、他、間、繰、の中（if、else、while、for、in）

制御フローのキーワードは[制御フロー](syntax.md#制御フロー)で説明しています。`break` や `continue`
はありません。`停止` と `継続` は予約語にすぎません。ループを途中で抜けるには、関数から `戻る` を
使います。

```ling
関数 探す(リスト, 目標) {
  繰 x の中 リスト {
    もし x == 目標 { 戻る 真 }
  }
  偽
}
束縛 開始 = 実行 {
  印刷(探す([1, 2, 3], 2))
  印刷(探す([1, 2, 3], 9))
}
```
```output
true
false
```

### 一致（match）

`一致 値 { パターン => 式, ... }` は、最初に合った腕を評価します。パターンは `_`、リテラル、名前、
`良い(p)` / `悪い(p)`、列挙型の変種です。[match](syntax.md#match) を参照してください。

### 構造と選択（form、choose）

`構造` はレコード型を、`選択` は列挙型を宣言します。
[レコードと列挙型](syntax.md#レコードと列挙型)を参照してください。

```ling
選択 信号 { 赤, 黄, 青 }
関数 動作(灯) {
  一致 灯 {
    赤() => "止まる",
    黄() => "ゆっくり",
    青() => "進む"
  }
}
束縛 開始 = 実行 {
  印刷(動作(青()))
  印刷(赤().tag)
}
```
```output
進む
赤
```

### モジュール、使う、として（mod、use、as）

`モジュール 名前 { ... }` は関数をまとめ、`名前::f()` で呼び出します。`使う "ファイル.ling"` は
別のファイルを読み込み、`使う "ファイル.ling" として m` はその関数を `m::f()` として使えるように
します。[モジュールとプロジェクト](modules.md)を参照してください。

### 良いと悪い（ok、bad）

`良い(値)` と `悪い(理由)` は結果を作ります。`一致` の中ではパターンになります。`悪い` の結果は
`Err(...)` と表示されます。[エラーと結果](errors.md)を参照してください。

```ling
関数 半分(n) {
  もし n % 2 == 0 { 良い(n / 2) } 他 { 悪い("奇数です") }
}
束縛 開始 = 実行 {
  印刷(半分(10))
  印刷(一致 半分(7) { 良い(v) => v, 悪い(e) => "エラー：" + e })
}
```
```output
Ok(5)
エラー：奇数です
```

### 真と偽（true、false）

真偽値のリテラルです。`もし` と `間` の条件にはこれを使います。

## 解析されるが無視されるキーワード

所有権を表す `所有`、`貸す`、`共有`、`移動`、`複製` は、式（または引数名）の前に置けますが、
無視されます。借用チェッカーはなく、`移動` した後に元の値を使っても問題ありません。

```ling
束縛 開始 = 実行 {
  束縛 a = 所有 [1, 2, 3]
  束縛 b = 移動 a
  印刷(a)
  印刷(b)
}
```
```output
[1, 2, 3]
[1, 2, 3]
```

`非同期 関数` は、呼ぶとすぐに実行される普通の関数を宣言します。関数の引数の後ろの `但し` 節は
読み飛ばされます。

```ling
非同期 関数 仕事(n) { n * 2 }
関数 次(x) 但し x { x + 1 }
束縛 開始 = 実行 {
  印刷(仕事(4))
  印刷(次(2))
}
```
```output
8
3
```

本当の並列処理には `thread_*` 組み込み関数を使ってください。

## キーワードに見えるがキーワードではない言葉

- `start`、`main`、`启`、`เริ่ม`、`시작` は名前であって、キーワードではありません。ランタイムは
  これらを手がかりにエントリポイントを探します。[エントリポイント](syntax.md#エントリポイント)を
  参照してください。
- `result`、`loop`、`break`、`continue`、`struct`、`enum`、`let`、`const` などは一部の語彙
  ファイルに出てきますが、キーワードではありません。Ling には `loop` も `let` もありません。
  `間` と `束縛` を使ってください。
- `number`、`text`、`bool`、`list`、`map`、`tuple` はドキュメント用の言葉にすぎません。Ling は
  動的型付けです。[型と値](types.md)を参照してください。
