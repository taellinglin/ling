# 型と値

Ling は動的型付けの言語です。型を宣言する必要はありません。どの値も自分の型を持っていて、演算子や
組み込み関数が実行時にそれを確かめます。このページでは、値の種類、その表示のされ方、条件や比較での
振る舞い、そして型どうしの変換方法を説明します。

## 値の種類

| 型 | 例 | 作り方 | 表示 |
|---|---|---|---|
| 数値 | `3`、`2.5`、`-7` | 数値リテラル、算術演算 | `3`、`2.5` |
| テキスト | `"abc"` | テキストリテラル、`+`、テキストの組み込み関数 | `abc` |
| 真偽値 | `真`、`偽` | リテラル、比較 | `true` |
| ユニット | `()` | `()`、結果のない関数、見つからなかった検索 | `()` |
| リスト | `[1, "a", 真]` | リストリテラル、`新規リスト`、リストの組み込み関数 | `[1, a, true]` |
| レコード | `点(3, 4)` | `構造` の名前を呼び出す | `点 { x: 3, y: 4 }` |
| 列挙値 | `円(2)`、`ドット()` | `選択` の変種を呼び出す | `円(2)` |
| 結果 | `良い(5)`、`悪い("e")` | `良い` と `悪い` | `Ok(5)`、`Err(e)` |
| 関数 | `\|x\| x + 1` | クロージャ | |

マップ（辞書）、集合、タプル、文字型、`null` はありません。キーと値のデータには、リスト、
レコード、並列のリストを使うか、`db_*` 組み込み関数で SQLite に保存してください。`x: number` や
`-> text` のような型注釈はパーサに受け付けられ、無視されます。

```ling
構造 点 { x, y }
束縛 開始 = 実行 {
  印刷(42)
  印刷("テキスト")
  印刷(真)
  印刷(())
  印刷([1, "a", 真])
  印刷(点(3, 4))
  印刷(良い(5))
  印刷(悪い("だめ"))
}
```
```output
42
テキスト
true
()
[1, a, true]
点 { x: 3, y: 4 }
Ok(5)
Err(だめ)
```

### 数値

数値はすべて 64 ビット浮動小数点数です。整数は小数点なしで表示され、2^53 までの整数は正確で、
割り算は常に正確な商を返します。

```ling
束縛 開始 = 実行 {
  印刷(7 / 2)
  印刷(10 / 5)
  印刷(7 % 3)
  印刷(0.1 + 0.2)
  印刷(1000000 * 1000000)
}
```
```output
3.5
2
1
0.30000000000000004
1000000000000
```

0 で割ってもエラーにはなりません。インタプリタでは `1 / 0` は `inf`、JIT では `()` です。
どちらでも `0 / 0` は `NaN` です。

### テキスト

テキストは Unicode 文字の並びです。`長さ` はバイト数ではなく文字数を数え、`+` はテキストを
つなぎます。`+` の片側がテキストなら、もう片側もテキストに変換されます。

```ling
束縛 開始 = 実行 {
  印刷(長さ("héllo"))
  印刷("あ" + "い")
  印刷("n=" + 5)
  印刷(5 + "！")
}
```
```output
5
あい
n=5
5！
```

`s[i]` で 1 文字を読むのはインタプリタでしか動きません。両方のエンジンで 1 文字を取り出すには
`substr(s, i, 1)` を使います。

### リスト

リストにはどんな型の値でも入れられ、番号は 0 から始まります。リストの組み込み関数は新しいリストを
返すので、結果は必ず束縛してください：`束縛 xs = リスト追加(xs, v)`。末尾より先を読むと、JIT では
空の値になり、インタプリタでは `index N out of bounds` で止まります。リストの組み込み関数は
[テキストとリスト](../reference/text-lists.md)を参照してください。

### ユニット

`()` は「何もない」を意味します。最後の式が値を持たない関数は `()` を返します。`他` のない
`もし` で条件が偽のときや、どの腕にも合わない `一致` も `()` になります。

### レコード、列挙値、結果

レコードは `構造` から、列挙値は `選択` から、結果は `良い` と `悪い` から作られます。レコードの
フィールドは `.名前` で、列挙値の変種名は `.tag` で読み、結果は `一致` で開きます。
[レコードと列挙型](syntax.md#レコードと列挙型)と[エラーと結果](errors.md)を参照してください。

## 真偽の判定

`もし` と `間` には本物の真偽値を渡してください。他の値も使えますが、2 つのエンジンの判断は
完全には一致しません。

| 条件の中の値 | JIT（デフォルト） | インタプリタ |
|---|---|---|
| `真` / `偽` | 真 / 偽 | 真 / 偽 |
| `0` | 偽 | 偽 |
| `()` | 偽 | 偽 |
| その他の数値、空でないテキスト、空でないリスト | 真 | 真 |
| `""`（空のテキスト） | **真** | 偽 |
| `[]`（空のリスト） | **真** | 偽 |

空かどうかは `長さ(xs) == 0` や `s == ""` で明示的に調べてください。また、`!x` は `x == 偽` の
意味なので、`!0` も `!""` も `false` です。`!` は真偽値にだけ使ってください。

## 値の比較

`==` と `!=` は、数値、テキスト、真偽値、`()` を値で比較します。型の違う値は決して等しくなりません。
`1 == "1"` は `false` です。

**リスト、レコード、列挙値、結果は、中身が同じでも決して等しくなりません。** 要素やフィールドを
自分で比較してください。

```ling
構造 P { x }
束縛 開始 = 実行 {
  印刷("abc" == "abc")
  印刷(1 == "1")
  印刷([1, 2] == [1, 2])
  印刷(P(1) == P(1))
  印刷(P(1).x == P(1).x)
}
```
```output
true
false
false
false
true
```

`<`、`>`、`<=`、`>=` は数値用です。テキストの大小比較（`"a" < "b"`）は、JIT では `false`、
インタプリタではエラーになります。

## 型変換

| 組み込み関数 | 変換 | 説明 |
|---|---|---|
| `str(v)` | 任意の値をテキストに | `印刷` で表示されるのと同じテキストです。`to_str` とも書けます。 |
| `to_number(s)` | テキストを数値に | 前後の空白は無視します。数値でなければ `0` を返します。 |
| `hex_to_number(s)` | 16 進のテキストを数値に | `0x` は付けません：`hex_to_number("ff")` は `255`。 |
| `整数(x)` | 数値を整数に | 小数部を 0 の方向に切り捨てます。英語では `int`（`trunc` とも）。 |
| `床関数(x)` / `天井関数(x)` | 数値を整数に | 切り下げ / 切り上げ。英語では `floor` / `ceil`。 |
| `四捨五入(x)` | 数値を整数に | 0.5 は 0 から遠い方に丸めます。英語では `round`。 |

```ling
束縛 開始 = 実行 {
  印刷(str(3) + "！")
  印刷(to_number(" 4 ") + 1)
  印刷(to_number("abc"))
  印刷(整数(-3.7))
  印刷(床関数(-2.5))
  印刷(四捨五入(2.5))
  印刷(hex_to_number("ff"))
}
```
```output
3！
5
0
-3
-3
3
255
```

値の型を教えてくれる組み込み関数はなく、値を真偽値に変換する組み込み関数もありません。
`to_number` は不正な入力に `0` を返すので、`0` も正しい答えになりうる場合は先にテキストを
確かめてください。方法は[エラーと結果](errors.md#入力の検証)で紹介しています。
