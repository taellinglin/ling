# 構文

このページでは、Ling プログラムの書き方を説明します。プログラムの構成、リテラル、演算子、束縛、
関数、制御フローです。どの例も現在の `ling` で実際に実行しています。Ling には 2 つの実行エンジン、
デフォルトの JIT（`ling run`）とインタプリタ（`ling run --interp`）があります。両者の動作が違う
ところはこのページで指摘し、すべての違いは[既知の制限](limits.md)にまとめています。

このページのコードは日本語のキーワードで書いています。各キーワードの英語や他の言語での綴りは
[キーワード](keywords.md)を見てください。

## プログラムの構造

Ling のファイルは、トップレベルの**項目**の並びです。

| 項目 | 形 | 参照 |
|---|---|---|
| 束縛 | `束縛 名前 = 式` | [束縛と再束縛](#束縛と再束縛) |
| 関数 | `関数 名前(a, b) { ... }` | [関数](#関数) |
| レコード型 | `構造 名前 { フィールド, フィールド }` | [レコードと列挙型](#レコードと列挙型) |
| 列挙型 | `選択 名前 { 変種, 変種(a) }` | [レコードと列挙型](#レコードと列挙型) |
| モジュール | `モジュール 名前 { 関数 ... }` | [モジュールとプロジェクト](modules.md) |
| 読み込み | `使う "ファイル.ling"` | [モジュールとプロジェクト](modules.md) |

`印刷(...)` のような文はトップレベルには書けません。関数の中か、エントリポイントの中に書きます。

### エントリポイント

プログラムは、値が `実行` ブロックであるトップレベルの束縛から始まります。

```ling
束縛 開始 = 実行 {
  印刷("こんにちは、Ling！")
}
```
```output
こんにちは、Ling！
```

ランタイムは次の名前の束縛を、この順に探します。`start`、`main`、`启`、`เริ่ม`、`시작`、それに
いくつかの他の言語での同じ意味の言葉です。どれもなければ、値が `実行` ブロックである最初の
トップレベル束縛を実行します。日本語専用の名前はないので、上の例の `開始` はこの方法で見つかります。
そのような束縛がないファイルはライブラリで、`ling run` は `no entry point` と表示して止まります。

```ling
束縛 main = 実行 {
  印刷("main でも動きます")
}
```
```output
main でも動きます
```

> `関数 main() { ... }` はエントリポイントでは**ありません**。`束縛 main = 実行 { ... }` と
> 書いてください。

## コメントと文

コメントは `#` または `//` から行末までです。ブロックコメントはありません。文は改行で区切ります。
文の終わりに `;` を付けると、1 行に 2 つの文を書けます。

```ling
# シャープのコメント
// スラッシュのコメント
束縛 開始 = 実行 {
  印刷("あ") // 行末のコメント
  印刷("い"); 印刷("う")
}
```
```output
あ
い
う
```

## 識別子

名前は文字か `_` で始まり、文字、数字、`_` が続きます。Unicode の文字ならどれでもよいので、
日本語、中国語、韓国語、タイ語の名前が使えます。名前は大文字と小文字を区別します。

```ling
束縛 開始 = 実行 {
  束縛 名前 = "Ling"
  束縛 ชื่อ = 3
  印刷(名前)
  印刷(ชื่อ + 1)
}
```
```output
Ling
4
```

まだ何もしないキーワード（`変える`（`change`）、`停止`（`stop`）、`多分`（`maybe`）など。
[キーワード](keywords.md)を参照）は、パーサにとっては普通の名前なので、`束縛 停止 = 2` は
動きます。ただし、`繰`（`for`）や `もし`（`if`）のような有効なキーワードを名前に使っては
いけません。日本語で名前を付けるときは、`他`、`間`、`型` などの 1 文字のキーワードにも
注意してください。

## リテラル

| リテラル | 形 | 説明 |
|---|---|---|
| 数値 | `42`、`3.14` | 10 進数で、小数部は 1 つまで。数値はすべて 64 ビット浮動小数点数です。 |
| テキスト | `"こんにちは"` | 二重引用符のみ。複数行にまたがってもかまいません。エスケープ：`\n` `\t` `\r` `\"` `\\` `\0`。 |
| 真偽値 | `真`、`偽` | |
| ユニット | `()` | 「何もない」を表す値です。 |
| リスト | `[1, "二", 3.5]` | 要素の型は自由で、番号は 0 から始まります。 |
| 範囲 | `0..5` | 終わりを含みません：0、1、2、3、4。`繰` で使います。 |
| クロージャ | `\|x\| x + 1` | [クロージャ](#クロージャ)を参照。 |

`1e3`、`0xff`、`1_000`、`.5`、`3.` という書き方はありません。文字リテラルはなく（`'a'` は
構文エラー）、マップのリテラルもタプルもありません。テキストに埋め込み（補間）はありません。
`"{x}"` はその 3 文字そのものです。テキストは `+` と `str()` で組み立ててください。`\q` のような
未知のエスケープは、バックスラッシュも含めてそのまま残ります。

```ling
束縛 開始 = 実行 {
  印刷("1行目\n2行目")
  印刷("引用符：\"q\" バックスラッシュ：\\")
  印刷(1.5 + 1)
  印刷([1, "二", 3.5, 真])
  印刷(())
}
```
```output
1行目
2行目
引用符："q" バックスラッシュ：\
2.5
[1, 二, 3.5, true]
()
```

## 演算子と優先順位

結合の強いものから順に並べます。

| 順位 | 演算子 | 説明 |
|---|---|---|
| 1 | `.` `()` `[]` `::` `..` | フィールドまたはメソッド、呼び出し、添字、モジュールパス、範囲 |
| 2 | `-x` `!x` | 前置のマイナスと否定 |
| 3 | `*` `/` `%` | `%` は小数にも使えます：`7.5 % 2` は `1.5` |
| 4 | `+` `-` | `+` はテキストをつなぎます。片側がテキストなら、もう片側の数値はテキストになります |
| 5 | `==` `!=` `<` `>` `<=` `>=` | |
| 6 | `&&` | |
| 7 | `\|\|` | |

二項演算子はすべて左結合です。`10 - 3 - 2` は `5` です。

```ling
束縛 開始 = 実行 {
  印刷(2 + 3 * 4)
  印刷((2 + 3) * 4)
  印刷(10 - 3 - 2)
  印刷(-3 + 5)
  印刷(2 * -4)
  印刷(1 < 2 && 2 < 3)
  印刷("n=" + 5)
  印刷(7 / 2)
}
```
```output
14
20
5
2
-8
true
n=5
3.5
```

注意する点：

- `&&` と `||` は、どちらのエンジンでも**常に両辺を評価します**。`x != 0 && 10 / x > 1` は
  割り算を守ってくれません。代わりに `もし` を入れ子にしてください。
- 比較は左から連なります。`1 == 1 == 1` は `(1 == 1) == 1` の意味で、結果は `false` です。
- 前置のマイナスは重ねられません。`- - x` は構文エラーです。`0 - x` なら常に動きます。
- リスト、レコード、列挙値どうしの `==` は常に `false` です。[型と値](types.md#値の比較)を
  参照してください。

## 束縛と再束縛

`束縛 名前 = 式` で値に名前を付けます。代入はありません。`x = 5` は構文エラーです。値を「変える」
には、同じ名前をもう一度束縛します。その地点から、新しい束縛が古い束縛に置き換わります。

```ling
束縛 開始 = 実行 {
  束縛 x = 1
  束縛 x = x + 10
  束縛 x = x * 2
  印刷(x)
}
```
```output
22
```

ブロックが終わった後も再束縛が見えるかどうかは、ブロックの種類によって決まります。

| 場所 | ブロック終了後の再束縛 |
|---|---|
| `もし` / `他` の本体 | 残る |
| `間` の本体 | 残る。だから `間` のループで値を累積できます |
| `繰` の本体 | **失われる**：毎回新しいコピーから始まります |
| `一致` の腕 | 失われる |
| 関数の本体 | その呼び出しの中だけ |
| `実行 { }` ブロック | インタプリタでは失われ、JIT では残る。どちらにも頼らないこと |

```ling
束縛 開始 = 実行 {
  束縛 合計 = 0
  繰 i の中 1..5 { 束縛 合計 = 合計 + i }
  印刷(合計)
  束縛 和 = 0
  束縛 i = 1
  間 i < 5 {
    束縛 和 = 和 + i
    束縛 i = i + 1
  }
  印刷(和)
}
```
```output
0
10
```

トップレベルの `束縛` はグローバル定数です。関数はそれを読めますが、呼び出し元のローカルな束縛は
決して見えません。

```ling
束縛 倍率 = 3
関数 拡大(n) { n * 倍率 }
束縛 開始 = 実行 {
  束縛 倍率 = 100
  印刷(拡大(2))
}
```
```output
6
```

## ブロック

`実行 { ... }` は中の文を順に実行し、最後の文の値がブロックの値になります。エントリポイントも
`実行` ブロックで、式を書ける場所ならどこでも使えます。

```ling
束縛 開始 = 実行 {
  束縛 総計 = 実行 {
    束縛 a = 20
    束縛 b = 22
    a + b
  }
  印刷(総計)
}
```
```output
42
```

## 関数

`関数 名前(引数) { 本体 }` で、トップレベル（または `モジュール` の中）に関数を宣言します。結果は
本体の最後の式です。`戻る 値` で途中で抜け、値なしの `戻る` は `()` を返します。関数は再帰でき、
宣言の順番は自由です。関数の中に関数を入れ子にすることはできません。

```ling
関数 フィボナッチ(n) {
  もし n < 2 { 戻る n }
  フィボナッチ(n - 1) + フィボナッチ(n - 2)
}
関数 挨拶(名前) { "こんにちは、" + 名前 + "！" }
束縛 開始 = 実行 {
  印刷(フィボナッチ(15))
  印刷(挨拶("Ling"))
}
```
```output
610
こんにちは、Ling！
```

- `関数 f(a: number) -> text` のような型注釈は受け付けられ、無視されます。
- 引数が足りないと、足りない引数は未定義になります。それを使うと、インタプリタではエラー、
  JIT では `()` になります。
- 存在しない関数を呼ぶと、インタプリタではエラーですが、JIT は黙って `()` を返します。
  プログラムが「何もしない」ときは、`ling run --interp` で実行してみてください。

## クロージャ

クロージャは `|引数| 式` と書きます。たとえば `|x| x * 2` です。引数のないクロージャには空白が
必要で、`| | 42` と書きます。`||` は「または」の演算子だからです。

クロージャ式をその場で呼び出すのは、どこでも動きます。

```ling
束縛 開始 = 実行 {
  印刷((|x| x + 1)(5))
}
```
```output
6
```

クロージャは、今のところ言語で最も信頼性の低い部分です。変数に入れたクロージャはインタプリタでは
名前で呼べず、JIT はクロージャ（や関数名）を `list_map` や `試す`（`try`）のような組み込み関数に
渡せません。名前付きの `関数` を使ってください。[既知の制限](limits.md#クロージャと関数値)を
参照してください。

## 制御フロー

### if / else

`もし`（`if`）は式です。波かっこは必須で、条件にかっこは要りません。`他`（`else`）がなく条件が
偽のとき、`もし` は `()` になります。

```ling
束縛 開始 = 実行 {
  束縛 n = 7
  束縛 ラベル = もし n < 0 { "負" } 他 もし n == 0 { "ゼロ" } 他 { "正" }
  印刷(ラベル)
}
```
```output
正
```

条件には本物の真偽値を使ってください。`""` と `[]` の扱いはエンジンによって違います。
[型と値](types.md#真偽の判定)を参照してください。

### while

`間 条件 { 本体 }`（`while`）は、条件が成り立つ間くり返します。本体は外側のスコープを共有するので、
カウンタや合計にはこのループを使います。

```ling
束縛 開始 = 実行 {
  束縛 n = 27
  束縛 手数 = 0
  間 n != 1 {
    束縛 n = もし n % 2 == 0 { n / 2 } 他 { 3 * n + 1 }
    束縛 手数 = 手数 + 1
  }
  印刷(手数)
}
```
```output
111
```

### for

`繰 名前 の中 列 { 本体 }`（`for ... in`）は、範囲やリストの要素ごとに本体を 1 回実行します。
範囲 `lo..hi` は `hi` の手前で止まります。

```ling
束縛 開始 = 実行 {
  繰 i の中 1..4 { 印刷(i * i) }
  繰 名前 の中 ["ada", "lin"] { 印刷(str_upper(名前)) }
}
```
```output
1
4
9
ADA
LIN
```

`break` や `continue` はありません。途中で止めるには、ループを関数に入れて `戻る` を使うか、
フラグ付きの `間` ループを使います。

### match

`一致 値 { パターン => 式, ... }`（`match`）は、腕を上から順に試し、最初に合った腕を評価します。
パターンは次のとおりです。

| パターン | 一致するもの |
|---|---|
| `_` | 何でも |
| `0`、`"はい"`、`真` | そのリテラル値 |
| `名前` | 何でも。その値を `名前` に束縛します |
| `良い(p)`、`悪い(p)` | 結果（[エラーと結果](errors.md)を参照） |
| `変種(p, ...)`、`変種()` | 列挙値 |

```ling
関数 分類(n) {
  一致 n {
    0 => "ゼロ",
    1 => "いち",
    その他 => "たくさん（" + str(その他) + "）"
  }
}
束縛 開始 = 実行 {
  印刷(分類(0))
  印刷(分類(9))
}
```
```output
ゼロ
たくさん（9）
```

どの腕にも合わなければ、`一致` は `()` になります。ガードはなく、リストやレコードのパターンも
ありません。

## レコードと列挙型

`構造`（`form`）はレコード型を宣言します。型の名前をフィールドの順に呼び出すとレコードができ、
`.` でフィールドを読みます。

```ling
構造 点 { x, y }
束縛 開始 = 実行 {
  束縛 p = 点(3, 4)
  印刷(p)
  印刷(p.x + p.y)
}
```
```output
点 { x: 3, y: 4 }
7
```

`選択`（`choose`）は、値を持てる変種からなる列挙型を宣言します。変種を呼び出して値を作り、
`一致` で分解します。値を持たない変種もかっこを付けて `ドット()` と書きます。変種の名前は
`.tag` で取り出せます。

```ling
選択 図形 { 円(r), 長方形(w, h), ドット }
関数 面積(s) {
  一致 s {
    円(r) => 3 * r * r,
    長方形(w, h) => w * h,
    ドット() => 0
  }
}
束縛 開始 = 実行 {
  印刷(面積(円(2)))
  印刷(面積(長方形(3, 4)))
  印刷(面積(ドット()))
  印刷(長方形(1, 2).tag)
}
```
```output
12
12
0
長方形
```

レコードは変更できないので、必要なら新しく作ります。`点 { x: 1, y: 2 }` のようなリテラル構文は
使えません。コンストラクタをフィールドの数を間違えて呼ぶと、インタプリタではエラー、JIT では
`()` になります。

## 構文上の落とし穴

- **`-` や `[` で始まる行は、前の行の続きになります。** `束縛 x = 5` の次の行が `-1` だと `x` は
  `4` になり、`[1, 2]` で始まる行は添字として読まれます。
- **範囲の境界。** `0..n + 1` は構文エラーで、`0..長さ(xs)` は黙って誤動作します。ただの名前か
  数値以外は、かっこで囲んでください：`0..(n + 1)`、`0..(長さ(xs))`。
- **`構造` のフィールド注釈。** `構造 P { x: number, y: number }` は構文エラーです。`}` の直前の
  注釈が閉じかっこを飲み込むからです。リストの最後にカンマを付けてください：
  `構造 P { x: number, y: number, }`。
- **代入はありません。** `x = x + 1` は構文エラーです。`束縛 x = x + 1` と書きます。
- **引数なしのクロージャ。** `|| 式` ではなく `| | 式` と書きます。
