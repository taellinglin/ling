# 5 つの言語で書く

Ling は英語、中国語、日本語、韓国語、タイ語のどれでも書けます。すべてのキーワードに
それぞれの言語での名前があり、よく使う組み込み関数の多くも同様です。インタプリタは
これらをすべて同時に受け付けます。切り替える設定はなく、1 つのファイル、さらには
1 行の中で複数の言語を混ぜることもできます。

## 同じプログラムを 5 回

同じ小さなプログラムをそれぞれの言語で書いたものです。キーワード、組み込み関数、
名前、コメント、テキストはすべてその言語で書かれていて、どれもそのまま実行できます。

**English**

```ling
# Count the fruit in a basket
fn describe(n) {
    if n == 1 {
        return "1 fruit"
    } else {
        return to_str(n) + " fruits"
    }
}

bind start = do {
    bind basket = ["apple", "pear", "plum"]
    for fruit in basket {
        print("- ", fruit)
    }
    print(describe(len(basket)))
    print("square root of 16: ", sqrt(16))
}
```

```output
- apple
- pear
- plum
3 fruits
square root of 16: 4
```

**中文**

```ling
# 数一数篮子里的水果
函 描述(数量) {
    若 数量 == 1 {
        归 "1 个水果"
    } 否则 {
        归 to_str(数量) + " 个水果"
    }
}

令 始 = 执 {
    令 篮子 = ["苹果", "梨", "李子"]
    历 水果 于 篮子 {
        打印("- ", 水果)
    }
    打印(描述(长度(篮子)))
    打印("16 的平方根：", 平方根(16))
}
```

```output
- 苹果
- 梨
- 李子
3 个水果
16 的平方根：4
```

**日本語**

```ling
# かごの果物を数える
関数 説明(個数) {
    もし 個数 == 1 {
        戻る "果物 1 個"
    } 他 {
        戻る "果物 " + to_str(個数) + " 個"
    }
}

束縛 開始 = 実行 {
    束縛 かご = ["りんご", "なし", "すもも"]
    繰 果物 の中 かご {
        印刷("- ", 果物)
    }
    印刷(説明(長さ(かご)))
    印刷("16 の平方根：", 平方根(16))
}
```

```output
- りんご
- なし
- すもも
果物 3 個
16 の平方根：4
```

**한국어**

```ling
# 바구니 속 과일 세기
함수 설명(개수) {
    만약 개수 == 1 {
        반환 "과일 1개"
    } 아니면 {
        반환 "과일 " + to_str(개수) + "개"
    }
}

바인드 시작 = 실행 {
    바인드 바구니 = ["사과", "배", "자두"]
    위해 과일 안에 바구니 {
        출력("- ", 과일)
    }
    출력(설명(길이(바구니)))
    출력("16의 제곱근: ", 제곱근(16))
}
```

```output
- 사과
- 배
- 자두
과일 3개
16의 제곱근: 4
```

**ไทย**

```ling
# นับผลไม้ในตะกร้า
ฟังก์ชัน บรรยาย(จำนวน) {
    ถ้า จำนวน == 1 {
        คืน "ผลไม้ 1 ผล"
    } มิฉะนั้น {
        คืน "ผลไม้ " + to_str(จำนวน) + " ผล"
    }
}

ผูก เริ่ม = ทำ {
    ผูก ตะกร้า = ["แอปเปิล", "สาลี่", "พลัม"]
    สำหรับ ผลไม้ ใน ตะกร้า {
        พิมพ์("- ", ผลไม้)
    }
    พิมพ์(บรรยาย(ความยาว(ตะกร้า)))
    พิมพ์("รากที่สองของ 16: ", รากที่สอง(16))
}
```

```output
- แอปเปิล
- สาลี่
- พลัม
ผลไม้ 3 ผล
รากที่สองของ 16: 4
```

注目してほしい点がいくつかあります。

- 自分で付ける名前（`describe`、`篮子`、`かご`、`바구니`、`ตะกร้า`）には、これらのどの文字も使えます。
- プログラムは値が `do` ブロックである束縛から始まるので、その名前は `start`、`始`、
  `開始`、`시작`、`เริ่ม` のどれでもかまいません。
- `to_str` はどの版でも英語のままです。これらの言語には別名がないためです。英語の名前は
  いつでも使えます。
- 英語以外の言語で書かれたファイルを `ling run` で実行すると、
  `[detected language: Thai (ภาษาไทย)]` のような短いメッセージが標準エラーに表示されます。
  プログラムの出力は変わりません。

## キーワード

よく使うキーワード：

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `bind` | `令` | `束縛` | `바인드` | `ผูก` |
| `do` | `执` | `実行` | `실행` | `ทำ` |
| `fn` | `函` | `関数` | `함수` | `ฟังก์ชัน` |
| `return` | `归` | `戻る` | `반환` | `คืน` |
| `if` | `若` | `もし` | `만약` | `ถ้า` |
| `else` | `否则` | `他` | `아니면` | `มิฉะนั้น` |
| `while` | `循` | `間` | `동안` | `ขณะที่` |
| `for` | `历` | `繰` | `위해` | `สำหรับ` |
| `in` | `于` | `の中` | `안에` | `ใน` |
| `match` | `配` | `一致` | `매치` | `จับคู่` |
| `form` | `形` | `形` | `구조` | `โครงสร้าง` |
| `ok` | `好` | `良い` | `좋아` | `ตกลง` |
| `bad` | `坏` | `悪い` | `나쁨` | `ผิดพลาด` |
| `true` | `真` | `真` | `참` | `จริง` |
| `false` | `假` | `偽` | `거짓` | `เท็จ` |

綴りが複数あるキーワードもあります（中国語の `如` も `if`、韓国語の `반복` も `while` です）。
完全な一覧は[キーワード](../glossary/keywords.md)を参照してください。

## 組み込み関数

組み込み関数も同じです。`print`、`打印`、`印刷`、`출력`、`พิมพ์` は 1 つの関数です。

| English | 中文 | 日本語 | 한국어 | ไทย |
|---|---|---|---|---|
| `print` | `打印` | `印刷` | `출력` | `พิมพ์` |
| `len` | `长度` | `長さ` | `길이` | `ความยาว` |
| `sqrt` | `平方根` | `平方根` | `제곱근` | `รากที่สอง` |
| `abs` | `绝对值` | `絶対値` | `절댓값` | `ค่าสัมบูรณ์` |
| `max` | `最大` | `最大` | `최댓값` | `สูงสุด` |
| `rand` | `随机` | `乱数` | `난수` | `สุ่ม` |
| `list_push` | `列表添加` | `リスト追加` | `목록추가` | `เพิ่มรายการ` |
| `open_window` | `开窗` | `ウィンドウ開く` | `창열기` | `เปิดหน้าต่าง` |
| `window_is_open` | `窗开` | `開いている` | `창열림` | `หน้าต่างเปิดอยู่` |
| `fill` | `填` | `塗り潰し` | `채우기` | `เติม` |
| `present` | `显` | `表示` | `표시` | `แสดงผล` |
| `set_color` | `设色` | `色設定` | `색설정` | `สีดินสอ` |
| `key_down` | `按键` | `キー押す` | `키누름` | `กดค้าง` |
| `audio_blip` | `提示音` | `ビープ音` | `효과음` | `เสียงบี๊บ` |
| `time_now` | `当前时间` | `経過時間` | `현재시간` | `เวลาปัจจุบัน` |

別名がある組み込み関数：

- **5 つの言語すべて：** 出力、数学、リスト、ウィンドウとフレームループ、2D と 3D の描画、
  ほとんどのキーボード入力、オーディオと音楽の再生、時間、`ui_*` ウィジェット。
- **英語のみ：** ほとんどのテキスト補助関数（`to_str`、`to_number`、`str_upper`、`str_split`
  など）、`write_file` などのファイル関数、音楽スタジオ（`daw_*`）、そして Web サーバー、
  データベース、リクエスト補助関数の大部分（`http_*`、`db_*`、`query_param`、`json_escape`）。
  このうちいくつかにはタイ語の別名があります（`http_route` は `เว็บเส้นทาง`、`db_open` は
  `ฐานข้อมูลเปิด` とも書けます）が、中国語、日本語、韓国語の別名はありません。

[クレート別組み込み関数](../glossary/builtins.md)のページに、各組み込み関数とその別名が
載っています。

> **ヒント：** 既定のエンジンでは、綴りを間違えた名前や未知の名前はエラーにならず、呼び出しは
> `()` を返すだけです。たとえば `长` は組み込み関数ではありません（`len` の中国語は `长度`
> です）。呼び出しが何もしていないように見えたら `ling run --interp yourfile.ling` を
> 実行してください。`unknown function` と表示して止まります。

## 1 つのファイルで言語を混ぜる

複数の言語を一緒に使っても問題ありません。

```ling
# English, Chinese, Japanese, Korean and Thai in one file
函 double(x) {
    归 x * 2
}

bind start = do {
    束縛 n = 21
    만약 n > 10 {
        พิมพ์("double: ", double(n))
    }
    print(长度([1, 2, 3]))
}
```

```output
double: 42
3
```

別の言語で書かれた例から学ぶときや、チームでコードを共有するときに便利です。長く保守する
プロジェクトでは、1 つのプロジェクトに 1 つの言語のほうが読みやすくなります。

## lingfu normalize でプロジェクトを変換する

`lingfu normalize` はプロジェクト全体を 1 つの言語に書き換えます。プロジェクトの
フォルダで実行します。

```sh
lingfu normalize --dry-run ja    # 変更内容を表示するだけ
lingfu normalize ja              # 日本語に書き換える
lingfu normalize en              # 英語に戻す
```

言語には `en`、`zh`、`ja`、`ko`、`th`（または `thai` のような名前）を指定できます。

- 現在のフォルダ（サブフォルダを含む）にあるすべての `.ling` ファイルのキーワードと
  組み込み関数名を翻訳します。
- 翻訳方法を知っている名前のファイルやフォルダも**名前を変更**します。ファイルの内容だけを
  変えるには `--content-only`、名前の変更だけをするには `--files-only` を付けます。
- 自分で付けた名前、コメント、テキストは翻訳しません。これらは手で直してください。
- 対象の言語に別名がない組み込み関数は英語の名前のままです。

> **警告：** `normalize` はファイルを直接書き換えます。先に作業をコミットするかコピーを取り、
> プロジェクト自身のフォルダでだけ実行してください。

変換したら、一度プログラムを実行して確認してください。特に `form`、`ok`、`bad` に注意します。
新しい綴りが解析できない、または何もしない場合は、上のキーワード表の綴りに置き換えてください。
組み込み関数も影響を受けることがあります。変換後に呼び出しが急に `()` を返すようになったら
`ling run --interp` を実行して未知の関数名を確かめ、その呼び出しを英語の名前に戻してください。
