# Ling ブック（PDF）

Ling ブックは、Ling 2030.1.53 をもとに書かれた 4 冊のシリーズです。どれも無料の PDF でダウンロードできます。
本は英語で書かれています。

| 巻 | レベル | ページ数 | ダウンロード |
|---|---|---|---|
| **Learn Ling**（Ling を学ぶ） | 入門 | 321 | [ling-beginner.pdf](https://ling-lang.org/books/ling-beginner.pdf)（13 MB） |
| **Build with Ling**（Ling で作る） | 中級 | 716 | [ling-intermediate.pdf](https://ling-lang.org/books/ling-intermediate.pdf)（27 MB） |
| **Mastering Ling**（Ling を極める） | 上級 | 452 | [ling-advanced.pdf](https://ling-lang.org/books/ling-advanced.pdf)（16 MB） |
| **The Ling Reference**（Ling リファレンス） | 完全リファレンス | 650 | [ling-reference.pdf](https://ling-lang.org/books/ling-reference.pdf)（26 MB） |

## 各巻の内容

### Learn Ling（入門）

値と束縛、条件分岐とループ、関数、リストとテキスト、はじめての 3D ルーム、描画とゲーム、サウンドと音楽。
最後に 1 つのプロジェクトを完成させます。

### Build with Ling（中級）

レコード（`form`）、エラーと結果、モジュールとプロジェクト構成、データとファイル、UI アプリ、アニメーションと入力、
ゲームと物理、音楽ツール、テストとデバッグ、パッケージングと配布。

### Mastering Ling（上級）

Ling の動く仕組み、並行処理とアイソレート、ネットワークサービス、Rust クレートを使った Web アプリ、暗号、
P2P プロトコル、AI とテンソル、Rust からクレートを使う方法、Ling の拡張、Ling OS と組み込みターゲット、
大規模アプリの設計。

### The Ling Reference

すべてのキーワードと組み込み関数について、引数、戻り値、別名、例を載せています。最後の章では既知の制限と
注意点をまとめています。

## どれを読むか

- **プログラミングがはじめて、または Ling がはじめて：** *Learn Ling* から始めましょう。
- **本格的なプログラムを作る：** *Build with Ling* を読みましょう。
- **深く知りたい：** *Mastering Ling* を読みましょう。
- **調べものをする：** *The Ling Reference* を手元に置いておきましょう。

このドキュメントは短いオンライン版の手引きです。本はさらに詳しく、1 つの Ling バージョンに合わせて書かれています。
ちょっと調べたいときは、[組み込み関数リファレンス](reference/index.md)と[既知の制限](language/limits.md)のページの
ほうが早いことも多いです。
