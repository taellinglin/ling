# 双曲世界（H²×ℝ）

ソース：[`examples/physics/hyperbolic_world.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic_world.ling)

地面が**双曲平面**になっている、小さなブロックの世界です。[Hypermine](https://github.com/Ralith/hypermine) に
着想を得ています。Hypermine の舞台は完全な 3 次元双曲空間（H³）ですが、このデモはいちばん簡単に遊べる親戚の
**H²×ℝ** を使います。双曲平面（ポアンカレ円板として描画）の上を歩き、上下方向の重力はふだんどおりに働きます。

リポジトリのルートで実行します。

```sh
ling run examples/physics/hyperbolic_world.ling
```

## 操作

| キー | 動作 |
|---|---|
| `W` / `S` | 前進 / 後退 |
| `A` / `D` | 左 / 右へ移動 |
| `Q` / `E` | 左 / 右を向く |
| `Space` | ジャンプ |

## どこが双曲なのか

- **端に行くほど混み合う。** ブロックは何重もの輪の上に並び、外側の輪ほど数が増えます（`cells = 6 * ring`）。
  円板の端は無限遠を表し、端に近いほどブロックが詰まって、係数 `1 − |z|²` で小さくなります。
- **メビウス変換による移動。** あなたは円板の中心にいたままで、世界のほうがメビウス平行移動
  `z ↦ (z + a) / (1 + ā z)` で足元を滑っていきます。向きを変えると、世界が中心のまわりに回転します。
- **ホロノミー。** 正方形などの閉じた道を一周すると、戻ってきたときに向きが変わっています。これが負の曲率を持つ
  空間を進む感覚です。
- **ふつうの重力。** ジャンプや落下は普通の上下方向の軸を使うので、ほかのゲームと同じ感覚で遊べます。

## テクスチャのないブロック

各ブロックは、自分の輪と位置をハッシュ（`hash01`、`fract(sin(...))` 型のハッシュ）して、種類（草、石、土、水晶）と
高さを決めます。色は種類で決まり、あとはセルシェーディングの設定（`set_shade_mode`、`set_cel_bands`、`set_rim`）が
仕上げます。テクスチャファイルはいりません。[ポストエフェクトとライティング](../reference/postfx.md)も見てください。

## 試してみよう

- ブロックは `cube` で描いています。`cylinder` や [3D 形状とメッシュ](../reference/shapes.md)のほかの形も試してみましょう。
- 輪の上限（`ring <= 4`）を大きくすると、世界が広がります。
- `STEP` と `TURN` を変えて、移動や回転を速くしてみましょう。

別の種類の 3D デモは[双曲 3D](hyperbolic-3d.md)にあります。
