# 双曲 3D

ソース：[`examples/physics/hyperbolic3d.ling`](https://github.com/taellinglin/ling/blob/master/examples/physics/hyperbolic3d.ling)

ファイル名とは違い、このデモの現在の版は、ふつうの（ユークリッドの）3D 空間にある物理迷路です。ボールを転がして
ワイヤーフレームの迷路を進み、壁で跳ね返り、力をためてジャンプします。そのあいだ、ボールの動きに合わせて音が変わります。
本物の双曲幾何は[双曲世界](hyperbolic-world.md)で見られます。

リポジトリのルートで実行します。

```sh
ling run examples/physics/hyperbolic3d.ling
```

## 操作

| キー | 動作 |
|---|---|
| `W` / `S` | ボールを前 / 後ろへ押す |
| `A` / `D` | ボールを左 / 右へ押す |
| `Space` | 押し続けて力をため、離してジャンプ |
| `←` / `→` | カメラを周回させる |
| `↑` / `↓` | カメラを上下に傾ける |
| `Z` / `X` | ズームイン / ズームアウト |

## しくみ

- **物理。** 毎フレーム、重力を加え、速度に減衰係数（`DAMPING = 0.99`）を掛けてからボールを動かします。ボールが壁を
  越えると、プログラムが押し戻し、速度を反転させて `ELASTICITY = 0.80` を掛けます。
- **迷路。** 300 × 200 × 300 の外枠と 5 枚の内壁です。壁は長方形として当たり判定を行い、`draw_line_3d` で線として描きます。
- **ジャンプ。** 地面の上で `Space` を押し続けると、`MAX_CHARGE` まで力がたまります。離すとボールが飛び上がります。
  ボールのところにある小さなメーターがたまり具合を示します。
- **ボール。** 回転する `vtex_chakra` の輪として描かれ、高さによって色が変わります。床の十字の影、床まで下ろした線、
  赤い速度の矢印で位置がわかりやすくなっています。
- **物理に合わせて変わる音。** `audio_tone` の 1 つの声部が毎フレーム変化します。音の高さは高度と速さで上がり、
  跳ね返るたびに一瞬はね上がります。音量は速さとともに大きくなり、左右の定位はボールの x 座標についていきます。
- **ライト。** ゆっくり漂う暖かい光、涼しげな補助光、ボールについていく紫の光の 3 つです。

## 試してみよう

- ファイル先頭の `GRAVITY`、`DAMPING`、`ELASTICITY` を変えて、違いを感じてみましょう。
- 壁を足してみましょう。壁の当たり判定を 1 つコピーし、対応する `draw_line_3d` の呼び出しで描きます。
- 別の値を音に結びつけてみましょう。たとえば、ためた力の大きさで音の高さを変えます。
