# 描画とゲーム

このページでは、円、三角形、線、グラデーションで平面の 2D の絵を描き、キーボードとマウスに
反応させ、それらを組み合わせて遊んだり改造したりできる小さなゲームを作ります。ここで使うのは
Ling に最初から入っている組み込み関数だけなので、画像ファイルやゲームエンジンは必要ありません。

これらのプログラムはウィンドウを開くので、コードブロックに出力はありません。**Escape** を押すか
ウィンドウを閉じると止まります。

## ウィンドウを開いてフレームループを回す

グラフィックスのプログラムはどれも同じ形をしています。ウィンドウを一度開き、ウィンドウが閉じる
まで **消す、描く、表示する** を繰り返します。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(640, 400, "フレームループ")
    束縛 t = 0
    間 開いている() {
        塗り潰し(10, 12, 30)                       # 1. 消す
        色設定(255, 200, 80)                       # 2. 描く
        塗りつぶし円(320 + 200 * サイン(t * 0.05), 200, 30)
        表示()                                     # 3. フレームを表示する
        束縛 t = t + 1
    }
}
```

- `ウィンドウ開く(幅, 高さ, タイトル)`（`open_window`）でウィンドウを開きます。大きさが先、
  タイトルが最後です。
- ウィンドウが閉じられるか Escape が押されると、`開いている()`（`window_is_open`）は偽になります。
- `塗り潰し(r, g, b)`（`fill`）はウィンドウ全体を 1 色で塗ります。色は 0 から 255 の赤、緑、青です。
- `表示()`（`present`）は描き終えたフレームを画面に出します。`表示()` のないフレームは見えません。
- `t` はフレームを数えます。`サイン(t * 0.05)` は -1 と 1 の間をなめらかに行き来するので、
  円が左右に動きます。

フレーム間の経過時間を返す組み込み関数はありません。実際の秒数が必要なら、`経過時間()`
（`time_now`、プログラム開始からの秒数）か `フレーム数()`（`frame_count`）を使います。

## 2D キャンバス

ウィンドウはピクセルの格子です。数学の授業とは 2 点が違います。

- 原点 `(0, 0)` は**左上**の角です。
- **y は下に向かって増えます。** `y = 300` は `y = 100` より画面の下にあります。

絵は**ペン**で描きます。`色設定(r, g, b)`（`set_color`）でペンの色を選ぶと、それ以降の図形は
色を変えるまでその色で描かれます。

| 組み込み関数 | 描くもの |
|---|---|
| `fill(r, g, b)` / `塗り潰し` | ウィンドウ全体を 1 色で |
| `draw_disc(cx, cy, r)` / `塗りつぶし円` | 塗りつぶした円 |
| `draw_circle(cx, cy, r)` | 円の輪郭 |
| `triangle(x0, y0, x1, y1, x2, y2)` / `三角形描画` | 塗りつぶした三角形 |
| `draw_line(x0, y0, x1, y1)` / `線描く` | 細い線 |
| `draw_arc(cx, cy, r, a0, a1, segments)` | 円の輪郭の一部。角度はラジアンで時計回り |
| `draw_poly([x0, y0, x1, y1, ...])` / `ポリゴン塗り` | 点の平らなリストから作る塗りつぶした多角形 |
| `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` / `グラデ矩形` | 2 色の間で変化する長方形。`dir` が 1 なら上から下、0 なら左から右 |
| `set_color_hsl(h, s, l)` / `HSL色` | 色相 0-360、彩度 0-100、明度 0-100 でペンの色を指定 |

単色の長方形を塗る組み込み関数はありません。ある色から同じ色へのグラデーションは単色の長方形
になるので、補助関数を自分で書きます。

```ling-module
関数 長方形(x, y, 幅, 高さ, r, g, b) {
    グラデ矩形(x, y, 幅, 高さ, r, g, b, r, g, b, 1)
}
```

> **ヒント：** 描画の呼び出しが何もしていないように見えたら、綴りを確かめてください。
> `draw_rect` のような未知の名前は黙って無視されます。

### 風景

奥から手前へ、層を重ねて描きます。後から描いた図形が先に描いた図形の上に重なります。

```ling-gui
関数 長方形(x, y, 幅, 高さ, r, g, b) {
    グラデ矩形(x, y, 幅, 高さ, r, g, b, r, g, b, 1)
}

関数 木(x, 地面) {
    長方形(x - 6, 地面 - 50, 12, 50, 110, 70, 40)
    色設定(40, 150, 70)
    塗りつぶし円(x, 地面 - 70, 32)
    塗りつぶし円(x - 20, 地面 - 50, 24)
    塗りつぶし円(x + 20, 地面 - 50, 24)
}

束縛 開始 = 実行 {
    ウィンドウ開く(800, 500, "風景")
    束縛 t = 0
    間 開いている() {
        グラデ矩形(0, 0, 800, 380, 30, 40, 110, 250, 150, 140, 1)   # 空
        色設定(255, 220, 120)
        塗りつぶし円(600, 300, 60)                                   # 太陽
        色設定(70, 60, 110)
        三角形描画(0, 380, 150, 190, 300, 380)                       # 山
        三角形描画(200, 380, 380, 150, 560, 380)
        長方形(0, 380, 800, 120, 50, 110, 60)                        # 地面
        木(120, 440)
        木(330, 460)
        木(690, 450)
        色設定(20, 20, 30)                                           # 鳥
        束縛 羽ばたき = サイン(t * 0.15) * 6
        draw_arc(150, 120 - 羽ばたき, 18, 3.4, 6.0, 16)
        draw_arc(186, 120 - 羽ばたき, 18, 3.4, 6.0, 16)
        表示()
        束縛 t = t + 1
    }
}
```

`木(x, 地面)` は引数を基準に幹と葉を配置するので、木を好きなだけ植えられます。鳥の翼は 2 本の
弧です。y が下向きなので角度は時計回りに増えます。`0` は右、`3.14` は左を指します。

## キーボードを読む

Ling にはイベントハンドラがありません。フレームごとに、キーが押されているかを**尋ねます**。

- `キー押す("left")`（`key_down`）は、キーを押している間ずっと真です。
- `キー押した("space")`（`key_pressed`）は、キーが押されたその 1 フレームだけ真です。ジャンプや
  リスタートのように、1 回押すごとに 1 回だけ起きることに使います。

キー名は英小文字の文字列です。`"a"` から `"z"`、数字、`"left"`、`"right"`、`"up"`、`"down"`、
`"space"`、`"enter"`、`"escape"`、`"lshift"` などがあります。未知の名前は偽になるだけです。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(640, 400, "ボールを動かす")
    束縛 x = 320
    束縛 y = 200
    間 開いている() {
        束縛 速さ = 3
        もし キー押す("lshift") {
            束縛 速さ = 8
        }
        もし キー押す("left") {
            束縛 x = x - 速さ
        }
        もし キー押す("right") {
            束縛 x = x + 速さ
        }
        もし キー押す("up") {
            束縛 y = y - 速さ
        }
        もし キー押す("down") {
            束縛 y = y + 速さ
        }
        束縛 x = 範囲制限(x, 20, 620)
        束縛 y = 範囲制限(y, 20, 380)

        塗り潰し(10, 10, 30)
        色設定(255, 180, 60)
        塗りつぶし円(x, y, 20)
        表示()
    }
}
```

ほとんどのゲームには次の 3 つの部分があります。

1. **状態：** `x` と `y` はループの外にあるので、フレームからフレームへ値が残ります。
2. **入力と更新：** `キー押す` の判定が状態を変え、`範囲制限`（`clamp`）がボールをウィンドウの
   中に留めます。
3. **描画：** 状態から絵を作ります。

毎フレーム、入力、更新、描画の順番を守りましょう。

## マウスを読む

`mouse_x()` と `mouse_y()` はポインタの位置をピクセルで返します。`mouse_down()` は左ボタンを
押している間、`mouse_down_right()` は右ボタンを押している間、真になります。これらには日本語の
別名がないので、英語の名前のまま使います。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(640, 400, "マウスでお絵かき")
    塗り潰し(245, 240, 225)
    束縛 色相 = 0
    間 開いている() {
        もし mouse_down() {
            HSL色(色相, 80, 50)
            塗りつぶし円(mouse_x(), mouse_y(), 10)
            束縛 色相 = (色相 + 3) % 360
        }
        もし mouse_down_right() {
            塗り潰し(245, 240, 225)
        }
        表示()
    }
}
```

このプログラムは毎フレーム `塗り潰し` を呼ばないので、描いた絵がキャンバスに残ります。右クリック
で `塗り潰し` を 1 回呼んで消します。

## 小さなゲーム：スターキャッチャー

空から星が落ちてきます。かごを左右に動かして受け止めましょう。受け止めるたびに 1 点入り、次の星は
少し速くなります。3 回取り逃すとゲームオーバー。スペースキーでもう一度遊べます。

ゲームを書く前に、**状態**（かごの x、星の位置、落ちる速さ、得点、残りライフ）、**ルール**
（毎フレーム状態がどう変わるか）、**絵**（状態をどう描くか）を書き出します。

```ling-gui
関数 長方形(x, y, 幅, 高さ, r, g, b) {
    グラデ矩形(x, y, 幅, 高さ, r, g, b, r, g, b, 1)
}

# 五芒星：角が 10 個ある多角形。
関数 星(cx, cy, 大きさ, 回転) {
    束縛 点 = []
    束縛 i = 0
    間 i < 10 {
        束縛 角度 = 回転 + i * 0.6283185
        束縛 半径 = 大きさ
        もし i % 2 == 1 {
            束縛 半径 = 大きさ * 0.45
        }
        束縛 点 = リスト追加(点, cx + コサイン(角度) * 半径)
        束縛 点 = リスト追加(点, cy + サイン(角度) * 半径)
        束縛 i = i + 1
    }
    ポリゴン塗り(点)
}

束縛 開始 = 実行 {
    ウィンドウ開く(640, 480, "スターキャッチャー")
    束縛 かごx = 320
    束縛 星x = 100 + 乱数() * 440
    束縛 星y = 0
    束縛 落下 = 3
    束縛 得点 = 0
    束縛 ライフ = 3
    束縛 t = 0

    間 開いている() {
        もし ライフ > 0 {
            # 入力
            もし キー押す("left") || キー押す("a") {
                束縛 かごx = かごx - 7
            }
            もし キー押す("right") || キー押す("d") {
                束縛 かごx = かごx + 7
            }
            束縛 かごx = 範囲制限(かごx, 50, 590)
            # 更新
            束縛 星y = 星y + 落下
            もし 星y > 440 {
                もし 絶対値(星x - かごx) < 55 {
                    束縛 得点 = 得点 + 1
                    束縛 落下 = 落下 + 0.25
                } 他 {
                    束縛 ライフ = ライフ - 1
                }
                束縛 星x = 50 + 乱数() * 540
                束縛 星y = 0
            }
        } 他 {
            もし キー押した("space") {
                束縛 ライフ = 3
                束縛 得点 = 0
                束縛 落下 = 3
                束縛 星y = 0
            }
        }

        # 描画
        グラデ矩形(0, 0, 640, 480, 15, 15, 50, 40, 25, 80, 1)
        色設定(255, 220, 80)
        星(星x, 星y, 24, t * 0.05)
        長方形(かごx - 50, 445, 100, 14, 90, 190, 255)
        色設定(255, 255, 255)
        UI文字(16, 14, 22, "SCORE " + to_str(得点))
        UI文字(500, 14, 22, "LIVES " + to_str(ライフ))
        もし ライフ <= 0 {
            色設定(255, 110, 110)
            UI文字(170, 200, 36, "GAME OVER")
        }
        表示()
        束縛 t = t + 1
    }
    印刷("最終得点：", 得点)
}
```

仕組み：

- **星。** `星` は `コサイン` と `サイン` で 10 個の角の座標を計算し、長い半径と短い半径を交互に
  使って平らなリストにし、`ポリゴン塗り`（`draw_poly`）に渡します。`回転` の角度で星は回りながら
  落ちます。
- **ゲームの状態。** `もし ライフ > 0 { ... } 他 { ... }` で「プレイ中」と「ゲームオーバー」を
  切り替えます。ゲームオーバーの間はリスタートのキーだけを調べます。
- **受け止め。** 星がかごの高さに届いたら、`絶対値(星x - かごx) < 55` で受け止めたかどうかを
  決めます。`乱数()`（`rand`）は 0 以上 1 未満の数を返すので、`50 + 乱数() * 540` は 50 から 590
  の間のランダムな x です。
- **難しさ。** `束縛 落下 = 落下 + 0.25` で次の星が少しずつ速くなります。
- **文字。** `UI文字(x, y, 大きさ, テキスト)`（`ui_text`）は内蔵の線フォントでペンの色の文字を
  描きます。フォントファイルは要りませんが、描けるのはラテン文字の大文字と数字だけなので、
  画面の文字は英語のままにしています。
- **終わり。** ウィンドウを閉じるとループが終わり、最後の行が端末に得点を表示します。

## やってみよう

1. 顔を描きましょう。大きな黄色の円、目になる暗い小さな円を 2 つ、口になる弧を 1 つ
   （中心が `(200, 200)` の顔なら `draw_arc(200, 210, 60, 0.4, 2.74, 24)` を試してください）。
2. ボールを跳ね返らせましょう。速さ `vx` と `vy` を持ち、毎フレーム `x` と `y` に足し、壁に
   届いたら符号を反転します（`束縛 vx = 0 - vx`）。
3. お絵かきプログラムで、色がポインタの x 位置に従うようにします：
   `束縛 色相 = mouse_x() / 640 * 360`。
4. スターキャッチャーに最高得点を加え、`UI文字` で得点の下に表示しましょう。
5. 爆弾を加えましょう。暗い円で描く 2 つ目の落下物で、受け止めるとライフが 1 つ減ります。
