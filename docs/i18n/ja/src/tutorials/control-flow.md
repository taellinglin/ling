# 条件分岐とループ

プログラムは、動作を選んだり繰り返したりできるようになると面白くなります。このレッスンでは、
`もし` と `他` で判断し、`間` と `繰` で作業を繰り返し、`一致` で多くの場合から 1 つを選びます。
また、Ling の初心者のほとんどが驚くスコープのルールもひとつ学びます。

## `もし` で判断する

```ling
束縛 開始 = 実行 {
  束縛 気温 = 31
  もし 気温 > 30 {
    印刷("暑いです。水を飲みましょう。")
  }
  印刷("確認しました。")
}
```
```output
暑いです。水を飲みましょう。
確認しました。
```

形は `もし 条件 { ... }` です。条件は `真` か `偽` になるものなら何でもよく、たいていは比較です。
真ならブロックが実行され、そうでなければ Ling はそれを飛ばします。条件にかっこは要りませんが、
波かっこは必須です。

`気温` を `20` に変えてもう一度実行してみましょう。`確認しました。` だけが表示されます。

## `他` と `他 もし`

`他` はもう一方の道です。`他 もし` で判断をつなげられます。Ling は上から順に調べ、最初に条件が
真になったブロックを実行します。

```ling
束縛 開始 = 実行 {
  束縛 点数 = 83
  もし 点数 >= 90 {
    印刷("評価 A")
  } 他 もし 点数 >= 80 {
    印刷("評価 B")
  } 他 もし 点数 >= 70 {
    印刷("評価 C")
  } 他 {
    印刷("練習を続けよう")
  }
}
```
```output
評価 B
```

83 は 70 以上でもありますが、`点数 >= 80` の分岐が先にあるのでそちらが選ばれます。いちばん大きな
基準を先に書きましょう。

条件は `&&`（かつ）、`||`（または）、`!`（否定）で組み合わせます。

```ling
束縛 開始 = 実行 {
  束縛 時刻 = 14
  束縛 雨 = 真
  束縛 傘あり = 偽
  もし 時刻 >= 9 && 時刻 < 17 {
    印刷("お店は開いています")
  }
  もし 雨 && !傘あり {
    印刷("ぬれてしまいます")
  }
  もし 時刻 < 6 || 時刻 > 22 {
    印刷("もう寝ましょう")
  } 他 {
    印刷("まだ起きていられます")
  }
}
```
```output
お店は開いています
ぬれてしまいます
まだ起きていられます
```

## `間` で繰り返す

`間`（`while`）ループは、条件が真である間ずっとブロックを繰り返します。

```ling
束縛 開始 = 実行 {
  束縛 i = 1
  間 i <= 5 {
    印刷("カウント：", i)
    束縛 i = i + 1
  }
  印刷("発射！")
}
```
```output
カウント：1
カウント：2
カウント：3
カウント：4
カウント：5
発射！
```

`間` ループには必ず 3 つの部分があります。

1. ループの前にカウンタを用意する（`束縛 i = 1`）。
2. ループを続ける条件（`i <= 5`）。
3. ループの中で作業をし、**カウンタを進める**（`束縛 i = i + 1`）。

手順 3 を忘れると、条件はずっと真のままです。終わらないプログラムは **Ctrl+C** で止めます。

### 結果をためる

`間`（または `もし`）ブロックの中の `束縛` は、ブロックの外の名前を変えます。そのため、合計を
求めるには `間` が向いています。

```ling
束縛 開始 = 実行 {
  束縛 合計 = 0
  束縛 n = 1
  間 n <= 100 {
    束縛 合計 = 合計 + n
    束縛 n = n + 1
  }
  印刷("1 + 2 + ... + 100 = ", 合計)
}
```
```output
1 + 2 + ... + 100 = 5050
```

## `繰` で数える

繰り返す回数がわかっているときは、`繰`（`for`）のほうが短く書けます。数の**範囲**や、リストの
要素を順にたどります。

```ling
束縛 開始 = 実行 {
  繰 i の中 0..4 {
    印刷("i は ", i)
  }
  繰 k の中 1..4 {
    印刷(k, " x 7 = ", k * 7)
  }
  繰 色 の中 ["赤", "緑", "青"] {
    印刷(色, "が好きです")
  }
}
```
```output
i は 0
i は 1
i は 2
i は 3
1 x 7 = 7
2 x 7 = 14
3 x 7 = 21
赤が好きです
緑が好きです
青が好きです
```

`0..4` は 0、1、2、3 を意味します。範囲は 2 つ目の数の**直前**で止まります。だから
`繰 i の中 0..4` はちょうど 4 回実行されます。

範囲の終わりは、数、名前、またはかっこで囲んだものでなければなりません。`0..(n + 1)` や
`0..(長さ(xs))` と書き、`0..長さ(xs)` とは決して書かないでください。そう書くと、何も言わずに
1 回も実行されません。

### `繰` のスコープのルール

誰もが驚くルールです。`繰` ループは 1 回ごとに、周りの名前の新しいコピーを受け取ります。`繰` の
本体の中の `束縛` は、外の名前を**変えません**。

```ling
束縛 開始 = 実行 {
  束縛 合計 = 0
  繰 i の中 1..5 {
    束縛 合計 = 合計 + i
  }
  印刷("繰 のあと：", 合計)

  束縛 合計 = 0
  束縛 i = 1
  間 i < 5 {
    束縛 合計 = 合計 + i
    束縛 i = i + 1
  }
  印刷("間 のあと：", 合計)
}
```
```output
繰 のあと：0
間 のあと：10
```

目安はこうです。何かを**する**だけのループ（表示、描画、音を鳴らす）には `繰` を使います。
**結果を残す**必要があるループ（合計、個数、増えていくリスト）には `間` を使います。

Ling には使える `break` や `continue` がありません。`間` ループを早めに抜けたいときは、
`束縛 探索中 = 偽` のようなフラグで条件を偽にします。

### ループの中のループ

ループは別のループの中に入れられます。ここでは外側の `繰` は表示するだけで、内側の `間` が各行の
テキストを組み立てます。

```ling
束縛 開始 = 実行 {
  繰 行 の中 1..5 {
    束縛 文字列 = ""
    束縛 列 = 0
    間 列 < 行 {
      束縛 文字列 = 文字列 + "*"
      束縛 列 = 列 + 1
    }
    印刷(文字列)
  }
}
```
```output
*
**
***
****
```

## `一致` で選ぶ

1 つの値をたくさんの候補と比べるときは、長い `他 もし` の連鎖より `一致`（`match`）のほうが
すっきりします。各**アーム**は `パターン => 動作` と書きます。Ling は最初に当てはまったアームを
実行し、`_` は何にでも当てはまります。

```ling
束縛 開始 = 実行 {
  束縛 曜日 = 3
  一致 曜日 {
    1 => 印刷("月曜日")
    2 => 印刷("火曜日")
    3 => 印刷("水曜日")
    _ => 印刷("ほかの曜日")
  }
  束縛 合図 = 一致 "青" {
    "赤" => "止まれ"
    "青" => "進め"
    _ => "待て"
  }
  印刷(合図)
}
```
```output
水曜日
進め
```

`一致` は数とテキストに使え、束縛できる値を返すこともできます。最後には必ず `_` のアームを
書きましょう。どれにも当てはまらないと、`一致` は黙って「何もない」値 `()` を返します。

## やってみよう

1. 数 `n` を束縛し、`正`、`負`、`ゼロ` のどれかを表示しましょう。
2. `繰` ループで 6 の段を `6 x 1` から `6 x 10` まで表示しましょう。
3. `間` ループで 2 から 50 までの偶数を足しましょう（答えは 650 です）。
4. 1 から始めて 1000 より大きくなるまで 2 倍にし続け、何回 2 倍にしたかを表示しましょう。
5. 評価の例を逆の順序（先に `点数 >= 70`）で書き直してみましょう。何がおかしくなりますか。
