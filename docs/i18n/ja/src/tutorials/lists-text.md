# リストとテキスト

これまでは、1 つの名前が 1 つの値を持っていました。このレッスンでは、たくさんの値を**リスト**に
まとめ、ループでたどり、テキストを分解してまた組み立てます。最後に小さな単語カウンターを作ります。

## リストを作る

リストは角かっこで囲み、要素をカンマで区切って書きます。

```ling
束縛 開始 = 実行 {
  束縛 果物 = ["りんご", "バナナ", "さくらんぼ"]
  印刷(果物)
  印刷(長さ(果物))
  印刷(要素取得(果物, 0))
  印刷(果物[2])
}
```
```output
[りんご, バナナ, さくらんぼ]
3
りんご
さくらんぼ
```

- リストを表示すると、要素が角かっこの中に並びます。
- `長さ(果物)` は要素の数です。
- `要素取得(果物, 0)` は位置 0 の要素を読みます。`果物[2]` は `要素取得(果物, 2)` の短い書き方です。

**位置は 0 から始まります。** 最初の要素は位置 0、3 つのうち最後の要素は位置 2 です。位置は
「いくつ飛ばすか」と考えるとわかりやすいでしょう。位置は 0 から `長さ(xs) - 1` の範囲に収めてください。
存在しない位置を求めると、標準のエンジンでは空の値になり、インタプリタではエラーになります。

## リストを変える：必ず束縛し直す

`リスト追加`（`list_push`）は末尾に要素を加え、`list_set` はある位置の要素を置き換えます。どちらも
**新しい**リストを返します。それを残すには、名前をもう一度束縛します。

```ling
束縛 開始 = 実行 {
  束縛 果物 = ["りんご", "バナナ", "さくらんぼ"]
  束縛 果物 = リスト追加(果物, "なつめ")
  印刷(果物)
  束縛 果物 = list_set(果物, 1, "ブルーベリー")
  印刷(果物)
  印刷("果物は ", 長さ(果物), " 種類になりました")
}
```
```output
[りんご, バナナ, さくらんぼ, なつめ]
[りんご, ブルーベリー, さくらんぼ, なつめ]
果物は 4 種類になりました
```

必ず `束縛 果物 = リスト追加(果物, "なつめ")` と書き、`リスト追加(果物, "なつめ")` だけを単独で
書かないでください。[値と束縛](values.md)で身に付けた、束縛し直す習慣と同じです。

## ループでリストを作る

`新規リスト()` で空のリストを作り、そこに要素を追加していきます。[条件分岐とループ](control-flow.md)の
スコープのルールを思い出してください。`繰` の本体は結果を残せないので、リストは `間` で作ります。

```ling
束縛 開始 = 実行 {
  束縛 平方数 = 新規リスト()
  束縛 i = 1
  間 i < 8 {
    束縛 平方数 = リスト追加(平方数, i * i)
    束縛 i = i + 1
  }
  印刷(平方数)
}
```
```output
[1, 4, 9, 16, 25, 36, 49]
```

## リストをたどる

リストを**読む**だけなら `繰` で十分です。結果をためる必要もあるときは、位置を使った `間` にします。

```ling
束縛 開始 = 実行 {
  束縛 得点 = [72, 95, 88, 61, 79]
  繰 s の中 得点 {
    印刷("得点：", s)
  }
  束縛 合計 = 0
  束縛 最高 = 得点[0]
  束縛 i = 0
  間 i < 長さ(得点) {
    束縛 s = 得点[i]
    束縛 合計 = 合計 + s
    もし s > 最高 {
      束縛 最高 = s
    }
    束縛 i = i + 1
  }
  印刷("合計：", 合計)
  印刷("平均：", 合計 / 長さ(得点))
  印刷("最高：", 最高)
  印刷("list_max の答え：", list_max(得点, 0))
}
```
```output
得点：72
得点：95
得点：88
得点：61
得点：79
合計：395
平均：79
最高：95
list_max の答え：95
```

`最高` は最初の要素から始まり、より大きな要素が出てくるたびに入れ替わります。組み込み関数 `list_max` と
`list_min` も同じ仕事をします。2 つ目の引数は、リストが空のときの答えです。

## テキストの道具

Ling にはテキストを扱う組み込み関数がそろっています。

```ling
束縛 開始 = 実行 {
  束縛 s = "  こんにちは、Ling 世界  "
  印刷(長さ(s))
  束縛 s = trim(s)
  印刷("[" + s + "]")
  印刷(str_upper(s))
  印刷(str_lower(s))
  印刷(substr(s, 0, 5))
  印刷(str_find(s, "Ling"))
  印刷(str_find(s, "Python"))
  印刷(str_replace(s, "世界", "友だち"))
  印刷(starts_with(s, "こんにちは"))
  印刷(str_repeat("ハ", 3))
}
```
```output
17
[こんにちは、Ling 世界]
こんにちは、LING 世界
こんにちは、ling 世界
こんにちは
6
-1
こんにちは、Ling 友だち
true
ハハハ
```

| 組み込み関数 | 用途 |
|---|---|
| `長さ(s)` | 文字数 |
| `trim(s)` | 両端の空白を取り除く |
| `str_upper(s)`、`str_lower(s)` | 大文字・小文字を変える |
| `substr(s, 開始位置, 個数)` | 位置 `開始位置`（0 から数える）から `個数` 文字を取り出す |
| `str_find(s, 部分)` | 最初に見つかった位置。見つからなければ `-1` |
| `str_replace(s, 元, 新)` | すべての `元` を `新` に置き換える |
| `starts_with(s, 部分)`、`ends_with(s, 部分)` | `真` か `偽` |
| `str_repeat(s, n)` | テキストを `n` 回繰り返す |

リストの組み込み関数と同じく、これらも元のテキストを変えません。新しいテキストを返すので、結果を
束縛してください：`束縛 s = trim(s)`。

## 分割と結合

`split` は、区切り文字が現れるところでテキストを切ってリストにします。`list_join` はリストを 1 つの
テキストに貼り合わせます（`join` も同じ組み込み関数です）。

```ling
束縛 開始 = 実行 {
  束縛 行 = "赤,緑,青"
  束縛 部分 = split(行, ",")
  印刷(部分)
  印刷(長さ(部分))
  印刷(list_join(部分, " | "))
  束縛 数字 = split("3 8 15", " ")
  印刷(to_number(数字[1]) + 1)
}
```
```output
[赤, 緑, 青]
3
赤 | 緑 | 青
9
```

`split` で得られる部分はテキストです。計算に使う前に `to_number` で変換しましょう。

## 1 文字ずつ

`substr(s, i, 1)` は位置 `i` の 1 文字を返します。これを使ってテキストを逆順にします。

```ling
関数 逆順(s) {
  束縛 結果 = ""
  束縛 i = 長さ(s) - 1
  間 i >= 0 {
    束縛 結果 = 結果 + substr(s, i, 1)
    束縛 i = i - 1
  }
  戻る 結果
}

束縛 開始 = 実行 {
  印刷(逆順("リング"))
  印刷(逆順("しんぶんし") == "しんぶんし")
}
```
```output
グンリ
true
```

## 単語カウンター

Ling にはまだ辞書型がないので、2 つのリストを並べて使います。`単語` には異なる単語を 1 つずつ、
`回数` にはそれが何回出てきたかを入れます。補助関数が単語の位置を探します。

```ling
関数 位置(要素, 目標) {
  束縛 i = 0
  間 i < 長さ(要素) {
    もし 要素[i] == 目標 {
      戻る i
    }
    束縛 i = i + 1
  }
  戻る -1
}

束縛 開始 = 実行 {
  束縛 全部 = split("ねこ、いぬ、とり、ねこ、いぬ、ねこ、さかな", "、")
  束縛 単語 = 新規リスト()
  束縛 回数 = 新規リスト()
  束縛 i = 0
  間 i < 長さ(全部) {
    束縛 w = 全部[i]
    束縛 p = 位置(単語, w)
    もし p == -1 {
      束縛 単語 = リスト追加(単語, w)
      束縛 回数 = リスト追加(回数, 1)
    } 他 {
      束縛 回数 = list_set(回数, p, 回数[p] + 1)
    }
    束縛 i = i + 1
  }
  束縛 k = 0
  間 k < 長さ(単語) {
    印刷(単語[k], "：", 回数[k])
    束縛 k = k + 1
  }
}
```
```output
ねこ：3
いぬ：2
とり：1
さかな：1
```

> **注：** `==` で比べられるのは数、テキスト、真偽値です。2 つのリストを `==` で比べると、中身が
> 同じでも常に `偽` になります。要素を 1 つずつ比べてください。
