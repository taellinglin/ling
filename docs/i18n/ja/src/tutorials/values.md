# 値と束縛

どんなプログラムも情報を扱います。点数、名前、「はい」か「いいえ」の答えなどです。このレッスンでは、
Ling の基本的な値の種類を知り、`束縛`（`bind`）で名前を付け、束縛し直すことで値を「変更」し、
それを表示します。各ステップには小さなプログラムがあるので、ファイルにコピーして `ling run` で
実行してみてください。

## 値

ひとつの情報を**値**と呼びます。よく使うのは次の種類です。

| 種類 | 中身 | 例 |
|---|---|---|
| 数値 | 整数や小数などの数 | `42`、`3.14`、`-7` |
| テキスト | 文字、単語、文（*文字列*とも呼びます） | `"こんにちは"`、`"101 号室"` |
| 真偽値 | 2 つの答えのどちらか：はい、いいえ | `真`、`偽` |
| リスト | 一列に並んだ複数の値 | `[1, 2, 3]`、`["赤", "青"]` |

それぞれをひとつずつ表示してみましょう。

```ling
束縛 開始 = 実行 {
  印刷(42)
  印刷(3.14)
  印刷("ひとかたまりのテキスト")
  印刷(真)
  印刷([1, 2, 3])
}
```
```output
42
3.14
ひとかたまりのテキスト
true
[1, 2, 3]
```

数値はそのまま書きます。テキストはダブルクォートで囲みます。`真` と `偽` はテキストではないので
クォートを付けません。表示すると `true` と `false` になります。リストは角かっこで囲み、要素を
カンマで区切ります。

値の書き方のルールをいくつか挙げます。

- 数値は普通の数字で書き、小数点は 1 つまでです。`.5` ではなく `0.5` と書きます。`1e3` や `0xff` の
  ような書き方はありません。
- テキストにはダブルクォートだけを使います。テキストの中では `\n` が改行、`\"` がクォート記号です。

## 束縛：値に名前を付ける

`束縛` で値に名前を付けます。それ以降、その名前は値の代わりになります。

```ling
束縛 開始 = 実行 {
  束縛 名前 = "ミナ"
  束縛 年齢 = 12
  印刷("こんにちは、" + 名前)
  印刷(名前, "は", 年齢, "歳です")
  印刷("来年：", 年齢 + 1)
}
```
```output
こんにちは、ミナ
ミナは12歳です
来年：13
```

`束縛 年齢 = 12` は「名前 `年齢` を値 12 に束縛する」と読みます。名前には文字、数字、アンダースコアを
使えますが、数字で始めることはできません。値の意味がわかる名前を選びましょう。`a` より `年齢` の
ほうがわかりやすいです。

あなたが書くプログラムは、どれも `束縛 開始 = 実行 { ... }` で始まります。波かっこの中の命令が上から
順に実行されます。

## 束縛し直す：Ling での「変更」

Ling には**代入文がありません**。`点数 = 点数 + 5` と書くと構文エラーになります。名前に新しい値を
持たせたいときは、もう一度束縛します。

```ling
束縛 開始 = 実行 {
  束縛 点数 = 10
  印刷("点数は ", 点数)
  束縛 点数 = 点数 + 5
  印刷("点数は ", 点数)
  束縛 点数 = 点数 * 2
  印刷("点数は ", 点数)
}
```
```output
点数は 10
点数は 15
点数は 30
```

`束縛 点数 = 点数 + 5` は、まず今の `点数` の値を使って右辺を計算し、その結果に `点数` という
ラベルを貼ります。何かを変えたくなったら `束縛` と書く、という習慣を付けましょう。

## 表示

`印刷` は引数を表示して改行します。英語の `println` もまったく同じ働きをします。Ling ではどちらも
最後に改行します。引数を複数渡すと、順番に表示されますが、**間には何も入りません**。スペースも
入りません。

```ling
束縛 開始 = 実行 {
  印刷("合計", 1 + 2)
  印刷("合計：", 1 + 2)
  印刷("あ", "い", "う")
  印刷("1 行目\n2 行目")
  印刷("彼女は\"やあ\"と言った")
}
```
```output
合計3
合計：3
あいう
1 行目
2 行目
彼女は"やあ"と言った
```

スペースや区切りが必要なら、`"合計："` のようにテキストの中に書きます。

## 算術

Ling ではおなじみの記号を使います。`+`、`-`、`*`、`/`、そして余りを求める `%` です。

```ling
束縛 開始 = 実行 {
  印刷(7 + 3)
  印刷(7 / 2)
  印刷(7 % 2)
  印刷(2 + 3 * 4)
  印刷((2 + 3) * 4)
  印刷(四捨五入(3.7))
  印刷(平方根(81))
}
```
```output
10
3.5
1
14
20
4
9
```

割り算は切り捨てずに正確な答え（`3.5`）を返します。掛け算は足し算より先に計算されるので、
`2 + 3 * 4` は `14` です。別の順序にしたいときはかっこを使います。`四捨五入` と `平方根` は
**組み込み関数**、つまり Ling に最初から入っている関数です。

## テキストと数値の変換

`+` で 2 つのテキストをつなげられます。数値をテキストにつなげるには、まず `str` でテキストに
変換します（`to_str` も同じ関数です）。逆に、`to_number` はテキストを数値に変換します。

```ling
束縛 開始 = 実行 {
  束縛 りんご = 3
  印刷("りんごが " + str(りんご) + " 個あります")
  束縛 入力 = "12"
  印刷(to_number(入力) + 1)
  印刷(フォーマット("{} + {} = {}", 2, 3, 2 + 3))
  印刷(フォーマット("約 {:.2}", 3.14159))
}
```
```output
りんごが 3 個あります
13
2 + 3 = 5
約 3.14
```

`フォーマット`（`format`）は、テンプレートの中の `{}` を後ろの引数で順に埋めます。`{:.2}` は数値を
小数点以下 2 桁で表示します。

## 比較と真偽値

比較は「はい」か「いいえ」の質問をして、`真` か `偽` を返します。

```ling
束縛 開始 = 実行 {
  印刷(5 > 3)
  印刷(5 == 5)
  印刷(5 != 5)
  印刷("ねこ" == "ねこ")
  束縛 大きい = 100 > 50
  印刷("大きい：", 大きい)
  印刷(真 && 偽)
  印刷(真 || 偽)
  印刷(!真)
}
```
```output
true
true
false
true
大きい：true
false
true
false
```

比較演算子は `==`、`!=`、`<`、`>`、`<=`、`>=` です。`=` ひとつだけでは決して比較になりません。
`束縛` の中にだけ現れます。答えは `&&`（かつ：両方が真）、`||`（または：少なくとも一方が真）、
`!`（否定）で組み合わせます。数学のように比較をつなげて書かないでください。`1 < x < 10` ではなく
`x > 1 && x < 10` と書きます。

## コメント

行の中で `#` または `//` より後ろはコメントです。Ling はこれを無視します。人のためのメモです。

```ling
# 小さな割り勘プログラム
束縛 開始 = 実行 {
  束縛 請求額 = 84.50
  束縛 人数 = 4      // テーブルの友だち
  束縛 ひとり分 = 請求額 / 人数
  印刷("ひとり ", 四捨五入(ひとり分 * 100) / 100)
}
```
```output
ひとり 21.13
```

`四捨五入(x * 100) / 100` は、表示用に数値を小数点以下 2 桁に丸めます。

## やってみよう

1. 自分の年齢を束縛し、「10 年後は ... 歳」と正しい数字を入れて表示しましょう。
2. 幅 12.5、高さ 8 の長方形があります。面積と周囲の長さを、それぞれラベル付きで表示しましょう。
3. `n` を 10 に束縛します。`束縛` だけを使って 11、22、4 の順に変え、各ステップのあとで `n` を
   表示しましょう。
4. `(f - 32) * 5 / 9` を使って華氏 98.6 度を摂氏に変換し、小数点以下 1 桁に丸めて表示しましょう。
5. `"7" + "3"` と `to_number("7") + to_number("3")` を表示してみましょう。なぜ結果が違うのでしょうか。
