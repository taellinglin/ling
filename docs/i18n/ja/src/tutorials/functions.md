# 関数

関数は名前の付いたレシピです。手順を一度書けば、何度でも使えます。`印刷`、`四捨五入`、`str` の
ような組み込み関数はもう使いましたね。このレッスンでは、`関数`（`fn`）で自分の関数を書き、引数を
渡し、`戻る`（`return`）で答えを返し、関数に自分自身を呼び出させます。

## 関数を定義して呼び出す

```ling
関数 あいさつ(名前) {
  印刷("こんにちは、" + 名前 + "さん！")
}

束縛 開始 = 実行 {
  あいさつ("エイダ")
  あいさつ("グレース")
  あいさつ("ミナ")
}
```
```output
こんにちは、エイダさん！
こんにちは、グレースさん！
こんにちは、ミナさん！
```

- `関数` は「これから関数を定義します」という意味です。
- `あいさつ` は関数の名前です。
- かっこの中の `名前` は**引数（パラメータ）**です。関数を呼ぶたびに埋められる空欄です。
- 波かっこの中が**本体**で、関数が実行する手順です。

関数を定義しただけでは実行されません。本体が実行されるのは、`あいさつ("エイダ")` のように関数を
**呼び出した**ときだけです。かっこの中の値は**実引数**と呼ばれ、その呼び出しの間は `名前` の値になります。

関数はファイルのトップレベル、つまり `束縛 開始` の外に書きます。実際に何かをする命令は `開始` の中に書きます。

## `戻る` で答えを返す

関数に何かを計算させて、その答えを返してほしいことはよくあります。それが `戻る` の役目です。
引数はカンマで区切って複数受け取れます。

```ling
関数 二乗(n) {
  戻る n * n
}

関数 平均(a, b) {
  戻る (a + b) / 2
}

束縛 開始 = 実行 {
  印刷(二乗(7))
  印刷(平均(10, 25))
  印刷(二乗(平均(2, 4)))
}
```
```output
49
17.5
9
```

`二乗(7)` は値を持つので、値を置ける場所ならどこでも使えます。`印刷` の中、もっと大きな式の中、
あるいは別の呼び出しの引数としてもです。`二乗(平均(2, 4))` は内側から計算されます。`平均(2, 4)` が
3 で、`二乗(3)` が 9 です。

### 早めに戻る

最初に実行された `戻る` で関数は終わります。これを使って、特別な場合を先に片付けましょう。

```ling
関数 説明(n) {
  もし n < 0 {
    戻る "負の数"
  }
  もし n == 0 {
    戻る "ゼロ"
  }
  戻る "正の数"
}

関数 三乗(n) { n * n * n }

束縛 開始 = 実行 {
  印刷(説明(-5))
  印刷(説明(0))
  印刷(説明(12))
  印刷(三乗(3))
}
```
```output
負の数
ゼロ
正の数
27
```

`説明` には `他` が要りません。`戻る` の時点で関数を抜けるからです。`三乗` は省略形の例です。
`戻る` がないと、関数は最後の式の値を返します。`あいさつ` のように何も計算しない関数は、「何もない」
値 `()` を返します。

## 関数から見えるもの

呼び出しのたびに、関数は自分専用の名前を持ちます。引数と、関数の中で束縛したものです。これらは
呼び出し元のコードの名前とぶつかりません。

```ling
束縛 税率 = 0.2

関数 税込み(価格) {
  束縛 合計 = 価格 + 価格 * 税率
  戻る 合計
}

束縛 開始 = 実行 {
  束縛 合計 = 99
  印刷(税込み(50))
  印刷("わたしの合計はまだ ", 合計)
}
```
```output
60
わたしの合計はまだ 99
```

関数は `税率` のようなファイルのトップレベルの束縛を見ることができます。定数を置くのに向いた場所です。
しかし、呼び出し元のローカルな名前は**見えません**。必要なものは引数として渡しましょう。

## 自分自身を呼ぶ関数

関数は自分自身を呼び出せます。これを**再帰**と呼びます。再帰には 2 つの部分が必要です。

1. **基底ケース**：答えがすぐにわかるほど単純な場合。
2. **再帰ケース**：自分を呼び出して、より小さな問題を解く場合。

5 の階乗は `5 * 4 * 3 * 2 * 1` で、これは `5 * 階乗(4)` と同じです。

```ling
関数 階乗(n) {
  もし n <= 1 {
    戻る 1
  }
  戻る n * 階乗(n - 1)
}

関数 フィボナッチ(n) {
  もし n < 2 {
    戻る n
  }
  戻る フィボナッチ(n - 1) + フィボナッチ(n - 2)
}

束縛 開始 = 実行 {
  印刷("5! = ", 階乗(5))
  印刷("10! = ", 階乗(10))
  繰 i の中 0..10 {
    印刷("フィボナッチ(", i, ") = ", フィボナッチ(i))
  }
}
```
```output
5! = 120
10! = 3628800
フィボナッチ(0) = 0
フィボナッチ(1) = 1
フィボナッチ(2) = 1
フィボナッチ(3) = 2
フィボナッチ(4) = 3
フィボナッチ(5) = 5
フィボナッチ(6) = 8
フィボナッチ(7) = 13
フィボナッチ(8) = 21
フィボナッチ(9) = 34
```

`階乗(3)` を手でたどってみましょう。`3 * 階乗(2)` を返し、それには `2 * 階乗(1)` が必要で、`階乗(1)` は
基底ケースなので 1 です。そこから答えが戻っていきます。`2 * 1 = 2`、次に `3 * 2 = 6` です。基底ケースが
ないと、関数は余地がなくなるまで自分を呼び続けてしまいます。

## まとめの練習：FizzBuzz

1 から 15 まで数えます。3 の倍数なら `Fizz`、5 の倍数なら `Buzz`、両方の倍数なら `FizzBuzz` を表示し、
それ以外は数そのものを表示します。

```ling
関数 fizzbuzz(n) {
  もし n % 15 == 0 {
    戻る "FizzBuzz"
  }
  もし n % 3 == 0 {
    戻る "Fizz"
  }
  もし n % 5 == 0 {
    戻る "Buzz"
  }
  戻る str(n)
}

束縛 開始 = 実行 {
  繰 n の中 1..16 {
    印刷(fizzbuzz(n))
  }
}
```
```output
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

15 の判定は最初に置きます。そうしないと、15 は 3 の判定で止まって `Fizz` と表示されてしまいます。
関数は数を言葉に変え、`開始` はループして表示するだけです。よい関数は 1 つのことだけをし、必要なものを
引数で受け取り、何をするかがわかる名前を持っています。

## 値としての関数

言語によっては、関数を束縛に入れたり、別の関数に渡したりできます。Ling にもそのための短いクロージャ
構文 `|x| x * 2` がありますが、現在のバージョンでは関数値は言語の中でもっとも不安定な部分です。束縛に
入れたクロージャや、引数として渡した関数は、`()` を返したり `unknown function` を報告したりすることが
あります。いつでも動くのは、書いたその場でクロージャを呼び出す形だけです。

```ling
束縛 開始 = 実行 {
  印刷((|x| x + 1)(5))
}
```
```output
6
```

今のところは名前付きの `関数` を書き、名前で呼び出してください。詳しくは[既知の制限](../language/limits.md)を参照してください。

> **ヒント：** 関数名のつづりを間違えると、標準のエンジンはエラーではなく `()` を表示します。関数が
> 「何もしない」ように見えるときは、`ling run --interp yourfile.ling` でプログラムを実行してください。
> `unknown function` と報告してくれます。

## やってみよう

1. `真` か `偽` を返す `偶数か(n)` を書き、`偶数か(10)` と `偶数か(7)` を表示しましょう。
2. 3 つの数のうち最大のものを返す `最大3(a, b, c)` を書きましょう（組み込み関数 `最大` は 2 つの引数を
   取ります。入れ子にして使えます）。
3. `間` ループで `総和(n)` を、再帰で `再帰総和(n)` を書きましょう。どちらも 100 に対して 5050 になるはずです。
4. 掛け算だけを使って、`累乗(底, 指数)` を再帰で書きましょう。`累乗(2, 10)` は 1024 です。
5. `"A"`、`"B"`、`"C"`、`"F"` のどれかを返す `評価(点数)` を書き、95、85、75、40 の評価を表示しましょう。
