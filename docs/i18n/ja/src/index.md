# はじめに

Ling は、自分の言語で書けるプログラミング言語です。キーワードと組み込み関数には、中国語、日本語、韓国語、
タイ語、英語、アラビア語、ヘブライ語、ロシア語など 16 以上の言語の名前があり、同じファイルの中で混ぜて使えます。
このドキュメントでは、そのうち English、中文、日本語、한국어、ไทย の 5 つを扱います。ページ上部の言語セレクターで
切り替えられます。

このガイドは Ling 2030.1.53 に対応しています。

## はじめての Ling

小さなプログラムを見てみましょう。どのプログラムも `束縛 開始 = 実行 { ... }` から始まります。

```ling
# 友だちにあいさつする
束縛 開始 = 実行 {
    束縛 友だち = ["さくら", "けんた", "ゆい"]
    繰 名前 の中 友だち {
        印刷("こんにちは、" + 名前 + "さん！")
    }
    印刷(長さ(友だち))
}
```

```output
こんにちは、さくらさん！
こんにちは、けんたさん！
こんにちは、ゆいさん！
3
```

同じプログラムは英語、中国語、韓国語、タイ語のキーワードでも書けます。ページの言語を切り替えて確かめるか、
[5 つの言語で書く](language/multilingual.md)を読んでください。

## できること

`ling` ひとつに、次のものが入っています。

- **JIT コンパイラとインタプリタ。** プログラムは Cranelift でネイティブコードにコンパイルされ、それ以外はインタプリタが実行します。
- **グラフィックスと 3D。** ウィンドウ、2D 描画、画像、フォント、そしてカメラ、ライト、セルシェーディング、ベクタージオメトリ（`vtex_*`）を備えたソフトウェア 3D レンダラー。
- **オーディオと音楽。** トーン、空間オーディオ、WAV 再生、音楽のデコード、BPM とキーの解析、GM 風シンセ、MIDI。
- **物理。** 剛体、ソフトボディ、液体シミュレーション。
- **UI。** HUD、メーター、ボタンなどのウィジェット。
- **Web サーバー。** `http_*` と `db_*` の組み込み関数で、ルート、静的ファイル、SQLite を扱えます。
- **暗号。** ハッシュ、暗号化、署名、耐量子鍵交換。
- **AI。** ニューラルネットワーク、ビヘイビアツリー、オプションの言語モデル対応。

プロジェクト管理ツールの `lingfu` でプロジェクトを作成・実行・テストでき、`lingfu normalize` を使えばプロジェクト全体を
1 つの言語に書き換えられます。

## インストール

macOS または Linux：

```sh
curl --proto '=https' --tlsv1.2 -sSf https://ling-lang.org/install.sh | sh
```

Windows（PowerShell）：

```powershell
irm https://ling-lang.org/install.ps1 | iex
```

Rust が入っていなければスクリプトが先にインストールし、そのあと `ling` と `lingfu` をビルドします。ほかの方法や
インストールプロファイルについては[インストール](getting-started/install.md)を見てください。
