# 2D 描画と画像

ここで紹介する組み込み関数は、ウィンドウのフレームバッファに画面ピクセル単位で直接描きます。線、三角形、
円、多角形、グラデーション、柔らかい影、それにファイルから読み込んだりピクセル単位で作ったりした画像です。
どれも開いたウィンドウが必要で、`fill()` と `present()` の間で使います
（[ウィンドウとカメラ](window.md)を参照）。

## 2D 描画のしくみ

- **座標**はピクセルです。原点は左上の角で、+x は右、**+y は下**を向きます。ウィンドウの外の
  座標は単に描かれません。
- **ペンの色。** 図形は現在のペンの色で描かれます。色は `set_color` で設定し、変えるまで有効です。
  3D の図形もこれを基本色として使います。
- **色の値**は 0 から 255 の数です。**範囲内に丸められません。** ランタイムは
  `(r << 16) | (g << 8) | b` とまとめるので、255 を超えた値は隣のチャンネルにあふれます。負の値は 0 になります。
- **即時の書き込み。** 2D の呼び出しはすぐにピクセルを書き込みます。キューの 3D ジオメトリは後で
  `present()` のときに描かれるので、2D の絵を覆います。3D シーンの上に 2D を描くには、先に `flush_3d()` を呼んでください。
- **まとめた色。** 組み込み関数の中には `0xRRGGBB` のひとつの数を受け取るものがあります。Ling には 16 進数の
  リテラルがないので、`r * 65536 + g * 256 + b` と書きます（たとえば `51 * 65536 + 102 * 256 + 255`）。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(640, 360, "2D")
    間 開いている() {
        塗り潰し(12, 14, 30)
        色設定(230, 90, 90)
        三角形描画(60, 300, 160, 140, 260, 300)
        色設定(90, 200, 255)
        draw_circle(380, 150, 60)
        色設定(120, 255, 160)
        塗りつぶし円(520, 150, 40)
        色設定(255, 220, 90)
        draw_arc(380, 280, 50, 0, 3.14159)
        グラデ矩形(20, 320, 600, 24, 255, 80, 0, 0, 80, 255, 0)
        表示()
    }
}
```

## ペンと合成

### `fill(r, g, b)`

フレームバッファ全体を色で消去し、深度バッファをリセットします。毎フレームの最初に呼んでください。
各チャンネルの既定は 0 なので、`fill()` は黒で消去します。ペンの色は変わりません。
`clear` は英語の同義語です。

### `set_color(r, g, b)`、`set_color_hsl(h, s, l)`、`mix_color(...)`

`set_color` はペンの色を設定します（各チャンネルの既定は 255）。

`set_color_hsl` は度単位の色相（0 から 360）と、彩度・明度（0 から 100、既定は 70 と 50）から色を
設定します。色相を少しずつ変えれば簡単に虹色になります。

`mix_color(r0, g0, b0, r1, g1, b1, t)` は 2 色を混ぜた色をペンに設定します。`t` は 0 から 1 です
（既定は 0.5）。OkLab 色空間で混ぜるので、中間色が濁らずきれいに見えます。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(700, 300, "虹")
    塗り潰し(0, 0, 0)
    束縛 番号 = 0
    間 番号 < 12 {
        HSL色(番号 * 30, 80, 55)
        塗りつぶし円(60 + 番号 * 50, 150, 20)
        束縛 番号 = 番号 + 1
    }
    表示()
    wait_window()
}
```

### `set_alpha(a)`

ペンの不透明度で、0（見えない）から 1（不透明）、既定は 1 です。グラデーションの塗りと
キューの 3D 図形に効きます。

### `set_blend(mode)`

新しいピクセルを既存のピクセルとどう合成するかを決めます。`0` は通常（既定）、`1` は加算です。
加算合成では重なった図形が明るくなり、あらゆる発光表現の基本になります。
キューの 3D 描画は `2` 乗算、`3` スクリーン、`4` 減算、`5` オーバーレイも受け付けます。
使い終わったら 0 に戻してください。

```ling-gui
束縛 start = 実行 {
    ブレンドモード(1)
    色設定(60, 40, 20)
    塗りつぶし円(500, 280, 40)
    塗りつぶし円(530, 280, 40)       # 重なった部分が明るくなる
    ブレンドモード(0)
}
```

### `set_antialias(on)` と `get_antialias()`

線の描画（線、円弧、円の輪郭、3D の辺）をなめらかにします。既定ではオフで、くっきりした
ピクセルの線になります。引数なしの `set_antialias()` でオンになります。`get_antialias()` で設定を読み返せます。
文字のなめらかさは別の設定です（[フォントと UI](fonts-ui.md) を参照）。

## 図形

### `draw_pixel(x, y)` と `draw_line(x0, y0, x1, y1)`

`draw_pixel` は 1 ピクセルを塗ります。`draw_line` は 2 点の間に 1 ピクセル幅の線を描き、
`set_antialias` と加算合成に従います。

### `triangle(x0, y0, x1, y1, x2, y2)`

塗りつぶした三角形です。長方形は三角形 2 つで作るか、`draw_poly` を使います。`draw_triangle` は
英語の同義語です。

```ling-gui
束縛 start = 実行 {
    色設定(230, 90, 90)
    三角形描画(100, 100, 300, 100, 300, 200)
    三角形描画(100, 100, 300, 200, 100, 200)      # 合わせて長方形になる
}
```

### `draw_circle(cx, cy, r)` と `draw_disc(cx, cy, r)`

円の輪郭と塗りつぶした円です。中心と半径はピクセル単位です（半径の既定は 10）。
`draw_disc` は合成モードに従うので、`set_blend(1)` にすると光のように描けます。

### `draw_arc(cx, cy, r, a0, a1, segments)`

角度 `a0` から `a1`（ラジアン）まで円の一部を描きます（既定は 0 から 2π で、円全体）。
`segments` は省略可能です。+y が下向きなので、角度は画面上で**時計回り**に増えます。0 は右、
`pi() / 2` は真下です。

### `draw_poly(points)`

自動的に閉じる塗りつぶし多角形です。`points` は平らなリスト `[x0, y0, x1, y1, ...]` です。
`project_3d` と組み合わせると、投影した 3D の点の間を塗りつぶせます。

```ling-gui
束縛 start = 実行 {
    色設定(200, 140, 255)
    ポリゴン塗り([100, 100, 200, 120, 180, 200, 90, 180])
}
```

### `grad_rect(x, y, w, h, r0, g0, b0, r1, g1, b1, dir)` と `grad_triangle(...)`

`grad_rect` は長方形を 1 色目から 2 色目へのグラデーションで塗ります。`dir` は `0` で左から右、
それ以外で上から下です（既定は 1）。

`grad_triangle(x0, y0, r0, g0, b0, x1, y1, r1, g1, b1, x2, y2, r2, g2, b2)` は各角に色を持たせ、
その間をなめらかに混ぜます。手軽に「光の当たった」面を作れます。

どちらも `set_alpha` に従います。グラデーションは既定で知覚的に混ぜます。`set_gradient_space(0)` で
普通の sRGB に切り替わります。

### `shadow_blob`、`cast_shadow`、`shadow_params`

`shadow_blob(cx, cy, rx, ry, alpha)` はペンの色で柔らかい楕円を描きます（半径の既定は 16 と 8、
`alpha` の既定は 0.5）。暗いペンなら普通の影に、ほかの色なら色付きの影になります。

`cast_shadow(cx, cy, height)` は、地面からの物体の高さに合わせて大きさと柔らかさが変わる接地影を描きます。
低い物体には小さく暗いくっきりした影、高い物体には大きく薄い影ができます。
`shadow_params(base, grow, alpha, fade, soft)` で調整でき、省略した引数は今の値のままです。

```ling-gui
束縛 start = 実行 {
    色設定(0, 0, 20)
    影を落とす(320, 330, 24)
}
```

### `depth_triangle(x0, y0, x1, y1, x2, y2, z)` と `depth_line(x0, y0, x1, y1, z)`

2D の三角形や線をキューに入れ、3D ジオメトリと一緒に奥行きで並べ替えて `present()` のときに描きます。
`z` が大きいほど遠くです。3D の物体の前にも後ろにも回り込む 2D スプライトに使います。

### `set_frame_blur(amount)`

残像のトレイルです。各フレームを、前のフレームを薄くしたものと混ぜます。`amount` は 0 から 0.95 で、
0.9 くらいにすると 60 フレーム毎秒でおよそ 1 秒残るトレイルになります。`0` でオフになります。

## 画像

画像はランタイム内部の表に保存されます。読み込みや作成のたびに**ハンドル**という小さな数が返り、
それをほかの `image_*` 関数に渡します。`-1` は失敗を表します。

| 組み込み関数 | 用途 |
|---|---|
| `image_load(path)` | PNG や JPEG などのラスター画像を読み込む。ハンドルまたは `-1` |
| `image_draw(id, x, y, w, h)` | `w` × `h` ピクセルに拡大縮小して描く |
| `image_new(w, h)` | 透明な新しい画像 |
| `image_set_pixel(id, x, y, r, g, b, a)` | 1 ピクセルを塗る |
| `image_pixel_r(id, x, y)`, `_g`, `_b`, `_a` | 1 チャンネルを読む（0 から 255） |
| `image_width(id)`, `image_height(id)` | ピクセル単位の大きさ |
| `image_save(id, path)` | PNG を書き出す。`1` または `-1` |
| `image_replace(id, path)` | 既存のハンドルに新しいファイルを読み込む |
| `image_tint(id, color)` | アルファの形をした単色のコピー |
| `image_resized(id, w, h)` | 大きさを変えたコピー |
| `image_svg(svg_text, w, h)` | SVG のソーステキストを画像にする |
| `image_free(id)` | ピクセルを解放する |

### `image_load(path)`

ラスター画像を読み込んでハンドルを返します。ファイルを読めないときは `-1` を返し、エラー出力に
メッセージを出します。パスはまずそのまま試し、次にスクリプトのフォルダーからの相対パスとして試します。
同じパスをもう一度読み込むとキャッシュしたハンドルが返るので、フレームループの中で呼んでも安全です。

### `image_draw(id, x, y, w, h, cx, cy, cw, ch, opacity)`

画像の左上を `x, y` に置き、`w` × `h` ピクセルに（最近傍法で）拡大縮小して、フレームの上にアルファ合成します。
**`w` と `h` は必須です。** 0 だと何も描かれないので、元の大きさで描くには `image_width(id)` と
`image_height(id)` を渡してください。省略可能な引数として、外側には何も描かないクリップ矩形
`cx, cy, cw, ch` と、その後ろに 0 から 1 の `opacity` を指定できます。画像は、ポストプロセスが 3D に
かけるトゥーン調の陰影を受けず、そのまま表示されます。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(640, 400, "スプライト")
    束縛 ヒーロー = image_load("hero.png")
    束縛 x = 0
    間 開いている() {
        塗り潰し(20, 24, 40)
        もし ヒーロー >= 0 {
            image_draw(ヒーロー, x, 160, image_width(ヒーロー) * 2, image_height(ヒーロー) * 2)
        }
        表示()
        束縛 x = (x + 2) % 640
    }
}
```

### `image_new`、`image_set_pixel` とピクセルの読み取り

`image_new(w, h)` は完全に透明な空の画像を作ります。`image_set_pixel(id, x, y, r, g, b, a)` は
1 ピクセルを塗ります（`a` の既定は 255）。`image_pixel_r`、`image_pixel_g`、`image_pixel_b`、
`image_pixel_a` はピクセルの 1 チャンネルを読みます。範囲外の位置や不正なハンドルは、書き込みでは
無視され、読み取りでは 0 になります。これらはウィンドウなしで動きます。

```ling
束縛 start = 実行 {
    束縛 画像 = image_new(8, 4)
    image_set_pixel(画像, 2, 1, 255, 128, 0)
    println("大きさ:   " + str(image_width(画像)) + " x " + str(image_height(画像)))
    println("ピクセル: " + str(image_pixel_r(画像, 2, 1)) + ", " + str(image_pixel_g(画像, 2, 1)))
    println("空:       " + str(image_pixel_a(画像, 0, 0)))
    束縛 青 = image_tint(画像, 51 * 65536 + 102 * 256 + 255)
    println("色付け:   " + str(image_pixel_b(青, 2, 1)))
}
```

```output
大きさ:   8 x 4
ピクセル: 255, 128
空:       0
色付け:   255
```

`image_pixel_u16(id, x, y)` は `r * 256 + g` を 1 回の呼び出しで返します。16 ビットのハイトマップ向けです。

### `image_save(id, path)` と `image_replace(id, path)`

`image_save` は（読み込んだか作った）画像をアルファを保ったままファイルに書き出し、足りないフォルダーを
作ります。パスはプログラムを実行した場所からの相対パスです。`1` を返し、失敗すると `-1` を返します。
`image_replace` は既存のハンドルに新しいファイルを読み込むので、何度も読み直す絵で画像の表が
大きくなりません。`1` または `-1` を返します。

ウィンドウそのものを保存するには `screenshot` を使います（[ウィンドウとカメラ](window.md)を参照）。

### `image_tint`、`image_resized`、`image_svg`、`image_free`

`image_tint(id, color)` は、元の画像のアルファの形をした、まとめた色 1 色の新しい画像を返します。
アイコンを好きな色で描き直せます。`image_resized(id, w, h)` は大きさを変えたコピーを返します。
`image_svg(svg_text, w, h)` は SVG の**ソーステキスト**（パスではありません）を新しい画像にします。
ファイルから読むなら先に `read_file` で読み込んでください。3 つとも新しいハンドルか `-1` を返します。

`image_free(id)` は画像のピクセルを解放します。ハンドルは有効なままですが、何も描かれません。

## 文字

文字にはベクターフォントか組み込みのストロークフォントを使います。どちらも[フォントと UI](fonts-ui.md) に
あります。フォントファイルなしで画面にラベルを出すいちばん手軽な方法はこれです。

```ling-gui
束縛 start = 実行 {
    色設定(120, 255, 160)
    UI文字(30, 30, 16, "SCORE 0420")    # ストロークフォントは ASCII のみ
}
```

`ui_text` は英字を大文字で描き、基本的な ASCII 文字しか知りません。それ以外は小さな四角で表示されます。
日本語などほかの文字には、`font_load` でフォントを読み込んで `font_text_fill` で描いてください。
