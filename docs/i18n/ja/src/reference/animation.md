# アニメーション

Anima は Ling のアニメーションシステムです。2D の絵でも 3D メッシュでも、パーティクルでもただの数値でも、動くものはすべて小さな**ドライバ**で動かします。ドライバとは、毎フレーム現在の時刻を渡して呼び出す関数です。ドライバは数値を 1 つ返すので、それを大きさ・位置・角度・パターンの引数に渡します。

ドライバには 2 つの気質があります。

- **有機的**ドライバ（灵、「霊」）は、柔らかく生き物らしい動きを作ります。呼吸、揺れ、歩行、バネのような追従、2 ボーンの逆運動学です。
- **機械的**ドライバ（机、「機械」）は、正確で硬い動きを作ります。かみ合う歯車、カム、スライダークランク、ラックアンドピニオンです。

1 体のキャラクターで両方を混ぜることもできます。たとえば、胸は呼吸し、あごは機械仕掛けで動く生き物です。スケルトンを持つ 3D キャラクターを読み込んだ場合は、このページの最後にある `gltf_*` 組み込み関数でスケルタルアニメーションのクリップを再生できます。

## ドライバのしくみ

ドライバは**純粋関数**です。隠れた状態を持たないので、同じ引数には必ず同じ答えを返します。

- 時間ベースのドライバ（`breathe`、`wobble`、`gait_*`）は、現在時刻をあなたから受け取ります。ふつうは `time_now()` か、毎フレーム `1/60` ずつ進める変数です。裏で何かが再生されているわけではありません。
- バネのドライバ（`spring_to`）は新しい状態を返すので、次のフレームでそれを渡し直します。状態を持つのはあなたのプログラムです。

角度はラジアンです。長さは描画に使っている単位のままです。ドライバは単精度で計算するので、例では小さな補助関数 `r3` で結果を丸めています。

## 補間

### `tween(a, b, t)` と `tween_ease(a, b, t, curve)`

`tween` は `a + (b - a) * t` を返します。進み具合 `t` は 0..1 に**クランプ**されるので、1 を超えて増やし続けても値は `b` のままです。

`tween_ease` は同じことをイージングカーブを通して行います。`curve` は下の Anima の表にある名前です（既定値は `"linear"`）。elastic や back のカーブは `b` を行き過ぎることがあります。

### `ease(curve, t)`

UI ツールキットのイージングカーブの、進み具合 `t`（0..1 にクランプ）での生の値です。始点で 0、終点で 1 になります。カーブ名が**先**に来ます。2 つの色を混ぜるときなど、カーブそのものが必要なときに使います。ローカライズ名はありません。

```ling
関数 丸め3(x: number) -> number {
    四捨五入(x * 1000) / 1000
}

束縛 開始 = 実行 {
    印刷(補間(0, 10, 0.25))
    印刷(補間(0, 10, 2.0))
    印刷(丸め3(緩和補間(0, 100, 0.5, "cubic_in")))
    印刷(丸め3(緩和補間(0, 100, 0.5, "bounce_out")))
    印刷(ease("quad_in", 0.5))
    印刷(丸め3(ease("smooth", 0.25)))
}
```

```output
2.5
10
12.5
76.563
0.25
0.125
```

### イージングカーブの名前

2 つの組み込み関数は**別々の名前の集合**を使います。どちらも大文字と小文字を区別しません。

**`tween_ease`**（Anima のカーブ）。アンダースコアは省略できます。知らない名前は `linear` になります。

| 系統 | 名前 |
|---|---|
| 基本 | `linear`, `step` |
| 2 次 | `quad_in`, `quad_out`, `quad_in_out` |
| 3 次 | `cubic_in`, `cubic_out`, `cubic_in_out`（`smooth` も可） |
| サイン | `sine_in`, `sine_out`, `sine_in_out` |
| 指数 | `expo_in`, `expo_out`, `expo_in_out` |
| エラスティック | `elastic_in`, `elastic_out`（`elastic` も可） |
| バック | `back_in`, `back_out`, `back_in_out`（`overshoot` も可） |
| バウンス | `bounce_in`, `bounce_out`（`bounce` も可） |

**`ease`**（UI のカーブ）。ダッシュとアンダースコアは同じ扱いです。知らない名前は `quad_inout` になります。

| 名前 | 形 |
|---|---|
| `linear` | 直線 |
| `quad_in`, `ease_in` | ゆっくり始まる |
| `quad_out`, `ease_out` | ゆっくり終わる |
| `quad_inout`, `ease`, `smooth` | ゆっくり始まりゆっくり終わる（既定） |
| `cubic_in`, `cubic_out`, `cubic_inout` | より強い版 |
| `quart_out` | 速く始まり、長くゆっくり終わる |
| `sine`, `sine_inout` | 穏やかなサインの in-out |
| `expo`, `expo_out` | 指数的な減衰 |
| `back`, `back_out` | 行き過ぎてから落ち着く |
| `elastic`, `elastic_out` | バネのような行き過ぎ |
| `bounce`, `bounce_out` | 最後に弾む |

## 有機的ドライバ

### `breathe(t, rate, depth)`

1 を中心とした呼吸の倍率で、`1 + depth * sin(2π * rate * t)` です。`rate` は 1 秒あたりの呼吸数（既定値 1）、`depth` は振幅（既定値 0.1）です。大きさやパターンの半径に掛けて使います。

### `wobble(t, freq, amp, phase)`

二次的な動きのためのサインの揺れで、`amp * sin(2π * (freq * t + phase))` です。既定値は `freq` 1、`amp` 1、`phase` 0 です。位相の単位はサイクルなので、`0.25` は 4 分の 1 サイクルのずれです。手足ごとに違う位相を与えると、体全体がばらばらに揺れます。

### `gait_phase(t, speed)`、`gait_swing(t, speed, stride)`、`gait_lift(t, speed, height)`

歩行サイクルです。`speed` は 1 秒あたりのサイクル数です（既定値 1）。

- `gait_phase` はサイクルのどこにいるかを、0 以上 1 未満で返します。
- `gait_swing` は脚の前後の振りを、`-stride` から `stride` の範囲で返します。もう片方の脚には `t + 0.5 / speed` を使います。
- `gait_lift` は足がどれだけ上がっているかを返します。振り出しの半サイクルでは正、接地中は 0 です。画面の y は下向きなので、引き算します。`足のy = 地面のy - gait_lift(...)` のようにします。

```ling
関数 丸め3(x: number) -> number {
    四捨五入(x * 1000) / 1000
}

束縛 開始 = 実行 {
    束縛 時刻 = 0.125
    印刷(丸め3(呼吸(時刻, 1, 0.2)))
    印刷(丸め3(揺れ(時刻, 1, 10, 0)))
    印刷(丸め3(歩相(時刻, 2)))
    印刷(丸め3(歩振り(時刻, 1, 30)))
    印刷(丸め3(足上げ(時刻, 1, 10)))
}
```

```output
1.141
7.071
0.25
21.213
7.071
```

### `spring_to(pos, vel, target, stiffness, damping, dt)`

`pos` を `target` に引き寄せる減衰バネの 1 ステップです。追従の余韻、カメラのスムージング、しっぽなどに使います。既定値は `stiffness` 120、`damping` 14、`dt` 1/60 です。戻り値は 2 要素のリスト `[新しい位置, 新しい速度]` です。両方を保持して、次のフレームで渡し直します。

既定値では、値は少し行き過ぎてから 1 秒ほどで落ち着きます。

```ling
束縛 開始 = 実行 {
    束縛 位置 = 0.0
    束縛 速度 = 0.0
    束縛 フレーム = 0
    間 フレーム < 60 {
        束縛 結果 = バネ寄せ(位置, 速度, 1.0, 120, 14, 1 / 60)
        束縛 位置 = 結果[0]
        束縛 速度 = 結果[1]
        束縛 フレーム = フレーム + 1
        もし フレーム % 15 == 0 {
            印刷(str(フレーム) + ": " + str(四捨五入(位置 * 1000) / 1000))
        }
    }
}
```

```output
15: 0.982
30: 1.021
45: 0.997
60: 1
```

### `ik2(l1, l2, tx, ty)`

平面上の 2 ボーン逆運動学です。2 つの節からなる腕や脚の先端を目標に届かせる、肩とひじの角度を求めます。`l1` と `l2` はボーンの長さ（既定値 1）、`(tx, ty)` は肩から見た目標位置です。

戻り値はラジアンの `[肩, ひじ]` です。`肩` は 1 本目のボーンの角度、`ひじ` は 2 本目のボーンの曲がりで、**1 本目に対する相対値**です。届かない目標はクランプされるので、手足はそちらへまっすぐ伸びます。関節の位置は次のように求めます。

- ひじ = 肩の位置 + `l1 * (cos(肩), sin(肩))`
- 手 = ひじ + `l2 * (cos(肩 + ひじ), sin(肩 + ひじ))`

```ling
関数 丸め3(x: number) -> number {
    四捨五入(x * 1000) / 1000
}

束縛 開始 = 実行 {
    束縛 角度 = 逆運動(1, 1, 1, 1)
    印刷([丸め3(角度[0]), 丸め3(角度[1])])
}
```

```output
[1.571, -1.571]
```

## 機械的ドライバ

| 組み込み関数 | 戻り値 |
|---|---|
| `gear_couple(angle, teeth_in, teeth_out)` | 従動歯車の角度：`-angle * teeth_in / teeth_out`（`teeth_out` が 0 なら 0）。かみ合う歯車は逆向きに回ります。 |
| `gear_train(angle, teeth)` | 列になった歯車それぞれの角度のリスト。`teeth` は歯数のリストで、結果の最初の要素は `angle` そのものです。 |
| `cam_lift(angle, lift)` | カムフォロワーの高さ：`lift * (1 - cos(angle)) / 2`。角度 0 で 0、π で `lift` です。 |
| `piston(angle, crank, rod)` | クランク中心からシリンダーに沿ったピストンピンの位置。既定値は `crank` 1、`rod` 2 です（ロッドはクランクより長くします）。 |
| `rack(angle, radius)` | ラックの移動量：`angle * radius`。 |

歯数 12 の歯車が歯数 36 の歯車を回すと、相手は 3 分の 1 の速さで逆向きに回ります。

```ling
関数 丸め3(x: number) -> number {
    四捨五入(x * 1000) / 1000
}

束縛 開始 = 実行 {
    印刷(丸め3(歯車連動(3, 12, 36)))
    束縛 歯車 = 歯車列(1, [12, 36, 12])
    印刷([丸め3(歯車[0]), 丸め3(歯車[1]), 丸め3(歯車[2])])
    印刷(丸め3(カム揚程(3.14159265, 2)))
    印刷(丸め3(ピストン(0, 1, 3)))
    印刷(ラック(2, 0.5))
}
```

```output
-1
[1, -0.333, 1]
2
4
1
```

## 動くシーン

このウィンドウでは、呼吸する円、歩く足、動く目標を追いかけるバネを組み合わせています。バネの位置と速度はフレームからフレームへ引き継がれます。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(640, 360, "Anima")
    束縛 時刻 = 0.0
    束縛 位置 = 0.0
    束縛 速度 = 0.0
    間 開いている() {
        塗り潰し(10, 12, 28)
        # 有機的：呼吸する円
        色設定(120, 220, 255)
        塗りつぶし円(120, 120, 40 * 呼吸(時刻, 0.4, 0.12))
        # 有機的：歩く足
        束縛 振り = 歩振り(時刻, 1.0, 30)
        束縛 持ち上げ = 足上げ(時刻, 1.0, 20)
        色設定(255, 210, 90)
        線描く(120, 200, 120 + 振り, 260 - 持ち上げ)
        塗りつぶし円(120 + 振り, 260 - 持ち上げ, 10)
        # 有機的：目標を追いかけるバネ
        束縛 目標 = 400 + 80 * サイン(時刻 * 1.3)
        束縛 結果 = バネ寄せ(位置, 速度, 目標, 120, 10, 0.016)
        束縛 位置 = 結果[0]
        束縛 速度 = 結果[1]
        色設定(120, 255, 160)
        塗りつぶし円(位置, 180, 12)
        表示()
        束縛 時刻 = 時刻 + 0.016
    }
}
```

## スケルタルアニメーション（glTF）

`.glb` や `.gltf` で書き出されたリグ付きキャラクターは、スケルトン、スキンウェイト、アニメーションクリップを持っています。これらの組み込み関数は、そうしたモデルを読み込んでスキニングして描画します。ローカライズ名はありませんが、テクスチャ付きの 2 つの描画だけは例外です。`gltf_anim_draw_tex` は `骨骼动画纹理绘制`（zh）、`スキンアニメ描画`（ja）、`글꼴애니텍스처`（ko）、`วาดแอนิเมชันมีพื้นผิว`（th）でも呼べ、`gltf_pose_draw_tex` は `骨骼姿势纹理绘制`、`スキンポーズ描画`、`글꼴포즈텍스처`、`วาดสกินมีพื้นผิว` でも呼べます。

| 組み込み関数 | 用途 |
|---|---|
| `gltf_load(path)` | モデルを読み込みます。ハンドルを返し、失敗すると `-1` を返します。 |
| `gltf_anim_count(h)` | アニメーションクリップの数。 |
| `gltf_anim_name(h, i)` | クリップ `i` の名前。 |
| `gltf_anim_dur(h, i)` | クリップ `i` の長さ（秒）。 |
| `gltf_joint_count(h)` | スキンのジョイント（ボーン）の数。 |
| `gltf_joint_name(h, j)` | ジョイント `j` の名前。 |
| `gltf_autorig(h)` | スケルトンのないモデルに、手続き的な 20 ボーンの人型リグを付けます。ボーン数を返します。 |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | クリップ `clip` の `time` 秒時点でスキニングし、テクスチャ付きで描画します。 |
| `gltf_pose_draw(h, x, y, z, scale, yaw, pose)` | 自分で用意したポーズでスキニングして描画します（単色）。 |
| `gltf_pose_draw_tex(h, x, y, z, scale, yaw, pose)` | 同じことをテクスチャ付きで行います。 |
| `gltf_bounds(h, clip, time)` | そのクリップと時刻で描画したときのモデルの `[minX, minY, minZ, maxX, maxY, maxZ]`。 |

注意点：

- クリップの時刻は折り返すので、増え続ける時刻を渡せばクリップはループします。
- `pose` はラジアンのオイラー角の平たいリストで、ボーン 1 本につき 3 つ（X、Y、Z）です。
- glTF のモデルは Y 軸が上です。描画時にレンダラーの y 下向きの空間へ反転されるので、`(x, y, z)` はモデルの原点（ふつうは足元）を置く位置になります。
- `gltf_anim_draw_tex` は `time` の後にさらに省略可能な引数を取ります。環境光、裏面カリング（`1` でカリング）、このモデルを動かすクリップを持つ元モデル（ジョイント名で合わせる装備品用）、ボーンごとの追加回転のリスト、`0xRRGGBB` の色合いです。
- `gltf_draw(h, x, y, z, scale, yaw)` はスキニングせずにモデルを描画します。`gltf_mesh_count`、`gltf_mesh_name`、`gltf_mesh_show(h, i, on)`、`gltf_mesh_tint(h, i, 0xRRGGBB)` で個々のメッシュを表示・非表示にしたり色を付けたりできます。装備の付け替えなどに使えます。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(960, 540, "歩行")
    深度テスト(1)
    束縛 ヒーロー = gltf_load("hero.glb")
    束縛 番号 = 0
    間 番号 < gltf_anim_count(ヒーロー) {
        印刷(gltf_anim_name(ヒーロー, 番号) + ": " + str(gltf_anim_dur(ヒーロー, 番号)) + " 秒")
        束縛 番号 = 番号 + 1
    }
    間 開いている() {
        塗り潰し(20, 24, 40)
        gltf_anim_draw_tex(ヒーロー, 0, 2, 6, 1, 0.5, 0, 経過時間())
        flush_3d()
        表示()
    }
}
```

## 組み込み関数ではないもの

`ling-animation` クレートには、キーフレームのトラックとタイムライン、スキニング行列付きのジョイントリグ、手続き的な二足・四足の歩行、四節リンクのソルバー、顔のリグもあります。これらは組み込み先向けの Rust API で、Ling の組み込み関数ではありません。古い文書に出てくる `rig_load` や `anim_play` といった名前は存在せず、`delta_time()` も実装されていません。時刻には `time_now()` を使ってください。
