# ウィンドウとカメラ

グラフィックを使う Ling のプログラムは、どれもウィンドウを開き、フレームループを回し、ひとつの 3D カメラを向けます。
このページではその 3 つを扱います。ウィンドウとフレームループ、フレームの速さと時間の計測、
そして 3D の点を画面に投影するカメラです。描画については次のページを見てください:
[2D 描画と画像](drawing.md)、[3D 形状とメッシュ](shapes.md)。

## フレームループ

グラフィックプログラムの形はいつも同じです。ウィンドウを開き、閉じられるまで
「消去、描画、`present()`」を繰り返します。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(800, 600, "フレームループ")
    束縛 フレーム = 0
    間 開いている() {
        塗り潰し(10, 12, 30)              # 1. 背景色で消去する
        色設定(255, 200, 80)              # 2. 描く
        塗りつぶし円(400 + 200 * サイン(フレーム * 0.05), 300, 40)
        表示()                            # 3. フレームを表示する
        束縛 フレーム = フレーム + 1
    }
}
```

覚えておきたいことが 3 つあります。

1. `window_is_open()` は、ユーザーがウィンドウを閉じたとき**または Escape キーを押したとき**に偽になります。
   Escape を自分で処理する必要はありません。
2. 画面にピクセルを出すのは `present()` だけです。キューに入った 3D ジオメトリの描画、
   ポストプロセス、マウスの読み取りもここで行います。`present()` のないフレームは表示されません。
3. 経過時間（デルタタイム）を返す組み込み関数はありません。現在の `time_now()` から前回の値を引くか、
   `frame_count()` でフレームを数えてください。

存在しない組み込み関数（たとえば Ling にない `draw_rect`）を呼んでも、何も言わずに無視されます。
描画が何もしていないように見えたら、まず綴りを確認してください。

### 座標

| 空間 | 原点 | +x | +y | +z |
|---|---|---|---|---|
| 画面（2D） | 左上のピクセル | 右 | **下** | 使わない |
| ワールド（3D） | カメラの中心点 | 右 | **下** | カメラから遠ざかる方向 |

+y が下向きなので、「上」は負の y です。天井は `y = -3`、床は `y = 3` のようになります。

既定の投影は、視点をウィンドウの中央に置き、焦点距離をウィンドウの高さ（ピクセル）と同じにし、
透視除算の前に奥行きオフセット `zdist = 5` を加えます。

```text
screen_x = width/2  + height * x / (z + zdist)
screen_y = height/2 + height * y / (z + zdist)
```

## ウィンドウとフレーム

### `open_window(w, h, title, resizable)`

プログラムのウィンドウを開き、フレームバッファを確保します。

- **引数:** `w`、`h` はピクセル単位の大きさ（既定は 800 × 600）、`title`（既定は `"Ling"`）、
  `resizable` は省略可能で、`1` にするとウィンドウの大きさを変えられます（既定は 0）。
- **戻り値:** なし。
- **注意:** 数値が先で、タイトルは 3 番目です。ウィンドウを開くとカメラの投影も既定値に戻ります。
  大きさを変えられるウィンドウでは、毎フレーム `get_width()` と `get_height()` を読んでください。
  ウィンドウを作れないときは、`cannot open window` でプログラムが止まります。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(1024, 640, "私のゲーム", 1)
}
```

### `open_fullscreen(title, w, h)` と `open_fullscreen_scaled(title, scale)`

`open_fullscreen` は、メインモニター全体を覆う枠なしウィンドウを開きます。`w` と `h` は
省略可能です（既定はモニターの解像度）。こちらは**タイトルが先**なので注意してください。

`open_fullscreen_scaled` はモニター解像度の何分の一かで描画し、結果を拡大します。
鮮明さと引き換えに速くなります。`scale` は `1`、`2`、`4` のいずれかです（それ以外は 1 として扱います）。
`get_width()` と `get_height()` は縮小後の大きさを返します。

```ling-gui
束縛 start = 実行 {
    open_fullscreen_scaled("レトロ", 2)
}
```

### `window_is_open()`

ウィンドウが開いている間は `true` です。ユーザーが閉じたとき、Escape を押したとき、
コードが `quit()` を呼んだときに `false` になります。ウィンドウを開く前は `false` を返すので、
これを条件にしたループは実行されません。

### `present()`

フレームを終えます。キューに入った 3D 図形をすべて描き、ポストプロセスをかけ、フレームバッファを
ウィンドウにコピーし、マウスを読み取ります。

3D 図形（`cube`、`vtex_*`、`draw_line_3d` など）は奥行きで並べ替えられ、ここで初めてラスタライズされるので、
どの順番で呼んでもかまいません。直接描く 2D の呼び出し（`draw_line`、`triangle`、`draw_disc`、
`tex_*`、`image_draw`）はすぐにフレームバッファに書き込むため、キューの 3D ジオメトリは
それらの**上に**描かれます。3D シーンの上に HUD を描くには、先に `flush_3d()` を呼んでください。
`ui_*` ウィジェットはフレームをまたいでクリックを検出するので、毎フレーム 1 回の `present()` が必要です。

### `flush_3d()` と `flush_post()`

`flush_3d()` は、キューの 3D ジオメトリを表示せずに今すぐフレームバッファに描きます。
その後に描いたものは上に重なります。`flush_post()` は同じことをしたあと、すぐにポストプロセスを
実行するので、その後に描いた HUD はブルームでぼやけません。
[ポストエフェクトとライティング](postfx.md)を見てください。

```ling-gui
束縛 start = 実行 {
    立方体(0, 0, 8, 1, 1, 1, 0, 0, 0, 0)
    flush_3d()                        # 立方体がフレームバッファに入った
    バー(20, 20, 200, 14, 0.5, 1)     # その上に描かれる
    表示()
}
```

### `quit()`

Escape を押したのとまったく同じように、コードからウィンドウを閉じます。`exit_game` と `close_window`
は英語の同義語です。

```ling-gui
束縛 start = 実行 {
    もし ボタン(20, 20, 100, 32) == 1 { quit() }
}
```

### `get_width()` と `get_height()`

現在のフレームバッファの大きさ（ピクセル）です。固定サイズのウィンドウでは `open_window` の
引数と同じです。大きさを変えられるウィンドウでは、ユーザーが変えると値も変わります。
ウィンドウがないときは 0 を返します。

```ling-gui
束縛 start = 実行 {
    束縛 中心x = 幅取得() / 2
    束縛 中心y = 高取得() / 2
}
```

### `set_fps(n)` と `set_vsync(on)`

`set_fps(n)` はフレームレートに上限を設けます（既定は 60、最小は 1）。`open_window` の後に呼んでください。
`set_vsync(on)` は代わりにモニターのリフレッシュレートに合わせてループの速さを調整します。
これはフレームの速さの調整であり、ティアリングを防ぐ垂直同期ではありません。明示的な `set_fps` や
環境変数 `LING_FPS_CAP` があれば、そちらが優先されます。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(800, 600, "上限あり")
    フレームレート設定(30)
}
```

### `monitor_width()`, `monitor_height()`, `monitor_refresh()`, `monitor_info()`

メインモニターの幅と高さ（ピクセル）と、リフレッシュレート（ヘルツ）です。
`monitor_info()` は 3 つを `[width, height, hz]` のリストで返します。ウィンドウを開く前にも
呼べるので、ウィンドウの大きさを決めるのに使えます。

```ling-gui
束縛 start = 実行 {
    束縛 情報 = 画面情報()
    ウィンドウ開く(情報[0] / 2, 情報[1] / 2, "画面の半分")
}
```

### `wait_window()`

ウィンドウが閉じられるか Escape が押されるまで、最後のフレームを表示したまま待ちます。
静止画を 1 枚描くだけのプログラムに便利です。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(400, 300, "静止画")
    塗り潰し(20, 40, 80)
    表示()
    wait_window()
}
```

### `screenshot(tag)`

現在のフレームバッファを PNG で保存し、そのパス
`screenshots/ss_<unix-time>_<tag>_<width>x<height>.png` を返します。`tag` の既定は `"game"` で、
英数字以外の文字は下線に置き換わります。フォルダーはプログラムを実行した場所に作られます。
完全なフレームを撮るには `present()` の後に呼んでください。

```ling-gui
束縛 start = 実行 {
    表示()
    println(screenshot("title-screen"))
}
```

### `record_frame()` と `record_count()`

`record_frame()` は現在のフレームバッファを `recordings/frame_00000.ppm`、`frame_00001.ppm` と
順に書き出し（後で動画にまとめるため）、書いたフレームの番号を返します。`record_count()` は
これまでに書いたフレーム数を返します。

### `frame_count()` と `time_now()`

`frame_count()` はプログラム開始から表示したフレームの数です。`time_now()` はプログラム開始からの
秒数を小数で返します。フレームごとの経過時間を求めるには、前回の値を覚えておきます。

```ling-gui
束縛 start = 実行 {
    束縛 前回 = 経過時間()
    間 開いている() {
        束縛 今 = 経過時間()
        束縛 差分 = 今 - 前回
        束縛 前回 = 今
        塗り潰し(0, 0, 0)
        表示()
    }
}
```

## カメラ

3D の組み込み関数はすべて、ひとつのグローバルなカメラを通してワールドの点を投影します。カメラは次の 3 つで決まります。

* **中心点** `(x, y, z)`。`set_camera_pos` で設定し、すべての点から引かれます。
* **向き**。`set_camera` で、ヨー角とピッチ角のコサインとサインとして設定します。
* **奥行きオフセット** `zdist`。`set_zdist` で設定し、透視除算の前に加えられます。

正のヨーはカメラを右に向けるので、正面にあるものは画面上で左に動きます。
正のピッチはカメラを下に傾けるので、正面のものは上に動きます。ヨー角 `a` のとき、ワールドでの
「前」は x-z 平面の `(sin a, cos a)` です。カメラは毎フレーム、3D ジオメトリを描く前に設定してください。

| 組み込み関数 | 中文 | 日本語 | 한국어 | ไทย | 用途 |
|---|---|---|---|---|---|
| `set_camera(cy, sy, cp, sp)` | `设镜` | `カメラ設定` | `카메라설정` | `ตั้งกล้อง` | ヨーとピッチの cos/sin で向きを決める |
| `set_camera_pos(x, y, z)` | `镜坐标` | `カメラ座標` | `카메라좌표` | `ตั้งตำแหน่งกล้อง` | 中心点を動かす |
| `move_camera(dx, dy, dz)` | — | — | — | — | 中心点をオフセット分動かす |
| `set_zdist(d)` | `镜距` | `Z距離設定` | `Z거리설정` | `ตั้งระยะห่าง` | 奥行きオフセット |
| `set_projection(cx, cy, focal, zdist)` | `投影` | `投影設定` | `투영설정` | `ตั้งโปรเจกชัน` | レンズのパラメータをまとめて設定 |
| `tm_fov(degrees, width)` | — | — | — | — | 視野角から焦点距離を決める |
| `set_camera_roll(angle)` | — | — | — | — | 視線の軸まわりに回す |
| `set_camera_hyper(R, saddle, px, mid_y, pz)` | — | — | — | — | 双曲空間の視点 |
| `project_3d(x, y, z)` | `投影3D` | `3D投影` | `3D투영` | `ฉาย3มิติ` | ワールドの点を画面へ |
| `mouse_ray()` | — | — | — | — | 画面（マウス）からワールドへの光線 |

### `set_camera(cy, sy, cp, sp)`

あらかじめ計算した値で向きを設定します。`cy`、`sy` はヨー角のコサインとサイン、
`cp`、`sp` はピッチ角のコサインとサインです（既定は `1, 0, 1, 0` で、+z の方向をまっすぐ見ます）。
角度ではなく、この 4 つの数を渡してください。

```ling-gui
束縛 start = 実行 {
    束縛 ヨー = 0.3
    束縛 ピッチ = 0.1
    カメラ設定(コサイン(ヨー), サイン(ヨー), コサイン(ピッチ), サイン(ピッチ))
}
```

### `set_camera_pos(x, y, z)` と `move_camera(dx, dy, dz)`

`set_camera_pos` はカメラの中心点をワールドの位置に動かします（既定は 0, 0, 0）。`move_camera` は
そこにオフセットを加えます。y は下向きなので、カメラを上げるには y を減らします。オーディオが
動いているときは、聞き手の位置がカメラの位置に追従します。

```ling-gui
束縛 start = 実行 {
    カメラ座標(0, -2, -6)      # 2 単位上、6 単位後ろ
}
```

### `set_zdist(d)`、`set_projection(cx, cy, focal, zdist)`、`tm_fov(degrees, width)`

`set_zdist(d)` は奥行きオフセットを設定します（既定は 5、ウィンドウを開くと元に戻ります）。値を大きくすると
シーンが遠ざかって遠近感が弱まります。`-zdist` より手前のジオメトリは切り取られます。

`set_projection` はレンズのパラメータをすべて上書きします。`cx`、`cy` はピクセル単位の光学中心、`focal`
はピクセル単位の焦点距離（大きいほどズームイン）、そして `zdist` です。画面分割のような特殊な場合にだけ必要です。

`tm_fov(degrees, width)` は、視野が指定の水平角になるように焦点距離を設定します。`width` はビューポートの
幅（ピクセル、既定はウィンドウの幅）です。`tm_fov(0)` で既定の焦点距離に戻ります。

```ling-gui
束縛 start = 実行 {
    投影設定(幅取得() / 2, 高取得() / 2, 高取得() * 1.5, 5)   # ズームイン
}
```

### `set_camera_roll(angle)` と `set_camera_hyper(R, saddle, px, mid_y, pz)`

`set_camera_roll` は視線の軸まわりに視界をラジアン単位で回します（別名 `camera_roll`）。
`set_camera_hyper` は中心点 `(px, mid_y, pz)` のまわりに双曲空間の視点をオンにします。地面上の距離は
`R * tanh(d / R)` に圧縮され、空間は強さ `saddle` の鞍のように曲がります。`R = 0` でオフになります。

### `project_3d(x, y, z)`

現在のカメラでワールドの点を投影し、`[screen_x, screen_y, depth]` を返します。カメラの後ろにある点は
`[-99999, -99999, depth]` になります。3D の物体に 2D のラベルを付けるのに使います。
ウィンドウがないときは 1920 × 1080 のフレームを仮定するので、次のプログラムはターミナルで動きます。

別名 `3D投影` は数字で始まるため、式の中では数値の `3` として読まれてしまいます。コードでは英語名の
`project_3d` を使ってください。

```ling
束縛 start = 実行 {
    カメラ設定(1, 0, 1, 0)
    println("正面:   " + str(project_3d(0, 0, 5)))
    println("右:     " + str(project_3d(1, 0, 5)))
    カメラ座標(2, 0, 0)
    println("移動後: " + str(project_3d(0, 0, 5)))
    カメラ座標(0, 0, 0)
    println("後ろ:   " + str(project_3d(0, 0, -20)))
}
```

```output
正面:   [960, 540, 5]
右:     [1068, 540, 5]
移動後: [744, 540, 5]
後ろ:   [-99999, -99999, -20]
```

奥行き 10（5 に `zdist` を足した値）で右に 1 単位ずれると、焦点距離 1080 では 108 ピクセル動きます。

### `mouse_ray()`

カメラの中心点からマウスの下のピクセルを通るワールド空間の光線を、
`[ox, oy, oz, dx, dy, dz]` のリスト（原点と方向）で返します。`project_3d` の逆です。
光線に沿って進めば、クリックした地点への移動のためにカーソルの下の地面を求められます。

```ling-gui
束縛 start = 実行 {
    束縛 光線 = mouse_ray()
    束縛 t = (2 - 光線[1]) / 光線[4]          # 光線が y = 2 の床と交わる位置
    束縛 地面x = 光線[0] + 光線[3] * t
    束縛 地面z = 光線[2] + 光線[5] * t
}
```

## 自由に飛べるカメラ

マウスで見回し、WASD で歩き、回る立方体を眺めます。`(sin yaw, cos yaw)` に沿って動くと、歩く方向が
視線と揃います。マウスとキーボードの組み込み関数は[入力とマイク](input.md)に、
ライトは[ポストエフェクトとライティング](postfx.md)にあります。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(900, 600, "飛行")
    マウス捕捉()
    深度テスト(1)
    束縛 ヨー = 0.0
    束縛 ピッチ = 0.0
    束縛 位置x = 0.0
    束縛 位置z = -4.0
    束縛 t = 0.0
    間 開いている() {
        束縛 ヨー = ヨー + mouse_dx() * 0.003
        束縛 ピッチ = 範囲制限(ピッチ + mouse_dy() * 0.003, -1.5, 1.5)
        束縛 前x = サイン(ヨー) * 0.08
        束縛 前z = コサイン(ヨー) * 0.08
        もし キー押す("w") { 束縛 位置x = 位置x + 前x  束縛 位置z = 位置z + 前z }
        もし キー押す("s") { 束縛 位置x = 位置x - 前x  束縛 位置z = 位置z - 前z }
        もし キー押す("d") { 束縛 位置x = 位置x + 前z  束縛 位置z = 位置z - 前x }
        もし キー押す("a") { 束縛 位置x = 位置x - 前z  束縛 位置z = 位置z + 前x }
        カメラ設定(コサイン(ヨー), サイン(ヨー), コサイン(ピッチ), サイン(ピッチ))
        カメラ座標(位置x, 0, 位置z)
        塗り潰し(8, 10, 24)
        ライト消去()
        ライト追加(-3, -6, 0, 1.0, 0.95, 0.85, 1.0, 0)
        格子模様(0, 2, 8, 1, 0, 0, 0, 0, 1, 20, 20, 1, 1, t, 0)
        色設定(240, 150, 110)
        立方体(0, 0, 8, 1, 1, 1, t * 0.5, t, 0, 0)
        表示()
        束縛 t = t + 0.02
    }
}
```
