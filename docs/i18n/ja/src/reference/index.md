# 概要

組み込み関数は Ling に最初から付いている関数です。出力、数学、テキスト、ファイル、ウィンドウ、サウンド、Web サーバーなど、さまざまなものがあります。
このセクションではそれらをテーマごとに並べ、各言語での名前、受け取る値と返す値、そして実行できる短い例を載せています。

## 組み込み関数のしくみ

**いつでも使えます。** 組み込み関数をインポートする必要はありません。プログラムのどこからでも名前で呼び出せます。

```ling
束縛 start = 実行 {
  印刷(平方根(16) + 最大(2, 5))
}
```
```output
9
```

**引数は位置で渡します。** 引数に名前はなく、順番が意味を持ちます。末尾の引数を省略すると、たいていはエラーではなく
文書に書かれた既定値が使われます。たとえば `clamp(1.5)` は 0..1 の範囲に収めます。

**失敗も値です。** ほとんどの組み込み関数は、調べられる値を返して問題を知らせます：`false`、`0`、`-1`、空のリスト、
あるいは `bad(...)` の結果です。どれになるかは各項目に書いてあります。失敗の仕方が複雑な組み込み関数は `ok(value)` か `bad(reason)` を返します。
[エラーと結果](../language/errors.md)を参照してください。

**5 つの言語の名前。** 多くの組み込み関数には、英語のほかに中国語・日本語・韓国語・タイ語の名前があります。どれも同じ関数を呼び出し、
英語の名前はどのファイルでも、ほかのどの言語と並べても、いつでも使えます。

```ling
束縛 start = 実行 {
  print(sqrt(16))
  印(根(16))
  印刷(平方根(16))
  출력(제곱근(16))
  พิมพ์(รากที่สอง(16))
}
```
```output
4
4
4
4
4
```

`lingfu normalize --to <lang>` は、プログラムのキーワードと組み込み関数を 1 つの言語に書き換えます。[5 つの言語で書く](../language/multilingual.md)を参照してください。
ランタイムはほかの言語（フランス語、ドイツ語、ロシア語、アラビア語、ペルシア語、ヘブライ語、ウルドゥー語）の名前も一部知っていますが、
これらのページでは文書化されている 5 つの言語だけを載せています。

## プロファイル

`cargo install ling-lang` は、すべての組み込み関数を含む `full` プロファイルをインストールします。もっと小さな
[プロファイル](../getting-started/install.md)でインストールした場合、いくつかの組み込み関数のファミリーはビルドに含まれません。
そうした関数を呼ぶと、追加すべきプロファイルを示すエラーでプログラムが止まります。

```text
'http_get' needs the `web` profile, which this build of ling leaves out (reinstall with: cargo install ling-lang --features web, or the default full install)
```

| プロファイル | 組み込み関数のファミリー（例） |
|---|---|
| `core` | 出力・テキスト・ファイルの各ページ（プロセスを除く）、ウィンドウ、2D 描画、フォント、画像、メッシュ |
| `web` | `http_*`、`db_*`、`zip_*`、`tar_gz_*`、`video_*`、`run_process`、`proc_*`、ハッシュと暗号 |
| `privacy` | `p2p_*`、`lingtp_*`、`ssh_*`、`lw_*` |
| `game` | `rb_*`、`soft_*`、`liquid_*`、`gltf_*`、`gpu_*`、`body_*`、`pad_*`、`dialog_*`、`ui_*` |
| `ai` | `nn_*`、`bt_*`、`stt_*`、学習型の対話モデル |
| `audio` | `audio_*`、`music_*`、`mic_*`、`fft_*` |

`llm_*`（ローカル言語モデル）や `vision_*` のような重い追加機能は、どのプロファイルにも別途オプトインで加えます。

## ページの読み方

リファレンスの各ページは同じ形をしています。

1. ページ全体に当てはまるルールを説明する導入。
2. **一覧表。** 最初の列は `clamp(x, low, high)` のようなシグネチャです。言語の列にはローカライズされた名前があり、
   `—` はまだローカライズ名がないことを表すので、英語の名前を使ってください。翻訳されたページでは、読んでいる言語の列だけが表示されます。
3. **組み込み関数またはグループごとの節**：引数、戻り値、注意点、例。

`ling` と書かれた例は `ling run` で実行したもので、その下の出力は実際のものです。ウィンドウ、サウンド、ネットワーク、サーバーが必要な例は
構文だけを確認しているので、出力ブロックはありません。`start` ブロックのない断片は、もっと大きなプログラムの一部です。

Ling には 2 つのバックエンドがあります。既定のコンパイル型バックエンドと、インタプリタ（`ling run --interp`）です。
引数として渡した関数がインタプリタでしか動かないなど、両者の動きが違うところは項目に書いてあります。[既知の制限](../language/limits.md)にこうした違いをまとめています。
