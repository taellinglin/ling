# 3D 形状とメッシュ

ここで紹介する組み込み関数は、3D シーンに物を置きます。20 種類ほどのパラメトリックな立体、生の三角形と線、
平面に描く `vtex_*` ベクターパターン、`tex_*` ピクセルテクスチャ、ファイルから読み込むメッシュ
（Ling 独自の形式と glTF）です。どれも開いたウィンドウと、[ウィンドウとカメラ](window.md)のカメラが必要です。
ライト、陰影のスタイル、ポストプロセスは[ポストエフェクトとライティング](postfx.md)にあります。

3D の呼び出しはすぐには描かれません。**深度キュー**に入り、`present()`（または `flush_3d()`）のときに
並べ替えられて描かれます。そのため、フレームの中ではどの順番で呼んでもかまいません。

## 基本の立体

立体はすべて同じ引数をとります。

```text
name(cx, cy, cz,  sx, sy, sz,  rx, ry, rz,  mode,  e0, e1, e2)
```

| 引数 | 意味 |
|---|---|
| `cx, cy, cz` | ワールド座標での中心 |
| `sx, sy, sz` | 軸ごとの拡大率（既定は 1）。形はおよそ半径 1 単位なので、拡大率はほぼ半分の大きさです。`cube(0, 0, 8, 1, 1, 1)` は一辺 2 単位の立方体です |
| `rx, ry, rz` | ラジアン単位の回転（既定は 0）。X、Y、Z の順にかかります |
| `mode` | `0` 塗りつぶし（既定）、`1` ワイヤーフレーム、`2` 両方 |
| `e0, e1, e2` | 形ごとの追加引数（下の表を参照）。0 か省略で既定値になります |

必須なのは位置だけで、後ろの引数は省略できます。ペンの色（`set_color`）が塗りと線の色になります。
立体はシーンのライトで照らされ、トゥーン調で陰影が付きます。

+y は下向きだということを忘れないでください。`cone` は頂点が +y にあるので、回転しないと画面の下を向きます。
上に向けるには x 軸まわりに π 回転します。`gear` と `torus` は x-z 平面に寝ているので、カメラに向けるには
x 軸まわりに 1.57 ほど回転します。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(900, 600, "形状")
    深度テスト(1)
    束縛 n = 0
    間 開いている() {
        塗り潰し(8, 10, 24)
        カメラ設定(1, 0, 1, 0)
        ライト消去()
        ライト追加(-2, -6, -2, 1.0, 0.95, 0.85, 0.6, 0)
        束縛 角 = n * 0.03
        色設定(230, 120, 90)
        立方体(-2.8, 0, 7.5, 0.8, 0.8, 0.8, 角, 角 * 0.7, 0, 0)
        色設定(120, 200, 255)
        球(0, 0, 7.5, 0.9, 0.9, 0.9, 0, 0, 0, 0)
        色設定(190, 190, 200)
        歯車(2.8, 0, 7.5, 0.9, 0.3, 0.9, 1.57, 角 * 2, 0, 0, 14, 0.3)
        表示()
        束縛 n = n + 1
    }
}
```

### 立体ごとの注意

- **`cylinder`** はローカルの y に沿って -1 から 1 まで伸びるので、高さは `2 * sy` です。0.05 のような
  小さな `sy` にすると円盤や板になります。
- **`torus`**: `tube` は外側の半径に対する管の半径の比率です（0.02 から 0.9）。
- **`frustum`**: 上面の比率は、底面の半径に対する上面の半径です。0 に近いと円錐、1 で円柱になります。
  比率を小さくして `sy` を高くするとオベリスクになります。
- **`gear`**: 厚みは `sy` で決まります。歯の数は 3 から 96、歯の深さは 0.02 から 0.6 です。
- **`stairs`**: 段ごとに +y と +z に 1 段ずつずれます。+y が下向きなので、奥へ行くほど下っていくように見えます。
  反転するには `rz` で π 回転します。
- **`gyro`** はジンバルのリングを軸を交互に変えて入れ子にします。**`capsule_chain`** は玉を x に沿って並べます。
- サイコロ型（`tetrahedron` から `icosahedron`）は、`mode` を 2 にして明るい色にすると宝石のように見えます。

```ling-gui
束縛 start = 実行 {
    色設定(255, 140, 180)
    二十面体(0, 0, 8, 1, 1, 1, 0.4, 0.7, 0, 2)
    円錐(3, 0, 8, 0.8, 1, 0.8, 3.14159, 0, 0, 0)       # 頂点を上に
}
```

## 三角形、線、深度テスト

| 組み込み関数 | 中文 | 日本語 | 한국어 | ไทย | 用途 |
|---|---|---|---|---|---|
| `draw_triangle_3d(ax, ay, az, bx, by, bz, cx, cy, cz)` | — | — | — | — | 照らされた三角形 1 つ |
| `draw_quad_3d(...)`, `draw_polygon_3d(...)` | — | — | — | — | 照らされた凸多角形 |
| `draw_line_3d(ax, ay, az, bx, by, bz)` | — | — | — | — | 奥行きで並べ替える線 |
| `set_depth_test(on)` | `深度测试` | `深度テスト` | `깊이테스트` | `ทดสอบความลึก` | ピクセルごとの深度バッファ |
| `clear_depth()` | — | — | — | — | フレームの途中で深度バッファを消去する |

### `draw_triangle_3d`、`draw_quad_3d`、`draw_polygon_3d`

ワールド空間のジオメトリをペンの色で描きます。ライト、フォグ、ニアプレーンでの切り取りが適用されます。
`draw_triangle_3d` は 3 点をとり、頂点の順番（巻き方向）でどちらの面がライトを向くかが決まります。
`draw_quad_3d` は `x, y, z` の組を 4 つ（12 個の数）とり、`draw_pent_3d` と `draw_hex_3d` は 5 つと 6 つです。
これらは `draw_polygon_3d` と実装を共有しており、`draw_polygon_3d` は平らなリスト
`[x0, y0, z0, x1, y1, z1, ...]` ひとつも受け付けます。使われる頂点は最大 8 個です。

```ling-gui
束縛 start = 実行 {
    色設定(120, 200, 255)
    draw_quad_3d(-2, 1, 8, 2, 1, 8, 2, 1, 12, -2, 1, 12)     # 床のタイル
    draw_polygon_3d([0, -1, 8, 1, 0, 8, 0, 1, 8, -1, 0, 8])  # ひし形
}
```

### `draw_line_3d(ax, ay, az, bx, by, bz)`

ワールドの 2 点を結ぶ線です。ほかのものと一緒に奥行きで並べ替えられ、ニアプレーンで切り取られます。
なめらかな線にするには `set_antialias(1)` を使います。

### `set_depth_test(on)` と `clear_depth()`

深度テストは既定でオフで、キューのジオメトリは遠いものから順に塗られます。立体どうしが交差しうるときや、
アンビエントオクルージョン、輪郭線、被写界深度を使うときはオン（`1`）にしてください。`fill()` は毎フレーム
深度バッファを消去します。`clear_depth()` はフレームの途中で新しい深度パスを始めるためのものです。

## ベクターパターン: `vtex_*`

`vtex_*` の呼び出しはどれも、**3D 空間の平面**の上に動く線のパターンを描きます。最初の 9 個の引数は共通で、
最後の 2 つは必ず `fr` と `hue` です。

```text
vtex_name(cx, cy, cz,  ux, uy, uz,  vx, vy, vz,  ...パターンの引数...,  fr, hue)
```

`cx, cy, cz` は中心です。`u` はパターンの「右」が向く方向、`v` は「上」が向く方向です。`fr` は自分で渡す
フレームカウンターで、色と動きを進めます。`hue` は色をずらして、隣り合うパターンが違って見えるようにします。
色は自動的に虹色に巡り、ペンの色は使いません。

| 平面 | `u` | `v` |
|---|---|---|
| 床または天井 | `1, 0, 0` | `0, 0, 1` |
| カメラに向いた壁（直立） | `1, 0, 0` | `0, -1, 0` |
| 横の壁（直立） | `0, 0, 1` | `0, -1, 0` |

+y が下向きなので、直立したパターンには `v = (0, -1, 0)` を使います。パターンはただの線分なので軽く、
少しだけカメラ寄りに描かれるため、同じ場所にある面の上に乗って見えます。

| 組み込み関数 | 中文 | 日本語 | 한국어 | ไทย | パターンの引数（既定値） |
|---|---|---|---|---|---|
| `vtex_grid` | `纹格` | `格子模様` | `격자무늬` | `ลายตาราง` | 列 10、行 10、cell_w 1、cell_h 1 |
| `vtex_rings` | `纹环` | `同心円` | `동심원` | `ลายวงซ้อน` | リング 6、辺 6、max_r 3、ねじれ 0 |
| `vtex_star` | `纹星` | `星模様` | `별무늬` | `ลายดาว` | 頂点 6、r_out 2、r_in 1、毎フレームの回転 0.01 |
| `vtex_spiral` | `纹螺` | `螺旋模様` | `나선무늬` | `ลายเกลียว` | 巻き数 3、max_r 3、ステップ 120 |

`orb_shell(cx, cy, cz, radius, rot_y, rot_x, density, r, g, b)` はパターンの仲間で、球に巻き付いた
らせんが交差する半透明の殻を描きます（`density` は 1 から 48、既定は 10。色の既定は薄い灰色）。
別名: zh `球壳`、ja `オーブ殻`、ko `오브껍질`、th `เปลือกทรงกลม`。

## ピクセルテクスチャ: `tex_*`

`tex_*` の組み込み関数は、画面上の長方形を手続き的なパターンで 1 ピクセルずつ、**すぐに**塗ります。
ほかの 2D の呼び出しと同じく、キューの 3D ジオメトリに覆われます。どれも最初の引数はピクセル単位の
長方形 `x, y, w, h` です（既定は 0, 0, 256, 256）。

呼び出すたびにすべてのピクセルを計算するので、大きなテクスチャは遅くなります。小さく保つか、
一度だけ描いて画面に残してください。

`palette` を受け付けるものでは、`"rainbow"`、`"fire"`、`"ocean"`、`"psychedelic"`、`"neon"`、`"forest"` の
いずれかを指定します。知らない名前は rainbow になります。

| 組み込み関数 | 用途 |
|---|---|
| `tex_checkerboard(x, y, w, h, tiles, r1, g1, b1, r2, g2, b2)` | 2 色の市松模様（8 枚、白と黒） |
| `tex_gradient(x, y, w, h, angle_deg, r1, g1, b1, r2, g2, b2)` | 角度に沿った線形グラデーション（0 で左から右） |
| `tex_noise(x, y, w, h, scale, octaves, seed, palette)` | フラクタルノイズ（scale 4、octaves 1 から 8） |
| `tex_spiral(x, y, w, h, freq, bands, time, palette)` | `time` で回るらせんの帯 |
| `tex_ripple(x, y, w, h, freq, cx, cy, time, palette)` | `cx, cy`（長方形内で 0 から 1）から広がる波紋 |
| `tex_mandelbrot(x, y, w, h, zoom, cx, cy, max_iter, palette)` | マンデルブロ集合 |
| `tex_julia(x, y, w, h, c_re, c_im, max_iter, palette)` | ジュリア集合（c = -0.7 + 0.27i） |
| `tex_voronoi(x, y, w, h, cells, seed, palette)` | ボロノイのセル（16 個） |
| `tex_halftone(x, y, w, h, dot_size, time, palette)` | ハーフトーンの網点 |
| `tex_freq_map(x, y, w, h, time, speed, palette)` | 最後の `fft_bands` 呼び出しからのスペクトル（[オーディオ](audio.md)を参照） |

`tex_mandelbrot` は複素平面の `1 / zoom` 単位を縦横どちらにも表示するので、`zoom` が 1 だと主なカージオイドしか
見えません。集合全体を見るには 0.4 くらいにします。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(660, 340, "tex")
    塗り潰し(0, 0, 0)
    tex_checkerboard(10, 10, 200, 150, 8, 240, 240, 240, 30, 30, 60)
    tex_noise(230, 10, 200, 150, 5, 4, 7, "fire")
    tex_mandelbrot(450, 10, 200, 150, 0.4, -0.5, 0, 64, "psychedelic")
    表示()
    wait_window()
}
```

## メッシュ

Ling は、リストで組み立てたメッシュ、独自のバイナリメッシュ形式、glTF モデルを描けます。どれもカメラを
通して投影され、ほかの 3D シーンと一緒にキューに入ります。

### `draw_mesh(positions, indices, ox, oy, oz, scale, mode)`

2 つのリストに入った三角形メッシュを描きます。`positions` は平らな `[x0, y0, z0, x1, y1, z1, ...]`、
`indices` は三角形ごとに 3 つの頂点番号を並べたものです。各頂点は `scale`（既定は 1）倍され、
`ox, oy, oz` だけ移動します。`mode` が `0` ならペンの色で照らし、`1` なら三角形ごとに虹色を付けます。
不正な番号は無視されます。

```ling-gui
束縛 start = 実行 {
    束縛 頂点 = [0, -1, 8, 1, 1, 8, -1, 1, 8, 0, 0, 10]
    束縛 番号 = [0, 1, 2, 0, 2, 3, 0, 3, 1]
    色設定(200, 160, 255)
    draw_mesh(頂点, 番号, 0, 0, 0, 1, 0)
}
```

### `mesh_load(path)` と `mesh_draw(id, x, y, z, scale, yaw)`

`mesh_load` は `.lmesh` ファイル（三角形ごとに単色を持つコンパクトな形式）を読み込み、ハンドルか `-1` を返します。
`mesh_draw` はそれを、位置、均一な拡大率、ヨー角を指定して、自身の色のまま**ライトなしで**描きます。
さらに省略可能な引数（`sway`、`arm`、`lean`、`leg`、`tuck`、既定は 0）でキャラクターのメッシュを変形できます。
`sway` は上半身を傾け、`arm` は腕を振ります。`mesh_free(id)` はジオメトリを解放します。
`mesh_load` の別名: zh `载入网格`、ja `メッシュ読込`、ko `메시로드`、th `โหลดเมช`。

### glTF モデル: `gltf_*`

`gltf_load(path)` は `.glb` または `.gltf` ファイルを、スケルトン、スキン、アニメーションも含めて読み込み、
ハンドルか `-1` を返します。glTF は Y が上ですが、描画の呼び出しが Ling の Y が下のワールドに変換してくれます。

| 組み込み関数 | 用途 |
|---|---|
| `gltf_load(path)` | モデルを読み込む。ハンドルまたは `-1` |
| `gltf_draw(h, x, y, z, scale, yaw)` | 基本姿勢のまま、ライトを当てて描く |
| `gltf_anim_draw_tex(h, x, y, z, scale, yaw, clip, time)` | アニメーションクリップの `time` 秒の姿勢で、テクスチャ付きで描く |
| `gltf_anim_count(h)`, `gltf_anim_name(h, i)`, `gltf_anim_dur(h, i)` | アニメーションクリップの数、名前、長さ（秒） |
| `gltf_bounds(h, clip, time)` | 描いたときの `[minx, miny, minz, maxx, maxy, maxz]`（glTF 空間） |
| `gltf_tris(h)` | 三角形の数 |
| `gltf_mesh_count(h)`, `gltf_mesh_name(h, i)` | モデルのメッシュ |
| `gltf_mesh_show(h, i, on)` | 以降の描画でメッシュ 1 つを表示・非表示にする（装備、衣装） |
| `gltf_mesh_tint(h, i, color)` | メッシュ 1 つにまとめた色を掛ける |
| `gltf_joint_count(h)`, `gltf_joint_name(h, j)` | スケルトンのボーン |

`gltf_bounds` では y が上向きなので、地面の高さ `gy` に拡大率 `s` で描いたモデルの頂上は `gy - maxy * s` にあります。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(800, 600, "モデル")
    深度テスト(1)
    束縛 狐 = gltf_load("models/fox.glb")
    束縛 クリップ = 0
    間 開いている() {
        塗り潰し(20, 24, 40)
        ライト消去()
        ライト追加(-3, -6, 2, 1.0, 1.0, 1.0, 1.0, 0)
        もし 狐 >= 0 {
            束縛 長さ = gltf_anim_dur(狐, クリップ)
            gltf_anim_draw_tex(狐, 0, 2, 8, 0.02, 経過時間(), クリップ, 経過時間() % 最大(長さ, 0.01))
        }
        表示()
    }
}
```

## テクスチャ付きメッシュ: `tm_*`

`tm_*` の仲間は、3D ゲーム向けにテクスチャ付きのジオメトリを描きます。テクスチャとメッシュはそれぞれハンドルを持ちます。

| 組み込み関数 | 用途 |
|---|---|
| `tm_tex_load(path, size)` | PNG、SVG、SVGZ を `size` ピクセル（既定は 256）の正方形テクスチャとして読み込む。id または `-1` |
| `tm_load(path)` | `.ltm` メッシュ（名前付きのテクスチャ付き三角形グループ）を読み込む。id または `-1` |
| `tm_groups(m)`, `tm_group(m, name)`, `tm_group_name(m, g)`, `tm_group_tris(m, g)` | メッシュのグループを調べる |
| `tm_bounds(m, g)` | グループ 1 つ（`g = -1` なら全体）の `[minx, miny, minz, maxx, maxy, maxz]` |
| `tm_edges(m, g, max)` | 輪郭の辺を線分の平らなリストで返す（ミニマップやワイヤーフレーム用） |
| `tm_draw(m, g, tex, x, y, z, scale, rot, tint, alpha, ...)` | グループをテクスチャ付き三角形としてキューに入れる |
| `tm_sprite(tex, cx, cy, w, h, rot, tint, alpha, blend)` | 回転したテクスチャ付き長方形を画面に直接描く |
| `tm_billboard(tex, x, y, z, size, rot, tint, alpha, blend)` | 3D 空間でカメラを向くテクスチャ付きの正方形 |
| `tm_quad(tex, x, y, z, ux, uy, uz, vx, vy, vz, tint, alpha, blend)` | 任意の向きのテクスチャ付き四角形（デカール） |
| `tm_wire(kind, x, y, z, size, rx, ry, rz, color, detail, thick)` | ワイヤーフレームの形 |
| `tm_solid(kind, x, y, z, size, rx, ry, rz, color, alpha, blend)` | 面ごとにフラットな陰影の付いた結晶のような立体 |

共通の決まり: `tint` と `color` はまとめた `0xRRGGBB` の数（既定は白）、`alpha` は 0 から 1、
`blend` は `0` で通常、`1` で加算です。テクスチャ id `-1` は組み込みの柔らかい光の点を意味し、
`tm_quad` では `-2` が柔らかい丸い影になります。

- **`tm_draw`** はさらに `uoff, voff, uscale, vscale`（テクスチャのスクロールと拡大）、`shade`
  （0 から 1、ライトから背いた面を暗くする）、`blend`、`cull`（`0` なし、`1` か `2` で片方の巻き方向）と続きます。
  `rot` はヨー角か、行優先の 3 × 3 のリストです。キューに入れた三角形の数を返します。
- **`tm_sprite`** は 2D のフレームバッファに描くので、HUD やタイトルカードには `flush_3d()` の後に呼びます。
- **`tm_wire`** の種類: `0` 立方体、`1` 四面体、`2` 八面体、`3` 二十面体、`4` トーラス、
  `5` 球、`6` リング、`7` 星柱、`8` 格子。`size` は半径で、`thick` を 1 にすると線が太くなります。
- **`tm_solid`** の種類: `0` 立方体、`1` 四面体、`2` 八面体、`3` 二十面体、`9` 破片
  （引き伸ばした八面体）。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(800, 600, "結晶")
    束縛 t = 0.0
    間 開いている() {
        塗り潰し(6, 8, 20)
        ブレンドモード(1)
        tm_wire(3, -2, 0, 8, 1, t, t * 0.7, 0, 65535, 12, 1)
        ブレンドモード(0)
        tm_solid(9, 2, 0, 8, 0.8, 0, t, 0, 16744576, 0.8, 1)
        表示()
        束縛 t = t + 0.02
    }
}
```
