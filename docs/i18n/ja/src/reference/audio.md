# オーディオ

オーディオエンジンは、ゲームに必要な音をひととおり鳴らせます。3D 空間に置いた連続音、短いビープ音や効果音、サンプルファイル、ループする BGM、マスターエフェクトチェーンです。これとは別に FFT アナライザーがあり、サンプルデータを周波数帯に変えて、音に反応する映像に使えます。

曲全体、楽器パッチ、MIDI、DAW については[音楽](music.md)を、マイクについては[入力とマイク](input.md)を見てください。

最初に知っておくこと：

- ランタイムはプログラムの開始時にオーディオデバイスを開きます。出力デバイスがない場合、`audio_*` 組み込み関数は何もせず、エラーにもなりません。
- 時間の単位は秒です。シグネチャ中の引数は、既定値が書かれている位置から後ろが省略可能です。
- オーディオはネイティブ版だけです。ブラウザ版では FFT の組み込み関数は何もせず、一部の呼び出しは引数が少なくなります（下で注記します）。
- 以下の例は音が出るので `ling-gui` のプログラムです。最後の FFT の例はどこでも動きます。

## エンジンのミックスのしかた

1 本の出力ストリームに 4 種類の音が乗ります。

- **トーン**：番号付きスロットにある長寿命のオシレーターで、空間に配置されます（`audio_tone`）。
- **ワンショット**：ビープ音（`audio_blip`、`ui_sound`）、位置を持つ効果音（`audio_sfx`）、モーフ音（`morph_note`）。
- **サンプル**：デコードしたファイルを 3D で、または定位なしで再生します（`audio_sample_*`）。
- **BGM**：ループする WAV が 1 つ（`audio_bgm`）。

リスナーはカメラです。パンはカメラから見た音の位置に応じた等パワーの左右定位で、音量は距離とともに減衰します。`set_camera_pos` でリスナーが動き、`audio_listener` で向きが変わります。最終ミックスはソフトクリップされるので、大きな音は硬く割れずに穏やかにひずみます。

トーンのスロットは必要に応じて増えます。ビープ音は 32、効果音は 64、モーフ音は 32、サンプルは 64 ボイスまでで、いっぱいになると最も古いボイスが消されます。

## 音量と BGM

### `audio_volume(level)`

このエンジンがミックスするすべての音のマスターゲインです（既定値 0.7、1.0 で等倍）。独自の `music_volume` を持つ音楽エンジンには影響しません。

### `audio_bgm(path, volume)` と `audio_bgm_volume(level)`

`audio_bgm` は **WAV** ファイルを読み込み、BGM としてループ再生します（既定の音量 0.5）。2 回目の呼び出しで曲が置き換わります。ファイルを読めなかったときは標準エラーにエラーが出て、プログラムは無音のまま続きます。パスは書いたとおりに使われます。MP3、OGG、FLAC、AAC には `audio_sample_load` か `music_load` を使ってください。

`audio_bgm_volume` は読み込み直さずに音量を変えます。

```ling-gui
束縛 開始 = 実行 {
    音量(0.6)
    BGM("theme.wav", 0.4)
    BGM音量(0.15)
}
```

## トーン

### `audio_tone(slot, x, y, z, w, freq, amp, lfo_rate, lfo_depth, wave, duty)`

連続するオシレーターを作るか、音程を変えます。同じスロットを使うとそのトーンがその場で更新され、周波数と振幅は新しい値へ滑らかに移るので、毎フレーム呼んでもかまいません。

| 引数 | 既定値 | 意味 |
|---|---|---|
| `slot` | 0 | トーンのスロット番号。 |
| `x, y, z` | 0 | 音源のワールド座標。 |
| `w` | 1 | 4 次元目の値。トーンを相互変調するゆっくりした副オシレーターを動かします。0 で無効。 |
| `freq` | 220 | 周波数（Hz）。 |
| `amp` | 0.15 | 振幅。0 でスロットを無音にします（削除はありません）。 |
| `lfo_rate` | 0.5 | ビブラートの速さ（Hz）。 |
| `lfo_depth` | 0.02 | `freq` に対する割合で表したビブラートの深さ。 |
| `wave` | `"sine"` | `"sine"`、`"square"`、`"saw"`、`"triangle"`、`"noise"`（`freq` の音程で刻むノイズ）。 |
| `duty` | 0.5 | 矩形波のパルス幅。チップチューンなら 0.125、0.25、0.5、0.75 など。 |

### `audio_glide(amp_ms, freq_ms)`

トーンの振幅と周波数が新しい値に移るまでの時間をミリ秒で設定します（0 以下なら既定のまま）。毎フレーム 1 回トーンを更新するチップチューンのプレイヤーは、10 ms くらいにすると滑らかに聞こえます。

### `audio_listener(cos_yaw, sin_yaw, cos_pitch, sin_pitch)`

リスナーの向きを変えます。`set_camera` に渡すのと同じ 4 つの数を渡します（既定値 1, 0, 1, 0）。カメラが回るときは毎フレーム呼んでください。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(640, 360, "トーン")
    音調(0, 0, 0, 6, 0, 261.63, 0.10, 0.5, 0.01)
    音調(1, 0, 0, 6, 0, 440.0, 0.06, 0, 0, "square", 0.25)
    束縛 向き = 0.0
    間 開いている() {
        束縛 向き = 向き + 0.01
        カメラ設定(コサイン(向き), サイン(向き), 1, 0)
        音声リスナー(コサイン(向き), サイン(向き), 1, 0)
        塗り潰し(10, 12, 28)
        表示()
    }
}
```

## ワンショットの音

### `audio_blip(freq, duration, wave, amp)`

アタックと減衰の速い、定位なしの短いビープ音です。既定値は `freq` 660 Hz、`duration` 0.08 秒（最小 0.01）、`wave` `"sine"`、`amp` 0.25 です。波形名：`"sine"`、`"square"`（`"sq"`）、`"saw"`（`"sawtooth"`）、`"tri"`（`"triangle"`）、`"noise"`。知らない名前はサイン波になります。

### `ui_sound(name)`

組み込みの UI 音の 1 つです。`"click"`（既定）、`"hover"`、`"confirm"`、`"error"`、`"toggle"`、`"tick"`。それ以外の名前は `"click"` を鳴らします。

### `audio_sfx(x, y, z, w, freq, amp, duration, wave)`

ワールド座標で鳴る合成のワンショットで、トーンと同じくパンと減衰がかかります。既定値は位置 0、`w` 1、`freq` 440、`amp` 0.3、`duration` 0.15、`wave` `"sine"` です。

### `morph_note(x, y, z, w, freq, amp, duration, material, morph)`

物理モデルとデジタルモデルを混ぜる「陰陽」の音です。`material` は 0 擦弦、1 撥弦、2 管、3 打たれた金属です。`morph` は 0（明るくアコースティック）から 1（暗くデジタル：FM、ビットクラッシュ、ドライブ）までです。既定値は `freq` 220、`amp` 0.3、`duration` 0.6 です。

### `audio_stop_sfx()`

ワンショットの効果音、モーフ音、サンプルのボイスをすべて一度に止めるので、シーンが変わっても余韻が漏れません。トーン、BGM、音楽エンジンは鳴り続けます。

```ling-gui
束縛 開始 = 実行 {
    UI音("confirm")
    ビープ音(880, 0.06, "square", 0.2)
    空間効果音(1.5, 0, 4, 1, 330, 0.3, 0.2, "triangle")
    morph_note(0, 0, 5, 1, 220, 0.3, 1.2, 1, 0.4)
}
```

## サンプル

### `audio_sample_load(path)`

WAV、FLAC、OGG、MP3、AAC のファイルをメモリにデコードし、モノラルにまとめます。書いたパスにファイルがなければ、スクリプトのフォルダーからの相対パスとして探します。サンプル ID（0 から）を返し、失敗したときやオーディオデバイスがないときは `-1` を返します。

### `audio_sample_play(id, x, y, z, w, volume, loop, pitch)`

読み込んだサンプルをワールド座標で再生し、リスナーに対するパンと減衰をかけます。`volume` の既定値は 1、`loop` が 0.5 を超えるとループ、`pitch` は再生速度の倍率です（2 で 1 オクターブ上、0.5 で 1 オクターブ下）。サンプルでは `w` は聞こえる効果を持ちません。ボイス ID を返し、失敗すると 0 を返します。ブラウザ版ではシグネチャが `(id, x, y, z, w, volume, loop)` で、pitch はありません。

### `audio_sample_play_flat(id, volume, loop, pitch)`

パンも距離減衰もなしでサンプルを再生します。ナレーション、ボイスオーバー、UI の合図に使います。ボイス ID か 0 を返します。

### `audio_sample_stop(voice)` と `audio_sample_duration(id)`

`audio_sample_stop` は再生の呼び出しが返したボイスを止めます。`audio_sample_duration` はサンプルの長さを秒で返します（知らない ID なら 0）。実際に読み込んだクリップの長さにカットシーンを合わせるときに便利です。

```ling-gui
束縛 開始 = 実行 {
    束縛 足音 = サンプル読込("step.ogg")
    束縛 うなり = サンプル読込("hum.wav")
    サンプル再生(足音, 1.0, 0.0, 3.0, 1.0, 0.8, 0, 1.2)
    束縛 ボイス = audio_sample_play_flat(うなり, 0.5, 1, 1.0)
    印刷(audio_sample_duration(うなり))
    サンプル停止(ボイス)
}
```

## マスターエフェクト

マスターチェーンはディレイ、リバーブ、ローパスフィルターの順です。3 つとも最初はオフか全開です。

| 組み込み関数 | 引数 |
|---|---|
| `audio_fx_delay(time, feedback, mix)` | エコーの時間（秒、既定値 0.3）、フィードバック 0〜0.95（既定値 0.3）、ウェットのミックス 0〜1（既定値 0.3、0 でオフ）。 |
| `audio_fx_reverb(mix)` | リバーブのウェットのミックス、0〜1（既定値 0.3）。 |
| `audio_fx_lowpass(cutoff)` | 0〜1。1 で全開、小さくするとミックスがこもり、水中のような感じになります。フィルターは新しい値へ滑らかに移ります。 |

```ling-gui
束縛 開始 = 実行 {
    ディレイ効果(0.35, 0.4, 0.25)
    リバーブ(0.4)
    ローパス(0.15)
}
```

## FFT 解析

FFT アナライザーは、あなたが渡したサンプルを解析します。`fft_push` でモノラルのサンプル（-1 から 1 の数値、44.1 kHz）のまとまりを渡し、結果を読み出します。

| 組み込み関数 | 戻り値 |
|---|---|
| `fft_bands(n)` | 対数間隔の振幅の帯 `n` 個のリスト（既定値 32）。低音が先頭です。 |
| `fft_beat()` | 最新のまとまりがビートなら `true`。 |
| `fft_beat_ratio()` | ビートの強さ。1 が検出しきい値で、1 を超えると強いビートです。 |
| `fft_rms()` | 信号の二乗平均平方根（RMS）レベル。 |
| `fft_dominant_freq()` | 最も強い周波数（Hz）。 |

このプログラムは 1000 Hz のサイン波を作って解析します。答えは 1000 に近くなり、ずれはアナライザーの周波数分解能によるものです。

```ling
束縛 開始 = 実行 {
    束縛 サンプル列 = []
    束縛 番号 = 0
    間 番号 < 4096 {
        束縛 サンプル列 = サンプル列.追加(サイン(番号 * 6.2831853 * 1000 / 44100))
        束縛 番号 = 番号 + 1
    }
    FFT入力(サンプル列)
    印刷(四捨五入(主要周波数()))
    印刷(四捨五入(二乗平均() * 1000) / 1000)
    束縛 帯 = 周波数帯(8)
    束縛 最大番号 = 0
    束縛 k = 1
    間 k < 長さ(帯) {
        もし 帯[k] > 帯[最大番号] {
            束縛 最大番号 = k
        }
        束縛 k = k + 1
    }
    印刷("最も大きい帯: " + str(最大番号))
}
```

```output
991
0.707
最も大きい帯: 4
```

再生中の曲に反応させるには[音楽](music.md)のページの `music_fft(track, bands)` を、マイクには[入力とマイク](input.md)の `mic_fft` を使ってください。
