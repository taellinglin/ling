# 出力・数学・論理

この組み込み関数群は、コンソールへの出力、テキストの組み立て、計算、プログラムの一時停止を担当します。
ウィンドウは不要なので、このページの例はすべて普通のターミナルで `ling run` を使って実行できます。

Ling の数値はすべて 64 ビット浮動小数点数です。整数値は小数点なしで表示されます（`3.0` ではなく `3`）。
角度はラジアンです。末尾の数値引数を省略すると、たいていはエラーではなく既定値が使われます。

## 出力

### `print(value, ...)` と `println(value, ...)`

`print` と `println` は同じ組み込み関数です。各引数をテキストに変換し、**区切りなしで**つなげてから
改行します。リストは `[1, 2, 3]`、結果は `Ok(v)` と `Err(e)` のように表示されます。

```ling
束縛 start = 実行 {
  印刷("こんにちは、Ling！")
  印刷(42, " ", 3.5, " ", 真)
  印刷([1, 2, 3])
  印刷("合計", 1 + 2)
  印刷("合計 ", 1 + 2)
}
```
```output
こんにちは、Ling！
42 3.5 true
[1, 2, 3]
合計3
合計 3
```

空白は自分で文字列の中に入れるか、`format` で行を組み立ててください。

### `print_file(text)`

最初の引数を改行**なし**で表示します。名前に反して、ファイルには触れません。
同じ行に表示を続ける唯一の方法です。

```ling
束縛 start = 実行 {
  繰 i の中 1..4 {
    print_file(i)
    print_file(" ")
  }
  印刷("スタート！")
}
```
```output
1 2 3 スタート！
```

### `print_color(color, value, ...)`

太字の明るい ANSI カラーで 1 行表示します。`color` は 0 から 7 で、黒・赤・緑・黄・青・マゼンタ・シアン・白です。
残りの引数は `print` と同じようにつなげます。エスケープコードはそのまま書き出されるので、
出力をファイルにリダイレクトすると制御文字として現れます。

```ling-gui
束縛 start = 実行 {
  print_color(2, "成功：", "すべてのテストに合格")
  print_color(1, "エラー！")
}
```

### `format(template, value, ...)`

各 `{}` を次の引数で置き換えたテキストを返します。`{:.N}` は数値を小数点以下 `N` 桁で整形します。
対応する引数のない `{}` は空になり、余った引数は無視されます。使えるのは `{}` と `{:.N}` だけです
（幅指定、`{0}`、`{name}`、波かっこのエスケープはできません）。

```ling
束縛 start = 実行 {
  印刷(フォーマット("{} + {} = {}", 2, 3, 2 + 3))
  印刷(フォーマット("円周率はおよそ {:.3}", 円周率()))
  印刷(フォーマット("{:.1}%", 45.678))
  印刷(フォーマット("{} と {}", "ひとつだけ"))
}
```
```output
2 + 3 = 5
円周率はおよそ 3.142
45.7%
ひとつだけ と 
```

`format::join(list)` は各要素をテキストとして区切りなしで連結します。要素の間に何かを挟みたいときは
`list_join` を使います（[テキストとリスト](text-lists.md)を参照）。

## 結果

### `ok(value)` と `bad(reason)`

Ling には例外がありません。失敗しうる関数は `ok(value)` か `bad(reason)` を返し、呼び出し側は `match` で取り出します。
表示は `Ok(...)` と `Err(...)` になります。`err` は `bad` の英語の別名です。
詳しくは[エラーと結果](../language/errors.md)を参照してください。

```ling
関数 半分(n) {
  もし n % 2 == 0 { 良し(n / 2) } 他 { 悪い("奇数です") }
}
束縛 start = 実行 {
  印刷(半分(10))
  印刷(半分(7))
  印刷(一致 半分(7) { 良し(v) => v, 悪い(e) => "失敗：" + e })
}
```
```output
Ok(5)
Err(奇数です)
失敗：奇数です
```

### `try(function, arg, ...)`

残りの引数で `function` を呼び出します。成功すれば `ok(result)`、呼び出し中に実行時エラーが起きれば `bad(message)` を返します。

> **インタプリタ専用です。** 既定のバックエンドは、引数として渡された関数やクロージャを `()` にしてしまうため、
> `try` は `Err(try: first argument must be a function)` を返します。`try` を使うプログラムは
> `ling run --interp` で実行してください。引数のないクロージャは、空白を入れて `| | expr` と書きます。

```ling-module
関数 安全に読む(パス) { 試す(| | read_file(パス)) }
```

## 数学

### 丸め

`floor` は切り下げ、`ceil` は切り上げ、`round` は四捨五入（ちょうど半分はゼロから遠い方へ）、`trunc` は小数部分を捨て、
`fract` は小数部分だけを残します。`int` は `trunc` の英語の別名で、テキストを数値に変換するものではありません（それには `to_number` を使います）。

```ling
束縛 start = 実行 {
  印刷(床関数(2.7), " ", 床関数(0 - 2.1))
  印刷(天井関数(2.1), " ", 天井関数(0 - 2.9))
  印刷(四捨五入(2.5), " ", 四捨五入(2.4), " ", 四捨五入(0 - 2.5))
  印刷(整数化(2.9), " ", 整数化(0 - 2.9), " ", int(7.99))
  印刷(fract(2.25))
}
```
```output
2 -3
3 -2
3 2 -3
2 -2 7
0.25
```

### `min`・`max`・`clamp`・`sign`・`abs`

`min` と `max` はちょうど 2 つの数を取ります。リストには `list_min` と `list_max` を使います。`clamp` の既定の範囲は 0..1 で、
`low > high` なら上下を入れ替えます。`sign(0)` は `0` ではなく `1` です。

```ling
束縛 start = 実行 {
  印刷(最小(3, 1), " ", 最大(3, 1))
  印刷(範囲制限(15, 0, 10), " ", 範囲制限(0 - 3, 0, 10))
  印刷(符号関数(0 - 4), " ", 符号関数(0), " ", 絶対値(0 - 7))
}
```
```output
1 3
10 0
-1 1 7
```

### べき乗・根・対数

負の数の `sqrt` は `NaN` です。`log` は**自然**対数（`ln` と同じ）です。底が 10 の対数には `log10` を使います。

```ling
束縛 start = 実行 {
  印刷(平方根(16), " ", べき乗(2, 10), " ", べき乗(9, 0.5))
  印刷(cbrt(27), " ", hypot(3, 4), " ", exp(1))
  印刷(対数(exp(2)), " ", 対数(1), " ", log2(8), " ", log10(1000))
  印刷(平方根(0 - 1))
}
```
```output
4 1024 3
3 5 2.718281828459045
2 0 3 3
NaN
```

### 三角関数と定数

角度はラジアンです。`pi()` と `tau()` は必ずかっこを付けて呼んでください。既定のバックエンドでは、かっこなしの `pi` は `()` になります。

```ling
束縛 start = 実行 {
  印刷(サイン(円周率() / 2), " ", コサイン(円周率()))
  印刷(アークタンジェント2(1, 1) * 4)
  印刷(タウ())
}
```
```output
1 -1
3.141592653589793
6.283185307179586
```

### 補間とノイズ

`lerp(a, b, t)` は `t` を範囲内に制限しません。`smoothstep(low, high, x)` は `low` 未満で 0、`high` を超えると 1、
その間は滑らかな曲線を返します。ノイズ関数は決定的で、同じ引数なら常に同じ値を返すため、地形やテクスチャ作りに便利です。

```ling
束縛 start = 実行 {
  印刷(線形補間(0, 10, 0.25), " ", スムーズステップ(0, 1, 0.5), " ", スムーズステップ(0, 1, 2))
  印刷(バリューノイズ2D(1.5, 2.5, 0) == バリューノイズ2D(1.5, 2.5, 0))
  印刷(フラクタルノイズ(0.3, 0.7, 4, 1) >= 0)
}
```
```output
2.5 0.5 1
true
true
```

### `rand()`

0 以上 1 未満の疑似乱数を返します。シードも整数版もないので、自分で拡大して丸めてください。
セキュリティ用途には向きません。予測できない値が必要なら `random_hex`（[ファイル・時刻・システム](files.md)を参照）を使います。

```ling
束縛 start = 実行 {
  束縛 さいころ = 床関数(乱数() * 6) + 1
  印刷(さいころ >= 1 && さいころ <= 6)
}
```
```output
true
```

## 論理と比較

論理と比較は組み込み関数ではなく演算子です：`==`、`!=`、`<`、`<=`、`>`、`>=`、`&&`、`||`、`!`。
数値・テキスト・真偽値は値で比較されます。注意点が 2 つあります。リストは `==` では決して等しくならないこと（要素ごとに比べてください）、
そして `<` によるテキストの順序比較は当てにならないことです。

```ling
束縛 start = 実行 {
  印刷(1 < 2 && !(3 == 4))
  印刷("あ" == "あ", " ", 2 != 3)
  印刷([1, 2] == [1, 2])
}
```
```output
true
true true
false
```

## 一時停止

### `sleep(ms)`

指定したミリ秒だけプログラムを止めます（`sleep_ms` は英語の別名）。時間を測るには、[ファイル・時刻・システム](files.md)の `time_now` を参照してください。

```ling
束縛 start = 実行 {
  眠る(50)
  印刷("完了")
}
```
```output
完了
```
