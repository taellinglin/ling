# ダイアログ

Ling には 2 つのダイアログ用ツールがあります。**ダイアログボックス**はキャラクターの
セリフを見せるものです。アドベンチャーゲーム風のテキストボックスで、文字が 1 文字ずつ
表示され、ページ送りがあり、人名・地名・アイテムを色分けします。**ダイアログモデル**は
キャラクターが何を言うかを決めるものです。そのキャラクター自身のセリフから 1 秒もかからず
学習できる小さな言語モデルで、NPC それぞれに持たせられます。学習データには
**Ling ダイアログ標準**（`.lingdialog`）というプレーンテキスト形式を使います。

`dialog_draw` を除き、どちらもウィンドウなしで動くので、会話全体をヘッドレスでテスト
できます。

## ダイアログボックス

ボックスの状態は描画とは別にランタイムが持っています。`dialog_show` で開き、`dialog_step`
で時間を進め、`dialog_advance` でプレイヤーに反応し、`dialog_draw` で描きます。
`dialog_active()` が真の間は、ゲームの世界を止めておきましょう。

### マークアップ

| マークアップ | 意味 |
|---|---|
| `{n}...{/}` | 人名（色の役割 1）。 |
| `{p}...{/}` | 地名（役割 2）。 |
| `{i}...{/}` | アイテム（役割 3）。 |
| 改行文字 | ボックス内で改行します。 |
| `\|\|` | 改ページ。 |

タグはちょうど 3 文字、`{`、英字 1 つ、`}` です。`{/}` で普通のテキスト（役割 0）に
戻ります。それ以外は書いたとおりに表示されます。

文字送りが終わったページは 1.4 秒後に自動で次へ進み、最後のページの後でボックスが閉じます。

### `dialog_show(text, cps)`

`text` でボックスを開き、1 秒あたり `cps` 文字（既定値 32、最小 1）の速さで表示します。
すでに開いているボックスは置き換えられます。

### `dialog_step(dt)`

文字送りと自動ページ送りのタイマーを `dt` 秒（既定値 `0.016`）進めます。ボックスが
開いている間は毎フレーム呼んでください。

### `dialog_advance()`

プレイヤーが決定キーを押したときに呼びます。ページの文字送り中なら残りを一度に表示し、
そうでなければ次のページへ進むか、最後のページの後で閉じます。押しっぱなしのキーではなく
キーを押した瞬間（`key_pressed`）で呼ぶと、1 回押しただけで何ページも飛ばずに済みます。

### `dialog_active()`、`dialog_typing()`、`dialog_close()`

`dialog_active()` はボックスが開いている間 `true` です。`dialog_typing()` は今のページの
文字がまだ出ている間 `true` です。`dialog_close()` はボックスをすぐに閉じます。

```ling
束縛 開始 = 実行 {
  会話表示("こんにちは、{n}リン{/}。||2 ページ目。", 100)
  印刷("開いている: " + str(会話中()))
  印刷("入力中: " + str(会話タイプ中()))
  会話更新(0.5)
  印刷("0.5 秒後の入力中: " + str(会話タイプ中()))
  会話送り()
  印刷("2 ページ目の入力中: " + str(会話タイプ中()))
  会話送り()
  会話送り()
  印刷("最後に開いている: " + str(会話中()))
}
```

```output
開いている: true
入力中: true
0.5 秒後の入力中: false
2 ページ目の入力中: true
最後に開いている: false
```

1 秒 100 文字なら、最初のページは 0.5 秒で表示し終わります。1 回目の `会話送り` で
2 ページ目へ進み、2 回目で 2 ページ目を全部表示し、3 回目でボックスが閉じます。

### `dialog_color(role, r, g, b)`

役割の色を設定します。`0` 普通のテキスト、`1` 人名、`2` 地名、`3` アイテムです（3 より
大きい値は 3 として扱います）。`r`、`g`、`b` は 0〜255（既定値 255）です。

### `dialog_draw(x, y, w, h, font)`

左上を `(x, y)`（既定値 40, 0）、大きさを `w` × `h`（既定値 720 × 150）として、面取りした
ボックスとここまで表示されたテキストを描きます。`font` は `font_load` のハンドルで、
省略するか `-1` を渡すと組み込みの文字描画を使います。

```ling-gui
束縛 開始 = 実行 {
  ウィンドウ開く(800, 600)
  束縛 UI字体 = フォント読込("assets/fonts/NotoSansJP.ttf", 600.0)
  束縛 セリフ = "やあ、{n}リンク{/}！ {i}マスターソード{/}を{p}ハイラル平原{/}へ持っていけ。||夜には気をつけろ。"
  会話色(1, 255, 210, 80)
  間 開いている() {
    もし キー押した("space") {
      もし 会話中() { 会話送り() } でなければ { 会話表示(セリフ, 34.0) }
    }
    塗り潰し(10, 10, 20)
    もし 会話中() {
      会話更新(0.016)
      会話描画(50.0, 420.0, 700.0, 150.0, UI字体)
    } でなければ {
      // ここでふだんのゲーム更新をします
    }
    表示()
  }
}
```

## ダイアログモデル

ダイアログモデルは Ling に組み込まれた、数 KB ほどの小さな「次の単語を予測する」言語モデル
（`ling_ai::dialog_lm`）です。キャラクターのセリフを与えて学習させ、プロンプトの続きを
言わせます。覚えるのは事実ではなく口調と語彙なので、周囲のおしゃべり、かけ声、雰囲気づくりの
テキストに向いています。小さなコーパスなら学習は 1 秒もかかりません。温度を `0` にすると
出力は決定的になります。

```ling
束縛 開始 = 実行 {
  束縛 店主 = 対話モデル作成(3, 32, 64, 1)
  対話学習(店主, "ようこそ 旅の 方")
  対話学習(店主, "剣 を 研いで おけ")
  対話学習(店主, "ようこそ お帰り 旅の 方")
  束縛 損失 = 対話訓練(店主, 60, 0.1)
  印刷(損失 < 2.0)
  印刷(対話生成(店主, "ようこそ", 6, 0.0))
}
```

```output
true
お帰り 旅の 方
```

### `dialog_new(ctx, embed, hidden, seed)`

空のモデルを作ってハンドルを返します。`ctx`（既定値 3）は直前の何単語を見るか、`embed`
（既定値 32）と `hidden`（既定値 64）はネットワークの大きさ、`seed`（既定値 1）は学習を
再現できるようにするための値です。

### `dialog_learn(m, text)` と `dialog_load(m, path)`

`dialog_learn` はコーパスに 1 行加えます。`dialog_load` は `.lingdialog` ファイル全体を加え、
加えた学習行の数（会話 1 つにつき 1 行）を返します。ファイルを読めなければ `-1` です。

### `dialog_train(m, epochs, lr)`

学習率 `lr`（既定値 0.1）で、コーパス全体を `epochs` 回（既定値 20）学習します。最終的な
損失を返します。低いほどモデルがセリフによく合っています。

### `dialog_say(m, prompt, max, temp)`

`prompt` の続きを最大 `max` 単語（既定値 24）生成し、新しい単語だけを返します。発言の
区切りに来ると早めに止まります。`temp`（既定値 0.8）は温度で、`0` なら常にいちばん
ありそうな単語を選び、高いほどばらつきます。

トークナイザーはテキストを空白と句読点で区切り、小文字にします。日本語は単語の間に
空白を入れない言語なので、コーパスとプロンプトでは単語（文節）の間に空白を入れてください。
返答も単語の間に空白が入った形で返ってきます。

### `dialog_save(m, path)` と `dialog_load_model(path)`

`dialog_save` は学習済みモデルをファイル（既定値 `"model.llm"`）に書き出し、成功すれば
`true` を返します。`dialog_load_model` はそれを読み戻して新しいハンドルを返し、失敗すると
`-1` を返します。ゲームを作る段階で一度学習し、出荷時はこの小さなモデルファイルを同梱して
読み込みましょう。

## Ling ダイアログ標準

`.lingdialog` は行単位で人が書きやすいコーパス形式です。ライターが手で書くことも、
スプレッドシートから生成することもでき、レビューでは差分がきれいに出て、普通のテキスト
ファイルと同じようにローカライズできます。

```text
# Ling Dialog Standard v1
@meta title: 酒場の主人
@meta speaker: ブラム

= 歓迎
ブラム: ようこそ 旅の 方
勇者: 道中 何か 知らせ は
ブラム: 北の 峠 に 山賊 が 出る
      わしの シチュー で 治らん もの は ない

= 噂
ブラム: 剣 を 研いで おけ
```

| 行 | 意味 |
|---|---|
| `# ...` | 行末までのコメント。 |
| `@meta key: value` | データセットのメタデータ。何度でも書けます。 |
| `= label` | 新しい会話を始めます。ラベルは省略できます。 |
| `speaker: text` | 1 回の発言。話し手は**最初の**コロンより前の部分です。 |
| `:` のない行 | 前の発言の続き（空白でつなぎます）。 |
| 空行 | 無視されます。 |

コロンは半角の `:` を使ってください。解析は決して失敗しません。形式のおかしな行は飛ばされる
ので、余計な 1 文字で学習が止まることはありません。最初の `=` より前の発言は、暗黙の会話に
まとめられます。

会話は 1 つずつ学習用の 1 行になり、発言の間は予約トークン `<eos>` でつながれます。そのため
モデルは発言を**またいで**続きを言うことを学びます。自分で `<eos>` と書いても発言の区切りに
なります。予約トークンは `<pad>`、`<bos>`、`<eos>`、`<unk>` です。

```ling
束縛 開始 = 実行 {
  write_file("bram.lingdialog", "# Ling Dialog Standard v1\n@meta speaker: ブラム\n\n= 歓迎\nブラム: ようこそ 旅の 方\n勇者: 道中 何か 知らせ は\nブラム: 北の 峠 に 山賊 が 出る\n\n= 噂\nブラム: 剣 を 研いで おけ\n")
  束縛 店主 = 対話モデル作成(3, 32, 64, 1)
  印刷(対話読込(店主, "bram.lingdialog"))
  対話訓練(店主, 80, 0.1)
  印刷(対話生成(店主, "北の 峠", 8, 0.0))
  印刷(対話モデル保存(店主, "bram.llm"))
  束縛 再び = 対話モデル読込("bram.llm")
  印刷(対話生成(再び, "剣 を", 8, 0.0))
}
```

```output
2
に 山賊 が 出る
true
研いで おけ
```

### よいコーパスを書くには

- **量より一貫性。** 声のはっきりした小さなコーパスのほうが、大きくてありきたりなものより
  印象に残るキャラクターになります。
- **決めゼリフは繰り返す。** キャラクターによく言わせたいセリフは、いくつかの会話に何度か
  入れておきます。
- **声ごとに 1 ファイル。** キャラクターごとにファイルを分ければ、それぞれが自分のモデルと
  個性を持てます。
- **自然に書く。** 大文字小文字や句読点はトークナイザーが処理します。

## 組み合わせる

モデルがセリフを作り、ボックスがそれを見せます。

```ling-gui
束縛 開始 = 実行 {
  ウィンドウ開く(800, 600)
  束縛 ブラム = 対話モデル読込("npc/bram.llm")
  間 開いている() {
    もし キー押した("e") && !会話中() {
      会話表示("{n}ブラム{/}: " + 対話生成(ブラム, "ようこそ", 12, 0.7))
    }
    もし キー押した("space") && 会話中() { 会話送り() }
    塗り潰し(10, 10, 20)
    会話更新(0.016)
    もし 会話中() { 会話描画(50, 420, 700, 150) }
    表示()
  }
}
```
