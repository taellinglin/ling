# ポストエフェクトとライティング

このページでは、Ling が 3D シーンをどう照らし、各フレームをどう仕上げるかを説明します。ライトとシェーディングは、三角形を描くときにその色を決めます。そのあと、完成した画像の上でスクリーン空間の**ポストチェーン**が動きます。アンビエントオクルージョン、インクの輪郭線、トーンランプ、ブルーム、アンチエイリアスです。さらに被写界深度、画面のゆがみ、柔らかなボリュメトリックの光の筋を加えることもできます。

ここにあるものはすべて開いているウィンドウに描画するので、例は `ling-gui` のプログラムです。

インタプリタは表にあるすべての名前を受け付けます。`lingfu normalize` が翻訳するのはその一部（ライトと `set_ambient`）だけなので、このサイトのローカライズ例では残りを英語名のままにしています。

## ライト

ライトは描画と同じく、毎フレームの手順に従います。消して、追加して、描きます。

### `set_ambient(level)`

ライトに関係なくすべての面に届く光で、0 から 1 です（既定値 0.15）。

### `add_light(x, y, z, r, g, b, intensity, radius)`

ワールド座標に色付きの点光源を追加します。色は 0〜1 でも 0〜255 でも指定できます。どれか 1 つのチャンネルが 1.5 を超えると、3 つとも 0〜255 として読みます。`intensity` は明るさの倍率です（既定値 1）。`radius` は光がゼロまで減衰する距離で、0 なら減衰しません（既定）。

引数の順序は、位置、**色**、強さ、半径です。ライトは `clear_lights()` を呼ぶまで足し合わされていくので、毎フレーム消してから追加し直してください。

### `set_fog(r, g, b, start, end)`

距離フォグです。カメラからの深度が `start` から `end` の間で、ジオメトリが指定の色（0〜255）に溶け込みます。`end` が 0 以下ならフォグはオフです。下のボリュメトリックライトもフォグと一緒に薄れます。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(720, 420, "ライト")
    深度テスト(1)
    環境光設定(0.2)
    set_fog(8, 10, 24, 10, 40)
    間 開いている() {
        塗り潰し(8, 10, 24)
        ライト消去()
        ライト追加(0, -5, 4, 1.0, 0.85, 0.6, 1.2, 20)
        色設定(240, 150, 110)
        立方体(0, 0, 8, 1, 1, 1, 0.3, 経過時間(), 0, 0)
        表示()
    }
}
```

## シェーディング

シェーダーは頂点ごとに、ペンの色に次のものを混ぜます。環境光の項（どのライトからも背を向けた面では影の色で色付けされます）、各ライトの寄与、シルエットに向かうリムグロー、そして既定のモードではかすかな虹色の光沢です。結果はいくつかの明るさの段に量子化されます。

既定値はあえて様式化されています。冷たい藍色の影、シアンのリム、ホログラフィックな光沢です。ペンの色どおりの色にしたいときは、`set_shade_mode(1)`、`set_rim(0, 0, 0, 0)`、暗く中立的な `set_shadow_color` を使います。

| 組み込み関数 | 引数 |
|---|---|
| `set_shade_mode(m)` | `0` フラット、三角形ごとに 1 段。`1` 滑らかなセル、光沢なし、リム弱め。`2` ホログラフィック（既定）。 |
| `set_cel_bands(n)` | 段の数、2 以上（既定値 4）。 |
| `set_shadow_color(r, g, b)` | 光の当たらない部分の色、0〜255（既定値 26, 33, 77）。 |
| `set_rim(strength, r, g, b)` | リムの強さ（既定値 0.6、0 でオフ）と色 0〜255（既定値 115, 217, 255）。 |
| `set_flat_shade(on)` | 0 以外でライティングをすべて省き、ペンの色そのままで描きます。性能テスト用です。 |

### `set_material(key, value)` と `reset_material()`

`set_material` は、以降の `draw_triangle_3d` とポリゴン描画に物理ベースのトゥーンマテリアルを有効にします。`key` は文字列、`value` は数値で、色のキーには `0xRRGGBB` 形式の数値を渡します。キー：`albedo`、`roughness`、`metallic`、`emission`、`emission_strength`、`specular`、`specular_tint`、`subsurface`、`subsurface_color`、`clearcoat`、`clearcoat_roughness`、`transmission`、`ior`、`iridescence`、`sheen`、`anisotropy`、`anisotropy_angle`、`toon_bands`、`shadow_softness`、`outline_px`、`outline_color`、`highlight_color`。知らないキーは無視されます。`reset_material()` で通常のライティングに戻ります。基本立体（`cube`、`sphere` など）はマテリアルを読みません。

## ポストチェーン

ポストチェーンは `present()` の中で次の順に動きます。

1. **アンビエントオクルージョン**（`set_ssao`）：深度バッファから求める柔らかな接触影。
2. **輪郭線**（`toon_outlines`）：深度が急に変わる所に引くインクの線。
3. **トーンランプ**（`tone_*`）：明るさをセルの段に対応づけます。
4. **ブルーム**（`set_bloom`）：明るいピクセルからにじむ光。
5. **FXAA**（`set_fxaa`）：最終画像に対するエッジのアンチエイリアス。

アンビエントオクルージョン、輪郭線、ブルーム、FXAA は、有効にするまでオフです。トーンランプは常に動き、最初は既定の 3 段ランプです。オクルージョンと輪郭線は深度バッファを読むので、先に `set_depth_test(1)` を呼んでください。

ベクターの線と文字はトーンランプの対象外なので、UI の文字やワイヤーフレームが段に張り付くことはありません。

### `set_ssao(strength, radius_px, zrange)`

隅やくぼみ、物の下を柔らかく暗くします。半分の解像度で計算してなめらかにします。`strength` は 0〜1（0 でオフ）、`radius_px` はサンプリング半径のピクセル数（既定値 6）、`zrange` は隣のピクセルを遮蔽物とみなす深度の範囲です（既定値 12）。

### `toon_outlines(thickness, color, threshold)`

深度の不連続な所にインクの線を引きます。`thickness` はピクセル単位の半分の太さ（0 でオフ、アニメ調なら 1.5 が目安）、`color` は `0xRRGGBB` 形式の数値（既定値 0、黒）、`threshold` はエッジとみなす深度の差です（既定値 0.05）。

### トーンランプ

トーンランプはストップのリストで、各ストップが入力の明るさ `t` を出力の明るさ `value` に対応づけます（どちらも 0〜1）。既定のランプは 3 段で、0.25 未満は 0.08、0.60 未満は 0.50、それ以上は 1.00 です。

- `tone_stop(t, value)` はストップを追加します。ストップは `t` の順に並べられます。
- `tone_ramp_clear()` はストップをすべて消すので、自分のランプを作れます。`tone_ramp_reset()` は既定に戻します。
- `tone_smooth(on)`：`0` はストップの間で硬く切り替え（既定）、`1` は滑らかに混ぜます。
- `tone_bezier(y1, y2)` は、参照の前に入力の明るさを 3 次ベジェで変換します。`0.333, 0.667` 付近が中立（既定値）、`0, 0` は影寄り、`1, 1` はハイライト寄り、`0.1, 0.9` は S 字カーブです。`tone_bezier_off()` で外します。
- `tone_soft(soft, sheen)`：`soft`（0〜1、既定値 0.32）は各段の間のうち境界をまたいで混ぜる割合で、0 ならかみそりのように鋭く、0.3 前後で柔らかな影の境目になります。`sheen`（0〜1、既定値 0.65）は明るいピクセルのグラデーションを残すので、ハイライトががさついた段ではなく、きれいなつやに見えます。

よく使う 2 つの見た目：

| 見た目 | 呼び出し |
|---|---|
| くっきりしたアニメ調のセル | `tone_smooth(0)`, `tone_soft(0.32, 0.65)` |
| 絵画的で滑らか | `tone_smooth(1)`, `tone_bezier(0.12, 0.88)`, `tone_soft(0.32, 0.65)` |

### `set_bloom(strength, threshold)`

明るいピクセルから柔らかな光がにじみます。4 分の 1 の解像度で計算します。`strength` の既定値は 0.45（0 でオフ）、`threshold` は 0〜0.99 の輝度のしきい値です（既定値 0.74）。

### `set_fxaa(on)`

画像全体にかける軽いアンチエイリアスです（引数の既定値は 1）。ポリゴンの階段状のギザギザや輪郭線のジャギーを和らげ、平らな塗りには手を付けません。描画時にワイヤーフレームの線を滑らかにする `set_antialias` とは別物です。

### `flush_post()`

`flush_3d()` と同じように 3D キューを書き出し、すぐにポストチェーンを実行します。そのフレームでは `present()` がチェーンを省くので、`flush_post()` の後に描いた HUD はブルームもぼかしもかからず、くっきりしたままです。`post_now()` という英語名もあります。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(960, 540, "トゥーン")
    深度テスト(1)
    set_shade_mode(1)
    set_rim(0, 0, 0, 0)
    set_shadow_color(30, 30, 50)
    toon_outlines(1.5, 0, 0.05)
    set_ssao(0.4, 7, 14)
    tone_smooth(1)
    tone_bezier(0.12, 0.88)
    tone_soft(0.32, 0.65)
    set_bloom(0.5, 0.74)
    set_fxaa(1)
    間 開いている() {
        塗り潰し(20, 24, 40)
        ライト消去()
        ライト追加(-2, -6, -2, 1.0, 0.95, 0.85, 0.8, 0)
        色設定(220, 180, 120)
        球(0, 0, 8, 1.5, 1.5, 1.5, 0, 経過時間(), 0, 0)
        flush_post()
        色設定(255, 255, 255)
        UI文字(20, 20, 16, "HUD")
        表示()
    }
}
```

## 画面エフェクト

### `depth_blur(focus, range, radius, oil)`

深度バッファを使った、フレーム全体の被写界深度です。カメラ深度 `focus`（既定値 30）でくっきりし、深度が `range`（既定値 60）離れると最大のぼかし `radius` ピクセル（既定値 3）になります。ジオメトリのない背景は完全にぼけます。`oil`（0〜1、既定値 0）は、ぼけた領域に油膜のような虹色のにじみと色相の渦を加えます。水や陽炎に向いています。`dof` と `depth_of_field` という英語名もあります。

`flush_3d()` の**後**（深度バッファが埋まってから）、UI を描く**前**に呼んでください。`set_depth_test(1)` が必要です。

### `screen_distort(amount, t, step)`

端で折り返す、粘り気のある全画面のゆがみです。スライム、陽炎、夢のような演出に使います。`amount` は最大の変位のピクセル数（既定値 8）、`t` はゆがみを動かすための時刻（既定値 0）、`step` は 1 でフル解像度、2 以上で軽いブロック単位のゆがみになります（既定値 1）。`depth_blur` と同じく、3D の書き出しの後、UI の前に呼びます。ブラウザ版では使えません。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(960, 540, "陽炎")
    深度テスト(1)
    間 開いている() {
        塗り潰し(10, 20, 40)
        色設定(120, 200, 255)
        立方体(0, 0, 8, 1, 1, 1, 0, 経過時間(), 0, 0)
        立方体(3, 0, 20, 1, 1, 1, 0, 経過時間(), 0, 0)
        flush_3d()
        depth_blur(8, 6, 4, 0.3)
        screen_distort(4, 経過時間(), 2)
        表示()
    }
}
```

## ボリュメトリックライト

`light_pool` と `light_beam` は、水中やほこりっぽい空気の中を光が広がるように見える、柔らかな加算のグラデーションを描きます。外側の縁は黒へ溶けていくので、加算合成なら縁が見えません。どちらも距離フォグで薄れます。コストはフィルレートで、画面上で大きいほど重くなります。

### `light_pool(x, y, z, radius, r, g, b, intensity)`

ランプが高さ `y` の床に投げかける色付きの光だまりです。既定値は位置 0、`radius` 20、色 255（各チャンネル 0〜255）、`intensity` 1（0.2〜1.5 くらいがきれいです）。

### `light_beam(x, y, z, floor_y, radius, r, g, b, intensity)`

光の筋（ゴッドレイ）です。光源の位置から `floor_y` の床面まで伸び、`radius`（既定値 14）まで広がる二重の円錐です。根元に `light_pool` を組み合わせます。

どちらも `set_blend(1)`（加算）で描き、終わったら `set_blend(0)` に戻してください。硬い段は滑らかなグラデーションを平らな階段に変えてしまうので、`tone_smooth(1)` と組み合わせるときれいです。

```ling-gui
束縛 開始 = 実行 {
    ウィンドウ開く(720, 420, "ボリュメトリック")
    深度テスト(1)
    環境光設定(0.2)
    set_shade_mode(1)
    tone_smooth(1)
    set_bloom(0.5, 0.74)
    間 開いている() {
        塗り潰し(6, 8, 18)
        カメラ設定(1, 0, コサイン(0.25), サイン(0.25))
        カメラ座標(0, -3, 0)
        ライト消去()
        ライト追加(0, -5, 8, 1.0, 0.9, 0.7, 0.8, 0)
        色設定(220, 180, 120)
        円柱(0, 1.3, 9, 0.8, 0.7, 0.8, 0, 0, 0, 0)
        ブレンドモード(1)
        light_beam(0, -6, 9, 2, 3.0, 255, 220, 160, 0.8)
        light_pool(0, 2, 9, 5.0, 255, 220, 160, 0.9)
        ブレンドモード(0)
        flush_3d()
        表示()
    }
}
```

## 古い名前

`shadow_smooth(softness)` は `tone_smooth` と `tone_bezier` をまとめて設定する古い近道です。代わりにこの 2 つを使ってください。`toon_highlight(...)` は受け付けられますが何もしません。`tone_stop` と `tone_soft` を使ってください。
