# フォントと UI

このページでは文字とインターフェースを扱います。くっきりしたベクターの輪郭で描く TrueType と OpenType の
フォント、組み込みのストロークフォント、そしてメーター、ゲージ、操作部品をそろえた `ui_*` ツールキットです。
どれも [2D 描画](drawing.md)の呼び出しと同じフレームバッファに描くので、`fill()` と `present()` の間で使います。
3D シーンの上に描くには、先に `flush_3d()` を呼んでください。タイプライター風のダイアログボックスには
専用のページがあります: [ダイアログ](dialog.md)。

## フォント

Ling は 2 種類の文字を描きます。

* **ベクターフォント。** `font_load` が `.ttf` や `.otf` ファイルを読み込み、`font_text_fill`、`font_text`、
  `font_text_3d` がそのグリフの輪郭を描きます。曲線がそのまま保たれるので、どの大きさでも文字がくっきりします。
  フォントにグリフがあれば、ラテン文字、中国語、日本語、韓国語、タイ語のどれでも使えます。
* **ストロークフォント。** `ui_text` は、フォントファイルのいらないシンプルな等幅の「ホログラム風」書体で、
  基本的な ASCII の文字を描きます。

グリフを初めて使うとき、その輪郭はプログラムを実行したフォルダーの `cache/fonts/` の下にディスクキャッシュされ、
次からの起動が速くなります。Web ランタイムでは `font_load` が `-1` を返します。両方で動かしたいプログラムでは、
ハンドルを確かめて `ui_text` に切り替えてください。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(720, 320, "フォント")
    束縛 書体 = フォント読込("assets/fonts/Exo2.ttf", 600)
    束縛 和文 = フォント読込("assets/fonts/NotoSansJP.ttf")
    間 開いている() {
        塗り潰し(8, 10, 24)
        色設定(0, 230, 255)
        フォント塗り(書体, 30, 40, 48, "Hello Ling")
        色設定(255, 200, 80)
        フォント文字(書体, 30, 110, 48, "Stroked Outline")
        色設定(255, 255, 255)
        フォント塗り(和文, 30, 180, 40, "こんにちは、世界")
        色設定(120, 255, 160)
        UI文字(30, 260, 16, "UI TEXT 0123")
        表示()
    }
}
```

### `font_load(path, weight)`

フォントを読み込み、ハンドル（最初のフォントは 0、次は 1、以下同様）を返します。読めないときは `-1` を返し、
エラー出力にメッセージを出します。パスはまずそのまま試し、次にスクリプトのフォルダーからの相対パスとして試します。
`weight` は省略可能です。可変フォントなら 600 のような数で太字らしい見た目になります。0 か省略でフォントの既定です。

Ling のリポジトリには、Exo2、Orbitron、Rajdhani、Noto Sans（SC、JP、KR、Thai）、Galmuri が
`assets/fonts/` に入っています。プログラムを別のフォルダーから起動することがあるなら、2 つ目のパスも試しましょう。

```ling-gui
束縛 start = 実行 {
    束縛 書体 = フォント読込("assets/fonts/Exo2.ttf", 600)
    もし 書体 < 0 { 束縛 書体 = フォント読込("../../assets/fonts/Exo2.ttf", 600) }
}
```

### `font_text_fill(font, x, y, px, text)` と `font_text(font, x, y, px, text)`

`font_text_fill` はペンの色で塗りつぶしたグリフを描きます。`font_text` は輪郭だけを描き、より軽く、
`set_blend` と `set_antialias` に従います。`x, y` は行の**左上**で、ベースラインではありません。大文字は
`y` のおよそ `0.3 * px` 下から始まり、ベースラインはおよそ `0.97 * px` 下にあります。`px` はピクセル単位の
大きさです（既定は 16）。`set_font_antialias(1)` を呼ばない限り、縁はくっきりしています。不正なハンドルでは何も描かれません。

### `font_text_3d(font, cx, cy, cz, ux, uy, uz, vx, vy, vz, size, text, fill_rows)`

3D の平面上に文字を描きます。シーンと一緒に奥行きで並べ替えられるので、カメラに合わせて向きが変わります。
`c` は行の始まり、`u` は文字が進む方向（既定は `1, 0, 0`）、`v` はグリフの上方向（既定は `0, 1, 0`）、
`size` は 1 em のワールド単位での高さです（既定は 1）。+y が下向きなので、直立した文字には `v = (0, -1, 0)` が必要です。
`fill_rows` が 0 より大きくない限り輪郭だけで、大きいときは各グリフをその本数の走査線で塗りつぶします。

```ling-gui
束縛 start = 実行 {
    束縛 書体 = フォント読込("assets/fonts/Exo2.ttf", 600)
    色設定(120, 230, 255)
    フォント3D(書体, -2, 0, 8, 1, 0, 0, 0, -1, 0, 0.6, "LING 3D")
}
```

### `font_width(font, px, text)`

文字列の幅をピクセルで返します（不正なハンドルでは 0）。引数の順番に注意してください。大きさが文字列の
**前**に来ます。ボックス `bx, by, bw, bh` の中央にラベルを置くには、
`x = bx + (bw - font_width(f, px, text)) / 2`、`y = by + bh / 2 - 0.64 * px` に描きます。

### `font_advance(font, char)` と `font_glyph_outline(font, char, tol)`

`font_advance` は 1 文字の送り幅を em 単位で返します（ピクセルの大きさを掛けて使います）。
`font_glyph_outline` は独自のエフェクト用に文字の輪郭を返します。輪郭線のリストで、それぞれが em 単位の
平らなリスト `[x0, y0, x1, y1, ...]` です。ベースラインは 0 で、**y は上向き**です。`tol` は折れ線が本当の曲線から
離れてよい距離です（既定は 0.01 em）。失敗すると空になります。

### `font_fallback(primary, fallback, scale)`

`primary` にない文字すべてに `fallback` を使います。たとえば、おしゃれなラテン文字のフォントの後ろに、
収録文字の多い Unicode フォントを置けます。`scale` は primary に対する fallback の大きさです（既定は 1）。
`fallback` に `-1` を渡すと解除されます。primary のハンドルを返し、ハンドルが不正なら `-1` を返します。

```ling-gui
束縛 start = 実行 {
    束縛 欧文 = フォント読込("assets/fonts/Orbitron.ttf", 600)
    束縛 和文 = フォント読込("assets/fonts/NotoSansJP.ttf")
    font_fallback(欧文, 和文, 0.9)
}
```

### `set_font_antialias(on)` と `get_font_antialias()`

グリフのなめらかさをオン・オフします（既定はオフで、くっきりした文字になります）。引数なしの
`set_font_antialias()` でオンになります。これは線の描画に効く `set_antialias` とは別の設定です。

### `ui_text(x, y, scale, text)`

組み込みのストロークフォントで、ペンの色で文字を描きます。`x, y` は左上で、グリフの高さは `scale`
ピクセル（既定は 16）、各グリフの幅は `scale * 0.62`、間隔は `scale * 0.24` です。英字は大文字で描かれ、
書体にない文字（ASCII 以外のすべての文字を含む）は小さな四角で表示されます。

## UI ツールキット

`ui_*` の組み込み関数は**イミディエイトモード**のツールキットです。フレームの間には何も保存されません。
各ウィジェットを毎フレーム現在の値とともに呼ぶと、それが自分を描き、操作部品なら新しい値を返します。
状態はすべて、プログラムが普通の変数で持ちます。

```ling-gui
束縛 start = 実行 {
    ウィンドウ開く(480, 220, "操作部品")
    束縛 音量 = 0.4
    束縛 有効 = 0
    間 開いている() {
        塗り潰し(6, 10, 22)
        束縛 音量 = スライダー(40, 60, 280, 音量, 0, 1)
        束縛 有効 = トグル(40, 100, 52, 24, 有効)
        もし ボタン(40, 150, 120, 36) == 1 { println("クリックされました") }
        色設定(220, 240, 255)
        UI文字(64, 160, 14, "PLAY")
        表示()
    }
}
```

共通の決まり:

* **座標**は画面ピクセルです。長方形のウィジェットは `x, y, w, h`、丸いものは中心 `cx, cy` と半径 `r` をとります。
* **色**はテーマ（`ui_theme`）から取ります。ほとんどのウィジェットは、その呼び出しだけ主な色を上書きする
  省略可能な `r, g, b` を最後に受け付けます。3 つすべてを渡すか、どれも渡さないかのどちらかです。
* **ウィジェットは文字を描きません。** ボタンにはラベルがなく、タブにも見出しがありません。ラベルは
  `ui_text` や `font_text_fill` で自分で描いてください。
* **操作**はマウスの左ボタンを読みます。ボタンはマウスがその上で押された 1 フレームだけ `1` を返すので、
  `== 1` で比べてください。これには毎フレーム 1 回の `present()` が必要です。
* **合成。** ウィジェットは `set_blend` に従うので、`set_blend(1)` にすると光って見えます。

### `ui_theme(...)` と `ui_theme_colors()`

`ui_theme` は、すべてのウィジェットが使う色を設定します。`r, g, b` の組を 6 つ、primary、accent、track
（メーターの暗い背景）、warn、text、bg（パネルの塗り）の順に渡します。省略した組は今の値のままなので、
`ui_theme(255, 0, 128)` は primary だけを変えます。`ui_theme_colors()` は現在のテーマを 18 個の数のリストで返すので、
自分で描いたインターフェースの色を合わせられます。

```ling
束縛 start = 実行 {
    UIテーマ(255, 0, 128)
    println(ui_theme_colors())
}
```

```output
[255, 0, 128, 40, 255, 180, 44, 62, 100, 255, 90, 90, 190, 235, 255, 10, 16, 24]
```

出力からは、ほかの 5 色の組み込みの既定値もわかります。

### レイアウトの補助: `ui_hot`、`ui_frame`、`ui_bevel`、`ui_panel`、`ui_scanlines`

`ui_hot` はマウスが長方形の中にあると `true` を返します。ホバー効果や自作の操作部品に使います。
`ui_frame`（ブラケットの腕の長さ、既定は 14）と `ui_bevel`（角の切り込み、既定は 10）はペンの色で輪郭を描きます。
`ui_panel` はテーマの bg の色で塗った角切りのパネルを描きます（切り込みの既定は 12、6 番目の引数から
枠の色を指定可能）。`ui_scanlines` は `density` 本の横線を描きます（既定は 24）。

```ling-gui
束縛 start = 実行 {
    パネル(20, 20, 340, 200, 14)
    もし ホットエリア(40, 140, 120, 36) { 色設定(255, 255, 255) } 他 { 色設定(120, 140, 160) }
    ベベル枠(40, 140, 120, 36, 8)
}
```

### HUD: `ui_radar`、`ui_compass`、`ui_reticle`、`ui_target`

`ui_radar` は距離の輪と、ラジアン単位の角度 `sweep` の走査線を描きます。`time_now()` で動かしましょう。
`ui_compass` は**度**単位の `heading` を中心にした帯を表示し、15 度ごとに目盛りがあります。
`ui_reticle` は、`spread` が 0 から 1 になるにつれて隙間が開く輪を描きます。`ui_target` は、`lock` が 0 から 1 に
なるにつれて狭まるブラケットを描きます。

### メーター: `ui_bar`、`ui_segbar`、`ui_gauge`、`ui_ring`、`ui_vu`、`ui_spark`、`ui_battery`、`ui_progress`

どのメーターも `max`（既定は 1）に対する `value` を表示します。`ui_segbar` はバーを `segments` 個のブロックに
分けます（既定は 10）。`ui_gauge` は針のある文字盤、`ui_ring` は時計回りに満ちていきます。`ui_vu` は 0 から 1 の
レベルのリストをとり、それぞれを 1 本のバーにして、上がるほど warn の色に近づけます。`ui_spark` は 2 つ以上の数の
リストを枠に収まるように拡大縮小します。`ui_battery` は 25 パーセントを下回ると warn の色になります。
`ui_progress` は 0 から 1 の `fraction` ひとつをとります。

```ling-gui
束縛 start = 実行 {
    バー(40, 70, 280, 14, 70, 100)
    分割バー(40, 96, 280, 14, 6, 10, 10)
    ゲージ(450, 120, 50, 62, 100)
    VUメーター(330, 330, 160, 60, [0.2, 0.5, 0.8, 1.0, 0.7, 0.3])
}
```

### 操作部品: `ui_button`、`ui_toggle`、`ui_slider`、`ui_checkbox`、`ui_tabs`、`ui_stepper`、`ui_tooltip`

- `ui_button` はホバーで明るくなり、クリックされたフレームで `1`、それ以外で `0` を返します。
- `ui_toggle` と `ui_checkbox` は現在の状態をとり、新しい状態 `1` か `0` を返します。
- `ui_slider` には高さの引数がありません（つかめる範囲は高さ 20 ピクセル）。新しい値を返し、
  ボタンを押している間は値がカーソルに追従します。
- `ui_tabs` は `count` 個の同じ幅のタブを描き、選ばれている番号（0 から）を返します。見出しを置くには
  幅を `count` で割ってください。
- `ui_stepper` は、どちらかの側がクリックされると `value` に `step` を足すか引いた値を返します。数字は描きません。
- `ui_tooltip` は吹き出しです。何かがホバーされたときにカーソルの近くに描きます。

```ling-gui
束縛 start = 実行 {
    束縛 選択タブ = 0
    束縛 個数 = 3
    束縛 選択タブ = タブ(20, 250, 300, 28, 3, 選択タブ)
    束縛 個数 = ステッパー(160, 178, 140, 28, 個数, 1)
    UI文字(222, 186, 14, str(個数))
}
```

### ゲーム UI: `ui_healthbar`、`ui_cooldown`、`ui_counter`、`ui_minimap`、`ui_dpad`、`ui_slotgrid`、`ui_vignette`

`ui_healthbar` は、空のときの warn の色から満タンのときの accent の色へ変わります。`pulse`（0 から 1）を指定すると、
30 パーセントを下回ったときに白に向かって点滅します。`ui_cooldown` は 12 時の位置から時計回りに扇形を塗ります。
`ui_counter` は `value` を `digits` 桁の 7 セグメント数字で表示します。`ui_minimap` は空の地図の枠を描くので、
点は `draw_disc` で自分で描きます。`ui_dpad` は、マウスを押している間、`0` なし、`1` 上、`2` 右、`3` 下、`4` 左を返します。
`ui_slotgrid` は `selected` 番目の欄を強調します（`-1` でなし）。`ui_vignette` は画面の縁を光らせるので、ダメージの演出に使えます。

```ling-gui
束縛 start = 実行 {
    束縛 体力 = 24
    体力バー(20, 300, 220, 16, 体力, 100, 0.5 + 0.5 * サイン(経過時間() * 8))
    カウンター(20, 340, 16, 28, 1234, 5)
    スロットグリッド(400, 260, 5, 2, 40, 1)
}
```

### 疑似 3D: `ui_gauge3d`、`ui_panel3d`、`ui_radar3d`

`ui_gauge3d` は `spin` で回るワイヤーフレームの帯を描き、`value` まで光らせます。`ui_panel3d` は角切りのパネルを
`depth` ピクセル（既定は 14）だけ画面から浮かせます。`ui_radar3d` はレーダーを画面の奥へ傾けます
（`tilt` は 0 から 1、既定は 0.9）。

### `ui_sound(name)`

短い合成のインターフェース音を鳴らします。`"click"`（知らない名前のときもこれ）、`"hover"`、`"confirm"`、
`"toggle"`、`"tick"`、`"error"` のいずれかです。オーディオが動いていなければ鳴りません。

```ling-gui
束縛 start = 実行 {
    もし ボタン(20, 400, 120, 36) == 1 { UI音("confirm") }
}
```
