# 入力とマイク

Ling は**ポーリング**で入力を読みます。毎フレーム、ループの中で「プレイヤーは今何を
しているか」を尋ねます。コールバックはありません。このページでは、キーボードとマウス、
文字入力、ゲームコントローラー（`gilrs` ライブラリと `ling-input` クレート経由）、
マイク（`ling-mic` クレート）を扱います。

どの入力用組み込み関数も、デバイスがなくても安全に呼べます。キーやボタンは押されて
いない、軸は `0`、マイクは無音として読めます。そのためゲームは特別な処理なしで
キーボード操作に切り替えられます。ハードウェアがあるかどうかは、`mic_open` か
`pad_poll` の戻り値で確かめてください。

キーボード、マウス、文字入力がイベントを受け取るには、ウィンドウが開いている必要が
あります。ウィンドウがなければ、何も起きていない状態として読めます。

```ling
束縛 開始 = 実行 {
  印刷(キー押す("space"))
  印刷(キー押した("enter"))
  印刷(mouse_down())
  印刷(ホイール())
  印刷(マイクRMS())
  印刷(リアルタイムFFT(4))
}
```

```output
false
false
false
0
0
[0, 0, 0, 0]
```

## キーボード

### `key_down(name)` と `key_pressed(name)`

`key_down` はキーを押している間ずっと真で、移動に向いています。`key_pressed` はキーが
押されたその 1 フレームだけ真で、押しっぱなしでも繰り返しません。切り替え、メニュー、
1 回押すごとの発射に向いています。

どちらも小文字のキー名を受け取ります。未知の名前は単に `false` です。別のウィンドウに
フォーカスがある間は、どちらも `false` になります。ゲームコントローラーの Start ボタンも
`key_pressed("enter")` として数えられるので、Enter を待つメニューはパッドでも操作できます。

| グループ | 名前 |
|---|---|
| 英字・数字 | `"a"`〜`"z"`、`"0"`〜`"9"` |
| 矢印と移動 | `"left"`、`"right"`、`"up"`、`"down"`、`"home"`、`"end"`、`"pageup"`、`"pagedown"`、`"insert"`、`"delete"` |
| 編集 | `"space"`、`"enter"`、`"escape"`、`"tab"`、`"backspace"`、`"capslock"` |
| 修飾キー | `"lshift"`、`"rshift"`、`"lctrl"`、`"rctrl"`、`"lalt"`、`"ralt"` |
| ファンクションキー | `"f1"`〜`"f12"` |
| テンキー | `"numpad0"`〜`"numpad9"`（または `"kp0"`〜`"kp9"`）、`"numpad+"`、`"numpad-"`、`"numpad*"`、`"numpad/"` |
| 記号 | `"minus"`、`"equals"`、`"comma"`、`"period"`、`"slash"`、`"semicolon"`、`"quote"`、`"lbracket"`、`"rbracket"`、`"backslash"`、`"grave"`（記号そのものも使えます） |

```ling-gui
束縛 開始 = 実行 {
  ウィンドウ開く(800, 600)
  束縛 x = 400
  束縛 一時停止 = 0
  間 開いている() {
    もし キー押した("p") { 束縛 一時停止 = 1 - 一時停止 }
    もし 一時停止 == 0 {
      もし キー押す("left") { 束縛 x = x - 4 }
      もし キー押す("right") { 束縛 x = x + 4 }
    }
    塗り潰し(0, 0, 0)
    色設定(255, 255, 255)
    塗りつぶし円(x, 300, 20)
    表示()
  }
}
```

### 文字入力

名前の入力やチャットでは、Ling に文字を集めさせられます。`text_poll()` は前回の呼び出し
以降に入力されたキーをテキストバッファに加え（Backspace で削除、押しっぱなしで繰り返し）、
バッファ全体を返します。入力欄が有効な間は毎フレーム 1 回呼んでください。`text_get()` は
ポーリングせずにバッファを読み、`text_set(s)` は置き換え、`text_clear()` は空にします。

```ling
束縛 開始 = 実行 {
  text_set("エイダ")
  印刷(text_get())
  text_clear()
  印刷("[" + text_get() + "]")
}
```

```output
エイダ
[]
```

## マウス

- `mouse_x()`、`mouse_y()`：ウィンドウ内のカーソル位置（ピクセル）。ウィンドウができるまでは
  どちらも `0` です。
- `mouse_down()`、`mouse_down_right()`、`mouse_down_middle()`：そのボタンを押している間は真。
  状態を見るだけなので、クリックを検出するには前のフレームの値と比べます。
- `mouse_scroll()`、`mouse_scroll_x()`：直前のフレームのホイール移動量。何もしなければ `0`。
- `mouse_dx()`、`mouse_dy()`：前のフレームからマウスが動いた量。`dx` の正は右、`dy` の正は
  下です。マウスをキャプチャしている間だけ 0 以外になります。
- `capture_mouse()` はカーソルを隠して相対移動に切り替えるので、マウスをどれだけ動かしても
  `mouse_dx` と `mouse_dy` が報告し続けます。一人称視点の基本です。`release_mouse()` で
  元に戻します。Esc キーでは引き続きウィンドウが閉じます。
- `cursor_hide()`、`cursor_show()` はポインタだけを隠す・表示します。位置は普通に追跡される
  ので、自分でカーソルを描くゲームに向いています。

```ling-gui
束縛 開始 = 実行 {
  ウィンドウ開く(800, 600)
  束縛 前回 = 偽
  間 開いている() {
    束縛 今回 = mouse_down()
    もし 今回 && !前回 {
      印刷("クリック位置 " + str(mouse_x()) + ", " + str(mouse_y()))
    }
    束縛 前回 = 今回
    塗り潰し(0, 0, 0)
    表示()
  }
}
```

## ゲームコントローラー

系統は 2 つあります。使うべきなのは **`pad_*`** 系統です。最大 4 人、エッジ検出付きの
ボタン、アナログトリガーがあり、デスクトップでもブラウザ（W3C Gamepad API を使用）でも
同じコードで動きます。古い **`gamepad_*`** 系統は、最後に使われたコントローラーを名前で
読み、コントローラーを振動させられるのはこちらです。

### `pad_*` 系統

何かを読む前に、毎フレーム 1 回 `pad_poll()` を呼んでください。コントローラーのイベントを
取り出し、エッジ検出を進め、接続中のパッド数を返します。プレイヤー枠は `0`〜`3` です。
最初の呼び出しでコントローラーのバックエンドを開きます。失敗すると `0` を返し、以後の
読み取りはすべて中立の値になります。

- `pad_button(player, name)`：ボタンを押している間は真。
- `pad_pressed(player, name)`：押したフレームだけ真。ブラウザ版では現在の状態しか分からない
  ので、`pad_button` と同じ動きになります。
- `pad_lx`、`pad_ly`、`pad_rx`、`pad_ry`：スティックの軸（`-1`〜`1`）。スティックを**上**に
  倒すと `y` は**負**になり、画面の向きと一致します。デッドゾーンはないので、小さな値は
  自分で無視してください。
- `pad_lt`、`pad_rt`：アナログトリガー。`0`（離した状態）〜`1`（いっぱいに引いた状態）。
- `pad_connected(player)`、`pad_count()`：どの枠が埋まっているか。
- `pad_rumble(player, low, high)`：現在はデスクトップでもブラウザでも何もしません。振動には
  `gamepad_rumble` を使ってください。

ボタン名は大文字小文字を区別せず、同じボタンを指す名前がいくつかあります。デスクトップでは
フェイスボタンは位置で決まり、どのメーカーでも下のボタンが `a` です。

| ボタン | 名前 |
|---|---|
| 下のフェイスボタン | `a`、`south`、`cross` |
| 右のフェイスボタン | `b`、`east`、`circle` |
| 左のフェイスボタン | `x`、`west`、`square` |
| 上のフェイスボタン | `y`、`north`、`triangle` |
| ショルダー | `lb`、`l1`、`left_shoulder`；`rb`、`r1`、`right_shoulder` |
| トリガー（デジタル） | `lt`、`l2`、`left_trigger`；`rt`、`r2`、`right_trigger` |
| スタート / セレクト | `start`、`menu`、`options`；`select`、`back`、`share`、`view` |
| ガイド | `guide`、`home` |
| スティック押し込み | `l3`、`left_stick`；`r3`、`right_stick` |
| 十字キー | `up`/`dpad_up`、`down`/`dpad_down`、`left`/`dpad_left`、`right`/`dpad_right` |

```ling-gui
束縛 開始 = 実行 {
  ウィンドウ開く(800, 600)
  束縛 x = 400.0
  束縛 y = 300.0
  間 開いている() {
    パッド更新()
    もし パッド接続(0) {
      束縛 x = x + パッド左X(0) * 5.0
      束縛 y = y + パッド左Y(0) * 5.0
      もし パッド押下(0, "a") { 印刷("ジャンプ") }
    }
    塗り潰し(0, 0, 0)
    色設定(255, 255, 255)
    塗りつぶし円(x, y, 20)
    表示()
  }
}
```

### `gamepad_*` 系統

毎フレーム 1 回 `gamepad_poll()` を呼びます。最後に操作されたコントローラーが現在の
コントローラーになります。ブラウザ版では `gamepad_poll` と `gamepad_rumble` は何もしない
ので、そこでは `pad_*` を使ってください。

- `gamepad_button(name)`：押している間は `1`、それ以外は `0`。名前：`a`、`b`、`x`、`y`、
  `l1`、`r1`、`l2`、`r2`、`l3`、`r3`、`start`、`select`、`dup`、`ddown`、`dleft`、`dright`。
- `gamepad_axis(name)`：`lx`、`ly`、`rx`、`ry`（スティック、`-1`〜`1`）と `l2`、`r2`
  （トリガー）。こちらはスティックを上に倒すと `y` が**正**になり、`pad_ly` とは逆です。
- `gamepad_rumble(low, high, ms)`：重いモーター（`low`）と軽いモーター（`high`）を、それぞれ
  `0`〜`1` の強さで `ms` ミリ秒（既定値 200）振動させます。フォースフィードバックのない
  コントローラーでは何も起きません。
- `gamepad_list()`：システムが認識しているコントローラーを 1 行ずつ、名前、接続の有無、
  振動の可否、ボタン割り当ての出どころとともに返します。おかしな動きをするコントローラーの
  診断に使います。
- `gamepad_any()`：標準ボタンのどれかが押されていれば `1`。

```ling-gui
束縛 開始 = 実行 {
  印刷(gamepad_list())
  gamepad_poll()
  もし gamepad_button("a") == 1 {
    gamepad_rumble(0.4, 0.8, 250)
  }
}
```

## マイク

`mic_open()` は既定の入力デバイスから 44.1 kHz モノラルで録音を始め、成功すれば `1`、
デバイスがないかアクセスを拒否されたら `0` を返します。呼ぶのは 1 回だけで、その後の
レベルの読み取りにはほとんどコストがかかりません。

- `mic_rms()`：最新バッファの音量（二乗平均平方根）、`0`〜`1`。
- `mic_peak()`：最新バッファのサンプルの絶対値の最大、`0`〜`1`。
- `mic_fft(bands)`：20 Hz から対数間隔で分けた `bands` 個（既定値 8）の帯域の、平滑化した
  大きさのリスト。低音が先です。マイクが閉じている間はすべて 0 です。

```ling-gui
束縛 開始 = 実行 {
  ウィンドウ開く(640, 240)
  もし マイク開く() == 0 { 印刷("マイクがありません") }
  間 開いている() {
    束縛 帯域 = リアルタイムFFT(16)
    塗り潰し(0, 0, 0)
    色設定(80, 200, 255)
    束縛 i = 0
    間 i < 長さ(帯域) {
      束縛 高さ = 帯域[i] * 200.0
      束縛 x = i * 40
      三角形描画(x, 230, x + 30, 230, x + 30, 230 - 高さ)
      三角形描画(x, 230, x + 30, 230 - 高さ, x, 230 - 高さ)
      束縛 i = i + 1
    }
    表示()
  }
}
```

歌に点数を付けるには、マイクと音楽の組み込み関数を組み合わせます。`music_mic_pitch()`
（`マイク音程`）が毎フレーム歌った周波数を返します。[音楽](../reference/music.md)を参照してください。

### シードを録る

`mic_capture()` は最新のサンプルを録音バッファに追加し（直近 96000 サンプルを保持）、
その長さを返します。録音中は毎フレーム呼んでください。`mic_seed()` はバッファの音声の
SHA3-256 ハッシュを 64 文字の 16 進数で返し、そのまま乱数生成器のシードに使えます。
`mic_clear()` はバッファを空にします。マイクが閉じているとバッファは空のままで、シードは
空の入力のハッシュになります。

```ling
束縛 開始 = 実行 {
  印刷(mic_capture())
  印刷(mic_seed())
  印刷(mic_clear())
}
```

```output
0
d75a5e3ee36c258bec7dced963d55ef24bda7d06d0cef7708f2ecca8371a95f7
0
```
