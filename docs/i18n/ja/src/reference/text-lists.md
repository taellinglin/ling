# テキストとリスト

テキスト（文字列）とリストは、Ling で毎日のように使う 2 つのコレクションです。このページでは、テキストを測る・探す・切り出す・変換する組み込み関数と、
リストを作る・読む組み込み関数を扱います。もっとやさしい入門は[リストとテキスト](../tutorials/lists-text.md)のチュートリアルを参照してください。

ページ全体に共通するルールが 2 つあります。

- **組み込み関数は入力を変更しません。** 新しい値を返すので、結果を束縛し直してください：
  `束縛 xs = リスト追加(xs, 5)`。
- **不正な入力でもエラーになることはまれです。** 範囲外のインデックスや解釈できない数値は、エラーではなく
  代わりの値（`""`、`0`、`-1`）になります。どれになるかは各項目に書いてあります。

## テキスト

### 連結と変換

`+` はテキストを連結し、どちら側の数値もテキストに変換します。`to_str` は任意の値を明示的にテキストに変換します。
`to_number` は前後の空白を無視し、読めないものには **`0`** を返すので、`"0"` と不正な入力を区別できません。
16 進数は読めないので、それには `hex_to_number` を使います。

```ling
束縛 start = 実行 {
  印刷("得点：" + 10)
  印刷(to_str(3) + "！")
  印刷(to_number(" 42 ") + 1, " ", to_number("abc"))
  印刷(hex_to_number("ff"))
}
```
```output
得点：10
3！
43 0
255
```

### `len(value)`

テキストの文字数やリストの要素数を数えます。それ以外の値は `0` です。メソッド形式の `"テキスト".len()` は
**バイト数**を数えるので、ASCII 以外のテキストでは結果が変わります。

```ling
束縛 start = 実行 {
  印刷(長さ("Ling"), " ", 長さ([1, 2, 3]))
  印刷(長さ("日本"), " ", "日本".len())
}
```
```output
4 3
2 6
```

### 検索

`starts_with`、`ends_with`、`str_contains` は `true` か `false` を返します。`str_find` は最初に一致した位置を
0 から数えた文字インデックスで返し、見つからなければ `-1` を返します。メソッド `text.contains(part)` も使えます。

```ling
束縛 start = 実行 {
  束縛 語 = "こんにちは"
  印刷(starts_with(語, "こん"), " ", ends_with(語, "ちは"))
  印刷(str_contains(語, "にち"), " ", 語.contains("さよ"))
  印刷(str_find(語, "に"), " ", str_find(語, "さ"))
}
```
```output
true true
true false
2 -1
```

### 切り出しと変更

`substr(text, start, length)` は 0 から文字単位で数えます。`length` を省くと末尾までです。
範囲外の値は範囲内に収められ、エラーにはなりません。`str_replace` はすべての出現箇所を置き換えます。

```ling
束縛 start = 実行 {
  印刷(substr("hello", 1, 3), " ", substr("hello", 2))
  印刷(str_replace("a-b-c", "-", "+"))
  印刷(trim("   余白   ") + "|")
  印刷(str_upper("Ling"), " ", str_lower("LING"))
  印刷(str_repeat("ハ", 3), " ", str_strip_prefix("v1.2", "v"))
}
```
```output
ell llo
a+b+c
余白|
LING ling
ハハハ 1.2
```

### `split(text, sep)`

文字列のリストを返します。区切りを省く（または `""` を渡す）と改行で分割します。空白は取り除かないので、
区切りが 2 つ続くと空の文字列ができます。

```ling
束縛 start = 実行 {
  印刷(split("いち に さん", " "))
  印刷(split("a,b,,c", ","))
  印刷(長さ(split("1 行目\n2 行目")))
}
```
```output
[いち, に, さん]
[a, b, , c]
2
```

### 文字とハッシュ

`ord` は最初の文字のコードポイント（空のテキストなら `-1`）を返し、`chr` はコードポイントを 1 文字のテキストに戻します。
`hash_str` と `hash_int` は同じテキストに対して毎回同じ値を返すので、名前から決まった色やバリエーションを選ぶのに便利です。

```ling
束縛 start = 実行 {
  印刷(ord("A"), " ", chr(97))
  印刷(hash_str("りんご") == hash_str("りんご"))
  印刷(hash_int("apple", 10))
}
```
```output
65 a
true
5
```

## リスト

### 作成と読み取り

リストは `[1, 2, 3]` とそのまま書くか、`list_new()` から始めて `list_push` で要素を加えます。
要素は `xs[i]`（0 始まり）か `list_get(xs, i)` で読みます。違いは範囲外のときの動きで、
`list_get` は `""` を返し、`xs[i]` はインタプリタではエラーになります。`list_set` は要素を 1 つ置き換えたコピーを返し、範囲外のインデックスは無視します。

```ling
束縛 start = 実行 {
  束縛 表 = 新規リスト()
  束縛 表 = リスト追加(表, "あ")
  束縛 表 = リスト追加(表, "い")
  束縛 表 = list_set(表, 0, "う")
  印刷(表, " ", 長さ(表))
  印刷(表[1], " ", list_get(表, 0))
  印刷(list_get(表, 9) == "")
}
```
```output
[う, い] 2
い う
true
```

メソッド `xs.push(value)` は `list_push` と同じ働きをします。結果は必ず束縛し直してください。インタプリタは元のリストを変えませんが、
既定のバックエンドはその場で変えることがあり、どちらの動きにも頼るべきではありません。

### 組み合わせ

```ling
束縛 start = 実行 {
  印刷(list_join(["あ", "い", "う"], "、"))
  印刷(list_join([1, 2, 3], "-"))
  印刷(list_cat([1, 2], [3]), " ", list_iota(4))
  印刷(list_max([3, 9, 2], 0), " ", list_min([], 0 - 1))
}
```
```output
あ、い、う
1-2-3
[1, 2, 3] [0, 1, 2, 3]
9 -1
```

### map と filter の代わりにループ

`list_map`、`list_filter`、`list_find` は関数を受け取りますが、組み込み関数に渡した関数はインタプリタ
（`ling run --interp`）でしか動きません。既定のバックエンドでは代わりに `()` が渡されます。`list_filter` は関数がちょうど `true` を返したときだけ要素を残します。

```ling-module
関数 二倍(表) { list_map(表, |x| x * 2) }
```

`sort`、`slice`、`reverse` の組み込み関数もありません。どれも `while` ループで書け、すべてのバックエンドで動きます。
値を積み上げるときは `for` ではなく `while` を使ってください。`for` の本体の中の `bind` は外側のスコープに届きません。

```ling
束縛 start = 実行 {
  束縛 数 = [3, 1, 2, 4]
  束縛 合計 = 0
  束縛 逆順 = 新規リスト()
  束縛 i = 長さ(数) - 1
  間 i >= 0 {
    束縛 合計 = 合計 + 数[i]
    束縛 逆順 = リスト追加(逆順, 数[i])
    束縛 i = i - 1
  }
  印刷(合計, " ", 逆順)
}
```
```output
10 [4, 2, 1, 3]
```
